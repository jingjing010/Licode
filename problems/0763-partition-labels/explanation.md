# 763. 划分字母区间 —— 小白详细题解

> 这是一道"区间合并"味道的贪心题。关键是先记住**每个字母最后一次出现在哪**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把字符串切成尽量多的段，要求**同一个字母只能出现在一段里**。返回每一段的长度。

拿示例 1 `s = "ababcbacadefegdehijhklij"` 来说：

| 片段 | 内容 | 长度 |
|---|---|---|
| 第 1 段 | `ababcbaca` | 9 |
| 第 2 段 | `defegde` | 7 |
| 第 3 段 | `hijhklij` | 8 |

第 1 段里出现了 a、b、c，它们在后面都不再出现；第 2 段的 d、e、f、g 也是如此。

**几个需要注意的细节：**

1. 要切成**尽可能多**的段，`[24]`（整个不切）虽然合法但不是答案。
2. 片段必须按原来的顺序连起来等于 `s`，不能打乱字符。
3. 返回的是每段的**长度**，不是字符串本身。

---

## 🧰 第二步：这道题需要的 C 语言知识

1. **用字符做下标**：`s[i] - 'a'` 把字母 `'a'~'z'` 变成 `0~25`，于是可以用 `int last[26]` 记录每个字母的信息。
2. **`strlen(s)`**：求字符串长度（不包括末尾的 `'\0'`），来自 `<string.h>`。
3. **返回数组 + `*returnSize`**：结果数组要用 `malloc` 申请，片段个数写进 `*returnSize`。片段数最多等于字符串长度，所以申请 `n` 个 int 一定够。

---

## 💡 第三步：思路一 —— 逐个尝试切点（朴素）

### 思路

从当前段的起点 `start` 开始，依次尝试把段的结尾放在 `e`：检查 `s[start..e]` 中的每个字母是否都**不在** `e` 后面出现。第一个满足条件的 `e` 就是最短的合法切点，切下来，继续处理后面。

### 代码

```c
int* partitionLabels(char* s, int* returnSize) {
    int n = (int)strlen(s);
    int* res = (int*)malloc(sizeof(int) * n);   // 片段数最多 n 个
    int cnt = 0;
    int start = 0;

    while (start < n) {
        // 尝试让当前片段在 e 处结束
        for (int e = start; e < n; e++) {
            bool ok = true;
            // 检查 s[start..e] 中的字母是否在 e 之后还出现
            for (int i = start; i <= e && ok; i++) {
                for (int j = e + 1; j < n; j++) {
                    if (s[j] == s[i]) { ok = false; break; }
                }
            }
            if (ok) {                       // 找到最短的合法片段
                res[cnt++] = e - start + 1;
                start = e + 1;
                break;
            }
        }
    }
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n³)**：三层循环。本题 n ≤ 500，最坏约 10⁸ 量级但实际远小于此，能过；n 再大就不行了。
- **空间复杂度 O(1)**（不计返回数组）。

---

## 🚀 第四步：思路二 —— 贪心 + 最后出现位置

### 思路

思路一慢在"反复检查某个字母后面还有没有"。其实只要**预先记下每个字母最后出现的下标** `last[c]`：

- 当前片段从 `start` 开始，片段里只要出现了字母 `c`，片段就至少要延伸到 `last[c]`
- 从左往右扫描，维护 `end = max(end, last[s[i]])`
- 当 `i == end` 时，说明片段里所有字母的最后一次出现都已经包含进来了 → 切！

### 手动模拟（示例 2：`"eccbbbbdec"`）

`last`：e→8，c→9，b→6，d→7

| i | s[i] | last[s[i]] | end | i == end？ |
|---|---|---|---|---|
| 0 | e | 8 | 8 | 否 |
| 1 | c | 9 | 9 | 否 |
| 2~8 | … | ≤ 9 | 9 | 否 |
| 9 | c | 9 | 9 | **是** → 切出长度 10 |

结果 `[10]`。

### 代码

```c
int* partitionLabels(char* s, int* returnSize) {
    int n = (int)strlen(s);

    // 1. 记录每个字母最后一次出现的下标
    int last[26];
    for (int i = 0; i < n; i++) {
        last[s[i] - 'a'] = i;       // 后出现的会覆盖先出现的，最终就是"最后一次"
    }

    // 2. 贪心划分
    int* res = (int*)malloc(sizeof(int) * n);   // 片段数最多 n 个
    int cnt = 0;
    int start = 0, end = 0;          // 当前片段的起点和（至少要到的）终点
    for (int i = 0; i < n; i++) {
        int lastPos = last[s[i] - 'a'];
        if (lastPos > end) end = lastPos;       // 片段必须包含 s[i] 的最后一次出现
        if (i == end) {                         // 片段内所有字母都"收尾"了
            res[cnt++] = end - start + 1;
            start = i + 1;                      // 下一个片段从 i+1 开始
        }
    }

    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：扫描两遍。
- **空间复杂度 O(1)**：`last` 只有 26 个元素（不计返回数组）。

---

## ⚠️ 第五步：小白常见错误

1. **`last[s[i]]` 忘记减 `'a'`** → `s[i]` 是 97~122 的 ASCII 码，直接当下标会越界。
2. **`end = last[s[i] - 'a']` 而不是取最大值** → 后面遇到一个更早结束的字母会把 `end` 缩小，切得太早，片段中会有字母在后面再出现。
3. **忘记更新 `start`** → 片段长度用 `end - start + 1` 计算，`start` 不更新就会把前面的片段长度也算进去。
4. **忘记设置 `*returnSize`** → 判题程序不知道你返回了几个数，输出为空或乱码。
5. **用局部数组 `int res[500]` 返回** → 函数结束后内存失效，必须用 `malloc`。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 |
|---|---|---|---|
| 逐个尝试切点 | O(n³) | O(1) | ⭐ |
| 贪心 + 最后出现位置 | O(n) | O(26) | ⭐⭐ |

## 🔗 举一反三

- **56. 合并区间**：把每个字母看成区间 `[第一次出现, 最后一次出现]`，本题其实就是"合并重叠区间后数每块的长度"。
- **55. 跳跃游戏**：同样是"一边扫描一边维护最远边界"。
