# 9035. 实现 strlen —— 小白详细题解

> `strlen` 可能是最短的面试题：三行代码。但它是理解 C 字符串的钥匙——**C 的字符串没有长度，只有一个结尾标记 `'\0'`**。后面的 strcpy、strcat、strcmp、strstr 全部建立在这个约定之上。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 从字符串第一个字节开始往后数，数到值为 0 的那个字节为止，0 本身不算。

拿示例 1 来说，`"hello"` 在内存里是这样存的：

| 地址偏移 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 字符 | `'h'` | `'e'` | `'l'` | `'l'` | `'o'` | `'\0'` |
| 字节值 | 104 | 101 | 108 | 108 | 111 | **0** |

`'\0'` 在偏移 5，所以长度是 **5**；但它实际占用 **6** 个字节。

**几个需要注意的细节：**

1. 空串 `""` 只有一个 `'\0'`，长度为 0（示例 2）。
2. 统计的是**字节数**：UTF-8 中文每个字 3 字节，`"温度:25C"` 长度是 10 不是 6（示例 3）。
3. 换行符 `'\n'`、空格都是普通字符，要计入长度。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `'\0'` 和 `'0'` 和 `"0"` 的区别

| 写法 | 含义 | 值 |
|---|---|---|
| `'\0'` | 空字符，字符串结束标记 | 0 |
| `'0'` | 数字字符 0 | 48 |
| `"0"` | 字符串，占 2 个字节：`'0'` 和 `'\0'` | — |

所以 `while (*p != '\0')` 也可以简写成 `while (*p)`——值为 0 就是"假"。

### 2. 指针相减

两个指向**同一个数组**的指针相减，结果是它们之间相差的**元素个数**（类型是 `ptrdiff_t`）。`char` 一个元素一个字节，所以 `p - s` 就是字节数。

### 3. `size_t` 返回值

长度不可能是负数，标准库用无符号的 `size_t`。打印时本 OJ 不能用 `%zu`，要转成 `(long long)` 再用 `%lld`（判题程序已经帮你处理好了）。

### 4. `sizeof` 和 `strlen` 不是一回事

```c
char buf[32] = "hello";
sizeof(buf);   // 32：数组占多少字节，编译时就确定了
strlen(buf);   // 5：运行时数到 '\0'
```

## 💡 第三步：思路一 —— 计数器（最朴素）

### 思路

用一个整数 `len` 当下标，`s[len]` 不是 `'\0'` 就 `len++`。

### 手动模拟（`s = "hi"`）

| len | s[len] | 是 '\0' 吗 | 动作 |
|---|---|---|---|
| 0 | `'h'` | 否 | len = 1 |
| 1 | `'i'` | 否 | len = 2 |
| 2 | `'\0'` | 是 | 返回 2 |

### 代码

```c
size_t my_strlen(const char* s) {
    size_t len = 0;
    // s[len] 不是 '\0' 就继续数
    while (s[len] != '\0') {
        len++;
    }
    return len;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个字节看一次。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 指针相减（库函数常见写法）

### 思路

不用下标，让指针 `p` 一路往后走到 `'\0'`，长度就是 `p - s`。每一轮少了一次"基地址 + 下标"的加法，在没有优化的编译器上会快一点，也是面试官最喜欢看到的写法。

### 代码

```c
size_t my_strlen(const char* s) {
    const char* p = s;      // p 从字符串开头出发
    while (*p) {            // *p 为 0（即 '\0'）时停止
        p++;
    }
    return (size_t)(p - s); // 走了多少步就是多少个字节
}
```

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**。

## 🔌 嵌入式实战

**1. 计算发送长度时别忘了 `'\0'` 要不要发：**

```c
const char* cmd = "AT+RST\r\n";
uart_send((const uint8_t*)cmd, strlen(cmd));   // 发 8 个字节，'\0' 不发
```

**2. 缓冲区要留 `'\0'` 的位置：**

```c
char name[5];
strcpy(name, "hello");   // ❌ "hello" 需要 6 个字节，越界写了 1 个字节
```

**3. 不可信的数据用 `strnlen`：** 串口收到的数据不一定有 `'\0'`，`strlen` 会一路读出缓冲区，读到哪里算哪里。安全的写法是限定最大长度：

```c
size_t safe_len(const char* s, size_t max) {
    size_t n = 0;
    while (n < max && s[n]) n++;   // 最多数 max 个
    return n;
}
```

> 💬 glibc 的 strlen 还会一次读 8 个字节，用位运算 `(x - 0x0101..01) & ~x & 0x8080..80` 判断 8 个字节里有没有 0，比逐字节快很多倍。感兴趣可以搜索 "haszero bit trick"。

## ⚠️ 第五步：小白常见错误

1. **把 `'\0'` 也算进去**：返回 `len + 1`，示例 1 输出 6。
2. **和 `'0'` 比较**：

   ```c
   while (*p != '0') p++;   // ❌ '0' 是 48，空串会一路越界读下去
   ```

3. **对指针用 `sizeof`**：`sizeof(s)` 是指针大小（4 或 8），不是字符串长度。
4. **返回 `p - s - 1`**：指针停在 `'\0'` 上时 `p - s` 已经正好是长度，不需要再减 1。
5. **字符串没有 `'\0'`**：比如用 `char a[3] = {'a','b','c'};` 调用 strlen，函数会一直读到内存里碰巧出现 0 为止——结果随机，还可能访问非法地址。
6. **在循环条件里反复调用 strlen**：`for (i = 0; i < strlen(s); i++)` 每次循环都从头数一遍，O(n) 变 O(n²)。先存到变量里。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 计数器 | O(n) | O(1) | ⭐ | 最直观 |
| 指针相减 | O(n) | O(1) | ⭐ | 面试推荐写法 |

> 🎯 **学习建议**：在纸上画出 `"hi"` 的 3 个字节，标出 `s` 和 `p` 的位置，体会"指针走到 `'\0'` 时，`p - s` 正好是长度"。
