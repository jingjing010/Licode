# RTC BCD 时间增加分钟：题解

## 📖 先读懂题目

hourBcd为合法24小时BCD，minuteBcd为合法分钟BCD，delta为0..10^6。增加分钟并按24小时回绕，返回[小时BCD,分钟BCD]。输入输出以十进制整数显示，例如0x23输入35。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `35 / 89 / 1` | `[0,0]` |
| 2 | `18 / 48 / 90` | `[20,0]` |

## 🧰 需要的 C 语言知识

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

先将BCD解为普通整数，用一天1440分钟取模处理跨日，再分别编码小时和分钟。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *addBcdMinutes(int hourBcd, int minuteBcd, int delta, int *returnSize) {
    int h = (hourBcd >> 4) * 10 + (hourBcd & 15), m = (minuteBcd >> 4) * 10 + (minuteBcd & 15);
    int total = (h * 60 + m + delta) % 1440;
    h = total / 60;
    m = total % 60;
    int *out = malloc(2 * sizeof(int));
    out[0] = (h / 10) * 16 + h % 10;
    out[1] = (m / 10) * 16 + m % 10;
    *returnSize = 2;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，输出空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
