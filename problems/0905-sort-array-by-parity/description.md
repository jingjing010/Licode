给你一个整数数组 `nums`，将 `nums` 中的的所有偶数元素移动到数组的前面，后跟所有奇数元素。

返回满足此条件的 **任一数组** 作为答案。

### 示例 1

```
输入：nums = [3,1,2,4]
输出：[2,4,3,1]
解释：[4,2,3,1]、[2,4,1,3] 和 [4,2,1,3] 也会被视作正确答案。
```

### 示例 2

```
输入：nums = [0]
输出：[0]
```

### 提示

- `1 <= nums.length <= 5000`
- `0 <= nums[i] <= 5000`

### 函数说明

```c
int* sortArrayByParity(int* nums, int numsSize, int* returnSize);
```

- `nums`：数组首地址，`numsSize`：数组长度
- 返回值：结果数组（可以在 `nums` 上原地修改后返回 `nums`，也可以用 `malloc` 申请新数组）
- `*returnSize`：必须设置为返回数组的长度（即 `numsSize`）

### 自定义输入格式

```
[3,1,2,4]
```

只有 1 行，是数组 `nums`。

**关于输出**：本题答案不唯一。判题程序会先检查你返回的数组是否合法（长度正确、是原数组的一个排列、所有偶数都在所有奇数前面）：

- 如果合法，统一输出一个**标准形式**：原数组中的偶数按原来的相对顺序排在前面，奇数按原来的相对顺序排在后面（例如 `[3,1,2,4]` 输出 `[2,4,3,1]`）。所以只要你的答案合法，输出就一定和标准答案相同。
- 如果不合法，原样输出你返回的数组，方便你调试。
