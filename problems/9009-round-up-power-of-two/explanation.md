# 9009. 向上取整到 2 的幂 —— 小白详细题解

> "把 x 向上取整到 2 的幂"有一个非常漂亮的位运算写法：**先减 1，再把最高位的 1 往右"抹"满，最后加 1**。Linux 内核的 `roundup_pow_of_two()`、很多 RTOS 的内存池都用了这个技巧。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 在 1、2、4、8、16、…… 这串数里，找**第一个不比 `x` 小**的。

| x | 答案 | 说明 |
|---|---|---|
| 1 | 1 | 1 本身就是 2⁰（示例 3） |
| 5 | 8 | 4 < 5 ≤ 8（示例 1） |
| 16 | 16 | 本身就是 2 的幂，不变（示例 2） |
| 100 | 128 | 64 < 100 ≤ 128 |

**几个需要注意的细节：**

1. 是"**大于等于**"，不是"大于"——`x = 16` 时答案是 16，不是 32。
2. 题目保证 `x <= 2³¹`，所以答案最大是 `2³¹ = 2147483648`，`uint32_t` 放得下。如果 `x > 2³¹`，答案会是 2³²，32 位已经装不下了。
3. 题目保证 `x >= 1`，不用考虑 0。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 左移一位 = 乘 2

`p <<= 1` 和 `p *= 2` 等价，`p` 从 1 开始不断左移，就会依次经过所有 2 的幂。

### 2. 观察：2 的幂减 1 是什么样子？

```
8   = 0000 1000      8 - 1   = 0000 0111
128 = 1000 0000      128 - 1 = 0111 1111
```

**2ᵏ − 1 是低 k 位全为 1 的数**。反过来，如果我们能把一个数变成"最高位的 1 以及它右边全是 1"的样子，再加 1，就得到了一个 2 的幂。

### 3. 右移 + 或：把最高位的 1 往右"抹"

```
v          = 0100 0000
v |= v >> 1  → 0110 0000    最高位的 1 复制了一份到右边 1 位，现在有 2 个 1
v |= v >> 2  → 0111 1000    2 个变 4 个
v |= v >> 4  → 0111 1111    4 个变 8 个
```

每一步，1 的"连续长度"翻一倍：1 → 2 → 4 → 8 → 16 → 32。所以 5 步（移 1、2、4、8、16）就能覆盖 32 位。

### 4. 为什么要先减 1？

如果 `x` 本身就是 2 的幂，比如 16 = `0001 0000`，直接抹完是 `0001 1111`，加 1 变成 32，错了。先减 1 得到 15 = `0000 1111`，抹完还是 15，加 1 正好是 16。

而如果 `x` 不是 2 的幂，减 1 不会改变它最高位的 1 的位置，不影响结果。

---

## 💡 第三步：思路一 —— 从 1 开始不断乘 2（最朴素）

### 思路

`p = 1`，只要 `p < x` 就让 `p` 翻倍。循环结束时 `p` 就是第一个 `>= x` 的 2 的幂。

### 手动模拟（示例 1：`x = 5`）

| p | p < 5 ? | 操作 |
|---|---|---|
| 1 | 是 | p = 2 |
| 2 | 是 | p = 4 |
| 4 | 是 | p = 8 |
| 8 | 否 | 返回 **8** |

### 代码

```c
uint32_t round_up_pow2(uint32_t x) {
    uint32_t p = 1;          // 最小的 2 的幂：2^0
    while (p < x) {          // 还不够大
        p <<= 1;             // 翻倍，变成下一个 2 的幂
    }
    return p;                // x <= 2^31 保证 p 不会溢出
}
```

### 复杂度分析

- **时间复杂度 O(log x)**，最多 31 次循环。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 减 1、抹位、加 1（无循环）

### 思路

1. `v = x - 1`：让本身是 2 的幂的 `x` 不被"多进一位"。
2. `v |= v >> 1; v |= v >> 2; v |= v >> 4; v |= v >> 8; v |= v >> 16;`：把 `v` 最高位的 1 右边全部填成 1。
3. `v + 1`：低位全 1 的数加 1，进位后变成 2 的幂。

### 手动模拟（`x = 100`，只看低 8 位）

| 步骤 | 二进制 | 十进制 |
|---|---|---|
| v = x − 1 | `0110 0011` | 99 |
| v \|= v >> 1 | `0111 0011` | 115 |
| v \|= v >> 2 | `0111 1111` | 127 |
| v \|= v >> 4、8、16 | `0111 1111` | 127（已经抹满，不再变化） |
| v + 1 | `1000 0000` | **128** |

### 代码

```c
uint32_t round_up_pow2(uint32_t x) {
    uint32_t v = x - 1u;   // 先减 1：让本身就是 2 的幂的 x 结果不变
    v |= v >> 1;           // 最高位的 1 往右复制，连续 1 的长度：1 -> 2
    v |= v >> 2;           // 2 -> 4
    v |= v >> 4;           // 4 -> 8
    v |= v >> 8;           // 8 -> 16
    v |= v >> 16;          // 16 -> 32，最高位以下全部是 1 了
    return v + 1u;         // 低位全 1 的数加 1 = 2 的幂
}
```

`x = 1` 时 `v = 0`，抹完还是 0，加 1 得 1 ✔。`x = 2³¹` 时 `v = 0x7FFFFFFF`，加 1 得 `0x80000000` ✔。

### 复杂度分析

- **时间复杂度 O(1)**：固定 5 次移位、5 次或、1 次减、1 次加。
- **空间复杂度 O(1)**。

## ⚠️ 第五步：小白常见错误

1. **忘了先减 1**：
   ```c
   uint32_t v = x;   // ❌ 少了 - 1
   v |= v >> 1; v |= v >> 2; v |= v >> 4; v |= v >> 8; v |= v >> 16;
   return v + 1;
   ```
   示例 2 会返回 32 而不是 16，示例 3 会返回 2 而不是 1。
2. **少抹了一步**：只写到 `v >> 8`，当 `x` 很大（比如 `2³⁰ + 1`）时最高位的 1 和低位之间还有空洞，结果错误。32 位必须 5 步，16 位 4 步，8 位 3 步。
3. **循环条件写成 `p <= x`**：`x` 本身是 2 的幂时会多翻倍一次，示例 2 输出 32。
4. **不考虑溢出**：如果输入可能超过 2³¹，思路一中 `p` 从 `2³¹` 左移后变成 0，`0 < x` 永远成立，**死循环**；思路二会返回 0。真实代码里要先检查范围。
5. **用浮点 `pow(2, ceil(log2(x)))`**：大数时有精度问题，而且单片机上浮点运算很慢。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 不断乘 2 | O(log x) | O(1) | ⭐ | 最容易写对 |
| 减 1、抹位、加 1 | O(1) | O(1) | ⭐⭐⭐ | 经典技巧，面试加分 |
| 前导零计数 `clz` | O(1) | O(1) | ⭐⭐ | 有硬件指令时最快 |

## 🔌 嵌入式实战

- **用 CLZ 指令**：Cortex-M3 以上有 `CLZ`（数前导零）指令，GCC 提供 `__builtin_clz(v)`。`x - 1` 的最高位 1 在第 `31 - clz` 位，答案就是 `1u << (32 - clz)`。注意 `__builtin_clz(0)` 是未定义的，`x = 1` 要单独处理：

```c
uint32_t round_up_pow2(uint32_t x) {
    if (x <= 1u) {
        return 1u;                                   // x - 1 = 0 时 __builtin_clz 无定义
    }
    return 1u << (32 - __builtin_clz(x - 1u));       // x - 1 的位数 = 32 - 前导零个数
}
```

- **内存池按大小分级**：很多 RTOS/分配器把请求的大小向上取整到 16、32、64、…… 字节的"桶"里，就是用本题的函数算出桶的大小。
- **向上取整到 2 的幂的倍数**（对齐）是另一个常用操作：`(x + align - 1) & ~(align - 1)`，比如把 13 字节对齐到 4 字节得到 16。

## 🔗 举一反三

- **9008. 判断 2 的幂**：本题的前置题。`round_up_pow2(x) == x` 也可以用来判断 2 的幂。
- **向下取整到 2 的幂**：找"不大于 x 的最大 2 的幂"，不减 1、直接对 `x` 抹位，最后返回 `v - (v >> 1)` 即可（想想为什么）。
- **9006. 统计置位个数**：抹位的思想（每步翻倍）和分组求和的思想（每步合并）很像。
