很多模块的配置都用**十六进制字符串**来传递二进制数据：例如通过串口 AT 指令下发 AES 密钥 `AT+KEY=00112233...`、LoRaWAN 的 AppKey、蓝牙 MAC 地址、或者从上位机"串口调试助手"粘贴过来的一段报文。MCU 收到的是文本，必须先把它还原成字节才能使用。

请实现函数 `hex_to_bytes`：把以 `'\0'` 结尾的字符串 `hex` 每 **2 个字符**转换成 **1 个字节**（前一个字符是高 4 位，后一个字符是低 4 位），依次写入 `out`，并返回写入的字节数。

- 字母大小写都要支持：`"ab"`、`"AB"`、`"aB"` 都表示 `0xAB`
- 如果字符串长度为**奇数**，或者含有 `0-9`、`a-f`、`A-F` 之外的字符，说明输入非法，**返回 `-1`**（此时 `out` 的内容不做要求）
- 空字符串是合法输入，返回 `0`

### 示例 1

```
输入：hex = "1234abCD"
输出：4
[18,52,171,205]
解释："12" -> 0x12 = 18，"34" -> 0x34 = 52，"ab" -> 0xAB = 171，"CD" -> 0xCD = 205。
```

### 示例 2

```
输入：hex = "00ff0A"
输出：3
[0,255,10]
```

### 示例 3

```
输入：hex = "12G4"
输出：-1
解释：'G' 不是十六进制字符。
```

### 提示

- `0 <= strlen(hex) <= 2000`
- `hex` 只包含可打印 ASCII 字符（不含双引号和反斜杠）
- `out` 已由调用者分配，至少有 `strlen(hex) / 2` 个字节的空间
- 不要使用 `sscanf`、`strtol` 等库函数

### 函数说明

```c
int hex_to_bytes(const char* hex, uint8_t* out);
```

- `hex`：输入的十六进制字符串
- `out`：输出缓冲区
- 返回值：成功时为写入的字节数；输入非法时为 `-1`

### 自定义输入格式

```
"1234abCD"
```

只有 1 行：带双引号的字符串 `hex`。输出第 1 行为返回值；如果返回值不是 `-1`，第 2 行输出 `out` 的前 `返回值` 个字节。
