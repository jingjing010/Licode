# Hamming(7,4) 编码

data为0到15。码字位置从1起、位置1对应最低位；数据从低到高放在3/5/6/7位置，1/2/4为偶校验位。返回0到127的码字。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int hamming74Encode(int data);
```

## 示例 1

输入：
```text
0
```
输出：
```text
0
```

## 示例 2

输入：
```text
10
```
输出：
```text
82
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
