在单片机里求两个数的平均值非常常见：对两次 ADC 采样做平滑滤波、取两次定时器捕获值的中点、二分查找时计算中间位置……最直接的写法 `(a + b) / 2` 有一个隐患：**`a + b` 可能超出 32 位能表示的范围**，发生回绕后结果完全错误。例如两个接近 `0xFFFFFFFF` 的数相加，和会"绕回"一个很小的数，平均值也就变得很小。

给定两个 32 位无符号整数 `a` 和 `b`，请返回它们的平均值 **向下取整** 的结果，即 `⌊(a + b) / 2⌋`（按数学意义计算，不发生溢出）。

### 示例 1

```
输入：a = 4, b = 6
输出：5
```

### 示例 2

```
输入：a = 4294967295, b = 4294967293
输出：4294967294
解释：a + b = 8589934588 超出了 uint32_t 的范围，但数学上的平均值 4294967294 = 0xFFFFFFFE 可以用 uint32_t 表示。
```

### 示例 3

```
输入：a = 3, b = 4
输出：3
解释：(3 + 4) / 2 = 3.5，向下取整为 3。
```

### 提示

- `0 <= a, b <= 2^32 - 1`

### 函数说明

```c
uint32_t average_u32(uint32_t a, uint32_t b);
```

- `a`、`b`：两个 32 位无符号整数
- 返回值：`⌊(a + b) / 2⌋`

### 自定义输入格式

```
4
6
```

第 1 行是 `a`，第 2 行是 `b`，均为十进制整数。输出为平均值（十进制）。
