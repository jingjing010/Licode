# 统计位数为偶数的数字

给定正整数数组，统计十进制位数为偶数的元素数量。1 ≤ n ≤ 500，1 ≤ 元素 ≤ 10^5。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int findNumbers(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[12,345,2,6,7896]
```
输出：
```text
2
```

## 示例 2

输入：
```text
[555,901,482,1771]
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
