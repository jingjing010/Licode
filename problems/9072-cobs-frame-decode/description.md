# COBS 数据区解码

输入保证为9071定义的合法COBS编码，不包含帧分隔符。解码并返回原始字节数组；编码长度1到1030。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* cobsDecode(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[10,49,50,51,52,53,54,55,56,57]
```
输出：
```text
[49,50,51,52,53,54,55,56,57]
```

## 示例 2

输入：
```text
[1]
```
输出：
```text
[]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
