# 快乐数：题解

## 📖 先读懂题目

给定正整数 n，重复替换为各十进制位平方和；最终变为1则返回 true。n ≤ 2^31−1。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `19` | `true` |
| 2 | `2` | `false` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

下一项只由当前项决定。快慢指针相遇后，检查环是否是固定点1。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
static int digitSquare(int x) {
    int sum = 0;
    while (x) {
        int d = x % 10;
        sum += d * d;
        x /= 10;
    }
    return sum;
}
bool isHappy(int n) {
    int slow = n, fast = n;
    /* 快慢指针检测平方和序列是否进入非1环。 */
    do {
        slow = digitSquare(slow);
        fast = digitSquare(digitSquare(fast));
    } while (slow != fast);
    return slow == 1;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(log n)，额外空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
