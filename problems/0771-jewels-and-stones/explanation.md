# 宝石与石头：题解

## 📖 先读懂题目

jewels是互不相同的英文字母，stones是持有石头的类型序列。统计宝石数量，大小写敏感。两个字符串长度1到50。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"aA" / "aAAbbbb"` | `3` |
| 2 | `"z" / "ZZ"` | `0` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

建立宝石字符集合，扫描石头字符串判断每颗是否在集合内。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int numJewelsInStones(char *jewels, char *stones) {
    bool isJewel[256] = {false};
    for (int i = 0; jewels[i]; ++i)
        isJewel[(unsigned char)jewels[i]] = true;
    int answer = 0;
    for (int i = 0; stones[i]; ++i)
        answer += isJewel[(unsigned char)stones[i]];
    return answer;
}
```

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
