# 字符串相加：题解

## 📖 先读懂题目

从最低位开始，把两个当前数字和进位相加。新的一位为sum%10，新进位为sum/10，最后反转倒序累积的答案。不能把长字符串整体转成整数。

### 示例1

输入：
```text
"11"
"123"
```
输出：
```text
"134"
```

### 示例2

输入：
```text
"456"
"77"
```
输出：
```text
"533"
```

### 示例3

输入：
```text
"0"
"0"
```
输出：
```text
"0"
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 数字最长 10^4 位，不能转成整数。回忆小学竖式加法：个位对齐，从右往左一位一位加。
2. 用 i、j 分别从两个字符串的末尾往前走，carry 记录进位：本位 = (x + y + carry) % 10，新进位 = (x + y + carry) / 10。某个字符串走完了，它的位就当作 0。
3. 循环条件写成 while (i >= 0 || j >= 0 || carry)，最后的进位也不会漏。结果最长 max(len1, len2) + 1 位，倒着写再反转，或者从结果末尾往前填。

## 可直接提交的 C 代码

```c
char* addStrings(char* num1, char* num2) {
    int i = strlen(num1) - 1, j = strlen(num2) - 1;
    int cap = (i > j ? i : j) + 2;
    char* res = (char*)malloc(cap + 1);
    int k = cap;
    res[k] = '\0';
    int carry = 0;
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += num1[i--] - '0';
        if (j >= 0) sum += num2[j--] - '0';
        res[--k] = (char)('0' + sum % 10);
        carry = sum / 10;
    }
    if (k > 0) memmove(res, res + k, cap - k + 1);
    return res;
}
```

## 📊 复杂度

时间 O(n+m)，输出空间 O(max(n,m))。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。
