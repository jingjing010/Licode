# 1143. 最长公共子序列 —— 小白详细题解

> 这是"二维动态规划"的入门经典（简称 LCS）。学会它，编辑距离、最长回文子序列等一大批字符串 DP 题都是同一个套路。

---

## 📖 第一步：先读懂题目

先分清两个概念：

| 概念 | 要求 | `"abcde"` 的例子 |
|---|---|---|
| 子串 | 必须**连续** | `"bcd"` ✅，`"ace"` ❌ |
| 子序列 | 可以跳着选，但**顺序不能变** | `"ace"` ✅，`"aec"` ❌ |

用大白话说，这道题就是：

> 从 `text1` 里删掉一些字符，从 `text2` 里也删掉一些字符，让剩下的两个字符串**一模一样**。剩下的最长能有多长？

拿示例 1 `text1 = "abcde"`、`text2 = "ace"` 来说：

| text1 | **a** | b | **c** | d | **e** |
|---|---|---|---|---|---|
| text2 | **a** | | **c** | | **e** |

两边都能挑出 `"ace"`，长度 3。

**几个需要注意的细节：**

1. 返回的是**长度**，不需要返回子序列本身。
2. 没有公共字符时答案是 0（示例 3）。
3. 两个字符串长度可以不同，最长 1000。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 字符串长度

```c
int m = (int)strlen(text1);   // 需要 <string.h>，返回 '\0' 之前的字符个数
```

### 2. 二维数组放哪里？

`dp` 表最大是 1001 × 1001 个 `int`，约 4MB。如果写成函数里的局部数组 `int dp[1001][1001];`，会放在**栈**上，Windows 默认栈只有 1MB 左右，直接**栈溢出崩溃**。

两种安全写法：

```c
static int dp[1001][1001];   // 写法一：static，放在静态区，不占栈
```

```c
// 写法二：malloc 一块连续内存，自己算下标
int* dp = (int*)calloc((m + 1) * (n + 1), sizeof(int));   // calloc 会自动清零
// 第 i 行第 j 列：dp[i * (n + 1) + j]
```

> ⚠️ 用 `static` 时要注意：同一个程序里函数被多次调用，上次的数据还在。本题我们会把用到的第 0 行、第 0 列重新赋值为 0，其余格子都会被覆盖，所以没问题。

---

## 💡 第三步：思路一 —— 二维动态规划

### 思路

设 `dp[i][j]` = `text1` 的**前 i 个字符**和 `text2` 的**前 j 个字符**的最长公共子序列长度。

看两个前缀的**最后一个字符** `text1[i-1]` 和 `text2[j-1]`：

1. **相等**：这个字符可以作为公共子序列的最后一个字符，`dp[i][j] = dp[i-1][j-1] + 1`。
2. **不相等**：至少有一个用不上。要么扔掉 `text1` 的最后一个（`dp[i-1][j]`），要么扔掉 `text2` 的最后一个（`dp[i][j-1]`），取较大者。

边界：任何字符串和空串的 LCS 都是 0，所以第 0 行、第 0 列全是 0。这就是为什么 dp 表要**多开一行一列**。

### 手动模拟（示例 1：`text1 = "abcde"`，`text2 = "ace"`）

| | "" | a | c | e |
|---|---|---|---|---|
| **""** | 0 | 0 | 0 | 0 |
| **a** | 0 | **1** ↖ | 1 | 1 |
| **b** | 0 | 1 | 1 | 1 |
| **c** | 0 | 1 | **2** ↖ | 2 |
| **d** | 0 | 1 | 2 | 2 |
| **e** | 0 | 1 | 2 | **3** ↖ |

带 ↖ 的格子是"两个字符相等，从左上角 +1"；其余格子取"上方"和"左方"的较大值。答案是右下角的 3。

### 代码

```c
int longestCommonSubsequence(char* text1, char* text2) {
    int m = (int)strlen(text1);
    int n = (int)strlen(text2);
    // 多开一行一列：dp[0][*] 和 dp[*][0] 表示和空串比较，都是 0
    static int dp[1001][1001];

    for (int i = 0; i <= m; i++) dp[i][0] = 0;
    for (int j = 0; j <= n; j++) dp[0][j] = 0;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            // dp 的下标 i 对应字符串下标 i-1（因为多开了一行）
            if (text1[i - 1] == text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;          // 最后一个字符相同，一起选上
            } else if (dp[i - 1][j] > dp[i][j - 1]) {
                dp[i][j] = dp[i - 1][j];                  // 扔掉 text1 的最后一个
            } else {
                dp[i][j] = dp[i][j - 1];                  // 扔掉 text2 的最后一个
            }
        }
    }
    return dp[m][n];
}
```

### 复杂度分析

- **时间复杂度 O(m × n)**：填满整张表，最多 10⁶ 个格子。
- **空间复杂度 O(m × n)**。

## 🚀 第四步：思路二 —— 滚动数组（空间优化）

### 思路

观察转移方程，算第 `i` 行时只用到了**第 `i-1` 行**和**第 `i` 行左边**的值。所以只需要一个一维数组 `dp[j]`，一行一行地原地覆盖：

| 需要的值 | 在一维数组里是 |
|---|---|
| 上方 `dp[i-1][j]` | 还没被覆盖的 `dp[j]` |
| 左方 `dp[i][j-1]` | 刚刚算好的 `dp[j-1]` |
| 左上 `dp[i-1][j-1]` | ⚠️ 已经被覆盖了！要提前用变量 `leftUp` 存起来 |

### 手动模拟（第 3 行，即 text1 的 `c`；上一行是 `[0,1,1,1]`）

| j | text2[j-1] | 覆盖前 dp[j]（上方） | leftUp（左上） | 新 dp[j] |
|---|---|---|---|---|
| 1 | a | 1 | 0 | max(1, dp[0]=0) = 1 |
| 2 | c | 1 | 1 | 相等 → 1 + 1 = **2** |
| 3 | e | 1 | 1 | max(1, dp[2]=2) = 2 |

得到 `[0,1,2,2]`，和二维表的第 3 行一致。

### 代码

```c
int longestCommonSubsequence(char* text1, char* text2) {
    int m = (int)strlen(text1);
    int n = (int)strlen(text2);
    // 只保留一行：dp[j] 表示"当前行"第 j 列；calloc 会把它们全部初始化为 0
    int* dp = (int*)calloc(n + 1, sizeof(int));

    for (int i = 1; i <= m; i++) {
        int leftUp = 0;                  // 左上角 dp[i-1][j-1]，每行开始时是 dp[i-1][0] = 0
        for (int j = 1; j <= n; j++) {
            int up = dp[j];              // 覆盖前先保存：它是上方 dp[i-1][j]，也是下一格的左上
            if (text1[i - 1] == text2[j - 1]) {
                dp[j] = leftUp + 1;
            } else if (dp[j - 1] > dp[j]) {
                dp[j] = dp[j - 1];       // 左方更大
            }                            // 否则保持上方的值不变
            leftUp = up;                 // 往右移一格，旧的上方就成了新的左上
        }
    }

    int ans = dp[n];
    free(dp);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(m × n)**。
- **空间复杂度 O(n)**：只有一行。

---

## ⚠️ 第五步：小白常见错误

1. **局部二维数组 `int dp[1001][1001];`** → 约 4MB 放在栈上，运行直接崩溃（Runtime Error）。改成 `static` 或 `malloc`。
2. **下标对不齐** → `dp[i][j]` 对应的字符是 `text1[i-1]` 和 `text2[j-1]`，写成 `text1[i]` 会漏掉第一个字符，还会读到 `'\0'`。
3. **相等时写成 `dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + 1`** → 同一个字符可能被重复使用，例如 `"a"` 和 `"aa"` 会算出 2（正确是 1）。
4. **滚动数组忘记保存左上角** → 直接用 `dp[j-1]` 当左上角，但它已经是本行的新值了，结果偏大。
5. **把子序列当子串做** → 子串版本（最长公共子串）不相等时要清零，而不是取 max，两者的转移方程不同。
6. **用 `static` 数组但忘了初始化第 0 行、第 0 列** → 如果程序多次调用函数，上一次留下的数据会污染结果。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 二维 DP | O(mn) | O(mn) | ⭐⭐ | 先画表理解转移 |
| 滚动数组 | O(mn) | O(n) | ⭐⭐⭐ | 理解后再优化空间 |

> 💬 暴力枚举 `text1` 的所有子序列有 2^m 种，m = 1000 时根本跑不完，所以本题必须用 DP。
