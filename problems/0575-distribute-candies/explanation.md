# 分糖果：题解

## 📖 先读懂题目

偶数个糖果，每个数表示糖果种类，只能吃一半，返回最多吃到的种类数。2 ≤ n ≤ 10^4。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[1,1,2,2,3,3]` | `3` |
| 2 | `[1,1,2,3]` | `2` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

最多只能吃n/2颗，也不可能超过现有种类总数，取二者最小值。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
static int cmp(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);
}
int distributeCandies(int *candyType, int candyTypeSize) {
    qsort(candyType, candyTypeSize, sizeof(int), cmp);
    int kinds = 0;
    for (int i = 0; i < candyTypeSize; ++i)
        if (i == 0 || candyType[i] != candyType[i - 1])
            ++kinds;
    return kinds < candyTypeSize / 2 ? kinds : candyTypeSize / 2;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n log n)，排序栈空间 O(log n) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
