# 灯泡开关：题解

## 📖 先读懂题目

n 盏灯初始关闭，第i轮翻转所有编号为i的倍数的灯。进行n轮后，返回亮灯数。0 ≤ n ≤ 10^9。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `3` | `1` |
| 2 | `0` | `0` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

第i盏灯被其每个约数对应的轮次翻转。约数成对出现，唯独平方数的平方根不成对。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int bulbSwitch(int n) {
    /* 只有完全平方数有奇数个约数。 */
    int lo = 0, hi = 46340;
    while (lo < hi) {
        int m = lo + (hi - lo + 1) / 2;
        if ((long long)m * m <= n)
            lo = m;
        else
            hi = m - 1;
    }
    return lo;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(log n)，额外空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。

## 🔗 举一反三
