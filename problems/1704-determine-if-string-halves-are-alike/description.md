# 判断字符串的两半是否相似

给定偶数长度的英文字母字符串，判断前后两半的元音个数是否相同。元音不区分大小写。长度2到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool halvesAreAlike(char* s);
```

## 示例 1

输入：
```text
"book"
```
输出：
```text
true
```

## 示例 2

输入：
```text
"textbook"
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
