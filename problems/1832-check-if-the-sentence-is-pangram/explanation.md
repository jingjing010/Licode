# 判断句子是否为全字母句：题解

## 📖 先读懂题目

输入仅含小写英文字母的句子，判断是否每个英文字母至少出现一次。长度1到1000。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"thequickbrownfoxjumpsoverthelazydog"` | `true` |
| 2 | `"leetcode"` | `false` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

`uint32_t`运算按2^32取模。先转换为无符号类型再移位，避免负数左移；移位数必须小于类型位宽。超过INT_MAX的结果仍要按无符号值理解。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

26个字母映射到26个位，全部置1时说明所有字母均已出现。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
bool checkIfPangram(char *sentence) {
    uint32_t mask = 0;
    for (int i = 0; sentence[i]; ++i)
        mask |= 1u << (sentence[i] - 'a');
    return mask == ((1u << 26) - 1);
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 用有符号int承接无符号32位位模式，导致最高位被当成符号。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
