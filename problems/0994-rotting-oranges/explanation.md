# 994. 腐烂的橘子 —— 小白详细题解

> 这道题是「多源 BFS」的经典入门题：好几个起点**同时**向外扩散，扩散了几层就是几分钟。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一个箱子里放着橘子：`0` 是空位，`1` 是好橘子，`2` 是烂橘子。每过 1 分钟，烂橘子会把它**上下左右**的好橘子传染成烂的。问：最少几分钟后所有橘子都烂了？如果有好橘子永远烂不了，返回 `-1`。

拿示例 1 `[[2,1,1],[1,1,0],[0,1,1]]` 来说，每分钟的变化如下（加粗是这一分钟新烂的）：

| 时间 | 第 0 行 | 第 1 行 | 第 2 行 |
|---|---|---|---|
| 第 0 分钟 | 2 1 1 | 1 1 0 | 0 1 1 |
| 第 1 分钟 | 2 **2** 1 | **2** 1 0 | 0 1 1 |
| 第 2 分钟 | 2 2 **2** | 2 **2** 0 | 0 1 1 |
| 第 3 分钟 | 2 2 2 | 2 2 0 | 0 **2** 1 |
| 第 4 分钟 | 2 2 2 | 2 2 0 | 0 2 **2** |

第 4 分钟后没有好橘子了，答案是 `4`。

**几个需要注意的细节：**

1. 一开始就没有好橘子（比如示例 3），答案是 `0`，哪怕一个烂橘子也没有。
2. 有好橘子但一个烂橘子都没有，答案是 `-1`。
3. **同一分钟里新烂掉的橘子，要到下一分钟才开始传染。** 如果边扫描边传染，就会一分钟传好几格，答案偏小。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `int** grid` 二维数组

`grid[i][j]` 就是第 `i` 行第 `j` 列。行数是 `gridSize`，列数是 `gridColSize[0]`。

### 2. 用数组模拟队列

C 语言没有现成的队列，用一个数组加两个下标就能模拟：

| 变量 | 含义 |
|---|---|
| `q[]` | 存放排队的元素 |
| `head` | 队头：下一个要出队的位置 |
| `tail` | 队尾：下一个要放入的位置 |

入队 `q[tail++] = x;`，出队 `x = q[head++];`，队列为空就是 `head == tail`。本题最多 100 个格子，每个格子最多入队一次，`int q[100]` 就够了。

### 3. 把二维坐标压成一个整数

`(r, c)` → `r * n + c`；还原时 `r = x / n`，`c = x % n`。这样队列里只存一个 `int`。

## 💡 第三步：思路一 —— 一分钟一分钟地模拟

### 思路

1. 每一轮（一分钟）先**记下**所有「挨着烂橘子的好橘子」，扫描完再把它们统一变烂（避免同一分钟连续传染）。
2. 如果这一轮一个都没变烂：
   - 还有好橘子 → 永远烂不完，返回 `-1`；
   - 没有好橘子 → 返回已经过去的分钟数。

为了「先记下，再统一变烂」，我们用一个小技巧：本轮要变烂的好橘子先标成 `3`，扫描完再把所有 `3` 改成 `2`。

### 代码

```c
int orangesRotting(int** grid, int gridSize, int* gridColSize) {
    int m = gridSize, n = gridColSize[0];
    int minutes = 0;

    while (1) {
        int fresh = 0;       // 本轮开始时还有几个好橘子
        int changed = 0;     // 本轮有几个橘子变烂
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] != 1) continue;
                fresh++;
                // 看看上下左右有没有「本轮开始前就烂了」的橘子（值为 2）
                if ((i > 0 && grid[i - 1][j] == 2) || (i < m - 1 && grid[i + 1][j] == 2) ||
                    (j > 0 && grid[i][j - 1] == 2) || (j < n - 1 && grid[i][j + 1] == 2)) {
                    grid[i][j] = 3;      // 先标记成 3：本轮要烂，但这一轮还不能传染别人
                    changed++;
                }
            }
        }
        if (fresh == 0) return minutes;  // 已经没有好橘子了
        if (changed == 0) return -1;     // 有好橘子，但再也烂不了

        // 统一把 3 变成 2
        for (int i = 0; i < m; i++)
            for (int j = 0; j < n; j++)
                if (grid[i][j] == 3) grid[i][j] = 2;
        minutes++;
    }
}
```

### 复杂度分析

- **时间复杂度 O((m·n)²)**：每分钟扫描整张网格，最多要 m·n 分钟。本题 m、n ≤ 10，完全够用。
- **空间复杂度 O(1)**：直接在原网格上标记。

## 🚀 第四步：思路二 —— 多源 BFS

### 思路

思路一每分钟都要把整张图扫一遍，其实只有「刚烂掉的橘子」周围才会有变化。

1. 先把**所有**初始烂橘子放进队列，同时数一数好橘子 `fresh`。
2. 按「层」处理队列：当前队列里的全部橘子是同一分钟烂的，把它们的好邻居变烂并入队，这就是下一分钟烂的。
3. 每处理完一层，分钟数 `+1`；好橘子数降到 0 就停止。
4. 最后 `fresh > 0` 说明有橘子永远烂不了，返回 `-1`。

> ❓ **怎么知道「一层」到哪里结束？** 开始处理这一层前，记下当时的 `tail`（`levelEnd`）。`head` 走到 `levelEnd` 就说明这一层处理完了，之后入队的都属于下一层。

### 手动模拟（示例 1）

| 分钟 | 这一层出队的橘子 | 新烂（入队）的橘子 | 剩余好橘子 |
|---|---|---|---|
| 开始 | — | (0,0) | 6 |
| 1 | (0,0) | (1,0)、(0,1) | 4 |
| 2 | (1,0)、(0,1) | (1,1)、(0,2) | 2 |
| 3 | (1,1)、(0,2) | (2,1) | 1 |
| 4 | (2,1) | (2,2) | 0 |

### 代码

```c
int orangesRotting(int** grid, int gridSize, int* gridColSize) {
    int m = gridSize, n = gridColSize[0];
    int q[100];                    // 最多 10*10 个格子，每个最多入队一次
    int head = 0, tail = 0;
    int fresh = 0;

    // 1. 所有初始烂橘子入队，同时统计好橘子
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 2) q[tail++] = i * n + j;
            else if (grid[i][j] == 1) fresh++;
        }
    }

    int dr[4] = {1, -1, 0, 0};
    int dc[4] = {0, 0, 1, -1};
    int minutes = 0;

    // 2. 一层一层地扩散；没有好橘子了就不用再等
    while (head < tail && fresh > 0) {
        int levelEnd = tail;                 // 这一层到 levelEnd 为止
        while (head < levelEnd) {
            int cur = q[head++];
            int r = cur / n, c = cur % n;
            for (int d = 0; d < 4; d++) {
                int nr = r + dr[d], nc = c + dc[d];
                if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == 1) {
                    grid[nr][nc] = 2;        // 入队时就标记成烂的，防止重复入队
                    fresh--;
                    q[tail++] = nr * n + nc;
                }
            }
        }
        minutes++;                           // 处理完一层 = 过去 1 分钟
    }

    // 3. 还有好橘子就说明永远烂不完
    return fresh == 0 ? minutes : -1;
}
```

### 复杂度分析

- **时间复杂度 O(m·n)**：每个格子最多入队、出队一次。
- **空间复杂度 O(m·n)**：队列。

---

## ⚠️ 第五步：小白常见错误

1. **边扫描边传染**：思路一里直接把好橘子改成 `2`，同一轮里它会马上传染下一个格子，示例 1 会得到比 4 小的答案。
2. **while 条件没写 `fresh > 0`**：最后一层烂橘子出队时虽然没有传染任何人，`minutes` 还是会 `+1`，答案多 1。
3. **忘了处理「一开始就没有好橘子」**：例如 `[[0,2]]` 应返回 0，不是 -1。
4. **没有烂橘子但有好橘子**：例如 `[[1]]`，队列一开始就是空的，必须返回 -1；用最后的 `fresh == 0 ? minutes : -1` 就能正确处理。
5. **出队时才标记**：同一个好橘子会被多个烂邻居重复入队，`q[100]` 可能越界。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐分钟模拟 | O((m·n)²) | O(1) | ⭐⭐ | 最直观，先写对它 |
| 多源 BFS | O(m·n) | O(m·n) | ⭐⭐⭐ | 标准答案，一定要掌握 |

> 🎯 **学习建议**：BFS「按层处理」的写法（记下 `levelEnd`）非常常用，二叉树的层序遍历也是同一个套路。
