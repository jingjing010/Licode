给你一个字符串 `s`，找到 `s` 中最长的 **回文** 子串。

> **回文**：一个字符串正着读和反着读都一样，例如 `"aba"`、`"abba"`。
> **子串**：字符串中**连续**的一段字符。

### 示例 1

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

### 示例 2

```
输入：s = "cbbd"
输出："bb"
```

### 提示

- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

### 函数说明

```c
char* longestPalindrome(char* s);
```

- `s`：以 `'\0'` 结尾的字符串
- 返回值：一个**新的**、以 `'\0'` 结尾的字符串（用 `malloc` 申请，记得给 `'\0'` 留一个位置），内容是 `s` 的一个最长回文子串

### 自定义输入格式

```
"babad"
```

只有 1 行：带双引号的字符串 `s`。

（最长回文子串可能不止一个，返回任意一个即可。判题时会检查你返回的字符串：是 `s` 的子串、是回文、长度等于最长回文子串的长度。
三项都满足时，统一输出 `s` 中**最靠左**的那个最长回文子串（例如示例 1 无论你返回 `"bab"` 还是 `"aba"`，都会输出 `"bab"`）；否则原样输出你返回的字符串。）
