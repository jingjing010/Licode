# 279. 完全平方数 —— 小白详细题解

> 这道题是"完全背包"类动态规划的入门题：用若干个"物品"（平方数）凑出一个总数，问最少用几个。最后我们还会看到一个漂亮的数学解法。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 用 1、4、9、16、25……这些平方数（**可以重复用**）加起来凑出 `n`，问最少要几个数。

| n | 一种最优凑法 | 个数 |
|---|---|---|
| 12 | 4 + 4 + 4 | **3** |
| 13 | 4 + 9 | **2** |
| 7 | 4 + 1 + 1 + 1 | 4 |
| 16 | 16 | 1 |

**几个需要注意的细节：**

1. 1 也是平方数，所以**任何 n 都一定能凑出来**（大不了全用 1）。
2. **贪心不对**：每次拿能拿的最大平方数，12 会拿 9 + 1 + 1 + 1 = 4 个，但最优是 4 + 4 + 4 = 3 个。
3. 只需要返回**个数**，不需要具体方案。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 循环条件 `j * j <= i`

枚举所有不超过 `i` 的平方数，最自然的写法是：

```c
for (int j = 1; j * j <= i; j++) {
    int square = j * j;   // 1, 4, 9, 16, ...
}
```

这样避免了调用 `sqrt`，也就不用担心浮点数误差。

### 2. 用 `malloc` 开 dp 数组并设初值

```c
int* dp = (int*)malloc(sizeof(int) * (n + 1));   // 下标 0 ~ n
for (int i = 0; i <= n; i++) dp[i] = i;          // 最坏全用 1：i 个
```

### 3. `sqrt` 与整数

`<math.h>` 里的 `sqrt` 返回 `double`。判断一个数是不是平方数时，转成 `int` 后最好再用整数乘法确认一下：`r * r == x`，防止浮点误差导致 `sqrt(25)` 变成 `4.9999999`。

---

## 💡 第三步：思路一 —— 动态规划（完全背包）

### 思路

定义 `dp[i]` = **凑出 i 最少需要几个平方数**。

凑出 `i` 的方案里，总有"最后一个"平方数，假设是 `j*j`。那么剩下的 `i - j*j` 也要用最少的个数凑出来，也就是 `dp[i - j*j]`。枚举所有可能的 `j`，取最小：

**`dp[i] = min(dp[i - j*j]) + 1`，其中 `1 <= j*j <= i`**

边界 `dp[0] = 0`（凑出 0 不需要任何数）。

### 手动模拟（n = 12）

| i | 可选的最后一个平方数 j*j | 候选 dp[i - j*j] + 1 | dp[i] |
|---|---|---|---|
| 0 | — | — | 0 |
| 1 | 1 | dp[0]+1 = 1 | 1 |
| 2 | 1 | dp[1]+1 = 2 | 2 |
| 3 | 1 | dp[2]+1 = 3 | 3 |
| 4 | 1, 4 | dp[3]+1 = 4，dp[0]+1 = 1 | 1 |
| 5 | 1, 4 | dp[4]+1 = 2，dp[1]+1 = 2 | 2 |
| 8 | 1, 4 | dp[7]+1 = 5，dp[4]+1 = 2 | 2 |
| 9 | 1, 4, 9 | dp[8]+1 = 3，dp[5]+1 = 3，dp[0]+1 = 1 | 1 |
| 12 | 1, 4, 9 | dp[11]+1 = 4，dp[8]+1 = **3**，dp[3]+1 = 4 | **3** |

（省略了 6、7、10、11 这几行：dp[6]=3，dp[7]=4，dp[10]=2，dp[11]=3。）

### 代码

```c
int numSquares(int n) {
    // dp[i]：凑出 i 最少需要几个完全平方数
    int* dp = (int*)malloc(sizeof(int) * (n + 1));
    dp[0] = 0;

    for (int i = 1; i <= n; i++) {
        dp[i] = i;                               // 最坏情况：全用 1，需要 i 个
        for (int j = 1; j * j <= i; j++) {       // 枚举最后一个平方数 j*j
            if (dp[i - j * j] + 1 < dp[i]) {
                dp[i] = dp[i - j * j] + 1;
            }
        }
    }

    int ans = dp[n];
    free(dp);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n√n)**：外层 n 次，内层最多 √n 次。n = 10⁴ 时约 10⁶ 次，很快。
- **空间复杂度 O(n)**。

## 🚀 第四步：思路二 —— 数学（四平方和定理）

### 思路

数学家早就研究过这个问题，有两个定理可以直接用：

1. **拉格朗日四平方和定理**：每个正整数都能写成**至多 4 个**平方数之和。所以答案只可能是 1、2、3、4。
2. **勒让德三平方和定理**：一个数**必须用 4 个**平方数，当且仅当它能写成 `4^a × (8b + 7)` 的形式。

于是可以按顺序判断：

| 判断 | 答案 |
|---|---|
| n 本身是平方数 | 1 |
| 把 n 里的因子 4 全部除掉后，余数满足 `% 8 == 7` | 4 |
| 存在 `i*i`，使 `n - i*i` 也是平方数 | 2 |
| 都不是 | 3 |

### 手动模拟

| n | 是平方数？ | 除尽 4 后 % 8 | 能拆成两个平方数？ | 答案 |
|---|---|---|---|---|
| 12 | 否 | 12 → 3，3 % 8 = 3 | 12-1=11 ❌，12-4=8 ❌，12-9=3 ❌ | **3** |
| 13 | 否 | 13 % 8 = 5 | 13-4=9 ✅ | **2** |
| 28 | 否 | 28 → 7，7 % 8 = **7** | （不用判断了） | **4** |

### 代码

```c
// 判断 x 是不是完全平方数
static bool isSquare(int x) {
    int r = (int)sqrt((double)x);
    // 修正浮点误差：保证 r 是满足 r*r <= x 的最大整数
    while (r * r > x) r--;
    while ((r + 1) * (r + 1) <= x) r++;
    return r * r == x;
}

int numSquares(int n) {
    // 情况 1：本身就是平方数
    if (isSquare(n)) return 1;

    // 情况 4：形如 4^a * (8b + 7)
    int m = n;
    while (m % 4 == 0) m /= 4;       // 除掉所有因子 4
    if (m % 8 == 7) return 4;

    // 情况 2：能拆成两个平方数之和
    for (int i = 1; i * i < n; i++) {
        if (isSquare(n - i * i)) return 2;
    }

    // 剩下的都是 3
    return 3;
}
```

### 复杂度分析

- **时间复杂度 O(√n)**：只有"判断能否拆成两个平方数"需要一个循环。
- **空间复杂度 O(1)**。

> 💬 面试时通常期望你写出 DP 解法；数学解法可以作为加分项提一下。

---

## ⚠️ 第五步：小白常见错误

1. **贪心：每次取最大的平方数** → 12 得到 9+1+1+1 = 4 个，正确答案是 3。
2. **dp 初值设成 0** → 取 min 时永远是 0，答案全错。要设成 `i`（全用 1）或一个足够大的数。
3. **内层循环写成 `j * j < i`** → 漏掉了 `i` 本身就是平方数的情况，`dp[4]` 会算成 2。
4. **直接用 `sqrt(x) == (int)sqrt(x)` 判断平方数** → 浮点误差在大数时可能出错，最后要用整数 `r * r == x` 确认。
5. **dp 数组只开 `n` 个** → 访问 `dp[n]` 越界，要开 `n + 1` 个。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 动态规划（完全背包） | O(n√n) | O(n) | ⭐⭐ | 必须掌握，套路通用 |
| BFS（按"用了几个数"分层） | O(n√n) | O(n) | ⭐⭐⭐ | 了解 |
| 四平方和定理 | O(√n) | O(1) | ⭐⭐ | 知道就能写，加分项 |
