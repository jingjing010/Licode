很多单片机的 ADC 支持 **扫描模式**：一个 32 位的通道选择寄存器中，第 `i` 位为 `1` 表示要采集第 `i` 号通道。启动一次扫描后，ADC 会依次转换所有被选中的通道，并通过 DMA 把结果搬运到内存。为了配置 DMA 的传输次数、分配缓冲区大小，驱动程序必须先知道 **一共选中了多少个通道**。

给定通道选择寄存器的值 `x`，请返回 `x` 的二进制表示中 **`1` 的个数**（也叫"汉明重量"、popcount）。

### 示例 1

```
输入：x = 11
输出：3
解释：11 = 0b1011，选中了第 0、1、3 号通道，共 3 个。
```

### 示例 2

```
输入：x = 128
输出：1
解释：128 = 0b1000_0000，只选中了第 7 号通道。
```

### 示例 3

```
输入：x = 4294967295
输出：32
解释：0xFFFFFFFF，32 个通道全部选中。
```

### 提示

- `0 <= x <= 2^32 - 1`

### 函数说明

```c
int popcount32(uint32_t x);
```

- `x`：通道选择寄存器的值（32 位无符号整数）
- 返回值：`x` 中值为 `1` 的位的个数（`0 ~ 32`）

### 自定义输入格式

```
11
```

输入一行，为十进制整数 `x`。输出为 `1` 的个数。
