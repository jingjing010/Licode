# 318. 最大单词长度乘积 —— 小白详细题解

> 这道题的核心技巧叫**位掩码（bitmask）**：小写字母只有 26 个，一个 `int` 有 32 位，正好可以用一个整数表示"一个单词里出现过哪些字母"。判断两个单词有没有公共字母，就只需要一次 `&` 运算。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 从单词表里挑两个单词，要求它俩**没有任何一个相同的字母**。在所有这样的挑法里，让"两个单词长度的乘积"最大。找不到就返回 0。

拿示例 1 来说：

| 单词对 | 有公共字母吗？ | 长度乘积 |
|---|---|---|
| "abcw" 和 "baz" | 有（a、b） | ✗ |
| "abcw" 和 "foo" | 没有 | 4 × 3 = 12 |
| "abcw" 和 "xtfn" | 没有 | 4 × 4 = **16** |
| "foo" 和 "abcdef" | 有（f） | ✗ |
| "xtfn" 和 "abcdef" | 有（f） | ✗ |

最大的是 16。

**几个需要注意的细节：**

1. 只看**有没有公共字母**，和字母出现几次无关。`"aaaa"` 和 `"a"` 也有公共字母。
2. 两个单词必须是**不同位置**的两个（`i != j`）。
3. 最多 1000 个单词，每个最长 1000，所以答案最大是 `1000 × 1000 = 10^6`，`int` 够用。

---

## 🧰 第二步：需要的 C 语言知识

### 1. `char** words` 是什么？

一个"字符串数组"：`words[i]` 是第 `i` 个字符串（`char*`），`words[i][k]` 是它的第 `k` 个字符。每个字符串都以 `'\0'` 结尾，所以可以这样遍历：

```c
for (int k = 0; words[i][k] != '\0'; k++) {
    char c = words[i][k];
}
```

### 2. 字母变成 0~25：`c - 'a'`

字符在 C 里就是整数（ASCII 码），`'a'` 是 97，`'c' - 'a' = 2`。

### 3. ⭐ 用一个整数表示一个集合

让第 `k` 位表示"第 `k` 个字母有没有出现"：

```
单词 "abcw"：
  a → 第 0 位，b → 第 1 位，c → 第 2 位，w → 第 22 位
  mask = 0000 0100 0000 0000 0000 0000 0111
```

- 加入字母：`mask |= 1 << (c - 'a');`
- 两个集合有没有交集：`(mask1 & mask2) != 0` 就说明有公共字母。

---

## 💡 第三步：思路一 —— 预处理字母表 + 枚举所有单词对

### 思路

最直接的想法是：枚举每一对单词，再逐字符比较。但每对单词最长 1000 × 1000 次比较，一共 50 万对，太慢了。

改进一下：**先给每个单词做一张"字母出现表"** `has[i][0..25]`。比较两个单词时，只需要看 26 个字母有没有同时出现，每对只要 26 次比较。

### 手动模拟（示例 2 的一部分）

| 单词 | a | b | c | d |
|---|---|---|---|---|
| "ab" | ✔ | ✔ | | |
| "cd" | | | ✔ | ✔ |
| "abc" | ✔ | ✔ | ✔ | |

- "ab" 和 "cd"：没有一列两个都打勾 → 无公共字母，乘积 2 × 2 = 4；
- "abc" 和 "cd"：c 列两个都打勾 → 有公共字母。

### 代码

```c
int maxProduct(char** words, int wordsSize) {
    // has[i * 26 + c] 表示第 i 个单词里有没有出现字母 c
    bool* has = (bool*)calloc(wordsSize * 26, sizeof(bool));
    int* len = (int*)malloc(sizeof(int) * wordsSize);

    // 预处理：每个单词的字母表和长度
    for (int i = 0; i < wordsSize; i++) {
        int k = 0;
        for (; words[i][k] != '\0'; k++) {
            has[i * 26 + (words[i][k] - 'a')] = true;
        }
        len[i] = k;
    }

    int best = 0;
    for (int i = 0; i < wordsSize; i++) {
        for (int j = i + 1; j < wordsSize; j++) {
            // 检查 26 个字母，看有没有两个单词都出现的
            bool common = false;
            for (int c = 0; c < 26; c++) {
                if (has[i * 26 + c] && has[j * 26 + c]) {
                    common = true;
                    break;
                }
            }
            if (!common && len[i] * len[j] > best) {
                best = len[i] * len[j];
            }
        }
    }

    free(has);
    free(len);
    return best;
}
```

### 复杂度分析

设单词个数为 `n`，所有单词总长度为 `L`。

- **时间复杂度 O(L + 26 · n²)**：预处理 O(L)；枚举 n²/2 对，每对最多 26 次比较。n = 1000 时约 1300 万次。
- **空间复杂度 O(26n)**：字母表。

## 🚀 第四步：思路二 —— 位掩码

### 思路

思路一里的 `has[i][0..25]` 是 26 个 `true/false`，正好可以压缩进一个 `int` 的低 26 位！

- 预处理：`mask[i] |= 1 << (c - 'a')`；
- 比较：26 次循环变成**一次** `mask[i] & mask[j]`。

### 手动模拟（示例 1）

| 单词 | 出现的字母 | mask（只写出有 1 的位） |
|---|---|---|
| "abcw" | a b c w | 第 0、1、2、22 位 |
| "baz" | a b z | 第 0、1、25 位 |
| "xtfn" | f n t x | 第 5、13、19、23 位 |

- `mask("abcw") & mask("baz")`：第 0、1 位都是 1 → 非 0 → 有公共字母；
- `mask("abcw") & mask("xtfn")`：没有共同的 1 → 等于 0 → 无公共字母，乘积 16。

### 代码

```c
int maxProduct(char** words, int wordsSize) {
    int* mask = (int*)malloc(sizeof(int) * wordsSize);   // 每个单词的字母集合
    int* len = (int*)malloc(sizeof(int) * wordsSize);    // 每个单词的长度

    for (int i = 0; i < wordsSize; i++) {
        int m = 0, k = 0;
        for (; words[i][k] != '\0'; k++) {
            m |= 1 << (words[i][k] - 'a');               // 把这个字母对应的位置 1
        }
        mask[i] = m;
        len[i] = k;                                      // 顺便记下长度，避免反复调用 strlen
    }

    int best = 0;
    for (int i = 0; i < wordsSize; i++) {
        for (int j = i + 1; j < wordsSize; j++) {
            // 两个集合没有交集 ⇔ 按位与为 0
            if ((mask[i] & mask[j]) == 0 && len[i] * len[j] > best) {
                best = len[i] * len[j];
            }
        }
    }

    free(mask);
    free(len);
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(L + n²)**：每对单词只需要一次 `&`。n = 1000 时约 50 万次。
- **空间复杂度 O(n)**：两个数组。

> 💬 **小优化**：如果多个单词的字母集合相同（比如 `"ab"` 和 `"aabb"`），只需要保留最长的那个，可以进一步减少单词对的数量。

---

## ⚠️ 第五步：小白常见错误

1. **`(mask[i] & mask[j] == 0)` 少了括号**：`==` 比 `&` 先算，变成 `mask[i] & (mask[j] == 0)`，结果完全错。必须写 `(mask[i] & mask[j]) == 0`。
2. **用 `mask = 1 << c` 而不是 `mask |= 1 << (c - 'a')`**：`=` 会把之前的字母覆盖掉，只剩最后一个字母；忘了减 `'a'` 则会移位 97 位以上，结果未定义。
3. **在双重循环里调用 `strlen`**：`strlen` 每次都要从头数到 `'\0'`，50 万对 × 1000 字符 = 5 亿次，可能超时。预处理时把长度存起来。
4. **`j` 从 0 开始**：会出现 `i == j`，同一个单词和自己比较。虽然自己和自己一定有公共字母不会算进答案，但白白多算了一倍。
5. **每对单词逐字符比较**：O(n² · len²)，最坏 10^12 次，超时。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐字符比较（❌） | O(n² · len²) | O(1) | ⭐ | 会超时 |
| 字母表 + 枚举 | O(L + 26 · n²) | O(26n) | ⭐⭐ | 好理解，能 AC |
| 位掩码 | O(L + n²) | O(n) | ⭐⭐ | 标准答案，代码也最短 |
