# Excel 表列名称：题解

## 📖 先读懂题目

给定列号 columnNumber，1 ≤ columnNumber ≤ 2^31−1，返回 A、B、…、Z、AA 等列名。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `1` | `"A"` |
| 2 | `28` | `"AB"` |

## 🧰 需要的 C 语言知识

申请输出字符串时，要在有效字符之外多留1字节写入结束符。参考实现返回动态内存，由调用方负责释放。

## 💡 推导与实现

每一位的数字是1到26，而非0到25。先减1即可使用普通的除余操作。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
char *convertToTitle(int columnNumber) {
    char tmp[16];
    int n = 0;
    /* 列号从1开始，每次先减1再做26进制转换。 */
    while (columnNumber) {
        --columnNumber;
        tmp[n++] = 'A' + columnNumber % 26;
        columnNumber /= 26;
    }
    char *out = malloc(n + 1);
    for (int i = 0; i < n; ++i)
        out[i] = tmp[n - 1 - i];
    out[n] = '\0';
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(log n)，额外空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 只申请有效字符数大小的缓冲区，没有给结束符留空间。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。

## 🔗 举一反三

尝试把同一处理过程改成逐个输入的流式接口，思考需要保留哪些状态。用空边界、最小值、最大值和重复值检查自己的实现。
