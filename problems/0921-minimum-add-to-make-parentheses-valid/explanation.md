# 921. 使括号有效的最少添加 —— 小白详细题解

> "有效的括号"的变形：不是判断对不对，而是问**最少补几个**才能对。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一串只有 `(` 和 `)` 的字符串，你可以在任意位置**插入**括号。最少插入几个，能让它变成合法的括号串？

关键观察：**能配对的括号先配对**，剩下没配上的括号，每一个都需要补一个"另一半"。

| 输入 | 配对后剩下 | 需要补 | 答案 |
|---|---|---|---|
| `"())"` | 第 3 个 `)` | 在前面补一个 `(` | 1 |
| `"((("` | 3 个 `(` | 在后面补 3 个 `)` | 3 |
| `")("` | `)` 和 `(` 都配不上 | 补 `(` 和 `)` 各一个 | 2 |

**几个需要注意的细节：**

1. `")("` 的答案是 **2**，不是 0！虽然左右括号个数一样，但 `)` 在前面，没法和后面的 `(` 配对。
2. 只能**插入**，不能删除。
3. 字符串里只有 `(` 和 `)`。

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 遍历字符串

```c
for (int i = 0; s[i] != '\0'; i++) {
    if (s[i] == '(') { /* 左括号 */ }
    else             { /* 右括号 */ }
}
```

注意字符要用**单引号** `'('`，双引号 `"("` 是字符串（一个指针），不能和 `char` 比较。

### 2. 用数组模拟栈

```c
char* st = (char*)malloc(strlen(s) + 1);   // 栈最多放 n 个字符
int top = 0;
st[top++] = '(';     // 入栈
top--;               // 出栈
```

`strlen(s)` 返回字符串长度（不含 `'\0'`），需要 `<string.h>`（本 OJ 已自动包含）。

## 💡 第三步：思路一 —— 栈模拟配对

### 思路

和「20. 有效的括号」一样用栈：

- 遇到 `(`：入栈，等待配对。
- 遇到 `)`：如果栈顶是 `(`，配对成功，弹出；否则这个 `)` 配不上，也压进栈里。

最后栈里剩下的就是所有配不上的括号，**栈的大小就是答案**。

### 手动模拟（`"()))(("`）

| i | 字符 | 操作 | 栈（底→顶） |
|---|---|---|---|
| 0 | ( | 入栈 | ( |
| 1 | ) | 栈顶是 (，配对弹出 | 空 |
| 2 | ) | 栈空，配不上，入栈 | ) |
| 3 | ) | 栈顶是 )，配不上，入栈 | ) ) |
| 4 | ( | 入栈 | ) ) ( |
| 5 | ( | 入栈 | ) ) ( ( |

剩下 4 个，答案 4。

### 代码

```c
int minAddToMakeValid(char* s) {
    int n = strlen(s);
    char* st = (char*)malloc(n + 1);   // 栈：存还没配对的括号
    int top = 0;
    for (int i = 0; i < n; i++) {
        if (s[i] == ')' && top > 0 && st[top - 1] == '(') {
            top--;                     // 和栈顶的 '(' 配对成功
        } else {
            st[top++] = s[i];          // 配不上（或者是 '('），先放进栈里
        }
    }
    free(st);
    return top;                        // 剩下几个配不上的，就要补几个
}
```

### 复杂度分析

- **时间复杂度 O(n)**
- **空间复杂度 O(n)**

## 🚀 第四步：思路二 —— 计数代替栈（O(1) 空间）

### 为什么能优化？

仔细看栈里的内容：一旦压进了一个 `)`，它下面的东西永远不会再被弹出（`)` 不会和后面任何东西配对）。
所以我们只关心两个数：

- `open`：目前**还在等待配对的 `(`** 的个数；
- `ans`：已经确定**配不上的 `)`** 的个数（每个都要在前面补一个 `(`）。

遇到 `)` 时：`open > 0` 就配对（`open--`），否则 `ans++`。最后剩下的 `open` 个 `(` 也要各补一个 `)`。

### 手动模拟（`"()))(("`）

| i | 字符 | open | ans |
|---|---|---|---|
| 0 | ( | 1 | 0 |
| 1 | ) | 0 | 0 |
| 2 | ) | 0 | 1 |
| 3 | ) | 0 | 2 |
| 4 | ( | 1 | 2 |
| 5 | ( | 2 | 2 |

答案 `ans + open = 2 + 2 = 4` ✅

### 代码

```c
int minAddToMakeValid(char* s) {
    int open = 0;   // 还没配对的 '(' 个数
    int ans = 0;    // 配不上的 ')' 个数（需要补 '('）
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] == '(') {
            open++;                 // 新的左括号，等待配对
        } else if (open > 0) {
            open--;                 // 有左括号可以配对
        } else {
            ans++;                  // 没有左括号可配，必须补一个 '('
        }
    }
    return ans + open;              // 剩下的 '(' 也要各补一个 ')'
}
```

### 复杂度分析

- **时间复杂度 O(n)**
- **空间复杂度 O(1)**

## ⚠️ 第五步：小白常见错误

1. **直接返回 `|左括号数 - 右括号数|`** → `")("` 会得到 0，正确答案是 2。顺序很重要！
2. **`open` 减成负数** → 写成 `else open--;` 不判断 `open > 0`，那么 `"))(("` 中 open 先变成 -2 再变回 0，返回 0，错误。
3. **最后忘了加 `open`** → `"((("` 会返回 0，正确是 3。
4. **用双引号比较字符** → `s[i] == "("` 是拿字符和指针比较，编译警告且结果错误。
5. **栈解法里没检查 `top > 0` 就访问 `st[top - 1]`** → 栈空时访问 `st[-1]`，越界。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 栈模拟 | O(n) | O(n) | ⭐ | 最直观 |
| 计数 | O(n) | O(1) | ⭐ | 推荐，代码最短 |
