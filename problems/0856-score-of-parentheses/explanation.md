# 856. 括号的分数 —— 小白详细题解

> 括号题的老朋友：**栈**。这道题还能进一步找到规律，做到不用栈。

---

## 📖 第一步：先读懂题目

三条规则翻译成大白话：

> - 一对紧挨着的 `()` 值 **1 分**；
> - 两段并排放，分数**相加**；
> - 用一对括号把一段**包起来**，分数**翻倍**。

拿示例 4 `"(()(()))"` 拆解：

| 片段 | 怎么算 | 分数 |
|---|---|---|
| `()` | 规则一 | 1 |
| `(())` | 把 `()` 包起来，翻倍 | 2 |
| `()(())` | 两段并排，相加 1 + 2 | 3 |
| `(()(()))` | 再整体包起来，翻倍 | **6** |

**几个需要注意的细节：**

1. 输入保证是**平衡**的括号串，不用判断合法性。
2. 长度最多 50，最深 25 层，最大分数是 2²⁴，`int` 放得下。
3. 空串分数是 0，但 `(A)` 里 A 为空时不是 2×0，而是规则一的 1 分。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 遍历 `'\0'` 结尾的字符串

```c
for (int i = 0; s[i] != '\0'; i++) {   // 也可以简写成 s[i]
    // s[i] 是第 i 个字符
}
```

C 字符串没有"长度"字段，靠末尾的 `'\0'` 判断结束。

### 2. 用数组当栈

```c
int st[30];          // 最多 25 层，开 30 足够
int top = 0;
st[top++] = 0;       // 入栈
int x = st[--top];   // 出栈
st[top - 1] += x;    // 修改栈顶
```

### 3. 位运算 `1 << d`

`1 << d` 就是 2 的 d 次方：`1 << 0 = 1`，`1 << 3 = 8`。比 `pow` 快，而且结果是整数。

---

## 💡 第三步：思路一 —— 栈：每一层记录自己的分数

### 思路

把每一对括号看作一"层"。栈里存放**每一层目前累计的分数**：

- 一开始栈里放一个 0，代表最外面（还没有括号）的那一层。
- 遇到 `'('`：开启新的一层，压入 0。
- 遇到 `')'`：当前层结束，弹出它的分数 `v`：
  - 如果 `v == 0`，说明里面是空的，这一对是 `()`，值 1；
  - 否则这一对是 `(A)`，值 `2 * v`。
  - 把这个值**加到外面一层**（新的栈顶）上。
- 最后栈底那个数就是答案。

### 手动模拟（示例 4：`"(()(()))"`）

| i | 字符 | 操作 | 栈（底→顶） |
|---|---|---|---|
| 初始 | | | 0 |
| 0 | ( | 压 0 | 0 0 |
| 1 | ( | 压 0 | 0 0 0 |
| 2 | ) | 弹 0 → 值 1，加到栈顶 | 0 1 |
| 3 | ( | 压 0 | 0 1 0 |
| 4 | ( | 压 0 | 0 1 0 0 |
| 5 | ) | 弹 0 → 值 1 | 0 1 1 |
| 6 | ) | 弹 1 → 值 2×1=2 | 0 3 |
| 7 | ) | 弹 3 → 值 2×3=6 | 6 |

答案 6 ✅

### 代码

```c
int scoreOfParentheses(char* s) {
    int st[64];          // 栈：st[k] 是第 k 层目前累计的分数
    int top = 0;
    st[top++] = 0;       // 最外层（还没进任何括号）

    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] == '(') {
            st[top++] = 0;                      // 进入新的一层，分数从 0 开始
        } else {
            int v = st[--top];                  // 当前层结束，取出它的分数
            int val = (v == 0) ? 1 : 2 * v;     // 空的是 ()=1，否则 (A)=2*A
            st[top - 1] += val;                 // 加到外面一层
        }
    }
    return st[0];
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个字符处理一次。
- **空间复杂度 O(n)**：栈的深度最多 n/2 + 1。

## 🚀 第四步：思路二 —— 只数 `()` 的深度（O(1) 空间）

### 思路

把分数"展开"来看：`(()(()))` = 2 × (1 + 2 × 1) = 2 + 4。

发现了吗？**真正产生分数的只有紧挨着的 `()`**，外面每包一层就把它乘 2。
所以一个 `()` 如果外面套了 d 层括号，它贡献 **2^d** 分，答案就是所有 `()` 的贡献之和。

实现：用 `depth` 记录当前在第几层。遇到 `')'` 先 `depth--`，如果前一个字符是 `'('`（说明这是一个紧挨着的 `()`），就加上 `1 << depth`。

### 手动模拟（`"(()(()))"`）

| i | 字符 | depth（处理后） | 是 `()` 吗？ | 贡献 | 累计 |
|---|---|---|---|---|---|
| 0 | ( | 1 | | | 0 |
| 1 | ( | 2 | | | 0 |
| 2 | ) | 1 | ✅ | 2¹ = 2 | 2 |
| 3 | ( | 2 | | | 2 |
| 4 | ( | 3 | | | 2 |
| 5 | ) | 2 | ✅ | 2² = 4 | 6 |
| 6 | ) | 1 | ❌（前一个是 `)`） | | 6 |
| 7 | ) | 0 | ❌ | | **6** |

### 代码

```c
int scoreOfParentheses(char* s) {
    int ans = 0;
    int depth = 0;                 // 当前嵌套深度
    for (int i = 0; s[i] != '\0'; i++) {
        if (s[i] == '(') {
            depth++;
        } else {
            depth--;
            if (s[i - 1] == '(') {     // 紧挨着的 ()：i >= 1 一定成立，因为第 0 个字符一定是 '('
                ans += 1 << depth;     // 外面还有 depth 层，贡献 2^depth
            }
        }
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**
- **空间复杂度 O(1)**

---

## ⚠️ 第五步：小白常见错误

1. **把 `()` 当作 2 × 0 = 0** → 栈解法里弹出的 `v == 0` 时要特判为 1，否则所有答案都是 0。
2. **思路二里先算贡献再 `depth--`** → 那样 `()` 会多算一层，`"()"` 得到 2 而不是 1。
3. **把所有 `)` 都算贡献** → 只有前一个字符是 `(` 的 `)` 才是"紧挨着的 `()`"。
4. **用 `pow(2, depth)`** → 返回 `double`，虽然这里能过，但有精度隐患，整数次幂用 `1 << depth`。
5. **栈数组开太小** → 最深 25 层加上最外层，至少要 26 个位置。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 栈记录每层分数 | O(n) | O(n) | ⭐⭐ | 通用，先掌握 |
| 统计 `()` 的深度 | O(n) | O(1) | ⭐⭐ | 需要发现规律，很巧妙 |
