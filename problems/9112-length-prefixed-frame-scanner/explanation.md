# 带长度字段的数据帧扫描：题解

## 📖 先读懂题目

帧格式AA 55 LEN PAYLOAD，LEN为1字节，载荷可含任意字节。跳过帧外噪声，遇不完整帧则停止，返回所有完整帧的载荷长度。0到1024字节。此练习无CRC且假定完整同步头不会在噪声中误出现。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[170,85,2,1,2,170,85,0]` | `[2,0]` |
| 2 | `[0,170,85,3,1]` | `[]` |

## 🧰 需要的 C 语言知识

`uint8_t`表示一个0到255的字节；`const uint8_t *`允许读取数据但不修改它。`size_t len`明确给出缓冲区长度，不能使用`strlen`计算二进制数据长度，因为数据中可能含0。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

按字节找双字节同步头，确认长度字段与剩余数据一致再接收；有效载荷内的同步字不应误认成新帧。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *scanFrames(const uint8_t *data, size_t len, int *returnSize) {
    int *out = malloc((len + 1) * sizeof(int)), k = 0;
    size_t i = 0;
    while (i + 2 < len) {
        if (data[i] == 0xaa && data[i + 1] == 0x55) {
            size_t n = data[i + 2];
            if (n > len - i - 3)
                break;
            out[k++] = (int)n;
            i += 3 + n;
        } else
            ++i;
    }
    *returnSize = k;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，输出空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 把二进制缓冲区当成以零结尾的字符串，遇到0便提前停止。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
