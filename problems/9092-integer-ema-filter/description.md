# 整数指数滑动平均

初始输出y=0，每个采样后计算y=y+trunc((x−y)/2^shift)。shift0..8，采样为int16范围，最多1000个，返回每步输出。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* emaFilter(int* samples,int samplesSize,int shift,int* returnSize);
```

## 示例 1

输入：
```text
[100,100,100,0]
2
```
输出：
```text
[25,43,57,43]
```

## 示例 2

输入：
```text
[-7,-7,7]
1
```
输出：
```text
[-3,-5,1]
```

## 自定义输入格式

按顺序每行一个参数：samples、shift。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
