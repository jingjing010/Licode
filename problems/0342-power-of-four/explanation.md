# 342. 4的幂 —— 小白详细题解

> 判断"是不是 4 的幂"，最朴素的方法是不停地除以 4；而用位运算可以一行搞定：**先判断是 2 的幂（只有一个 1），再判断那个 1 在偶数位上**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 问 `n` 能不能写成 `4 × 4 × …… × 4`（乘若干次 4，乘 0 次就是 1）。

4 的幂有：`1, 4, 16, 64, 256, ……`。看看它们的二进制：

| 数 | 1 | 4 | 16 | 64 | 256 |
|---|---|---|---|---|---|
| 二进制 | 1 | 100 | 1 0000 | 100 0000 | 1 0000 0000 |
| 1 在第几位 | 0 | 2 | 4 | 6 | 8 |

**几个需要注意的细节：**

1. **`n = 1` 是 4 的幂**（`4^0 = 1`），示例 3。
2. **0 和负数都不是**：`4^x` 永远是正数。
3. **2 的幂不一定是 4 的幂**：比如 2、8、32，它们只有一个 1，但在奇数位上。
4. int 范围内最大的 4 的幂是 `4^15 = 2^30 = 1073741824`。

---

## 🧰 第二步：需要的 C 语言知识

### 1. `n & (n - 1)`：消掉最右边的 1

如果 `n` 只有一个 1（2 的幂），消掉后就变成 0：

```
n           = 0001 0000   (16)
n - 1       = 0000 1111
n & (n - 1) = 0000 0000   ← 等于 0，说明 n 只有一个 1
```

### 2. 掩码 `0x55555555`

```
0x55555555 = 0101 0101 0101 0101 0101 0101 0101 0101
                                                  ↑ 第 0 位
```

它的所有**偶数位**（第 0、2、4、……、30 位）都是 1，奇数位都是 0。`n & 0x55555555` 不为 0，说明 `n` 在某个偶数位上有 1。

### 3. 运算符优先级：位运算一定加括号

`n & (n - 1) == 0` 会被解析成 `n & ((n - 1) == 0)`，因为 `==` 比 `&` 先算。必须写成 `(n & (n - 1)) == 0`。

---

## 💡 第三步：思路一 —— 不停除以 4

### 思路

1. `n <= 0` 直接返回 `false`；
2. 只要 `n` 能被 4 整除，就 `n /= 4`；
3. 最后剩下 1 就是 4 的幂，否则不是。

### 手动模拟

| n | 过程 | 结果 |
|---|---|---|
| 16 | 16 → 4 → 1 | 剩 1，`true` |
| 5 | 5 不能被 4 整除 | 剩 5，`false` |
| 8 | 8 → 2，2 不能被 4 整除 | 剩 2，`false` |

### 代码

```c
bool isPowerOfFour(int n) {
    if (n <= 0) return false;      // 0 和负数都不是
    while (n % 4 == 0) {           // 能被 4 整除就一直除
        n /= 4;
    }
    return n == 1;                 // 最后剩 1 才是 4 的幂
}
```

### 复杂度分析

- **时间复杂度 O(log n)**：最多除 15 次。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 位运算（无循环）

### 思路

`n` 是 4 的幂，等价于同时满足三个条件：

1. `n > 0`；
2. `n` 是 2 的幂，二进制只有一个 1：`(n & (n - 1)) == 0`；
3. 这个 1 在偶数位上：`(n & 0x55555555) != 0`。

### 手动模拟

| n | 二进制 | n > 0 | 只有一个 1 | 在偶数位 | 结果 |
|---|---|---|---|---|---|
| 16 | 1 0000 | ✔ | ✔ | ✔（第 4 位） | `true` |
| 8 | 1000 | ✔ | ✔ | ✘（第 3 位） | `false` |
| 5 | 101 | ✔ | ✘ | | `false` |
| 0 | 0 | ✘ | | | `false` |

### 代码

```c
bool isPowerOfFour(int n) {
    return n > 0                       // 必须是正数
        && (n & (n - 1)) == 0          // 只有一个 1（是 2 的幂）
        && (n & 0x55555555) != 0;      // 这个 1 在偶数位上
}
```

### 复杂度分析

- **时间复杂度 O(1)**。
- **空间复杂度 O(1)**。

> 💬 **另一个数学技巧**：`4^k = (3 + 1)^k`，展开后除了最后一项 1 都是 3 的倍数，所以 4 的幂除以 3 一定余 1；而 `2 × 4^k` 除以 3 余 2。于是第 3 个条件也可以写成 `n % 3 == 1`。

---

## ⚠️ 第五步：小白常见错误

1. **忘了判断 `n <= 0`**：`n = 0` 时 `0 & (0 - 1) = 0`，会被误判成 2 的幂；`n = INT_MIN` 时 `n - 1` 还会溢出。`n > 0` 必须写在最前面，利用 `&&` 的短路特性。
2. **只判断 2 的幂**：`(n & (n - 1)) == 0` 会把 2、8、32 也判成 `true`。
3. **掩码用错**：`0xAAAAAAAA` 选的是奇数位，正好相反。记住 `0x5 = 0101`，最低位是 1。
4. **优先级陷阱**：`n & (n - 1) == 0` 实际是 `n & ((n - 1) == 0)`，大多数情况下结果是 0，全部判错。
5. **把 `n == 1` 漏掉**：如果你的循环写成"先除再判断"，可能会把 1 判成 `false`。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 不停除以 4 | O(log n) | O(1) | ⭐ | 最直观 |
| 位运算 | O(1) | O(1) | ⭐⭐ | 满足进阶要求 |
| 2 的幂 + 模 3 | O(1) | O(1) | ⭐⭐ | 了解即可 |
