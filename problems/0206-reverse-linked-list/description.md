给你单链表的头节点 `head` ，请你反转链表，并返回反转后的链表。

### 示例 1

```
1 -> 2 -> 3 -> 4 -> 5
  反转后
5 -> 4 -> 3 -> 2 -> 1
```

```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]
```

### 示例 2

```
输入：head = [1,2]
输出：[2,1]
```

### 示例 3

```
输入：head = []
输出：[]
```

### 提示

- 链表中节点的数目范围是 `[0, 5000]`
- `-5000 <= Node.val <= 5000`

**进阶：** 链表可以选用迭代或递归方式完成反转。你能否用两种方法解决这道题？

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* reverseList(struct ListNode* head);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `head`：链表的头指针，空链表用 `NULL` 表示
- 返回值：反转后链表的头指针（直接修改原结点的 `next` 即可，不需要 `malloc` 新结点）

### 自定义输入格式

```
[1,2,3,4,5]
```

只有 1 行，是链表 `head`，空链表写作 `[]`。输出为反转后的链表。
