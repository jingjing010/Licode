# 83. 删除排序链表中的重复元素 —— 小白详细题解

> 链表"删除结点"的入门题。学会"跳过一个结点"这一招，后面的链表题都会用到。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 链表已经从小到大排好序了，相同的数**挨在一起**。每种数只留一个，多出来的删掉。

用示例 2（`[1,1,2,3,3]`）看看：

```
1 -> 1 -> 2 -> 3 -> 3
     ×              ×        打叉的是多余的重复结点
1 -> 2 -> 3
```

**几个需要注意的细节：**

1. 链表**有序**，所以只需要比较**相邻**的两个结点。
2. 空链表（`head == NULL`）直接返回 `NULL`。
3. 第一个结点永远会被保留，所以返回的头结点就是原来的 `head`。
4. 可能连续很多个相同，比如 `[7,7,7,7]`，要全部删到只剩一个。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 结构体指针和 `->`

```c
struct ListNode {
    int val;                 // 结点里存的数
    struct ListNode *next;   // 指向下一个结点，最后一个结点的 next 是 NULL
};
```

`cur->next->val` 的意思是：先找到 `cur` 的下一个结点，再取它的值。**前提是 `cur->next != NULL`**，否则就是访问空指针，程序崩溃。

### 2. 怎样"删除"链表中的一个结点

想删掉 `cur` 后面的结点 `del`，只要让 `cur` **跳过**它：

```
删除前：cur -> del -> X
删除后：cur ---------> X        （cur->next = del->next）
```

```c
struct ListNode* del = cur->next;   // 先记住要删的结点
cur->next = del->next;              // 跳过它
free(del);                          // 释放它占的内存（可选，但是好习惯）
```

> 💬 `free` 之后就不能再访问 `del->next` 了，所以要**先改指针，再 free**。

---

## 💡 第三步：思路一 —— 把值存到数组里再重建（最朴素）

### 思路

1. 遍历链表，把"和前一个保留值不同"的值依次存进数组 `vals`
2. 再把原链表的前 `k` 个结点的值依次改成 `vals[0..k-1]`，第 `k` 个结点后面剪断

### 代码

```c
struct ListNode* deleteDuplicates(struct ListNode* head) {
    if (head == NULL) return NULL;

    // 1. 收集不重复的值（最多 300 个结点）
    int vals[300];
    int k = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) {
        if (k == 0 || p->val != vals[k - 1]) {   // 和上一个保留的值不同 → 新值
            vals[k++] = p->val;
        }
    }

    // 2. 用原链表的前 k 个结点装这 k 个值
    struct ListNode* p = head;
    for (int i = 0; i < k; i++) {
        p->val = vals[i];
        if (i == k - 1) p->next = NULL;          // 第 k 个结点后面剪断
        else p = p->next;
    }
    return head;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(n)**（数组）。能过，但没有用到链表"删结点很方便"的特点。

---

## 🚀 第四步：思路二 —— 一次遍历，直接跳过重复结点（最优）

### 思路

用指针 `cur` 从头开始：

- 如果 `cur->val == cur->next->val`：下一个是重复的，**删掉它**（`cur` 不动，因为新的下一个可能还是重复的）
- 否则：`cur` 往后走一步

### 手动模拟（示例 2：`[1,1,2,3,3]`）

| 步骤 | cur | cur->next | 相等？ | 操作 | 当前链表 |
|---|---|---|---|---|---|
| 1 | 1 | 1 | 是 | 删掉第二个 1 | 1->2->3->3 |
| 2 | 1 | 2 | 否 | cur 走到 2 | 1->2->3->3 |
| 3 | 2 | 3 | 否 | cur 走到 3 | 1->2->3->3 |
| 4 | 3 | 3 | 是 | 删掉第二个 3 | 1->2->3 |
| 5 | 3 | NULL | - | 循环结束 | 1->2->3 |

### 代码

```c
struct ListNode* deleteDuplicates(struct ListNode* head) {
    struct ListNode* cur = head;
    // cur 和 cur->next 都存在时才需要比较
    while (cur != NULL && cur->next != NULL) {
        if (cur->val == cur->next->val) {
            struct ListNode* del = cur->next;   // 下一个是重复的
            cur->next = del->next;              // 跳过它
            free(del);                          // 释放内存
            // 注意：cur 不动！新的 cur->next 可能还是同一个值
        } else {
            cur = cur->next;                    // 值不同，cur 才往后走
        }
    }
    return head;                                // 头结点一定保留
}
```

空链表时 `cur == NULL`，循环不执行，直接返回 `NULL`。

### 复杂度分析

- **时间复杂度 O(n)**：每个结点只看一次。
- **空间复杂度 O(1)**：只用了一个 `cur` 指针。

---

## ⚠️ 第五步：小白常见错误

1. **循环条件只写 `cur != NULL`**：走到最后一个结点时 `cur->next` 是 `NULL`，再访问 `cur->next->val` 会崩溃。必须写 `cur != NULL && cur->next != NULL`。
2. **删除后 `cur` 也往后走了**：对 `[1,1,1]`，删掉第二个 1 后 `cur` 如果走到第三个 1，就再也不会和第一个比较，结果变成 `[1,1]`。
3. **先 `free` 再取 `next`**：`free(cur->next); cur->next = cur->next->next;` 访问了已释放的内存，行为未定义。要先保存、先改指针、最后 `free`。
4. **以为要返回新的头**：本题第一个结点永远保留，直接返回 `head` 即可；不需要 `malloc` 新链表。
5. **忘记判空**：在函数开头直接写 `head->next`，空链表时崩溃。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 存数组再重建 | O(n) | O(n) | ⭐ | 能过，但不够"链表" |
| 一次遍历跳过重复 | O(n) | O(1) | ⭐ | **推荐**，链表删除的基本功 |
