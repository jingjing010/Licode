设备通过串口接收上位机的文本命令，例如 `SPEED -1500`、`AT+VOL=12`。命令解析器切出参数部分后，需要把它转换成整数。标准库的 `atoi` 遇到溢出时行为未定义，很多嵌入式项目为了**体积小、行为确定**会自己实现一个。

请实现函数 `my_atoi`，把字符串 `s` 转换成 32 位有符号整数，规则如下：

1. 跳过开头的所有**空格** `' '`（只有空格，制表符等其它字符不跳过）
2. 接下来如果是 `'+'` 或 `'-'`，记下符号（最多一个符号）
3. 连续读取数字字符 `'0'~'9'`，遇到第一个非数字字符（或字符串结束）就停止，后面的内容全部忽略
4. 如果一个数字都没读到，返回 `0`
5. 结果超出 `int32_t` 范围时**饱和**：大于 `2147483647` 返回 `2147483647`，小于 `-2147483648` 返回 `-2147483648`

### 示例 1

```
输入：s = "1500"
输出：1500
```

### 示例 2

```
输入：s = "  -42mV"
输出：-42
解释：跳过 2 个空格，读到 '-'，再读数字 42，遇到 'm' 停止。
```

### 示例 3

```
输入：s = "AT+CSQ"
输出：0
解释：第一个非空格字符是 'A'，不是符号也不是数字，没有读到任何数字。
```

### 提示

- `0 <= strlen(s) <= 200`
- `s` 由可打印 ASCII 字符、空格和制表符组成
- 不要调用 `atoi`、`strtol`、`sscanf` 等库函数

### 函数说明

```c
int32_t my_atoi(const char* s);
```

- `s`：以 `'\0'` 结尾的字符串
- 返回值：按上述规则转换得到的整数

### 自定义输入格式

```
"  -42mV"
```

只有 1 行：带双引号的字符串 `s`（可以用 `\t` 表示制表符）。输出为十进制整数。
