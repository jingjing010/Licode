# 仅仅反转字母

反转ASCII字符串中的英文字母顺序，非字母字符保持位置不变。长度1到100。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* reverseOnlyLetters(char* s);
```

## 示例 1

输入：
```text
"ab-cd"
```
输出：
```text
"dc-ba"
```

## 示例 2

输入：
```text
"a-bC-dEf-ghIj"
```
输出：
```text
"j-Ih-gfE-dCba"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
