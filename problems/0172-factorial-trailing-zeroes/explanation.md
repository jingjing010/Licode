# 阶乘后的零：题解

## 📖 先读懂题目

末尾每个0需要一对2和5。阶乘中2比5多，只数因子5即可：n/5+n/25+n/125。不断将n除以5可避免幂次乘法溢出。

### 示例1

输入：
```text
3
```
输出：
```text
0
```

### 示例2

输入：
```text
5
```
输出：
```text
1
```

### 示例3

输入：
```text
0
```
输出：
```text
0
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 直接算 n! 不可行：20! 就超出 long long 了。末尾的 0 是怎么来的？每个 0 都来自一个因子 10 = 2 × 5。
2. 1~n 中因子 2 的个数远多于因子 5，所以只需要数出 n! 里一共有多少个因子 5。
3. 1~n 中 5 的倍数有 n/5 个，25 的倍数又各多贡献一个 5，有 n/25 个……答案是 n/5 + n/25 + n/125 + …，也就是不断 n /= 5 并累加。

## 可直接提交的 C 代码

```c
/* 统计因子 5 的个数：n/5 + n/25 + ...，O(log n) */
int trailingZeroes(int n) {
    int cnt = 0;
    while (n > 0) {
        n /= 5;
        cnt += n;
    }
    return cnt;
}
```

## 📊 复杂度

时间 O(log n)，空间 O(1)。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。

## 🔗 举一反三

改变输入长度为1、重复值、边界整数，手工验证每一步保存的状态。思考能否在输入逐个到达时保留相同的状态完成计算。
