# 最长和谐子序列

返回最长子序列长度，使最大值与最小值之差恰好为1。子序列可不连续。1 ≤ n ≤ 2*10^4，元素为32位整数。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int findLHS(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,3,2,2,5,2,3,7]
```
输出：
```text
5
```

## 示例 2

输入：
```text
[1,1,1,1]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
