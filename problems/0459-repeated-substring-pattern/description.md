给定一个非空的字符串 `s` ，检查是否可以通过由它的一个子串重复多次构成。

### 示例 1

```
输入：s = "abab"
输出：true
解释：可由子串 "ab" 重复两次构成。
```

### 示例 2

```
输入：s = "aba"
输出：false
```

### 示例 3

```
输入：s = "abcabcabcabc"
输出：true
解释：可由子串 "abc" 重复四次构成。 (或子串 "abcabc" 重复两次构成。)
```

### 提示

- `1 <= s.length <= 10^4`
- `s` 由小写英文字母组成

### 函数说明

```c
bool repeatedSubstringPattern(char* s);
```

- `s`：以 `'\0'` 结尾的字符串
- 返回值：能由某个子串重复**至少两次**构成返回 `true`，否则返回 `false`

### 自定义输入格式

```
"abab"
```

只有 1 行，带双引号的字符串 `s`。
