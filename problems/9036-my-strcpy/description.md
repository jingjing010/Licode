`strcpy` 把一个字符串复制到另一块内存里，包括结尾的 `'\0'`。在嵌入式中常用来把设备名、固件版本号、AT 指令等复制进缓冲区。它也是"缓冲区溢出"漏洞的头号来源，面试官非常喜欢就此追问。

请你实现 `my_strcpy(dst, src)`：把字符串 `src`（**包括结尾的 `'\0'`**）复制到 `dst`，返回 `dst`。

> **不要调用库函数 `strcpy` / `memcpy` 等**，请自己用指针完成。

判题程序准备一个**刚好** `strlen(src) + 1` 字节、且事先填满了字符 `'#'` 的缓冲区 `dst`，调用 `my_strcpy(dst, src)` 后把 `dst` 当作字符串输出。

### 示例 1

```
输入：src = "hello"
输出："hello"
```

### 示例 2

```
输入：src = ""
输出：""
解释：空串也要复制它的 '\0'。dst 原来是 "#"，复制后 dst[0] = '\0'。
```

### 示例 3

```
输入：src = "AT+RST"
输出："AT+RST"
```

### 提示

- `0 <= strlen(src) <= 10^5`
- `src` 由可打印 ASCII 字符和 UTF-8 编码的中文组成

### 函数说明

```c
char* my_strcpy(char* dst, const char* src);
```

- `dst`：目标缓冲区，保证足够大（正好 `strlen(src) + 1` 字节）
- `src`：源字符串，两者不重叠
- 返回值：必须返回 `dst`

`dst` 后面有一段"哨兵"内存。如果没有复制 `'\0'`、返回值不是 `dst`，或写到了 `dst` 之外，会输出一行错误信息（判为答案错误）。

### 自定义输入格式

```
"hello"
```

输入一行，为带双引号的字符串 `src`（支持 `\"`、`\\` 转义）。输出为复制后的 `dst`。
