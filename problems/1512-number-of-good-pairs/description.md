# 好数对的数目

满足i<j且nums[i]==nums[j]称为好数对，返回总对数。1 ≤ n ≤ 100，元素1到100。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int numIdenticalPairs(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,2,3,1,1,3]
```
输出：
```text
4
```

## 示例 2

输入：
```text
[1,1,1,1]
```
输出：
```text
6
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
