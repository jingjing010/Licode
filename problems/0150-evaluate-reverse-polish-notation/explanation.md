# 150. 逆波兰表达式求值 —— 小白详细题解

> 计算器、编译器在背后都会把算式转换成"逆波兰表达式"再计算，因为它**不需要括号、也不用考虑优先级**，只要一个栈就能算出来。

---

## 📖 第一步：先读懂题目

我们平时写 `(2 + 1) * 3`，运算符在两个数**中间**（中缀）。逆波兰表达式把运算符写在两个数**后面**（后缀）：`2 1 + 3 *`。

计算规则只有一句话：

> 从左往右读，遇到数字就记下来；遇到运算符，就拿**最近记下的两个数**算一下，结果再记下来。

"最近记下的"——这正是**栈**的特点（后进先出）。走一遍示例 2：`["4","13","5","/","+"]`

| 读到 | 操作 | 栈（底→顶） |
|---|---|---|
| 4 | 压栈 | 4 |
| 13 | 压栈 | 4, 13 |
| 5 | 压栈 | 4, 13, 5 |
| / | 弹出 b=5、a=13，算 13 / 5 = 2，压栈 | 4, 2 |
| + | 弹出 b=2、a=4，算 4 + 2 = 6，压栈 | 6 |

最后栈里剩下的唯一一个数 `6` 就是答案。

**几个需要注意的细节：**

1. **顺序很重要**：先弹出的是 `b`（右操作数），后弹出的是 `a`（左操作数），要算 `a - b`、`a / b`，反了就错。
2. **`"-11"` 是负数，不是减号**。只有长度为 1 的 `"-"` 才是运算符。
3. 除法"向零截断"：`-7 / 2 = -3`（不是 -4）。C 语言的 `/` 本来就是向零截断，直接用即可。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `char** tokens` 是什么？

它是"字符串数组"：`tokens[i]` 是一个 `char*`，指向第 i 个字符串。比如 `tokens[0]` 是 `"2"`，`tokens[0][0]` 是字符 `'2'`。

### 2. 判断一个记号是不是运算符

```c
char* t = tokens[i];
if (t[1] == '\0' && (t[0] == '+' || t[0] == '-' || t[0] == '*' || t[0] == '/'))
```

`t[1] == '\0'` 表示字符串长度为 1。`"-11"` 的 `t[1]` 是 `'1'`，所以不会被当成减号。

### 3. 字符串转整数：`atoi`

`atoi("-11")` 返回 `-11`。它在 `<stdlib.h>` 里，会自动处理负号。

### 4. 用 malloc 的数组当栈

栈里最多同时有 `tokensSize` 个数，所以：

```c
int* st = (int*)malloc(sizeof(int) * tokensSize);
int top = 0;            // 栈中元素个数
st[top++] = x;          // 压栈
int y = st[--top];      // 弹栈：先把 top 减 1，再取 st[top]
```

注意 `st[--top]` 和 `st[top--]` 不一样：栈顶元素在 `st[top - 1]`，所以要**先减再取**。

## 💡 第三步：思路 —— 栈模拟

### 手动模拟（示例 1：`["2","1","+","3","*"]`）

| 读到 | 操作 | 栈 |
|---|---|---|
| 2 | 压栈 | 2 |
| 1 | 压栈 | 2, 1 |
| + | 2 + 1 = 3 | 3 |
| 3 | 压栈 | 3, 3 |
| * | 3 * 3 = 9 | 9 |

### 代码

```c
int evalRPN(char** tokens, int tokensSize) {
    // 1. 栈里最多 tokensSize 个数
    int* st = (int*)malloc(sizeof(int) * tokensSize);
    int top = 0;

    for (int i = 0; i < tokensSize; i++) {
        char* t = tokens[i];
        // 2. 长度为 1 且是 + - * / 之一，才是运算符
        if (t[1] == '\0' && (t[0] == '+' || t[0] == '-' || t[0] == '*' || t[0] == '/')) {
            int b = st[--top];      // 先弹出的是右操作数
            int a = st[--top];      // 后弹出的是左操作数
            int r;
            if (t[0] == '+') r = a + b;
            else if (t[0] == '-') r = a - b;
            else if (t[0] == '*') r = a * b;
            else r = a / b;         // C 的整数除法本来就是向零截断
            st[top++] = r;          // 结果压回栈
        } else {
            st[top++] = atoi(t);    // 3. 数字（可能带负号）直接压栈
        }
    }

    int ans = st[0];                // 4. 最后栈里只剩一个数
    free(st);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个记号处理一次。
- **空间复杂度 O(n)**：栈最多存 n 个数。

> 💬 有没有更快的方法？没有了——每个记号至少要看一眼，O(n) 已经是最优。

---

## ⚠️ 第四步：小白常见错误

1. **`a`、`b` 弹反了** → `["4","2","-"]` 应该是 4 - 2 = 2，弹反了会算出 -2。
2. **用 `t[0] == '-'` 判断减号** → `"-11"` 的第一个字符也是 `'-'`，会被误判为运算符，然后栈里元素不够，程序崩溃。
3. **写成 `st[top--]` 弹栈** → 取到的是栈顶**上面**那个没用的位置。
4. **用 `tokens[i] == "+"` 比较字符串** → 这是在比较两个指针（地址），永远不相等。要么比较字符，要么用 `strcmp(tokens[i], "+") == 0`。
5. **自己写除法取整** → 比如用 `floor` 向下取整，`-7 / 2` 会得到 -4，而题目要求 -3。
6. **把栈开成局部大数组 `int st[10000];`** → 本题能过，但养成按需 `malloc` 的习惯更安全。
