# 两个数对之间的最大乘积差

选取四个不同下标，最大化nums[w]*nums[x]−nums[y]*nums[z]。4 ≤ n ≤ 10^4，元素1到10^4。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int maxProductDifference(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[5,6,2,7,4]
```
输出：
```text
34
```

## 示例 2

输入：
```text
[4,2,5,9,7,4,8]
```
输出：
```text
64
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
