配置单片机外设时，经常需要修改寄存器中的某个 **位域**（连续的若干位），例如把定时器控制寄存器第 `4 ~ 7` 位的"分频系数"改成 `5`，同时 **绝对不能改动** 寄存器里的其它位——那些位可能控制着别的功能，改错了外设就会工作异常。

给定寄存器的原值 `reg`、位域的 **起始位** `pos`（位域最低位的位号）、**宽度** `width`，以及要写入的值 `val`，请把 `reg` 的第 `pos` 位到第 `pos + width - 1` 位替换为 `val`，其余位保持不变，返回修改后的寄存器值。

`val` 可能超出 `width` 位能表示的范围，此时 **只使用 `val` 的低 `width` 位**，多出来的高位必须丢弃，不能影响位域以外的位。

### 示例 1

```
输入：reg = 4294967295, pos = 4, width = 4, val = 0
输出：4294967055
解释：reg = 0xFFFFFFFF，把第 4~7 位写成 0，得到 0xFFFFFF0F = 4294967055。
```

### 示例 2

```
输入：reg = 180, pos = 2, width = 3, val = 2
输出：168
解释：180 = 0b1011_0100，第 2~4 位原来是 0b101，改写为 0b010 后得到 0b1010_1000 = 168。
```

### 示例 3

```
输入：reg = 0, pos = 0, width = 4, val = 255
输出：15
解释：val = 0xFF 超过了 4 位，只取低 4 位 0xF 写入，结果为 15。
```

### 提示

- `0 <= reg <= 2^32 - 1`
- `0 <= val <= 2^32 - 1`
- `0 <= pos <= 31`
- `1 <= width <= 32`
- `pos + width <= 32`

### 函数说明

```c
uint32_t set_bit_field(uint32_t reg, int pos, int width, uint32_t val);
```

- `reg`：寄存器原值
- `pos`：位域的起始位（最低位）位号
- `width`：位域宽度
- `val`：要写入的值（只使用低 `width` 位）
- 返回值：写入后的寄存器值

### 自定义输入格式

```
180
2
3
2
```

依次为 `reg`、`pos`、`width`、`val`，每行一个十进制整数。输出为写入后的寄存器值（十进制）。
