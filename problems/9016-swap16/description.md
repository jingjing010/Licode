在嵌入式开发中，不同设备的**字节序**（Endianness）可能不同：STM32 等 ARM Cortex-M 单片机是**小端**（低字节在低地址），而很多网络协议（TCP/IP 头部）和传感器芯片（例如通过 I2C 读出的温湿度寄存器）使用**大端**（高字节在前）。在两者之间传递 16 位数据时，就需要交换高低字节。

请实现函数 `swap16`：给定一个 16 位无符号整数 `x`，返回把它的**高字节和低字节对调**后的结果。

例如 `x = 0x1234`，高字节是 `0x12`、低字节是 `0x34`，交换后得到 `0x3412`。

### 示例 1

```
输入：x = 4660
输出：13330
解释：4660 = 0x1234，交换高低字节得到 0x3412 = 13330。
```

### 示例 2

```
输入：x = 255
输出：65280
解释：255 = 0x00FF，交换后得到 0xFF00 = 65280。
```

### 示例 3

```
输入：x = 0
输出：0
```

### 提示

- `0 <= x <= 65535`（即 `0x0000 ~ 0xFFFF`）
- 不允许调用编译器内置函数（如 `__builtin_bswap16`），请用位运算实现

### 函数说明

```c
uint16_t swap16(uint16_t x);
```

- `x`：待转换的 16 位无符号整数
- 返回值：高低字节交换后的 16 位无符号整数

### 自定义输入格式

```
4660
```

只有 1 行：十进制整数 `x`。输出也是十进制整数。
