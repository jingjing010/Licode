# 整理字符串

反复删除相邻的同一字母不同大小写字符，直到无法删除。输入仅英文字母，返回唯一最终结果。长度1到100。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* makeGood(char* s);
```

## 示例 1

输入：
```text
"leEeetcode"
```
输出：
```text
"leetcode"
```

## 示例 2

输入：
```text
"abBAcC"
```
输出：
```text
""
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
