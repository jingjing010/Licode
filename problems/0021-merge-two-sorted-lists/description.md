将两个升序链表合并为一个新的 **升序** 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

### 示例 1

```
1 -> 2 -> 4
1 -> 3 -> 4
  合并后
1 -> 1 -> 2 -> 3 -> 4 -> 4
```

```
输入：list1 = [1,2,4], list2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

### 示例 2

```
输入：list1 = [], list2 = []
输出：[]
```

### 示例 3

```
输入：list1 = [], list2 = [0]
输出：[0]
```

### 提示

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `list1` 和 `list2` 均按 **非递减顺序** 排列

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* mergeTwoLists(struct ListNode* list1, struct ListNode* list2);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `list1`、`list2`：两个链表的头指针，空链表用 `NULL` 表示
- 返回值：合并后新链表的头指针（可以直接复用原来的结点，不需要 `malloc` 新结点）

### 自定义输入格式

```
[1,2,4]
[1,3,4]
```

第 1 行是链表 `list1`，第 2 行是链表 `list2`，空链表写作 `[]`。输出为合并后的链表。
