很多设备都支持通过串口发送文本命令来调参，例如 `SET_SPEED -1500`、`AT+BAUD=115200`。命令解析器把命令名切掉之后，剩下的参数还是一个字符串，需要转换成整数。标准库的 `atoi` 遇到溢出时行为未定义，而且有些精简的嵌入式 C 库为了省 Flash 根本不提供它，所以固件里通常会自己实现一个**行为明确**的版本。

请实现函数 `my_atoi`，按以下规则把字符串 `s` 转换成 32 位有符号整数：

1. 跳过开头的所有**空格** `' '`
2. 接下来如果是 `'+'` 或 `'-'`，记录符号（最多一个符号字符）
3. 连续读取数字字符 `'0'~'9'`，遇到第一个非数字字符（或字符串结束）就停止，后面的内容全部忽略
4. 如果一个数字都没读到，返回 `0`
5. 如果结果超出 `int32_t` 范围，**饱和**到边界：大于 `2147483647` 返回 `2147483647`，小于 `-2147483648` 返回 `-2147483648`

### 示例 1

```
输入：s = "42"
输出：42
```

### 示例 2

```
输入：s = "   -1500rpm"
输出：-1500
解释：跳过 3 个空格，读到 '-'，再读到数字 1500，遇到 'r' 停止。
```

### 示例 3

```
输入：s = "99999999999"
输出：2147483647
解释：超出 int32_t 范围，饱和到最大值。
```

### 提示

- `0 <= strlen(s) <= 200`
- `s` 只包含可打印 ASCII 字符（不含双引号和反斜杠）
- 不要使用 `atoi`、`strtol`、`sscanf` 等库函数

### 函数说明

```c
int32_t my_atoi(const char* s);
```

- `s`：以 `'\0'` 结尾的输入字符串
- 返回值：转换结果（按上述规则饱和）

### 自定义输入格式

```
"   -1500rpm"
```

只有 1 行：带双引号的字符串 `s`。输出为一个整数。
