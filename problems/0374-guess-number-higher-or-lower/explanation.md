# 374. 猜数字大小 —— 小白详细题解

> 小时候玩过"我心里想一个 1~100 的数，你来猜，我告诉你大了还是小了"吗？最聪明的玩法是每次都猜**中间**——这就是二分查找。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 系统心里想了一个 `1 ~ n` 之间的数 `pick`。你每次调用 `guess(num)` 猜一个数，它回答：猜大了（`-1`）、猜小了（`1`）、猜中了（`0`）。请找出 `pick`。

⚠️ 返回值的含义很容易搞反，一定要看清楚：

| guess(num) 返回 | 含义 | 下一步该往哪猜？ |
|---|---|---|
| `-1` | `num > pick`，**你猜大了** | 往**小**的猜 |
| `1` | `num < pick`，**你猜小了** | 往**大**的猜 |
| `0` | `num == pick`，猜中了 | 返回 num |

拿示例 1 `n = 10, pick = 6` 来说：先猜 5 → 返回 1（猜小了）→ 再猜 8 → 返回 -1（猜大了）→ 猜 6 → 返回 0，答案 6。

**几个需要注意的细节：**

1. 数字范围从 **1** 开始，到 `n` 结束（包含 n）。
2. `n` 最大是 `2^31 - 1`，就是 `int` 的最大值，计算中点时会溢出。
3. 你拿不到 `pick`，只能通过 `guess` 去问；本 OJ 限制调用次数（n 最大时 64 次）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 模板里那段注释是什么？

```c
/**
 * Forward declaration of guess API.
 * int guess(int num);
 */
```

这是在告诉你：`guess` 函数**系统已经实现好了**，你直接调用就行，不要自己再定义一个同名函数（会编译报错"重复定义"）。

### 2. 保存函数返回值，避免重复调用

```c
int r = guess(mid);      // 只调用一次，把结果存起来
if (r == 0) return mid;
if (r < 0) hi = mid - 1;
```

如果写成 `if (guess(mid) == 0) ... else if (guess(mid) < 0) ...`，每轮会调用 2~3 次，白白浪费调用次数。

### 3. 中点防溢出

`lo + hi` 最大可以到 `2 × (2^31 - 1)`，超过 `int` 范围。用 `mid = lo + (hi - lo) / 2`：`hi - lo` 一定在 int 范围内，结果也一定在 `[lo, hi]` 中。

---

## 💡 第三步：思路一 —— 从 1 开始挨个猜（会超出调用次数）

### 思路

从 1 开始猜，猜到返回 0 为止。

### 代码

```c
// ❌ 思路正确，但 n = 2^31-1 时可能要猜 21 亿次，超出本题调用上限
int guessNumber(int n) {
    for (int num = 1; num < n; num++) {
        if (guess(num) == 0) {
            return num;          // 猜中了
        }
    }
    return n;                    // 前面都不是，那就是 n
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 二分查找（标准答案）

### 思路

每次猜**区间正中间**的数 `mid`：

- 猜中（`0`）：直接返回。
- 猜大了（`-1`）：`pick < mid`，`mid` 和它右边全都不可能，`hi = mid - 1`。
- 猜小了（`1`）：`pick > mid`，`mid` 和它左边全都不可能，`lo = mid + 1`。

### 区间定义与循环条件

- 区间：**闭区间 `[lo, hi]`**，表示"pick 还可能是这些数"。初始 `lo = 1, hi = n`。
- 循环条件：`while (lo <= hi)`。闭区间里 `lo == hi` 时还有 1 个数没猜，所以要用 `<=`。
- 更新：因为 mid 已经确认**不是**答案，所以两边都可以 `±1` 把 mid 排除掉。这和"找第一个满足条件"的模板（`hi = mid`）不一样，因为这里能直接判断"猜中"。

### 手动模拟（`n = 10, pick = 6`）

| 轮次 | lo | hi | mid | guess(mid) | 操作 |
|---|---|---|---|---|---|
| 1 | 1 | 10 | 5 | 1（猜小了） | lo = 6 |
| 2 | 6 | 10 | 8 | -1（猜大了） | hi = 7 |
| 3 | 6 | 7 | 6 | 0 | 返回 6 ✅ |

### 代码

```c
/**
 * Forward declaration of guess API.
 * int guess(int num);
 */

int guessNumber(int n) {
    int lo = 1;                  // 闭区间 [lo, hi]：pick 可能的范围
    int hi = n;

    while (lo <= hi) {           // 区间里还有数没排除
        int mid = lo + (hi - lo) / 2;   // 防溢出写法
        int r = guess(mid);      // 只问一次，存下结果
        if (r == 0) {
            return mid;          // 猜中了
        } else if (r < 0) {
            hi = mid - 1;        // 猜大了，往小的猜
        } else {
            lo = mid + 1;        // 猜小了，往大的猜
        }
    }
    return -1;                   // 题目保证有答案，不会走到这里
}
```

### 复杂度分析

- **时间复杂度 O(log n)**：`n = 2^31-1` 时最多猜 31 次。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **把 `-1` 和 `1` 的含义搞反** → `-1` 是"你猜的数**大了**"，应该 `hi = mid - 1`。搞反会越猜越远，最后调用次数超限。
2. **`mid = (lo + hi) / 2`** → `n = 2147483647`、pick 很大时，`lo + hi` 溢出成负数，`guess` 收到负数（本 OJ 会报"参数越界"）。
3. **`while (lo < hi)` 搭配 `±1` 更新** → 当区间只剩一个数时直接退出循环，没去猜它。比如 `n = 1`，一次都没猜就返回了 -1。
4. **同一轮调用多次 `guess(mid)`** → 调用次数翻倍，n 大时超过上限。
5. **`lo` 从 0 开始** → `guess(0)` 不在 `[1, n]` 范围内。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 调用次数（n = 2^31-1） | 难度 | 建议 |
|---|---|---|---|---|
| 从 1 挨个猜 | O(n) | 最多约 21 亿次 | ⭐ | 只用来理解题意 |
| 二分查找 | O(log n) | 最多 31 次 | ⭐⭐ | 标准答案 |

> 🎯 **学习建议**：本题是"找**某个确定值**"的二分（猜中就返回，用 `lo <= hi` + `±1`）；278 题是"找**边界**"的二分（用 `lo < hi` + `hi = mid`）。把两题对照着看，记住两套模板的区别。
