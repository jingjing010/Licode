给定一个已排序的链表的头 `head` ， *删除原始链表中所有重复数字的节点，只留下不同的数字* 。返回 *已排序的链表* 。

### 示例 1

```
1 -> 2 -> 3 -> 3 -> 4 -> 4 -> 5
  删除所有重复出现的数字后
1 -> 2 -> 5
```

```
输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]
```

### 示例 2

```
1 -> 1 -> 1 -> 2 -> 3
  删除所有重复出现的数字后
2 -> 3
```

```
输入：head = [1,1,1,2,3]
输出：[2,3]
```

### 提示

- 链表中节点数目在范围 `[0, 300]` 内
- `-100 <= Node.val <= 100`
- 题目数据保证链表已经按升序 **排列**

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* deleteDuplicates(struct ListNode* head);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `head`：升序链表的头指针，空链表用 `NULL` 表示
- 返回值：删除后链表的头指针（头结点也可能被删除；如果全部删光，返回 `NULL`）

### 自定义输入格式

```
[1,2,3,3,4,4,5]
```

只有 1 行，是升序链表 `head`，空链表写作 `[]`。输出为删除后的链表。
