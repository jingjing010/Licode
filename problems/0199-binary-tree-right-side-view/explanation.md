# 199. 二叉树的右视图 —— 小白详细题解

> 这道题是层序遍历的直接应用：每一层只要**最右边**那一个。但要小心，"最右边"不一定在右子树里！

---

## 📖 第一步：先读懂题目

想象你站在树的**右边**往左看，每一层只能看到**最靠右的那个结点**（后面的被挡住了）。从上到下把看到的值记下来。

示例 2 `[1,2,3,4,null,null,null,5]`：

```
      1      <--- 第 0 层看到 1
     / \
    2   3    <--- 第 1 层看到 3
   /
  4          <--- 第 2 层只有 4，看到 4
 /
5            <--- 第 3 层只有 5，看到 5
```

| 层 | 这一层的结点（从左到右） | 看到的 |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 2, 3 | 3 |
| 2 | 4 | 4 |
| 3 | 5 | 5 |

答案 `[1,3,4,5]`。

**几个需要注意的细节：**

1. **不是**"一直往右孩子走"！示例 2 中，第 2、3 层的结点都在**左**子树里，但右边没有东西挡着，所以能看到。
2. 答案长度 = 树的层数。
3. 空树返回空数组。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用数组模拟队列

```c
struct TreeNode* queue[100];   // 结点最多 100 个
int head = 0, tail = 0;
queue[tail++] = root;          // 入队
struct TreeNode* x = queue[head++];   // 出队
```

### 2. 返回数组 + `*returnSize`

和第 1 题一样：结果数组用 `malloc` 申请，长度写进 `*returnSize`。

## 💡 第三步：思路一 —— 层序遍历，取每层最后一个

### 思路

1. 用队列做层序遍历（第 102 题的模板）。
2. 每层开始时记下 `size`；出队第 `size` 个（下标 `size - 1`）结点时，它就是这一层最右边的，记进答案。

### 手动模拟（示例 1：`[1,2,3,null,5,null,4]`）

| 层 | 队列（本层） | 最后一个 | 答案 |
|---|---|---|---|
| 0 | [1] | 1 | [1] |
| 1 | [2, 3] | 3 | [1,3] |
| 2 | [5, 4] | 4 | [1,3,4] |

### 代码

```c
int* rightSideView(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 100);   // 最多 100 层
    int cnt = 0;

    struct TreeNode* queue[100];                  // 最多 100 个结点
    int head = 0, tail = 0;
    if (root != NULL) queue[tail++] = root;       // 空树就不入队，循环直接结束

    while (head < tail) {
        int size = tail - head;                   // 这一层有几个结点
        for (int i = 0; i < size; i++) {
            struct TreeNode* node = queue[head++];
            if (i == size - 1) res[cnt++] = node->val;      // 本层最后一个 = 最右边
            if (node->left)  queue[tail++] = node->left;    // 先左后右入队
            if (node->right) queue[tail++] = node->right;
        }
    }

    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点入队出队一次。
- **空间复杂度 O(n)**：队列。

---

## 🚀 第四步：思路二 —— DFS，先右后左

### 思路

换一种访问顺序：**根 → 右 → 左**。这样在每一层里，**最先**被访问到的结点一定是最右边的那个。

所以递归时带上层号 `depth`：

- 如果 `depth == 答案当前长度`，说明这是**第一次**来到这一层 → 它就是这一层最右边的结点，加入答案。
- 否则这一层已经有答案了，不用管。

### 手动模拟（示例 2）

| 访问顺序 | 结点 | depth | 答案长度 | 操作 | 答案 |
|---|---|---|---|---|---|
| 1 | 1 | 0 | 0 | 第一次到第 0 层，加入 | [1] |
| 2 | 3 | 1 | 1 | 第一次到第 1 层，加入 | [1,3] |
| 3 | 2 | 1 | 2 | 第 1 层已有，跳过 | [1,3] |
| 4 | 4 | 2 | 2 | 第一次到第 2 层，加入 | [1,3,4] |
| 5 | 5 | 3 | 3 | 第一次到第 3 层，加入 | [1,3,4,5] |

### 代码

```c
void dfs(struct TreeNode* node, int depth, int* res, int* cnt) {
    if (node == NULL) return;
    if (depth == *cnt) {                 // 第一次到达这一层
        res[(*cnt)++] = node->val;       // 先右后左，所以它就是最右边的
    }
    dfs(node->right, depth + 1, res, cnt);   // 先右
    dfs(node->left, depth + 1, res, cnt);    // 再左
}

int* rightSideView(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 100);
    int cnt = 0;
    dfs(root, 0, res, &cnt);
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(h)**（递归栈）。

---

## ⚠️ 第五步：小白常见错误

1. **一直沿着右孩子往下走**：
   ```c
   while (root) { res[cnt++] = root->val; root = root->right; }   // ❌
   ```
   示例 2 会得到 `[1,3]`，漏掉了左子树里更深的 4 和 5。
2. **DFS 里先左后右**：那么每层第一次到达的是**最左边**的结点，得到的是"左视图"。
3. **层序遍历时取 `i == 0`**：取的是每层第一个（最左边）。
4. **`size` 没有提前保存**：循环里用 `tail - head` 做上界，层与层就混在一起了。
5. **空树时把 `NULL` 入队**：之后访问 `node->val` 崩溃。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 层序遍历取每层最后一个 | O(n) | O(n) | ⭐⭐ | 最直观 |
| DFS 先右后左 | O(n) | O(h) | ⭐⭐ | 代码短，思路巧 |
