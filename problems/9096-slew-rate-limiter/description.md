# 控制量变化率限制

初始输出0，每个采样向目标靠近至多step，不能越过目标。targets为int16范围，step0..32767，最多1000项。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* slewLimit(int* targets,int targetsSize,int step,int* returnSize);
```

## 示例 1

输入：
```text
[100,100,-100,-100]
30
```
输出：
```text
[30,60,30,0]
```

## 示例 2

输入：
```text
[1,2,3]
0
```
输出：
```text
[0,0,0]
```

## 自定义输入格式

按顺序每行一个参数：targets、step。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
