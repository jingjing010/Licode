# DMA 传输分块长度

把length字节顺序切成尽量大的非空块，每块≤maximum。length0..10^6，maximum1..65535，返回各块长度。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* dmaChunks(int length,int maximum,int* returnSize);
```

## 示例 1

输入：
```text
1000
256
```
输出：
```text
[256,256,256,232]
```

## 示例 2

输入：
```text
512
256
```
输出：
```text
[256,256]
```

## 自定义输入格式

按顺序每行一个参数：length、maximum。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
