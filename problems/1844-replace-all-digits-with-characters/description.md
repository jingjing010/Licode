# 将所有数字用字符替换

字符串偶数下标是小写字母，奇数下标是数字，将数字替换为前一个字母向后偏移该数字的字母。保证不超过z。长度1到100。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* replaceDigits(char* s);
```

## 示例 1

输入：
```text
"a1c1e1"
```
输出：
```text
"abcdef"
```

## 示例 2

输入：
```text
"a1b2c3d4e"
```
输出：
```text
"abbdcfdhe"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
