# 磨损均衡槽位选择

输入每个可用槽位的擦除次数，返回最少磨损槽位下标；相同次数取最左。长度1到1000，次数0到10^9。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int chooseWearSlot(int* counts,int countsSize);
```

## 示例 1

输入：
```text
[10,3,5]
```
输出：
```text
1
```

## 示例 2

输入：
```text
[2,2,2]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：counts。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
