给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。

### 示例 1

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2
```

### 示例 2

```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```

### 提示

- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`

### 函数说明

```c
double findMedianSortedArrays(int* nums1, int nums1Size, int* nums2, int nums2Size);
```

- `nums1`、`nums2`：两个升序数组的首地址（可能有一个为空，长度为 0）
- `nums1Size`、`nums2Size`：两个数组的长度
- 返回值：中位数，类型为 `double`

### 自定义输入格式

```
[1,3]
[2]
```

第 1 行是 `nums1`，第 2 行是 `nums2`（空数组写作 `[]`）。判题时把你返回的 `double` **保留 5 位小数**输出（如 `2.50000`）。
