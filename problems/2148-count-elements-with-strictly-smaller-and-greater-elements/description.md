# 元素计数

统计数组中同时存在严格更小值和严格更大值的元素个数。1 ≤ n ≤ 100，元素−10^5到10^5。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int countElements(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[11,7,2,15]
```
输出：
```text
2
```

## 示例 2

输入：
```text
[-3,3,3,90]
```
输出：
```text
2
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
