# 476. 数字的补数 —— 小白详细题解

> "把二进制每一位都取反"听起来就是 `~num`，但直接用 `~` 是错的！这道题的关键是：**只翻转有效位**，也就是从最高位的 1 到第 0 位这一段。做法是先造一个"这一段全是 1"的掩码，再用异或翻转。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把 `num` 写成**没有前导 0** 的二进制，每一位 0 变 1、1 变 0，再转回十进制。

| num | 二进制（无前导 0） | 取反 | 结果 |
|---|---|---|---|
| 5 | 101 | 010 | 2 |
| 1 | 1 | 0 | 0 |
| 10 | 1010 | 0101 | 5 |

**几个需要注意的细节：**

1. **前导 0 不翻转**：`5` 在 32 位里是 `0000……0101`，如果把前面 29 个 0 也翻成 1，就会得到一个负数。
2. `num` 最小是 1，最大是 `2^31 - 1`（31 个 1，补数是 0）。
3. 造掩码时如果写 `(1 << 31) - 1`，`1 << 31` 对 `int` 是溢出的，要小心。

---

## 🧰 第二步：需要的 C 语言知识

### 1. 为什么 `~num` 不行？

`~` 会把 **32 位全部取反**：

```
 num = 0000 0000 0000 0000 0000 0000 0000 0101   (5)
~num = 1111 1111 1111 1111 1111 1111 1111 1010   (-6)
```

我们只想要最后 3 位 `010`，前面那 29 个 1 是多余的。

### 2. 用异或翻转指定的位

`x ^ 1 = ~x`（对一位而言），`x ^ 0 = x`。所以：

> `num ^ mask`：`mask` 里是 1 的位被翻转，是 0 的位保持不变。

只要造出一个 `mask`，让它**有效位那一段全是 1、前面全是 0**，`num ^ mask` 就是答案。

```
num        = 101
mask       = 111
num ^ mask = 010   ✔
```

### 3. 等价写法：`~num & mask`

先全部取反，再用 `mask` 把前面多余的 1 清零，效果一样。

---

## 💡 第三步：思路一 —— 逐步扩大掩码

### 思路

`mask` 从 1 开始，每次左移一位并在最低位补 1：`1 → 11 → 111 → ……`，直到 `mask >= num`。此时 `mask` 的位数正好和 `num` 一样。

为了防止 `mask << 1` 溢出，用 `unsigned int`。`num` 最大是 `2^31 - 1`（31 个 1），`mask` 最多也只会到 31 个 1，不会越界。

### 手动模拟（`num = 10 = 1010`）

| 第几次 | mask | mask >= num ? |
|---|---|---|
| 初始 | 1 | 否 |
| 1 | 11 | 否 |
| 2 | 111 | 否 |
| 3 | 1111 = 15 | **是**，停 |

`1010 ^ 1111 = 0101 = 5`。

### 代码

```c
int findComplement(int num) {
    unsigned int mask = 1;
    // 不断把 mask 变成 1、11、111……，直到位数和 num 一样
    while (mask < (unsigned int)num) {
        mask = (mask << 1) | 1u;
    }
    return (int)((unsigned int)num ^ mask);   // 有效位全部翻转
}
```

### 复杂度分析

- **时间复杂度 O(log num)**：最多 31 次循环。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 位扩散（无循环）

### 思路

能不能一次性把"最高位的 1 右边所有位"都变成 1？可以，用"位扩散"：

```c
m |= m >> 1;    // 最高位 1 右边 1 位也变成 1   →  最高的 2 位是 1
m |= m >> 2;    // 再往右扩散 2 位             →  最高的 4 位是 1
m |= m >> 4;    //                             →  最高的 8 位是 1
m |= m >> 8;    //                             →  最高的 16 位是 1
m |= m >> 16;   //                             →  最高的 32 位是 1（不够的就到第 0 位为止）
```

每一步都把已有的连续 1 "复制"到右边，长度翻倍。5 步之后，从最高位的 1 到第 0 位全是 1——这正是我们要的 `mask`。

### 手动模拟（`num = 0100 0000`，只看 8 位）

| 步骤 | m |
|---|---|
| 初始 | 0100 0000 |
| 右移 1 位再按位或 | 0110 0000 |
| 右移 2 位再按位或 | 0111 1000 |
| 右移 4 位再按位或 | 0111 1111 |
| 后面两步 | 0111 1111（不变） |

`~num & m = 1011 1111 & 0111 1111 = 0011 1111`。

### 代码

```c
int findComplement(int num) {
    unsigned int m = (unsigned int)num;
    // 把最高位的 1 向右"扩散"，得到从最高位到第 0 位全是 1 的掩码
    m |= m >> 1;
    m |= m >> 2;
    m |= m >> 4;
    m |= m >> 8;
    m |= m >> 16;
    // 全部取反后，用掩码去掉前导位上多出来的 1
    return (int)(~(unsigned int)num & m);
}
```

### 复杂度分析

- **时间复杂度 O(1)**：固定 10 次位运算。
- **空间复杂度 O(1)**。

> 💬 这个"位扩散"技巧还可以用来求"不小于 n 的最小的 2 的幂"：先 `n - 1`，扩散，再 `+ 1`。

---

## ⚠️ 第五步：小白常见错误

1. **直接返回 `~num`**：前导 0 也被翻成了 1，`num = 5` 时返回 `-6`。
2. **用 `int` 造掩码导致溢出**：比如 `int mask = 1; while (mask <= num) mask <<= 1; return num ^ (mask - 1);`，当 `num >= 2^30` 时 `mask` 会左移到 `2^31`，溢出成负数，`mask <= num` 一直成立，再左移变成 0 后永远停不下来，**死循环**。用 `unsigned int` 并且条件写 `mask < num`。
3. **循环条件写成 `mask <= num`**：`num = 3 = 11` 时，`mask = 11` 已经够了，`<=` 会让它再扩一位变成 `111`，结果 `3 ^ 7 = 4`，错。
4. **位扩散只做到 `>> 8`**：最高位在第 16 位以上时，低位扩散不到，掩码不完整。必须做满 1、2、4、8、16 五步。
5. **把 `^` 当成"次方"**：`2 ^ 3` 在 C 里是异或，等于 1，不是 8。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐步扩大掩码 | O(log num) | O(1) | ⭐ | 最直观 |
| 位扩散 | O(1) | O(1) | ⭐⭐ | 无循环，这个技巧以后经常用得到 |
