嵌入式里经常要判断两段内存是否相同：校验收到的帧头是不是 `0xAA 0x55`、比较 Flash 里存的配置和 RAM 里的是否一致、核对 OTA 升级包的签名……这些都离不开 `memcmp`。

请你实现 `my_memcmp(s1, s2, n)`，按字节比较两段内存的前 `n` 个字节：

- 找到第一个不同的字节，把两个字节都当成 **`unsigned char`**（0 ~ 255）比较：`s1` 的字节较小返回**负数**，较大返回**正数**
- 前 `n` 个字节全部相同（包括 `n = 0`）返回 `0`

> **不要调用库函数 `memcmp`**，请自己用指针完成。

判题程序调用 `my_memcmp(a, b, n)`，把返回值规范化后输出：负数输出 `-1`，零输出 `0`，正数输出 `1`。

### 示例 1

```
输入：a = [1,2,3], b = [1,2,4], n = 3
输出：-1
解释：前两个字节相同，第 3 个字节 3 < 4。
```

### 示例 2

```
输入：a = [1,2,3], b = [1,2,4], n = 2
输出：0
解释：只比较前 2 个字节，它们相同。
```

### 示例 3

```
输入：a = [200,0], b = [100,0], n = 2
输出：1
解释：200 > 100。注意必须按无符号比较，如果当成有符号 char，200 会变成 -56。
```

### 提示

- `1 <= a.length, b.length <= 10^5`
- `0 <= a[i], b[i] <= 255`
- `0 <= n <= min(a.length, b.length)`

### 函数说明

```c
int my_memcmp(const void* s1, const void* s2, size_t n);
```

- `s1`、`s2`：要比较的两段内存
- `n`：比较的字节数
- 返回值：负数 / 0 / 正数（具体数值任意，只看正负）

### 自定义输入格式

```
[1,2,3]
[1,2,4]
3
```

第 1 行是 `a`，第 2 行是 `b`，第 3 行是 `n`。输出为 `-1`、`0` 或 `1`。
