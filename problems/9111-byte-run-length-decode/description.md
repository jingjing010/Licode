# 字节游程长度解压

输入合法[次数,值]编码，次数1..255，输入偶数长度且解码后≤1024字节。返回解压后的字节数组，空输入输出空数组。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* runLengthDecode(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[1,49,1,50,1,51,1,52,1,53,1,54,1,55,1,56,1,57]
```
输出：
```text
[49,50,51,52,53,54,55,56,57]
```

## 示例 2

输入：
```text
[]
```
输出：
```text
[]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
