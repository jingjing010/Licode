# 29. 两数相除 —— 小白详细题解

> 不许用 `*`、`/`、`%`，怎么做除法？答案是回到小学的"竖式除法"：除法本质上就是**反复做减法**，而二进制下的竖式除法每一步只需要"移位 + 比较 + 减法"。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 算 `dividend / divisor`，小数部分直接扔掉（向 0 取整），但是**不能用乘、除、取余**。如果结果装不进 `int`，就返回 `INT_MAX`。

| 输入 | 真实结果 | 向零截断 | 输出 |
|---|---|---|---|
| 10 / 3 | 3.333… | 3 | `3` |
| 7 / -3 | -2.333… | -2 | `-2` |
| -2147483648 / -1 | 2147483648 | 超过 `INT_MAX` | `2147483647` |

**几个需要注意的细节：**

1. **向零截断**：`-7 / 3 = -2.33`，答案是 `-2`，不是 `-3`（不是向下取整）。
2. **唯一会溢出的情况**：`-2^31 / -1 = 2^31`，比 `INT_MAX = 2^31 - 1` 大 1，要返回 `INT_MAX`。其它任何组合的商的绝对值都不会超过 `2^31`。
3. **`-2^31` 的绝对值装不进 `int`**：`int` 的范围是 `-2147483648 ~ 2147483647`，`-(-2147483648)` 会溢出。这是本题最大的坑。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 左移就是乘 2，右移就是除以 2

```
5      = 0000 0101
5 << 1 = 0000 1010 = 10     (×2)
5 << 3 = 0010 1000 = 40     (×8 = ×2³)
40 >> 3 = 0000 0101 = 5     (÷8，无符号数时向下取整)
```

题目禁止 `*` 和 `/`，但**没有禁止移位**，移位就是我们的"乘 2 / 除 2"。

### 2. 用 `unsigned int` 存绝对值

`unsigned int` 的范围是 `0 ~ 4294967295`，装得下 `2^31 = 2147483648`。

```c
unsigned int a = dividend < 0 ? 0u - (unsigned int)dividend : (unsigned int)dividend;
```

- `(unsigned int)dividend`：负数转成无符号数，C 标准规定结果是 `dividend + 2^32`；
- `0u - 它`：无符号减法按 `2^32` 取模，正好得到 `-dividend`，也就是绝对值。
- 对 `-2147483648` 这样做，得到 `2147483648`，**不会溢出**。

### 3. 符号单独处理

商的符号只取决于两个数是否**异号**：`bool neg = (dividend < 0) != (divisor < 0);`。先用绝对值算出商，最后再根据 `neg` 加上负号。

---

## 💡 第三步：思路一 —— 倍增减法

### 先看最笨的方法（会超时）

```c
// ❌ 一个一个地减：-2147483648 / 1 需要减 21 亿次，超时
while (a >= b) {
    a -= b;
    q++;
}
```

### 思路

慢在每次只减 1 个 `b`。我们可以**每次尽量多减**：

1. 从 `t = b, m = 1` 开始，只要 `t` 翻倍后还不超过 `a`，就让 `t` 翻倍、`m` 翻倍。此时 `t = b × m`；
2. 从 `a` 里一次减掉 `t`，商加上 `m`；
3. 重复，直到 `a < b`。

判断"翻倍后不超过 a"时，不要写 `(t << 1) <= a`（`t << 1` 可能溢出），而是写成等价的 `t <= (a >> 1)`。

### 手动模拟（示例 1：`a = 10, b = 3`）

| 轮次 | a | 翻倍过程 (t, m) | 减掉 t | 商 q |
|---|---|---|---|---|
| 1 | 10 | (3,1) → (6,2)；12 > 10 停 | 10 - 6 = 4 | 2 |
| 2 | 4 | (3,1)；6 > 4 停 | 4 - 3 = 1 | 3 |
| 3 | 1 | 1 < 3，结束 | | **3** |

### 代码

```c
int divide(int dividend, int divisor) {
    // 唯一会溢出的情况：-2^31 / -1 = 2^31 > INT_MAX
    if (dividend == INT_MIN && divisor == -1) return INT_MAX;

    // 商是否为负：两数异号
    bool neg = (dividend < 0) != (divisor < 0);

    // 用 unsigned int 存绝对值，-2^31 的绝对值 2^31 也装得下
    unsigned int a = dividend < 0 ? 0u - (unsigned int)dividend : (unsigned int)dividend;
    unsigned int b = divisor < 0 ? 0u - (unsigned int)divisor : (unsigned int)divisor;

    unsigned int q = 0;
    while (a >= b) {
        unsigned int t = b;   // 这一轮要减掉的数：b × m
        unsigned int m = 1;   // 这一轮商要加上的数
        // t 翻倍后不超过 a 就继续翻倍；写成 t <= a/2 防止 t << 1 溢出
        while (t <= (a >> 1)) {
            t <<= 1;
            m <<= 1;
        }
        a -= t;               // 一次减掉 b × m
        q += m;
    }

    // 加上符号。q 最大是 2^31（-2^31 / 1），取负后正好是 INT_MIN
    return neg ? (int)(0u - q) : (int)q;
}
```

### 复杂度分析

- **时间复杂度 O(log² C)**（C = 2^31）：每一轮至少减掉 a 的一半，最多 32 轮；每轮翻倍最多 32 次。约 1000 次运算。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 二进制竖式除法（逐位试商）

### 思路

思路一里，每一轮都要重新从 `b` 开始翻倍，有点浪费。其实商的二进制就是逐位确定的，就像十进制竖式除法从最高位开始试商：

> 商的第 `i` 位能不能是 1？只要看 `a` 里还能不能减掉 `b × 2^i`，即 `b << i <= a`。

从 `i = 31` 往下试到 `i = 0`，能减就减，并把商的第 `i` 位置 1。

同样为了防止 `b << i` 溢出，把 `(b << i) <= a` 改写成等价的 `b <= (a >> i)`。

### 手动模拟（示例 1：`a = 10 = 1010₂, b = 3`）

| i | a >> i | ≥ 3 ? | 操作 | a | q（二进制） |
|---|---|---|---|---|---|
| 31 ~ 2 | 0 ~ 2 | 否 | | 10 | 0 |
| 1 | 5 | 是 | a -= 3 << 1 = 6 | 4 | 10 |
| 0 | 4 | 是 | a -= 3 | 1 | 11 = **3** |

### 代码

```c
int divide(int dividend, int divisor) {
    if (dividend == INT_MIN && divisor == -1) return INT_MAX;   // 唯一溢出的情况

    bool neg = (dividend < 0) != (divisor < 0);
    unsigned int a = dividend < 0 ? 0u - (unsigned int)dividend : (unsigned int)dividend;
    unsigned int b = divisor < 0 ? 0u - (unsigned int)divisor : (unsigned int)divisor;

    unsigned int q = 0;
    // 从高位到低位逐位试商
    for (int i = 31; i >= 0; i--) {
        // 等价于 (b << i) <= a，但不会溢出
        if ((a >> i) >= b) {
            a -= b << i;      // 这里 b << i <= a，不会溢出
            q |= 1u << i;     // 商的第 i 位是 1
        }
    }
    return neg ? (int)(0u - q) : (int)q;
}
```

### 复杂度分析

- **时间复杂度 O(log C)**：固定循环 32 次。
- **空间复杂度 O(1)**。

> 💬 CPU 里没有硬件除法器时（比如很多 8 位单片机、Cortex-M0），编译器调用的软件除法函数就是这种"移位—比较—相减"的写法。

---

## ⚠️ 第五步：小白常见错误

1. **直接取绝对值 `abs(dividend)`**：`abs(INT_MIN)` 溢出，结果还是负数，后面的循环全乱。要转成 `unsigned int` 或 `long long` 再取绝对值。
2. **忘了特判 `INT_MIN / -1`**：答案 `2^31` 转回 `int` 会变成 `-2147483648`，而题目要求返回 `2147483647`。
3. **翻倍时写 `(t << 1) <= a`**：当 `t >= 2^31` 时 `t << 1` 溢出变成很小的数，条件永远成立，死循环。写成 `t <= (a >> 1)`。
4. **对 `int` 负数做左移**：`(-3) << 2` 在 C 标准里是未定义行为。所有移位都在 `unsigned int` 上做。
5. **符号写成 `dividend * divisor < 0`**：既用了乘法违反题意，又可能溢出。用 `(dividend < 0) != (divisor < 0)`。
6. **向下取整而不是向零截断**：Python 的 `//` 是向下取整（`-7 // 3 = -3`），本题要的是 `-2`。先算绝对值再加符号，自然就是向零截断。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐个减（❌） | O(商) ≈ 2^31 | O(1) | ⭐ | 会超时，只用来理解原理 |
| 倍增减法 | O(log² C) | O(1) | ⭐⭐ | 思路直观，容易想到 |
| 逐位试商 | O(log C) | O(1) | ⭐⭐ | 代码最短，就是二进制竖式除法 |
