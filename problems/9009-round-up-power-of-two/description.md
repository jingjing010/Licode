上一题提到，环形缓冲区、内存池的块大小最好是 **2 的幂**，这样下标回绕只需要一次按位与。但用户往往只知道"我至少需要多少字节"，比如串口一帧最长 `100` 字节，那么驱动就应该自动分配 **不小于 100 的最小的 2 的幂**，即 `128` 字节。同样的计算也出现在 DMA 对齐、FFT 点数选择、哈希表扩容等场景中。

给定一个 32 位无符号整数 `x`，请返回 **大于等于 `x` 的最小的 2 的幂**。如果 `x` 本身就是 2 的幂，返回 `x`。

### 示例 1

```
输入：x = 5
输出：8
解释：比 5 大的 2 的幂有 8、16、32……其中最小的是 8。
```

### 示例 2

```
输入：x = 16
输出：16
解释：16 = 2^4 本身就是 2 的幂。
```

### 示例 3

```
输入：x = 1
输出：1
解释：1 = 2^0。
```

### 提示

- `1 <= x <= 2^31`（保证答案能用 `uint32_t` 表示）

### 函数说明

```c
uint32_t round_up_pow2(uint32_t x);
```

- `x`：需要的最小大小
- 返回值：大于等于 `x` 的最小的 2 的幂

### 自定义输入格式

```
5
```

输入一行，为十进制整数 `x`。输出为结果（十进制）。
