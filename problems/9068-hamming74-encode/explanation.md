# Hamming(7,4) 编码：题解

## 📖 先读懂题目

data为0到15。码字位置从1起、位置1对应最低位；数据从低到高放在3/5/6/7位置，1/2/4为偶校验位。返回0到127的码字。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `0` | `0` |
| 2 | `10` | `82` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

把4个数据位放在非2的幂次位置，位置1、2、4分别检查位置编号二进制中对应位为1的所有位，采用偶校验。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int hamming74Encode(int data) {
    int d0 = data & 1, d1 = (data >> 1) & 1, d2 = (data >> 2) & 1, d3 = (data >> 3) & 1;
    /* 位置1、2、4为偶校验位，位置3、5、6、7保存数据。 */
    return (d0 ^ d1 ^ d3) | ((d0 ^ d2 ^ d3) << 1) | (d0 << 2) | ((d1 ^ d2 ^ d3) << 3) | (d1 << 4) |
           (d2 << 5) | (d3 << 6);
}
```

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
