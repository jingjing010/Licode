网络协议（如 TCP/IP 头部里的 IP 地址、Modbus TCP 中的 32 位寄存器值）规定使用**大端字节序**，而 STM32、ESP32 等常见 MCU 是**小端**。当你从以太网或 4G 模组收到一个 32 位数值时，往往需要先做一次 32 位字节序交换（相当于 `ntohl()`）。

请实现函数 `swap32`：给定一个 32 位无符号整数 `x`，把它的 4 个字节**顺序完全颠倒**后返回。

例如 `x = 0x12345678`，4 个字节从高到低是 `12 34 56 78`，颠倒后是 `78 56 34 12`，即 `0x78563412`。

### 示例 1

```
输入：x = 305419896
输出：2018915346
解释：305419896 = 0x12345678，交换后得到 0x78563412 = 2018915346。
```

### 示例 2

```
输入：x = 4278190080
输出：255
解释：4278190080 = 0xFF000000，交换后得到 0x000000FF = 255。
```

### 示例 3

```
输入：x = 1
输出：16777216
解释：1 = 0x00000001，交换后得到 0x01000000 = 16777216。
```

### 提示

- `0 <= x <= 4294967295`（即 `0x00000000 ~ 0xFFFFFFFF`）
- 不允许调用编译器内置函数（如 `__builtin_bswap32`），请用位运算实现

### 函数说明

```c
uint32_t swap32(uint32_t x);
```

- `x`：待转换的 32 位无符号整数
- 返回值：4 个字节顺序颠倒后的 32 位无符号整数

### 自定义输入格式

```
305419896
```

只有 1 行：十进制整数 `x`。输出也是十进制整数。
