# 旋转字符串：题解

## 📖 先读懂题目

一次操作把s最左字符移到最右，判断能否经过若干次得到goal。只含小写字母，长度1到100。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"abcde" / "cdeab"` | `true` |
| 2 | `"abcde" / "abced"` | `false` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

长度必须相等，旋转后的结果必然是两个原字符串拼接后的子串。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
bool rotateString(char *s, char *goal) {
    int n = (int)strlen(s);
    if (n != (int)strlen(goal))
        return false;
    char *twice = malloc(2 * n + 1);
    memcpy(twice, s, n);
    memcpy(twice + n, s, n + 1);
    /* 任意旋转都在s+s中作为长度n的子串出现。 */
    bool found = strstr(twice, goal) != NULL;
    free(twice);
    return found;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间最坏 O(n²)，空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
