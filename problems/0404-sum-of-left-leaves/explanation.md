# 404. 左叶子之和 —— 小白详细题解

> 这道题的关键是一个视角转换：**一个结点自己不知道自己是"左孩子"还是"右孩子"，要站在它的父亲那里才能判断。**

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 找出所有"**既是叶子、又是某个结点的左孩子**"的结点，把它们的值加起来。

示例 1：`[3,9,20,null,null,15,7]`

```
    3
   / \
  9  20
    /  \
   15   7
```

| 结点 | 是叶子吗 | 是左孩子吗 | 算不算 |
|---|---|---|---|
| 3 | 否 | 是根，不是任何人的孩子 | ❌ |
| 9 | 是 | 是 3 的左孩子 | ✅ |
| 20 | 否 | 右孩子 | ❌ |
| 15 | 是 | 是 20 的左孩子 | ✅ |
| 7 | 是 | 右孩子 | ❌ |

答案 9 + 15 = **24**。

**几个需要注意的细节：**

1. **根结点不算**：示例 2 `[1]` 只有一个结点，它是叶子，但不是任何人的左孩子，答案是 0。
2. 左孩子如果**不是叶子**（下面还挂着结点），它本身不算，但它下面可能还有左叶子，要继续找。
3. 右子树里也可能有左叶子（比如示例 1 的 15），右子树也要遍历。
4. 最多 1000 个结点，值在 ±1000 内，和最多 10⁶，用 `int` 不会溢出。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 判断叶子

```c
node->left == NULL && node->right == NULL
```

### 2. 多层 `->` 要逐层判空

```c
root->left->left   // 如果 root->left 是 NULL，这里直接崩溃
```

所以要写成 `root->left != NULL && root->left->left == NULL && ...`。`&&` 是**短路**的：前面为假，后面就不会执行，所以把判空写在最前面就安全了。

### 3. 递归函数带一个"标记"参数

可以写一个辅助函数 `dfs(node, isLeft)`，由父亲告诉孩子"你是不是左孩子"。

---

## 💡 第三步：思路一 —— 递归（站在父结点上判断）

### 思路

对当前结点 `root`：

1. 空树返回 0。
2. 看它的左孩子 `l`：
   - 如果 `l` 存在且是叶子 → 加上 `l->val`（`l` 下面没东西了，不用再递归）；
   - 否则 → 递归到左子树里找。
3. 右孩子本身一定不是左叶子，但右子树里可能有 → 递归右子树。

### 手动模拟（示例 1）

| 调用 | 左孩子 | 左孩子是叶子？ | 本层加 | 递归右边 | 返回 |
|---|---|---|---|---|---|
| f(3) | 9 | 是 | 9 | f(20) | 9 + 15 = 24 |
| f(20) | 15 | 是 | 15 | f(7) | 15 + 0 = 15 |
| f(7) | 无 | — | 0 | f(NULL)=0 | 0 |

### 代码

```c
int sumOfLeftLeaves(struct TreeNode* root) {
    if (root == NULL) return 0;
    int sum = 0;
    struct TreeNode* l = root->left;
    if (l != NULL && l->left == NULL && l->right == NULL)
        sum += l->val;                       // 左孩子是叶子：它就是一个左叶子
    else
        sum += sumOfLeftLeaves(l);           // 左孩子不是叶子（或为空）：到左子树里继续找
    return sum + sumOfLeftLeaves(root->right);   // 右子树里也可能有左叶子
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点访问一次。
- **空间复杂度 O(h)**：递归栈。

---

## 🚀 第四步：思路二 —— 层序遍历（BFS）

### 思路

用队列遍历所有结点。每出队一个结点，检查它的**左孩子**是不是叶子，是就加上。然后把孩子们入队继续。

这和思路一用的是同一个判断（站在父亲上看左孩子），只是遍历方式从递归换成了队列。

### 手动模拟（示例 1）

| 出队 | 左孩子是叶子？ | sum | 入队 |
|---|---|---|---|
| 3 | 9 是叶子 | 9 | 9, 20 |
| 9 | 无左孩子 | 9 | |
| 20 | 15 是叶子 | 24 | 15, 7 |
| 15 | 无 | 24 | |
| 7 | 无 | 24 | |

### 代码

```c
int sumOfLeftLeaves(struct TreeNode* root) {
    struct TreeNode* q[1000];                // 最多 1000 个结点，每个只入队一次
    int head = 0, tail = 0, sum = 0;
    q[tail++] = root;
    while (head < tail) {
        struct TreeNode* node = q[head++];
        struct TreeNode* l = node->left;
        if (l != NULL) {
            if (l->left == NULL && l->right == NULL) sum += l->val;   // 左孩子是叶子
            else q[tail++] = l;              // 不是叶子就入队，继续往下找
        }
        if (node->right != NULL) q[tail++] = node->right;
    }
    return sum;
}
```

> 左叶子没有孩子，入不入队都不影响结果，这里直接不入队了。

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(n)**（队列）。

---

## ⚠️ 第五步：小白常见错误

1. **把所有叶子都加上**：
   ```c
   if (root->left == NULL && root->right == NULL) return root->val;   // ❌
   ```
   站在结点自己身上判断，分不出左右，示例 1 会得到 9+15+7 = 31。
2. **把根结点也算进去**：示例 2 `[1]` 输出了 1。根不是任何结点的左孩子。
3. **把"左孩子"都加上，不管是不是叶子**：`[1,2,3,4,5]` 中 2 是左孩子但不是叶子，不应该算；正确答案是 4。
4. **左孩子是叶子时还忘了递归右子树**：直接 `return l->val;`，右子树里的左叶子就漏了。
5. **多层 `->` 没判空**：`root->left->left == NULL` 在 `root->left == NULL` 时崩溃。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 递归 DFS | O(n) | O(h) | ⭐ | **首选**，代码最短 |
| 层序 BFS | O(n) | O(n) | ⭐ | 不想用递归时用 |
