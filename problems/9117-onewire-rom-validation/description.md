# 单总线 ROM 校验

输入候选1-Wire ROM字节数组，必须恰好8字节且最后字节等于前7字节的CRC8/MAXIM才返回true。不检查家族码及序列号是否已登记。长度0到16。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool validateOneWireRom(const uint8_t* rom,size_t len);
```

## 示例 1

输入：
```text
[40,1,2,3,4,5,6,158]
```
输出：
```text
true
```

## 示例 2

输入：
```text
[0,0,0,0,0,0,0,0]
```
输出：
```text
true
```

## 自定义输入格式

按顺序每行一个参数：rom。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
