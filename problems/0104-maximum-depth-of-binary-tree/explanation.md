# 104. 二叉树的最大深度 —— 小白详细题解

> 这是二叉树递归的"Hello World"。学会它，你就掌握了一个万能套路：**先问左右子树要答案，再算出自己的答案。**

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 从根结点出发，一路往下走到最底下的叶子，**最长的那条路上有几个结点**？

示例 1：`[3,9,20,null,null,15,7]`

```
    3          ← 第 1 层
   / \
  9  20        ← 第 2 层
    /  \
   15   7      ← 第 3 层
```

| 路径 | 经过的结点数 |
|---|---|
| 3 → 9 | 2 |
| 3 → 20 → 15 | 3 |
| 3 → 20 → 7 | 3 |

最长的是 3，所以答案是 **3**。

**几个需要注意的细节：**

1. 深度数的是**结点个数**，不是边的条数。只有根结点的树深度是 1。
2. 空树（`root == NULL`）深度是 **0**。
3. 树最多 10⁴ 个结点，可能退化成一条链（每个结点只有一个孩子），这时深度就是 10⁴。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 结构体指针访问成员

```c
root->left    // 等价于 (*root).left：root 指向的结点的左孩子
root->val     // 结点里存的值
```

访问之前一定要确认 `root != NULL`，否则程序崩溃。

### 2. 递归函数

函数自己调用自己。写递归只需要想清楚两件事：

- **出口**：什么情况下不用再往下调用，直接返回答案？（本题：空树返回 0）
- **怎么用小问题的答案拼出大问题的答案**？（本题：左右子树的深度取大的，再加 1）

### 3. 用数组模拟队列

C 语言没有现成的队列，可以用数组 + 两个下标 `head`、`tail` 模拟：

```c
queue[tail++] = x;     // 入队：放到末尾
x = queue[head++];     // 出队：从开头取
head < tail            // 队列不为空
```

---

## 💡 第三步：思路一 —— 递归（深度优先搜索）

### 思路

站在根结点上想：

> 如果我已经知道了**左子树的深度** `l` 和**右子树的深度** `r`，那整棵树的深度就是 `max(l, r) + 1`（加的 1 是根结点自己）。

而"左子树的深度"又是同一个问题，交给递归去算。空树是递归的出口，深度为 0。

### 手动模拟（示例 1）

从下往上算：

| 结点 | 左子树深度 | 右子树深度 | 自己的深度 = max + 1 |
|---|---|---|---|
| 9 | 0（空） | 0（空） | 1 |
| 15 | 0 | 0 | 1 |
| 7 | 0 | 0 | 1 |
| 20 | 1（15） | 1（7） | 2 |
| 3 | 1（9） | 2（20） | **3** |

### 代码

```c
int maxDepth(struct TreeNode* root) {
    if (root == NULL) return 0;              // 出口：空树深度为 0

    int l = maxDepth(root->left);            // 左子树有多深
    int r = maxDepth(root->right);           // 右子树有多深

    return (l > r ? l : r) + 1;              // 取较深的一边，再加上自己这一层
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点恰好被访问一次。
- **空间复杂度 O(h)**：h 是树高，即递归调用栈的深度。最坏（一条链）h = n = 10⁴，每层只占几十字节，没问题。

---

## 🚀 第四步：思路二 —— 层序遍历（广度优先搜索）

### 思路

深度就是**层数**。所以可以一层一层地往下走，每走完一层，计数器加 1：

1. 把根结点放进队列
2. 记下当前队列里有几个结点（`size`），这就是这一层的全部结点
3. 把这 `size` 个结点依次出队，同时把它们的孩子入队（下一层）
4. 这一层处理完，`depth++`；队列空了就结束

### 手动模拟（示例 1）

| 轮次 | 本层结点 | 入队的下一层 | depth |
|---|---|---|---|
| 1 | 3 | 9, 20 | 1 |
| 2 | 9, 20 | 15, 7 | 2 |
| 3 | 15, 7 | （无） | 3 |
| | 队列空，结束 | | **3** |

### 代码

```c
int maxDepth(struct TreeNode* root) {
    if (root == NULL) return 0;

    // 每个结点最多入队一次，开 10^4 个位置就够了
    struct TreeNode** queue = (struct TreeNode**)malloc(sizeof(struct TreeNode*) * 10000);
    int head = 0, tail = 0;
    queue[tail++] = root;
    int depth = 0;

    while (head < tail) {                    // 队列不空
        int size = tail - head;              // 当前这一层有几个结点
        for (int i = 0; i < size; i++) {
            struct TreeNode* node = queue[head++];          // 出队
            if (node->left != NULL)  queue[tail++] = node->left;    // 孩子入队
            if (node->right != NULL) queue[tail++] = node->right;
        }
        depth++;                             // 处理完一层
    }

    free(queue);
    return depth;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点入队、出队各一次。
- **空间复杂度 O(n)**：队列（这里直接开了最大规模）。

---

## ⚠️ 第五步：小白常见错误

1. **空树返回 1**：`if (root == NULL) return 1;` 会让每片叶子都多算一层，示例 1 会输出 4。
2. **不判断空就访问孩子**：`root->left->val` 在 `root->left == NULL` 时崩溃。递归写法把判空放在函数开头，自然就避免了。
3. **把递归调用写两遍**：
   ```c
   return (maxDepth(root->left) > maxDepth(root->right) ? maxDepth(root->left) : maxDepth(root->right)) + 1;   // ❌
   ```
   每层都会重复计算，时间复杂度变成指数级，结点一多就超时。先用变量存下来再比较。
4. **层序遍历时没有先记下 `size`**：写成 `for (int i = 0; i < tail - head; i++)`，循环过程中 `tail` 会不断变大，就把下一层的结点也算进这一层了。
5. **只看左子树或只看右子树**：比如一直沿着 `left` 走数步数，示例 2 `[1,null,2]` 会得到 1 而不是 2。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 递归（DFS） | O(n) | O(h) | ⭐ | **首选**，三行代码 |
| 层序遍历（BFS） | O(n) | O(n) | ⭐⭐ | 学会"按层处理"的模板，很多题要用 |
