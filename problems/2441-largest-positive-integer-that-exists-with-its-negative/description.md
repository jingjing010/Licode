# 与对应负数同时存在的最大正整数

返回同时在数组中出现k与−k的最大正整数k，没有则返回−1。1 ≤ n ≤ 1000，元素在−1000到1000之间且不为0。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int findMaxK(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[-1,2,-3,3]
```
输出：
```text
3
```

## 示例 2

输入：
```text
[-1,10,6,7,-7,1]
```
输出：
```text
7
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
