# 6 和 9 组成的最大数字：题解

## 📖 先读懂题目

正整数 num 只由6和9组成，最多改变一位（6变9或9变6），返回可得到的最大整数。num ≤ 10^4。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `9669` | `9969` |
| 2 | `9996` | `9999` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

改变越高位的6收益越大，只把最高位的6变成9。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int maximum69Number(int num) {
    int x = num, place = 1, last = 0;
    /* 从低位扫描，最后记录的位置就是最高位的6。 */
    while (x) {
        if (x % 10 == 6)
            last = place;
        place *= 10;
        x /= 10;
    }
    return num + 3 * last;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(log n)，额外空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
