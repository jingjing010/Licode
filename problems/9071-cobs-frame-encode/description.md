# COBS 无零字节编码

编码为COBS数据区，不附加帧分隔符0。空输入编码为[1]。每块最多254个数据字节；即使最后恰好满块，也输出结尾空块码1。输入0到1024字节。返回整数数组表示字节。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* cobsEncode(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[49,50,51,52,53,54,55,56,57]
```
输出：
```text
[10,49,50,51,52,53,54,55,56,57]
```

## 示例 2

输入：
```text
[]
```
输出：
```text
[1]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
