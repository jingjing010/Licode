# 84. 柱状图中最大的矩形 —— 小白详细题解

> 单调栈的经典"困难"题。核心只有一句话：**以每根柱子为高，找它左右两边第一根更矮的柱子**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一排宽度为 1 的柱子紧挨着，在这些柱子里画一个**贴着底边的矩形**（不能超出柱子），面积最大是多少？

示例 1：`heights = [2,1,5,6,2,3]`

```
        6
      5 █
      █ █
      █ █   3
  2   █ █ 2 █
  █ 1 █ █ █ █
  ─────────────
  0 1 2 3 4 5
```

下标 2、3 的柱子（高 5 和 6）能组成高 5、宽 2 的矩形，面积 10，这是最大的。

**几个需要注意的细节：**

1. 矩形的高**由最矮的那根柱子决定**。
2. 柱子高度可以是 **0**，高度 0 的柱子把柱状图"切断"了。
3. 一根柱子自己也是一个矩形（宽 1）。
4. 最大面积可达 10⁴ × 10⁵ = 10⁹，还在 int 范围内（约 2.1×10⁹）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 数组模拟栈（存下标）

```c
int* stack = (int*)malloc(sizeof(int) * n);
int top = 0;
stack[top++] = i;        // 压栈
int j = stack[--top];    // 弹栈
stack[top - 1]           // 栈顶（top > 0 时）
```

### 2. 三目运算符

```c
int left = (top == 0) ? -1 : stack[top - 1];
// 栈空就取 -1，否则取栈顶
```

### 3. 用完记得 `free`

`malloc` 出来的辅助数组在函数结束前 `free` 掉，养成好习惯。

## 💡 第三步：思路一 —— 枚举左右端点（会超时）

```c
// ❌ 思路正确，但 O(n²)，n = 10^5 时约 5×10^9 次运算，必然超时
for (int i = 0; i < n; i++) {
    int minH = heights[i];
    for (int j = i; j < n; j++) {
        if (heights[j] < minH) minH = heights[j];   // [i, j] 区间的最矮柱子
        int area = minH * (j - i + 1);
        if (area > best) best = area;
    }
}
```

它告诉我们一个关键事实：**矩形的高一定等于区间里某根柱子的高度**。于是可以换个枚举方式——枚举"谁当最矮的那根"。

---

## 🚀 第四步：思路二 —— 以每根柱子为高，求左右边界

### 思路

固定柱子 i，让它当矩形的高 `heights[i]`。矩形往左能延伸到哪？一直延伸到**左边第一根比它矮的柱子**之前；右边同理。

- `left[i]`：i 左边第一根**比它矮**的柱子下标，没有就是 -1；
- `right[i]`：i 右边第一根**比它矮**的柱子下标，没有就是 n；
- 以 i 为高的矩形面积 = `heights[i] * (right[i] - left[i] - 1)`。

"第一个更小的元素"正是单调栈的拿手好戏：从左往右扫，栈里保持高度**递增**，遇到比栈顶矮（或相等）的就弹出，剩下的栈顶就是左边第一根更矮的。

### 手动模拟（求 left，`heights = [2,1,5,6,2,3]`）

| i | 高度 | 弹出 | 弹完后栈顶 → left[i] | 压栈后栈 |
|---|---|---|---|---|
| 0 | 2 | - | 空 → -1 | 0 |
| 1 | 1 | 0 | 空 → -1 | 1 |
| 2 | 5 | - | 1 | 1,2 |
| 3 | 6 | - | 2 | 1,2,3 |
| 4 | 2 | 3,2 | 1 | 1,4 |
| 5 | 3 | - | 4 | 1,4,5 |

同理从右往左求出 `right = [1,6,4,4,6,6]`。柱子 2：`5 × (4 - 1 - 1) = 10` ✅

### 代码

```c
int largestRectangleArea(int* heights, int heightsSize) {
    int n = heightsSize;
    int* left = (int*)malloc(sizeof(int) * n);
    int* right = (int*)malloc(sizeof(int) * n);
    int* stack = (int*)malloc(sizeof(int) * n);
    int top = 0;

    // 从左往右：left[i] = 左边第一根比 heights[i] 矮的柱子
    for (int i = 0; i < n; i++) {
        while (top > 0 && heights[stack[top - 1]] >= heights[i]) top--;
        left[i] = (top == 0) ? -1 : stack[top - 1];
        stack[top++] = i;
    }

    // 从右往左：right[i] = 右边第一根比 heights[i] 矮的柱子
    top = 0;
    for (int i = n - 1; i >= 0; i--) {
        while (top > 0 && heights[stack[top - 1]] >= heights[i]) top--;
        right[i] = (top == 0) ? n : stack[top - 1];
        stack[top++] = i;
    }

    int best = 0;
    for (int i = 0; i < n; i++) {
        int area = heights[i] * (right[i] - left[i] - 1);
        if (area > best) best = area;
    }
    free(left);
    free(right);
    free(stack);
    return best;
}
```

> 💬 **为什么弹栈条件是 `>=`？** 把和当前柱子一样高（或更高）的都弹走，剩下的栈顶才是**严格更矮**的那根。等高的柱子不会挡住矩形，必须越过它们继续延伸。

### 复杂度分析

- **时间复杂度 O(n)**：每个下标最多入栈、出栈各一次。
- **空间复杂度 O(n)**：三个辅助数组。

## 🚀 第五步：思路三 —— 一遍单调栈 + 哨兵

### 思路

其实**弹栈的那一刻**就能算面积：柱子 `j` 被今天的柱子 `i` 弹出，说明 `i` 是 `j` 右边第一根更矮（或相等）的；弹出后的新栈顶就是 `j` 左边第一根更矮的。

最后在末尾假想一根**高度为 0 的柱子**（哨兵），它会把栈里剩下的柱子全部弹出结算。

### 代码

```c
int largestRectangleArea(int* heights, int heightsSize) {
    int n = heightsSize;
    int* stack = (int*)malloc(sizeof(int) * (n + 1));
    int top = 0;
    int best = 0;
    for (int i = 0; i <= n; i++) {
        int h = (i == n) ? 0 : heights[i];      // i == n 时是高度 0 的哨兵
        while (top > 0 && heights[stack[top - 1]] >= h) {
            int height = heights[stack[--top]];  // 被弹出的柱子当高
            int left = (top == 0) ? -1 : stack[top - 1];   // 左边界
            int area = height * (i - left - 1);  // 右边界就是 i
            if (area > best) best = area;
        }
        stack[top++] = i;
    }
    free(stack);
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(n)**，但只扫一遍、少用两个数组。

## ⚠️ 第六步：小白常见错误

1. **宽度算成 `right - left`** → 多算了一格。左右边界上的柱子比当前矮，不在矩形里，宽度是 `right - left - 1`。
2. **栈空时左边界不是 -1** → 写成 0 会让最矮的柱子少算一格宽度，例如 `[2,4]` 里的 2 应该覆盖整个宽度 2。
3. **忘了末尾的哨兵** → 单调递增的输入（如 `[1,2,3,4,5]`）一个都不会被弹出，结果是 0。
4. **哨兵直接写进 `heights[n]`** → 越界写！只能用变量 `h` 假装有这根柱子。
5. **while 条件写成 `if`** → 一根矮柱子可能要连续弹出好几根高柱子。
6. **面积用 `long long` 也行，但别用 `short`** → 最大 10⁹，int 刚好够。

## 📊 第七步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 枚举区间 | O(n²) | O(1) | ⭐⭐ | 会超时，帮助理解 |
| 左右边界两遍单调栈 | O(n) | O(n) | ⭐⭐⭐ | 思路最清晰 |
| 一遍单调栈 + 哨兵 | O(n) | O(n) | ⭐⭐⭐⭐ | 代码最短 |
