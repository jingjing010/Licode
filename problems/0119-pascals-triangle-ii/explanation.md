# 119. 杨辉三角 II —— 小白详细题解

> 杨辉三角大家在数学课上都见过。这道题教你两件事：**用上一行推出下一行**（最简单的动态规划），以及**怎样用一个数组原地滚动更新**。

---

## 📖 第一步：先读懂题目

杨辉三角长这样（行号从 **0** 开始）：

| 行号 | 内容 |
|---|---|
| 0 | 1 |
| 1 | 1 1 |
| 2 | 1 2 1 |
| 3 | 1 3 3 1 |
| 4 | 1 4 6 4 1 |

规律：

- 第 `i` 行有 `i + 1` 个数；
- 每行**首尾都是 1**；
- 中间的数 = 上一行**左上方** + **正上方**的两个数之和。比如第 4 行的 6 = 第 3 行的 3 + 3。

题目只要第 `rowIndex` 行，例如 `rowIndex = 3` 返回 `[1,3,3,1]`。

**几个需要注意的细节：**

1. 行号从 0 开始，`rowIndex = 0` 返回 `[1]`，返回数组长度是 `rowIndex + 1`。
2. `rowIndex` 最大 33。第 33 行最大的数是 `1166803110`，还在 `int` 范围内（约 `2.1 × 10^9`），但已经很接近了，中间计算要小心溢出。
3. 进阶要求只用 `O(rowIndex)` 的额外空间。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回数组：`malloc` + `*returnSize`

```c
int* getRow(int rowIndex, int* returnSize)
```

返回的数组必须 `malloc`，并通过 `*returnSize = rowIndex + 1;` 告诉调用者长度。

### 2. 二维数组的动态申请（思路一要用）

```c
int** tri = (int**)malloc(sizeof(int*) * 行数);      // 先申请"行指针"数组
for (int i = 0; i < 行数; i++)
    tri[i] = (int*)malloc(sizeof(int) * (i + 1));   // 再给每一行单独申请空间
```

`tri[i][j]` 就表示第 `i` 行第 `j` 个数。用完后要先 `free` 每一行，再 `free(tri)`。

### 3. `long long` 防溢出

两个 `int` 相乘，结果还是 `int`，超过范围就会溢出。写成 `(long long)a * b`，先把 `a` 转成 `long long` 再乘，就安全了。

---

## 💡 第三步：思路一 —— 把整个三角形都算出来（最直观）

### 思路

按照定义一行一行算：

- `tri[i][0] = tri[i][i] = 1`
- `tri[i][j] = tri[i-1][j-1] + tri[i-1][j]`（`0 < j < i`）

算到第 `rowIndex` 行，把它复制出来返回。

### 手动模拟（`rowIndex = 3`）

| 行 i | j=0 | j=1 | j=2 | j=3 | 说明 |
|---|---|---|---|---|---|
| 0 | 1 | | | | 只有一个 1 |
| 1 | 1 | 1 | | | 首尾都是 1 |
| 2 | 1 | 1+1=2 | 1 | | |
| 3 | 1 | 1+2=3 | 2+1=3 | 1 | 答案 |

### 代码

```c
int* getRow(int rowIndex, int* returnSize) {
    int rows = rowIndex + 1;
    // 1. 申请整个三角形：第 i 行有 i+1 个数
    int** tri = (int**)malloc(sizeof(int*) * rows);
    for (int i = 0; i < rows; i++) {
        tri[i] = (int*)malloc(sizeof(int) * (i + 1));
        tri[i][0] = tri[i][i] = 1;                       // 首尾都是 1
        for (int j = 1; j < i; j++) {
            tri[i][j] = tri[i - 1][j - 1] + tri[i - 1][j];  // 左上 + 正上
        }
    }

    // 2. 把最后一行复制出来作为答案
    int* res = (int*)malloc(sizeof(int) * rows);
    for (int j = 0; j < rows; j++) res[j] = tri[rowIndex][j];

    // 3. 释放三角形占用的内存
    for (int i = 0; i < rows; i++) free(tri[i]);
    free(tri);

    *returnSize = rows;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：一共算了约 n²/2 个数（n = rowIndex）。
- **空间复杂度 O(n²)**：保存了整个三角形。

---

## 🚀 第四步：思路二 —— 一维数组从后往前滚动（O(n) 空间）

### 思路

算第 `i` 行时，只用到了第 `i-1` 行，更早的行全都没用了。那就只用**一个数组** `row`，让它从第 0 行一路"变成"第 `rowIndex` 行。

关键问题：原地更新时，`row[j] = row[j-1] + row[j]` 需要的 `row[j-1]` 必须是**上一行**的值。

- 如果**从前往后**算，`row[j-1]` 刚刚已经被改成了新一行的值 ❌
- 如果**从后往前**算，`row[j-1]` 还没被改，仍然是上一行的值 ✅

### 手动模拟（从第 2 行 `[1,2,1]` 变成第 3 行）

先在末尾补一个 1：`row = [1,2,1,1]`，然后 `j` 从 2 往 1 倒着算：

| j | row[j-1] | row[j]（旧） | row[j]（新） | row |
|---|---|---|---|---|
| 2 | 2 | 1 | 3 | [1,2,3,1] |
| 1 | 1 | 2 | 3 | [1,3,3,1] |

如果从前往后算：`j=1` 时 `row[1] = 1+2 = 3`，`j=2` 时 `row[2] = 3+1 = 4`，得到 `[1,3,4,1]`，错了！

### 代码

```c
int* getRow(int rowIndex, int* returnSize) {
    int* row = (int*)malloc(sizeof(int) * (rowIndex + 1));
    row[0] = 1;                                 // 第 0 行：[1]

    for (int i = 1; i <= rowIndex; i++) {       // 依次把 row 变成第 i 行
        row[i] = 1;                             // 新的一行末尾是 1
        for (int j = i - 1; j >= 1; j--) {      // 从后往前更新中间的数
            row[j] = row[j] + row[j - 1];       // 此时 row[j-1] 还是上一行的值
        }
        // row[0] 一直是 1，不用动
    }

    *returnSize = rowIndex + 1;
    return row;
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：和思路一一样多的加法。
- **空间复杂度 O(n)**：只用了一个长度为 `rowIndex + 1` 的数组（就是返回值本身）。

### 🌟 进阶：组合数公式，O(n) 时间

杨辉三角第 `n` 行第 `k` 个数就是组合数 `C(n, k)`，而相邻两项有关系：

```
C(n, k) = C(n, k-1) × (n - k + 1) / k
```

所以可以从 `C(n, 0) = 1` 开始，一个乘除就推出下一个：

```c
int* getRow(int rowIndex, int* returnSize) {
    int* row = (int*)malloc(sizeof(int) * (rowIndex + 1));
    row[0] = 1;
    for (int k = 1; k <= rowIndex; k++) {
        // 先乘后除，结果一定是整数；乘法可能超过 int，所以用 long long
        row[k] = (int)((long long)row[k - 1] * (rowIndex - k + 1) / k);
    }
    *returnSize = rowIndex + 1;
    return row;
}
```

> ⚠️ 必须**先乘再除**：如果先算 `(rowIndex - k + 1) / k`，整数除法会丢掉小数部分。而先乘的结果最大约 `2 × 10^10`，超过了 `int`，所以要转成 `long long`。

---

## ⚠️ 第五步：小白常见错误

1. **一维数组从前往后更新** → `row[j-1]` 已经是新值，`rowIndex = 3` 会得到 `[1,3,4,1]`。
2. **返回数组长度写成 `rowIndex`** → 第 `rowIndex` 行有 `rowIndex + 1` 个数，少写一个最后的 1 就没了。
3. **数组只申请了 `rowIndex` 个元素** → `row[rowIndex] = 1` 越界写，可能导致崩溃。
4. **组合数公式里先除后乘** → `row[k-1] * ((rowIndex-k+1)/k)` 中的整数除法会截断，结果错误。
5. **组合数公式里没用 `long long`** → `rowIndex = 33` 时乘积超过 `int` 范围，溢出成负数。
6. **思路一忘了释放二维数组** → 本题规模小不会出错，但养成 `malloc` 配 `free` 的习惯很重要。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 整个三角形 | O(n²) | O(n²) | ⭐ | 最直观，先写这个 |
| 一维数组倒序滚动 | O(n²) | O(n) | ⭐⭐ | 满足进阶要求，学会"倒序更新"技巧 |
| 组合数公式 | O(n) | O(n) | ⭐⭐ | 最快，但要注意先乘后除和溢出 |

> 🎯 **学习建议**："从后往前更新一维数组"是**0-1 背包**空间优化的核心技巧，在这里先把它弄懂，以后学动态规划会轻松很多。
