给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

### 示例 1

```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6
```

### 示例 2

```
输入：lists = []
输出：[]
```

### 示例 3

```
输入：lists = [[]]
输出：[]
```

### 提示

- `k == lists.length`
- `0 <= k <= 10^4`
- `0 <= lists[i].length <= 500`
- `-10^4 <= lists[i][j] <= 10^4`
- `lists[i]` 按 **升序** 排列
- `lists[i].length` 的总和不超过 `10^4`

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* mergeKLists(struct ListNode** lists, int listsSize);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `lists`：链表头指针组成的数组，`lists[i]` 是第 `i` 条链表的头，空链表为 `NULL`
- `listsSize`：链表的条数 `k`，可能为 0
- 返回值：合并后链表的头指针（可以直接复用原来的结点，不需要 `malloc` 新结点）

### 自定义输入格式

```
[[1,4,5],[1,3,4],[2,6]]
```

只有 1 行：二维数组，每一行是一条升序链表，空链表写作 `[]`，没有链表时整行写作 `[]`。输出为合并后的链表。
