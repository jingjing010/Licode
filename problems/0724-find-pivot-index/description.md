# 寻找数组的中心下标

返回左右元素总和相等的最左下标，不存在返回−1。1 ≤ n ≤ 10^4，元素范围−1000到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int pivotIndex(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,7,3,6,5,6]
```
输出：
```text
3
```

## 示例 2

输入：
```text
[1,2,3]
```
输出：
```text
-1
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
