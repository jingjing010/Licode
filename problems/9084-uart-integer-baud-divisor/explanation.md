# UART 整数分频器计算：题解

## 📖 先读懂题目

模型：baud实际=clockHz/(16*divisor)。返回clockHz/(16*baud)四舍五入的正整数，中点向上。保证clockHz≥16*baud，clockHz≤10^8；不涉及芯片特有的分数分频寄存器。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `48000000 / 115200` | `26` |
| 2 | `16000000 / 9600` | `104` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

假设UART固定16倍过采样，整数分频器等于时钟除以16倍波特率，采用四舍五入。乘法先转64位。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int uartDivisor(int clockHz, int baud) {
    int64_t denominator = (int64_t)baud * 16;
    return (int)(((int64_t)clockHz + denominator / 2) / denominator);
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
