# 445. 两数相加 II —— 小白详细题解

> 2 题"两数相加"的数字是**倒着**存的（个位在前），这道题是**正着**存的（最高位在前）。加法必须从个位开始，怎么"倒着走"链表就是本题的关键。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 两条链表各表示一个大整数，**最高位在前**。把它们加起来，结果也用"最高位在前"的链表表示。

用示例 1 列一个竖式：

```
    7 2 4 3        l1 = [7,2,4,3]
 +    5 6 4        l2 = [5,6,4]
 ----------
    7 8 0 7        结果 = [7,8,0,7]
```

从个位开始：`3+4=7`；`4+6=10` 写 0 进 1；`2+5+1=8`；`7+0=7`。

**几个需要注意的细节：**

1. 最多 100 位，远超 `long long`（约 19 位）的范围，**不能**转成整数相加。
2. 加法要从**个位**（链表的**末尾**）开始，但单链表只能从头往后走。
3. 两个数长度可能不同，短的那个高位当作 0。
4. 最高位相加后可能还有进位，例如 `[9] + [1] = [1,0]`，结果比两个数都长。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 新建结点

```c
struct ListNode* node = (struct ListNode*)malloc(sizeof(struct ListNode));
node->val = 7;
node->next = NULL;
```

### 2. 头插法：新结点插到最前面

我们从个位开始算，先算出的是个位。如果每次都把新结点插到结果链表的**最前面**，最后高位自然就在前面了：

```c
node->next = head;    // 新结点指向原来的头
head = node;          // 新结点成为新的头
```

| 算出的位 | 头插后的结果链表 |
|---|---|
| 7（个位） | 7 |
| 0（十位） | 0 -> 7 |
| 8（百位） | 8 -> 0 -> 7 |
| 7（千位） | 7 -> 8 -> 0 -> 7 |

### 3. 用数组当栈

"后进先出"的栈可以用数组 + 一个计数器实现：

```c
int stack[105];
int top = 0;
stack[top++] = x;     // 入栈
int y = stack[--top]; // 出栈：取最后放进去的那个
```

把链表从头到尾依次入栈，出栈的顺序就是**从尾到头**，也就是从个位到最高位。

## 💡 第三步：思路一 —— 反转链表，转化成第 2 题

### 思路

1. 把 `l1`、`l2` 都反转（206 题），个位就到了最前面
2. 像第 2 题一样从头开始逐位相加，处理进位
3. 第 2 步如果用**头插法**构造结果，结果就直接是"最高位在前"，不用再反转

### 代码

```c
// 反转链表（206 题）
static struct ListNode* reverse(struct ListNode* head) {
    struct ListNode* prev = NULL;
    while (head != NULL) {
        struct ListNode* next = head->next;
        head->next = prev;
        prev = head;
        head = next;
    }
    return prev;
}

struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    l1 = reverse(l1);                 // 反转后个位在前
    l2 = reverse(l2);

    struct ListNode* head = NULL;     // 结果链表（头插法，高位在前）
    int carry = 0;                    // 进位
    while (l1 != NULL || l2 != NULL || carry != 0) {
        int sum = carry;
        if (l1 != NULL) { sum += l1->val; l1 = l1->next; }
        if (l2 != NULL) { sum += l2->val; l2 = l2->next; }

        struct ListNode* node = (struct ListNode*)malloc(sizeof(struct ListNode));
        node->val = sum % 10;         // 这一位写 sum 的个位
        node->next = head;            // 头插
        head = node;
        carry = sum / 10;             // 进位留给下一位
    }
    return head;
}
```

### 复杂度分析

- **时间复杂度 O(m + n)**：反转和相加都是线性的。
- **空间复杂度 O(1)**（不算结果链表）。缺点是**修改了输入链表**，不满足"进阶"要求。

---

## 🚀 第四步：思路二 —— 用栈，不修改输入（满足进阶）

### 思路

1. 把 `l1` 的每一位依次压入栈 `s1`，`l2` 的压入栈 `s2`
2. 每次从两个栈各弹出一位（栈空了就当 0），加上进位
3. 用头插法把结果位插到结果链表最前面
4. 两个栈都空、并且没有进位时结束

### 手动模拟（示例 1）

`s1 = [7,2,4,3]`（栈顶是 3），`s2 = [5,6,4]`（栈顶是 4）

| 轮次 | 弹出 | sum | 写入 | carry | 结果链表 |
|---|---|---|---|---|---|
| 1 | 3, 4 | 7 | 7 | 0 | 7 |
| 2 | 4, 6 | 10 | 0 | 1 | 0->7 |
| 3 | 2, 5 | 8 | 8 | 0 | 8->0->7 |
| 4 | 7, 空 | 7 | 7 | 0 | 7->8->0->7 |

### 代码

```c
struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    // 1. 两个数组当栈用，链表最长 100
    int s1[105], s2[105];
    int n1 = 0, n2 = 0;                       // 栈中元素个数
    for (struct ListNode* p = l1; p != NULL; p = p->next) s1[n1++] = p->val;
    for (struct ListNode* p = l2; p != NULL; p = p->next) s2[n2++] = p->val;

    // 2. 从栈顶（个位）开始逐位相加
    struct ListNode* head = NULL;
    int carry = 0;
    while (n1 > 0 || n2 > 0 || carry != 0) {  // 还有数字或者还有进位
        int sum = carry;
        if (n1 > 0) sum += s1[--n1];          // 出栈；栈空了就相当于加 0
        if (n2 > 0) sum += s2[--n2];

        // 3. 头插法：新算出的位放到最前面
        struct ListNode* node = (struct ListNode*)malloc(sizeof(struct ListNode));
        node->val = sum % 10;
        node->next = head;
        head = node;
        carry = sum / 10;
    }
    return head;
}
```

### 复杂度分析

- **时间复杂度 O(m + n)**。
- **空间复杂度 O(m + n)**：两个栈。输入链表保持不变。

---

## ⚠️ 第五步：小白常见错误

1. **把链表转成整数再相加**：100 位数字用 `long long` 会溢出，结果错误。
2. **循环条件漏了 `carry != 0`**：`[9] + [1]` 会得到 `[0]`，丢了最高位的进位 1。
3. **用尾插法构造结果**：从个位开始算、尾插得到的是"个位在前"，还需要再反转一次；直接用头插法更简单。
4. **栈空了还继续出栈**：`s1[--n1]` 在 `n1 == 0` 时会访问 `s1[-1]`，越界。必须先判断 `n1 > 0`。
5. **新结点的 `next` 没赋值**：`malloc` 的内存是随机值，结尾结点的 `next` 不是 `NULL`，打印时崩溃。头插法里第一个结点的 `next = head` 正好是 `NULL`。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 修改输入？ | 建议 |
|---|---|---|---|---|
| 反转链表 | O(m+n) | O(1) | 是 | 复用 206 + 2 题 |
| 栈 | O(m+n) | O(m+n) | 否 | **满足进阶**，推荐 |
