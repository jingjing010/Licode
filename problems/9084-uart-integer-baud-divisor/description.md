# UART 整数分频器计算

模型：baud实际=clockHz/(16*divisor)。返回clockHz/(16*baud)四舍五入的正整数，中点向上。保证clockHz≥16*baud，clockHz≤10^8；不涉及芯片特有的分数分频寄存器。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int uartDivisor(int clockHz,int baud);
```

## 示例 1

输入：
```text
48000000
115200
```
输出：
```text
26
```

## 示例 2

输入：
```text
16000000
9600
```
输出：
```text
104
```

## 自定义输入格式

按顺序每行一个参数：clockHz、baud。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
