你在为一块电池监测板写固件：MCU 的 ADC 通过 DMA 连续采样，把一批**原始值**（raw）写进缓冲区。原始值只是一个"刻度"，要换算成**毫伏（mV）**才能用于显示、上报或判断低电量。

一个 `bits` 位的 ADC，满量程原始值是 `fs = 2^bits - 1`（12 位 ADC 是 4095）。当参考电压为 `vref_mv` 毫伏时，原始值 `raw` 对应的电压是：

```
电压(mV) = raw × vref_mv / fs
```

请实现函数 `adc_to_mv`：把 `raw[0] ~ raw[len-1]` 逐个换算成毫伏，结果**四舍五入到整数**后写入 `mv[0] ~ mv[len-1]`。

> 由于 `fs` 是奇数，`raw × vref_mv / fs` 的小数部分不可能恰好是 0.5，因此不存在"四舍五入时一样近"的情况。

**注意：MCU 上通常没有 FPU，请只用整数运算完成换算。**

### 示例 1

```
输入：raw = [0,4095,2048], bits = 12, vref_mv = 3300
输出：[0,3300,1650]
解释：STM32 常见配置，12 位 ADC、3.3V 参考电压。2048 × 3300 / 4095 ≈ 1650.40，四舍五入为 1650。
```

### 示例 2

```
输入：raw = [1000,3000], bits = 12, vref_mv = 5000
输出：[1221,3663]
解释：1000 × 5000 / 4095 ≈ 1221.00，3000 × 5000 / 4095 ≈ 3663.00。
```

### 示例 3

```
输入：raw = [65535,40000,12345], bits = 16, vref_mv = 50000
输出：[50000,30518,9419]
解释：16 位外置 ADC，前端分压后满量程对应 50V。65535 × 50000 ≈ 3.28 × 10^9，已经超出 int32_t 的范围！
```

### 提示

- `1 <= len <= 1000`
- `8 <= bits <= 16`
- `0 <= raw[i] <= 2^bits - 1`
- `1 <= vref_mv <= 65535`

### 函数说明

```c
void adc_to_mv(const uint16_t* raw, uint16_t* mv, size_t len, uint8_t bits, uint16_t vref_mv);
```

- `raw`：ADC 原始值缓冲区（只读）
- `mv`：输出缓冲区，调用方已分配好 `len` 个 `uint16_t`
- `len`：采样个数
- `bits`：ADC 分辨率（位数）
- `vref_mv`：满量程对应的电压（毫伏）
- 无返回值：判题程序会打印 `mv` 的全部内容

### 自定义输入格式

```
[0,4095,2048]
12
3300
```

第 1 行是 `raw`，第 2 行是 `bits`，第 3 行是 `vref_mv`。输出为 `mv` 数组。
