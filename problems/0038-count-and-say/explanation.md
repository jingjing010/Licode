# 38. 外观数列 —— 小白详细题解

> 题目描述有点绕，但本质很简单：**把上一个字符串"读"出来**。这道题能练熟"分段统计连续相同字符"和"动态申请字符串"。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 第 1 项是 `"1"`。之后每一项，都是**大声念出**上一项的结果。

怎么"念"？从左往右，把**连续相同的数字**分成一段，每段念成"几个几"：

| 项 | 字符串 | 怎么念 | 下一项 |
|---|---|---|---|
| 1 | `1` | 一个 1 | `11` |
| 2 | `11` | 两个 1 | `21` |
| 3 | `21` | 一个 2，一个 1 | `1211` |
| 4 | `1211` | 一个 1，一个 2，两个 1 | `111221` |
| 5 | `111221` | 三个 1，两个 2，一个 1 | `312211` |

所以示例 1 的 `n = 4` 答案是 `"1211"`。

**几个需要注意的细节：**

1. 念的时候是**先写个数、再写数字**："两个 1" 写成 `21`，不是 `12`。
2. 只有**连续**相同的才算一段：`1211` 里的 1 不连续，要分开念。
3. 字符串长度增长很快，第 30 项有 4462 个字符，必须用 `malloc` 动态申请。
4. 一个有趣的事实：外观数列里**永远不会出现 4 个连续相同的数字**，所以每段的个数只会是 1、2、3，写成一个字符就够了。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 数字和数字字符的转换

字符 `'0'` ~ `'9'` 的 ASCII 码是连续的，所以：

```c
char c = '0' + 3;   // c == '3'
int  d = '7' - '0'; // d == 7
```

### 2. 新字符串要多大？

最坏情况下，每个字符都单独成一段（比如 `"121"`），每段要写 2 个字符，所以新长度 **≤ 旧长度 × 2**。再加上结尾的 `'\0'`：

```c
char* next = (char*)malloc(2 * len + 1);
```

### 3. 用完的旧字符串要 `free`

每一轮都会生成一个新字符串，旧的那个没用了。及时 `free` 可以避免内存泄漏（本题数据小，不释放也能过，但要养成好习惯）。

---

## 💡 第三步：思路一 —— 递归（直接照着定义写）

### 思路

题目的定义本身就是递归的：

- `n == 1` 时返回 `"1"`；
- 否则先求出 `countAndSay(n - 1)`，再把它"念"一遍。

"念"的过程：用 `i` 指向一段的开头，`j` 往后走到第一个和 `s[i]` 不同的位置，这一段的长度就是 `j - i`。

### 手动模拟（念 `"1211"`）

| i | 从 i 开始的一段 | j | 个数 j-i | 写入 | 结果 |
|---|---|---|---|---|---|
| 0 | `1` | 1 | 1 | `1` `1` | `11` |
| 1 | `2` | 2 | 1 | `1` `2` | `1112` |
| 2 | `11` | 4 | 2 | `2` `1` | `111221` |

### 代码

```c
char* countAndSay(int n) {
    // 递归出口：第 1 项就是 "1"
    if (n == 1) {
        char* res = (char*)malloc(2);
        strcpy(res, "1");
        return res;
    }

    char* prev = countAndSay(n - 1);       // 先拿到上一项
    int len = strlen(prev);
    char* res = (char*)malloc(2 * len + 1);  // 新长度最多是旧长度的 2 倍
    int k = 0;                             // res 中已写入的字符数

    int i = 0;
    while (i < len) {
        int j = i;
        while (j < len && prev[j] == prev[i]) {
            j++;                           // j 走到这一段的末尾之后
        }
        res[k++] = '0' + (j - i);          // 先写"几个"
        res[k++] = prev[i];                // 再写"几"
        i = j;                             // 跳到下一段
    }
    res[k] = '\0';

    free(prev);                            // 上一项用完了，释放
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(总长度)**：每一项都要扫描一遍，长度大约每次乘 1.3，所以总工作量主要由最后几项决定，n = 30 时只有几万次操作。
- **空间复杂度 O(L + n)**：L 为结果长度，另有 n 层递归栈。

## 🚀 第四步：思路二 —— 迭代（进阶要求）

### 思路

递归要一层层"压栈"再"弹栈"，其实完全没必要：从 `"1"` 出发，**循环 n-1 次**，每次把当前字符串念一遍换成新字符串即可。逻辑和思路一一样，只是用循环代替了递归。

### 手动模拟（`n = 4`）

| 循环第几次 | cur（念之前） | next（念之后） |
|---|---|---|
| 1 | `1` | `11` |
| 2 | `11` | `21` |
| 3 | `21` | `1211` |

循环 3 次后 `cur = "1211"`。

### 代码

```c
char* countAndSay(int n) {
    // cur 保存当前这一项，初始为第 1 项 "1"
    char* cur = (char*)malloc(2);
    strcpy(cur, "1");
    int len = 1;                              // cur 的长度

    for (int step = 2; step <= n; step++) {   // 依次生成第 2 ~ n 项
        char* next = (char*)malloc(2 * len + 1);
        int k = 0;
        for (int i = 0; i < len; ) {
            int j = i;
            while (j < len && cur[j] == cur[i]) j++;   // 找出这一段 [i, j)
            next[k++] = (char)('0' + (j - i));         // 个数（一定是 1~3）
            next[k++] = cur[i];                        // 数字
            i = j;
        }
        next[k] = '\0';

        free(cur);                            // 旧的不要了
        cur = next;                           // 新的变成当前项
        len = k;
    }
    return cur;
}
```

### 复杂度分析

- **时间复杂度 O(总长度)**：同思路一。
- **空间复杂度 O(L)**：只同时保留两项字符串，没有递归栈。

---

## ⚠️ 第五步：小白常见错误

1. **个数和数字写反** → `next[k++] = cur[i]; next[k++] = '0' + cnt;` ❌ 会把"两个 1"写成 `12`。
2. **直接写 `next[k++] = cnt;`** ❌ → 写进去的是 ASCII 码为 2 的不可见字符，不是 `'2'`，要加 `'0'`。
3. **`malloc` 只申请 `2 * len`** → 最坏情况刚好写满 `2 * len` 个字符，`'\0'` 就越界了。
4. **在原字符串上直接修改** → 念的同时把结果写回 `cur`，会覆盖掉还没读的部分。必须写到新的缓冲区里。
5. **返回字符串常量后又 `free` 它** → 例如 `char* cur = "1"; ... free(cur);` ❌ 字符串常量不是 `malloc` 来的，`free` 会崩溃。所以第 1 项也要 `malloc` 后 `strcpy`。
6. **内层循环条件写成 `cur[j] == cur[i] && j < len`** → 顺序反了，虽然这里 `cur[len]` 是 `'\0'` 恰好不会出错，但养成"先判断下标再访问"的习惯。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 特点 |
|---|---|---|---|---|
| 递归 | O(总长度) | O(L + n) | ⭐⭐ | 和定义一一对应，好理解 |
| 迭代 | O(总长度) | O(L) | ⭐⭐ | 没有递归开销，满足进阶要求 |

> 🎯 **学习建议**：本题的核心是"分段统计"那个 `while` 循环（`i` 指段首、`j` 找段尾），它在很多字符串题里都会出现，一定要写熟。
