单片机的中断控制器里有一个 32 位的 **中断挂起寄存器**（pending register）：第 `i` 位为 `1` 表示第 `i` 号中断源有请求正在等待处理。很多芯片约定 **编号越小、优先级越高**，所以中断分发程序每次都要找出 **最低的那个为 `1` 的位**，先处理它对应的中断。同样的操作也出现在 DMA 通道分配（找第一个空闲通道）、RTOS 就绪表（找优先级最高的就绪任务）等场景中。

给定挂起寄存器的值 `pending`，请返回其中 **最低的值为 `1` 的位的位号**。如果没有任何位为 `1`（没有中断挂起），返回 `-1`。

位号从 `0` 开始：第 `0` 位是最低位（LSB），第 `31` 位是最高位（MSB）。

### 示例 1

```
输入：pending = 12
输出：2
解释：12 = 0b1100，第 2、3 号中断挂起，编号最小的是 2。
```

### 示例 2

```
输入：pending = 2147483648
输出：31
解释：0x80000000 只有第 31 位为 1。
```

### 示例 3

```
输入：pending = 0
输出：-1
解释：没有任何中断挂起。
```

### 提示

- `0 <= pending <= 2^32 - 1`

### 函数说明

```c
int lowest_set_bit(uint32_t pending);
```

- `pending`：中断挂起寄存器的值
- 返回值：最低的为 `1` 的位的位号（`0 ~ 31`）；`pending == 0` 时返回 `-1`

### 自定义输入格式

```
12
```

输入一行，为十进制整数 `pending`。输出为位号（十进制）。
