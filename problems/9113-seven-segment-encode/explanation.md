# 七段数码管段码：题解

## 📖 先读懂题目

digit为0..9。位0..6依次表示a,b,c,d,e,f,g，不含小数点；commonAnode=0使用高电平点亮，=1使用低电平点亮，位7始终0。返回段码。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `0 / 0` | `63` |
| 2 | `0 / 1` | `64` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

先查共阴极的高电平点亮表，共阳极只反转有效7个位，不反转未使用的最高位。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int sevenSegment(int digit, int commonAnode) {
    static const uint8_t table[10] = {0x3f, 0x06, 0x5b, 0x4f, 0x66, 0x6d, 0x7d, 0x07, 0x7f, 0x6f};
    return commonAnode ? (table[digit] ^ 0x7f) : table[digit];
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
