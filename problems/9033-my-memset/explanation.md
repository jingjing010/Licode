# 9033. 实现 memset —— 小白详细题解

> `memset(buf, 0, sizeof(buf))` 几乎是每个嵌入式工程师写的第一行"内存操作"。它看起来简单，但藏着两个面试常考点：**`c` 为什么是 `int` 却只用低 8 位？** 以及 **`memset(arr, 1, sizeof(arr))` 能不能把 int 数组全设成 1？** 这道题一并讲清楚。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 从地址 `s` 开始，连续 `n` 个字节，全部写成同一个值 `(unsigned char)c`，然后把 `s` 原样还回去。

拿示例 1 来说（`buf = [1,2,3,4,5,6]`，`offset = 1`，`c = 0`，`n = 3`）：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 填充前 | 1 | 2 | 3 | 4 | 5 | 6 |
| 填充范围 | | **s** | **s+1** | **s+2** | | |
| 填充后 | 1 | **0** | **0** | **0** | 5 | 6 |

**几个需要注意的细节：**

1. 写入的是 `c` 的**低 8 位**：`c = 300 = 0x12C` 写进去的是 `0x2C = 44`（示例 3）；`c = -1` 写进去的是 `0xFF = 255`。
2. `n` 是**字节数**，`n = 0` 时什么都不做。
3. 返回值是**原来的 `s`**，不是循环结束后的指针。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `void*` 转成 `unsigned char*`

`void*` 不能解引用、不能加减（9031 讲过），要按字节写内存就转成 `unsigned char*`：

```c
unsigned char* p = (unsigned char*)s;
```

### 2. `int` 转 `unsigned char`：只留低 8 位

C 语言规定：把一个整数转成无符号类型时，结果是"对 2^8 = 256 取模"，也就是**只保留低 8 位**：

| c | 十六进制 | `(unsigned char)c` |
|---|---|---|
| 0 | `0x00000000` | 0 |
| 300 | `0x0000012C` | `0x2C` = 44 |
| 256 | `0x00000100` | `0x00` = 0 |
| -1 | `0xFFFFFFFF` | `0xFF` = 255 |

> ❓ **那为什么标准库要把 `c` 定义成 `int`？** 历史原因：早期 C 语言没有函数原型时，`char` 参数会被自动提升成 `int` 传递。为了兼容，这个签名一直保留到现在。

### 3. 经典陷阱：memset 只能按字节填

```c
int a[4];
memset(a, 1, sizeof(a));   // ❌ 以为 a 变成 {1,1,1,1}
```

每个**字节**都变成了 `0x01`，一个 `int` 有 4 个字节，所以每个元素是 `0x01010101 = 16843009`！memset 只适合填 `0`（所有字节为 0 → 整数 0）和 `-1`/`0xFF`（所有字节为 0xFF → 整数 -1）。

---

## 💡 第三步：思路一 —— 逐字节填充（面试标准答案）

### 思路

1. 把 `s` 转成 `unsigned char* p`，把 `c` 转成 `unsigned char v`
2. 循环 `n` 次，`*p++ = v`
3. 返回原始的 `s`

### 手动模拟（示例 3：`buf = [7,7,7]`，`c = 300`，`n = 2`）

| 第几轮 | 进入时 n | 操作 | buf |
|---|---|---|---|
| — | — | `v = (unsigned char)300 = 44` | [7,7,7] |
| 1 | 2 | buf[0] = 44 | [44,7,7] |
| 2 | 1 | buf[1] = 44 | [44,44,7] |
| — | 0 | 退出循环，返回 s | |

### 代码

```c
void* my_memset(void* s, int c, size_t n) {
    // 1. 按字节访问内存
    unsigned char* p = (unsigned char*)s;
    // 2. 只取 c 的低 8 位
    unsigned char v = (unsigned char)c;

    // 3. 循环 n 次，每次写一个字节
    while (n--) {
        *p++ = v;
    }
    // 4. 返回原始的 s（p 已经移动到末尾了）
    return s;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个字节写一次。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 按字（4 字节）填充（进阶）

### 思路

32 位 MCU 一次能写 4 个字节，逐字节写浪费带宽。可以先造一个"4 个字节都是 `v`"的字：

```
v    = 0x2C
word = 0x2C2C2C2C = v * 0x01010101
```

然后像 9031 思路二一样分三段：

1. **头部**：逐字节写，直到 `p` 的地址是 4 的倍数（避免非对齐访问，Cortex-M0 上会 HardFault）
2. **中间**：每次写一个 `uint32_t`
3. **尾部**：剩下不足 4 字节的逐字节写

和 memcpy 不同，memset 只有**一个**指针，所以只要它对齐就一定能按字写。

### 代码

```c
void* my_memset(void* s, int c, size_t n) {
    unsigned char* p = (unsigned char*)s;
    unsigned char v = (unsigned char)c;

    // 1. 头部：逐字节写，直到 p 对齐到 4 字节边界
    while (n > 0 && ((uintptr_t)p & 3) != 0) {
        *p++ = v;
        n--;
    }

    // 2. 中间：把 v 复制到 4 个字节里，每次写一个字
    uint32_t word = (uint32_t)v * 0x01010101u;
    uint32_t* pw = (uint32_t*)p;
    while (n >= 4) {
        *pw++ = word;
        n -= 4;
    }

    // 3. 尾部：剩下的逐字节写
    p = (unsigned char*)pw;
    while (n--) {
        *p++ = v;
    }
    return s;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，但常数约为思路一的 1/4。
- **空间复杂度 O(1)**。

## 🔌 嵌入式实战

```c
uint8_t  rx_buf[128];
uint16_t frame_buf[320];          // 一行 RGB565 像素

memset(rx_buf, 0, sizeof(rx_buf));          // 清空接收缓冲区：最常见的用法
memset(page_buf, 0xFF, FLASH_PAGE_SIZE);    // Flash 擦除后全是 0xFF，未写入的部分保持 0xFF
// 想把一行像素填成红色 0xF800？memset 做不到（它只能填相同的字节），要自己写循环
for (int i = 0; i < 320; i++) frame_buf[i] = 0xF800;
```

另一个安全相关的用法：用完密钥后用 memset 清零。但编译器发现"清零之后再也没读过这块内存"时，可能**把 memset 整个优化掉**！所以安全代码里会用 `volatile` 指针来写，或者使用 `memset_s` / `explicit_bzero`。

## ⚠️ 第五步：小白常见错误

1. **忘记截断 `c`**：用 `int* p` 去写，或者把 `c` 当成 4 字节写入，会把相邻的字节一起改掉，甚至写出 `buf` 边界。
2. **用 `char` 存 `v` 然后比较/打印**：`char` 在 x86 上有符号，`0xFF` 会变成 `-1`。处理原始字节一律用 `unsigned char` / `uint8_t`。
3. **返回了移动后的指针**：`return p;` 是错的，判题会提示"返回值必须是 s"。
4. **以为能用 memset 填 int**：`memset(a, 1, sizeof(a))` 得到的是 `16843009` 而不是 `1`。
5. **`sizeof` 用在指针上**：

   ```c
   void clear(uint8_t* buf) {
       memset(buf, 0, sizeof(buf));   // ❌ sizeof(buf) 是指针大小（4 或 8），不是数组大小
   }
   ```

   数组作为参数传进函数后就退化成指针了，长度必须单独传进来。
6. **按字填充时不先对齐**：直接 `*(uint32_t*)p = word`，`p` 不是 4 的倍数时在部分 MCU 上会 HardFault。

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐字节填充 | O(n) | O(1) | ⭐ | 面试先写这个 |
| 按字填充 | O(n)，约快 4 倍 | O(1) | ⭐⭐ | 追问"怎么优化"时回答 |

> 🎯 **学习建议**：把 `memset(a, 1, sizeof(a))` 这个坑在纸上画一遍字节布局，你就再也不会写错了。
