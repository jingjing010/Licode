给你链表的头节点 `head` ，每 `k` 个节点一组进行翻转，请你返回修改后的链表。

`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。

你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。

### 示例 1

```
1 -> 2 -> 3 -> 4 -> 5
  k = 2
2 -> 1 -> 4 -> 3 -> 5
```

```
输入：head = [1,2,3,4,5], k = 2
输出：[2,1,4,3,5]
```

### 示例 2

```
1 -> 2 -> 3 -> 4 -> 5
  k = 3
3 -> 2 -> 1 -> 4 -> 5
```

```
输入：head = [1,2,3,4,5], k = 3
输出：[3,2,1,4,5]
```

### 提示

- 链表中的节点数目为 `n`
- `1 <= k <= n <= 5000`
- `0 <= Node.val <= 1000`

**进阶：** 你可以设计一个只用 `O(1)` 额外内存空间的算法解决此问题吗？

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* reverseKGroup(struct ListNode* head, int k);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `head`：链表的头指针（至少 1 个结点）
- `k`：每组的结点个数，`1 <= k <= 链表长度`
- 返回值：翻转后链表的头指针
- **只能通过修改 `next` 来调整结点**，不能修改结点的 `val`，也不能 `malloc` 新结点代替原结点（判题程序会检查）

### 自定义输入格式

```
[1,2,3,4,5]
2
```

第 1 行是链表 `head`，第 2 行是整数 `k`。输出为翻转后的链表；如果修改了结点的值、使用了新结点或丢失了结点，会输出错误提示。
