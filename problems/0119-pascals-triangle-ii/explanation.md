# 119. 杨辉三角 II —— 小白详细题解

> 杨辉三角是学习"递推"（动态规划的雏形）最直观的例子。这道题还能教会你一个常用技巧：**倒序更新一维数组**。

---

## 📖 第一步：先读懂题目

杨辉三角长这样（行号从 **0** 开始）：

| 行号 | 内容 |
|---|---|
| 0 | 1 |
| 1 | 1 1 |
| 2 | 1 2 1 |
| 3 | 1 3 3 1 |
| 4 | 1 4 6 4 1 |

规律：

1. 第 `i` 行有 `i + 1` 个数；
2. 每行**两端都是 1**；
3. 中间的数 = 上一行**左上方** + **右上方**。比如第 4 行的 6 = 第 3 行的 3 + 3。

题目只要你返回**某一行**，比如 `rowIndex = 3` 返回 `[1,3,3,1]`。

**几个需要注意的细节：**

1. 行号从 0 开始，`rowIndex = 0` 返回 `[1]`。
2. 返回数组长度是 `rowIndex + 1`，要写进 `*returnSize`。
3. `rowIndex` 最大 33，第 33 行最大的数是 1166803110，还在 `int` 范围内（`int` 最大约 2.1×10⁹）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回数组：`malloc` + `*returnSize`

```c
int* row = (int*)malloc(sizeof(int) * (rowIndex + 1));   // 申请 rowIndex+1 个 int
*returnSize = rowIndex + 1;                               // 告诉调用者长度
return row;
```

### 2. 用下标表示"左上方"和"右上方"

把每一行左对齐来看：

```
第 3 行： 1 3 3 1
第 4 行： 1 4 6 4 1
```

第 4 行下标 `j` 的数 = 第 3 行下标 `j - 1` 的数 + 第 3 行下标 `j` 的数。所以递推式是：

```
cur[j] = prev[j - 1] + prev[j]     （1 <= j <= i - 1）
```

---

## 💡 第三步：思路一 —— 用两个数组一行一行推

### 思路

1. `prev` 存上一行，`cur` 存当前行。
2. 从第 1 行推到第 `rowIndex` 行：两端填 1，中间用递推式。
3. 每推完一行，把 `cur` 抄回 `prev`。

### 手动模拟（`rowIndex = 3`）

| 第 i 行 | prev（上一行） | cur 的计算 | cur |
|---|---|---|---|
| 1 | [1] | 两端为 1 | [1,1] |
| 2 | [1,1] | cur[1] = 1+1 | [1,2,1] |
| 3 | [1,2,1] | cur[1] = 1+2，cur[2] = 2+1 | [1,3,3,1] |

### 代码

```c
int* getRow(int rowIndex, int* returnSize) {
    int* prev = (int*)malloc(sizeof(int) * (rowIndex + 1));   // 上一行
    int* cur  = (int*)malloc(sizeof(int) * (rowIndex + 1));   // 当前行
    prev[0] = 1;                                // 第 0 行只有一个 1
    cur[0] = 1;

    for (int i = 1; i <= rowIndex; i++) {       // 依次推出第 1 行 ~ 第 rowIndex 行
        cur[0] = 1;                             // 左端
        cur[i] = 1;                             // 右端
        for (int j = 1; j < i; j++) {
            cur[j] = prev[j - 1] + prev[j];     // 左上 + 右上
        }
        for (int j = 0; j <= i; j++) {          // 当前行变成下一轮的"上一行"
            prev[j] = cur[j];
        }
    }

    free(cur);                                  // cur 用完了，释放
    *returnSize = rowIndex + 1;
    return prev;                                // 最后一轮后 prev 就是第 rowIndex 行
}
```

### 复杂度分析

- **时间复杂度 O(rowIndex²)**：一共推 rowIndex 行，每行 O(rowIndex)。
- **空间复杂度 O(rowIndex)**：两个数组（其中一个是返回值）。

---

## 🚀 第四步：思路二 —— 一个数组，从右往左更新（进阶）

### 思路

能不能只用一个数组 `row`，**原地**把上一行变成下一行？

如果从左往右更新 `row[j] = row[j - 1] + row[j]`，算 `row[j]` 时 `row[j - 1]` **已经被改成新值**了，结果就错了。

**从右往左**更新就没问题：算 `row[j]` 时，左边的 `row[j - 1]` 还没被动过，仍然是上一行的值。

### 手动模拟（由第 3 行 `[1,3,3,1]` 推第 4 行）

| 步骤 | 操作 | row |
|---|---|---|
| 0 | 末尾补一个 1 | [1,3,3,1,**1**] |
| 1 | j=3：row[3] = row[3] + row[2] = 1+3 | [1,3,3,**4**,1] |
| 2 | j=2：row[2] = row[2] + row[1] = 3+3 | [1,3,**6**,4,1] |
| 3 | j=1：row[1] = row[1] + row[0] = 3+1 | [1,**4**,6,4,1] |

> 对比：如果从左往右，j=1 时 row[1] 变成 4，到 j=2 时就成了 3+4=7，错了！

### 代码

```c
int* getRow(int rowIndex, int* returnSize) {
    int* row = (int*)malloc(sizeof(int) * (rowIndex + 1));
    row[0] = 1;                                 // 第 0 行

    for (int i = 1; i <= rowIndex; i++) {       // 把第 i-1 行原地变成第 i 行
        row[i] = 1;                             // 新行多出来的最右端
        for (int j = i - 1; j >= 1; j--) {      // 从右往左！保证 row[j-1] 还是旧值
            row[j] += row[j - 1];               // 等价于 row[j] = 旧row[j] + 旧row[j-1]
        }
    }

    *returnSize = rowIndex + 1;
    return row;
}
```

### 复杂度分析

- **时间复杂度 O(rowIndex²)**。
- **空间复杂度 O(rowIndex)**：只有一个数组（就是返回值本身），满足进阶要求。

---

## ⚠️ 第五步：小白常见错误

1. **一维数组从左往右更新** → 用到的 `row[j-1]` 已经是新值，第 3 行会得到 `[1,3,4,1]` 之类的错误结果。
2. **数组只申请了 `rowIndex` 个** → 第 `rowIndex` 行有 `rowIndex + 1` 个数，最后一个写入会越界。
3. **`rowIndex = 0` 时没有返回 `[1]`** → 例如循环从 `i = 0` 开始写了 `row[i - 1]`，访问了 `row[-1]`。
4. **忘记设置 `*returnSize`** → 判题程序拿到长度 0，输出 `[]`。
5. **用组合数公式时直接算阶乘** → `33!` 远超 `long long`，必然溢出（见下方"举一反三"的正确做法）。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 两个数组逐行推 | O(rowIndex²) | O(rowIndex) | ⭐ | 最直观 |
| 一个数组倒序更新 | O(rowIndex²) | O(rowIndex) | ⭐⭐ | 更省内存，"倒序更新"是 01 背包的核心技巧 |

---

## 🔗 举一反三

- **118. 杨辉三角**：返回前 `numRows` 行，需要返回二维数组（`int**` + `returnColumnSizes`）。
- **组合数公式（O(rowIndex) 时间）**：第 `n` 行第 `k` 个数是组合数 C(n, k)，并且 `C(n, k) = C(n, k-1) × (n - k + 1) / k`。用 `long long` 计算乘法再除，就能一个循环得到整行，不需要阶乘。
