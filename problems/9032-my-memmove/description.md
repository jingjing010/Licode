`memcpy` 要求源和目标内存**不重叠**，而 `memmove` 没有这个限制：即使两段内存有重叠，也要保证复制结果**和"先把源数据完整拍一张快照、再贴到目标位置"完全一样**。
嵌入式中常见的用法是在环形缓冲区 / 协议缓冲区里把未处理的数据整体前移或后移。

请你实现 `my_memmove(dst, src, n)`：把从 `src` 开始的 `n` 个字节复制到 `dst`，**两段内存可能重叠**，返回 `dst`。

> **不要调用库函数 `memmove` / `memcpy`**，请自己用指针完成。

为了测试重叠，判题程序只准备**一个**缓冲区 `buf`，然后调用 `my_memmove(buf + dstOffset, buf + srcOffset, n)`，最后输出整个 `buf`。

### 示例 1

```
输入：buf = [1,2,3,4,5,6,7,8], dstOffset = 2, srcOffset = 0, n = 5
输出：[1,2,1,2,3,4,5,8]
解释：把 buf[0..4] = 1,2,3,4,5 搬到 buf[2..6]。dst 在 src 后面且有重叠。
     如果从前往后逐字节复制，会得到错误的 [1,2,1,2,1,2,1,8]。
```

### 示例 2

```
输入：buf = [1,2,3,4,5,6,7,8], dstOffset = 0, srcOffset = 3, n = 5
输出：[4,5,6,7,8,6,7,8]
解释：把 buf[3..7] = 4,5,6,7,8 搬到 buf[0..4]，dst 在 src 前面。
```

### 示例 3

```
输入：buf = [10,20,30], dstOffset = 1, srcOffset = 1, n = 2
输出：[10,20,30]
解释：源和目标是同一块内存，内容不变。
```

### 提示

- `1 <= buf.length <= 10^5`
- `0 <= buf[i] <= 255`
- `0 <= n`，`0 <= dstOffset`，`0 <= srcOffset`
- `dstOffset + n <= buf.length`，`srcOffset + n <= buf.length`

### 函数说明

```c
void* my_memmove(void* dst, const void* src, size_t n);
```

- `dst`：目标首地址，`src`：源首地址，两者指向的区域可能重叠
- `n`：要复制的字节数
- 返回值：必须返回 `dst`

`buf` 前后各有一段"哨兵"内存。如果返回值不是 `dst`，或写到了 `buf` 之外，会输出一行错误信息（判为答案错误）。

### 自定义输入格式

```
[1,2,3,4,5,6,7,8]
2
0
5
```

第 1 行是 `buf` 的字节内容，第 2 行是 `dstOffset`，第 3 行是 `srcOffset`，第 4 行是 `n`。输出为调用后的整个 `buf`。
