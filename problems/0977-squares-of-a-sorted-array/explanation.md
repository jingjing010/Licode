# 977. 有序数组的平方 —— 小白详细题解

> 本来有序的数组，平方之后为什么会乱？因为**负数**。理解了这一点，双指针就呼之欲出了。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把每个数平方，然后从小到大排好返回。

拿示例 1 来说：`nums = [-4,-1,0,3,10]`

| 原数 | -4 | -1 | 0 | 3 | 10 |
|---|---|---|---|---|---|
| 平方 | 16 | 1 | 0 | 9 | 100 |

平方后是 `[16,1,0,9,100]`，不再有序了；排序后 `[0,1,9,16,100]`。

**关键观察：**

1. 如果全是非负数，平方后顺序不变。
2. 负数越"小"（比如 -4 比 -1 小），平方反而越**大**。
3. 所以平方后，**最大值一定在原数组的两端**：要么是最左边（最小的负数），要么是最右边（最大的正数）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回新数组

```c
int* res = (int*)malloc(sizeof(int) * numsSize);   // 在堆上申请，函数结束后仍然有效
*returnSize = numsSize;                            // 告诉调用者长度
return res;
```

### 2. 平方会溢出吗？

`|nums[i]| <= 10^4`，平方最多 `10^8`，`int` 装得下。

### 3. `qsort` 比较函数

```c
int cmp(const void* a, const void* b) {
    int x = *(const int*)a, y = *(const int*)b;
    return (x > y) - (x < y);   // 升序
}
```

---

## 💡 第三步：思路一 —— 平方后直接排序

### 思路

1. 新建数组，把每个数的平方放进去。
2. 用 `qsort` 排序。

### 代码

```c
int cmp(const void* a, const void* b) {
    int x = *(const int*)a, y = *(const int*)b;
    return (x > y) - (x < y);
}

int* sortedSquares(int* nums, int numsSize, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * numsSize);
    for (int i = 0; i < numsSize; i++) {
        res[i] = nums[i] * nums[i];                  // 1. 逐个平方
    }
    qsort(res, numsSize, sizeof(int), cmp);          // 2. 排序
    *returnSize = numsSize;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n log n)**：排序。
- **空间复杂度 O(log n)**：排序的递归栈（不算返回数组）。

> 这个方法完全没用到"原数组有序"这个条件，所以有优化空间。

---

## 🚀 第四步：思路二 —— 左右双指针，从后往前填（O(n)）

### 思路

既然平方后的**最大值一定在两端**：

- `l` 指向最左端，`r` 指向最右端
- 比较 `nums[l]²` 和 `nums[r]²`，**较大的那个**就是当前剩余元素中最大的平方
- 把它放到结果数组的**最后一个空位**（从后往前填），然后移动对应的指针

重复 n 次，结果数组就从后往前填满了。

### 手动模拟（示例 1：`[-4,-1,0,3,10]`）

| pos | l（值²） | r（值²） | 较大者 | res |
|---|---|---|---|---|
| 4 | 0（16） | 4（100） | 100，r-- | [_,_,_,_,100] |
| 3 | 0（16） | 3（9） | 16，l++ | [_,_,_,16,100] |
| 2 | 1（1） | 3（9） | 9，r-- | [_,_,9,16,100] |
| 1 | 1（1） | 2（0） | 1，l++ | [_,1,9,16,100] |
| 0 | 2（0） | 2（0） | 0，r-- | [0,1,9,16,100] |

### 代码

```c
int* sortedSquares(int* nums, int numsSize, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * numsSize);
    int l = 0, r = numsSize - 1;               // 两端的指针
    // pos：结果数组中下一个要填的位置，从最后一个往前
    for (int pos = numsSize - 1; pos >= 0; pos--) {
        int a = nums[l] * nums[l];             // 左端的平方
        int b = nums[r] * nums[r];             // 右端的平方
        if (a > b) {
            res[pos] = a;                      // 左边的大，放到 pos
            l++;                               // 左指针右移
        } else {
            res[pos] = b;                      // 右边的大（或相等），放到 pos
            r--;                               // 右指针左移
        }
    }
    *returnSize = numsSize;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个元素只处理一次。
- **空间复杂度 O(1)**（不算返回数组）。

> ❓ **为什么从后往前填？** 因为两端能确定的是**最大值**，而不是最小值（最小的平方藏在中间，0 附近）。从大往小填，就要从结果数组的末尾开始。

---

## ⚠️ 第五步：小白常见错误

1. **以为平方后还是有序的，直接逐个平方返回** → 示例 1 会得到 `[16,1,0,9,100]`。
2. **双指针从前往后填，取两端较小的** → 两端的平方不一定是最小值！`[-4,-1,0,3,10]` 两端是 16 和 100，最小的 0 在中间。
3. **循环条件写成 `while (l < r)`** → 少处理一个元素（`l == r` 时那个），结果数组第 0 位是垃圾值。用 `pos` 从 `n-1` 到 `0` 循环最稳妥。
4. **忘记设置 `*returnSize`** → 输出为空。
5. **返回局部数组 `int res[10000];`** → 函数返回后内存失效，结果是乱码。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 平方 + 排序 | O(n log n) | O(log n) | ⭐ | 先写这个保证正确 |
| 双指针从后往前 | O(n) | O(1) | ⭐⭐ | 题目进阶要求，推荐 |
