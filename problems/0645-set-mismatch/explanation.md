# 错误的集合：题解

## 📖 先读懂题目

原集合包含1到n，某个值被替换成另一个值，造成一个重复和一个缺失。返回[重复值,缺失值]。2 ≤ n ≤ 10^4。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[1,2,2,4]` | `[2,3]` |
| 2 | `[1,1]` | `[1,2]` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

数值应该各出现一次，用计数表分别找出现两次与零次的值。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *findErrorNums(int *nums, int numsSize, int *returnSize) {
    int *counts = calloc(numsSize + 1, sizeof(int)), *out = malloc(2 * sizeof(int));
    for (int i = 0; i < numsSize; ++i)
        ++counts[nums[i]];
    for (int x = 1; x <= numsSize; ++x) {
        if (counts[x] == 2)
            out[0] = x;
        if (counts[x] == 0)
            out[1] = x;
    }
    free(counts);
    *returnSize = 2;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
