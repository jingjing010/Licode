**Modbus RTU** 是工业现场（PLC、变频器、电表、温控器）最常见的串口通信协议，每一帧的最后两个字节都是 **CRC-16/MODBUS** 校验值。

请实现 CRC-16/MODBUS，参数如下：

| 参数 | 值 |
|---|---|
| 宽度 | 16 位 |
| 多项式 Poly | `0x8005`（x¹⁶ + x¹⁵ + x² + 1）；因为输入反射，代码中使用按位倒序后的 `0xA001` |
| 初值 Init | `0xFFFF` |
| 输入反射 RefIn | 是（每个字节从**最低位**开始处理） |
| 输出反射 RefOut | 是 |
| 结果异或 XorOut | `0x0000` |
| 标准校验值 Check | 字符串 `"123456789"` 的 CRC 为 `0x4B37`（十进制 19255） |

计算过程（逐位法）：`crc = 0xFFFF`；对每个字节 `b`，先 `crc ^= b`，再重复 8 次：如果 `crc` 的最低位为 1，则 `crc = (crc >> 1) ^ 0xA001`，否则 `crc = crc >> 1`。处理完所有字节后的 `crc` 就是结果。

给你一段数据 `buf`（长度 `len`），返回它的 CRC-16/MODBUS 值。

> 发送时 Modbus 把 CRC 的**低字节在前、高字节在后**附加到帧尾，例如 CRC 为 `0x0A84` 时依次发送 `0x84`、`0x0A`。本题只需返回 16 位的 CRC 值本身。

### 示例 1

```
输入：buf = [49,50,51,52,53,54,55,56,57]
输出：19255
解释：ASCII 字符串 "123456789" 的标准校验值 0x4B37 = 19255。
```

### 示例 2

```
输入：buf = [1,3,0,0,0,1]
输出：2692
解释：这是一个真实的 Modbus 请求"读 1 号从机、地址 0 开始的 1 个保持寄存器"，
     CRC = 0x0A84 = 2692，完整帧为 01 03 00 00 00 01 84 0A。
```

### 示例 3

```
输入：buf = []
输出：65535
解释：没有数据，结果就是初值 0xFFFF。
```

### 提示

- `0 <= len <= 10^5`
- `0 <= buf[i] <= 255`

### 函数说明

```c
uint16_t crc16Modbus(const uint8_t* buf, size_t len);
```

### 自定义输入格式

```
[1,3,0,0,0,1]
```

一行，数据的每个字节（十进制）。输出 CRC 值（十进制）。
