# 290. 单词规律 —— 小白详细题解

> 这是「205. 同构字符串」的升级版：一边是字母，另一边变成了**单词**。难点从"映射"转移到了**C 语言里怎么切分和比较单词**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> `pattern` 的每个字母代表一个单词。同一个字母必须始终代表同一个单词，不同的字母必须代表不同的单词。问 `s` 是否符合这个"模板"。

拿示例 1 来说：

| 位置 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| pattern | a | b | b | a |
| 单词 | dog | cat | cat | dog |

`a ↔ dog`，`b ↔ cat`，处处一致 → `true`。

- 示例 2：位置 3 的 `a` 对应 `fish`，但 `a` 之前已经对应 `dog` → `false`。
- 示例 3：`a` 先对应 `dog`，位置 1 又对应 `cat` → `false`。

**几个需要注意的细节：**

1. **两个方向都要一一对应**：`pattern = "ab"`，`s = "dog dog"` 是 `false`，因为两个不同字母对应了同一个单词。
2. **单词个数可能和 `pattern` 长度不同**：`"aa"` 和 `"dog"`、`"a"` 和 `"dog dog"` 都是 `false`。
3. 单词比较要**完整比较**：`"dog"` 和 `"do"` 是不同的单词。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 原地切分字符串

`s` 形如 `"dog cat cat dog"`。把每个空格**改成 `'\0'`**，原字符串就被切成了几个独立的小字符串，每个单词的开头地址就是一个 `char*`：

```
修改前： d o g ␣ c a t ␣ c a t ␣ d o g \0
修改后： d o g \0 c a t \0 c a t \0 d o g \0
         ↑        ↑        ↑        ↑
       words[0] words[1] words[2] words[3]
```

这样不用额外申请内存来存单词。

### 2. 比较字符串用 `strcmp`

```c
if (w1 == w2)              // ❌ 比较的是两个地址，不是内容
if (strcmp(w1, w2) == 0)   // ✅ 内容相同时返回 0
```

### 3. 指针数组

```c
char* word[26] = {0};   // 26 个 char* 指针，初始全是 NULL
word['b' - 'a'] = w;    // 记下字母 b 对应的单词
```

## 💡 第三步：思路一 —— 切分后两两比较

### 思路

1. 把 `s` 切成单词数组 `words[]`，个数和 `pattern` 长度不同就直接返回 `false`；
2. "一一对应"等价于：对任意两个位置 `i`、`j`，

> `pattern[i] == pattern[j]` 当且仅当 `words[i]` 和 `words[j]` 相同。

两两检查即可。`pattern` 最长 300，最多 300 × 300 = 9 万次比较，完全没问题。

### 代码

```c
bool wordPattern(char* pattern, char* s) {
    int n = strlen(pattern);
    char* words[3000];                     // 最多 1500 个单词，开大一点更安全
    int cnt = 0;

    // 1. 原地切分：把空格改成 '\0'，记录每个单词的起始地址
    char* p = s;
    while (*p != '\0') {
        words[cnt++] = p;                  // 一个单词的开头
        while (*p != '\0' && *p != ' ') p++;
        if (*p == ' ') {
            *p = '\0';                     // 切断
            p++;                           // 跳到下一个单词
        }
    }
    if (cnt != n) return false;            // 单词个数和字母个数不同

    // 2. 两两检查："字母相同" 必须和 "单词相同" 同时成立或同时不成立
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            bool sameLetter = (pattern[i] == pattern[j]);
            bool sameWord = (strcmp(words[i], words[j]) == 0);
            if (sameLetter != sameWord) return false;
        }
    }
    return true;
}
```

### 复杂度分析

- **时间复杂度 O(n² × L)**：n 为单词数，L 为单词长度（`strcmp` 的代价）。
- **空间复杂度 O(n)**：单词指针数组。

## 🚀 第四步：思路二 —— 字母→单词映射表 + 反向检查

### 思路

和 205 题一样建立映射。字母只有 26 个，所以用 `word[26]` 记录"每个字母对应哪个单词"：

- 字母**已有**单词：当前单词必须和它相同；
- 字母**还没有**单词：检查当前单词是否已经被**别的字母**占用（最多和 26 个单词比一比），没被占用才能建立映射。

边切分边检查，最后还要确认：`pattern` 用完时 `s` 也正好用完。

### 手动模拟（`pattern = "abba"`，`s = "dog dog dog dog"`）

| i | 字母 | 单词 | word[字母] | 操作 |
|---|---|---|---|---|
| 0 | a | dog | 空 | 没有字母占用 dog → word[a] = dog |
| 1 | b | dog | 空 | dog 已被 a 占用 → 返回 false |

### 代码

```c
bool wordPattern(char* pattern, char* s) {
    char* word[26] = {0};                  // word[c]：字母 c 对应的单词，NULL 表示还没有
    int plen = strlen(pattern);
    char* p = s;                           // 在 s 上移动的指针

    for (int i = 0; i < plen; i++) {
        if (*p == '\0') return false;      // 单词不够用了

        // 1. 切出一个单词 w
        char* w = p;
        while (*p != '\0' && *p != ' ') p++;
        if (*p == ' ') {
            *p = '\0';
            p++;
        }

        // 2. 检查映射
        int c = pattern[i] - 'a';
        if (word[c] == NULL) {
            // 新字母：它的单词不能已经属于别的字母
            for (int k = 0; k < 26; k++) {
                if (word[k] != NULL && strcmp(word[k], w) == 0) return false;
            }
            word[c] = w;
        } else if (strcmp(word[c], w) != 0) {
            return false;                  // 同一个字母对应了不同单词
        }
    }
    return *p == '\0';                     // pattern 用完时，s 也必须正好用完
}
```

### 复杂度分析

- **时间复杂度 O(n × 26 × L)**，即 O(n × L)：每个字母第一次出现时最多比较 26 次，其余只比较 1 次。
- **空间复杂度 O(1)**：只有 26 个指针（原地切分没有额外拷贝）。

---

## ⚠️ 第五步：小白常见错误

1. **用 `==` 比较单词** ❌ → `word[c] == w` 比较的是地址，两个内容相同的单词在不同位置，地址不同，永远不相等。必须用 `strcmp`。
2. **只检查字母 → 单词** → `"ab"` 和 `"dog dog"` 会被误判为 `true`，要检查单词是否被别的字母占了。
3. **没检查单词个数** → `"a"` 和 `"dog cat"`：只循环 `pattern` 的长度，会漏掉多出来的 `cat`。思路二最后的 `*p == '\0'` 就是检查这个。
4. **单词不够时越界** → `"aaaa"` 和 `"dog"`：第二轮时 `p` 已经在结尾，必须先判断 `*p == '\0'` 返回 `false`。
5. **只比较单词首字母或长度** → `"dog"` 和 `"dot"` 首字母、长度都相同，但不是同一个单词。
6. **用 `strtok` 切分但不熟悉它** → `strtok` 会修改原串并有内部状态，第一次传 `s`、之后传 `NULL`，写错很容易死循环。手写切分更可控。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 特点 |
|---|---|---|---|---|
| 切分后两两比较 | O(n² L) | O(n) | ⭐ | 逻辑最简单，n 小时够用 |
| 映射表 + 反向检查 | O(n L) | O(1) | ⭐⭐ | 边切边查，可提前结束 |

> 🎯 **学习建议**：本题的精华是"**原地把空格改成 `'\0'` 来切分字符串**"，这是 C 语言处理文本的常用技巧。
