# DS18B20 原始温度转换

输入已按小端字节组装的16位raw，温度在−55..125℃，12位分辨率、无故障码。返回毫摄氏度，半毫单位向零截断。不包含CRC验证。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int ds18b20MilliC(int raw);
```

## 示例 1

输入：
```text
400
```
输出：
```text
25000
```

## 示例 2

输入：
```text
65376
```
输出：
```text
-10000
```

## 自定义输入格式

按顺序每行一个参数：raw。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
