# 389. 找不同 —— 小白详细题解

> `t` 比 `s` 多了一个字母，把它找出来。这道题能用三种方法做：**计数数组、求和相减、异或抵消**。后两种都只需要一个变量，异或法和 136 题"只出现一次的数字"是同一个思想。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把 `s` 的字母打乱顺序，再随便塞进去一个字母，就得到了 `t`。问塞进去的是哪个字母？

拿示例 1 来说：`s = "abcd"`，`t = "abcde"`，多出来的是 `'e'`。

**几个需要注意的细节：**

1. **`t` 被打乱了顺序**：不能逐位置比较 `s[i]` 和 `t[i]`。比如 `s = "ab"`，`t = "bca"`，第 0 位就不一样，但多出来的是 `'c'`。
2. **多出来的字母可能是 `s` 里已有的**：比如 `s = "a"`，`t = "aa"`，答案是 `'a'`。所以不能只判断"某个字母在 `s` 里有没有出现"，要看**出现次数**。
3. **`s` 可以是空串**（示例 2）。
4. 返回值是 `char`，不是字符串。

---

## 🧰 第二步：需要的 C 语言知识

### 1. 遍历以 `'\0'` 结尾的字符串

```c
for (int i = 0; s[i] != '\0'; i++) {
    char c = s[i];
}
```

C 语言的字符串没有"长度"属性，靠末尾的 `'\0'` 判断结束。

### 2. 字符就是整数

`'a'` 的 ASCII 码是 97，`'b'` 是 98……所以：

- `c - 'a'` 把字母变成 `0 ~ 25`，可以当数组下标；
- 字符可以直接相加、相减、异或。

### 3. 计数数组

```c
int cnt[26] = {0};    // 26 个格子，全部初始化为 0
cnt[c - 'a']++;       // 字母 c 出现一次
```

---

## 💡 第三步：思路一 —— 计数数组

### 思路

1. 遍历 `s`，统计每个字母出现的次数；
2. 遍历 `t`，每遇到一个字母就把它的次数减 1；
3. 如果某个字母减完变成了 **负数**，说明 `t` 里它比 `s` 多，它就是答案。

### 手动模拟（`s = "abc"`，`t = "cbaa"`）

| 步骤 | 字母 | cnt[a] | cnt[b] | cnt[c] |
|---|---|---|---|---|
| 统计 s 后 | | 1 | 1 | 1 |
| t[0] | c | 1 | 1 | 0 |
| t[1] | b | 1 | 0 | 0 |
| t[2] | a | 0 | 0 | 0 |
| t[3] | a | **-1** ← 负了！ | 0 | 0 |

答案是 `'a'`。

### 代码

```c
char findTheDifference(char* s, char* t) {
    int cnt[26] = {0};                     // 每个字母出现的次数
    for (int i = 0; s[i] != '\0'; i++) {
        cnt[s[i] - 'a']++;                 // 统计 s
    }
    for (int i = 0; t[i] != '\0'; i++) {
        cnt[t[i] - 'a']--;                 // t 里出现一次就减一次
        if (cnt[t[i] - 'a'] < 0) {         // 减成负数：t 比 s 多了这个字母
            return t[i];
        }
    }
    return ' ';                            // 题目保证有答案，不会走到这里
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两次遍历。
- **空间复杂度 O(26)**：计数数组。

---

## 🚀 第四步：思路二 —— 求和相减

### 思路

`t` 的字母 = `s` 的字母 + 多出来的那一个。所以：

> **`t` 所有字符的 ASCII 码之和 − `s` 所有字符的 ASCII 码之和 = 多出来的字符**

### 手动模拟（示例 1）

- `s = "abcd"`：97 + 98 + 99 + 100 = 394
- `t = "abcde"`：394 + 101 = 495
- 495 − 394 = 101 = `'e'`

### 代码

```c
char findTheDifference(char* s, char* t) {
    int sum = 0;                           // 用 int 累加，1001 个字母最多约 12 万，不会溢出
    for (int i = 0; t[i] != '\0'; i++) {
        sum += t[i];                       // 加上 t 的所有字符
    }
    for (int i = 0; s[i] != '\0'; i++) {
        sum -= s[i];                       // 减去 s 的所有字符
    }
    return (char)sum;                      // 剩下的就是多出来的字符
}
```

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**：只用一个变量。

---

## 🚀 思路三 —— 异或抵消

### 思路

把 `s` 和 `t` 的**所有字符**放在一起：除了多出来的那个，每个字母都出现了**偶数次**（`s` 里一次、`t` 里一次）。利用异或的性质：

- `x ^ x = 0`，`x ^ 0 = x`；
- 顺序无关。

全部异或起来，成对的都抵消了，剩下的就是答案。这和 136 题"只出现一次的数字"完全一样。

### 手动模拟（示例 1）

```
a ^ b ^ c ^ d   ^   a ^ b ^ c ^ d ^ e
= (a ^ a) ^ (b ^ b) ^ (c ^ c) ^ (d ^ d) ^ e
= 0 ^ 0 ^ 0 ^ 0 ^ e
= e
```

### 代码

```c
char findTheDifference(char* s, char* t) {
    char x = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        x ^= s[i];                         // 异或 s 的所有字符
    }
    for (int i = 0; t[i] != '\0'; i++) {
        x ^= t[i];                         // 再异或 t 的所有字符
    }
    return x;                              // 成对的都抵消了，剩下多出来的那个
}
```

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**。而且异或不会溢出，比求和法更"干净"。

---

## ⚠️ 第五步：小白常见错误

1. **逐位置比较 `s[i] != t[i]`**：`t` 被打乱了，第一个不同的位置不一定是多出来的字母。
2. **只看"有没有出现"**：`s = "a"`, `t = "aa"` 时，`a` 在 `s` 里出现过，但答案就是 `a`。要比较次数。
3. **计数数组没初始化**：`int cnt[26];` 里是随机值。要写 `int cnt[26] = {0};`。
4. **求和时用 `char` 累加**：`char sum` 最多到 127，加几个字母就溢出了。累加要用 `int`。
5. **用 `strlen(s)` 当循环条件**：`for (i = 0; i < strlen(s); i++)` 每次循环都重新数一遍长度，O(n²)。本题数据小能过，但这是坏习惯。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 计数数组 | O(n) | O(26) | ⭐ | 最通用，能扩展到"多了好几个字母" |
| 求和相减 | O(n) | O(1) | ⭐ | 最容易想到 |
| 异或抵消 | O(n) | O(1) | ⭐ | 不会溢出，位运算经典套路 |

## 🔗 举一反三

- **136. 只出现一次的数字**：同样是"全部异或，成对抵消"。
- **268. 丢失的数字**：把 `0 ~ n` 和数组元素一起异或，或者用求和相减。
- **242. 有效的字母异位词**：判断两个字符串的字母次数是否完全相同，用计数数组。
- **思考题**：如果 `t` 比 `s` 多了**两个**字母，哪种方法还能直接用？
