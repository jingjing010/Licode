给你一个字符串 `s`，请你将 `s` 分割成一些 子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

**回文串** 是向前和向后读都相同的字符串。

### 示例 1

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

### 示例 2

```
输入：s = "a"
输出：[["a"]]
```

### 提示

- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

### 函数说明

```c
char*** partition(char* s, int* returnSize, int** returnColumnSizes);
```

- `s`：以 `'\0'` 结尾的字符串
- 返回值：用 `malloc` 申请的「字符串数组的数组」：第 `i` 个元素是一种分割方案（一个 `char**`），方案里的每个子串也要 `malloc` 并以 `'\0'` 结尾
- `*returnSize`：写入分割方案的个数
- `*returnColumnSizes`：你需要 `malloc` 一个长度为方案数的 `int` 数组，第 `i` 个元素写第 `i` 种方案切成了几段，再把它的地址赋给 `*returnColumnSizes`

### 自定义输入格式

```
"aab"
```

只有 1 行：带双引号的字符串 `s`。（方案之间的顺序任意：判题时会把所有方案按字典序排序后输出；每种方案内部的子串必须按它们在 `s` 中的先后顺序排列）
