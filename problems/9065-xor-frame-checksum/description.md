# 帧异或校验字节

返回所有输入字节的按位异或；空输入返回0。输入0到1024字节。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int xorChecksum(const uint8_t* data,size_t len);
```

## 示例 1

输入：
```text
[49,50,51,52,53,54,55,56,57]
```
输出：
```text
49
```

## 示例 2

输入：
```text
[]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
