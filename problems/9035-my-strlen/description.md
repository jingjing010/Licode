C 语言的字符串就是一串以 `'\0'`（值为 0 的字节）结尾的字符，**本身不记录长度**。要知道它有多长，只能从头数到 `'\0'`。串口打印、拼接 AT 指令、计算报文长度……嵌入式里处处都要用到 `strlen`。

请你实现 `my_strlen(s)`：返回字符串 `s` 中 `'\0'` **之前**的字节数。

> **不要调用库函数 `strlen`**，请自己用指针完成。

注意：`strlen` 统计的是**字节数**，不是"字"数。中文在 UTF-8 编码下每个字占 3 个字节。

### 示例 1

```
输入：s = "hello"
输出：5
```

### 示例 2

```
输入：s = ""
输出：0
解释：空串只有一个 '\0'，长度为 0。
```

### 示例 3

```
输入：s = "温度:25C"
输出：10
解释："温"、"度"各占 3 个字节，":25C" 占 4 个字节，共 3 + 3 + 4 = 10。
```

### 提示

- `0 <= s 的字节数 <= 10^5`
- `s` 由可打印 ASCII 字符、换行符 `\n` 以及 UTF-8 编码的中文组成

### 函数说明

```c
size_t my_strlen(const char* s);
```

- `s`：以 `'\0'` 结尾的字符串
- 返回值：`'\0'` 之前的字节数

### 自定义输入格式

```
"hello"
```

输入一行，为带双引号的字符串（支持 `\"`、`\\`、`\n`、`\t` 转义）。输出为长度。
