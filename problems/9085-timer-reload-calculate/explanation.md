# 定时器重装载值计算：题解

## 📖 先读懂题目

返回16位向上计数器的ARR。频率公式f=clockHz/((prescaler+1)*(ARR+1))，计数四舍五入（中点向上）。保证舍入计数在1..65536；PSC在0..65535，频率正，时钟≤10^8。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `72000000 / 71 / 1000` | `999` |
| 2 | `48000000 / 47 / 100` | `9999` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

定时器周期为(PSC+1)*(ARR+1)/时钟，先求每周期计数再减1，注意两个寄存器都存在加1关系。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int timerReload(int clockHz, int prescaler, int frequency) {
    int64_t divisor = (int64_t)(prescaler + 1) * frequency;
    return (int)(((int64_t)clockHz + divisor / 2) / divisor) - 1;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
