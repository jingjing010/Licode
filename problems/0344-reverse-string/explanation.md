# 344. 反转字符串 —— 小白详细题解

> 最基础的**对撞双指针**题，也是练习“交换两个变量”和“原地修改数组”的好机会。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把一排字符**首尾颠倒**，而且只能在原来的数组上改，不能另外开一个数组。

拿示例 1 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 修改前 | h | e | l | l | o |
| 修改后 | o | l | l | e | h |

可以发现：下标 0 和 4 互换，1 和 3 互换，中间的 2 不动。

**几个需要注意的细节：**

1. 函数返回 `void`，判题程序看的是**被修改后的 `s`**。
2. 题目要求 O(1) 额外空间，即不能 `malloc` 一个同样大的数组。
3. 长度可能是奇数也可能是偶数，奇数时中间那个字符不用动。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 交换两个变量需要一个“中转站”

```c
char t = s[l];   // 先把 s[l] 存起来
s[l] = s[r];     // s[l] 被覆盖了，但原值在 t 里
s[r] = t;        // 把原来的 s[l] 放到 s[r]
```

如果直接写 `s[l] = s[r]; s[r] = s[l];`，第一句执行后 `s[l]` 的原值就丢了，两个位置会变成同一个字符。

### 2. 为什么函数里改了 `s`，外面能看到？

`s` 是指针，存的是数组的地址。`s[l] = ...` 是顺着地址**直接改那块内存**，调用者用的是同一块内存。

### 3. 这里的 `s` 不是普通字符串

本题的 `s` 是**字符数组**，长度由 `sSize` 给出。不要依赖 `strlen(s)`——力扣的 C 语言版本并不保证它以 `'\0'` 结尾。

---

## 💡 第三步：思路一 —— 借助临时数组（容易想到，但不符合 O(1) 要求）

### 思路

先把 `s` 倒序拷贝到临时数组 `tmp`，再拷回 `s`。它能 AC，但用了 O(n) 额外空间，只适合帮助理解。

### 代码

```c
void reverseString(char* s, int sSize) {
    char* tmp = (char*)malloc(sSize);         // 临时数组
    for (int i = 0; i < sSize; i++) {
        tmp[i] = s[sSize - 1 - i];            // 第 i 个位置放倒数第 i 个字符
    }
    for (int i = 0; i < sSize; i++) {
        s[i] = tmp[i];                        // 拷贝回去
    }
    free(tmp);
}
```

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(n)**（不满足题目要求）。

---

## 🚀 第四步：思路二 —— 对撞双指针（题目要求的写法）

### 思路

- 左指针 `l` 从 0 开始，右指针 `r` 从 `sSize - 1` 开始；
- 交换 `s[l]` 和 `s[r]`，然后 `l++`、`r--`，两个指针向中间靠拢；
- 当 `l >= r` 时停止。

### 手动模拟（示例 1：`["h","e","l","l","o"]`）

| 步骤 | l | r | 交换 | 数组 |
|---|---|---|---|---|
| 1 | 0 | 4 | h ↔ o | o e l l h |
| 2 | 1 | 3 | e ↔ l | o l l e h |
| 3 | 2 | 2 | l 不再小于 r，停 | o l l e h |

### 代码

```c
void reverseString(char* s, int sSize) {
    int l = 0;              // 左指针
    int r = sSize - 1;      // 右指针
    while (l < r) {         // 两个指针相遇（或交错）就停
        char t = s[l];      // 交换 s[l] 和 s[r]
        s[l] = s[r];
        s[r] = t;
        l++;                // 向中间靠拢
        r--;
    }
}
```

### 复杂度分析

- **时间复杂度 O(n)**：交换 n/2 次。
- **空间复杂度 O(1)**：只用了 `l`、`r`、`t` 三个变量。

---

## ⚠️ 第五步：小白常见错误

1. **交换时没有临时变量** → `s[l] = s[r]; s[r] = s[l];` 会让两边变成同一个字符。
2. **循环条件写成 `l <= sSize - 1` 或遍历整个数组** → 每对字符交换了两次，又换回原样，数组没有变化。
3. **右指针从 `sSize` 开始** → `s[sSize]` 越界。最后一个元素是 `s[sSize - 1]`。
4. **用 `strlen(s)` 求长度** → 字符数组不一定以 `'\0'` 结尾，要用参数 `sSize`。
5. **在函数里 `return` 一个新数组** → 返回类型是 `void`，判题程序只看原数组 `s`。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 是否满足题意 |
|---|---|---|---|---|
| 临时数组 | O(n) | O(n) | ⭐ | ❌ 不满足 O(1) |
| 对撞双指针 | O(n) | O(1) | ⭐ | ✅ |

> 🎯 **学习建议**：对撞双指针的模板 `while (l < r) { 处理; l++; r--; }` 一定要写熟，它是很多题的基础。
