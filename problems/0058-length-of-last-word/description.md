# 最后一个单词的长度

字符串只含英文字母和空格，至少包含一个单词。返回最后一个单词长度。长度不超过10^4。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int lengthOfLastWord(char* s);
```

## 示例 1

输入：
```text
"Hello World"
```
输出：
```text
5
```

## 示例 2

输入：
```text
"   fly me   to   the moon  "
```
输出：
```text
4
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
