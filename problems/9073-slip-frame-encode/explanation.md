# SLIP 帧转义编码：题解

## 📖 先读懂题目

SLIP END=0xC0、ESC=0xDB。数据C0编码为DB DC，DB编码为DB DD，首尾各加C0。输入0到1024字节。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[49,50,51,52,53,54,55,56,57]` | `[192,49,50,51,52,53,54,55,56,57,192]` |
| 2 | `[]` | `[192,192]` |

## 🧰 需要的 C 语言知识

`uint8_t`表示一个0到255的字节；`const uint8_t *`允许读取数据但不修改它。`size_t len`明确给出缓冲区长度，不能使用`strlen`计算二进制数据长度，因为数据中可能含0。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

帧首尾加END，数据中的END和ESC必须转义，否则接收端会误判边界。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *slipEncode(const uint8_t *data, size_t len, int *returnSize) {
    int *out = malloc((2 * len + 2) * sizeof(int)), k = 0;
    out[k++] = 0xc0;
    for (size_t i = 0; i < len; ++i) {
        if (data[i] == 0xc0) {
            out[k++] = 0xdb;
            out[k++] = 0xdc;
        } else if (data[i] == 0xdb) {
            out[k++] = 0xdb;
            out[k++] = 0xdd;
        } else
            out[k++] = data[i];
    }
    out[k++] = 0xc0;
    *returnSize = k;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，输出空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 把二进制缓冲区当成以零结尾的字符串，遇到0便提前停止。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
