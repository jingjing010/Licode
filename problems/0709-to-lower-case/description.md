# 转换成小写字母

把ASCII字符串中的大写英文字母改为小写，其他字符不变，返回新字符串。长度1到100。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* toLowerCase(char* s);
```

## 示例 1

输入：
```text
"Hello"
```
输出：
```text
"hello"
```

## 示例 2

输入：
```text
"LOVELY"
```
输出：
```text
"lovely"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
