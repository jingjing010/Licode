# 73. 矩阵置零 —— 小白详细题解

> 这道题看起来简单，最大的坑是"**边找边改**"会把自己写进去的 0 当成原来的 0。学会"先记录、后修改"就成功了一大半。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 矩阵里**原本**是 0 的格子，把它所在的**整行**和**整列**都改成 0。直接在原矩阵上改。

示例 1：中间那个 0 在第 1 行、第 1 列，所以第 1 行、第 1 列全部变 0：

```
修改前          修改后
1 1 1          1 0 1
1 0 1    →     0 0 0
1 1 1          1 0 1
```

**几个需要注意的细节：**

1. 只有**原来**就是 0 的格子才会"传染"。被改成 0 的格子**不会**继续传染。
2. 函数返回 `void`，判题程序会直接看你修改后的 `matrix`。
3. 列数是 `matrixColSize[0]`（`matrixColSize` 是一个数组，存每一行的长度，本题每行一样长）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `int** matrix` 怎么用？

```c
void setZeroes(int** matrix, int matrixSize, int* matrixColSize)
```

| 写法 | 含义 |
|---|---|
| `matrix[i][j]` | 第 `i` 行第 `j` 列，和普通二维数组一样用 |
| `matrixSize` | 行数 m |
| `matrixColSize[0]` | 第 0 行的列数，也就是 n。注意它是**指针（数组）**，不是一个数 |

```c
int n = matrixColSize[0];   // ✅
int n = matrixColSize;      // ❌ 把指针当成整数，编译警告，结果是一个巨大的"地址值"
```

### 2. 为什么不能边扫边改？

```c
// ❌ 错误示范
for (i...) for (j...)
    if (matrix[i][j] == 0) { 把第 i 行、第 j 列全改成 0; }
```

示例 1 中，扫到 `(1,1)` 时把第 1 行改成 `0 0 0`；继续扫到 `(1,2)` 时，它已经是 0 了，又会把第 2 列也清零——这是**错的**！

---

## 💡 第三步：思路一 —— 行标记 + 列标记数组（O(m+n) 空间）

### 思路

1. 第一遍扫描：遇到 0 就记下"第 `i` 行要清零"`row[i] = true`、"第 `j` 列要清零" `col[j] = true`。**这一遍不改矩阵**。
2. 第二遍扫描：如果 `row[i]` 或 `col[j]` 为真，就把 `matrix[i][j]` 改成 0。

### 手动模拟（示例 1）

第一遍：只有 `matrix[1][1] == 0` → `row = [F, T, F]`，`col = [F, T, F]`。

第二遍：

| (i, j) | row[i] | col[j] | 改成 0？ |
|---|---|---|---|
| (0,0) | F | F | 否，保持 1 |
| (0,1) | F | T | 是 |
| (1,0) | T | F | 是 |
| (1,2) | T | F | 是 |
| (2,1) | F | T | 是 |
| (2,2) | F | F | 否，保持 1 |

结果 `[[1,0,1],[0,0,0],[1,0,1]]`。

### 代码

```c
void setZeroes(int** matrix, int matrixSize, int* matrixColSize) {
    int m = matrixSize;              // 行数
    int n = matrixColSize[0];        // 列数

    // 1. 两个标记数组，calloc 会把它们全部初始化为 false
    bool* row = (bool*)calloc(m, sizeof(bool));
    bool* col = (bool*)calloc(n, sizeof(bool));

    // 2. 第一遍：只记录，不修改
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (matrix[i][j] == 0) {
                row[i] = true;       // 第 i 行要清零
                col[j] = true;       // 第 j 列要清零
            }
        }
    }

    // 3. 第二遍：根据标记修改
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (row[i] || col[j]) {
                matrix[i][j] = 0;
            }
        }
    }

    free(row);
    free(col);
}
```

### 复杂度分析

- **时间复杂度 O(mn)**：扫两遍矩阵。
- **空间复杂度 O(m + n)**：两个标记数组。

---

## 🚀 第四步：思路二 —— 借用第 0 行、第 0 列做标记（O(1) 空间）

### 思路

能不能不开 `row`、`col` 数组？可以把**矩阵的第 0 列当 `row` 数组、第 0 行当 `col` 数组**：

- `matrix[i][j] == 0` 时，令 `matrix[i][0] = 0`（第 i 行要清零）、`matrix[0][j] = 0`（第 j 列要清零）

问题是：第 0 行、第 0 列**本身**原来有没有 0 呢？标记写进去之后就分不清了。所以**先用两个变量**记住：

- `row0`：第 0 行原来有没有 0
- `col0`：第 0 列原来有没有 0

完整步骤：

1. 记录 `row0`、`col0`
2. 扫描 `i >= 1, j >= 1` 的部分，把标记写到第 0 行 / 第 0 列
3. 再扫描 `i >= 1, j >= 1` 的部分，根据标记清零
4. 最后根据 `row0`、`col0` 处理第 0 行、第 0 列（**必须最后做**，否则标记会被提前破坏）

### 手动模拟（示例 2：`[[0,1,2,0],[3,4,5,2],[1,3,1,5]]`）

| 步骤 | 操作 | 矩阵 |
|---|---|---|
| 1 | 第 0 行有 0 → `row0 = true`；第 0 列有 0 → `col0 = true` | 不变 |
| 2 | 内部 (i,j ≥ 1) 没有 0，不写标记 | 不变 |
| 3 | 第 0 行的标记：`matrix[0][3] == 0`，所以第 3 列（i ≥ 1 部分）清零 | `[[0,1,2,0],[3,4,5,0],[1,3,1,0]]` |
| 4 | `row0` → 第 0 行清零；`col0` → 第 0 列清零 | `[[0,0,0,0],[0,4,5,0],[0,3,1,0]]` |

### 代码

```c
void setZeroes(int** matrix, int matrixSize, int* matrixColSize) {
    int m = matrixSize, n = matrixColSize[0];
    bool row0 = false, col0 = false;     // 第 0 行 / 第 0 列原来有没有 0

    // 1. 先记录第 0 行、第 0 列自己的情况
    for (int j = 0; j < n; j++) {
        if (matrix[0][j] == 0) row0 = true;
    }
    for (int i = 0; i < m; i++) {
        if (matrix[i][0] == 0) col0 = true;
    }

    // 2. 用第 0 列标记"哪些行要清零"，用第 0 行标记"哪些列要清零"
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;
                matrix[0][j] = 0;
            }
        }
    }

    // 3. 根据标记，把内部（不含第 0 行、第 0 列）清零
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (matrix[i][0] == 0 || matrix[0][j] == 0) {
                matrix[i][j] = 0;
            }
        }
    }

    // 4. 最后处理第 0 行和第 0 列本身
    if (row0) {
        for (int j = 0; j < n; j++) matrix[0][j] = 0;
    }
    if (col0) {
        for (int i = 0; i < m; i++) matrix[i][0] = 0;
    }
}
```

### 复杂度分析

- **时间复杂度 O(mn)**。
- **空间复杂度 O(1)**：只用了两个 `bool` 变量。

---

## ⚠️ 第五步：小白常见错误

1. **边扫描边清零** → 新写的 0 被当成原来的 0，整个矩阵可能被清空。
2. **`int n = matrixColSize;`** → 少了 `[0]`，把指针当整数用。
3. **思路二中第 3 步从 `i = 0` / `j = 0` 开始** → 第 0 行、第 0 列是标记区，提前清零会把标记全部破坏，导致更多行列被误清零。
4. **思路二中先处理第 0 行 / 第 0 列，再处理内部** → 同上，标记被提前覆盖。
5. **只用一个变量记录"第 0 行或第 0 列有 0"** → `matrix[0][0]` 同时属于第 0 行和第 0 列，用它一个格子没法区分是哪一个要清零，所以要用 `row0`、`col0` 两个变量分开记。
6. **在 `m == 1` 或 `n == 1` 时出错** → 比如 `[[1,0,3]]`，内部循环一次都不执行，全靠第 4 步处理，记得测试这类情况。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 复制整个矩阵再对照修改 | O(mn) | O(mn) | ⭐ | 可行但浪费 |
| 行标记 + 列标记 | O(mn) | O(m+n) | ⭐ | 先写这个，最不容易错 |
| 第 0 行 / 列做标记 | O(mn) | O(1) | ⭐⭐⭐ | 进阶写法，注意处理顺序 |
