# RGB888 压缩为 RGB565

r/g/b各0..255，丢弃低位进行RGB565打包：R在位15..11，G在10..5，B在4..0。返回16位无符号整数。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint16_t rgb565(int red,int green,int blue);
```

## 示例 1

输入：
```text
255
0
0
```
输出：
```text
63488
```

## 示例 2

输入：
```text
0
255
0
```
输出：
```text
2016
```

## 自定义输入格式

按顺序每行一个参数：red、green、blue。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
