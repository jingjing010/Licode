你是产品经理，目前正在带领一个团队开发新的产品。不幸的是，你的产品的最新版本没有通过质量检测。由于每个版本都是基于之前的版本开发的，所以错误的版本之后的所有版本都是错的。

假设你有 `n` 个版本 `[1, 2, ..., n]`，你想找出导致之后所有版本出错的第一个错误的版本。

你可以通过调用 `bool isBadVersion(version)` 接口来判断版本号 `version` 是否在单元测试中出错。实现一个函数来查找第一个错误的版本。你应该尽量减少对调用 API 的次数。

### 示例 1

```
输入：n = 5, bad = 4
输出：4
解释：
调用 isBadVersion(3) -> false 
调用 isBadVersion(5) -> true 
调用 isBadVersion(4) -> true
所以，4 是第一个错误的版本。
```

### 示例 2

```
输入：n = 1, bad = 1
输出：1
```

### 提示

- `1 <= bad <= n <= 2^31 - 1`

### 函数说明

```c
// 系统已经为你实现好了这个接口，直接调用即可：
bool isBadVersion(int version);

int firstBadVersion(int n);
```

- `n`：版本总数，版本号是 `1 ~ n`
- 返回值：第一个错误版本的版本号
- `isBadVersion(version)`：版本 `version` 是错误版本时返回 `true`

### 判题说明

- `bad` 是隐藏答案，你的代码**只能通过 `isBadVersion` 得知**，不能直接读取。
- 判题程序会统计 `isBadVersion` 的调用次数，上限为 `2 × (n 的二进制位数) + 2`（`n = 2^31-1` 时为 64 次）。超过上限或者传入 `[1, n]` 范围外的版本号，会立即输出错误信息并判为答案错误。

### 自定义输入格式

```
5
4
```

第 1 行是 `n`，第 2 行是 `bad`（第一个错误版本）。
