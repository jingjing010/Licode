# 9014. 串口奇偶校验位 —— 小白详细题解

> 配置串口时经常看到 "9600, 8, **E**, 1" 这样的参数，其中的 E（Even）就是偶校验。本题把校验位的计算拆出来：本质是判断"1 的个数是奇是偶"，而这又等于**所有位的异或**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 发送方在数据后面**补一位**，让"1 的总数"凑成约定好的奇偶性。偶校验凑成偶数，奇校验凑成奇数。

| data | 二进制 | 1 的个数 | 偶校验位 | 奇校验位 |
|---|---|---|---|---|
| 65（'A'） | `0100 0001` | 2 | **0**（示例 1） | **1**（示例 2） |
| 7 | `0000 0111` | 3 | **1**（示例 3） | 0 |
| 0 | `0000 0000` | 0 | 0 | 1 |
| 255 | `1111 1111` | 8 | 0 | 1 |

规律：

- **偶校验位 = 1 的个数 % 2**（个数是奇数就补个 1 凑成偶数）；
- **奇校验位 = 偶校验位取反**。

**几个需要注意的细节：**

1. 校验位**不是**"数据是奇数还是偶数"（看最低位），而是"**1 的个数**是奇数还是偶数"。65 是奇数，但它有 2 个 1。
2. 数据全 0 时，偶校验位是 0，奇校验位是 1——奇校验能检测出"线路断了、一直是 0"这种故障，这是它的一个优点。
3. 返回值只能是 0 或 1。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 奇偶性 = 异或和

异或可以看成"不进位的加法"，也就是**只保留和的最低位**：

```
1 ^ 1         = 0      （2 个 1，偶数）
1 ^ 1 ^ 1     = 1      （3 个 1，奇数）
1 ^ 0 ^ 1 ^ 1 = 1      （3 个 1，奇数）
```

所以 **"1 的个数 % 2" = 所有位的异或**，不用真的去数有几个。

### 2. 折叠异或：一次处理一半的位

`x ^= x >> 4`：把高 4 位异或到低 4 位上。此时低 4 位的异或和 = 原来 8 位的异或和（高 4 位"折"下来了）。再折 2 位、折 1 位，最低位就是全部 8 位的异或和。

```
x            = abcd efgh
x ^= x >> 4  → 低 4 位 = (a^e)(b^f)(c^g)(d^h)
x ^= x >> 2  → 低 2 位 = (a^e^c^g)(b^f^d^h)
x ^= x >> 1  → 最低位 = a^b^c^d^e^f^g^h
```

高位留下的东西是"垃圾"，最后 `& 1` 丢掉即可。

### 3. `uint8_t` 与整型提升

`x >> 4` 中的 `x` 会先被提升为 `int`，但因为 `uint8_t` 的值不超过 255，右移后再赋值回 `uint8_t` 不会有问题。

## 💡 第三步：思路一 —— 数 1 的个数（最朴素）

### 思路

1. 逐位数出 `data` 中 1 的个数 `cnt`；
2. 偶校验位 = `cnt % 2`；
3. 奇校验时取反。

### 手动模拟（示例 3：`data = 7, odd = 0`）

| i | 第 i 位 | cnt |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 1 | 2 |
| 2 | 1 | 3 |
| 3 ~ 7 | 0 | 3 |

`cnt % 2 = 1`，偶校验，答案 **1**。

### 代码

```c
uint8_t parity_bit(uint8_t data, int odd) {
    int cnt = 0;
    for (int i = 0; i < 8; i++) {      // 8 个数据位
        if ((data >> i) & 1u) {
            cnt++;                     // 数 1 的个数
        }
    }
    uint8_t even_bit = (uint8_t)(cnt % 2);   // 偶校验位：个数为奇数时补 1
    if (odd) {
        return (uint8_t)(1 - even_bit);      // 奇校验：和偶校验正好相反
    }
    return even_bit;
}
```

### 复杂度分析

- **时间复杂度 O(8)**。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 折叠异或（无循环）

### 思路

1. `x ^= x >> 4; x ^= x >> 2; x ^= x >> 1;`，最低位 = 全部 8 位的异或 = 偶校验位；
2. 奇校验 = 偶校验位 ^ 1。

### 手动模拟（示例 3：`data = 7 = 0000 0111`）

| 步骤 | x（二进制） |
|---|---|
| 初始 | `0000 0111` |
| x ^= x >> 4 | `0000 0111`（高 4 位是 0，没变） |
| x ^= x >> 2 | `0000 0111 ^ 0000 0001 = 0000 0110` |
| x ^= x >> 1 | `0000 0110 ^ 0000 0011 = 0000 0101` |
| x & 1 | **1** |

### 代码

```c
uint8_t parity_bit(uint8_t data, int odd) {
    uint8_t x = data;
    x ^= x >> 4;          // 高 4 位折叠到低 4 位
    x ^= x >> 2;          // 再折叠到低 2 位
    x ^= x >> 1;          // 再折叠到最低位：此时第 0 位 = 8 个数据位的异或
    uint8_t even_bit = x & 1u;                       // 偶校验位
    return (uint8_t)(even_bit ^ (odd ? 1u : 0u));    // 奇校验再翻转一次
}
```

### 复杂度分析

- **时间复杂度 O(log 8) = 3 步**。
- **空间复杂度 O(1)**。

### 进阶：用一个 16 位常数查表

折叠到 4 位之后，4 位数一共只有 16 种，它们的奇偶性可以预先编进一个常数 `0x6996` 里（第 `k` 位 = `k` 的奇偶性）：

```c
uint8_t parity_bit(uint8_t data, int odd) {
    uint8_t x = data ^ (data >> 4);                   // 折叠到低 4 位
    uint8_t even_bit = (0x6996u >> (x & 0x0Fu)) & 1u; // 0x6996 = 0110 1001 1001 0110，第 k 位是 k 的奇偶性
    return (uint8_t)(even_bit ^ (odd ? 1u : 0u));
}
```

## ⚠️ 第五步：小白常见错误

1. **用数值的奇偶代替 1 的个数的奇偶**：
   ```c
   return (uint8_t)((data & 1u) ^ odd);   // ❌ 只看了最低位，示例 1 会返回 1
   ```
2. **奇偶校验搞反**：偶校验是"让总数为偶数"，不是"数据有偶数个 1 时校验位为 1"。示例 1 有 2 个 1，偶校验位是 **0**。
3. **折叠后忘了 `& 1`**：高位还残留着中间结果，直接返回会得到 2、5 这样的值。
4. **`odd` 直接参与异或时类型不一致**：`odd` 可能是任意非零值（虽然本题保证是 0 或 1），写成 `odd ? 1u : 0u` 更稳妥。
5. **折叠顺序写成 `>> 1`、`>> 2`、`>> 4` 但没有每步都赋值回去**：比如 `x ^ (x >> 1) ^ (x >> 2) ^ (x >> 4)` 并不等于全部位的异或——它只覆盖了 4 个位置。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 数 1 的个数 | O(8) | O(1) | ⭐ | 最直观 |
| 折叠异或 | O(3) | O(1) | ⭐⭐ | 推荐，可推广到 32 位（多折两次） |
| 折叠 + `0x6996` 查表 | O(1) | O(1) | ⭐⭐ | 位运算"黑魔法"，了解即可 |

## 🔌 嵌入式实战

- **硬件 UART 自动处理**：STM32 配置 `USART_CR1` 的 `PCE`（校验使能）和 `PS`（0 偶、1 奇），硬件发送时自动加校验位，接收时出错会置 `PE` 标志。注意：开启校验后，字长要设成 **9 位**（8 数据 + 1 校验），否则最高的数据位会被校验位占用。
- **软件串口发送一帧**（示意）：起始位 0 → 8 个数据位（**低位先发**）→ 校验位 → 停止位 1。

```c
void soft_uart_send(uint8_t data) {
    tx_bit(0);                                   /* 起始位 */
    for (int i = 0; i < 8; i++) tx_bit((data >> i) & 1u);
    tx_bit(parity_bit(data, 0));                 /* 偶校验位 */
    tx_bit(1);                                   /* 停止位 */
}
```

- **局限性**：奇偶校验只能发现**奇数个**位出错；两个位同时翻转时 1 的个数奇偶不变，检测不出来。可靠性要求高的场合要用 CRC。
