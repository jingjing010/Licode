# 144. 二叉树的前序遍历 —— 小白详细题解

> 前序遍历是最"顺"的一种遍历：**看到一个结点就先记下它**，再去看它的孩子。学会它，就能理解"用栈模拟递归"最简单的形式。

---

## 📖 第一步：先读懂题目

**前序遍历**的规则只有一句话：

> 对每一个结点，都先访问**它自己**，再遍历它的**左子树**，最后遍历它的**右子树**（根 → 左 → 右）。

拿示例 1 `[1,null,2,3]` 来说：

```
    1
     \
      2
     /
    3
```

| 步骤 | 当前处理 | 做了什么 | 结果 |
|---|---|---|---|
| 1 | 结点 1 | 访问自己 | [1] |
| 2 | 结点 1 | 左子树为空，跳过；去右子树 | [1] |
| 3 | 结点 2 | 访问自己 | [1,2] |
| 4 | 结点 2 | 去左子树：结点 3，访问 | [1,2,3] |
| 5 | 结点 2 | 右子树为空，结束 | [1,2,3] |

**几个需要注意的细节：**

1. 空树返回长度为 0 的数组，`*returnSize = 0`。
2. 输入的 `[1,null,2,3]` 是**层序**写法，只用来描述形状，你拿到的是已经建好的 `root`。
3. 结点最多 100 个，结果数组开 100 个 `int` 就够。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 结构体指针与 `->`

`root->val` 等价于 `(*root).val`，`root->left` 是左孩子指针（没有就是 `NULL`）。

### 2. 递归里共享计数器：传地址

```c
void dfs(struct TreeNode* node, int* res, int* cnt) {
    res[(*cnt)++] = node->val;   // 写到 res[*cnt]，然后 *cnt 加 1
}
```

`(*cnt)++` 的括号不能省：`*cnt++` 的意思是"指针 cnt 往后移一格"，完全不是一回事。

### 3. 用数组当栈

```c
struct TreeNode* st[100];
int top = 0;
st[top++] = x;      // 入栈（压到顶上）
x = st[--top];      // 出栈（取最上面的）
top > 0             // 栈不空
```

栈是"**后进先出**"：最后放进去的最先拿出来。

---

## 💡 第三步：思路一 —— 递归

### 思路

把"根 → 左 → 右"直接翻译成代码：

1. 结点为空，直接返回（递归出口）。
2. 把当前结点的值写进数组。
3. 递归左子树。
4. 递归右子树。

### 手动模拟（示例 2 的左半部分）

```
          1
        /   \
       2     3
      / \     \
     4   5     8
        / \   /
       6   7 9
```

| 调用 | 写入 | res |
|---|---|---|
| dfs(1) | 1 | [1] |
| dfs(2) | 2 | [1,2] |
| dfs(4) | 4 | [1,2,4] |
| dfs(5) | 5 | [1,2,4,5] |
| dfs(6)、dfs(7) | 6、7 | [1,2,4,5,6,7] |
| dfs(3)、dfs(8)、dfs(9) | 3、8、9 | [1,2,4,5,6,7,3,8,9] |

### 代码

```c
// 把以 node 为根的子树按前序写进 res，*cnt 是已写入的个数
void dfs(struct TreeNode* node, int* res, int* cnt) {
    if (node == NULL) return;          // 递归出口
    res[(*cnt)++] = node->val;         // 1. 先访问根
    dfs(node->left, res, cnt);         // 2. 再遍历左子树
    dfs(node->right, res, cnt);        // 3. 最后遍历右子树
}

int* preorderTraversal(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 100);   // 最多 100 个结点
    int cnt = 0;
    dfs(root, res, &cnt);
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点访问一次。
- **空间复杂度 O(h)**：递归栈深度，最坏 O(n)。

## 🚀 第四步：思路二 —— 迭代（显式栈）

### 思路

前序的迭代写法特别简单：

1. 根结点入栈。
2. 栈不空时：弹出栈顶结点，**马上访问它**。
3. 先把**右**孩子入栈，再把**左**孩子入栈。

为什么先右后左？因为栈是后进先出，后压进去的左孩子会**先**弹出来，正好满足"先左后右"。

### 手动模拟（示例 1：`[1,null,2,3]`）

| 步骤 | 弹出 | res | 压入 | 栈（底→顶） |
|---|---|---|---|---|
| 0 | | | 1 | [1] |
| 1 | 1 | [1] | 右孩子 2（无左孩子） | [2] |
| 2 | 2 | [1,2] | 左孩子 3（无右孩子） | [3] |
| 3 | 3 | [1,2,3] | 无 | [] |

### 代码

```c
int* preorderTraversal(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 100);
    struct TreeNode* st[100];          // 用数组当栈
    int top = 0, cnt = 0;
    if (root) st[top++] = root;        // 空树就不入栈
    while (top > 0) {
        struct TreeNode* node = st[--top];     // 弹出栈顶
        res[cnt++] = node->val;                // 立刻访问
        if (node->right) st[top++] = node->right;   // 先压右
        if (node->left) st[top++] = node->left;     // 再压左（左先出栈）
    }
    *returnSize = cnt;
    return res;
}
```

> 栈开 100 够吗？每个结点只会入栈一次，所以栈里同时最多 100 个。

### 复杂度分析

- **时间复杂度 O(n)**：每个结点入栈出栈各一次。
- **空间复杂度 O(h)~O(n)**：栈的大小。

---

## ⚠️ 第五步：小白常见错误

1. **迭代时先压左再压右**：
   ```c
   if (node->left) st[top++] = node->left;    // ❌ 顺序反了
   if (node->right) st[top++] = node->right;
   ```
   右孩子会先出栈，结果变成"根 → 右 → 左"。示例 2 会得到 `[1,3,8,9,2,5,7,6,4]`。
2. **计数器用值传递**：`void dfs(..., int cnt)`，每层改的都是拷贝，所有值都写进 `res[0]`。
3. **写成 `*cnt++`**：这是让指针移动，不是让计数加 1，要写 `(*cnt)++`。
4. **空树时把 `NULL` 压栈**：弹出后访问 `node->val` 直接崩溃。入栈前判空。
5. **忘记设置 `*returnSize`**：数组内容对了，但输出是 `[]`。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 递归 | O(n) | O(h) | ⭐ | 先写这个，理解"根左右" |
| 迭代 + 栈 | O(n) | O(h) | ⭐⭐ | 面试常考，前序是三种遍历里迭代最简单的 |

## 🔗 举一反三

- **94. 二叉树的中序遍历**：左 → 根 → 右，迭代时要"一路向左"。
- **145. 二叉树的后序遍历**：左 → 右 → 根。把本题的迭代改成"先压左再压右"得到"根右左"，再整体反转就是后序！
- **589. N 叉树的前序遍历**：孩子不止两个，倒序压栈即可。
