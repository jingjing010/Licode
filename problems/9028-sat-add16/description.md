你在为一款蓝牙音箱编写混音模块：两路 16 位 PCM 音频（例如"音乐"和"提示音"）需要逐个采样点相加后送给 DAC / I2S 播放。PCM 采样用 `int16_t` 表示，范围是 `-32768 ~ 32767`。

两个采样相加很容易超出这个范围。如果让它自然溢出"绕回去"，`30000 + 10000` 会变成 `-25536`，波形从最高点瞬间跳到负半轴，喇叭里就是一声刺耳的"啪"。正确做法是**饱和（saturation）**：超出上限就取上限，低于下限就取下限，听起来只是轻微的削波失真。

请实现函数 `sat_add16`：对 `i = 0 ~ len-1`，计算 `out[i] = a[i] + b[i]` 的饱和结果：

1. 计算数学上的和 `S = a[i] + b[i]`
2. 若 `S > 32767`，`out[i] = 32767`；若 `S < -32768`，`out[i] = -32768`；否则 `out[i] = S`

### 示例 1

```
输入：a = [1000,-2000,30000], b = [234,500,10000]
输出：[1234,-1500,32767]
解释：30000 + 10000 = 40000 > 32767，饱和到 32767；前两个没有溢出，正常相加。
```

### 示例 2

```
输入：a = [-32768,-20000,32767], b = [-1,-20000,-32768]
输出：[-32768,-32768,-1]
解释：-32769 和 -40000 都低于 -32768，饱和到 -32768；32767 + (-32768) = -1 不会溢出。
```

### 示例 3

```
输入：a = [32767,0,-100], b = [32767,0,100]
输出：[32767,0,0]
```

### 提示

- `1 <= len <= 20000`
- `-32768 <= a[i], b[i] <= 32767`
- `a`、`b` 的长度相同

### 函数说明

```c
void sat_add16(const int16_t* a, const int16_t* b, int16_t* out, size_t len);
```

- `a`、`b`：两路输入采样（只读）
- `out`：输出缓冲区，调用方已分配好 `len` 个 `int16_t`
- `len`：采样点个数
- 无返回值：判题程序会打印 `out` 的全部内容

### 自定义输入格式

```
[1000,-2000,30000]
[234,500,10000]
```

第 1 行是 `a`，第 2 行是 `b`（长度必须相同）。输出为 `out` 数组。
