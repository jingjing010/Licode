你总共有 `n` 枚硬币，并计划将它们按阶梯状排列。对于一个由 `k` 行组成的阶梯，其第 `i` 行必须正好有 `i` 枚硬币。阶梯的最后一行 **可能** 是不完整的。

给你一个数字 `n` ，计算并返回可形成 **完整阶梯行** 的总行数。

### 示例 1

```
输入：n = 5
输出：2
解释：第一行 1 枚，第二行 2 枚，第三行只剩 2 枚（需要 3 枚），不完整。因此返回 2 。
```

### 示例 2

```
输入：n = 8
输出：3
解释：第一行 1 枚，第二行 2 枚，第三行 3 枚，第四行只剩 2 枚（需要 4 枚），不完整。因此返回 3 。
```

### 提示

- `1 <= n <= 2^31 - 1`

### 函数说明

```c
int arrangeCoins(int n);
```

- `n`：硬币总数
- 返回值：完整阶梯行的行数

### 自定义输入格式

```
5
```

只有 1 行，是整数 `n`。
