# 带长度字段的数据帧扫描

帧格式AA 55 LEN PAYLOAD，LEN为1字节，载荷可含任意字节。跳过帧外噪声，遇不完整帧则停止，返回所有完整帧的载荷长度。0到1024字节。此练习无CRC且假定完整同步头不会在噪声中误出现。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* scanFrames(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[170,85,2,1,2,170,85,0]
```
输出：
```text
[2,0]
```

## 示例 2

输入：
```text
[0,170,85,3,1]
```
输出：
```text
[]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
