# 数组的相对排序：题解

## 📖 先读懂题目

arr2无重复且每个值出现在arr1中；arr1按arr2指定次序排列重复值，其他值在末尾升序排列。数组长度1到1000，元素0到1000。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[2,3,1,3,2,4,6,7,9,2,19] / [2,1,4,3,9,6]` | `[2,2,2,1,4,3,3,9,6,7,19]` |
| 2 | `[28,6,22,8,44,17] / [22,28,8,6]` | `[22,28,8,6,17,44]` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

用计数数组保存arr1的各值次数，先按arr2次序输出，再按数值递增输出余项。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *relativeSortArray(int *arr1, int arr1Size, int *arr2, int arr2Size, int *returnSize) {
    int counts[1001] = {0}, k = 0, *out = malloc(arr1Size * sizeof(int));
    for (int i = 0; i < arr1Size; ++i)
        ++counts[arr1[i]];
    for (int i = 0; i < arr2Size; ++i)
        while (counts[arr2[i]] > 0) {
            out[k++] = arr2[i];
            --counts[arr2[i]];
        }
    /* 未指定相对次序的元素按数值升序放到末尾。 */
    for (int x = 0; x <= 1000; ++x)
        while (counts[x] > 0) {
            out[k++] = x;
            --counts[x];
        }
    *returnSize = k;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n+m+1001)，空间 O(n+1001) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
