给你两个二进制字符串 `a` 和 `b` ，以二进制字符串的形式返回它们的和。

### 示例 1

```
输入：a = "11", b = "1"
输出："100"
```

### 示例 2

```
输入：a = "1010", b = "1011"
输出："10101"
```

### 提示

- `1 <= a.length, b.length <= 10^4`
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成
- 字符串如果不是 `"0"` ，就不含前导零

### 函数说明

```c
char* addBinary(char* a, char* b);
```

- `a`、`b`：以 `'\0'` 结尾的二进制字符串
- 返回值：和的二进制字符串（用 `malloc` 申请，以 `'\0'` 结尾，不能有前导零）

### 自定义输入格式

```
"1010"
"1011"
```

第 1 行是 `a`，第 2 行是 `b`，都带双引号。输出为带双引号的字符串。
