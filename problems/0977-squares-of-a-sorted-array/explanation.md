# 有序数组的平方：题解

## 📖 先读懂题目

输入为非递减数组，返回所有元素平方后按非递减排序的数组。1 ≤ n ≤ 10^4，|元素| ≤ 10^4。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[-4,-1,0,3,10]` | `[0,1,9,16,100]` |
| 2 | `[-7,-3,2,3,11]` | `[4,9,9,49,121]` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

平方最大值一定来自剩余数组两端之一，用两个指针反向填充输出。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *sortedSquares(int *nums, int numsSize, int *returnSize) {
    int *out = malloc(numsSize * sizeof(int)), l = 0, r = numsSize - 1;
    /* 最大绝对值位于两端，从结果末尾向前填。 */
    for (int i = numsSize - 1; i >= 0; --i) {
        int a = nums[l] * nums[l], b = nums[r] * nums[r];
        if (a > b) {
            out[i] = a;
            ++l;
        } else {
            out[i] = b;
            --r;
        }
    }
    *returnSize = numsSize;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，输出空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
