# 260. 只出现一次的数字 III —— 小白详细题解

> 136 题只有一个"单身数"，全部异或就出来了。这题有**两个**单身数，全部异或得到的是它俩混在一起的结果 `a ^ b`。怎么把它们拆开？答案是：**按某一位把数组分成两组**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 数组里有两个数各出现 1 次（记为 `a`、`b`），其余的数都成对出现。把 `a` 和 `b` 找出来，顺序随意。要求 O(n) 时间、O(1) 额外空间。

拿示例 1 来说：`[1,2,1,3,2,5]` 中 1 和 2 各出现两次，3 和 5 各出现一次，答案是 `[3,5]`（`[5,3]` 也对）。

**几个需要注意的细节：**

1. 返回的是一个**长度为 2 的数组**，要用 `malloc`，并设置 `*returnSize = 2`。
2. 顺序任意：本 OJ 会把你的答案排序后再比较。
3. 数的范围是整个 `int`，包括 `-2^31`。后面求"最低位的 1"时要小心溢出。
4. `a` 和 `b` 一定不相等（否则它们就算"出现两次"了）。

---

## 🧰 第二步：需要的 C 语言知识

### 1. 异或的性质

- `x ^ x = 0`，`x ^ 0 = x`；
- 满足交换律和结合律，顺序无所谓。

所以一堆数异或起来，**成对的全部抵消**，只剩下出现奇数次的。

### 2. ⭐ `x & -x`：取出最低位的 1

```
x      = 0110 1000
-x     = 1001 1000      (补码：取反加一)
x & -x = 0000 1000      ← 只剩下 x 最右边的那个 1
```

**溢出陷阱**：如果 `x = INT_MIN`（`1000……0`），`-x` 在 `int` 里溢出，是未定义行为。解决办法是用无符号数：`unsigned int low = x & (0u - x);`，无符号减法按 `2^32` 取模，结果有定义。

### 3. 返回数组

```c
int* res = (int*)malloc(sizeof(int) * 2);
res[0] = a;
res[1] = b;
*returnSize = 2;     // 告诉调用者数组长度
return res;
```

## 💡 第三步：思路一 —— 排序后两两比较

### 思路

先把数组排序，相同的数就挨在一起了。然后从头开始看：

- 如果 `nums[i] == nums[i + 1]`，这是一对，跳过两个（`i += 2`）；
- 否则 `nums[i]` 是单身数，记下来，只跳过一个（`i += 1`）。

### 手动模拟（示例 1：排序后 `[1,1,2,2,3,5]`）

| i | nums[i] | nums[i+1] | 相等？ | 操作 |
|---|---|---|---|---|
| 0 | 1 | 1 | 是 | 跳到 i = 2 |
| 2 | 2 | 2 | 是 | 跳到 i = 4 |
| 4 | 3 | 5 | 否 | 记下 3，跳到 i = 5 |
| 5 | 5 | （没有了） | | 记下 5 |

### 代码

```c
// qsort 的比较函数：不要写 return x - y，两个大数相减会溢出
int cmp(const void* p, const void* q) {
    int x = *(const int*)p, y = *(const int*)q;
    return (x > y) - (x < y);
}

int* singleNumber(int* nums, int numsSize, int* returnSize) {
    qsort(nums, numsSize, sizeof(int), cmp);   // 排序后相同的数挨在一起
    int* res = (int*)malloc(sizeof(int) * 2);
    int k = 0;                                 // 已经找到几个单身数
    int i = 0;
    while (i < numsSize) {
        if (i + 1 < numsSize && nums[i] == nums[i + 1]) {
            i += 2;                            // 一对，跳过
        } else {
            res[k++] = nums[i];                // 单身数
            i += 1;
        }
    }
    *returnSize = 2;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n log n)**：排序的代价。不满足题目"线性时间"的要求，但能 AC。
- **空间复杂度 O(1)**（不算排序的递归栈）。注意它修改了原数组。

## 🚀 第四步：思路二 —— 异或 + 分组

### 思路

1. **全部异或**：成对的数抵消，得到 `x = a ^ b`。
2. **找一个"分界位"**：因为 `a != b`，`x` 至少有一位是 1，这一位上 `a` 和 `b` **一个是 0、一个是 1**。取最低的那个 1：`low = x & -x`。
3. **分组异或**：按 `nums[i] & low` 是否为 0 把所有数分成两组：
   - `a` 和 `b` 一定分在**不同组**；
   - 成对的两个数完全相同，一定分在**同一组**，组内异或会抵消。
   - 所以每组异或的结果，分别就是 `a` 和 `b`。

### 手动模拟（示例 1：`[1,2,1,3,2,5]`）

**第 1 步**：`1 ^ 2 ^ 1 ^ 3 ^ 2 ^ 5 = 3 ^ 5 = 011 ^ 101 = 110 = 6`

**第 2 步**：`low = 6 & -6 = 010 = 2`（第 1 位）

**第 3 步**：

| 数 | 二进制 | 第 1 位 | 分到 |
|---|---|---|---|
| 1 | 001 | 0 | B 组 |
| 2 | 010 | 1 | A 组 |
| 1 | 001 | 0 | B 组 |
| 3 | 011 | 1 | A 组 |
| 2 | 010 | 1 | A 组 |
| 5 | 101 | 0 | B 组 |

- A 组：`2 ^ 3 ^ 2 = 3`
- B 组：`1 ^ 1 ^ 5 = 5`

答案 `[3, 5]`。

### 代码

```c
int* singleNumber(int* nums, int numsSize, int* returnSize) {
    // 第 1 步：全部异或，得到 a ^ b
    unsigned int x = 0;
    for (int i = 0; i < numsSize; i++) {
        x ^= (unsigned int)nums[i];
    }

    // 第 2 步：取出最低位的 1。用无符号数，x = 0x80000000 时也不会溢出
    unsigned int low = x & (0u - x);

    // 第 3 步：按这一位分组，各自异或
    int a = 0, b = 0;
    for (int i = 0; i < numsSize; i++) {
        if ((unsigned int)nums[i] & low) {
            a ^= nums[i];      // 这一位是 1 的一组
        } else {
            b ^= nums[i];      // 这一位是 0 的一组
        }
    }

    int* res = (int*)malloc(sizeof(int) * 2);
    res[0] = a;
    res[1] = b;
    *returnSize = 2;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两次遍历。
- **空间复杂度 O(1)**：几个变量。

---

## ⚠️ 第五步：小白常见错误

1. **对 `int` 直接写 `x & -x`**：当 `a ^ b` 恰好是 `0x80000000`（比如 `a = INT_MIN, b = 0`）时，`-x` 溢出。要用 `unsigned int`。
2. **判断条件写成 `(nums[i] & low) == 1`**：`low` 可能是 2、4、8……，与出来的结果是 `low` 本身而不是 1。应该判断"是否非 0"。
3. **`nums[i] & low == 0` 的优先级陷阱**：`==` 比 `&` 先算，变成 `nums[i] & (low == 0)`。位运算一定加括号。
4. **qsort 比较函数写 `return x - y`**：`INT_MAX - (-1)` 溢出，排序结果错乱。
5. **忘了设置 `*returnSize = 2`**：调用者以为返回了空数组。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 哈希表计数 | O(n) | O(n) | ⭐ | 不满足常数空间 |
| 排序后两两比较 | O(n log n) | O(1) | ⭐ | 容易想到，但不是线性 |
| 异或 + 分组 | O(n) | O(1) | ⭐⭐⭐ | 标准答案 |

## 🔗 举一反三

- **136. 只出现一次的数字**：只有一个单身数，直接全部异或。
- **137. 只出现一次的数字 II**：其余数出现三次，按位统计模 3。
- **268. 丢失的数字**：把下标 `0 ~ n` 和数组元素一起异或，丢失的数就是"单身数"。
