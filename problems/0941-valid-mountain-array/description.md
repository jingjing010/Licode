# 有效的山脉数组

数组长度至少3，存在非端点峰顶，之前严格递增、之后严格递减时是山脉。判断数组是否满足。1 ≤ n ≤ 10^4。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool validMountainArray(int* arr,int arrSize);
```

## 示例 1

输入：
```text
[0,3,2,1]
```
输出：
```text
true
```

## 示例 2

输入：
```text
[3,5,5]
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
