# 独一无二的出现次数：题解

## 📖 先读懂题目

判断数组中每个不同数值的出现次数是否互不相同。1 ≤ n ≤ 1000，元素在−1000到1000之间。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[1,2,2,1,1,3]` | `true` |
| 2 | `[1,2]` | `false` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

用一张表统计元素次数，再用另一张表记录次数是否已经出现。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
bool uniqueOccurrences(int *arr, int arrSize) {
    int counts[2001] = {0};
    bool seen[1001] = {false};
    for (int i = 0; i < arrSize; ++i)
        ++counts[arr[i] + 1000];
    /* 先数值计数，再检查各非零次数是否重复。 */
    for (int i = 0; i < 2001; ++i)
        if (counts[i]) {
            if (seen[counts[i]])
                return false;
            seen[counts[i]] = true;
        }
    return true;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n+2001)，空间 O(3002) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
