# 283. 移动零 —— 小白详细题解

> 这是一道练习**快慢双指针**的经典简单题，和「26. 删除有序数组中的重复项」是同一个套路。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把数组里所有的 `0` 都"赶"到最后面去，其余的数字**保持原来的先后顺序**排在前面。而且只能在原数组上改，不能新建一个数组再整体拷贝回去。

拿示例 1 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 修改前 | 0 | 1 | 0 | 3 | 12 |
| 修改后 | **1** | **3** | **12** | 0 | 0 |

非零元素 `1, 3, 12` 的先后顺序没有变，两个 `0` 都跑到了末尾。

**几个需要注意的细节：**

1. 函数返回 `void`，判题程序看的是**你改完之后的 `nums`**。
2. 非零元素的**相对顺序不能变**：`[1,3,12,0,0]` 对，`[12,3,1,0,0]` 错。
3. 数组里可能有负数，也可能**没有 0** 或者**全是 0**。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 为什么函数里改 `nums`，外面能看到？

`int* nums` 是一个指针，指向调用者的那块数组内存。`nums[i] = 0;` 是顺着地址**直接改原数组**，所以返回 `void` 也没关系。

### 2. 如何交换两个变量

C 语言没有内置的 `swap`，要借助一个临时变量：

```c
int t = a;   // 先把 a 存起来
a = b;       // a 被 b 覆盖
b = t;       // 把原来的 a 给 b
```

直接写 `a = b; b = a;` 是错的——第一句执行完 `a` 的旧值就丢了。

---

## 💡 第三步：思路一 —— 先挪非零，再补 0

### 思路

1. 用下标 `k` 表示"下一个非零元素应该写到哪"，一开始 `k = 0`。
2. 从左到右扫描，遇到非零的 `nums[i]`，就写到 `nums[k]`，然后 `k++`。
3. 扫描完后，前 `k` 个就是按原顺序排好的非零元素，把 `nums[k]` 到末尾全部填 `0`。

> ❓ 为什么写 `nums[k]` 不会覆盖还没读的数？因为 `k` 永远 `<= i`，写的位置不会跑到读的位置前面。

### 手动模拟（示例 1：`nums = [0,1,0,3,12]`）

| i | nums[i] | 非零？ | 操作 | k | 数组 |
|---|---|---|---|---|---|
| 0 | 0 | 否 | 跳过 | 0 | [0,1,0,3,12] |
| 1 | 1 | 是 | nums[0] = 1 | 1 | [1,1,0,3,12] |
| 2 | 0 | 否 | 跳过 | 1 | [1,1,0,3,12] |
| 3 | 3 | 是 | nums[1] = 3 | 2 | [1,3,0,3,12] |
| 4 | 12 | 是 | nums[2] = 12 | 3 | [1,3,12,3,12] |

最后把下标 3、4 填 0：`[1,3,12,0,0]`。

### 代码

```c
void moveZeroes(int* nums, int numsSize) {
    int k = 0;                              // 下一个非零元素要放的位置

    // 1. 把所有非零元素按顺序挪到前面
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] != 0) {
            nums[k] = nums[i];
            k++;
        }
    }

    // 2. 剩下的位置全部填 0
    for (int i = k; i < numsSize; i++) {
        nums[i] = 0;
    }
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两个循环各走最多 n 步。
- **空间复杂度 O(1)**：只用了 `i`、`k`。

## 🚀 第四步：思路二 —— 一遍交换（减少操作次数）

### 思路

思路一在"补 0"时还要再写一遍。能不能一遍就搞定？

把"写到 `nums[k]`"换成"**交换** `nums[i]` 和 `nums[k]`"：

- `nums[0..k-1]` 永远是处理好的非零元素；
- `nums[k..i-1]` 永远全是 0；
- 遇到非零的 `nums[i]`，和 `nums[k]`（一个 0，或者 `k == i` 时就是它自己）交换，非零区就扩大一格。

### 手动模拟（示例 1）

| i | nums[i] | 操作 | k | 数组 |
|---|---|---|---|---|
| 0 | 0 | 跳过 | 0 | [0,1,0,3,12] |
| 1 | 1 | 交换 nums[1] 和 nums[0] | 1 | [1,0,0,3,12] |
| 2 | 0 | 跳过 | 1 | [1,0,0,3,12] |
| 3 | 3 | 交换 nums[3] 和 nums[1] | 2 | [1,3,0,0,12] |
| 4 | 12 | 交换 nums[4] 和 nums[2] | 3 | [1,3,12,0,0] |

### 代码

```c
void moveZeroes(int* nums, int numsSize) {
    int k = 0;                              // 慢指针：nums[0..k-1] 是已经放好的非零元素
    for (int i = 0; i < numsSize; i++) {    // 快指针：扫描每个元素
        if (nums[i] != 0) {
            // 把非零元素换到慢指针的位置，原来那里的 0 被换到后面
            int t = nums[i];
            nums[i] = nums[k];
            nums[k] = t;
            k++;
        }
    }
}
```

### 复杂度分析

- **时间复杂度 O(n)**：只扫描一遍。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **遇到 0 就把后面整体往前挪一格** → 结果虽然对，但每次挪动是 O(n)，总共 O(n²)；而且连续两个 0 时，挪完 `i++` 会跳过新挪过来的 0。
2. **交换写成 `nums[i] = nums[k]; nums[k] = nums[i];`** → 第一句就把 `nums[i]` 覆盖了，两个位置变成同一个值。
3. **思路一忘了补 0** → `[0,1,0,3,12]` 会得到 `[1,3,12,3,12]`。
4. **新建数组再 `return`** → 函数是 `void`，返回不了；如果把 `nums = 新数组;` 只是改了局部指针，外面看不到。
5. **用"首尾交换"把 0 换到最后** → 0 是到末尾了，但非零元素的相对顺序被打乱，判 Wrong Answer。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 写操作次数 | 建议 |
|---|---|---|---|---|
| 先挪非零再补 0 | O(n) | O(1) | 固定 n 次 | 最好理解 |
| 一遍交换 | O(n) | O(1) | 2 × 非零个数 | 0 很少时更省 |
