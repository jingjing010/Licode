# 72. 编辑距离 —— 小白详细题解

> 编辑距离是字符串动态规划的"终极 Boss"之一，拼写检查、DNA 比对都在用它。不过只要把三种操作和 dp 表的"上、左、左上"对应起来，它其实和 1143 最长公共子序列是同一个套路。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 你可以对 `word1` 做三种操作：**插入**一个字符、**删除**一个字符、**替换**一个字符。问最少操作几次能把它变成 `word2`？

拿示例 1 `word1 = "horse"`、`word2 = "ros"` 来说：

| 步骤 | 操作 | 结果 |
|---|---|---|
| 0 | 初始 | horse |
| 1 | 把 h 替换成 r | rorse |
| 2 | 删除第 3 个字符 r | rose |
| 3 | 删除 e | ros |

一共 **3** 步，没有更少的办法。

**几个需要注意的细节：**

1. 字符串**可能是空串**。空串变成 `"abc"` 需要插入 3 次；`"abc"` 变成空串需要删除 3 次。
2. 三种操作代价都是 1。
3. 只需要返回最少次数，不需要输出具体步骤。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 二维 dp 表要放在哪？

最大 501 × 501 个 `int`，约 1MB。写成函数里的局部数组 `int dp[501][501];` 会占用约 1MB **栈**空间，在 Windows 上很可能直接栈溢出。安全做法是加 `static`（放到静态区）或者用 `malloc`。

### 2. 三个数取最小值

```c
static int min3(int a, int b, int c) {
    int m = a < b ? a : b;   // 先在 a、b 里取小的
    return m < c ? m : c;    // 再和 c 比
}
```

### 3. 字符串下标与 dp 下标错开一位

`dp[i][j]` 表示"前 i 个字符"，所以它对应的最后一个字符是 `word1[i-1]`，不是 `word1[i]`。这是这类题最容易写错的地方。

---

## 💡 第三步：思路一 —— 二维动态规划

### 思路

定义 `dp[i][j]` = 把 `word1` 的**前 i 个字符**变成 `word2` 的**前 j 个字符**，最少需要几步。

**边界**：

- `dp[i][0] = i`：前 i 个字符变成空串，删 i 次。
- `dp[0][j] = j`：空串变成前 j 个字符，插 j 次。

**转移**：看两个前缀的最后一个字符 `word1[i-1]` 和 `word2[j-1]`。

- **相等**：最后一个字符不用动，`dp[i][j] = dp[i-1][j-1]`。
- **不等**：三种操作选代价最小的，再 +1：

| 操作 | 含义 | 来自 | 在表里的位置 |
|---|---|---|---|
| 替换 | 把 `word1[i-1]` 改成 `word2[j-1]`，然后前面的对齐 | `dp[i-1][j-1]` | 左上 ↖ |
| 删除 | 删掉 `word1[i-1]`，用 word1 前 i-1 个去对齐 word2 前 j 个 | `dp[i-1][j]` | 上方 ↑ |
| 插入 | 在 word1 末尾插入 `word2[j-1]`，再让 word1 前 i 个去对齐 word2 前 j-1 个 | `dp[i][j-1]` | 左方 ← |

### 手动模拟（示例 1：`"horse"` → `"ros"`）

| | "" | r | o | s |
|---|---|---|---|---|
| **""** | 0 | 1 | 2 | 3 |
| **h** | 1 | 1 | 2 | 3 |
| **o** | 2 | 2 | 1 ↖ | 2 |
| **r** | 3 | 2 ↖ | 2 | 2 |
| **s** | 4 | 3 | 3 | 2 ↖ |
| **e** | 5 | 4 | 4 | **3** |

举两个格子说明：

- `dp[1][1]`（h → r）：不相等，min(左上 0, 上 1, 左 1) + 1 = **1**（替换）。
- `dp[2][2]`（ho → ro）：o == o，直接等于左上 `dp[1][1]` = **1**。

右下角 3 就是答案。

### 代码

```c
int minDistance(char* word1, char* word2) {
    int m = (int)strlen(word1);
    int n = (int)strlen(word2);
    static int dp[501][501];                 // static：约 1MB，不能放在栈上

    for (int i = 0; i <= m; i++) dp[i][0] = i;   // 删光 i 个字符
    for (int j = 0; j <= n; j++) dp[0][j] = j;   // 从空串插入 j 个字符

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (word1[i - 1] == word2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1];          // 最后一个字符相同，不用操作
            } else {
                int rep = dp[i - 1][j - 1];           // 替换
                int del = dp[i - 1][j];               // 删除
                int ins = dp[i][j - 1];               // 插入
                int best = rep < del ? rep : del;
                if (ins < best) best = ins;
                dp[i][j] = best + 1;
            }
        }
    }
    return dp[m][n];
}
```

### 复杂度分析

- **时间复杂度 O(m × n)**：500 × 500 = 2.5×10⁵ 个格子。
- **空间复杂度 O(m × n)**。

> 💬 如果直接写递归"三种操作都试一遍"而不记忆结果，时间是指数级的（大约 3^(m+n)），长度几十就跑不动了。dp 表就是把每个 `(i, j)` 的结果记下来，只算一次。

---

## 🚀 第四步：思路二 —— 滚动数组（空间优化到一行）

### 思路

算第 `i` 行只需要第 `i-1` 行，所以用一个一维数组 `dp[j]` 原地滚动即可。和 1143 题一样，**左上角**会在本行被覆盖，需要用变量 `leftUp` 提前保存：

| 需要的值 | 在一维数组里 |
|---|---|
| 上方 `dp[i-1][j]` | 覆盖前的 `dp[j]` |
| 左方 `dp[i][j-1]` | 本行刚算好的 `dp[j-1]` |
| 左上 `dp[i-1][j-1]` | 变量 `leftUp` |

还要注意：每一行的 `dp[0]` 要更新成 `i`（对应边界 `dp[i][0] = i`），更新之前先把旧的 `dp[0]` 存进 `leftUp`。

### 手动模拟（处理第 2 行 `o`；上一行是 `[1,1,2,3]`）

| j | word2[j-1] | 上方（旧 dp[j]） | 左上 leftUp | 左方 dp[j-1] | 新 dp[j] |
|---|---|---|---|---|---|
| 0 | — | 1 | — | — | 2（= i） |
| 1 | r | 1 | 1 | 2 | 不等：min(1,1,2)+1 = 2 |
| 2 | o | 2 | 1 | 2 | 相等：leftUp = **1** |
| 3 | s | 3 | 2 | 1 | 不等：min(2,3,1)+1 = 2 |

得到 `[2,2,1,2]`，与二维表第 2 行一致。

### 代码

```c
int minDistance(char* word1, char* word2) {
    int m = (int)strlen(word1);
    int n = (int)strlen(word2);
    int* dp = (int*)malloc(sizeof(int) * (n + 1));

    for (int j = 0; j <= n; j++) dp[j] = j;      // 第 0 行：空串变成前 j 个字符

    for (int i = 1; i <= m; i++) {
        int leftUp = dp[0];                      // 保存 dp[i-1][0]，它是 j=1 时的左上
        dp[0] = i;                               // dp[i][0] = i
        for (int j = 1; j <= n; j++) {
            int up = dp[j];                      // 覆盖前保存上方 dp[i-1][j]
            if (word1[i - 1] == word2[j - 1]) {
                dp[j] = leftUp;                  // 相同：直接继承左上
            } else {
                int best = leftUp;               // 替换
                if (up < best) best = up;        // 删除
                if (dp[j - 1] < best) best = dp[j - 1];   // 插入
                dp[j] = best + 1;
            }
            leftUp = up;                         // 右移一格：旧的上方变成新的左上
        }
    }

    int ans = dp[n];
    free(dp);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(m × n)**。
- **空间复杂度 O(n)**。

---

## ⚠️ 第五步：小白常见错误

1. **边界初始化成 0** → `dp[i][0]` 应该是 `i`、`dp[0][j]` 应该是 `j`。全写 0 的话，空串和 `"abc"` 的距离会算成 0。
2. **相等时也 +1** `dp[i][j] = dp[i-1][j-1] + 1` → 相同字符不需要任何操作，结果会偏大。
3. **下标错位** → 比较 `word1[i]` 和 `word2[j]` 而不是 `word1[i-1]`、`word2[j-1]`，会漏比第一个字符，还会读到 `'\0'`。
4. **局部数组 `int dp[501][501]` 不加 `static`** → 约 1MB 的栈空间，可能直接运行错误。
5. **滚动数组忘了更新 `dp[0] = i`** → 每一行的边界都停留在第 0 行的值，结果偏小。
6. **滚动数组中先改 `dp[0]` 再保存 `leftUp`** → `leftUp` 拿到的是新值 `i`，而不是上一行的 `i-1`。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力递归 | 指数级 | O(m + n) | ⭐ | 只用于理解三种操作 |
| 二维 DP | O(mn) | O(mn) | ⭐⭐⭐ | 先画表，推荐掌握 |
| 滚动数组 | O(mn) | O(n) | ⭐⭐⭐⭐ | 理解后再优化 |
