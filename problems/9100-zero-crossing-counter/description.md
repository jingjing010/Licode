# 忽略零平台的过零计数

计算非零符号变化次数，忽略所有值为0的采样；开头无前一符号所以不计数。输入int16范围，0到1000项。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int zeroCrossings(int* samples,int samplesSize);
```

## 示例 1

输入：
```text
[-1,0,0,1,0,-1]
```
输出：
```text
2
```

## 示例 2

输入：
```text
[0,0,0]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：samples。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
