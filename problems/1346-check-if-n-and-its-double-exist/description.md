# 检查整数及其两倍数是否存在

判断是否存在不同下标i,j，使arr[i]==2*arr[j]。2 ≤ n ≤ 500，元素−1000到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool checkIfExist(int* arr,int arrSize);
```

## 示例 1

输入：
```text
[10,2,5,3]
```
输出：
```text
true
```

## 示例 2

输入：
```text
[3,1,7,11]
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
