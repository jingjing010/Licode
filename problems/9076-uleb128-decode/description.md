# ULEB128 无符号整数解码

输入保证为9075定义的最短合法uint32_t编码，长度1到5，第5字节至多0x0F。返回无符号十进制整数。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint32_t uleb128Decode(const uint8_t* data,size_t len);
```

## 示例 1

输入：
```text
[229,142,38]
```
输出：
```text
624485
```

## 示例 2

输入：
```text
[0]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
