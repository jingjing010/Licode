# ULEB128 可变长整数编码

把uint32_t编码为最短无符号LEB128，0编码为[0]。返回字节整数数组，输入0到4294967295。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* uleb128Encode(uint32_t value,int* returnSize);
```

## 示例 1

输入：
```text
624485
```
输出：
```text
[229,142,38]
```

## 示例 2

输入：
```text
0
```
输出：
```text
[0]
```

## 自定义输入格式

按顺序每行一个参数：value。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
