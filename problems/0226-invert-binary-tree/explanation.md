# 226. 翻转二叉树 —— 小白详细题解

> 一道"照镜子"的题：把整棵树左右镜像过来。它能帮你真正理解"修改指针"和"递归处理子树"。

---

## 📖 第一步：先读懂题目

**翻转**就是把每一个结点的左孩子和右孩子**互换**，最终整棵树变成原来的镜像。

示例 1：

```
     4                4
   /   \            /   \
  2     7    =>    7     2
 / \   / \        / \   / \
1   3 6   9      9   6 3   1
```

| 结点 | 翻转前 (左, 右) | 翻转后 (左, 右) |
|---|---|---|
| 4 | (2, 7) | (7, 2) |
| 2 | (1, 3) | (3, 1) |
| 7 | (6, 9) | (9, 6) |
| 1、3、6、9 | (空, 空) | (空, 空) |

层序输出：`[4,7,2,9,6,3,1]`。

**几个需要注意的细节：**

1. 不只是根结点要换，**每一个**结点都要换，否则只翻转了第一层。
2. 交换的是**指针**（整棵子树一起搬过去），不是交换数值。
3. 空树直接返回 `NULL`。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 交换两个变量需要"临时变量"

```c
struct TreeNode* tmp = root->left;   // 先把左边存起来
root->left = root->right;            // 左边 = 右边
root->right = tmp;                   // 右边 = 原来的左边
```

如果直接写 `root->left = root->right; root->right = root->left;`，第二句执行时 `root->left` 已经被覆盖了，左子树就丢了。

### 2. 修改指针 vs 修改数值

`root->left = ...` 是让 `root` 的"左手"指向另一个结点，原来那个结点并没有被删除或复制。所以翻转不需要 `malloc`，直接改指针即可。

---

## 💡 第三步：思路一 —— 递归

### 思路

1. 空树：直接返回 `NULL`。
2. 交换当前结点的左右指针。
3. 递归翻转左子树、递归翻转右子树（顺序无所谓）。
4. 返回 `root`。

### 手动模拟（示例 2：`[2,1,3]`）

| 步骤 | 当前结点 | 操作 | 树的样子 |
|---|---|---|---|
| 1 | 2 | 交换左右 | 2 的左=3，右=1 |
| 2 | 3 | 交换左右（都为空） | 不变 |
| 3 | 1 | 交换左右（都为空） | 不变 |

结果 `[2,3,1]`。

### 代码

```c
struct TreeNode* invertTree(struct TreeNode* root) {
    if (root == NULL) return NULL;           // 递归出口：空树不用翻转

    // 1. 交换当前结点的左右孩子（用临时变量）
    struct TreeNode* tmp = root->left;
    root->left = root->right;
    root->right = tmp;

    // 2. 再分别翻转左右两棵子树
    invertTree(root->left);
    invertTree(root->right);

    return root;                             // 根结点没变，返回它
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点交换一次。
- **空间复杂度 O(h)**：递归栈深度为树高。

---

## 🚀 第四步：思路二 —— 层序遍历（迭代）

### 思路

"每个结点都交换一次左右孩子"——访问顺序其实无所谓，只要**每个结点都被访问到**。所以也可以用队列一层一层地访问，访问时交换。

### 代码

```c
struct TreeNode* invertTree(struct TreeNode* root) {
    if (root == NULL) return NULL;

    struct TreeNode* queue[100];             // 最多 100 个结点
    int head = 0, tail = 0;
    queue[tail++] = root;

    while (head < tail) {
        struct TreeNode* node = queue[head++];          // 出队

        struct TreeNode* tmp = node->left;              // 交换左右孩子
        node->left = node->right;
        node->right = tmp;

        if (node->left)  queue[tail++] = node->left;    // 孩子入队，稍后处理
        if (node->right) queue[tail++] = node->right;
    }
    return root;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(n)**（队列）。

---

## ⚠️ 第五步：小白常见错误

1. **交换时没用临时变量**：`root->left = root->right; root->right = root->left;` → 两边都变成了原来的右子树。
2. **只交换了根结点**：忘了递归，只有第一层被翻转。
3. **交换数值而不是指针**：`int t = root->left->val; ...` 不仅不对（子树结构没变），还会在孩子为空时崩溃。
4. **写成"先递归再用返回值赋值"却搞乱了顺序**：
   ```c
   root->left = invertTree(root->right);   // ❌ 这时 root->left 已被覆盖
   root->right = invertTree(root->left);   //    这里拿到的是新的 left，原左子树丢了
   ```
   正确写法是先用两个变量把结果存下来再赋值。
5. **忘记返回 `root`**：函数末尾没有 `return root;`，输出是乱的。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 递归 | O(n) | O(h) | ⭐ | 首选 |
| 层序遍历 | O(n) | O(n) | ⭐⭐ | 理解"访问顺序无所谓" |
