# 2. 两数相加 —— 小白详细题解

> 这道题本质上就是小学的**竖式加法**，只不过数字存在链表里。难点在于：进位、两个链表长度不同、最后多出来的那一位。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 每个链表表示一个整数，但是**倒着存**的：头结点是个位，第二个结点是十位……把两个数加起来，结果也用同样倒着存的链表返回。

示例 1：`l1 = [2,4,3]` 表示 **342**，`l2 = [5,6,4]` 表示 **465**，342 + 465 = **807**，倒着存就是 `[7,0,8]`。

倒着存反而方便！因为竖式加法正是**从个位开始**算的：

| 位 | l1 | l2 | 进位（来自上一位） | 和 | 这一位写 | 新进位 |
|---|---|---|---|---|---|---|
| 个位 | 2 | 5 | 0 | 7 | 7 | 0 |
| 十位 | 4 | 6 | 0 | 10 | 0 | 1 |
| 百位 | 3 | 4 | 1 | 8 | 8 | 0 |

结果 `[7,0,8]`。

**几个需要注意的细节：**

1. 两个链表**长度可能不同**（示例 3：7 位 + 4 位）。短的走完了就当作 0。
2. 加完最后一位，如果还有进位（比如 5 + 5 = 10），要**额外补一个结点 1**。
3. 链表最长 100 个结点，也就是 100 位的数字——`long long` 最多存 19 位，**根本装不下**，不能转成整数再加。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `/` 和 `%` 拆出"本位"和"进位"

```c
int sum = 4 + 6 + 0;   // 10
int digit = sum % 10;  // 0：这一位写 0
int carry = sum / 10;  // 1：向下一位进 1
```

### 2. 用 `malloc` 创建新结点

```c
struct ListNode* node = (struct ListNode*)malloc(sizeof(struct ListNode));
node->val = digit;
node->next = NULL;     // 新结点暂时是最后一个，next 一定要设为 NULL
```

### 3. 哑结点（dummy）

在真正的头结点前面放一个"假头"，所有新结点都接在 `tail` 后面，最后返回 `dummy.next`。这样就**不用单独处理"第一个结点"**的情况。

```c
struct ListNode dummy;      // 假头，放在栈上即可，不需要 malloc
dummy.next = NULL;
struct ListNode* tail = &dummy;   // tail 永远指向结果链表的最后一个结点
```

### ❌ 为什么不能转成整数？

```c
long long a = 0;      // ❌ 错误示范
// 把 l1 转成整数 a、l2 转成整数 b，再把 a + b 拆回链表……
// 100 位的数远远超过 long long 的范围（约 9.2 × 10^18），会溢出得到错误结果
```

---

## 💡 第三步：思路一 —— 模拟竖式加法（迭代）

### 思路

用两个指针同时从两个链表的头（个位）往后走，每一步：

1. `sum = (l1 这一位，没有就是 0) + (l2 这一位，没有就是 0) + carry`
2. 新建结点存 `sum % 10`，接到结果链表尾部
3. `carry = sum / 10`

循环条件：**只要 l1 没走完、或 l2 没走完、或还有进位**，就继续。把 `carry` 放进循环条件，最后多出来的进位就自动处理了。

### 手动模拟（示例 3：`[9,9,9,9,9,9,9] + [9,9,9,9]`）

| 位 | l1 | l2 | carry | sum | 写入 | 新 carry |
|---|---|---|---|---|---|---|
| 1 | 9 | 9 | 0 | 18 | 8 | 1 |
| 2 | 9 | 9 | 1 | 19 | 9 | 1 |
| 3 | 9 | 9 | 1 | 19 | 9 | 1 |
| 4 | 9 | 9 | 1 | 19 | 9 | 1 |
| 5 | 9 | 无(0) | 1 | 10 | 0 | 1 |
| 6 | 9 | 无(0) | 1 | 10 | 0 | 1 |
| 7 | 9 | 无(0) | 1 | 10 | 0 | 1 |
| 8 | 无 | 无 | 1 | 1 | 1 | 0 |

结果 `[8,9,9,9,0,0,0,1]`。

### 代码

```c
struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode dummy;              // 哑结点：结果链表的"假头"
    dummy.next = NULL;
    struct ListNode* tail = &dummy;     // tail 指向结果链表的最后一个结点
    int carry = 0;                      // 进位，只可能是 0 或 1

    // 只要还有没加完的位，或者还有进位，就继续
    while (l1 != NULL || l2 != NULL || carry != 0) {
        int sum = carry;
        if (l1 != NULL) {               // l1 还有这一位
            sum += l1->val;
            l1 = l1->next;
        }
        if (l2 != NULL) {               // l2 还有这一位
            sum += l2->val;
            l2 = l2->next;
        }

        // 新建结点存放这一位的数字
        struct ListNode* node = (struct ListNode*)malloc(sizeof(struct ListNode));
        node->val = sum % 10;
        node->next = NULL;

        tail->next = node;              // 接到结果链表末尾
        tail = node;                    // tail 后移
        carry = sum / 10;               // 计算新的进位
    }
    return dummy.next;                  // 跳过假头，返回真正的头结点
}
```

### 复杂度分析

- **时间复杂度 O(max(m, n))**：较长的链表有多少位就循环多少次（最多再多 1 次进位）。
- **空间复杂度 O(1)**：除了返回的结果链表，只用了几个变量。

## 🚀 第四步：思路二 —— 递归写法

### 思路

把"这一位 + 剩下的位"看成一个子问题：

> `add(l1, l2, carry)` = 一个存放 `(l1位 + l2位 + carry) % 10` 的结点，它的 `next` 是 `add(l1->next, l2->next, 新进位)`。

当 `l1`、`l2` 都为空且没有进位时，返回 `NULL`。

### 代码

```c
// 把 l1、l2 从当前位开始相加，并加上来自低位的进位 carry
static struct ListNode* addWithCarry(struct ListNode* l1, struct ListNode* l2, int carry) {
    if (l1 == NULL && l2 == NULL && carry == 0) return NULL;   // 全部加完

    int sum = carry;
    if (l1 != NULL) { sum += l1->val; l1 = l1->next; }
    if (l2 != NULL) { sum += l2->val; l2 = l2->next; }

    struct ListNode* node = (struct ListNode*)malloc(sizeof(struct ListNode));
    node->val = sum % 10;
    node->next = addWithCarry(l1, l2, sum / 10);   // 剩下的位交给递归
    return node;
}

struct ListNode* addTwoNumbers(struct ListNode* l1, struct ListNode* l2) {
    return addWithCarry(l1, l2, 0);
}
```

### 复杂度分析

- **时间复杂度 O(max(m, n))**。
- **空间复杂度 O(max(m, n))**：递归调用栈的深度。本题最多 101 层，完全没问题。

---

## ⚠️ 第五步：小白常见错误

1. **转成 `int` / `long long` 再相加**：100 位的数会溢出，结果错误。
2. **忘记最后的进位**：循环条件只写 `l1 != NULL || l2 != NULL`，`[5] + [5]` 会得到 `[0]` 而不是 `[0,1]`。
3. **短链表走完后还访问 `l1->val`**：`l1` 已经是 `NULL`，访问 `l1->val` 会崩溃。必须先判断 `l1 != NULL`。
4. **新结点的 `next` 没有设成 `NULL`**：`malloc` 出来的内存里是随机值，输出时会顺着野指针乱走，导致崩溃。
5. **返回 `&dummy` 而不是 `dummy.next`**：会多输出一个随机值的假头结点。更严重的是 `dummy` 是局部变量，返回它的地址是错误的。
6. **把结果正着存**：题目要求结果也是逆序（个位在前），直接按计算顺序往后接就是对的，不要再反转。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 转成整数相加 | - | - | ⭐ | ❌ 会溢出，不可行 |
| 迭代模拟竖式 | O(max(m,n)) | O(1) | ⭐⭐ | **推荐**，标准写法 |
| 递归 | O(max(m,n)) | O(max(m,n)) | ⭐⭐ | 练习递归思维 |

> 🎯 **学习建议**：哑结点 + 尾指针 `tail` 是"构造新链表"的万能模板，第 21 题合并有序链表也是这么写的，一定要熟练。
