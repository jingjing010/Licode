在单片机上，`printf` 动辄占用几 KB 的 Flash 和大量栈空间，很多项目会自己写一个轻量的 `itoa`，用来在串口日志、LCD 屏幕、数码管上显示数字：十进制显示温度，十六进制显示寄存器值，二进制显示 GPIO 状态。

请实现函数 `my_itoa`：把整数 `value` 按 `base` 进制转换成字符串，写入调用者提供的缓冲区 `buf`，并**返回 `buf`**。

- `base` 的范围是 `2 ~ 16`，大于 9 的数字用**大写字母** `A~F` 表示
- **只有 `base == 10` 时**负数前面加 `'-'`；其它进制下把 `value` 当作 `uint32_t` 处理（与常见的 `itoa` 实现一致），例如 `-1` 的十六进制是 `"FFFFFFFF"`
- 不输出前导 0（`0` 本身输出 `"0"`），不加 `0x` 等前缀
- 结果以 `'\0'` 结尾；`buf` 至少有 34 个字节，足够放下最长的结果
- 不要使用 `sprintf` 等格式化函数

### 示例 1

```
输入：value = 1234, base = 10
输出："1234"
```

### 示例 2

```
输入：value = -255, base = 10
输出："-255"
```

### 示例 3

```
输入：value = 255, base = 16
输出："FF"
```

### 提示

- `-2147483648 <= value <= 2147483647`
- `2 <= base <= 16`

### 函数说明

```c
char* my_itoa(int32_t value, char* buf, int base);
```

- `value`：要转换的整数
- `buf`：输出缓冲区（调用者分配，至少 34 字节）
- `base`：进制
- 返回值：`buf`（判题程序会检查返回的指针是不是 `buf`）

### 自定义输入格式

```
1234
10
```

第 1 行是 `value`，第 2 行是 `base`。输出为带双引号的结果字符串。
