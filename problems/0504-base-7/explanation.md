# 七进制数：题解

## 📖 先读懂题目

将 −10^7 ≤ num ≤ 10^7 的整数转为七进制字符串。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `100` | `"202"` |
| 2 | `-7` | `"-10"` |

## 🧰 需要的 C 语言知识

申请输出字符串时，要在有效字符之外多留1字节写入结束符。参考实现返回动态内存，由调用方负责释放。

## 💡 推导与实现

重复除7收集余数，负号单独处理，最后反转所有字符。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
char *convertToBase7(int num) {
    long long x = num;
    bool negative = x < 0;
    if (negative)
        x = -x;
    char tmp[32];
    int n = 0;
    do {
        tmp[n++] = '0' + x % 7;
        x /= 7;
    } while (x);
    if (negative)
        tmp[n++] = '-';
    char *out = malloc(n + 1);
    /* 余数按低位到高位产生，需要倒序输出。 */
    for (int i = 0; i < n; ++i)
        out[i] = tmp[n - 1 - i];
    out[n] = 0;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(log n)，额外空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 只申请有效字符数大小的缓冲区，没有给结束符留空间。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。

## 🔗 举一反三

尝试把同一处理过程改成逐个输入的流式接口，思考需要保留哪些状态。用空边界、最小值、最大值和重复值检查自己的实现。
