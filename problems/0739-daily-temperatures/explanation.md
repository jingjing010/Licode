# 739. 每日温度 —— 小白详细题解

> **单调栈**的模板题。一句话记住它的用途：快速找到每个元素"右边第一个比它大的数"。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 每天有一个温度。对于每一天，问：**还要再等几天**才会遇到比今天更热的一天？永远等不到就填 0。

示例 1：`temperatures = [73,74,75,71,69,72,76,73]`

| 下标 i | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 温度 | 73 | 74 | 75 | 71 | 69 | 72 | 76 | 73 |
| 下一个更热的是第几天 | 1 | 2 | 6 | 5 | 5 | 6 | 无 | 无 |
| answer[i] | 1 | 1 | **4** | 2 | 1 | 1 | 0 | 0 |

第 2 天是 75 度，后面 71、69、72 都不比它热，要等到第 6 天的 76 度，所以 `answer[2] = 6 - 2 = 4`。

**几个需要注意的细节：**

1. 要的是**天数差**（下标差），不是温度值。
2. **相等不算更热**：`[50,50]` 的答案是 `[0,0]`。
3. n 最大 10⁵，O(n²) 的暴力最坏要算 5×10⁹ 次，会超时。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `calloc`：申请并清零

```c
int* ans = (int*)calloc(n, sizeof(int));   // n 个 int，全部初始化为 0
```

和 `malloc(n * sizeof(int))` 的区别是：`calloc` 会把内存清零。本题"等不到更热的一天填 0"，用 `calloc` 就不用再手动初始化了。

### 2. 数组模拟栈（存下标）

```c
int* stack = (int*)malloc(sizeof(int) * n);
int top = 0;                 // 栈里元素个数
stack[top++] = i;            // 压入下标 i
int j = stack[--top];        // 弹出栈顶
stack[top - 1]               // 看栈顶（top > 0 时才能看）
```

栈里存**下标**而不是温度，因为下标既能算天数差，又能通过 `temperatures[下标]` 拿到温度。

---

## 💡 第三步：思路一 —— 暴力往后找（会超时）

对每一天 i，从 i+1 开始往后找第一个更热的：

```c
// ❌ 思路正确，但最坏 O(n²)：温度一直下降时，每天都要找到最后
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        if (temperatures[j] > temperatures[i]) {
            ans[i] = j - i;
            break;
        }
    }
}
```

n = 10⁵、温度全部相同时，内层循环总共要跑约 5×10⁹ 次，必然超时。

---

## 💡 第四步：思路二 —— 利用"温度只有 71 种"（从后往前扫）

### 思路

温度范围只有 30~100。从**最后一天往前**扫，用数组 `next[t]` 记录"温度 t 在当前位置之后**最早**出现在哪一天"。

到第 i 天时，只要查一遍 `next[temperatures[i]+1 .. 100]`，取其中最小的下标，就是第一个更热的日子。查完再把 `next[temperatures[i]] = i`。

### 代码

```c
int* dailyTemperatures(int* temperatures, int temperaturesSize, int* returnSize) {
    int n = temperaturesSize;
    int* ans = (int*)calloc(n, sizeof(int));
    int next[101];                         // next[t]：温度 t 在后面最早出现的下标
    for (int t = 0; t <= 100; t++) next[t] = INT_MAX;   // INT_MAX 表示还没出现过

    for (int i = n - 1; i >= 0; i--) {     // 从后往前
        int best = INT_MAX;
        for (int t = temperatures[i] + 1; t <= 100; t++) {
            if (next[t] < best) best = next[t];   // 所有更高温度里最早的那天
        }
        if (best != INT_MAX) ans[i] = best - i;
        next[temperatures[i]] = i;         // 更新：今天的温度最早出现在 i
    }
    *returnSize = n;
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(70n)**：每天最多查 70 个温度，约 7×10⁶ 次，很快。
- **空间复杂度 O(1)**：`next` 只有 101 个格子（返回数组不算）。

缺点：依赖"温度范围很小"这个条件。如果温度可以到 10⁹ 就不行了。

---

## 🚀 第五步：思路三 —— 单调栈（通用解法）

### 思路

换个角度：**从左往右扫，今天能"解决"前面哪些日子？**

用一个栈存"还没等到更热天气"的日子的下标。对于今天 i：

- 只要栈顶那天比今天冷，它就等到了！弹出它，`ans[栈顶] = i - 栈顶`；
- 一直弹，直到栈空或栈顶不比今天冷；
- 最后把今天压进栈，等待未来更热的日子。

栈里的温度从底到顶一定是**单调不增**的（比今天冷的都被弹走了），所以叫"单调栈"。

### 手动模拟（示例 1）

| i | 温度 | 弹出（并记录答案） | 压栈后栈（下标:温度） |
|---|---|---|---|
| 0 | 73 | - | 0:73 |
| 1 | 74 | 0 → ans[0]=1 | 1:74 |
| 2 | 75 | 1 → ans[1]=1 | 2:75 |
| 3 | 71 | - | 2:75, 3:71 |
| 4 | 69 | - | 2:75, 3:71, 4:69 |
| 5 | 72 | 4 → ans[4]=1，3 → ans[3]=2 | 2:75, 5:72 |
| 6 | 76 | 5 → ans[5]=1，2 → ans[2]=4 | 6:76 |
| 7 | 73 | - | 6:76, 7:73 |

扫完后栈里剩下的 6、7 永远等不到，保持 0。结果 `[1,1,4,2,1,1,0,0]` ✅

### 代码

```c
int* dailyTemperatures(int* temperatures, int temperaturesSize, int* returnSize) {
    int n = temperaturesSize;
    int* ans = (int*)calloc(n, sizeof(int));   // 默认 0：等不到更热的一天
    int* stack = (int*)malloc(sizeof(int) * n); // 存下标
    int top = 0;
    for (int i = 0; i < n; i++) {
        // 栈顶那天比今天冷：它等到了今天
        while (top > 0 && temperatures[stack[top - 1]] < temperatures[i]) {
            int j = stack[--top];
            ans[j] = i - j;
        }
        stack[top++] = i;                      // 今天入栈，等待更热的日子
    }
    free(stack);
    *returnSize = n;
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：虽然有 while 套在 for 里，但每个下标**最多入栈一次、出栈一次**，总操作次数不超过 2n。
- **空间复杂度 O(n)**：栈最多存 n 个下标（温度一直下降时）。

---

## ⚠️ 第六步：小白常见错误

1. **比较写成 `<=`**：`temperatures[栈顶] <= temperatures[i]` 会把相等的温度也当成"更热"，`[50,50]` 会输出 `[1,0]`。
2. **栈里存温度而不是下标** → 弹出时算不出天数差。
3. **`while` 写成 `if`** → 一天只能解决前面一天，示例中第 5 天应该同时解决第 4 天和第 3 天。
4. **用 `malloc` 申请 ans 却不初始化** → 栈里剩下的日子答案是随机值，而不是 0。
5. **`while` 条件里先访问 `stack[top - 1]` 再判断 `top > 0`** → 栈空时越界。`&&` 是短路求值，`top > 0` 必须写在前面。
6. **忘了 `*returnSize = n`** → 输出空数组。

---

## 📊 第七步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力往后找 | O(n²) | O(1) | ⭐ | 会超时 |
| 温度数组从后往前 | O(70n) | O(1) | ⭐⭐ | 巧用数据范围 |
| 单调栈 | O(n) | O(n) | ⭐⭐⭐ | 通用模板，必须掌握 |
