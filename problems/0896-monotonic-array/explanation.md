# 896. 单调数列 —— 小白详细题解

> 判断一个数组是不是"一路不下降"或"一路不上升"。练习**布尔标记变量**的好题。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 数组要么**从头到尾不会变小**（可以持平），要么**从头到尾不会变大**（可以持平）。满足其中一种就返回 `true`。

| 示例 | 数组 | 相邻变化 | 结论 |
|---|---|---|---|
| 1 | [1,2,2,3] | ↑ = ↑ | 只有上升和持平 → 单调递增 ✅ |
| 2 | [6,5,4,4] | ↓ ↓ = | 只有下降和持平 → 单调递减 ✅ |
| 3 | [1,3,2] | ↑ ↓ | 既上升又下降 ❌ |

**几个需要注意的细节：**

1. **相等是允许的**：`[1,2,2,3]` 是单调的。
2. 全部相等（如 `[5,5,5]`）或只有一个元素，既算递增也算递减，返回 `true`。
3. 题目定义里说"所有 `i <= j`"，但其实只需要检查**相邻**的两个数：如果每一对相邻的都 `<=`，那任意两个都 `<=`（传递性）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `bool` 变量当"标记"

```c
bool up = false;           // 一开始还没见过上升
if (nums[i] > nums[i - 1]) up = true;   // 见过一次就永久标记
```

这种"先设为 false，遇到某件事就设为 true"的写法，叫**标记（flag）**，非常常用。

### 2. 逻辑运算符

- `a && b`：两个都为真才为真
- `a || b`：有一个为真就为真
- `!a`：取反

---

## 💡 第三步：思路一 —— 分别检查递增、递减

### 思路

写两个循环：

1. 检查是否单调递增：有没有一对相邻 `nums[i] < nums[i-1]`？没有就是递增。
2. 检查是否单调递减：有没有一对相邻 `nums[i] > nums[i-1]`？没有就是递减。

返回 `递增 || 递减`。

### 代码

```c
bool isMonotonic(int* nums, int numsSize) {
    bool inc = true, dec = true;            // 先假设两种都成立
    for (int i = 1; i < numsSize; i++) {
        if (nums[i] < nums[i - 1]) {        // 出现下降 → 不是递增
            inc = false;
            break;
        }
    }
    for (int i = 1; i < numsSize; i++) {
        if (nums[i] > nums[i - 1]) {        // 出现上升 → 不是递减
            dec = false;
            break;
        }
    }
    return inc || dec;                      // 满足其一即可
}
```

### 复杂度分析

- **时间复杂度 O(n)**：最多两遍扫描。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 一遍扫描 + 两个标记

### 思路

换个角度：一个数组**不是**单调的，当且仅当它**既出现过上升、又出现过下降**。

所以扫描一遍，用两个标记：

- `up`：是否出现过 `nums[i] > nums[i-1]`
- `down`：是否出现过 `nums[i] < nums[i-1]`

一旦两个都为 `true`，立刻返回 `false`；扫完都没发生，就返回 `true`。

### 手动模拟（示例 3：`[1,3,2]`）

| i | 比较 | up | down | 结果 |
|---|---|---|---|---|
| 1 | 1 → 3 上升 | true | false | 继续 |
| 2 | 3 → 2 下降 | true | true | 两个都有 → 返回 false |

### 代码

```c
bool isMonotonic(int* nums, int numsSize) {
    bool up = false;     // 是否出现过上升
    bool down = false;   // 是否出现过下降
    for (int i = 1; i < numsSize; i++) {     // 从 1 开始，和前一个比较
        if (nums[i] > nums[i - 1]) up = true;
        if (nums[i] < nums[i - 1]) down = true;
        if (up && down) return false;        // 又升又降，肯定不单调，提前结束
    }
    return true;                             // 只升、只降或一直持平
}
```

### 复杂度分析

- **时间复杂度 O(n)**：一遍扫描，还可能提前结束。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **用严格比较判断递增**：`if (nums[i] <= nums[i-1]) 不是递增` → `[1,2,2,3]` 中 `2 <= 2` 会被误判为不递增。相等是允许的！
2. **只根据前两个数决定方向** → 比如看 `nums[0]` 和 `nums[1]` 定方向，`[1,1,2,1]` 前两个相等就不知道方向了；`[2,2,1]` 如果把"相等"当成递增，后面的下降就会被误判为不单调。
3. **返回 `inc && dec`** → 只有全部相等的数组才同时满足，应该是 `||`。
4. **循环从 `i = 0` 开始访问 `nums[i - 1]`** → 越界。
5. **用减法判断方向 `nums[i] - nums[i-1]`** → 本题数值范围小不会溢出，但养成直接比较大小的习惯更安全。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 分别检查递增/递减 | O(n) | O(1) | ⭐ | 最直观 |
| 一遍扫描 + 双标记 | O(n) | O(1) | ⭐ | 更简洁，推荐 |
