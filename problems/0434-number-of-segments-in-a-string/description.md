# 字符串中的单词数

返回字符串中由连续非空格字符组成的片段数量。仅空格字符作为分隔符。长度0到300。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int countSegments(char* s);
```

## 示例 1

输入：
```text
"Hello, my name is John"
```
输出：
```text
5
```

## 示例 2

输入：
```text
"Hello"
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
