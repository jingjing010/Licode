# 257. 二叉树的所有路径 —— 小白详细题解

> 树的回溯 + C 语言字符串拼接。这道题的算法很简单，难点全在 C 语言：**怎么拼字符串、怎么返回字符串数组**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把从根走到每一个叶子的路线都写出来，结点之间用 `->` 连接。

示例 1：`[1,2,3,null,5]`

```
    1
   / \
  2   3
   \
    5
```

| 叶子 | 路径 | 字符串 |
|---|---|---|
| 5 | 1 → 2 → 5 | `"1->2->5"` |
| 3 | 1 → 3 | `"1->3"` |

结点 2 不是叶子（它有右孩子 5），所以没有 `"1->2"`。

**几个需要注意的细节：**

1. 第一个数前面**没有** `->`，只有两个数之间才有。
2. 数可能是**负数**，例如 `"-1->-10"`，要按整数完整写出。
3. 只有一个结点时，答案是 `["1"]`。
4. 树至少有一个结点，不会是空树。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. C 字符串是以 `'\0'` 结尾的 `char` 数组

`"1->3"` 在内存里是 `'1' '-' '>' '3' '\0'` 共 5 个字节。申请空间时要多留 1 个字节给 `'\0'`。

### 2. `sprintf`：把格式化结果写进字符串

```c
char buf[100];
int k = sprintf(buf, "%d", -12);       // buf = "-12"，返回写入的字符数 3（不含 '\0'）
k += sprintf(buf + k, "->%d", 5);      // 接在后面写：buf = "-12->5"
```

`buf + k` 表示"从第 k 个字符的位置开始写"，这样就实现了**追加**。`sprintf` 会自动在末尾补 `'\0'`。

### 3. 返回字符串数组 `char**`

```c
char** res = (char**)malloc(sizeof(char*) * 最多条数);   // 每个元素是一个 char*
res[0] = (char*)malloc(长度 + 1);                         // 每个字符串单独申请
```

### 4. 回溯：恢复长度就等于"删掉"后缀

缓冲区里是当前路径 `"1->2"`，进入 5 后变成 `"1->2->5"`。回到 2 时只需把"当前长度"恢复为 4（`"1->2"` 的长度），后面再写会覆盖掉旧内容——不需要真的删除字符。

---

## 💡 第三步：思路一 —— DFS + 字符缓冲区回溯

### 思路

用一个全局缓冲区 `buf` 存当前路径，`dfs(node, len)` 的 `len` 表示进入 `node` 之前路径字符串的长度：

1. 把 `node->val` 追加到 `buf + len`（`len == 0` 说明是根，不加箭头），得到新长度 `newLen`。
2. 如果是叶子：`malloc(newLen + 1)`，把 `buf` 复制进去，存入答案。
3. 否则递归左右孩子，传入 `newLen`。

因为 `len` 是值传递的参数，回到上一层后它自动是原来的值，下一次追加会从正确的位置覆盖——这就完成了回溯。

### 手动模拟（示例 1）

| 调用 | 传入 len | 追加 | buf 内容（前 newLen 个字符） | 动作 |
|---|---|---|---|---|
| dfs(1) | 0 | `1` | `1` | 递归 |
| dfs(2) | 1 | `->2` | `1->2` | 递归 |
| dfs(5) | 4 | `->5` | `1->2->5` | 叶子，保存 |
| dfs(3) | 1 | `->3` | `1->3` | 叶子，保存 |

注意 dfs(3) 是从位置 1 开始写的，把 `->2->5` 覆盖成了 `->3`（`sprintf` 写入了新的 `'\0'`）。

### 代码

```c
static char buf[1024];     // 当前路径：最多 100 个结点，每个最多 "->-100" 6 个字符
static char** res;         // 答案数组
static int cnt;            // 答案条数

// len：进入 node 之前，buf 中路径字符串的长度
static void dfs(struct TreeNode* node, int len) {
    if (node == NULL) return;
    // 根结点前面不加箭头；sprintf 返回写入的字符数
    int newLen = len + sprintf(buf + len, len == 0 ? "%d" : "->%d", node->val);
    if (node->left == NULL && node->right == NULL) {      // 叶子：保存一份
        char* s = (char*)malloc(newLen + 1);              // +1 给 '\0'
        memcpy(s, buf, newLen + 1);                       // 连 '\0' 一起复制
        res[cnt++] = s;
        return;
    }
    dfs(node->left, newLen);
    dfs(node->right, newLen);
}

char** binaryTreePaths(struct TreeNode* root, int* returnSize) {
    res = (char**)malloc(sizeof(char*) * 100);    // 叶子数不会超过结点数 100
    cnt = 0;                                      // 每次调用都重新初始化
    dfs(root, 0);
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n · h)**：遍历 O(n)，再加上复制每条路径（每条长度 O(h)，最多 O(n) 条）。这已经是输出本身的大小，不可能更快。
- **空间复杂度 O(h)**：递归栈和缓冲区（不算答案）。

## 🚀 第四步：思路二 —— BFS，每个结点带着自己的路径字符串

### 思路

层序遍历时，队列里除了结点，还存"根到这个结点的路径字符串"（每个结点一份独立的拷贝）：

1. 根入队，路径为 `"1"`。
2. 出队 `(node, path)`：如果是叶子，`path` 直接作为一个答案。
3. 否则为每个孩子生成新字符串 `path + "->" + 孩子值`，一起入队。

这样不需要回溯，但每个结点都要单独申请一个字符串，比思路一费空间。

### 手动模拟（示例 1）

| 出队 | path | 是叶子吗 | 入队 |
|---|---|---|---|
| 1 | `"1"` | 否 | (2, `"1->2"`)、(3, `"1->3"`) |
| 2 | `"1->2"` | 否 | (5, `"1->2->5"`) |
| 3 | `"1->3"` | 是 → 答案 | |
| 5 | `"1->2->5"` | 是 → 答案 | |

### 代码

```c
char** binaryTreePaths(struct TreeNode* root, int* returnSize) {
    char** res = (char**)malloc(sizeof(char*) * 100);
    int cnt = 0;
    struct TreeNode* q[100];          // 结点队列
    char* qp[100];                    // qp[i]：根到 q[i] 的路径字符串
    int head = 0, tail = 0;

    char* s = (char*)malloc(8);
    sprintf(s, "%d", root->val);
    q[tail] = root; qp[tail] = s; tail++;

    while (head < tail) {
        struct TreeNode* node = q[head];
        char* path = qp[head];
        head++;
        if (node->left == NULL && node->right == NULL) {
            res[cnt++] = path;        // 叶子：这条字符串就是答案
            continue;
        }
        struct TreeNode* kids[2] = {node->left, node->right};
        for (int j = 0; j < 2; j++) {
            if (kids[j] == NULL) continue;
            int len = strlen(path);
            char* t = (char*)malloc(len + 8);              // 多出 "->-100" 和 '\0' 的空间
            sprintf(t, "%s->%d", path, kids[j]->val);
            q[tail] = kids[j]; qp[tail] = t; tail++;
        }
        free(path);                   // 非叶子的路径用完了，释放
    }
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n · h)**：每个结点都复制一遍路径字符串。
- **空间复杂度 O(n · h)**：队列里的字符串。

---

## ⚠️ 第五步：小白常见错误

1. **把 `buf` 直接存进答案**：
   ```c
   res[cnt++] = buf;   // ❌ 所有答案指向同一块内存，最后都变成最后一条路径
   ```
   必须为每条答案 `malloc` 新空间并复制。
2. **`malloc` 时忘了 `+1`**：`malloc(newLen)` 放不下结尾的 `'\0'`，`printf` 时会读到越界的垃圾数据。
3. **用 `val + '0'` 转字符**：只对 0~9 有效，`-100`、`23` 都会出错。用 `sprintf("%d")`。
4. **第一个数前面也加了箭头**：输出成 `"->1->2->5"`。用 `len == 0` 判断是否是根。
5. **在空结点处保存路径**：只有一个孩子的结点会被当成路径终点，而且叶子会被它的两个空孩子各存一次，答案重复。
6. **用 `strcat` 一直往后接却不回溯**：回到父结点时没有截断，后面的路径里会混入前一条分支的结点。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 额外空间 | 难度 | 建议 |
|---|---|---|---|---|
| DFS + 缓冲区回溯 | O(n·h) | O(h) | ⭐⭐ | **首选**，空间省 |
| BFS + 每结点一份字符串 | O(n·h) | O(n·h) | ⭐⭐ | 思路直观，不用想回溯 |
