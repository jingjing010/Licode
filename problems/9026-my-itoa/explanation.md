# 9026. 实现 itoa（整数转任意进制字符串）—— 小白详细题解

> 不用 `printf` 也能把数字显示出来——这是每个写过 LCD、数码管、串口日志的嵌入式工程师都手写过的函数。它会让你搞懂**进制转换的本质**、**字符串反转**，以及 **INT32_MIN 取绝对值溢出**这个经典坑。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把整数写成 `base` 进制的文字；十进制的负数前面加负号，其它进制把负数当成 32 位无符号数（补码）来写。

几个例子：

| value | base | 输出 | 说明 |
|---|---|---|---|
| 255 | 16 | `"FF"` | 255 = 15×16 + 15 |
| -1234 | 10 | `"-1234"` | 十进制负数带符号 |
| 10 | 2 | `"1010"` | 8 + 2 |
| -1 | 16 | `"FFFFFFFF"` | 非十进制按补码 `0xFFFFFFFF` 处理 |
| 0 | 任意 | `"0"` | 0 要单独保证输出一个字符 |

**几个需要注意的细节：**

1. 结果写进调用者给的 `buf`，最后要返回 `buf` 本身。
2. 字母用**大写**。
3. 最长的结果是 `-1` 的二进制：32 个 `'1'`，再加 `'\0'` 共 33 字节；`buf` 有 34 字节，够用。

---

## 🧰 第二步：需要的 C 语言知识

### 1. 进制转换：除 base 取余

把十进制数 `1234` 拆成各位：

```
1234 % 10 = 4,  1234 / 10 = 123
 123 % 10 = 3,   123 / 10 = 12
  12 % 10 = 2,    12 / 10 = 1
   1 % 10 = 1,     1 / 10 = 0   停止
```

得到的数字顺序是 **4 3 2 1**——**从低位到高位**，而我们书写时是从高位开始的，所以要**反转**。任何进制都一样，把 10 换成 `base` 即可。

### 2. ⭐ 为什么要先转成 `uint32_t`

- **十进制负数取绝对值**：`int32_t` 范围是 `-2147483648 ~ 2147483647`，`-(-2147483648)` 超出范围，是未定义行为。把它转成 `uint32_t` 后再求 `0u - u`，无符号运算是"对 2^32 取模"，结果正好是 `2147483648`。
- **其它进制按补码输出**：`(uint32_t)-1` 就是 `0xFFFFFFFF`，直接对它反复除 16 即可得到 `"FFFFFFFF"`。

### 3. 查找表

```c
static const char digits[] = "0123456789ABCDEF";
digits[11]   // 'B'
```

一张表覆盖 2~16 所有进制，不用写 `if (d < 10)` 的分支。

### 4. `do { } while` 正好处理 0

```c
do {
    ...先执行一次...
} while (u != 0);
```

`while` 循环在 `u == 0` 时一次都不执行，会得到空字符串；`do-while` 至少执行一次，0 自然输出 `"0"`。

## 💡 第三步：思路一 —— 先倒着写进 buf，再原地反转

### 思路

1. 若 `base == 10` 且 `value < 0`，先写 `'-'`，并把绝对值存进 `uint32_t u`；否则 `u = (uint32_t)value`
2. 用 `do-while` 把 `u % base` 对应的字符依次写到 `buf` 里（此时是倒序的）
3. 写 `'\0'`，再把**数字部分**（不含负号）首尾交换，反转过来

### 手动模拟（示例 2：`value = -1234, base = 10`）

| 步骤 | 操作 | buf 内容 |
|---|---|---|
| 1 | 写负号，u = 1234 | `-` |
| 2 | 1234 % 10 = 4 | `-4` |
| 3 | 123 % 10 = 3 | `-43` |
| 4 | 12 % 10 = 2 | `-432` |
| 5 | 1 % 10 = 1，u 变 0 停止 | `-4321` |
| 6 | 反转下标 1~4 | `-1234` ✅ |

### 代码

```c
char* my_itoa(int32_t value, char* buf, int base) {
    static const char digits[] = "0123456789ABCDEF";
    char* p = buf;
    uint32_t u = (uint32_t)value;          // 其它进制：直接按补码当无符号数

    if (base == 10 && value < 0) {
        *p++ = '-';                        // 十进制负数：先写负号
        u = 0u - u;                        // 无符号取负 = 绝对值，-2147483648 也不会溢出
    }

    char* start = p;                       // 数字部分从这里开始
    do {
        *p++ = digits[u % (uint32_t)base]; // 先得到的是最低位
        u /= (uint32_t)base;
    } while (u != 0);
    *p = '\0';

    // 反转 [start, p-1] 这段数字
    char* end = p - 1;
    while (start < end) {
        char t = *start;
        *start++ = *end;
        *end-- = t;
    }
    return buf;
}
```

### 复杂度分析

- **时间复杂度 O(k)**，k 为结果位数（最多 32）；**空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 先存进临时数组，再倒序拷贝

### 思路

不想写反转？可以先把数字倒序存进一个局部数组 `tmp`，然后**从后往前**拷到 `buf`。逻辑更直白，代价是多用 33 字节栈空间（在单片机上也完全可以接受）。

### 手动模拟（示例 1：`value = 255, base = 16`）

| 步骤 | u | u % 16 | tmp |
|---|---|---|---|
| 1 | 255 | 15 → `'F'` | `F` |
| 2 | 15 | 15 → `'F'` | `FF` |
| 3 | 0 | 停止 | |

倒序拷贝得到 `"FF"` ✅

### 代码

```c
char* my_itoa(int32_t value, char* buf, int base) {
    static const char digits[] = "0123456789ABCDEF";
    char tmp[33];                          // 最多 32 位二进制数字
    int n = 0;
    char* p = buf;
    uint32_t u = (uint32_t)value;

    if (base == 10 && value < 0) {
        *p++ = '-';
        u = 0u - u;
    }

    do {
        tmp[n++] = digits[u % (uint32_t)base];   // 低位先进 tmp
        u /= (uint32_t)base;
    } while (u != 0);

    while (n > 0) {
        *p++ = tmp[--n];                   // 从 tmp 的末尾（最高位）开始拷
    }
    *p = '\0';
    return buf;
}
```

## 🔌 嵌入式实战

在没有 `printf` 的小 MCU 上打印调试信息：

```c
char tmp[34];
uart_puts("ADC=");
uart_puts(my_itoa(adc_raw, tmp, 10));        // ADC=2048
uart_puts(" REG=0x");
uart_puts(my_itoa(GPIOA->IDR, tmp, 16));     // REG=0x1F
uart_puts("\r\n");
```

返回 `buf` 的设计就是为了能这样**嵌套调用**。注意 `tmp` 是局部数组，`my_itoa` 只是往里面写，调用方负责它的生命周期——这比在函数里 `malloc` 更适合嵌入式。

## ⚠️ 第五步：小白常见错误

1. **`while` 代替 `do-while`**：`value = 0` 时输出空字符串 `""`。
2. **忘了反转**：`1234` 输出 `"4321"`。
3. **对 INT32_MIN 直接取负**：`value = -value;` 当 `value = -2147483648` 时溢出（未定义行为），常见结果是仍为负数，`%` 得到负余数，`digits[-8]` 越界读。
4. **非十进制也输出负号**：`-1` 的十六进制应是 `"FFFFFFFF"`，不是 `"-1"`。
5. **反转时把负号也反转了**：`"-4321"` 整体反转成 `"1234-"`。反转范围要从负号之后开始。
6. **忘记写 `'\0'`**：`buf` 里原来的垃圾数据会跟在后面一起被打印出来（判题程序故意把 `buf` 填满了 `'#'`）。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 额外空间 | 特点 |
|---|---|---|---|
| 写入后原地反转 | O(k) | O(1) | 省内存 |
| 临时数组倒序拷贝 | O(k) | O(33) 栈 | 逻辑直白，不易出错 |
| `sprintf` | O(k) | 大量 Flash/栈 | 本题禁止 |
