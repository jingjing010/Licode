给你一棵二叉树的根节点 `root` ，翻转这棵二叉树，并返回其根节点。

### 示例 1

```
     4                4
   /   \            /   \
  2     7    =>    7     2
 / \   / \        / \   / \
1   3 6   9      9   6 3   1
```

```
输入：root = [4,2,7,1,3,6,9]
输出：[4,7,2,9,6,3,1]
```

### 示例 2

```
输入：root = [2,1,3]
输出：[2,3,1]
```

### 示例 3

```
输入：root = []
输出：[]
```

### 提示

- 树中节点数目范围在 `[0, 100]` 内
- `-100 <= Node.val <= 100`

### 函数说明

```c
struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

struct TreeNode* invertTree(struct TreeNode* root);
```

- `struct TreeNode` 已由系统定义，**不要**在代码里重复定义
- `root`：二叉树的根结点，空树为 `NULL`
- 返回值：翻转后的树的根结点（直接修改原来的结点即可，不需要 `malloc` 新结点）

### 自定义输入格式

```
[4,2,7,1,3,6,9]
```

只有 1 行：二叉树的层序表示，`null` 表示空结点，空树写作 `[]`。输出为翻转后的树的层序表示。
