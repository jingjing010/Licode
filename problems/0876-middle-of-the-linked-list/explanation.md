# 876. 链表的中间结点 —— 小白详细题解

> **快慢指针**的入门题。找中点是 143（重排链表）、234（回文链表）、148（排序链表）等题的基础步骤。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 找到链表正中间的那个结点并返回它。如果结点个数是偶数，中间有两个，返回**靠后**的那个。

| 链表 | 长度 n | 中间结点 | 是第几个（从 1 数） |
|---|---|---|---|
| `1 -> 2 -> [3] -> 4 -> 5` | 5 | 3 | 第 3 个 |
| `1 -> 2 -> 3 -> [4] -> 5 -> 6` | 6 | 4 | 第 4 个 |

规律：从 `head` 出发走 **`n / 2` 步**（整数除法）就到了中间结点。`5 / 2 = 2` 步到第 3 个，`6 / 2 = 3` 步到第 4 个。

**几个需要注意的细节：**

1. 返回的是**结点指针**，判题程序会从这个结点一直打印到末尾，所以示例 1 的输出是 `[3,4,5]`。
2. 偶数个结点返回**第二个**中间结点。
3. 不要修改链表。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回链表中某个结点的指针

链表的每个结点都可以看作"从这里开始的一条子链表"的头。返回 `slow`，就相当于返回了子链表 `slow -> ... -> NULL`。

### 2. 整数除法

C 语言中 `int / int` 结果会**向下取整**：`5 / 2 == 2`，`6 / 2 == 3`。

### 3. 连续两次 `->next` 前要检查

`fast->next->next` 要求 `fast != NULL` **而且** `fast->next != NULL`，否则就是访问空指针：

```c
while (fast != NULL && fast->next != NULL)   // && 短路：左边为假时不会执行右边
```

---

## 💡 第三步：思路一 —— 先数长度，再走 n / 2 步

### 思路

1. 第一遍遍历：数出长度 `n`
2. 第二遍：从 `head` 走 `n / 2` 步

### 代码

```c
struct ListNode* middleNode(struct ListNode* head) {
    // 1. 数长度
    int n = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) n++;

    // 2. 从头走 n / 2 步
    struct ListNode* cur = head;
    for (int i = 0; i < n / 2; i++) {
        cur = cur->next;
    }
    return cur;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：遍历约 1.5 遍。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 快慢指针，一次遍历（最优）

### 思路

两个指针都从 `head` 出发：`slow` 每次走 1 步，`fast` 每次走 2 步。`fast` 走到终点时，`slow` 刚好走了一半——就在中间。

### 手动模拟

示例 1（`[1,2,3,4,5]`，奇数个）：

| 步骤 | slow | fast | 继续？ |
|---|---|---|---|
| 开始 | 1 | 1 | fast->next = 2，继续 |
| 1 | 2 | 3 | fast->next = 4，继续 |
| 2 | 3 | 5 | fast->next = NULL，停 |

返回 `slow = 3`。

示例 2（`[1,2,3,4,5,6]`，偶数个）：

| 步骤 | slow | fast | 继续？ |
|---|---|---|---|
| 开始 | 1 | 1 | 继续 |
| 1 | 2 | 3 | 继续 |
| 2 | 3 | 5 | fast->next = 6，继续 |
| 3 | 4 | NULL | fast 为 NULL，停 |

返回 `slow = 4`，正好是第二个中间结点。

### 代码

```c
struct ListNode* middleNode(struct ListNode* head) {
    struct ListNode* slow = head;   // 慢指针：每次走 1 步
    struct ListNode* fast = head;   // 快指针：每次走 2 步

    // fast 还能再走两步时才继续
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;                    // fast 到头时，slow 在中间
}
```

### 复杂度分析

- **时间复杂度 O(n)**：`fast` 走完一遍链表，循环约 n/2 次。
- **空间复杂度 O(1)**。

> 💬 如果想要偶数时返回**第一个**中间结点，把条件改成 `while (fast->next != NULL && fast->next->next != NULL)` 即可——143 题就是这样用的。

---

## ⚠️ 第五步：小白常见错误

1. **循环条件只写 `fast->next != NULL`**：偶数个结点时 `fast` 最后会变成 `NULL`，再访问 `fast->next` 崩溃。
2. **循环条件只写 `fast != NULL`**：`fast->next` 为 `NULL` 时 `fast->next->next` 崩溃。
3. **思路一走了 `n / 2 + 1` 步或 `(n - 1) / 2` 步**：偶数时会返回错误的那个中间结点。从 `head` 出发走 `n / 2` 步才对。
4. **返回 `slow->val`**：函数要求返回结点指针，不是值。
5. **修改了链表**：比如为了"只输出中间结点"而把 `slow->next` 设为 `NULL`，输出就只剩一个数了。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 数长度再走 | O(n)，约 1.5 遍 | O(1) | ⭐ | 最直观 |
| 快慢指针 | O(n)，1 遍 | O(1) | ⭐ | **推荐**，必须掌握 |
