`strncpy` 常被误以为是"安全版的 strcpy"，其实它的行为相当特别，是嵌入式面试里的高频"坑题"。它**总是恰好写 `n` 个字节**：

- 如果 `strlen(src) < n`：复制整个 `src`，然后用 `'\0'` **补满**到 `n` 个字节
- 如果 `strlen(src) >= n`：只复制 `src` 的前 `n` 个字符，**不会**补 `'\0'`（`dst` 可能没有结束符！）

请你按照上述标准行为实现 `my_strncpy(dst, src, n)`，返回 `dst`。`dst` 中下标 `>= n` 的字节**不能修改**。

> **不要调用库函数 `strncpy` / `strcpy` / `memcpy` / `memset` 等**，请自己用指针完成。

判题程序准备一个 `n + 3` 字节的缓冲区 `dst`，事先**全部填成 `'*'`**，调用 `my_strncpy(dst, src, n)` 后，输出 `dst` 的全部 `n + 3` 个字节：用一个带双引号的字符串表示，其中值为 0 的字节显示为 `\0`。

### 示例 1

```
输入：src = "hi", n = 5
输出："hi\0\0\0***"
解释：复制 'h'、'i' 之后还差 3 个字节，用 '\0' 补满。最后 3 个 '*' 是 dst[5..7]，没有被修改。
```

### 示例 2

```
输入：src = "hello", n = 3
输出："hel***"
解释：src 太长，只复制前 3 个字符，并且不写 '\0'。
```

### 示例 3

```
输入：src = "abc", n = 4
输出："abc\0***"
解释：strlen(src) = 3 < 4，复制 "abc" 后补 1 个 '\0'。
```

### 提示

- `0 <= strlen(src) <= 10^5`，`src` 由小写字母、数字和空格组成
- `0 <= n <= 10^5`

### 函数说明

```c
char* my_strncpy(char* dst, const char* src, size_t n);
```

- `dst`：目标缓冲区（至少 `n` 字节），`src`：源字符串，两者不重叠
- `n`：恰好写入的字节数
- 返回值：必须返回 `dst`

`dst` 的 `n + 3` 个字节后面还有一段"哨兵"内存。如果返回值不是 `dst`，或写到了缓冲区之外，会输出一行错误信息（判为答案错误）。

### 自定义输入格式

```
"hi"
5
```

第 1 行是带双引号的字符串 `src`，第 2 行是 `n`。
