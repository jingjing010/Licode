# 300. 最长递增子序列 —— 小白详细题解

> 简称 LIS（Longest Increasing Subsequence），是动态规划最经典的题目之一。先学 O(n²) 的 DP，再学 O(n log n) 的"贪心 + 二分"。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 从数组里**挑出一些数**（可以不连续，但不能打乱顺序），让它们**严格从小到大**，问最多能挑几个？

拿示例 1 `nums = [10,9,2,5,3,7,101,18]` 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 数值 | 10 | 9 | **2** | 5 | **3** | **7** | **101** | 18 |

挑出 `2, 3, 7, 101`，长度 4。（`2, 5, 7, 18` 也是长度 4，答案只要长度。）

**几个需要注意的细节：**

1. **子序列 ≠ 子数组**：子序列可以跳着选，子数组必须连续。
2. **严格递增**：相等不算，所以示例 3 全是 7 时答案是 1。
3. 只要求返回长度，不用返回具体的子序列。

---

## 🧰 第二步：这道题需要的 C 语言知识

1. **两层循环 `j < i`**：枚举 i 前面的所有元素。
2. **二分查找**：在**有序数组**中找"第一个 ≥ x 的位置"，每次把搜索区间砍一半，O(log n)。写法用左闭右开区间 `[lo, hi)`：

   ```c
   int lo = 0, hi = len;               // 在 tails[0..len-1] 中查找
   while (lo < hi) {
       int mid = (lo + hi) / 2;
       if (tails[mid] < x) lo = mid + 1;   // 答案在右半边
       else hi = mid;                      // 答案是 mid 或在左半边
   }
   // 循环结束时 lo == hi，就是第一个 >= x 的位置（都比 x 小时 lo == len）
   ```

## 💡 第三步：思路一 —— 动态规划 O(n²)

### 思路

`dp[i]` = **以 `nums[i]` 结尾**的最长递增子序列的长度。

要以 `nums[i]` 结尾，前一个数 `nums[j]` 必须满足 `j < i` 且 `nums[j] < nums[i]`，于是：

```
dp[i] = max(dp[j] + 1)，对所有 j < i 且 nums[j] < nums[i]；如果没有这样的 j，dp[i] = 1
```

答案是所有 `dp[i]` 中的**最大值**（LIS 不一定以最后一个数结尾）。

### 手动模拟（示例 2：`[0,1,0,3,2,3]`）

| i | nums[i] | 可以接在谁后面（nums[j] < nums[i]） | dp[i] |
|---|---|---|---|
| 0 | 0 | 无 | 1 |
| 1 | 1 | j=0（dp=1） | 2 |
| 2 | 0 | 无 | 1 |
| 3 | 3 | j=0,1,2，最大 dp[1]=2 | 3 |
| 4 | 2 | j=0,1,2，最大 dp[1]=2 | 3 |
| 5 | 3 | j=0,1,2,4，最大 dp[4]=3 | **4** |

### 代码

```c
int lengthOfLIS(int* nums, int numsSize) {
    // dp[i]：以 nums[i] 结尾的最长严格递增子序列长度
    int* dp = (int*)malloc(sizeof(int) * numsSize);
    int ans = 0;

    for (int i = 0; i < numsSize; i++) {
        dp[i] = 1;                              // 只有它自己，长度为 1
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i] && dp[j] + 1 > dp[i]) {
                dp[i] = dp[j] + 1;              // 接在 nums[j] 后面
            }
        }
        if (dp[i] > ans) ans = dp[i];           // 答案取所有 dp[i] 的最大值
    }

    free(dp);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：n = 2500 时约 3×10⁶ 次，轻松通过。
- **空间复杂度 O(n)**。

## 🚀 第四步：思路二 —— 贪心 + 二分 O(n log n)

### 思路

换一个角度维护信息：`tails[k]` = 所有**长度为 k+1** 的递增子序列中，**最小的结尾元素**。

为什么要"最小的结尾"？结尾越小，后面越容易接上更大的数，子序列越有潜力变长。

可以证明 `tails` 一定是**严格递增**的。对每个新数 x：

- 如果 x 比 `tails` 里所有数都大 → 接在最长的后面，`tails` 末尾追加 x，长度 +1
- 否则 → 找到**第一个 ≥ x** 的位置 k，把 `tails[k]` 替换成 x（长度为 k+1 的子序列有了更小的结尾）

最终 `tails` 的长度就是答案。

### 手动模拟（示例 1：`[10,9,2,5,3,7,101,18]`）

| x | 第一个 ≥ x 的位置 | 操作 | tails |
|---|---|---|---|
| 10 | 0（空，等于 len） | 追加 | [10] |
| 9 | 0 | 替换 tails[0] | [9] |
| 2 | 0 | 替换 tails[0] | [2] |
| 5 | 1（= len） | 追加 | [2,5] |
| 3 | 1 | 替换 tails[1] | [2,3] |
| 7 | 2（= len） | 追加 | [2,3,7] |
| 101 | 3（= len） | 追加 | [2,3,7,101] |
| 18 | 3 | 替换 tails[3] | [2,3,7,18] |

长度 **4**。

> ⚠️ `tails` 不一定是一个真实存在的子序列。例如 `[3,4,1]` 处理完后 `tails = [1,4]`，但 1 在 4 后面，`[1,4]` 并不是子序列。它只是记录"每种长度的最小结尾"，**长度**才是我们要的答案。

### 代码

```c
int lengthOfLIS(int* nums, int numsSize) {
    // tails[k]：长度为 k+1 的递增子序列的最小结尾；tails 严格递增
    int* tails = (int*)malloc(sizeof(int) * numsSize);
    int len = 0;                                 // tails 当前的长度

    for (int i = 0; i < numsSize; i++) {
        int x = nums[i];
        // 二分查找 tails[0..len-1] 中第一个 >= x 的位置
        int lo = 0, hi = len;
        while (lo < hi) {
            int mid = (lo + hi) / 2;
            if (tails[mid] < x) lo = mid + 1;
            else hi = mid;
        }
        tails[lo] = x;                           // 替换，或者在末尾追加
        if (lo == len) len++;                    // 追加时长度加 1
    }

    free(tails);
    return len;
}
```

### 复杂度分析

- **时间复杂度 O(n log n)**：每个数做一次二分。
- **空间复杂度 O(n)**。

---

## ⚠️ 第五步：小白常见错误

1. **返回 `dp[n-1]`** → `dp[n-1]` 只是"以最后一个数结尾"的长度。`[1,3,2,0]` 中 `dp[3] = 1`，但答案是 2。必须取所有 `dp[i]` 的最大值。
2. **把"严格递增"写成 `nums[j] <= nums[i]`** → 示例 3 全是 7 会得到 7，正确答案是 1。
3. **二分查找"第一个 > x"而不是"第一个 ≥ x"** → 遇到相等的数会追加到末尾，同样把非严格递增也算进去了。
4. **`dp[i]` 忘了初始化为 1** → `malloc` 的内存是随机值，每个数自身就是长度为 1 的子序列。
5. **二分写成 `while (lo <= hi)` 却用 `hi = mid`** → 区间不再缩小，死循环。左闭右开就配 `lo < hi` 和 `hi = mid`。
