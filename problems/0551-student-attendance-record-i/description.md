# 学生出勤记录 I

记录由A缺勤、L迟到、P到场组成。缺勤少于2次且从未连续迟到3次即可获奖，返回能否获奖。长度1到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool checkRecord(char* s);
```

## 示例 1

输入：
```text
"PPALLP"
```
输出：
```text
true
```

## 示例 2

输入：
```text
"PPALLL"
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
