# 75. 颜色分类 —— 小白详细题解

> 这道题又叫"荷兰国旗问题"（荷兰国旗是红、白、蓝三色条纹）。题目不让用库函数排序，我们先用"数个数"的笨办法，再学一个漂亮的**三指针一趟扫描**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 数组里只有 0、1、2 三种数，把它们原地排成"所有 0 在前，然后是 1，最后是 2"。

拿示例 1 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 排序前 | 2 | 0 | 2 | 1 | 1 | 0 |
| 排序后 | 0 | 0 | 1 | 1 | 2 | 2 |

**几个需要注意的细节：**

1. **原地**修改：函数返回 `void`，你要直接改 `nums` 数组本身，判题程序会打印改完之后的数组。
2. **不能用** `qsort` 之类的库函数排序（题目要求，虽然判题程序检查不出来，但那样就失去了练习的意义）。
3. 可能某种颜色一个都没有，比如全是 2。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 为什么"原地修改"能被调用者看到？

```c
void sortColors(int* nums, int numsSize)
```

`nums` 是数组的**首地址**。你通过 `nums[i] = 0` 修改的是那块内存本身，调用者手里也是同一个地址，所以函数结束后调用者能看到修改结果。这和"`int x` 传值进去改了没用"是不同的。

### 2. 交换两个元素

C 语言没有 `swap` 函数，要借助一个临时变量：

```c
int t = nums[i];     // 先把 nums[i] 存起来
nums[i] = nums[j];   // 覆盖 nums[i]
nums[j] = t;         // 再把原来的 nums[i] 放到 j
```

> 💬 如果直接写 `nums[i] = nums[j]; nums[j] = nums[i];`，第一句执行完 `nums[i]` 的原值就丢了，两个位置都变成了 `nums[j]`。

---

## 💡 第三步：思路一 —— 计数后重写（两趟扫描）

### 思路

只有三种数，那就先数一数：0 有几个、1 有几个、2 有几个。然后从头开始，先写对应个数的 0，再写 1，最后写 2。

这种方法叫**计数排序**，适用于"取值种类很少"的情况。

### 手动模拟（`[2,0,2,1,1,0]`）

第一趟数个数：`cnt[0] = 2`，`cnt[1] = 2`，`cnt[2] = 2`。

第二趟按个数写回：

| 位置 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 写入 | 0 | 0 | 1 | 1 | 2 | 2 |

### 代码

```c
void sortColors(int* nums, int numsSize) {
    int cnt[3] = {0, 0, 0};              // cnt[c]：颜色 c 出现的次数

    // 第一趟：统计
    for (int i = 0; i < numsSize; i++) {
        cnt[nums[i]]++;
    }

    // 第二趟：按 0、1、2 的顺序依次写回
    int pos = 0;
    for (int c = 0; c < 3; c++) {
        for (int k = 0; k < cnt[c]; k++) {
            nums[pos++] = c;             // 写一个，pos 往后挪一格
        }
    }
}
```

### 复杂度分析

- **时间复杂度 O(n)**：扫两遍。
- **空间复杂度 O(1)**：只有 3 个计数器。

## 🚀 第四步：思路二 —— 三指针（荷兰国旗，一趟扫描）

### 思路

用三个指针把数组划成四个区域：

```
 [0, p0)      [p0, i)      [i, p2]        (p2, n-1]
 全是 0        全是 1       还没检查        全是 2
```

`i` 从左往右检查每个数：

| nums[i] | 应该去哪 | 操作 |
|---|---|---|
| 0 | 左边的 0 区 | 和 `nums[p0]` 交换，`p0++`，`i++` |
| 1 | 就在 1 区末尾 | `i++` |
| 2 | 右边的 2 区 | 和 `nums[p2]` 交换，`p2--`，**`i` 不动** |

> ❓ **为什么遇到 2 交换后 `i` 不动？** 因为从 `p2` 换过来的数还**没检查过**，它可能是 0、1、2 中的任何一个，必须再看一次。
> 而遇到 0 交换后可以 `i++`：从 `p0` 换过来的数位于 `[p0, i)` 区间，已经检查过了，一定是 1（或者 `p0 == i` 时就是它自己）。

当 `i > p2` 时，"还没检查"的区域为空，排序完成。

### 手动模拟（示例 2：`[2,0,1]`）

| 步骤 | 数组 | p0 | i | p2 | nums[i] | 操作 |
|---|---|---|---|---|---|---|
| 1 | [**2**,0,1] | 0 | 0 | 2 | 2 | 和 p2 交换，p2-- |
| 2 | [**1**,0,2] | 0 | 0 | 1 | 1 | i++ |
| 3 | [1,**0**,2] | 0 | 1 | 1 | 0 | 和 p0 交换，p0++，i++ |
| 4 | [0,1,2] | 1 | 2 | 1 | | i > p2，结束 |

### 代码

```c
void sortColors(int* nums, int numsSize) {
    int p0 = 0;                  // [0, p0) 都是 0；下一个 0 应该放到 p0
    int i = 0;                   // 当前检查的位置
    int p2 = numsSize - 1;       // (p2, n-1] 都是 2；下一个 2 应该放到 p2

    while (i <= p2) {            // [i, p2] 是还没检查的区域
        if (nums[i] == 0) {
            int t = nums[i]; nums[i] = nums[p0]; nums[p0] = t;   // 0 放到左边
            p0++;
            i++;                 // 换过来的一定是 1（或者就是自己），可以跳过
        } else if (nums[i] == 2) {
            int t = nums[i]; nums[i] = nums[p2]; nums[p2] = t;   // 2 放到右边
            p2--;                // 注意 i 不动：换过来的数还没检查
        } else {
            i++;                 // 1 就留在中间
        }
    }
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每一步要么 `i++`，要么 `p2--`，两者之间的距离每步缩小 1，最多 n 步。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **遇到 2 交换后也 `i++`** → 换过来的数没检查就跳过了。例如 `[1,2,0]`：`i = 1` 时把 2 和末尾的 0 交换得到 `[1,0,2]`，如果此时 `i++`，换过来的 0 就被跳过，最终输出 `[1,0,2]`。
2. **循环条件写成 `i < p2`** → 漏检查 `i == p2` 那个位置，`[1,0]` 会原样输出。
3. **交换时没用临时变量** → 两个位置变成同一个值，数组里的数"凭空消失"。
4. **用 `return nums;` 返回数组** → 函数是 `void`，不能也不需要返回，直接改 `nums` 就行。
5. **计数法里 `cnt` 没初始化** `int cnt[3];` → 局部数组里是随机垃圾值，统计结果错误。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 扫描次数 | 难度 |
|---|---|---|---|---|
| 库函数 qsort | O(n log n) | O(log n) | — | 题目不允许 |
| 计数后重写 | O(n) | O(1) | 2 趟 | ⭐ |
| 三指针（荷兰国旗） | O(n) | O(1) | 1 趟 | ⭐⭐⭐ |
