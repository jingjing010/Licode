# 完美数：题解

## 📖 先读懂题目

正整数 num 的所有正因子（不含自身）之和等于 num 时称为完美数。判断给定 num 是否满足，num ≤ 10^8。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `28` | `true` |
| 2 | `7` | `false` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

枚举到平方根即可找到成对的因子，排除数本身并避免重复累加平方根。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
bool checkPerfectNumber(int num) {
    if (num <= 1)
        return false;
    long long sum = 1;
    /* 约数成对累加，平方根只能计算一次。 */
    for (int d = 2; d <= num / d; ++d)
        if (num % d == 0) {
            sum += d;
            if (d != num / d)
                sum += num / d;
        }
    return sum == num;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(√n)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
