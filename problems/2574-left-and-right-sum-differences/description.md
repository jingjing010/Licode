# 左右元素和的差值

返回每个下标左边所有元素和与右边所有元素和的绝对差。当前位置不计入任何一边。1 ≤ n ≤ 1000，元素1到10^5。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* leftRightDifference(int* nums,int numsSize,int* returnSize);
```

## 示例 1

输入：
```text
[10,4,8,3]
```
输出：
```text
[15,1,11,22]
```

## 示例 2

输入：
```text
[1]
```
输出：
```text
[0]
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
