# 5. 最长回文子串 —— 小白详细题解

> 这道题是字符串题里的常客，核心技巧是「**中心扩展**」。在那之前，我们先用最笨的办法把它做对。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一个字符串，从里面截出**连续的一段**，要求这一段**正着读和反着读一样**（回文），而且要**尽可能长**。

拿示例 1 `s = "babad"` 来说，把所有回文子串列出来：

| 子串 | 起点 | 长度 | 是回文吗？ |
|---|---|---|---|
| `"b"`、`"a"`、`"d"` | — | 1 | ✅（单个字符一定是回文） |
| `"bab"` | 0 | 3 | ✅ |
| `"aba"` | 1 | 3 | ✅ |
| `"baba"` | 0 | 4 | ❌ |
| `"babad"` | 0 | 5 | ❌ |

最长的长度是 3，`"bab"` 和 `"aba"` 都对，返回哪个都行。

**几个需要注意的细节：**

1. 子串必须**连续**。`"babad"` 里挑出 `b、a、b` 不连续的组合不算。
2. 回文长度可以是**奇数**（`"aba"`）也可以是**偶数**（示例 2 的 `"bb"`）。
3. 至少有 1 个字符，所以答案至少长度为 1。
4. 字母**区分大小写**：`"Aa"` 不是回文。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. C 语言的字符串

C 字符串就是一个 `char` 数组，最后有一个 `'\0'` 作为结束标志。`strlen(s)` 返回 `'\0'` 之前的字符个数。

### 2. 返回一个新字符串

```c
char* res = (char*)malloc(len + 1);   // 多申请 1 个字节，留给 '\0'
memcpy(res, s + start, len);          // 从 s 的第 start 个字符开始，拷贝 len 个字符
res[len] = '\0';                      // ⭐ 一定要手动加结束符
return res;
```

- `s + start`：指针加法，表示"从 `s[start]` 开始的那个地址"。
- `memcpy(目标, 来源, 字节数)`：按字节拷贝内存。

> 💬 为什么不能直接 `s[start + len] = '\0'; return s + start;`？这样确实能得到正确的字符串，但它**修改了输入**，而且返回的不是 `malloc` 出来的首地址，调用者 `free` 时会出错。新手请老老实实 `malloc` 一份。

---

## 💡 第三步：思路一 —— 暴力枚举所有子串

### 思路

1. 用两层循环枚举子串的起点 `i` 和终点 `j`。
2. 用双指针判断 `s[i..j]` 是不是回文：一个从左往右，一个从右往左，逐个比较。
3. 记录最长的那个。

**剪枝**：如果当前子串长度 `j - i + 1` 不超过已经找到的最长长度 `best`，就没必要再判断了。所以让 `j` 从右往左枚举，长度从大到小，一旦长度 `<= best` 就停止。

### 手动模拟（示例 2：`s = "cbbd"`）

| i | j | 子串 | 长度 > best？ | 回文？ | best |
|---|---|---|---|---|---|
| 0 | 3 | cbbd | 4 > 0 | ❌ | 0 |
| 0 | 2 | cbb | 3 > 0 | ❌ | 0 |
| 0 | 1 | cb | 2 > 0 | ❌ | 0 |
| 0 | 0 | c | 1 > 0 | ✅ | 1 |
| 1 | 3 | bbd | 3 > 1 | ❌ | 1 |
| 1 | 2 | bb | 2 > 1 | ✅ | **2** |
| 1 | 1 | b | 1 > 2? 否，停止 | | 2 |
| 2 | 3 | bd | 2 > 2? 否，停止 | | 2 |

答案 `"bb"`。

### 代码

```c
// 判断 s[left..right] 是不是回文
static bool isPal(const char* s, int left, int right) {
    while (left < right) {
        if (s[left] != s[right]) return false;   // 对称位置不相等，不是回文
        left++;
        right--;
    }
    return true;
}

char* longestPalindrome(char* s) {
    int n = (int)strlen(s);
    int start = 0, best = 0;            // 最长回文的起点和长度

    for (int i = 0; i < n; i++) {
        // j 从右往左：长度从大到小，长度 <= best 时就没必要继续了
        for (int j = n - 1; j - i + 1 > best; j--) {
            if (isPal(s, i, j)) {
                best = j - i + 1;       // 找到更长的
                start = i;
                break;                  // 对这个 i 来说，后面只会更短，直接换下一个 i
            }
        }
    }

    // 拷贝出结果字符串
    char* res = (char*)malloc(best + 1);
    memcpy(res, s + start, best);
    res[best] = '\0';
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n³)**：枚举子串 O(n²)，每次判断 O(n)。有了剪枝，实际运行会快很多，`n = 1000` 能过。
- **空间复杂度 O(1)**（返回的字符串不算）。

## 🚀 第四步：思路二 —— 中心扩展

### 思路

暴力法的浪费在于：判断 `"abcba"` 是回文时，其实已经顺便知道 `"bcb"` 是回文了，但暴力法会重新判断。

换个角度：**每个回文串都有一个"中心"**，从中心往两边看是对称的。

- 奇数长度 `"aba"`：中心是一个字符 `b`
- 偶数长度 `"abba"`：中心在两个 `b` 之间

所以，**枚举每一个中心，然后往两边扩展**：只要左右两边字符相等就继续扩，不相等就停。这样每个中心扩到头，就得到了以它为中心的最长回文。

长度为 `n` 的字符串，一共有 `n` 个"字符中心"和 `n - 1` 个"缝隙中心"。

### 手动模拟（示例 1：`s = "babad"`）

| 中心 | 扩展过程 | 回文 | 长度 |
|---|---|---|---|
| 字符 0 `b` | 左边越界，停 | b | 1 |
| 字符 1 `a` | s[0]=b == s[2]=b ✅；左边越界，停 | **bab** | **3** |
| 字符 2 `b` | s[1]=a == s[3]=a ✅；s[0]=b ≠ s[4]=d，停 | aba | 3 |
| 字符 3 `a` | s[2]=b ≠ s[4]=d，停 | a | 1 |
| 缝隙 0/1 | s[0]=b ≠ s[1]=a | 空 | 0 |
| …其他缝隙 | 都是相邻字符不等 | 空 | 0 |

最长是 3。

### 代码

```c
// 从 s[left]、s[right] 开始向两边扩展，返回能扩出的最长回文长度
static int expand(const char* s, int n, int left, int right) {
    while (left >= 0 && right < n && s[left] == s[right]) {
        left--;                         // 往左扩一格
        right++;                        // 往右扩一格
    }
    // 退出循环时，s[left] 和 s[right] 已经不满足条件了
    // 真正的回文是 s[left+1 .. right-1]，长度为 right - left - 1
    return right - left - 1;
}

char* longestPalindrome(char* s) {
    int n = (int)strlen(s);
    int start = 0, best = 0;

    for (int i = 0; i < n; i++) {
        int len1 = expand(s, n, i, i);      // 奇数长度：中心是 s[i]
        int len2 = expand(s, n, i, i + 1);  // 偶数长度：中心在 s[i] 和 s[i+1] 之间
        int len = len1 > len2 ? len1 : len2;
        if (len > best) {
            best = len;
            // 中心在 i（或 i 与 i+1 之间），往左退 (len-1)/2 格就是起点
            start = i - (len - 1) / 2;
        }
    }

    char* res = (char*)malloc(best + 1);
    memcpy(res, s + start, best);
    res[best] = '\0';
    return res;
}
```

> 💬 起点公式 `i - (len - 1) / 2` 怎么来的？试两个例子：奇数 `"bab"`，中心 `i = 1`，`len = 3`，起点 `1 - 1 = 0` ✅；偶数 `"abba"`，`i = 1`（左边那个 b），`len = 4`，起点 `1 - 3/2 = 1 - 1 = 0` ✅。

### 复杂度分析

- **时间复杂度 O(n²)**：`2n - 1` 个中心，每个最多扩展 O(n) 次。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **`malloc(best)` 忘了 `+1`** → 没有位置放 `'\0'`，写 `res[best] = '\0'` 会越界。
2. **忘记写 `res[best] = '\0'`** → 输出的字符串后面跟着一堆乱码。
3. **只考虑奇数长度的中心** → `"cbbd"` 会返回 `"c"` 而不是 `"bb"`。
4. **返回局部数组** `char res[1001]; return res;` → 函数结束后内存被回收，结果是乱码。
5. **扩展时先访问再判断越界** → 条件必须写成 `left >= 0 && right < n && s[left] == s[right]`，利用 `&&` 的短路，先保证下标合法再访问。
6. **把"子序列"当成"子串"** → 子串必须连续。如果你想到了"把字符串反转后求最长公共子序列"，那是另一道题（516. 最长回文子序列）的思路。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力枚举 + 剪枝 | O(n³) | O(1) | ⭐ | 先写对 |
| 动态规划 `dp[i][j]` | O(n²) | O(n²) | ⭐⭐⭐ | 了解即可 |
| 中心扩展 | O(n²) | O(1) | ⭐⭐ | 推荐掌握 |
| Manacher 算法 | O(n) | O(n) | ⭐⭐⭐⭐⭐ | 竞赛向，面试很少要求 |

> 💬 动态规划思路：`dp[i][j]` 表示 `s[i..j]` 是否回文，它等于 `s[i] == s[j] && dp[i+1][j-1]`。复杂度和中心扩展一样，却多用了 O(n²) 空间，所以本题更推荐中心扩展。
