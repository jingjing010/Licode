# 高度检查器

学生按当前身高数组排队，返回与按身高非递减排序后不同的位置数。1 ≤ n ≤ 100，身高1到100。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int heightChecker(int* heights,int heightsSize);
```

## 示例 1

输入：
```text
[1,1,4,2,1,3]
```
输出：
```text
3
```

## 示例 2

输入：
```text
[5,1,2,3,4]
```
输出：
```text
5
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
