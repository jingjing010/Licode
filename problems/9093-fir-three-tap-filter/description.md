# 三抽头 FIR 低通滤波

零初始历史，y[n]=trunc((x[n]+2x[n−1]+x[n−2])/4)，负数向零截断。输入int16范围，0到1000采样，返回整数滤波序列。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* firThreeTap(int* samples,int samplesSize,int* returnSize);
```

## 示例 1

输入：
```text
[4,4,4,0]
```
输出：
```text
[1,3,4,3]
```

## 示例 2

输入：
```text
[8,0,0,0]
```
输出：
```text
[2,4,2,0]
```

## 自定义输入格式

按顺序每行一个参数：samples。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
