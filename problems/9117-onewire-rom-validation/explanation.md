# 单总线 ROM 校验：题解

## 📖 先读懂题目

输入候选1-Wire ROM字节数组，必须恰好8字节且最后字节等于前7字节的CRC8/MAXIM才返回true。不检查家族码及序列号是否已登记。长度0到16。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[40,1,2,3,4,5,6,158]` | `true` |
| 2 | `[0,0,0,0,0,0,0,0]` | `true` |

## 🧰 需要的 C 语言知识

`uint8_t`表示一个0到255的字节；`const uint8_t *`允许读取数据但不修改它。`size_t len`明确给出缓冲区长度，不能使用`strlen`计算二进制数据长度，因为数据中可能含0。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

ROM前7字节参与MAXIM CRC8，最后一个字节为收到的校验值；先检查长度，防止越界。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
bool validateOneWireRom(const uint8_t *rom, size_t len) {
    if (len != 8)
        return false;
    uint8_t crc = 0;
    for (size_t i = 0; i < 7; ++i) {
        crc ^= rom[i];
        for (int b = 0; b < 8; ++b)
            crc = (crc & 1) ? (crc >> 1) ^ 0x8c : crc >> 1;
    }
    return crc == rom[7];
}
```

## ⚠️ 常见错误

- 把二进制缓冲区当成以零结尾的字符串，遇到0便提前停止。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
