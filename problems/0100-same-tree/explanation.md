# 100. 相同的树 —— 小白详细题解

> 这是"同时递归两棵树"的入门题。学会它，第 101 题对称二叉树、第 572 题另一棵树的子树都能直接套用。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你两棵树，判断它们是不是**一模一样**：形状一样，并且每个对应位置上的数也一样。

示例 2：`p = [1,2]`，`q = [1,null,2]`

```
  p:   1          q:   1
      /                 \
     2                   2
```

| 位置 | p | q | 一样吗 |
|---|---|---|---|
| 根 | 1 | 1 | ✅ |
| 根的左孩子 | 2 | 空 | ❌ |

只要有一个位置不一样，答案就是 `false`。

**几个需要注意的细节：**

1. **形状**也要一样：示例 2 里两棵树的值完全相同（都是 1 和 2），但 2 一个挂在左边、一个挂在右边，所以不同。
2. 树可能是**空树**：两棵都空算相同（返回 `true`），一棵空一棵不空算不同。
3. 示例 3 `[1,2,1]` 和 `[1,1,2]`：左右孩子的值对调了，也不同。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `bool` 类型

C 语言本身没有 `bool`，要 `#include <stdbool.h>`（本 OJ 已经帮你包含了），之后就能用 `bool`、`true`、`false`。

### 2. 短路求值 `&&`、`||`

```c
return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
```

`A && B`：如果 `A` 已经是 `false`，就**不会再去算** `B`。左子树已经不同了，右子树就不用比了，省时间。

### 3. 先判空再用 `->`

`p->val` 在 `p == NULL` 时会让程序崩溃（Runtime Error）。所以一定先把"空"的情况处理掉，再访问成员。

---

## 💡 第三步：思路一 —— 递归（深度优先搜索）

### 思路

两棵树相同，当且仅当：

1. 根结点的值相同；
2. 左子树和左子树相同；
3. 右子树和右子树相同。

后两条又是"判断两棵树是否相同"——交给递归。递归出口是**空指针**的情况：

| p | q | 结论 |
|---|---|---|
| 空 | 空 | 相同 |
| 空 | 不空 | 不同 |
| 不空 | 空 | 不同 |
| 不空 | 不空 | 比较值，再递归比较左右 |

### 手动模拟（示例 3：`[1,2,1]` 与 `[1,1,2]`）

| 调用 | p 的值 | q 的值 | 结果 |
|---|---|---|---|
| 比较根 | 1 | 1 | 相同，继续比左子树 |
| 比较左孩子 | 2 | 1 | **不同，返回 false** |
| 比较右孩子 | — | — | 被 `&&` 短路，不执行 |

最终返回 `false`。

### 代码

```c
bool isSameTree(struct TreeNode* p, struct TreeNode* q) {
    if (p == NULL && q == NULL) return true;     // 两个都空：相同
    if (p == NULL || q == NULL) return false;    // 只有一个空：不同
    if (p->val != q->val) return false;          // 值不一样：不同
    // 值一样，再分别比较左子树和右子树
    return isSameTree(p->left, q->left) && isSameTree(p->right, q->right);
}
```

### 复杂度分析

- **时间复杂度 O(min(n, m))**：每对结点最多比较一次，遇到不同就提前结束。
- **空间复杂度 O(h)**：递归栈的深度等于较矮那棵树的高度，最坏 O(n)。

---

## 🚀 第四步：思路二 —— 迭代（用队列成对比较）

### 思路

不用递归也可以：把"要比较的一对结点"放进队列。每次取出一对：

1. 两个都空 → 这一对没问题，跳过。
2. 一个空、或值不同 → 直接返回 `false`。
3. 否则把 `(p->left, q->left)` 和 `(p->right, q->right)` 两对放进队列。

队列处理完都没发现不同，就返回 `true`。用两个数组 `qa`、`qb` 分别存每一对的左、右两个结点。

### 手动模拟（示例 2：`[1,2]` 与 `[1,null,2]`）

| 步骤 | 取出的一对 | 判断 | 放入队列 |
|---|---|---|---|
| 1 | (1, 1) | 值相同 | (2, 空)、(空, 2) |
| 2 | (2, 空) | 一个空 | **返回 false** |

### 代码

```c
bool isSameTree(struct TreeNode* p, struct TreeNode* q) {
    // 每处理一对最多放入 2 对，结点不超过 100 个，开 512 足够
    struct TreeNode* qa[512];
    struct TreeNode* qb[512];
    int head = 0, tail = 0;
    qa[tail] = p; qb[tail] = q; tail++;           // 第一对：两个根

    while (head < tail) {
        struct TreeNode* a = qa[head];
        struct TreeNode* b = qb[head];
        head++;
        if (a == NULL && b == NULL) continue;     // 都空，这一对没问题
        if (a == NULL || b == NULL) return false; // 只有一个空
        if (a->val != b->val) return false;       // 值不同
        qa[tail] = a->left;  qb[tail] = b->left;  tail++;   // 左孩子配对
        qa[tail] = a->right; qb[tail] = b->right; tail++;   // 右孩子配对
    }
    return true;
}
```

> 为什么 512 够？只有"两个都不空"的对才会再放入 2 对，这样的对最多 100 个，所以总共最多放入 1 + 2×100 = 201 对。

### 复杂度分析

- **时间复杂度 O(min(n, m))**。
- **空间复杂度 O(min(n, m))**：队列的大小。

---

## ⚠️ 第五步：小白常见错误

1. **只比较遍历序列**：比如把两棵树都中序遍历成数组再比较。示例 2 中 `[1,2]` 的中序是 `[2,1]`，`[1,null,2]` 的中序是 `[1,2]`，这个碰巧能区分；但 `[1,1]` 和 `[1,null,1]` 的中序都是 `[1,1]`，会被误判成相同。只看一种遍历序列（不记录空结点）**无法确定树的形状**。
2. **判空顺序写错**：
   ```c
   if (p->val != q->val) return false;   // ❌ p 或 q 可能是 NULL，直接崩溃
   ```
   一定先处理空指针。
3. **两个都空时返回 false**：`if (p == NULL || q == NULL) return false;` 写在最前面，会把"都空"也判成不同，于是任何两棵树都会返回 `false`（因为叶子的孩子都是空）。
4. **只比较了根的值就返回**：`return p->val == q->val;` 忘了递归比较左右子树。
5. **左右配错对**：写成 `isSameTree(p->left, q->right)`，这是第 101 题对称二叉树的写法，不是本题。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 递归 | O(min(n,m)) | O(h) | ⭐ | **首选**，五行搞定 |
| 队列迭代 | O(min(n,m)) | O(min(n,m)) | ⭐⭐ | 理解"成对处理"的技巧 |
