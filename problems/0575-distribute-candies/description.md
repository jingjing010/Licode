# 分糖果

偶数个糖果，每个数表示糖果种类，只能吃一半，返回最多吃到的种类数。2 ≤ n ≤ 10^4。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int distributeCandies(int* candyType,int candyTypeSize);
```

## 示例 1

输入：
```text
[1,1,2,2,3,3]
```
输出：
```text
3
```

## 示例 2

输入：
```text
[1,1,2,3]
```
输出：
```text
2
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
