给定一个已排序的链表的头 `head` ， *删除所有重复的元素，使每个元素只出现一次* 。返回 *已排序的链表* 。

### 示例 1

```
1 -> 1 -> 2
  删除重复后
1 -> 2
```

```
输入：head = [1,1,2]
输出：[1,2]
```

### 示例 2

```
1 -> 1 -> 2 -> 3 -> 3
  删除重复后
1 -> 2 -> 3
```

```
输入：head = [1,1,2,3,3]
输出：[1,2,3]
```

### 提示

- 链表中节点数目在范围 `[0, 300]` 内
- `-100 <= Node.val <= 100`
- 题目数据保证链表已经按升序 **排列**

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* deleteDuplicates(struct ListNode* head);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `head`：升序链表的头指针，空链表用 `NULL` 表示
- 返回值：删除重复元素后链表的头指针（被删掉的结点可以 `free`，也可以不管）

### 自定义输入格式

```
[1,1,2,3,3]
```

只有 1 行，是升序链表 `head`，空链表写作 `[]`。输出为删除重复元素后的链表。
