# 带偶校验的字节验收

data在0到255，parity为0或1；检查数据加校验位的1的总数是否为偶数。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool checkEvenParity(int data,int parity);
```

## 示例 1

输入：
```text
0
0
```
输出：
```text
true
```

## 示例 2

输入：
```text
0
1
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：data、parity。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
