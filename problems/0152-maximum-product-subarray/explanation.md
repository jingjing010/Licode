# 152. 乘积最大子数组 —— 小白详细题解

> 看起来像"最大子数组和"（53 题）的乘法版，但多了一个坑：**负负得正**。解决办法是同时记住"最大"和"最小"。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 在数组里找一段**连续**的数，让它们的**乘积最大**，返回这个乘积。

拿示例 1 `nums = [2,3,-2,4]` 来说：

| 子数组 | 乘积 |
|---|---|
| [2,3] | **6** |
| [2,3,-2] | -12 |
| [2,3,-2,4] | -48 |
| [4] | 4 |

最大是 6。

**几个需要注意的细节：**

1. 必须**连续**：示例 2 `[-2,0,-1]` 中，`-2 × -1 = 2`，但它们中间隔着 0，不连续，答案是 0。
2. **负数很关键**：`[-2,3,-4]` 的答案是 `(-2) × 3 × (-4) = 24`。前面乘出来的"最小值" -6，再乘一个负数就变成了最大值。
3. **0 会"清零"**：任何子数组跨过 0，乘积都是 0。
4. 至少要选一个数，所以 `[-2]` 的答案是 -2。

---

## 🧰 第二步：这道题需要的 C 语言知识

1. **同时更新两个变量时要先保存旧值**：

   ```c
   int a = mx * x, b = mn * x;   // 先用旧的 mx、mn 算出来
   mx = 新最大值;                 // 再更新
   mn = 新最小值;                 // 如果这里还用 mx，就已经是"新的 mx"了，会出错
   ```

2. **溢出意识**：int 最大约 2.1×10⁹。题目保证任何子数组乘积都在 int 范围内，所以本题用 int 没问题；不确定时可以用 `long long`。

---

## 💡 第三步：思路一 —— 暴力枚举所有子数组

### 思路

固定起点 `i`，让终点 `j` 从 `i` 往右走，**一边走一边乘**（不用每次从头乘），记录最大值。

### 手动模拟（示例 1，起点 i = 0）

| j | nums[j] | 当前乘积 p | 最大值 |
|---|---|---|---|
| 0 | 2 | 2 | 2 |
| 1 | 3 | 6 | 6 |
| 2 | -2 | -12 | 6 |
| 3 | 4 | -48 | 6 |

再依次以 1、2、3 为起点，最终最大值仍是 6。

### 代码

```c
int maxProduct(int* nums, int numsSize) {
    int best = nums[0];                       // 至少有一个数
    for (int i = 0; i < numsSize; i++) {      // 枚举起点
        int p = 1;
        for (int j = i; j < numsSize; j++) {  // 枚举终点，累乘
            p *= nums[j];
            if (p > best) best = p;
            if (p == 0) break;                // 乘到 0 以后一直是 0，不用再往后了
        }
    }
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：n = 2×10⁴ 时最坏约 2×10⁸ 次乘法，接近时间上限，数据再大就会超时。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 动态规划：同时维护最大和最小

### 思路

类比 53 题，定义"以 `nums[i]` 结尾的子数组"的乘积：

- `mx`：以 `nums[i]` 结尾的**最大**乘积
- `mn`：以 `nums[i]` 结尾的**最小**乘积（往往是一个很大的负数）

以 `nums[i] = x` 结尾的子数组只有三种可能：

1. 只有 x 自己
2. 接在"以 i-1 结尾的最大乘积"后面：`mx × x`
3. 接在"以 i-1 结尾的最小乘积"后面：`mn × x`（x 为负数时，最小 × 负数 可能变成最大）

```
新 mx = max(x, mx × x, mn × x)
新 mn = min(x, mx × x, mn × x)
```

### 手动模拟（`[-2,3,-4]`）

| i | x | mx × x | mn × x | 新 mx | 新 mn | ans |
|---|---|---|---|---|---|---|
| 0 | -2 | — | — | -2 | -2 | -2 |
| 1 | 3 | -6 | -6 | 3 | -6 | 3 |
| 2 | -4 | -12 | **24** | 24 | -12 | **24** |

第 2 步中，最小值 -6 乘以 -4 变成了最大值 24——这就是要记录最小值的原因。

### 代码

```c
int maxProduct(int* nums, int numsSize) {
    int mx = nums[0];    // 以当前元素结尾的最大乘积
    int mn = nums[0];    // 以当前元素结尾的最小乘积
    int ans = nums[0];   // 全局答案

    for (int i = 1; i < numsSize; i++) {
        int x = nums[i];
        int a = mx * x;  // 先用"旧的" mx、mn 算好，避免更新时互相干扰
        int b = mn * x;

        // 新最大值：三者取最大
        int newMx = x;
        if (a > newMx) newMx = a;
        if (b > newMx) newMx = b;
        // 新最小值：三者取最小
        int newMn = x;
        if (a < newMn) newMn = a;
        if (b < newMn) newMn = b;

        mx = newMx;
        mn = newMn;
        if (mx > ans) ans = mx;
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：一遍扫描。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **照搬"最大子数组和"只维护最大值** → `[-2,3,-4]` 会得到 3，正确答案是 24。
2. **更新时用了新值** → 先写 `mx = max(...)`，再写 `mn = min(x, mx * x, mn * x)`，这里的 `mx` 已经被改过了，结果错误。要先存旧值。
3. **`ans` 初始化为 0** → `[-2]` 的答案是 -2，初始化为 0 会错误地返回 0。应初始化为 `nums[0]`。
4. **把不连续的数也乘进去** → 例如以为"挑出所有负数凑成偶数个"，但子数组必须连续，示例 2 就是反例。
5. **暴力枚举时每次都从头累乘** → 变成 O(n³)，一定超时。要在固定起点后边走边乘。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 |
|---|---|---|---|
| 暴力枚举 | O(n²) | O(1) | ⭐（数据大时有超时风险） |
| 动态规划（最大 + 最小） | O(n) | O(1) | ⭐⭐ 推荐 |
