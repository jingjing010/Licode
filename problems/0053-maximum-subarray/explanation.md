# 53. 最大子数组和 —— 小白详细题解

> 这是动态规划最经典的入门题之一。我们从"暴力"出发，一步步推出只扫一遍的 O(n) 解法。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一排数（有正有负），请你挑出**连续的一段**（至少 1 个数），让这一段加起来**尽可能大**，返回这个最大的和。

拿示例 1 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| 数值 | -2 | 1 | -3 | **4** | **-1** | **2** | **1** | -5 | 4 |

选下标 3~6 这一段：`4 + (-1) + 2 + 1 = 6`，没有比它更大的了。

**几个需要注意的细节：**

1. 必须是**连续**的一段，不能跳着挑（不能只挑所有正数）。
2. **至少选 1 个数**。如果全是负数，比如 `[-3,-1,-2]`，答案是 `-1`（只选最大的那个），**不是 0**！
3. 返回的是**和**，不是下标。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 答案的初始值不能随便写 0

```c
int best = 0;          // ❌ 全是负数时，答案应该是负数，但 best 永远停在 0
int best = nums[0];    // ✅ 用第一个元素当初始值，它本身就是一个合法的子数组
```

如果一定要用"一个很小的数"，可以用 `<limits.h>` 里的 `INT_MIN`（本 OJ 已自动包含这个头文件）。

### 2. 会不会溢出？

最多 `10^5` 个数，每个绝对值不超过 `10^4`，任何一段的和绝对值不超过 `10^9`，而 `int` 最大约 `2.1 × 10^9`，所以用 `int` 就够了。

### 3. 三目运算符 `? :`

```c
int m = a > b ? a : b;   // 如果 a > b，m = a；否则 m = b。相当于取较大值
```

## 💡 第三步：思路一 —— 前缀和 + 最小前缀

### 先想想暴力

枚举起点 `i`、终点 `j`，把 `nums[i..j]` 加起来，取最大值。用"边走边加"的写法是 O(n²)：

```c
// ❌ 思路正确但会超时：n = 10^5 时要算约 5 × 10^9 次
for (int i = 0; i < numsSize; i++) {
    int sum = 0;
    for (int j = i; j < numsSize; j++) {
        sum += nums[j];
        if (sum > best) best = sum;
    }
}
```

### 用前缀和优化

定义前缀和 `S[k]` = 前 `k` 个数的和（`S[0] = 0`）。那么：

> `nums[i] + ... + nums[j] = S[j+1] - S[i]`

固定终点 `j` 时，`S[j+1]` 是确定的，想让差最大，就要让被减的 `S[i]`（`i <= j`）**尽量小**。
所以从左往右扫，一边扫一边记住"目前见过的最小前缀和" `minS`，就不用再回头枚举起点了。

### 手动模拟（示例 1）

前缀和：`S = [0, -2, -1, -4, 0, -1, 1, 2, -3, 1]`

| j | nums[j] | S[j+1] | minS（S[0..j] 的最小值） | S[j+1] - minS | best |
|---|---|---|---|---|---|
| 0 | -2 | -2 | 0 | -2 | -2 |
| 1 | 1 | -1 | -2 | 1 | 1 |
| 2 | -3 | -4 | -2 | -2 | 1 |
| 3 | 4 | 0 | -4 | 4 | 4 |
| 4 | -1 | -1 | -4 | 3 | 4 |
| 5 | 2 | 1 | -4 | 5 | 5 |
| 6 | 1 | 2 | -4 | **6** | **6** |
| 7 | -5 | -3 | -4 | 1 | 6 |
| 8 | 4 | 1 | -4 | 5 | 6 |

答案 6。

### 代码

```c
int maxSubArray(int* nums, int numsSize) {
    int prefix = 0;          // 当前前缀和 S[j+1]（边扫边算，不需要真的开数组）
    int minPrefix = 0;       // 目前为止最小的前缀和，初始是 S[0] = 0
    int best = nums[0];      // 答案初始值：第一个元素本身就是合法子数组

    for (int j = 0; j < numsSize; j++) {
        prefix += nums[j];                   // 现在 prefix = S[j+1]
        // 以 j 结尾的最大子数组和 = S[j+1] - min(S[0..j])
        if (prefix - minPrefix > best) {
            best = prefix - minPrefix;
        }
        // 更新最小前缀和，注意要在"用完"之后再更新：
        // 这样 minPrefix 只包含 S[0..j]，保证子数组至少有 1 个元素
        if (prefix < minPrefix) {
            minPrefix = prefix;
        }
    }
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：只扫一遍。
- **空间复杂度 O(1)**：只用了几个变量。

## 🚀 第四步：思路二 —— 动态规划（Kadane 算法）

### 思路

定义 `cur` = **以当前元素 `nums[i]` 结尾**的最大子数组和。那么以 `nums[i]` 结尾的子数组只有两种选择：

1. **接在前面那段后面**：和为 `cur(上一个) + nums[i]`
2. **自己另起一段**：和为 `nums[i]`

哪个大选哪个。其实就是一句话：

> **如果前面那段的和是负数，它只会拖后腿，直接扔掉，从自己重新开始。**

所有 `cur` 里的最大值就是答案。

### 手动模拟（示例 1）

| i | nums[i] | 上一个 cur | 前面是负数吗？ | 新 cur | best |
|---|---|---|---|---|---|
| 0 | -2 | — | — | -2 | -2 |
| 1 | 1 | -2 | 是，扔掉 | 1 | 1 |
| 2 | -3 | 1 | 否，接上 | -2 | 1 |
| 3 | 4 | -2 | 是，扔掉 | 4 | 4 |
| 4 | -1 | 4 | 否 | 3 | 4 |
| 5 | 2 | 3 | 否 | 5 | 5 |
| 6 | 1 | 5 | 否 | **6** | **6** |
| 7 | -5 | 6 | 否 | 1 | 6 |
| 8 | 4 | 1 | 否 | 5 | 6 |

### 代码

```c
int maxSubArray(int* nums, int numsSize) {
    int cur = nums[0];       // 以当前元素结尾的最大子数组和
    int best = nums[0];      // 全局最大值

    for (int i = 1; i < numsSize; i++) {
        if (cur > 0) {
            cur = cur + nums[i];   // 前面那段是正的，接上它更划算
        } else {
            cur = nums[i];         // 前面那段 <= 0，只会拖后腿，从 nums[i] 重新开始
        }
        if (cur > best) {
            best = cur;            // 记录出现过的最大值
        }
    }
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(1)**。

> 💬 思路一和思路二其实是一回事：`cur` 就等于 `S[i+1] - minS`。动态规划只是换了个更直观的角度。

## 🧗 第五步：进阶 —— 分治法

题目进阶要求用分治。把数组从中间 `mid` 劈成两半，最大子数组只有三种可能：

1. 完全在左半边 → 递归求
2. 完全在右半边 → 递归求
3. **跨过中点** → 从 `mid` 往左延伸的最大和 + 从 `mid+1` 往右延伸的最大和

```c
// 返回 nums[l..r] 的最大子数组和
static int solve(int* nums, int l, int r) {
    if (l == r) return nums[l];              // 只有一个数，答案就是它
    int mid = l + (r - l) / 2;

    int leftBest = solve(nums, l, mid);      // 情况 1
    int rightBest = solve(nums, mid + 1, r); // 情况 2

    // 情况 3：必须包含 nums[mid] 和 nums[mid+1]
    int sum = 0, leftMax = nums[mid];
    for (int i = mid; i >= l; i--) {         // 从中点往左延伸
        sum += nums[i];
        if (sum > leftMax) leftMax = sum;
    }
    sum = 0;
    int rightMax = nums[mid + 1];
    for (int i = mid + 1; i <= r; i++) {     // 从中点往右延伸
        sum += nums[i];
        if (sum > rightMax) rightMax = sum;
    }
    int cross = leftMax + rightMax;

    int best = leftBest > rightBest ? leftBest : rightBest;
    return best > cross ? best : cross;
}

int maxSubArray(int* nums, int numsSize) {
    return solve(nums, 0, numsSize - 1);
}
```

- **时间复杂度 O(n log n)**：每层总共扫 n 个数，一共 log n 层。
- **空间复杂度 O(log n)**：递归调用栈的深度。

> 分治在这题上比 Kadane 慢，但它的思想（"跨中点"的情况单独处理）在很多题里都会用到，比如归并排序求逆序对。

## ⚠️ 第六步：小白常见错误

1. **`best` 初始化为 0** → 全负数数组 `[-3,-1,-2]` 会返回 0，正确答案是 -1。
2. **`cur` 小于 0 时把它重置为 0，然后才和 `best` 比较** → 例如写成 `cur += nums[i]; if (cur < 0) cur = 0; best = max(best, cur);`，全负数时同样会得到 0。要么先比较再重置，要么用思路二的写法。
3. **只把正数加起来** → 子数组必须连续，`[5,-100,5]` 的答案是 5，不是 10。
4. **前缀和写法里先更新 `minPrefix` 再计算答案** → 会出现 `S[j+1] - S[j+1] = 0`，相当于选了一个"空子数组"，全负数时又错成 0。
5. **用两层循环暴力** → 10^5 的数据会超时（Time Limit Exceeded）。

## 📊 第七步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力枚举 | O(n²) | O(1) | ⭐ | 只用来理解题意，会超时 |
| 前缀和 + 最小前缀 | O(n) | O(1) | ⭐⭐ | 前缀和技巧很通用 |
| 动态规划（Kadane） | O(n) | O(1) | ⭐⭐ | 面试标准答案 |
| 分治 | O(n log n) | O(log n) | ⭐⭐⭐ | 进阶，练习分治思想 |
