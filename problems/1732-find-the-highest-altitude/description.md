# 找到最高海拔

骑行从海拔0开始，gain[i]是相邻站点海拔差，返回途经的最高海拔。1 ≤ n ≤ 100，−100 ≤ gain[i] ≤ 100。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int largestAltitude(int* gain,int gainSize);
```

## 示例 1

输入：
```text
[-5,1,5,0,-7]
```
输出：
```text
1
```

## 示例 2

输入：
```text
[-4,-3,-2,-1,4,3,2]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
