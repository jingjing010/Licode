# 32. 最长有效括号 —— 小白详细题解

> 这道题被标为"困难"，但核心工具只有一个：**栈**。我们先用最朴素的枚举把它做对，再看看栈是怎么把它优化到一遍扫描的。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一串只有 `(` 和 `)` 的字符串，找出其中**连续的一段**，要求这一段的括号能完全配对，问这一段最长有多长。

"完全配对"（有效）的意思是：

- 左括号和右括号个数相等；
- 从左往右数，任何时候右括号都**不能比左括号多**（不能先出现没人配对的 `)`）。

拿示例 2 `s = ")()())"` 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 字符 | ) | ( | ) | ( | ) | ) |

下标 1~4 的 `()()` 是有效的，长度 4；整个字符串开头的 `)` 和结尾的 `)` 都配不上。答案是 4。

**几个需要注意的细节：**

1. 是**子串**（连续），不是子序列。`"()(()"` 的答案是 2，不是 4。
2. 字符串可能是**空串** `""`，答案是 0。
3. 有效括号串的长度一定是**偶数**。
4. `"(())"` 这种嵌套的也算有效，答案是 4。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 字符串与 `strlen`

`char* s` 指向一串以 `'\0'` 结尾的字符。`strlen(s)` 返回 `'\0'` 之前的字符个数，需要 `<string.h>`。空串的 `strlen` 是 0。

> 💬 不要在循环条件里写 `i < strlen(s)`，那样每次循环都会重新数一遍长度，O(n) 的算法就变成了 O(n²)。先 `int n = strlen(s);` 存起来。

### 2. 用数组模拟栈

C 语言没有现成的栈，我们用一个数组 + 一个"栈顶指针" `top` 来模拟：

```c
int* st = (int*)malloc(sizeof(int) * (n + 1));  // 最多放 n+1 个元素
int top = 0;            // 栈里有几个元素；栈顶元素是 st[top - 1]
st[top++] = x;          // 入栈：先放到 st[top]，再 top 加 1
top--;                  // 出栈：top 减 1 就行
```

## 💡 第三步：思路一 —— 枚举起点 + 计数（朴素）

### 思路

固定起点 `i`，从 `i` 往右扫描终点 `j`，用一个计数器 `bal` 表示"还没配对的左括号个数"：

- 遇到 `(`：`bal++`
- 遇到 `)`：`bal--`；如果 `bal < 0`，说明出现了多余的 `)`，从 `i` 开始的所有更长子串都不可能有效了，直接 `break`
- 如果 `bal == 0`，说明 `s[i..j]` 刚好配平，是一个有效子串，更新答案

### 手动模拟（`s = ")()())"`，只看起点 i = 1）

| j | s[j] | bal | 有效？ | best |
|---|---|---|---|---|
| 1 | ( | 1 | | 0 |
| 2 | ) | 0 | ✅ 长度 2 | 2 |
| 3 | ( | 1 | | 2 |
| 4 | ) | 0 | ✅ 长度 4 | **4** |
| 5 | ) | -1 | 多余的 )，break | 4 |

### 代码

```c
int longestValidParentheses(char* s) {
    int n = (int)strlen(s);
    int best = 0;

    for (int i = 0; i < n; i++) {        // 枚举起点
        int bal = 0;                     // 未配对的左括号数
        for (int j = i; j < n; j++) {    // 向右扩展终点
            if (s[j] == '(') bal++;
            else bal--;

            if (bal < 0) break;          // 右括号多了，后面再长也不可能有效
            if (bal == 0 && j - i + 1 > best) {
                best = j - i + 1;        // s[i..j] 有效，更新答案
            }
        }
    }
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：两层循环。n = 3×10⁴ 时最坏约 4.5×10⁸ 次简单运算（例如全是 `(` 时每个起点都扫到底），有超时风险。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 栈里存下标（一遍扫描）

### 思路

我们换个问题：**以每个位置 `i` 结尾的最长有效子串有多长？**

用栈保存**下标**，并约定：

> 栈底始终放一个"分界线"——**最后一个没被匹配的 `)` 的下标**（一开始还没有，就放 `-1`）。

扫描到 `s[i]` 时：

- `(`：把下标 `i` 入栈，等着以后被匹配。
- `)`：先弹出栈顶（尝试和它配对）。
  - 弹完后**栈空了**：说明刚才弹出的是分界线，这个 `)` 没人配对，它成为新的分界线，把 `i` 入栈。
  - 栈不空：配对成功！此时栈顶是"有效子串左边第一个不属于它的位置"，所以以 `i` 结尾的有效长度 = `i - 栈顶`。

### 手动模拟（`s = ")()())"`）

| i | s[i] | 操作 | 栈（底→顶） | 长度 i - 栈顶 | best |
|---|---|---|---|---|---|
| 初始 | | 放分界线 -1 | [-1] | | 0 |
| 0 | ) | 弹出 -1，栈空 → 0 成为新分界线 | [0] | | 0 |
| 1 | ( | 入栈 1 | [0, 1] | | 0 |
| 2 | ) | 弹出 1，栈不空 | [0] | 2 - 0 = 2 | 2 |
| 3 | ( | 入栈 3 | [0, 3] | | 2 |
| 4 | ) | 弹出 3，栈不空 | [0] | 4 - 0 = 4 | **4** |
| 5 | ) | 弹出 0，栈空 → 5 成为新分界线 | [5] | | 4 |

答案 4。

> ❓ **为什么 `(()` 能得到 2？** 栈变化：[-1] → [-1,0] → [-1,0,1] → 遇到 `)` 弹出 1，栈顶是 0，长度 2 - 0 = 2。下标 0 的 `(` 一直没被弹出，它自然地充当了分界线。

### 代码

```c
int longestValidParentheses(char* s) {
    int n = (int)strlen(s);
    // 栈里最多同时有 n 个 '(' 的下标 + 1 个分界线
    int* st = (int*)malloc(sizeof(int) * (n + 1));
    int top = 0;
    int best = 0;

    st[top++] = -1;                      // 初始分界线：-1

    for (int i = 0; i < n; i++) {
        if (s[i] == '(') {
            st[top++] = i;               // 左括号的下标入栈，等待配对
        } else {
            top--;                       // 右括号：弹出栈顶，尝试配对
            if (top == 0) {
                st[top++] = i;           // 栈空：这个 ')' 没人配对，成为新分界线
            } else {
                int len = i - st[top - 1];   // 栈顶是有效子串左边的边界
                if (len > best) best = len;
            }
        }
    }

    free(st);
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个下标最多入栈、出栈各一次。
- **空间复杂度 O(n)**：栈。

> 💬 还有一种 O(1) 空间的做法：从左往右数 `left`、`right`，相等时更新答案，`right > left` 时两者清零；再从右往左做一遍（`left > right` 时清零）。两遍扫描能覆盖 `"(()"` 这类单向扫描漏掉的情况。

---

## ⚠️ 第五步：小白常见错误

1. **栈里存字符而不是下标** → 只能判断"能不能配对"，却算不出有效子串的长度。
2. **忘了初始放入 -1** → 第一个配对成功时栈是空的，`st[top - 1]` 访问了 `st[-1]`，越界。
3. **栈空时不压入当前 `)` 的下标** → 之后的长度会跨过这个无法配对的 `)`，例如 `"())()"` 会错误地得到 4。
4. **只统计配对的括号总数** `"()(()"` → 一共配对了 2 对，算出 4，但它们不连续，正确答案是 2。
5. **在循环条件里写 `i < strlen(s)`** → 每次循环都重新计算长度，变成 O(n²)，最大数据可能超时。
6. **栈数组开小了** → 全是 `(` 时会入栈 n 次，加上分界线要 `n + 1` 个位置。
