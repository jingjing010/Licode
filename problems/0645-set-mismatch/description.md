# 错误的集合

原集合包含1到n，某个值被替换成另一个值，造成一个重复和一个缺失。返回[重复值,缺失值]。2 ≤ n ≤ 10^4。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* findErrorNums(int* nums,int numsSize,int* returnSize);
```

## 示例 1

输入：
```text
[1,2,2,4]
```
输出：
```text
[2,3]
```

## 示例 2

输入：
```text
[1,1]
```
输出：
```text
[1,2]
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
