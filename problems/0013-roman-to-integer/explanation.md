# 13. 罗马数字转整数 —— 小白详细题解

> 一道很好的字符串入门题：练习**逐个字符扫描**、**`switch` 查表**，以及"看一眼下一个字符"的技巧。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一串罗马数字（只由 `I V X L C D M` 组成），把它翻译成我们平时用的整数。

规则其实只有两条：

1. 一般情况下，大的写在左边、小的写在右边，**直接相加**：`LVIII = 50 + 5 + 1 + 1 + 1 = 58`。
2. 特殊情况：**小的写在大的左边**，表示"大减小"：`IV = 5 - 1 = 4`，`CM = 1000 - 100 = 900`。

拿示例 5 `"MCMXCIV"` 来说：

| 字符 | M | C | M | X | C | I | V |
|---|---|---|---|---|---|---|---|
| 数值 | 1000 | 100 | 1000 | 10 | 100 | 1 | 5 |
| 比右边小吗？ | 否 | **是** | 否 | **是** | 否 | **是** | 否（最后一个） |
| 贡献 | +1000 | **-100** | +1000 | **-10** | +100 | **-1** | +5 |

总和 = 1000 - 100 + 1000 - 10 + 100 - 1 + 5 = **1994**。

**几个需要注意的细节：**

1. 题目保证输入一定是合法的罗马数字，不需要检查格式。
2. 最后一个字符右边没有字符，它**一定是加**。
3. 结果最大 3999，用 `int` 足够。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. C 字符串以 `'\0'` 结尾

`char* s` 指向一串字符，最后有一个看不见的 `'\0'`（数值 0）表示结束。所以遍历可以这样写：

```c
for (int i = 0; s[i] != '\0'; i++) { ... }   // 也可以简写为 s[i]
```

### 2. 用 `switch` 把字符翻译成数值

`'I'`、`'V'` 这种**单引号**写法是字符常量，本质是一个整数（ASCII 码），所以能放进 `switch` 的 `case` 里：

```c
switch (c) {
case 'I': return 1;
case 'V': return 5;
...
}
```

### 3. 看"下一个字符"时不会越界

当 `i` 是最后一个字符时，`s[i + 1]` 正好是结尾的 `'\0'`，访问它是**安全的**（它属于字符串的一部分）。我们把 `'\0'` 的值当成 0，任何字符都不会比 0 小，自然就走"加"的分支。

## 💡 第三步：思路一 —— 先认两个字符的特殊组合

### 思路

最直接的想法：从左往右读，每次先看**当前和下一个字符能不能组成** `IV IX XL XC CD CM` 这六种特殊组合之一：

- 能：加上组合的值（如 `CM` 加 900），然后一次跳过 2 个字符；
- 不能：加上当前单个字符的值，跳过 1 个字符。

### 手动模拟（`"MCMXCIV"`）

| i | 看到 | 是特殊组合？ | 加多少 | 累计 |
|---|---|---|---|---|
| 0 | M C | 否 | 1000 | 1000 |
| 1 | C M | 是 CM | 900 | 1900 |
| 3 | X C | 是 XC | 90 | 1990 |
| 5 | I V | 是 IV | 4 | 1994 |

### 代码

```c
// 单个罗马字符 -> 数值
static int value1(char c) {
    switch (c) {
    case 'I': return 1;
    case 'V': return 5;
    case 'X': return 10;
    case 'L': return 50;
    case 'C': return 100;
    case 'D': return 500;
    case 'M': return 1000;
    }
    return 0;
}

int romanToInt(char* s) {
    int ans = 0;
    int i = 0;
    while (s[i] != '\0') {
        char a = s[i], b = s[i + 1];   // b 可能是 '\0'，这是安全的
        int pair = 0;                  // 两个字符组成的特殊值，0 表示不是特殊组合
        if (a == 'I' && b == 'V') pair = 4;
        else if (a == 'I' && b == 'X') pair = 9;
        else if (a == 'X' && b == 'L') pair = 40;
        else if (a == 'X' && b == 'C') pair = 90;
        else if (a == 'C' && b == 'D') pair = 400;
        else if (a == 'C' && b == 'M') pair = 900;

        if (pair != 0) {
            ans += pair;               // 特殊组合：一次吃掉两个字符
            i += 2;
        } else {
            ans += value1(a);          // 普通字符：直接加
            i += 1;
        }
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个字符最多看两次。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 比较相邻字符（更简洁）

### 思路

观察那六种特殊组合，它们有一个共同点：**左边字符的值比右边小**。而且"大减小"可以拆开理解：

> `CM = 1000 - 100` 等价于：遇到 `C` 时**减 100**，遇到 `M` 时**加 1000**。

于是规则统一成一句话：

> 如果当前字符的值 **小于** 它右边字符的值，就**减去**它；否则**加上**它。

不需要列举六种组合，代码更短，也不容易漏写。

### 手动模拟（示例 4：`"LVIII"`）

| i | 字符 | 值 | 右边的值 | 操作 | 累计 |
|---|---|---|---|---|---|
| 0 | L | 50 | 5 | 加 | 50 |
| 1 | V | 5 | 1 | 加 | 55 |
| 2 | I | 1 | 1 | 加（相等不算小） | 56 |
| 3 | I | 1 | 1 | 加 | 57 |
| 4 | I | 1 | 0（`'\0'`） | 加 | 58 |

### 代码

```c
// 单个罗马字符 -> 数值；'\0' 或其它字符返回 0
static int romanValue(char c) {
    switch (c) {
    case 'I': return 1;
    case 'V': return 5;
    case 'X': return 10;
    case 'L': return 50;
    case 'C': return 100;
    case 'D': return 500;
    case 'M': return 1000;
    }
    return 0;
}

int romanToInt(char* s) {
    int ans = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        int cur = romanValue(s[i]);          // 当前字符的值
        int next = romanValue(s[i + 1]);     // 右边字符的值（最后一个字符时是 '\0'，得到 0）
        if (cur < next) {
            ans -= cur;                      // 小的在大的左边：减
        } else {
            ans += cur;                      // 正常情况：加
        }
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：扫描一遍，n ≤ 15。
- **空间复杂度 O(1)**。

## ⚠️ 第五步：小白常见错误

1. **用双引号比较字符**：`if (s[i] == "I")` ❌ 比较的是地址，永远不相等，要写 `s[i] == 'I'`。
2. **`switch` 里忘了 `return` 或 `break`**：`case 'I': v = 1;` 后面没有 `break`，会"穿透"到下一个 `case`，`v` 最终被覆盖成别的值。
3. **把"相等"也当成减**：写成 `cur <= next` 时，`"III"` 会算成 `-1 - 1 + 1 = -1`。只有**严格小于**才减。
4. **思路一里特殊组合只跳 1 格**：`CM` 处理完 `i += 1`，下一轮又会把 `M` 单独加一次，`"CM"` 得到 1900。
5. **在 `for` 条件里写 `i < strlen(s)`**：每轮都重新数一遍长度，虽然本题短不会超时，但这是个坏习惯。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 特点 |
|---|---|---|---|---|
| 列举特殊组合 | O(n) | O(1) | ⭐ | 直观，但要写全六种组合 |
| 比较相邻字符 | O(n) | O(1) | ⭐ | 规则统一，代码最短 |

> 🎯 **学习建议**：思路二的"把规则统一成一句话"是很重要的能力——先观察特例的共同点，再写代码。
