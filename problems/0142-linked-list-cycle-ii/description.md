给定一个链表的头节点  `head` ，返回链表开始入环的第一个节点。 *如果链表无环，则返回 `null`。*

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（**索引从 0 开始**）。如果 `pos` 是 `-1`，则在该链表中没有环。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

**不允许修改** 链表。

### 示例 1

```
3 -> 2 -> 0 -> -4
     ^          |
     +----------+
```

```
输入：head = [3,2,0,-4], pos = 1
输出：1
解释：链表中有一个环，其尾部连接到第二个节点（返回索引为 1 的链表节点）。
```

### 示例 2

```
1 -> 2
^    |
+----+
```

```
输入：head = [1,2], pos = 0
输出：0
解释：链表中有一个环，其尾部连接到第一个节点（返回索引为 0 的链表节点）。
```

### 示例 3

```
输入：head = [1], pos = -1
输出：-1
解释：链表中没有环（返回 NULL）。
```

### 提示

- 链表中节点的数目范围在范围 `[0, 10^4]` 内
- `-10^5 <= Node.val <= 10^5`
- `pos` 的值为 `-1` 或者链表中的一个有效索引

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode *detectCycle(struct ListNode *head);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `head`：链表的头指针，空链表为 `NULL`。如果有环，链表最后一个结点的 `next` 会指向下标为 `pos` 的结点
- 返回值：**环的入口结点的指针**（不是下标！）；无环时返回 `NULL`
- 不允许修改链表（结点的 `val` 和 `next` 都不能改）

### 自定义输入格式

```
[3,2,0,-4]
1
```

第 1 行是链表各结点的值，第 2 行是 `pos`（`-1` 表示无环）。判题程序按 `pos` 构造好环后调用你的函数，然后输出**你返回的结点在链表中的下标**（从 0 开始）；返回 `NULL` 时输出 `-1`。如果你修改了链表，会输出错误提示。
