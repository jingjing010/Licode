# 存在重复元素

判断整数数组 nums 中是否存在至少出现两次的值。0 ≤ 长度 ≤ 10^5，元素为32位整数。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool containsDuplicate(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,2,3,1]
```
输出：
```text
true
```

## 示例 2

输入：
```text
[1,2,3,4]
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
