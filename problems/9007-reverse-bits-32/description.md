SPI、I2S 等串行外设一位一位地收发数据，但不同器件的约定不同：有的 **高位先发**（MSB first），有的 **低位先发**（LSB first）。如果单片机的 SPI 只支持 MSB first，而外接的芯片按 LSB first 发送，那么收到的 32 位数据的 **位序正好是反的**：芯片的第 `0` 位落在了接收寄存器的第 `31` 位，第 `1` 位落在了第 `30` 位……PCB 走线时把数据总线接反了，也会出现同样的问题。

给定接收到的 32 位数据 `x`，请把它的 **位序完全反转**：原来的第 `i` 位变成结果的第 `31 - i` 位（`0 <= i <= 31`），返回反转后的值。

### 示例 1

```
输入：x = 1
输出：2147483648
解释：0x00000001 只有第 0 位是 1，反转后只有第 31 位是 1，即 0x80000000。
```

### 示例 2

```
输入：x = 43261596
输出：964176192
解释：
二进制 00000010100101000001111010011100
反转为 00111001011110000010100101000000 = 964176192。
```

### 示例 3

```
输入：x = 4294967293
输出：3221225471
解释：0xFFFFFFFD 只有第 1 位是 0，反转后只有第 30 位是 0，即 0xBFFFFFFF。
```

### 提示

- `0 <= x <= 2^32 - 1`

### 函数说明

```c
uint32_t reverse_bits32(uint32_t x);
```

- `x`：原始的 32 位数据
- 返回值：位序反转后的 32 位数据

### 自定义输入格式

```
1
```

输入一行，为十进制整数 `x`。输出为反转后的值（十进制）。
