数据在串口线、I²C 总线、无线信道上传输时可能出现位翻转。为了让接收方发现错误，发送方会在数据后面附加一个**校验码**。CRC（循环冗余校验）是嵌入式中最常用的校验算法：温湿度传感器 SHT3x、SMBus 的 PEC、1-Wire 等协议都使用 8 位 CRC。

请实现标准的 **CRC-8**（也叫 CRC-8/SMBUS），参数如下：

| 参数 | 值 | 含义 |
|---|---|---|
| 宽度 width | 8 | 校验值 8 位 |
| 多项式 poly | `0x07` | 即 x⁸ + x² + x + 1（最高位 x⁸ 省略不写） |
| 初值 init | `0x00` | 计算开始前 crc 寄存器的值 |
| 输入反射 refin | 否 | 每个字节从**最高位**开始处理 |
| 输出反射 refout | 否 | 结果不做位反转 |
| 输出异或 xorout | `0x00` | 结果不异或 |
| 校验值 check | `0xF4` | 字符串 `"123456789"` 的 CRC 结果 |

计算过程（逐位算法）：crc 初值为 `0x00`；对每个字节，先 `crc ^= byte`，再重复 8 次：若 crc 最高位为 1，则 `crc = (crc << 1) ^ 0x07`，否则 `crc = crc << 1`（只保留低 8 位）。全部字节处理完后的 crc 即为结果。

### 示例 1

```
输入：buf = [49,50,51,52,53,54,55,56,57]
输出：244
解释：这是字符串 "123456789" 的 ASCII 码，CRC-8 结果为 0xF4 = 244，即标准校验值。
```

### 示例 2

```
输入：buf = [1]
输出：7
解释：crc = 0x00 ^ 0x01 = 0x01，左移 7 次都不触发异或，得到 0x80；
     第 8 次最高位为 1：(0x80 << 1) ^ 0x07 = 0x100 ^ 0x07，保留低 8 位为 0x07。
```

### 示例 3

```
输入：buf = []
输出：0
解释：没有数据时结果就是初值 0x00。
```

### 提示

- `0 <= len <= 10^5`
- `0 <= buf[i] <= 255`

### 函数说明

```c
uint8_t crc8(const uint8_t* buf, size_t len);
```

- 返回 CRC-8 结果，判题程序以十进制输出

### 自定义输入格式

```
[49,50,51,52,53,54,55,56,57]
```

一行字节数组（每个元素 `0 ~ 255`）。
