给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

| 数字 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|
| 字母 | abc | def | ghi | jkl | mno | pqrs | tuv | wxyz |

### 示例 1

```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

### 示例 2

```
输入：digits = ""
输出：[]
```

### 示例 3

```
输入：digits = "2"
输出：["a","b","c"]
```

### 提示

- `0 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字。

### 函数说明

```c
char** letterCombinations(char* digits, int* returnSize);
```

- `digits`：以 `'\0'` 结尾的数字字符串（可能是空串 `""`）
- 返回值：用 `malloc` 申请的字符串数组，每个字符串也要 `malloc`，并以 `'\0'` 结尾
- `*returnSize`：写入组合的个数；`digits` 为空时写 0

### 自定义输入格式

```
"23"
```

只有 1 行：带双引号的字符串 `digits`。（组合的顺序任意，判题时会把你返回的字符串按字典序排序后输出）
