给定一个整数 `n` ，返回 `n!` 结果中尾随零的数量。

提示 `n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1`

### 示例 1

```
输入：n = 3
输出：0
解释：3! = 6 ，不含尾随 0
```

### 示例 2

```
输入：n = 5
输出：1
解释：5! = 120 ，有一个尾随 0
```

### 示例 3

```
输入：n = 0
输出：0
```

### 提示

- `0 <= n <= 10^4`

**进阶：** 你可以设计并实现对数时间复杂度的算法来解决此问题吗？

### 函数说明

```c
int trailingZeroes(int n);
```

- `n`：非负整数
- 返回值：`n!` 末尾连续 0 的个数

### 自定义输入格式

```
5
```

只有 1 行，是整数 `n`。
