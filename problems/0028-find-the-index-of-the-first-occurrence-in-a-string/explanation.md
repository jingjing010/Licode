# 找出字符串中第一个匹配项的下标：题解

## 📖 先读懂题目

给定小写字符串haystack与needle，返回needle首次出现的下标，不存在返回−1。长度1到10^4。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"sadbutsad" / "sad"` | `0` |
| 2 | `"leetcode" / "leeto"` | `-1` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

寻找第一个匹配位置；strstr返回NULL表示不存在，否则减去原字符串指针得到下标。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int strStr(char *haystack, char *needle) {
    /* 标准库返回匹配起点，指针相减得到下标。 */
    char *p = strstr(haystack, needle);
    return p ? (int)(p - haystack) : -1;
}
```

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间最坏 O(nm)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
