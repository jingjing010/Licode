# 875. 爱吃香蕉的珂珂 —— 小白详细题解

> 这是"**二分答案**"最经典的入门题。不在数组里二分，而是在"**速度**"这个答案上二分。学会它，410、1011、1482 都是同一个套路。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 有几堆香蕉，珂珂每小时只能挑**一堆**吃，最多吃 k 根。这一堆不够 k 根就吃完这堆，这一小时剩下的时间就浪费了。问：要在 h 小时内吃完，**k 最小是多少**？

拿示例 1 `piles = [3,6,7,11], h = 8` 来说，试几个速度：

| 速度 k | 每堆耗时 | 总耗时 | <= 8 ? |
|---|---|---|---|
| 3 | 1, 2, 3, 4 | 10 | ❌ |
| **4** | 1, 2, 2, 3 | **8** | ✅ |
| 5 | 1, 2, 2, 3 | 8 | ✅ |

速度 4 是能按时吃完的最小速度，答案 4。

**几个需要注意的细节：**

1. 一小时只吃一堆。吃一堆 p 根要 `⌈p / k⌉` 小时（向上取整）。比如 p = 7, k = 4，要 2 小时。
2. 速度 k 必须是正整数，最小是 1。
3. k 不需要超过 `max(piles)`：速度等于最大堆时，每堆 1 小时就吃完，再快也没用。
4. 题目保证 `h >= piles.length`，所以 `k = max(piles)` 一定可行，答案一定存在。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 整数的向上取整

C 语言整数除法是**向下取整**（正数）。要向上取整 `⌈p / k⌉`，有两种常用写法：

```c
int a = (p + k - 1) / k;   // 经典写法，但 p + k - 1 可能溢出！
int b = (p - 1) / k + 1;   // p >= 1 时等价，而且不会溢出 ✅
```

本题 `p` 和 `k` 都可能接近 `10^9`，`p + k - 1` 接近 `2 × 10^9`，超过了 `INT_MAX`（约 `2.147 × 10^9`）——非常危险。用第二种写法最安全。

### 2. 总时间要用 `long long`

速度 k = 1 时，总时间 = 所有香蕉数之和，最多 `10^4 × 10^9 = 10^13`，远超 int 范围。所以累加总时间的变量要用 `long long`。

---

## 💡 第三步：思路一 —— 从 k = 1 开始一个一个试（会超时）

### 思路

速度从 1 开始逐个尝试，第一个能在 h 小时内吃完的就是答案。

### 代码

```c
// ❌ 思路正确但会超时：max(piles) 可达 10^9，最坏要试 10^9 个速度
int minEatingSpeed(int* piles, int pilesSize, int h) {
    for (int k = 1; ; k++) {
        long long total = 0;                      // 速度为 k 时的总耗时
        for (int i = 0; i < pilesSize; i++) {
            total += (piles[i] - 1) / k + 1;      // 向上取整
        }
        if (total <= h) return k;                 // 第一个可行的速度
    }
}
```

### 复杂度分析

- **时间复杂度 O(n · max(piles))**：最坏 `10^4 × 10^9`，绝对超时。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 二分答案（标准解法）

### 为什么能二分？

速度 k 越大，每堆耗时越少（或不变），总耗时**单调不增**：

```
k:          1    2    3    4    5    6  ...  11
总耗时:     27   15   10   8    8    6  ...  4
<= 8 ?:     否   否   否   是   是   是  ...  是
                          ↑ 第一个"是"就是答案
```

"能不能在 h 小时内吃完"关于 k 是"**前面全否、后面全是**"——找第一个"是"，就是二分查找！

### 二分答案的三步套路

1. **确定答案范围**：`k ∈ [1, max(piles)]`。
2. **写 check 函数**：给定 k，算总耗时，判断是否 `<= h`。
3. **二分找第一个满足 check 的 k**。

### 区间定义与循环条件

- 区间：**闭区间 `[lo, hi]`**，`lo = 1, hi = max(piles)`，答案一定在里面。
- `while (lo < hi)`。
- `check(mid)` 成立：mid 可行，答案是 mid 或更小：`hi = mid`
- 否则：mid 太慢，答案更大：`lo = mid + 1`
- `mid = lo + (hi - lo) / 2`：hi 可能接近 10⁹，`lo + hi` 接近 2×10⁹，已经很接近 int 上限，一定要用防溢出写法。

### 手动模拟（`piles = [3,6,7,11], h = 8`）

| 轮次 | lo | hi | mid | 总耗时 | <= 8 ? | 操作 |
|---|---|---|---|---|---|---|
| 1 | 1 | 11 | 6 | 1+1+2+2 = 6 | 是 | hi = 6 |
| 2 | 1 | 6 | 3 | 1+2+3+4 = 10 | 否 | lo = 4 |
| 3 | 4 | 6 | 5 | 1+2+2+3 = 8 | 是 | hi = 5 |
| 4 | 4 | 5 | 4 | 1+2+2+3 = 8 | 是 | hi = 4 |
| 结束 | 4 | 4 | | | | 返回 4 ✅ |

### 代码

```c
// 速度为 k 时，吃完所有香蕉需要多少小时
static long long hoursNeeded(int* piles, int pilesSize, int k) {
    long long total = 0;                     // 可能高达 10^13，必须 long long
    for (int i = 0; i < pilesSize; i++) {
        total += (piles[i] - 1) / k + 1;     // ⌈piles[i] / k⌉，不会溢出的写法
    }
    return total;
}

int minEatingSpeed(int* piles, int pilesSize, int h) {
    int lo = 1, hi = 1;                      // 答案范围 [1, max(piles)]
    for (int i = 0; i < pilesSize; i++) {
        if (piles[i] > hi) hi = piles[i];
    }

    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;        // 防溢出
        if (hoursNeeded(piles, pilesSize, mid) <= h) {
            hi = mid;            // 速度 mid 来得及，试试更慢的
        } else {
            lo = mid + 1;        // 来不及，必须更快
        }
    }
    return lo;
}
```

### 复杂度分析

- **时间复杂度 O(n · log(max(piles)))**：二分约 30 轮，每轮 O(n)，约 `3 × 10^5` 次运算。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **总耗时用 `int` 累加** → k 很小时总耗时可达 10¹³，溢出后变成负数，`<= h` 误判为可行，答案偏小。
2. **向上取整写成 `(p + k - 1) / k`（全是 int）** → p 和 k 都接近 10⁹ 时溢出。改用 `(p - 1) / k + 1`，或者先转 `long long`。
3. **向上取整写成 `p / k`** → 这是向下取整，p = 7, k = 4 时算成 1 小时，实际要 2 小时。
4. **`lo` 从 0 开始** → `mid` 可能是 0，出现**除以 0**，程序崩溃（Runtime Error）。
5. **`mid = (lo + hi) / 2`** → lo、hi 都接近 10⁹ 时和超过 int 上限。
6. **check 条件写成 `== h`** → 总耗时不一定恰好等于 h，应该是 `<= h`。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐个尝试速度 | O(n · max) | O(1) | ⭐ | 会超时，只用来理解 |
| 二分答案 | O(n · log max) | O(1) | ⭐⭐ | 标准解法 |

> 🎯 **学习建议**：记住"二分答案"三步——**答案范围、check 函数、找第一个可行值**。题目里出现"最小的……使得……能够……"这类说法时，就要想到它。
