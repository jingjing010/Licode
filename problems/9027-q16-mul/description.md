很多 MCU（如 Cortex-M0/M3、8051）没有硬件浮点单元，用 `float` 做运算要调用很慢的软件库。电机控制（PID、FOC）、数字滤波、音频处理里，工程师普遍使用**定点数**代替浮点数。

**Q16.16 格式**用一个 `int32_t` 表示一个实数：高 16 位是整数部分（含符号），低 16 位是小数部分，即

```
实数值 = 原始值 / 65536
```

例如 `1.5` 存成 `1.5 × 65536 = 98304`，`-0.5` 存成 `-32768`。

请实现函数 `q16_mul`：输入两个 Q16.16 原始值 `a`、`b`，返回它们乘积的 Q16.16 原始值：

1. 计算精确乘积 `a × b`（需要 64 位）
2. 除以 `65536`，结果**向负无穷取整**（即对 64 位乘积**算术右移 16 位**）
3. 如果结果超出 `int32_t` 范围，**饱和**到 `2147483647` 或 `-2147483648`

### 示例 1

```
输入：a = 98304, b = 131072
输出：196608
解释：1.5 × 2.0 = 3.0，3.0 × 65536 = 196608。
```

### 示例 2

```
输入：a = -98304, b = 32768
输出：-49152
解释：-1.5 × 0.5 = -0.75，-0.75 × 65536 = -49152。
```

### 示例 3

```
输入：a = 2147483647, b = 131072
输出：2147483647
解释：约 32768.0 × 2.0 = 65536.0，超出 Q16.16 能表示的最大值（约 32767.99998），饱和为 2147483647。
```

### 提示

- `-2147483648 <= a, b <= 2147483647`
- 向负无穷取整的例子：精确结果为 `-0.3`（原始值单位）时取 `-1`，为 `0.3` 时取 `0`
- 不要使用 `float` / `double`

### 函数说明

```c
int32_t q16_mul(int32_t a, int32_t b);
```

- `a`、`b`：两个 Q16.16 定点数的原始值
- 返回值：乘积的 Q16.16 原始值（向负无穷取整，超范围饱和）

### 自定义输入格式

```
98304
131072
```

第 1 行是 `a`，第 2 行是 `b`（都是十进制原始值）。输出为结果的十进制原始值。
