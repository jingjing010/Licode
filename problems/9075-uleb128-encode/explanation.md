# ULEB128 可变长整数编码：题解

## 📖 先读懂题目

把uint32_t编码为最短无符号LEB128，0编码为[0]。返回字节整数数组，输入0到4294967295。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `624485` | `[229,142,38]` |
| 2 | `0` | `[0]` |

## 🧰 需要的 C 语言知识

`uint32_t`运算按2^32取模。先转换为无符号类型再移位，避免负数左移；移位数必须小于类型位宽。超过INT_MAX的结果仍要按无符号值理解。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

每字节保存7个低位，最高位表示后面还有数据，低有效组先发送。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *uleb128Encode(uint32_t value, int *returnSize) {
    int *out = malloc(5 * sizeof(int)), k = 0;
    do {
        uint8_t byte = (uint8_t)(value & 0x7fu);
        value >>= 7;
        if (value)
            byte |= 0x80;
        out[k++] = byte;
    } while (value);
    *returnSize = k;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，输出空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 用有符号int承接无符号32位位模式，导致最高位被当成符号。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
