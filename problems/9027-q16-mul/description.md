STM32F0/F1、ESP8266 等很多 MCU **没有硬件浮点单元（FPU）**，用 `float` 做一次乘法要调用几十上百个周期的软件库。因此 PID 控制、电机 FOC、数字滤波等算法常常改用**定点数**来计算。

**Q16.16** 格式用一个 `int32_t` 表示实数：高 16 位是整数部分，低 16 位是小数部分，也就是说原始值 `x` 表示的实数是 `x / 65536`。例如：

| 实数 | Q16.16 原始值 |
|---|---|
| 1.0 | 65536 |
| 1.5 | 98304 |
| -0.5 | -32768 |
| 0.25 | 16384 |

请实现函数 `q16_mul`：计算两个 Q16.16 数的乘积，返回 Q16.16 格式的结果。精确规则如下：

1. 计算数学上的乘积 `P = a × b`（这个值可能远远超出 32 位范围）
2. 结果原始值 = `P / 65536` **向下取整**（向负无穷方向取整，等价于对 64 位有符号整数算术右移 16 位）
3. 如果结果大于 `2147483647`，返回 `2147483647`；小于 `-2147483648`，返回 `-2147483648`（**饱和**）

### 示例 1

```
输入：a = 98304, b = 131072
输出：196608
解释：1.5 × 2.0 = 3.0，3.0 的原始值是 196608。
```

### 示例 2

```
输入：a = -98304, b = 32768
输出：-49152
解释：-1.5 × 0.5 = -0.75，-0.75 的原始值是 -49152。
```

### 示例 3

```
输入：a = 2147483647, b = 131072
输出：2147483647
解释：约 32768.0 × 2.0 = 65536.0，超出 Q16.16 能表示的最大值（约 32767.99998），饱和到 2147483647。
```

### 提示

- `-2147483648 <= a, b <= 2147483647`
- 你可以使用 `int64_t`

### 函数说明

```c
int32_t q16_mul(int32_t a, int32_t b);
```

- `a`、`b`：Q16.16 格式的乘数（原始值）
- 返回值：Q16.16 格式的乘积（原始值），向下取整并饱和

### 自定义输入格式

```
98304
131072
```

第 1 行是 `a`，第 2 行是 `b`（都是十进制的原始值）。输出为结果原始值。
