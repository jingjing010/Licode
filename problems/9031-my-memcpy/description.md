`memcpy` 是嵌入式开发中使用频率最高的库函数之一：把串口收到的数据拷到协议缓冲区、把结构体拷进 Flash 写缓冲、把 ADC 采样结果拷给 DMA……面试中"手写 memcpy"更是必考题。

请你实现 `my_memcpy(dst, src, n)`：把从 `src` 开始的 `n` 个**字节**复制到 `dst`，返回 `dst`。本题保证 `src` 和 `dst` 指向的两段内存**不重叠**。

> **不要调用库函数 `memcpy` / `memmove`**，请自己用指针完成。

判题程序准备一个和 `src` 一样长、**初始全为 0** 的缓冲区 `dst`，调用 `my_memcpy(dst, src, n)` 后输出整个 `dst`。

### 示例 1

```
输入：src = [1,2,3,4,5], n = 3
输出：[1,2,3,0,0]
解释：只复制前 3 个字节，dst 后面 2 个字节保持 0。
```

### 示例 2

```
输入：src = [255,0,128,7], n = 4
输出：[255,0,128,7]
解释：全部复制。字节值 0 也要照常复制（memcpy 不是字符串函数，不会遇到 0 就停）。
```

### 示例 3

```
输入：src = [9,8,7], n = 0
输出：[0,0,0]
解释：n = 0 时什么都不复制。
```

### 提示

- `1 <= src.length <= 10^5`
- `0 <= src[i] <= 255`
- `0 <= n <= src.length`

### 函数说明

```c
void* my_memcpy(void* dst, const void* src, size_t n);
```

- `dst`：目标首地址，`src`：源首地址，两者不重叠
- `n`：要复制的字节数
- 返回值：必须返回 `dst`

`dst` 前后各有一段"哨兵"内存。如果返回值不是 `dst`，或写到了 `dst` 之外，会输出一行错误信息（判为答案错误）。

### 自定义输入格式

```
[1,2,3,4,5]
3
```

第 1 行是 `src` 的字节内容，第 2 行是 `n`。输出为调用后的整个 `dst`。
