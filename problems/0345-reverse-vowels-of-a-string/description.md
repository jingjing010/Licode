给你一个字符串 `s` ，仅反转字符串中的所有元音字母，并返回结果字符串。

元音字母包括 `'a'`、`'e'`、`'i'`、`'o'`、`'u'`，且可能以大小写两种形式出现不止一次。

### 示例 1

```
输入：s = "IceCreAm"
输出："AceCreIm"
解释：
s 中的元音是 ['I', 'e', 'e', 'A']。反转这些元音，s 变为 "AceCreIm".
```

### 示例 2

```
输入：s = "leetcode"
输出："leotcede"
```

### 提示

- `1 <= s.length <= 3 * 10^5`
- `s` 由 **可打印的 ASCII** 字符组成

### 函数说明

```c
char* reverseVowels(char* s);
```

- `s`：以 `'\0'` 结尾的字符串（可以直接修改它）
- 返回值：结果字符串。可以原地修改 `s` 后返回 `s`，也可以返回 `malloc` 申请的新字符串

### 自定义输入格式

```
"IceCreAm"
```

只有 1 行，带双引号的字符串 `s`。字符串中的双引号写作 `\"`，反斜杠写作 `\\`。
