# 448. 找到所有数组中消失的数字 —— 小白详细题解

> 这道题教你一个非常巧妙的技巧：**把数组自己当成哈希表**，用"变成负数"来做标记。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 数组长度是 `n`，里面每个数都在 `1 ~ n` 之间，但有的数出现了多次，所以必然有的数**一次都没出现**。把这些没出现的数全部找出来。

示例 1：`nums = [4,3,2,7,8,2,3,1]`，`n = 8`

| 数字 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 出现了吗？ | ✅ | ✅（2 次） | ✅（2 次） | ✅ | ❌ | ❌ | ✅ | ✅ |

答案是 `[5,6]`。

**几个需要注意的细节：**

1. 返回的是一个**新数组**，长度不固定，要写进 `*returnSize`。
2. 可能**没有**消失的数字（如 `[2,1]`），此时返回长度为 0。
3. `n` 最大 10⁵，两层循环（每个数字都在数组里找一遍）是 10¹⁰ 次，会超时。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回数组：最多多长？

消失的数字最多 `n - 1` 个，所以 `malloc(sizeof(int) * numsSize)` 一定够用，最后用 `*returnSize` 告诉调用者实际用了几个。

### 2. `abs` 取绝对值

`abs(x)` 来自 `<stdlib.h>`，返回 `x` 的绝对值：`abs(-5) == 5`。思路二会把数组元素改成负数，读取时要用 `abs` 还原。

---

## 💡 第三步：思路一 —— 标记数组

### 思路

1. 开一个长度为 `n + 1` 的 `seen` 数组（下标 1 ~ n 有用），全部为 `false`；
2. 遍历 `nums`，`seen[nums[i]] = true`；
3. 从 1 到 n，凡是 `seen[x] == false` 的 `x` 都放进答案。

### 代码

```c
int* findDisappearedNumbers(int* nums, int numsSize, int* returnSize) {
    bool* seen = (bool*)calloc(numsSize + 1, sizeof(bool));   // 下标 0 不用，1~n 对应数字
    for (int i = 0; i < numsSize; i++) {
        seen[nums[i]] = true;                  // 标记出现过的数字
    }

    int* res = (int*)malloc(sizeof(int) * numsSize);
    int cnt = 0;
    for (int x = 1; x <= numsSize; x++) {      // 检查 1 ~ n 每个数字
        if (!seen[x]) {
            res[cnt] = x;                      // 没出现过 → 放进答案
            cnt++;
        }
    }
    free(seen);
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(n)**（`seen` 数组）。

---

## 🚀 第四步：思路二 —— 原地标记（变负数）

### 思路

进阶要求不使用额外空间。观察：数组有 `n` 个位置（下标 `0 ~ n-1`），数字范围是 `1 ~ n`——**正好一一对应**：数字 `x` ↔ 下标 `x - 1`。

那就用"**下标 `x-1` 处的数是不是负数**"来表示"数字 `x` 有没有出现过"：

1. 遍历每个 `nums[i]`，设 `x = abs(nums[i])`（它可能已经被别人改成负数了，所以取绝对值），把 `nums[x - 1]` 变成负数（已经是负数就不用再变了）；
2. 再遍历一遍，**仍然是正数**的位置 `i`，说明数字 `i + 1` 从没出现过。

### 手动模拟（示例 1：`[4,3,2,7,8,2,3,1]`）

| 读到的数 x | 要标记的下标 x-1 | 数组 |
|---|---|---|
| 4 | 3 | [4,3,2,**-7**,8,2,3,1] |
| 3 | 2 | [4,3,**-2**,-7,8,2,3,1] |
| abs(-2)=2 | 1 | [4,**-3**,-2,-7,8,2,3,1] |
| abs(-7)=7 | 6 | [4,-3,-2,-7,8,2,**-3**,1] |
| 8 | 7 | [4,-3,-2,-7,8,2,-3,**-1**] |
| 2 | 1 | 已是负数，不变 |
| abs(-3)=3 | 2 | 已是负数，不变 |
| abs(-1)=1 | 0 | [**-4**,-3,-2,-7,8,2,-3,-1] |

最后仍为正数的是下标 4（值 8）和下标 5（值 2），所以消失的数字是 **5 和 6**。

### 代码

```c
int* findDisappearedNumbers(int* nums, int numsSize, int* returnSize) {
    // 第一遍：数字 x 出现过，就把下标 x-1 处的数变成负数
    for (int i = 0; i < numsSize; i++) {
        int x = abs(nums[i]);          // nums[i] 可能已被标记成负数，取绝对值还原
        if (nums[x - 1] > 0) {         // 还没标记过才取反，避免负负得正
            nums[x - 1] = -nums[x - 1];
        }
    }

    // 第二遍：仍是正数的位置 i，说明数字 i+1 没出现过
    int* res = (int*)malloc(sizeof(int) * numsSize);
    int cnt = 0;
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] > 0) {
            res[cnt] = i + 1;
            cnt++;
        }
    }
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两遍扫描。
- **空间复杂度 O(1)**：除了返回数组，没有用额外空间。满足进阶要求。

---

## ⚠️ 第五步：小白常见错误

1. **标记时没有取绝对值**：`nums[nums[i] - 1]` → `nums[i]` 已被改成负数时，下标变成负数，越界崩溃。
2. **直接写 `nums[x - 1] = -nums[x - 1]` 不判断正负** → 同一个数字出现两次时会"负负得正"，标记被取消，示例 1 会多报出 2、3。
3. **下标和数字差 1 搞混** → 数字 `x` 对应下标 `x - 1`；最后输出时下标 `i` 对应数字 `i + 1`。
4. **标记数组只开 `n` 个**却用 `seen[nums[i]]` → `nums[i] = n` 时越界。要么开 `n + 1` 个，要么用 `seen[nums[i] - 1]`。
5. **两层循环暴力查找** → O(n²)，n = 10⁵ 时超时。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 标记数组 | O(n) | O(n) | ⭐ | 先写这个 |
| 原地变负数标记 | O(n) | O(1) | ⭐⭐ | 进阶解法，"数组当哈希表"的经典技巧 |
