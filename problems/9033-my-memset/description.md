嵌入式程序里到处都是 `memset`：上电时把接收缓冲区清零、把结构体初始化为 0、把一段显存填成同一种颜色、擦除 Flash 前把写缓冲填成 `0xFF`……

请你实现 `my_memset(s, c, n)`：把从 `s` 开始的 `n` 个字节**全部**设置为 `c`，返回 `s`。

和标准库一样，参数 `c` 的类型是 `int`，但真正写入内存的是 **`(unsigned char)c`**，也就是 `c` 的**低 8 位**。

> **不要调用库函数 `memset`**，请自己用指针完成。

判题程序准备一个缓冲区 `buf`，调用 `my_memset(buf + offset, c, n)`，最后输出整个 `buf`。

### 示例 1

```
输入：buf = [1,2,3,4,5,6], offset = 1, c = 0, n = 3
输出：[1,0,0,0,5,6]
解释：把 buf[1..3] 清零，其余字节不变。
```

### 示例 2

```
输入：buf = [0,0,0,0], offset = 0, c = 255, n = 4
输出：[255,255,255,255]
解释：整个缓冲区填成 0xFF（Flash 擦除后的状态）。
```

### 示例 3

```
输入：buf = [7,7,7], offset = 0, c = 300, n = 2
输出：[44,44,7]
解释：300 = 0x12C，低 8 位是 0x2C = 44，所以写进去的是 44。
```

### 提示

- `1 <= buf.length <= 10^5`
- `0 <= buf[i] <= 255`
- `-10^6 <= c <= 10^6`
- `0 <= offset`，`0 <= n`，`offset + n <= buf.length`

### 函数说明

```c
void* my_memset(void* s, int c, size_t n);
```

- `s`：要填充的内存首地址
- `c`：填充值，只使用低 8 位
- `n`：要填充的字节数
- 返回值：必须返回 `s`

`buf` 前后各有一段"哨兵"内存。如果返回值不是 `s`，或写到了 `buf` 之外，会输出一行错误信息（判为答案错误）。

### 自定义输入格式

```
[1,2,3,4,5,6]
1
0
3
```

第 1 行是 `buf` 的字节内容，第 2 行是 `offset`，第 3 行是 `c`，第 4 行是 `n`。输出为调用后的整个 `buf`。
