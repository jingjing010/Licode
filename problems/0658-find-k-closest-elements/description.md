给定一个 **排序好** 的数组 `arr` ，两个整数 `k` 和 `x` ，从数组中找到最靠近 `x`（两数之差最小）的 `k` 个数。返回的结果必须要是按升序排好的。

整数 `a` 比整数 `b` 更接近 `x` 需要满足：

- `|a - x| < |b - x|` 或者
- `|a - x| == |b - x|` 且 `a < b`

### 示例 1

```
输入：arr = [1,2,3,4,5], k = 4, x = 3
输出：[1,2,3,4]
```

### 示例 2

```
输入：arr = [1,1,2,3,4,5], k = 4, x = -1
输出：[1,1,2,3]
```

### 提示

- `1 <= k <= arr.length`
- `1 <= arr.length <= 10^4`
- `arr` 按 **升序** 排列
- `-10^4 <= arr[i], x <= 10^4`

### 函数说明

```c
int* findClosestElements(int* arr, int arrSize, int k, int x, int* returnSize);
```

- `arr`：升序数组首地址，`arrSize`：数组长度
- `k`：要找的元素个数，`x`：目标值
- 返回值：用 `malloc` 申请的数组，按升序存放这 `k` 个数
- `*returnSize`：必须设置为返回数组的长度（即 `k`）

### 自定义输入格式

```
[1,2,3,4,5]
4
3
```

第 1 行是数组 `arr`，第 2 行是 `k`，第 3 行是 `x`。
