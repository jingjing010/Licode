# 297. 二叉树的序列化与反序列化 —— 小白详细题解

> 一句话题解：**遍历时把空孩子也写下来**（比如写成 `#`），这样字符串就唯一确定了一棵树；反序列化时按**完全相同的顺序**读回来即可。

---

## 📖 第一步：先读懂题目

你要写两个函数：

- `serialize`：树 → 字符串；
- `deserialize`：字符串 → 树。

要求：`deserialize(serialize(树))` 得到的树和原来**一模一样**（形状和值都相同）。字符串长什么样**由你决定**，判题只看还原出来的树。

```
    1
   / \
  2   3
     / \
    4   5
```

**为什么只记录值不够？** 看这两棵树：

```
  1          1
 /            \
2              2
```

它们的前序遍历都是 `1, 2`，无法区分。但如果把空孩子也写出来（用 `#`）：

| 树 | 前序遍历 + 空标记 |
|---|---|
| 左边 | `1,2,#,#,#,` |
| 右边 | `1,#,2,#,#,` |

就不一样了。可以证明：**前序遍历 + 空结点标记**能唯一确定一棵二叉树。

**几个需要注意的细节：**

1. 树可以是空的，`serialize(NULL)` 也要返回一个合法字符串，`deserialize` 要能还原成 `NULL`。
2. 值可能是负数，比如 `-1000`，读数字时要处理负号。
3. 结点最多 10⁴ 个，链状树的递归深度可达 10⁴。
4. 判题程序会在 `deserialize` 之前**销毁原树**，所以不能"偷懒"只在字符串里存指针。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用 `sprintf` 往字符串末尾追加

`sprintf(buf + len, "%d,", x)` 会把 `x` 和一个逗号写到 `buf` 的第 `len` 个位置开始处，并自动补 `'\0'`，**返回写入的字符数**。所以

```c
len += sprintf(buf + len, "%d,", x);
```

就是"在末尾追加并更新长度"。

### 2. 缓冲区要开多大

最多 10⁴ 个结点，每个值最多占 6 个字符（`-1000,`）；空标记 `#,` 占 2 个字符，个数是"结点数 + 1"。总长度不超过 `6 × 10⁴ + 2 × 10001 ≈ 8 × 10⁴`，开 `100000` 字节足够。

### 3. 用 `strtol` 读数字，并让指针自动后移

```c
char* p = "-12,#,";
char* end;
long v = strtol(p, &end, 10);   // v = -12，end 指向 ','
```

`strtol` 能处理负号，并把"数字后面那个字符的位置"写进第二个参数。

### 4. `char**`：让递归的每一层共享"读到哪了"

反序列化时，所有递归层要共用同一个"当前读取位置"。传 `char* p` 只会传副本；要传它的地址 `char** p`，里面用 `*p` 读写它。`**p` 就是当前位置的字符。

---

## 💡 第三步：思路一 —— 前序遍历（DFS）+ 空标记

### 思路

**序列化**：前序遍历（根 → 左 → 右）。遇到空结点写 `#,`，否则写 `值,`。

**反序列化**：按同样的前序顺序读：

1. 当前字符是 `#`：这是一个空结点，跳过 `#,`，返回 `NULL`。
2. 否则读出一个数，创建结点；然后**递归**读出它的左子树、右子树。

因为写和读的顺序完全一致，读到的每一项都正好对应写的那一项。

### 手动模拟（示例 1）

序列化结果：`1,2,#,#,3,4,#,#,5,#,#,`

| 读到的项 | 动作 | 正在构建 |
|---|---|---|
| 1 | 建结点 1，去读它的左子树 | 1 |
| 2 | 建结点 2，去读它的左子树 | 1 的左 |
| # | 2 的左为空 | |
| # | 2 的右为空，2 完成 | |
| 3 | 建结点 3，去读它的左子树 | 1 的右 |
| 4 | 建结点 4 | 3 的左 |
| #, # | 4 的左右为空 | |
| 5 | 建结点 5 | 3 的右 |
| #, # | 5 的左右为空，全部完成 | |

### 代码

```c
// 前序遍历，把结果追加到 buf，*len 是当前长度
void ser(struct TreeNode* node, char* buf, int* len) {
    if (node == NULL) {
        *len += sprintf(buf + *len, "#,");            // 空结点写 #
        return;
    }
    *len += sprintf(buf + *len, "%d,", node->val);   // 根
    ser(node->left, buf, len);                        // 左
    ser(node->right, buf, len);                       // 右
}

char* serialize(struct TreeNode* root) {
    char* buf = (char*)malloc(100000);                // 最长约 8 万个字符，见上文估算
    int len = 0;
    buf[0] = '\0';
    ser(root, buf, &len);
    return buf;
}

// *p 指向当前要读的位置；读完一棵子树后，*p 停在下一项的开头
struct TreeNode* des(char** p) {
    if (**p == '#') {                                 // 空结点
        *p += 2;                                      // 跳过 "#,"
        return NULL;
    }
    struct TreeNode* node = (struct TreeNode*)malloc(sizeof(struct TreeNode));
    node->val = (int)strtol(*p, p, 10);               // 读数字，*p 移到逗号处
    (*p)++;                                           // 跳过逗号
    node->left = des(p);                              // 按前序：先左
    node->right = des(p);                             // 再右
    return node;
}

struct TreeNode* deserialize(char* data) {
    char* p = data;
    return des(&p);                                   // 传 p 的地址，所有递归层共享
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两个方向都是每个结点（含空标记）处理一次。
- **空间复杂度 O(n)**：字符串本身 O(n)，递归栈 O(h)。

## 🚀 第四步：思路二 —— 层序遍历（BFS），和力扣的格式一样

### 思路

力扣自己用的 `[1,2,3,null,null,4,5]` 就是层序 + 空标记。我们也可以这样做：

**序列化**：用队列做层序遍历，**空结点也入队**。出队时：空结点写 `#,`；非空结点写 `值,`，并把它的左右孩子（可能为空）入队。

**反序列化**：

1. 先把字符串切成一个个"项"，存进数组 `nodes`：`#` 存 `NULL`，数字就新建一个结点。
2. 第 0 项是根。用一个指针 `child` 从 1 开始，按顺序遍历 `nodes`：每遇到一个**非空**结点，就把 `nodes[child]`、`nodes[child+1]` 分别作为它的左、右孩子，`child += 2`。

这和本 OJ 读入树的方法完全一样。因为序列化时每个非空结点后面都恰好有两个孩子项，`child` 不会越界。

### 手动模拟（示例 1）

序列化结果：`1,2,3,#,#,4,5,#,#,#,#,`

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7~10 |
|---|---|---|---|---|---|---|---|---|
| 项 | 1 | 2 | 3 | # | # | 4 | 5 | # |

| 处理结点 | 左孩子 = nodes[child] | 右孩子 = nodes[child+1] | child 之后 |
|---|---|---|---|
| 1（下标 0） | 2 | 3 | 3 |
| 2（下标 1） | # | # | 5 |
| 3（下标 2） | 4 | 5 | 7 |
| 4（下标 5） | # | # | 9 |
| 5（下标 6） | # | # | 11 |

### 代码

```c
char* serialize(struct TreeNode* root) {
    char* buf = (char*)malloc(100000);
    int len = 0;
    buf[0] = '\0';
    // 空结点也入队：最多 n 个结点 + (n + 1) 个空，开 20001 足够
    struct TreeNode** q = (struct TreeNode**)malloc(sizeof(struct TreeNode*) * 20001);
    int head = 0, tail = 0;
    q[tail++] = root;
    while (head < tail) {
        struct TreeNode* t = q[head++];
        if (t == NULL) {
            len += sprintf(buf + len, "#,");          // 空结点
            continue;
        }
        len += sprintf(buf + len, "%d,", t->val);
        q[tail++] = t->left;                          // 孩子不管空不空都入队
        q[tail++] = t->right;
    }
    free(q);
    return buf;
}

struct TreeNode* deserialize(char* data) {
    if (data[0] == '#') return NULL;                  // 空树
    struct TreeNode** nodes = (struct TreeNode**)malloc(sizeof(struct TreeNode*) * 20001);
    int n = 0;
    char* p = data;
    while (*p != '\0') {                              // 1. 切分成一项一项
        if (*p == '#') {
            nodes[n++] = NULL;
            p += 2;                                   // 跳过 "#,"
        } else {
            struct TreeNode* t = (struct TreeNode*)malloc(sizeof(struct TreeNode));
            t->val = (int)strtol(p, &p, 10);          // 读数字，p 移到逗号
            t->left = NULL;
            t->right = NULL;
            nodes[n++] = t;
            p++;                                      // 跳过逗号
        }
    }
    int child = 1;                                    // 2. 按层序连接孩子
    for (int i = 0; i < n; i++) {
        if (nodes[i] == NULL) continue;
        nodes[i]->left = nodes[child++];
        nodes[i]->right = nodes[child++];
    }
    struct TreeNode* root = nodes[0];
    free(nodes);                                      // 只释放指针数组，结点还要用
    return root;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(n)**。
- 好处：不用递归，链状树再深也不会栈溢出。

## ⚠️ 第五步：小白常见错误

1. **不记录空结点**：只写值的话 `[1,2]` 和 `[1,null,2]` 序列化结果相同，必然有一个还原错。
2. **数字之间不加分隔符**：`1,2` 写成 `12`，读回来就分不清是 12 还是 1 和 2。
3. **用 `*p - '0'` 读数字**：只能读一位数，而且不能处理负号；用 `strtol` 最省心。
4. **反序列化时按值传指针**：

   ```c
   struct TreeNode* des(char* p) { ... node->left = des(p); ... }   // ❌
   ```

   左子树读完后，外层的 `p` 并没有前进，右子树会从错误的位置开始读。必须传 `char**`。
5. **缓冲区开太小 / 返回局部数组**：`char buf[100];` 既不够长，函数返回后也会失效；要 `malloc` 足够大的空间。
6. **在字符串里存指针地址**：例如把 `root` 的地址打印成字符串再读回来。判题会在反序列化前销毁原树，这样做会读到被释放的内存。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 前序 DFS + 空标记 | O(n) | O(n) | ⭐⭐ | 推荐，代码最短 |
| 层序 BFS + 空标记 | O(n) | O(n) | ⭐⭐⭐ | 与力扣格式一致，无递归 |
