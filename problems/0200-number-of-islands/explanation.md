# 200. 岛屿数量 —— 小白详细题解

> 这是「网格搜索」的入门题。学会它，你就掌握了 DFS / BFS 在二维数组上的基本套路。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一张地图，`'1'` 是陆地，`'0'` 是水。**上下左右**连在一起的陆地算同一座岛（斜着挨着**不算**）。问地图上一共有几座岛？

拿示例 2 来说（为了好看，用 `■` 表示陆地，`·` 表示水）：

| 行\列 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 0 | ■A | ■A | · | · | · |
| 1 | ■A | ■A | · | · | · |
| 2 | · | · | ■B | · | · |
| 3 | · | · | · | ■C | ■C |

左上角 4 块连在一起是岛 A；中间 1 块是岛 B；右下角 2 块是岛 C。岛 B 和岛 C 只是**斜着**相邻，不算连通，所以答案是 `3`。

**几个需要注意的细节：**

1. 网格里存的是**字符** `'1'` / `'0'`，不是整数 `1` / `0`。写成 `grid[i][j] == 1` 永远不成立！
2. 只看上下左右 4 个方向。
3. 网格外面全是水，所以走到边界外就停下。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `char** grid` 是什么？

```c
int numIslands(char** grid, int gridSize, int* gridColSize)
```

| 部分 | 含义 |
|---|---|
| `char** grid` | 「指向 `char*` 的指针」，可以理解为一个数组，里面每个元素是一行（一个 `char` 数组） |
| `grid[i][j]` | 第 `i` 行第 `j` 列的字符 |
| `gridSize` | 行数 |
| `gridColSize` | 一个数组，`gridColSize[i]` 是第 `i` 行的列数。本题每行一样长，用 `gridColSize[0]` 即可 |

### 2. 递归函数

递归就是**函数自己调用自己**。写递归一定要先写「什么时候停下」（递归出口），否则会无限调用直到栈溢出：

```c
void dfs(int x) {
    if (停止条件) return;   // ❌ 示意：先写出口
    dfs(x + 1);           //    再写往下走的部分
}
```

### 3. 为什么要先判断下标再访问？

```c
if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] != '1') return;
```

`||` 有「短路」特性：只要前面某个条件为真，后面的就**不再计算**。所以越界时根本不会去读 `grid[r][c]`，避免了数组越界。顺序不能反！

---

## 💡 第三步：思路一 —— DFS「淹没」整座岛

### 思路

1. 从左到右、从上到下扫描每个格子。
2. 遇到一个 `'1'`：说明发现了一座**新岛**，计数器 `+1`。
3. 然后从这个格子出发，把这座岛上**所有**陆地都改成 `'0'`（「淹掉」），这样以后扫描到它们时就不会重复计数。
4. 「淹掉一座岛」用递归：淹掉当前格，再去淹它上下左右的格子。

### 手动模拟（示例 2）

| 扫描到 | 是 `'1'` 吗？ | 操作 | 岛屿数 |
|---|---|---|---|
| (0,0) | 是 | 计数，淹掉 (0,0)(0,1)(1,0)(1,1) | 1 |
| (0,1)~(2,1) | 都已经是 `'0'` | 跳过 | 1 |
| (2,2) | 是 | 计数，淹掉 (2,2) | 2 |
| (3,3) | 是 | 计数，淹掉 (3,3)(3,4) | 3 |
| 其余 | 否 | 跳过 | 3 |

### 代码

```c
// 把 (r, c) 所在的整座岛淹掉（陆地改成水）
void dfs(char** grid, int m, int n, int r, int c) {
    // 递归出口：越界，或者这一格不是陆地，就什么也不做
    if (r < 0 || r >= m || c < 0 || c >= n || grid[r][c] != '1') return;

    grid[r][c] = '0';              // 淹掉当前格，防止被重复访问（否则会无限递归）
    dfs(grid, m, n, r + 1, c);     // 下
    dfs(grid, m, n, r - 1, c);     // 上
    dfs(grid, m, n, r, c + 1);     // 右
    dfs(grid, m, n, r, c - 1);     // 左
}

int numIslands(char** grid, int gridSize, int* gridColSize) {
    int m = gridSize;              // 行数
    int n = gridColSize[0];        // 列数
    int count = 0;

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == '1') {   // 注意是字符 '1'
                count++;               // 发现一座新岛
                dfs(grid, m, n, i, j); // 把整座岛淹掉
            }
        }
    }
    return count;
}
```

### 复杂度分析

- **时间复杂度 O(m·n)**：每个格子最多被淹一次，每次检查 4 个邻居。
- **空间复杂度 O(m·n)**：最坏情况（整张图都是陆地）递归深度可达 m·n。

> 💬 **小白提示**：力扣和本 OJ 的栈空间足够大，90000 层递归没问题。但在单片机等栈很小的环境里，深递归很危险，这时就该用思路二。

## 🚀 第四步：思路二 —— BFS（用队列，不递归）

### 思路

把「递归」换成「自己维护一个队列」：

1. 发现新岛 `(i, j)` 时，先把它淹掉并放进队列。
2. 每次从队头取出一个格子，看它的 4 个邻居：是陆地就淹掉并放进队尾。
3. 队列空了，说明这座岛淹完了。

> ❓ **为什么「入队时」就淹掉，而不是「出队时」？** 如果出队时才淹，同一个格子可能被它的多个邻居重复放进队列，队列会变得很大甚至溢出。

### 代码

```c
int numIslands(char** grid, int gridSize, int* gridColSize) {
    int m = gridSize, n = gridColSize[0];
    int dr[4] = {1, -1, 0, 0};     // 四个方向的行偏移
    int dc[4] = {0, 0, 1, -1};     // 四个方向的列偏移
    // 每个格子最多入队一次，队列长度 m*n 就够；把 (r,c) 编码成一个整数 r*n+c
    int* queue = (int*)malloc(sizeof(int) * m * n);
    int count = 0;

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] != '1') continue;
            count++;                       // 发现新岛
            int head = 0, tail = 0;        // 队列为空：head == tail
            grid[i][j] = '0';              // 入队时就淹掉
            queue[tail++] = i * n + j;
            while (head < tail) {
                int cur = queue[head++];   // 出队
                int r = cur / n, c = cur % n;
                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d], nc = c + dc[d];
                    if (nr >= 0 && nr < m && nc >= 0 && nc < n && grid[nr][nc] == '1') {
                        grid[nr][nc] = '0';
                        queue[tail++] = nr * n + nc;   // 入队
                    }
                }
            }
        }
    }
    free(queue);
    return count;
}
```

**代码中几个可能看不懂的地方：**

- `dr` / `dc` 方向数组：把「上下左右」写成循环，避免写 4 段几乎一样的代码。
- `r * n + c`：把二维坐标压成一个整数，取回时 `r = cur / n`、`c = cur % n`。
- 队列每次处理一座岛都从 0 开始复用，因为所有格子总共只入队一次，`m*n` 的空间足够。

### 复杂度分析

- **时间复杂度 O(m·n)**。
- **空间复杂度 O(m·n)**：队列。但它在堆上，不会栈溢出。

---

## ⚠️ 第五步：小白常见错误

1. **把字符当整数比较**：`if (grid[i][j] == 1)` 永远为假，答案恒为 0。要写 `'1'`。
2. **忘记把访问过的格子改成 `'0'`**：DFS 会在两个相邻陆地之间来回递归，最终栈溢出（Runtime Error）。
3. **越界判断写在访问之后**：`if (grid[r][c] != '1' || r < 0 ...)` 先读了 `grid[-1][...]`，直接崩溃。下标判断必须写在最前面。
4. **把斜对角也当成相邻**：用了 8 个方向，示例 2 会得到 2 而不是 3。
5. **行列搞反**：`m` 是行数（`gridSize`），`n` 是列数（`gridColSize[0]`）。非正方形网格搞反就会越界。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| DFS 递归 | O(m·n) | O(m·n) 递归栈 | ⭐⭐ | 代码最短，先掌握它 |
| BFS 队列 | O(m·n) | O(m·n) 堆内存 | ⭐⭐⭐ | 不怕栈溢出，嵌入式更常用 |

> 🎯 **学习建议**：先写 DFS，把「淹没」这个想法吃透；再改写成 BFS，体会递归和队列的对应关系。
