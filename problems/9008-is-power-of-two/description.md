嵌入式里大量使用 **环形缓冲区**（ring buffer）来缓存串口、ADC 等外设的数据。如果缓冲区大小 `size` 是 **2 的幂**，那么下标回绕可以用一次按位与 `idx & (size - 1)` 代替又慢又费空间的取模 `idx % size`——很多没有硬件除法器的单片机上，这能省下几十个时钟周期。因此驱动在初始化时通常会先检查：用户传入的缓冲区大小是不是 2 的幂？

给定一个 32 位无符号整数 `x`，如果它是 2 的幂（即存在整数 `k >= 0` 使得 `x = 2^k`），返回 `true`，否则返回 `false`。

### 示例 1

```
输入：x = 64
输出：true
解释：64 = 2^6 = 0b100_0000。
```

### 示例 2

```
输入：x = 0
输出：false
解释：0 不是 2 的幂（大小为 0 的缓冲区也没有意义）。
```

### 示例 3

```
输入：x = 96
输出：false
解释：96 = 0b110_0000，介于 64 和 128 之间，不是 2 的幂。
```

### 提示

- `0 <= x <= 2^32 - 1`
- `1 = 2^0` 也是 2 的幂

### 函数说明

```c
bool is_power_of_two(uint32_t x);
```

- `x`：待检查的 32 位无符号整数
- 返回值：`x` 是 2 的幂返回 `true`，否则返回 `false`

### 自定义输入格式

```
64
```

输入一行，为十进制整数 `x`。输出为 `true` 或 `false`。
