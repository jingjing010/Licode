# 独一无二的出现次数

判断数组中每个不同数值的出现次数是否互不相同。1 ≤ n ≤ 1000，元素在−1000到1000之间。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool uniqueOccurrences(int* arr,int arrSize);
```

## 示例 1

输入：
```text
[1,2,2,1,1,3]
```
输出：
```text
true
```

## 示例 2

输入：
```text
[1,2]
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
