# 重复的子字符串：题解

## 📖 先读懂题目

前缀函数nxt[i]记录s[0..i]最长相同真前缀与真后缀的长度。若整串最长边界长度p>0，候选周期为n−p；只有n能整除n−p，才可由该周期重复组成。失配时沿nxt回退，而不从头比较。

### 示例1

输入：
```text
"abab"
```
输出：
```text
true
```

### 示例2

输入：
```text
"aba"
```
输出：
```text
false
```

### 示例3

输入：
```text
"abcabcabcabc"
```
输出：
```text
true
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 如果 s 由长度为 len 的子串重复构成，那么这个子串一定是 s 的前缀，而且 len 一定能整除 n，并且 len <= n / 2。
2. 枚举每个可能的 len，检查是否对所有 i >= len 都有 s[i] == s[i - len]。
3. 更巧妙的做法：把 s 和自己拼接成 s + s，去掉首尾各一个字符后，如果还能在里面找到 s，就说明 s 是重复构成的（可以用 KMP 的 next 数组直接判断）。

## 可直接提交的 C 代码

```c
bool repeatedSubstringPattern(char* s) {
    int n = (int)strlen(s);
    int* nxt = (int*)malloc(sizeof(int) * n);
    nxt[0] = 0;
    for (int i = 1, j = 0; i < n; i++) {
        while (j > 0 && s[i] != s[j]) j = nxt[j - 1];
        if (s[i] == s[j]) j++;
        nxt[i] = j;
    }
    int p = nxt[n - 1];
    free(nxt);
    return p > 0 && n % (n - p) == 0;
}
```

## 📊 复杂度

时间 O(n)，空间 O(n)。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。
