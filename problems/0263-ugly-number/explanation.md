# 263. 丑数 —— 小白详细题解

> 一道练习"质因数分解"思想的简单题。核心只有一句话：**把 2、3、5 除干净，看剩下的是不是 1**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一个**正整数**，如果把它分解质因数后，只出现 2、3、5 这三种质数，它就是"丑数"。

| n | 分解质因数 | 丑数？ |
|---|---|---|
| 6 | 2 × 3 | ✅ |
| 1 | （没有质因数） | ✅ 约定 1 是丑数 |
| 14 | 2 × **7** | ❌ 含有 7 |
| 30 | 2 × 3 × 5 | ✅ |
| 0 | — | ❌ 不是正整数 |
| -6 | — | ❌ 不是正整数 |

**几个需要注意的细节：**

1. 必须是**正**整数：0 和负数都返回 `false`。
2. 1 是丑数（它没有任何质因数，自然也没有 2、3、5 以外的质因数）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用 `%` 判断整除

`n % 2 == 0` 表示 n 能被 2 整除。

### 2. `while` 反复除

```c
while (n % 2 == 0) {
    n /= 2;          // 把因子 2 一个一个除掉
}
```

例如 `n = 24`：24 → 12 → 6 → 3，3 不能再被 2 整除，停下。

### 3. 小心 `n = 0` 的死循环

`0 % 2 == 0` 永远成立，`0 / 2` 还是 0。如果不提前排除 0，`while (n % 2 == 0)` **永远不会结束**——判题结果是超时。

---

## 💡 第三步：思路一 —— 依次除尽 2、3、5

### 思路

1. `n <= 0`：直接返回 `false`。
2. 把 `n` 中所有因子 2 除掉，再除掉所有 3，再除掉所有 5。
3. 如果剩下 1，说明只含 2、3、5，是丑数；否则还有别的质因数。

### 手动模拟

| n | 除尽 2 | 除尽 3 | 除尽 5 | 剩下 | 结果 |
|---|---|---|---|---|---|
| 6 | 3 | 1 | 1 | 1 | ✅ |
| 14 | 7 | 7 | 7 | 7 | ❌ |
| 300 | 75 | 25 | 1 | 1 | ✅ |

### 代码

```c
bool isUgly(int n) {
    if (n <= 0) {                    // 丑数必须是正整数；同时避免 n = 0 时死循环
        return false;
    }
    while (n % 2 == 0) {             // 除尽所有因子 2
        n /= 2;
    }
    while (n % 3 == 0) {             // 除尽所有因子 3
        n /= 3;
    }
    while (n % 5 == 0) {             // 除尽所有因子 5
        n /= 5;
    }
    return n == 1;                   // 只剩 1，说明没有其他质因数
}
```

### 复杂度分析

- **时间复杂度 O(log n)**：每次除法至少让 n 变成一半，最多除约 31 次。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 用数组让代码更简洁

### 思路

三个 `while` 结构完全一样，可以把 2、3、5 放进数组，用循环处理。以后如果题目改成"只含质因数 2、3、5、7"，只需要改数组。

### 代码

```c
bool isUgly(int n) {
    if (n <= 0) {
        return false;
    }
    int factors[3] = {2, 3, 5};      // 允许的质因数
    for (int i = 0; i < 3; i++) {
        while (n % factors[i] == 0) {  // 把当前因子除干净
            n /= factors[i];
        }
    }
    return n == 1;
}
```

- **时间复杂度 O(log n)**，**空间复杂度 O(1)**。本质和思路一相同，只是写法更通用。

---

## ⚠️ 第五步：小白常见错误

1. **没有判断 `n <= 0`** → `n = 0` 时死循环（超时）。负数（如 `-6` 会被除成 `-1`）最后碰巧不等于 1，但依赖这种"碰巧"不好，一开始就排除最清楚。
2. **用 `if` 代替 `while`** → `if (n % 2 == 0) n /= 2;` 只除一次，`n = 8` 会剩下 4，误判为 `false`。
3. **认为 1 不是丑数** → 题目示例明确 1 是丑数。
4. **试图判断"有没有 7、11、13……这些因子"** → 质数有无穷多个，正确做法是反过来：除尽 2、3、5 后看剩下什么。
5. **写成 `return n % 2 == 0 || n % 3 == 0 || n % 5 == 0;`** → 这只说明"含有 2、3、5 中的某个因子"，`14 = 2 × 7` 会被误判为丑数，`1` 反而被判为不是。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 建议 |
|---|---|---|---|
| 依次除尽 2、3、5 | O(log n) | O(1) | 最直接 |
| 因子数组循环 | O(log n) | O(1) | 写法更通用 |
