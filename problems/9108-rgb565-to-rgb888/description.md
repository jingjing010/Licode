# RGB565 展开为 RGB888

pixel为0..65535，按RGB565解释，返回[R,G,B]。5位扩展用(v<<3)|(v>>2)，6位扩展用(v<<2)|(v>>4)。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* expandRgb565(int pixel,int* returnSize);
```

## 示例 1

输入：
```text
63488
```
输出：
```text
[255,0,0]
```

## 示例 2

输入：
```text
2016
```
输出：
```text
[0,255,0]
```

## 自定义输入格式

按顺序每行一个参数：pixel。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
