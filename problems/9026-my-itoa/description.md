在单片机上，`printf`/`sprintf` 往往要占用好几 KB 的 Flash 和几百字节的栈，对一颗只有 16KB Flash 的 MCU 来说太奢侈了。所以很多固件会自己实现一个小巧的 `itoa`，用来把整数转换成字符串，再送到串口、LCD 或数码管上显示——比如打印十进制的温度、十六进制的寄存器值、二进制的 GPIO 状态。

请实现函数 `my_itoa`：把 `value` 转换成 `base` 进制的字符串，写入调用者提供的缓冲区 `buf`（以 `'\0'` 结尾），并**返回 `buf`**。规则与常见 C 库的 `itoa` 一致：

- `base` 的取值范围是 `2 ~ 16`，大于 9 的数字用**大写字母** `A~F` 表示
- 只有 `base == 10` 时才把 `value` 当作有符号数：负数前面加 `'-'`
- `base != 10` 时，把 `value` 当作 **32 位无符号数**（即它的补码）转换，例如 `-1` 的十六进制是 `"FFFFFFFF"`
- 不输出前导 0；`value == 0` 时输出 `"0"`

### 示例 1

```
输入：value = 255, base = 16
输出："FF"
```

### 示例 2

```
输入：value = -1234, base = 10
输出："-1234"
```

### 示例 3

```
输入：value = 10, base = 2
输出："1010"
```

### 提示

- `-2147483648 <= value <= 2147483647`
- `2 <= base <= 16`
- `buf` 至少有 34 个字节（32 位二进制数字 + 符号 + `'\0'`，足够任何情况使用）
- 不要使用 `sprintf`、`itoa` 等库函数

### 函数说明

```c
char* my_itoa(int32_t value, char* buf, int base);
```

- `value`：要转换的整数
- `buf`：输出缓冲区
- `base`：进制
- 返回值：`buf`（方便写成 `uart_puts(my_itoa(x, tmp, 10))`）

### 自定义输入格式

```
255
16
```

第 1 行是 `value`，第 2 行是 `base`。输出为带双引号的结果字符串。
