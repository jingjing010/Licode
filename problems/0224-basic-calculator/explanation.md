# 基本计算器：题解

## 📖 先读懂题目

逐位累积当前数字，用符号记录加减。遇到左括号把外层结果和符号压栈，重新计算括号内表达式；遇到右括号把内层结果按外层符号合并。一元负号与空格也要处理。

### 示例1

输入：
```text
"1 + 1"
```
输出：
```text
2
```

### 示例2

输入：
```text
" 2-1 + 2 "
```
输出：
```text
3
```

### 示例3

输入：
```text
"(1+(4+5+2)-3)+(6+8)"
```
输出：
```text
23
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 只有加减法和括号。先想想没有括号时怎么算：从左到右，记住当前符号 sign，读到一个数就 res += sign * num。
2. 遇到 '(' 时，括号里是一个「子问题」。把括号外已经算好的 res 和括号前的符号先存起来（压栈），再从 0 开始算括号里的。
3. 遇到 ')' 时，括号里的结果 res 算完了：弹出之前保存的 (旧 res, 符号)，res = 旧 res + 符号 * res。注意 '-' 可以是一元负号，比如 "-(2+3)"。

## 可直接提交的 C 代码

```c
int calculate(char* s) {
    int n = (int)strlen(s);
    int* ops = (int*)malloc(sizeof(int) * (n + 2));
    int top = 0;
    ops[top++] = 1;
    int sign = 1;
    long long ret = 0;
    int i = 0;
    while (i < n) {
        char c = s[i];
        if (c == ' ') {
            i++;
        } else if (c == '+') {
            sign = ops[top - 1];
            i++;
        } else if (c == '-') {
            sign = -ops[top - 1];
            i++;
        } else if (c == '(') {
            ops[top++] = sign;
            i++;
        } else if (c == ')') {
            top--;
            i++;
        } else {
            long long num = 0;
            while (i < n && s[i] >= '0' && s[i] <= '9') {
                num = num * 10 + (s[i] - '0');
                i++;
            }
            ret += sign * num;
        }
    }
    free(ops);
    return (int)ret;
}
```

## 📊 复杂度

时间 O(n)，空间 O(n)。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。
