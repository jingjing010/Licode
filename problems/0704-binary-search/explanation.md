# 704. 二分查找 —— 小白详细题解

> 二分查找"思路很简单，细节是魔鬼"。这道题是所有二分题的地基：我们把**区间定义、循环条件、边界更新、mid 溢出**四件事一次讲透。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一排**从小到大排好、没有重复**的数，问 `target` 在第几个位置。不在就返回 `-1`。要求 O(log n)。

拿示例 1 `nums = [-1,0,3,5,9,12], target = 9` 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 数值 | -1 | 0 | 3 | 5 | **9** | 12 |

9 在下标 4，答案 4。示例 2 找 2，数组里没有，答案 -1。

**几个需要注意的细节：**

1. 返回的是**下标**，不是数值。
2. 找不到时返回 `-1`，不是插入位置（那是 35 题）。
3. 数组可能只有 1 个元素。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 整数除法向下取整

```c
int mid = (2 + 5) / 2;    // 3，不是 3.5
```

### 2. mid 溢出问题

```c
int mid = (lo + hi) / 2;         // lo + hi 可能超过 INT_MAX（约 21 亿）
int mid2 = lo + (hi - lo) / 2;   // 推荐：hi - lo 不会溢出
```

本题下标最大 9999，不会溢出。但如果数组有 15 亿个元素（或者像 278 题那样直接在数值上二分），`lo + hi` 就会变成负数，程序崩溃或死循环。**从第一题开始就养成写 `lo + (hi - lo) / 2` 的习惯**。

---

## 💡 第三步：思路一 —— 从头到尾找（O(n)）

### 代码

```c
int search(int* nums, int numsSize, int target) {
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] == target) {
            return i;            // 找到了
        }
    }
    return -1;                   // 找遍了都没有
}
```

### 复杂度分析

- **时间复杂度 O(n)**：本题 n ≤ 10⁴ 能过，但没有用到"有序"这个条件，不满足题目 O(log n) 的要求。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 二分查找（闭区间写法）

### 思路

数组有序，看中间的 `nums[mid]`：

- `nums[mid] == target`：找到了，返回 mid。
- `nums[mid] < target`：mid 和它**左边的所有数**都比 target 小，全部排除：`lo = mid + 1`。
- `nums[mid] > target`：mid 和它**右边的所有数**都比 target 大，全部排除：`hi = mid - 1`。

每次排除一半，10⁴ 个数最多比较 14 次。

### 二分的四个关键细节（重点！）

| 细节 | 闭区间写法 `[lo, hi]` | 原因 |
|---|---|---|
| 区间含义 | `lo` 和 `hi` 都是**可能的答案** | 定义决定了后面所有写法 |
| 初始化 | `lo = 0, hi = numsSize - 1` | 最后一个元素下标是 `numsSize - 1` |
| 循环条件 | `while (lo <= hi)` | `lo == hi` 时区间里还有 1 个数没检查 |
| 更新 | `lo = mid + 1` / `hi = mid - 1` | mid 已经检查过，不在答案里了 |
| 中点 | `mid = lo + (hi - lo) / 2` | 防溢出 |

> 💡 记住：**区间定义是"根"**。先想清楚 `lo`、`hi` 是"能取到"还是"取不到"，循环条件和更新方式就自然确定了。

### 手动模拟（`nums = [-1,0,3,5,9,12], target = 9`）

| 轮次 | lo | hi | mid | nums[mid] | 比较 | 操作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 5 | 2 | 3 | 3 < 9 | lo = 3 |
| 2 | 3 | 5 | 4 | 9 | 相等 | 返回 4 ✅ |

### 手动模拟（`target = 2`，找不到）

| 轮次 | lo | hi | mid | nums[mid] | 比较 | 操作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 5 | 2 | 3 | 3 > 2 | hi = 1 |
| 2 | 0 | 1 | 0 | -1 | -1 < 2 | lo = 1 |
| 3 | 1 | 1 | 1 | 0 | 0 < 2 | lo = 2 |
| 结束 | 2 | 1 | | | lo > hi，区间为空 | 返回 -1 ✅ |

### 代码

```c
int search(int* nums, int numsSize, int target) {
    int lo = 0;                  // 闭区间 [lo, hi]：两端都可能是答案
    int hi = numsSize - 1;

    while (lo <= hi) {           // 区间非空（lo == hi 时还有 1 个数）
        int mid = lo + (hi - lo) / 2;   // 防溢出写法
        if (nums[mid] == target) {
            return mid;          // 找到了
        } else if (nums[mid] < target) {
            lo = mid + 1;        // mid 太小，排除 mid 及左边
        } else {
            hi = mid - 1;        // mid 太大，排除 mid 及右边
        }
    }
    return -1;                   // 区间空了还没找到
}
```

### 复杂度分析

- **时间复杂度 O(log n)**，**空间复杂度 O(1)**。

## 🔁 补充：左闭右开写法 `[lo, hi)`

另一种同样常用的写法，`hi` 指向**取不到**的位置：

| 细节 | 左闭右开写法 `[lo, hi)` |
|---|---|
| 初始化 | `lo = 0, hi = numsSize`（`numsSize` 本身取不到） |
| 循环条件 | `while (lo < hi)`（`lo == hi` 时区间为空） |
| 更新 | `lo = mid + 1` / `hi = mid`（hi 本来就取不到，设成 mid 正好排除 mid） |

```c
int search(int* nums, int numsSize, int target) {
    int lo = 0, hi = numsSize;   // 左闭右开 [lo, hi)
    while (lo < hi) {            // 区间非空
        int mid = lo + (hi - lo) / 2;
        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            lo = mid + 1;        // 排除 mid 及左边
        } else {
            hi = mid;            // 排除 mid 及右边（hi 取不到）
        }
    }
    return -1;
}
```

两种写法都对，**选一种练熟，不要混用**。

---

## ⚠️ 第五步：小白常见错误

1. **闭区间写成 `while (lo < hi)`** → `lo == hi` 时最后一个数没检查。比如 `nums = [5], target = 5`，循环一次都不执行，错误返回 -1。
2. **左闭右开写成 `hi = mid - 1`** → 把 `mid - 1` 也排除了，可能错过答案。
3. **闭区间写成 `hi = mid`** → `lo == hi` 且 `nums[mid] > target` 时 `hi` 不变，**死循环**。
4. **`hi = numsSize` 却用 `while (lo <= hi)`** → `mid` 可能等于 `numsSize`，越界访问 `nums[numsSize]`。
5. **`mid = (lo + hi) / 2`** → 本题不会溢出，但在下标或数值很大的题（如 278）会出错，养成好习惯。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 顺序查找 | O(n) | O(1) | ⭐ | 没有利用有序 |
| 二分（闭区间） | O(log n) | O(1) | ⭐⭐ | 最经典的写法 |
| 二分（左闭右开） | O(log n) | O(1) | ⭐⭐ | 找边界类题目更常用 |
