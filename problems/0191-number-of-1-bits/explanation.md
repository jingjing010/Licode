# 191. 位1的个数 —— 小白详细题解

> "数一数一个整数的二进制里有几个 1"，学名叫**汉明重量**（popcount）。这道题有三种层层递进的写法：**逐位数 → `n & (n - 1)` 消 1 → 分组并行求和**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把 `n` 写成 32 位二进制，数一数里面有几个 `1`。

拿示例 1（`n = 11`）来说：

| 位号 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|
| 11 的二进制 | **1** | 0 | **1** | **1** |

一共 3 个 1，答案是 `3`。

**几个需要注意的细节：**

1. 答案范围是 `0 ~ 32`：`n = 0` 时是 0，`n = 4294967295`（32 个 1）时是 32。
2. **最高位（第 31 位）也要算**。示例 3 的 `n = 4294967293` 超过了 `int` 的范围，所以参数是无符号的 `uint32_t`。
3. 答案只和"有几个 1"有关，和 1 在哪儿无关。

---

## 🧰 第二步：需要的 C 语言知识

### 1. 读取第 i 位：`(n >> i) & 1`

把第 `i` 位右移到最低位，再和 1 相与，得到 0 或 1。

### 2. 为什么参数是无符号数？

- **无符号数**右移，左边补 0，移够 32 次一定变成 0；
- **有符号负数**右移（算术右移），左边补 1。如果你把 `n` 存进 `int` 再写 `while (x) { ...; x >>= 1; }`，负数永远变不成 0，**死循环**。

### 3. ⭐ `n & (n - 1)`：消掉最右边的 1

`n - 1` 会把 `n` 最右边的 1 变成 0，它右边的 0 全变成 1；更左边的位不变。两者相与，右边这一段就全变成 0 了：

```
n           = 1011 0100
n - 1       = 1011 0011     ← 最右边的 1（第 2 位）借位变 0，它右边的 00 变成 11
n & (n - 1) = 1011 0000     ← 最右边的 1 被消掉了，其它 1 原样保留
```

---

## 💡 第三步：思路一 —— 逐位检查

### 思路

从第 0 位到第 31 位，每一位取出来看看，是 1 就计数。

### 手动模拟（示例 1：`n = 11 = 1011`）

| i | (n >> i) & 1 | count |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 1 | 2 |
| 2 | 0 | 2 |
| 3 | 1 | 3 |
| 4 ~ 31 | 0 | **3** |

### 代码

```c
int hammingWeight(uint32_t n) {
    int count = 0;
    for (int i = 0; i < 32; i++) {   // 32 位一位都不漏
        if ((n >> i) & 1) {          // 第 i 位是 1
            count++;
        }
    }
    return count;
}
```

### 复杂度分析

- **时间复杂度 O(32)**：不管有几个 1，都循环 32 次。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— `n & (n - 1)` 逐个消 1

### 思路

每做一次 `n &= n - 1`，`n` 就少一个 1。一直做到 `n == 0`，做了几次就有几个 1。循环次数 = 1 的个数，**1 越少越快**。

### 手动模拟（示例 1：`n = 11`）

| 第几次 | n | n - 1 | n & (n - 1) | count |
|---|---|---|---|---|
| 1 | 1011 | 1010 | 1010 | 1 |
| 2 | 1010 | 1001 | 1000 | 2 |
| 3 | 1000 | 0111 | 0000 | **3** |

### 代码

```c
int hammingWeight(uint32_t n) {
    int count = 0;
    while (n != 0) {     // 还有 1 没消掉
        n &= n - 1;      // 消掉最右边的那个 1
        count++;         // 消一个，计一次
    }
    return count;
}
```

### 复杂度分析

- **时间复杂度 O(k)**，`k` 是 1 的个数，最多 32 次。
- **空间复杂度 O(1)**。

## 🚀 思路三 —— 分组并行求和（无循环）

### 思路

把 32 位看成 32 个"只有 1 位的小计数器"，然后**两两合并**：

1. 每 2 位一组，算出这 2 位里有几个 1（0~2，2 位放得下）；
2. 每 4 位一组，把相邻两个 2 位计数相加（0~4）；
3. 每 8 位一组，把相邻两个 4 位计数相加（0~8）；
4. 最后把 4 个字节的计数加起来（0~32）。

每一步都是**所有组同时算**，只要固定的几条指令。

- **第 1 步 `n - ((n >> 1) & 0x55555555)`**：一个 2 位组的值是 `v = 2a + b`（`a` 高位、`b` 低位），1 的个数是 `a + b = v - a`。`(n >> 1) & 0x55555555` 正好把每组的高位 `a` 挪到这组的低位上，相减就得到每组的 `a + b`。
- **第 4 步乘以 `0x01010101` 再右移 24**：设 4 个字节是 `A B C D`，乘 `0x01010101` 相当于把 `n`、`n << 8`、`n << 16`、`n << 24` 加起来，最高字节正好是 `A + B + C + D`。

### 手动模拟（示例 1：`n = 11`，只看低 8 位）

| 步骤 | 二进制 | 含义 |
|---|---|---|
| 原始 | `00 00 10 11` | |
| 第 1 步 | `00 00 01 10` | 4 个 2 位组：0、0、1、2 |
| 第 2 步 | `0000 0011` | 2 个 4 位组：0、3 |
| 第 3 步 | `00000011` | 1 个字节：3 |
| 第 4 步 | | 4 个字节求和 = **3** |

### 代码

```c
int hammingWeight(uint32_t n) {
    // 第 1 步：每 2 位一组，组内变成"这 2 位里 1 的个数"
    n = n - ((n >> 1) & 0x55555555u);
    // 第 2 步：每 4 位一组，相邻两个 2 位计数相加
    n = (n & 0x33333333u) + ((n >> 2) & 0x33333333u);
    // 第 3 步：每 8 位一组，相邻两个 4 位计数相加（和最多是 8，4 位放得下，可以先加后与）
    n = (n + (n >> 4)) & 0x0F0F0F0Fu;
    // 第 4 步：4 个字节的计数累加到最高字节，再移下来
    return (int)((n * 0x01010101u) >> 24);
}
```

### 复杂度分析

- **时间复杂度 O(1)**：约 12 条指令，没有循环。
- **空间复杂度 O(1)**。

> 💬 **进阶问题"多次调用怎么优化"**：可以用 256 项的表存好每个字节里 1 的个数，32 位拆成 4 个字节查 4 次表；GCC 还提供了内建函数 `__builtin_popcount(n)`。

## ⚠️ 第五步：小白常见错误

1. **把 `n` 转成 `int` 再右移**：最高位为 1 时是负数，算术右移左边补 1，`while (x)` 永远不结束。
   ```c
   int x = (int)n;
   while (x) { count += x & 1; x >>= 1; }   // ❌ n >= 2^31 时死循环
   ```
2. **循环只到 31**：`for (i = 0; i < 31; i++)` 漏掉了最高位，示例 3 会输出 30。
3. **`n & 1 == 1` 的优先级陷阱**：`==` 比 `&` 优先级高，它会被解析成 `n & (1 == 1)`，碰巧也对；但 `n & 1 == 0` 就变成了 `n & 0`，永远是 0。**位运算一律加括号**。
4. **分治第 2 步少写一个掩码**：写成 `(n + (n >> 2)) & 0x33333333u`，两个 2 位计数相加时会互相"串位"，结果错乱。只有第 3 步能先加后与。
5. **担心乘法溢出**：`n * 0x01010101u` 的高位确实会溢出，但无符号乘法溢出是有定义的（自动对 2³² 取模），我们只要最高字节，不受影响。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐位检查 | O(32) | O(1) | ⭐ | 最容易写对 |
| `n & (n - 1)` 消 1 | O(1 的个数) | O(1) | ⭐⭐ | 面试最爱问 |
| 分组并行求和 | O(1) | O(1) | ⭐⭐⭐ | 无分支、耗时固定 |

- **461. 汉明距离**：两个数有几位不同 = `hammingWeight(x ^ y)`。
- **231. 2 的幂**：2 的幂恰好只有一个 1，即 `n > 0 && (n & (n - 1)) == 0`。
