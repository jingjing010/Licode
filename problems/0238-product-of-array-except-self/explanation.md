# 238. 除自身以外数组的乘积 —— 小白详细题解

> 这道题禁止用除法，逼着我们学会一个非常重要的技巧：**前缀积 / 后缀积**（和"前缀和"是一家人）。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 对每个位置 `i`，把**除了它自己以外**的所有数乘起来，放进 `answer[i]`。

拿示例 1 `nums = [1,2,3,4]` 来说：

| i | 去掉 nums[i] 后剩下的数 | 乘积 answer[i] |
|---|---|---|
| 0 | 2, 3, 4 | 24 |
| 1 | 1, 3, 4 | 12 |
| 2 | 1, 2, 4 | 8 |
| 3 | 1, 2, 3 | 6 |

答案 `[24,12,8,6]`。

**几个需要注意的细节：**

1. **不能用除法**。"先算总乘积再除以 nums[i]"看起来很聪明，但题目禁止，而且遇到 `0` 就会除零崩溃（示例 2 里就有 0）。
2. 数组里可能有**负数和 0**。
3. 要求 **O(n)** 时间。n 最大 10⁵，O(n²) 的两层循环会做约 10¹⁰ 次乘法，必然超时。
4. 题目保证所有前缀积、后缀积都在 32 位 `int` 范围内，所以用 `int` 就够了。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回数组：`malloc` + `*returnSize`

```c
int* ans = (int*)malloc(sizeof(int) * numsSize);   // 在堆上申请，函数结束后依然有效
*returnSize = numsSize;                             // 告诉调用者返回数组有多长
```

不能写 `int ans[100000]; return ans;`——局部数组在函数结束时就失效了。

### 2. 乘法的"单位元"是 1

累加时初始值是 0，累乘时初始值必须是 **1**。如果写成 `int p = 0;`，乘什么都还是 0。

### 3. 倒着遍历数组

```c
for (int i = numsSize - 1; i >= 0; i--) { /* 从最后一个元素往前 */ }
```

注意终点是 `i >= 0`，下标 0 也要处理到。

---

## 💡 第三步：思路一 —— 左右两个辅助数组

### 思路

`answer[i]` = （`i` **左边**所有数的乘积）×（`i` **右边**所有数的乘积）。

- `L[i]`：`nums[0] × nums[1] × ... × nums[i-1]`，最左边 `L[0] = 1`（左边一个数都没有）。
  递推：`L[i] = L[i-1] × nums[i-1]`
- `R[i]`：`nums[i+1] × ... × nums[n-1]`，最右边 `R[n-1] = 1`。
  递推：`R[i] = R[i+1] × nums[i+1]`
- `answer[i] = L[i] × R[i]`

### 手动模拟（示例 1：`nums = [1,2,3,4]`）

| i | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| nums[i] | 1 | 2 | 3 | 4 |
| L[i]（左边乘积） | 1 | 1 | 1×2=2 | 2×3=6 |
| R[i]（右边乘积） | 2×12=24 | 3×4=12 | 4 | 1 |
| answer = L×R | **24** | **12** | **8** | **6** |

### 代码

```c
int* productExceptSelf(int* nums, int numsSize, int* returnSize) {
    int n = numsSize;
    int* L = (int*)malloc(sizeof(int) * n);     // L[i]：i 左边所有数的乘积
    int* R = (int*)malloc(sizeof(int) * n);     // R[i]：i 右边所有数的乘积
    int* ans = (int*)malloc(sizeof(int) * n);
    *returnSize = n;

    // 1. 从左往右算 L
    L[0] = 1;                                   // 下标 0 左边没有数，乘积是 1
    for (int i = 1; i < n; i++) {
        L[i] = L[i - 1] * nums[i - 1];
    }

    // 2. 从右往左算 R
    R[n - 1] = 1;                               // 最后一个右边没有数
    for (int i = n - 2; i >= 0; i--) {
        R[i] = R[i + 1] * nums[i + 1];
    }

    // 3. 左右相乘
    for (int i = 0; i < n; i++) {
        ans[i] = L[i] * R[i];
    }

    free(L);                                    // 辅助数组用完释放
    free(R);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：三次独立的遍历。
- **空间复杂度 O(n)**：`L`、`R` 两个辅助数组（答案数组不算）。

---

## 🚀 第四步：思路二 —— 答案数组当 L，一个变量当 R（O(1) 额外空间）

### 思路

进阶要求 O(1) 额外空间（答案数组不算）。观察思路一：

1. `L` 可以**直接存在 `ans` 里**，不用单独开数组。
2. `R` 是从右往左一个一个算的，每个 `R[i]` 用完就不再需要——那就用**一个变量** `right` 边算边乘到 `ans[i]` 上。

### 手动模拟（示例 1：`nums = [1,2,3,4]`）

第一遍（从左往右）后，`ans = [1, 1, 2, 6]`（就是 L）。

第二遍（从右往左），`right` 初始为 1：

| i | ans[i]（乘之前） | right | ans[i] *= right | right *= nums[i] |
|---|---|---|---|---|
| 3 | 6 | 1 | **6** | 4 |
| 2 | 2 | 4 | **8** | 12 |
| 1 | 1 | 12 | **12** | 24 |
| 0 | 1 | 24 | **24** | 24 |

结果 `[24,12,8,6]` ✅

> ❓ **为什么先乘再更新 `right`？** 处理位置 `i` 时，`right` 必须是 `i` **右边**的乘积，不能包含 `nums[i]` 自己。所以先用旧的 `right`，再把 `nums[i]` 乘进去，留给 `i-1` 用。

### 代码

```c
int* productExceptSelf(int* nums, int numsSize, int* returnSize) {
    int* ans = (int*)malloc(sizeof(int) * numsSize);
    *returnSize = numsSize;

    // 1. 第一遍：ans[i] 先存"左边所有数的乘积"
    ans[0] = 1;
    for (int i = 1; i < numsSize; i++) {
        ans[i] = ans[i - 1] * nums[i - 1];
    }

    // 2. 第二遍：right 记录"右边所有数的乘积"，边走边乘到 ans 上
    int right = 1;
    for (int i = numsSize - 1; i >= 0; i--) {
        ans[i] *= right;          // 左边乘积 × 右边乘积
        right *= nums[i];         // 把 nums[i] 算进去，留给左边的位置用
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两次遍历。
- **空间复杂度 O(1)**：只多用了一个变量 `right`（答案数组不算额外空间）。

---

## ⚠️ 第五步：小白常见错误

1. **用总乘积除以 nums[i]** → 违反题意；数组里有 0 时还会除零崩溃（Runtime Error）。
2. **累乘变量初始化为 0**：`int right = 0;` → 所有答案都变成 0。
3. **第二遍里先 `right *= nums[i]` 再 `ans[i] *= right`** → 把自己也乘进去了，示例 1 会得到 `[24,24,24,24]`。
4. **两层循环暴力求积** → O(n²)，n = 10⁵ 时约 10¹⁰ 次乘法，超时。
5. **倒序循环写成 `for (int i = numsSize - 1; i > 0; i--)`** → 漏掉了下标 0，`ans[0]` 停留在 1。
6. **忘记设置 `*returnSize`** → 调用者以为返回数组长度是 0，输出 `[]`。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 额外空间 | 难度 | 建议 |
|---|---|---|---|---|
| 两层循环暴力 | O(n²) | O(1) | ⭐ | 会超时 |
| 左右辅助数组 | O(n) | O(n) | ⭐⭐ | 先理解"左边积 × 右边积" |
| 答案数组 + 一个变量 | O(n) | O(1) | ⭐⭐ | 进阶要求，面试标准答案 |
