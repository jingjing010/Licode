用户通过按键或者串口命令设置时间后，MCU 需要把时、分、秒写回 RTC 芯片（DS1307、DS3231、PCF8563 等）。这些芯片的时间寄存器使用 **BCD 码**：一个字节的**高 4 位存十位数字，低 4 位存个位数字**。例如要写入 59 秒，寄存器里必须写 `0x59`（十进制值 89），而不是 `59`（`0x3B`）。

请实现函数 `bin_to_bcd`：输入一个 `0~99` 的数，返回它的 BCD 编码。

判题程序会把一组待写入的时间值依次交给你的函数，并输出编码结果（十进制写法）。

### 示例 1

```
输入：vals = [59,23,12]
输出：[89,35,18]
解释：59 -> 0x59 = 89，23 -> 0x23 = 35，12 -> 0x12 = 18。
```

### 示例 2

```
输入：vals = [0,9,10,99]
输出：[0,9,16,153]
解释：0 -> 0x00，9 -> 0x09，10 -> 0x10 = 16，99 -> 0x99 = 153。
```

### 示例 3

```
输入：vals = [25]
输出：[37]
解释：25 -> 0x25 = 37。
```

### 提示

- `1 <= vals 长度 <= 1000`
- `0 <= vals[i] <= 99`

### 函数说明

```c
uint8_t bin_to_bcd(uint8_t bin);
```

- `bin`：要编码的数值，`0~99`
- 返回值：对应的 BCD 字节（高 4 位十位，低 4 位个位）

### 自定义输入格式

```
[59,23,12]
```

只有 1 行：数值数组（每个元素 0~99）。输出为逐个调用 `bin_to_bcd` 的结果数组（十进制写法）。
