UART（串口）通信时，可以在每个字节的 8 个数据位后面额外发送 1 个 **校验位**（parity bit），接收方据此检查传输过程中是否有某一位被干扰翻转了：

- **偶校验**（even parity）：校验位的取值使得 **8 个数据位 + 校验位** 中 `1` 的总个数为 **偶数**；
- **奇校验**（odd parity）：校验位的取值使得 `1` 的总个数为 **奇数**。

大多数单片机的 UART 硬件能自动生成校验位，但用 GPIO 模拟串口（软件串口）或实现某些自定义协议时，就需要软件自己计算。

给定要发送的数据字节 `data` 和校验方式 `odd`（`0` 表示偶校验，`1` 表示奇校验），请返回应当发送的校验位（`0` 或 `1`）。

### 示例 1

```
输入：data = 65, odd = 0
输出：0
解释：65 = 0x41（字符 'A'）= 0b0100_0001，有 2 个 1，已经是偶数，偶校验位为 0。
```

### 示例 2

```
输入：data = 65, odd = 1
输出：1
解释：同样有 2 个 1，奇校验需要再补 1 个 1，凑成 3 个，校验位为 1。
```

### 示例 3

```
输入：data = 7, odd = 0
输出：1
解释：7 = 0b0000_0111，有 3 个 1，偶校验需要再补 1 个 1，校验位为 1。
```

### 提示

- `0 <= data <= 255`
- `odd` 为 `0` 或 `1`

### 函数说明

```c
uint8_t parity_bit(uint8_t data, int odd);
```

- `data`：要发送的 8 位数据
- `odd`：校验方式，`0` 为偶校验，`1` 为奇校验
- 返回值：校验位，`0` 或 `1`

### 自定义输入格式

```
65
0
```

第 1 行是 `data`，第 2 行是 `odd`，均为十进制整数。输出为校验位。
