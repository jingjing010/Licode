# 删除字符使字符串变好

最少删除字符，使结果不含连续三个相同字符，返回唯一结果。输入小写字母，长度1到10^5。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* makeFancyString(char* s);
```

## 示例 1

输入：
```text
"leeetcode"
```
输出：
```text
"leetcode"
```

## 示例 2

输入：
```text
"aaabaaaa"
```
输出：
```text
"aabaa"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
