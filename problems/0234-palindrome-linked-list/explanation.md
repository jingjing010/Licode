# 234. 回文链表 —— 小白详细题解

> 这道题把两个链表基本功串在了一起：**快慢指针找中点** + **反转链表**。学会它，链表就算入门了。

---

## 📖 第一步：先读懂题目

"回文"就是**正着读和倒着读一样**，比如 "上海自来水来自海上"、`1 2 2 1`、`1 2 3 2 1`。

> 给你一个链表，判断它从头读到尾的数字序列，是不是一个回文。

| 链表 | 正着读 | 倒着读 | 回文吗？ |
|---|---|---|---|
| `[1,2,2,1]` | 1 2 2 1 | 1 2 2 1 | ✅ true |
| `[1,2]` | 1 2 | 2 1 | ❌ false |
| `[1,0,1]` | 1 0 1 | 1 0 1 | ✅ true（奇数长度，中间的数不用比） |

**几个需要注意的细节：**

1. 只有 1 个结点的链表一定是回文。
2. 长度可能是奇数也可能是偶数，两种情况都要对。
3. 单链表**只能往后走**，不能像数组一样从尾巴往前读——这就是本题的难点。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `bool` 类型

本 OJ 已经包含了 `<stdbool.h>`，可以直接使用 `bool`、`true`、`false`。

### 2. 快慢指针找中点

```c
struct ListNode *slow = head, *fast = head;
while (fast->next != NULL && fast->next->next != NULL) {
    slow = slow->next;          // 慢指针走 1 步
    fast = fast->next->next;    // 快指针走 2 步
}
// 循环结束时 slow 停在"前半段的最后一个结点"
```

快指针速度是慢指针的 2 倍，所以快指针走到末尾时，慢指针刚好走到一半。

| 链表 | slow 最后停在 | 前半段 | 后半段 |
|---|---|---|---|
| `1 2 2 1` | 第 2 个（值 2） | 1 2 | 2 1 |
| `1 2 3 2 1` | 第 3 个（值 3） | 1 2 3 | 2 1 |

奇数长度时中间的结点归前半段，比较时只比到后半段走完为止，中间那个自然被跳过。

### 3. `fast->next->next` 的短路保护

`&&` 左边 `fast->next != NULL` 为假时，右边不会执行，所以不会访问 `NULL->next` 导致崩溃。**顺序不能反过来写**。

## 💡 第三步：思路一 —— 复制到数组 + 双指针（最容易想到）

### 思路

链表不能倒着读，数组可以！

1. 遍历链表，把所有值存到数组 `vals` 里
2. 用 `i` 从左往右、`j` 从右往左，逐个比较 `vals[i]` 和 `vals[j]`
3. 有一对不相等就不是回文

### 手动模拟（示例 1：`[1,2,2,1]`）

| i | j | vals[i] | vals[j] | 相等？ |
|---|---|---|---|---|
| 0 | 3 | 1 | 1 | ✅ |
| 1 | 2 | 2 | 2 | ✅ |
| 2 | 1 | - | - | i ≥ j，结束 → true |

### 代码

```c
bool isPalindrome(struct ListNode* head) {
    // 1. 先数一数有多少个结点
    int n = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) n++;

    // 2. 把值复制到数组里
    int* vals = (int*)malloc(sizeof(int) * n);
    int k = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) vals[k++] = p->val;

    // 3. 左右双指针往中间夹
    bool ok = true;
    for (int i = 0, j = n - 1; i < j; i++, j--) {
        if (vals[i] != vals[j]) {   // 有一对不相等，就不是回文
            ok = false;
            break;
        }
    }

    free(vals);                     // 释放数组
    return ok;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：遍历链表两遍，比较约 n/2 次。
- **空间复杂度 O(n)**：数组存了 n 个值。

## 🚀 第四步：思路二 —— 快慢指针 + 反转后半段（O(1) 空间）

### 思路

进阶要求 O(1) 空间，不能开数组了。那就把链表的**后半段反转**，这样后半段就能"倒着读"了：

1. **找中点**：快慢指针，`slow` 停在前半段末尾
2. **反转后半段**：把 `slow->next` 开头的链表反转（就是第 206 题）
3. **逐个比较**：`p` 从 `head` 出发，`q` 从反转后的后半段出发，同时往后走
4. **恢复链表**（好习惯）：把后半段再反转回去，接回 `slow->next`，不破坏调用者的数据

### 手动模拟（`[1,2,3,2,1]`）

| 步骤 | 状态 |
|---|---|
| 找中点 | slow 停在 3，前半段 `1 -> 2 -> 3`，后半段 `2 -> 1` |
| 反转后半段 | second = `1 -> 2` |
| 比较 p=1, q=1 | ✅ |
| 比较 p=2, q=2 | ✅ |
| q 变成 NULL | 结束 → true |

### 代码

```c
// 反转以 head 开头的链表，返回新的头（第 206 题）
static struct ListNode* reverse(struct ListNode* head) {
    struct ListNode* prev = NULL;
    while (head != NULL) {
        struct ListNode* next = head->next;   // 备份下一个
        head->next = prev;                    // 掉头
        prev = head;
        head = next;
    }
    return prev;
}

bool isPalindrome(struct ListNode* head) {
    if (head == NULL || head->next == NULL) return true;   // 0 或 1 个结点一定是回文

    // 1. 快慢指针找中点：slow 最终停在前半段的最后一个结点
    struct ListNode *slow = head, *fast = head;
    while (fast->next != NULL && fast->next->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }

    // 2. 反转后半段
    struct ListNode* second = reverse(slow->next);

    // 3. 前半段和反转后的后半段逐个比较（后半段不比前半段长，所以以它为准）
    bool ok = true;
    struct ListNode* p = head;
    struct ListNode* q = second;
    while (q != NULL) {
        if (p->val != q->val) {
            ok = false;
            break;
        }
        p = p->next;
        q = q->next;
    }

    // 4. 把后半段反转回来，恢复原链表
    slow->next = reverse(second);
    return ok;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：找中点、反转、比较、恢复，各走约 n/2 步。
- **空间复杂度 O(1)**：只用了几个指针。

---

## ⚠️ 第五步：小白常见错误

1. **快慢指针循环条件写错**：写成 `while (fast->next->next != NULL)`，当 `fast->next` 为 `NULL` 时会访问空指针崩溃。必须先判断 `fast->next != NULL`。
2. **比较时以前半段为准**：`while (p != NULL)` 会在奇数长度时让 `q` 先走到 `NULL`，再访问 `q->val` 就崩溃了。应该以较短的后半段 `q` 为准。
3. **把整个链表反转后和原链表比**：反转是**原地**修改的，反转后原链表已经不存在了，相当于自己和自己比，永远返回 true。
4. **数组写法用固定大小的局部数组** `int vals[100000];`：占用 400KB 栈空间，在一些环境下会栈溢出。用 `malloc` 更稳妥。
5. **比较的是指针而不是值**：`if (p != q)` 比较的是两个结点的地址，肯定不同。要比较 `p->val != q->val`。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 复制到数组 + 双指针 | O(n) | O(n) | ⭐ | 先写这个，稳稳 AC |
| 快慢指针 + 反转后半段 | O(n) | O(1) | ⭐⭐⭐ | 进阶写法，面试常考 |
