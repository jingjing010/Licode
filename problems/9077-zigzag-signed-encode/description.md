# ZigZag 有符号整数映射

将int32_t映射为uint32_t：0→0，−1→1，1→2，−2→3，依此类推。输出无符号十进制。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint32_t zigzagEncode(int32_t value);
```

## 示例 1

输入：
```text
0
```
输出：
```text
0
```

## 示例 2

输入：
```text
-1
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：value。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
