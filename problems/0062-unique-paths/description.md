一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

```
Start ■ □ □ □ □ □ □
      □ □ □ □ □ □ □
      □ □ □ □ □ □ ■ Finish
（m = 3 行，n = 7 列）
```

### 示例 1

```
输入：m = 3, n = 7
输出：28
```

### 示例 2

```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

### 示例 3

```
输入：m = 7, n = 3
输出：28
```

### 示例 4

```
输入：m = 3, n = 3
输出：6
```

### 提示

- `1 <= m, n <= 100`
- 题目数据保证答案小于等于 `2 * 10^9`

### 函数说明

```c
int uniquePaths(int m, int n);
```

- `m`：网格的行数，`n`：网格的列数
- 返回值：从左上角走到右下角的不同路径数

### 自定义输入格式

```
3
7
```

第 1 行是 `m`，第 2 行是 `n`。（请保证答案不超过 `2 * 10^9`）
