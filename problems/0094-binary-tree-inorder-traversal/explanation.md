# 94. 二叉树的中序遍历 —— 小白详细题解

> 这是二叉树的入门第一题。学会它，你就掌握了"递归处理树"和"用栈模拟递归"两大基本功。

---

## 📖 第一步：先读懂题目

**中序遍历**的规则只有一句话：

> 对每一个结点，都先遍历它的**左子树**，再访问**它自己**，最后遍历它的**右子树**（左 → 根 → 右）。

拿示例 1 `[1,null,2,3]` 来说，这棵树长这样：

```
    1
     \
      2
     /
    3
```

| 步骤 | 当前处理 | 做了什么 | 结果 |
|---|---|---|---|
| 1 | 结点 1 | 左子树为空，跳过 | [] |
| 2 | 结点 1 | 访问自己 | [1] |
| 3 | 结点 2 | 先去它的左子树：结点 3（3 的左右都空），访问 3 | [1,3] |
| 4 | 结点 2 | 访问自己 | [1,3,2] |
| 5 | 结点 2 | 右子树为空，结束 | [1,3,2] |

**几个需要注意的细节：**

1. 树可能是**空树**（`root == NULL`），此时返回长度为 0 的数组，`*returnSize = 0`。
2. 输入 `[1,null,2,3]` 是**层序**写法，只是用来描述树的形状；你拿到的是已经建好的 `root` 指针，不需要自己解析。
3. 结点最多 100 个，所以结果数组开 100 个 `int` 就够了。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 结构体指针与 `->`

```c
struct TreeNode {
    int val;
    struct TreeNode *left;   // 指向左孩子，没有就是 NULL
    struct TreeNode *right;  // 指向右孩子，没有就是 NULL
};
```

`root` 是一个**指针**，取它指向的结点的成员要用 `->`：`root->val`、`root->left`。`root->val` 等价于 `(*root).val`。

### 2. 在递归里"往同一个数组追加"

递归函数每一层都要往结果数组里写数，并且大家要共享"写到第几个了"这个计数。做法是把计数的**地址**传下去：

```c
void dfs(struct TreeNode* node, int* res, int* cnt) {
    res[(*cnt)++] = node->val;   // 写到 res[*cnt]，然后计数 +1
}
```

如果只传 `int cnt`（值），每层改的都是自己的拷贝，外面看不到——和 `*returnSize` 是同一个道理。

### 3. `malloc` 返回数组

和第 1 题一样，返回的数组必须用 `malloc` 申请，不能返回局部数组。

---

## 💡 第三步：思路一 —— 递归（最直观）

### 思路

把"左 → 根 → 右"直接翻译成代码：

1. 如果结点为空，什么也不做，直接返回（这叫**递归出口**）。
2. 递归遍历左子树。
3. 把当前结点的值写进数组。
4. 递归遍历右子树。

### 手动模拟（示例 1）

| 调用 | 做的事 | res |
|---|---|---|
| dfs(1) | dfs(NULL) 返回；写 1；调用 dfs(2) | [1] |
| dfs(2) | 调用 dfs(3) | [1] |
| dfs(3) | dfs(NULL) 返回；写 3；dfs(NULL) 返回 | [1,3] |
| 回到 dfs(2) | 写 2；dfs(NULL) 返回 | [1,3,2] |

### 代码

```c
// 递归辅助函数：把以 node 为根的子树按中序写进 res，*cnt 是已写入的个数
void dfs(struct TreeNode* node, int* res, int* cnt) {
    if (node == NULL) return;          // 递归出口：空树什么也不做
    dfs(node->left, res, cnt);         // 1. 先遍历左子树
    res[(*cnt)++] = node->val;         // 2. 再访问根结点
    dfs(node->right, res, cnt);        // 3. 最后遍历右子树
}

int* inorderTraversal(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 100);   // 题目保证最多 100 个结点
    int cnt = 0;                                  // 已经写了几个
    dfs(root, res, &cnt);                         // 传 cnt 的地址，递归里才能修改它
    *returnSize = cnt;                            // 告诉调用者数组长度
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点恰好访问一次。
- **空间复杂度 O(h)**：h 是树高，来自递归调用栈；最坏（链状树）为 O(n)。

## 🚀 第四步：思路二 —— 迭代（用栈模拟递归）

### 思路

递归之所以能"先去左边、回来再访问自己"，是因为系统帮我们用**调用栈**记住了"回来的路"。我们可以自己用一个数组当栈：

1. 从当前结点开始**一路向左**，把经过的结点都压进栈（它们都在等"左边处理完再访问自己"）。
2. 走到空了，说明最左边到头了：**弹出**栈顶结点，访问它。
3. 转向它的**右子树**，重复第 1 步。
4. 当前结点为空并且栈也空了，遍历结束。

### 手动模拟（示例 1）

| 步骤 | cur | 操作 | 栈（底→顶） | res |
|---|---|---|---|---|
| 1 | 1 | 压入 1，往左走 | [1] | [] |
| 2 | NULL | 弹出 1，访问，转向右孩子 2 | [] | [1] |
| 3 | 2 | 压入 2，往左走到 3 | [2] | [1] |
| 4 | 3 | 压入 3，往左走 | [2,3] | [1] |
| 5 | NULL | 弹出 3，访问，转向右（空） | [2] | [1,3] |
| 6 | NULL | 弹出 2，访问，转向右（空） | [] | [1,3,2] |
| 7 | NULL | 栈空，结束 | [] | [1,3,2] |

### 代码

```c
int* inorderTraversal(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 100);   // 结果数组
    struct TreeNode* stack[100];                  // 用数组模拟栈，最多 100 个结点
    int top = 0;                                  // 栈里有几个元素
    int cnt = 0;                                  // 结果里有几个元素
    struct TreeNode* cur = root;

    while (cur != NULL || top > 0) {
        // 1. 一路向左，把沿途结点压栈
        while (cur != NULL) {
            stack[top++] = cur;
            cur = cur->left;
        }
        // 2. 左边到头了，弹出栈顶并访问
        cur = stack[--top];
        res[cnt++] = cur->val;
        // 3. 转向右子树
        cur = cur->right;
    }

    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点进栈、出栈各一次。
- **空间复杂度 O(h)**：栈里最多同时存一条从根到叶的路径。

## ⚠️ 第五步：小白常见错误

1. **忘记处理空树**：`root == NULL` 时直接访问 `root->val` 会崩溃（Runtime Error）。递归出口一定要先判空。
2. **计数用值传递**：写成 `void dfs(struct TreeNode* node, int* res, int cnt)`，每层 `cnt++` 都只改了副本，最后结果全挤在 `res[0]`。
3. **忘记设置 `*returnSize`**：数组写对了但长度是 0，输出 `[]`。
4. **把顺序写成前序**：先 `res[...] = node->val` 再递归左子树，就成了"根 → 左 → 右"，示例 1 会得到 `[1,2,3]`。
5. **迭代写法循环条件只写 `top > 0`**：一开始栈是空的，循环一次都不执行，所以必须是 `cur != NULL || top > 0`。
6. **在函数里自己定义 `struct TreeNode`**：会导致重复定义的编译错误。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 递归 | O(n) | O(h) | ⭐ | 先写这个，理解"左根右" |
| 迭代 + 栈 | O(n) | O(h) | ⭐⭐ | 面试常考，理解递归的本质 |
