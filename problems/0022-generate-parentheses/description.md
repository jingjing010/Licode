数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

### 示例 1

```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

### 示例 2

```
输入：n = 1
输出：["()"]
```

### 提示

- `1 <= n <= 8`

### 函数说明

```c
char** generateParenthesis(int n, int* returnSize);
```

- `n`：括号的对数
- 返回值：用 `malloc` 申请的字符串数组，每个字符串也要 `malloc`，长度为 `2n`，并以 `'\0'` 结尾
- `*returnSize`：写入有效括号组合的个数

### 自定义输入格式

```
3
```

只有 1 行：整数 `n`。（组合的顺序任意，判题时会把你返回的字符串按字典序排序后输出）
