# 513. 找树左下角的值 —— 小白详细题解

> "左下角"不是"一直往左走到底"！它的准确意思是：**最深的那一层里，最左边的结点**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 先找出树的**最后一层**（最深的一层），再在这一层里取**最左边**的那个结点。

示例 2：`[1,2,3,4,null,5,6,null,null,7]`

```
        1          ← 第 1 层
       / \
      2   3        ← 第 2 层
     /   / \
    4   5   6      ← 第 3 层
       /
      7            ← 第 4 层（最深）
```

| 层 | 从左到右 | 最左边 |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 2, 3 | 2 |
| 3 | 4, 5, 6 | 4 |
| 4 | 7 | **7** |

最深一层是第 4 层，只有 7，答案是 **7**。如果"一直往左走"，会走到 4，这是错的。

**几个需要注意的细节：**

1. 答案**不一定是左孩子**：`[1,null,2]` 的最后一层只有 2（它是右孩子），答案是 2。
2. 至少有一个结点。只有根时，答案就是根的值。
3. 值的范围是整个 `int`（-2³¹ ~ 2³¹-1），只是返回它，不做运算，不会溢出。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用数组模拟队列

```c
q[tail++] = x;     // 入队
x = q[head++];     // 出队
head < tail        // 队列不空
```

最多 10⁴ 个结点，用 `malloc` 申请。

### 2. 用 `static` 全局变量在递归中记录"目前最好的答案"

```c
static int maxDepth, ans;
```

递归函数的每一层都能读写它们。记得在主函数里重新初始化。

---

## 💡 第三步：思路一 —— DFS，记录"第一次到达新深度"的结点

### 思路

用前序遍历（**先左后右**）走遍整棵树，同时记录当前深度 `d`：

- 如果 `d` 比之前见过的最大深度 `maxDepth` 还深，说明**第一次**到达这一层。因为先左后右，第一次到达某一层时遇到的一定是这一层**最左边**的结点 → 更新 `ans`。
- 同一层后面再遇到的结点，`d == maxDepth`，不更新。

遍历结束后，`ans` 就是最深一层的最左结点。

### 手动模拟（示例 2）

| 访问顺序 | 结点 | 深度 d | d > maxDepth? | maxDepth | ans |
|---|---|---|---|---|---|
| 1 | 1 | 1 | 是 | 1 | 1 |
| 2 | 2 | 2 | 是 | 2 | 2 |
| 3 | 4 | 3 | 是 | 3 | 4 |
| 4 | 3 | 2 | 否 | 3 | 4 |
| 5 | 5 | 3 | 否 | 3 | 4 |
| 6 | 7 | 4 | 是 | 4 | **7** |
| 7 | 6 | 3 | 否 | 4 | 7 |

### 代码

```c
static int maxDepth;   // 目前到过的最大深度
static int ans;        // 第一次到达 maxDepth 层时遇到的结点值

static void dfs(struct TreeNode* node, int d) {
    if (node == NULL) return;
    if (d > maxDepth) {        // 第一次到达这一层：它就是这一层最左边的结点
        maxDepth = d;
        ans = node->val;
    }
    dfs(node->left, d + 1);    // 一定要先左
    dfs(node->right, d + 1);   // 后右
}

int findBottomLeftValue(struct TreeNode* root) {
    maxDepth = 0;              // 每次调用都重新初始化
    dfs(root, 1);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点访问一次。
- **空间复杂度 O(h)**：递归栈，链状时为 10⁴ 层（本 OJ 栈空间足够）。

---

## 🚀 第四步：思路二 —— BFS 先右后左，最后出队的就是答案

### 思路

普通的层序遍历是"每层从左到右"，最后出队的是**最后一层最右边**的结点。

如果入队时**先放右孩子、再放左孩子**，每一层就变成"从右到左"，那么最后一个出队的结点就是**最后一层最左边**的结点——正是答案！连分层都不用。

### 手动模拟（示例 2）

| 出队 | 入队（先右后左） | 队列 |
|---|---|---|
| 1 | 3, 2 | [3, 2] |
| 3 | 6, 5 | [2, 6, 5] |
| 2 | 4 | [6, 5, 4] |
| 6 | — | [5, 4] |
| 5 | 7 | [4, 7] |
| 4 | — | [7] |
| 7 | — | []，**最后出队的是 7** |

### 代码

```c
int findBottomLeftValue(struct TreeNode* root) {
    // 每个结点只入队一次，最多 10^4 个
    struct TreeNode** q = (struct TreeNode**)malloc(sizeof(struct TreeNode*) * 10000);
    int head = 0, tail = 0;
    q[tail++] = root;
    struct TreeNode* node = root;
    while (head < tail) {
        node = q[head++];                          // 出队，记住最后一个
        if (node->right) q[tail++] = node->right;  // 先右
        if (node->left) q[tail++] = node->left;    // 后左
    }
    int ans = node->val;                           // 最后出队的结点
    free(q);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(n)**（队列）。

---

## ⚠️ 第五步：小白常见错误

1. **一直往左走到底**：
   ```c
   while (root->left) root = root->left;   // ❌
   return root->val;
   ```
   示例 2 会得到 4；`[1,null,2]` 会得到 1。
2. **DFS 时先右后左**：那第一次到达新一层时遇到的是最**右**边的结点。
3. **DFS 用 `d >= maxDepth` 更新**：同一层后面的结点会覆盖前面的，得到的是最右边的结点。必须是严格大于 `>`。
4. **普通 BFS（先左后右）取最后出队的**：那是最后一层最**右**边的结点。要么先右后左，要么记录每层的第一个。
5. **全局变量没有在主函数里重置**：多次调用时 `maxDepth` 保留了上次的值，后面的树一层都更新不了。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| DFS + 记录最大深度 | O(n) | O(h) | ⭐⭐ | 理解"先左后右，首次到达即最左" |
| BFS 先右后左 | O(n) | O(n) | ⭐ | **首选**，代码最短、最巧 |
