# 409. 最长回文串 —— 小白详细题解

> 不需要真的"构造"回文串，只要想清楚**回文串里字符个数的规律**，这道题就是一个计数问题。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一堆字母（可以随意调换顺序，也可以不全用），最多能拼出多长的回文串？

回文串就是正着读、反着读都一样的字符串，比如 `"dccaccd"`。它**左右对称**：

```
d c c a c c d
↑ ↑ ↑ ↑ ↑ ↑ ↑
└─┼─┼─┼─┼─┼─┘  d 成对
  └─┼─┼─┼─┘    c 成对
    └─┼─┘      c 成对
      a        正中间，可以单独一个
```

所以规律是：**除了正中间最多一个字符，其它字符都必须成对出现。**

拿示例 1 `"abccccdd"` 来说：

| 字符 | a | b | c | d |
|---|---|---|---|---|
| 出现次数 | 1 | 1 | 4 | 2 |
| 能成对用上的 | 0 | 0 | 4 | 2 |

成对部分共 6 个，再从 `a`、`b` 中挑一个放中间，答案 **7**。

**几个需要注意的细节：**

1. **区分大小写**：`'A'` 和 `'a'` 是不同的字符，`"Aa"` 的答案是 1。
2. 出现奇数次的字符不是完全不能用：出现 3 次的 `c` 可以用 2 个成对，剩下 1 个。
3. 中间位置**只有一个**：即使有多个字符剩下单个，也只能再加 1。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用 ASCII 码当数组下标

字符本质上是整数（`'A'` = 65，`'a'` = 97），大小写字母都小于 128，所以开一个 `int cnt[128]` 就能给每种字符计数：

```c
int cnt[128] = {0};
cnt[(unsigned char)s[i]]++;
```

也可以开两个 `cnt[26]` 分别存大写、小写，但 `cnt[128]` 更省事。

### 2. 整数除法的"取整"

C 语言里整数相除会**直接舍去小数**：`5 / 2 = 2`，所以

```c
cnt / 2 * 2    // 5 -> 4，4 -> 4，1 -> 0：最多能成对使用的个数
cnt % 2        // 5 -> 1（奇数），4 -> 0（偶数）
```

---

## 💡 第三步：思路一 —— 统计次数，奇数个数减掉多余的

### 思路

换个角度：先假设**所有字符都能用上**（答案 = 总长度），再看哪些用不上。

- 出现奇数次的字符，各有 1 个"落单"；
- 设落单的字符种类数为 `odd`。其中 1 个可以放在正中间，其余 `odd - 1` 个都用不上。

所以：`odd == 0` 时答案是 `n`；否则答案是 `n - (odd - 1)`。

### 手动模拟（示例 1：`"abccccdd"`，n = 8）

奇数次的字符有 `a`（1 次）、`b`（1 次），`odd = 2`，答案 `8 - (2 - 1) = 7`。

### 代码

```c
int longestPalindrome(char* s) {
    int cnt[128] = {0};          // 每种字符出现的次数
    int n = 0;                   // 字符串总长度
    for (; s[n] != '\0'; n++) {
        cnt[(unsigned char)s[n]]++;
    }

    int odd = 0;                 // 出现奇数次的字符有几种
    for (int c = 0; c < 128; c++) {
        if (cnt[c] % 2 == 1) odd++;
    }

    if (odd == 0) return n;      // 全是偶数次，全部用上
    return n - (odd - 1);        // 留一个放中间，其余落单的去掉
}
```

### 复杂度分析

- **时间复杂度 O(n + 128)**，即 O(n)。
- **空间复杂度 O(1)**：固定大小的计数数组。

---

## 🚀 第四步：思路二 —— 贪心累加成对的部分

### 思路

正面计算也很直观（贪心：能用就用）：

1. 每种字符最多用 `cnt / 2 * 2` 个（成对的部分），全部加起来；
2. 只要有**任何一种**字符出现了奇数次，就可以拿它的一个放中间，答案再加 1。

两种思路本质相同，这种写法更贴近"构造回文串"的过程。

### 手动模拟（`"cccAaBbB"`）

| 字符 | 次数 | 成对部分 | 有落单？ |
|---|---|---|---|
| c | 3 | 2 | 是 |
| A | 1 | 0 | 是 |
| a | 1 | 0 | 是 |
| B | 2 | 2 | 否 |
| b | 1 | 0 | 是 |

成对部分 2 + 2 = 4，有落单 → 答案 5（例如 `"BcAcB"`，把一个 `A` 放中间）。

### 代码

```c
int longestPalindrome(char* s) {
    int cnt[128] = {0};
    for (int i = 0; s[i] != '\0'; i++) {
        cnt[(unsigned char)s[i]]++;      // 统计每种字符的次数（大小写自动区分）
    }

    int ans = 0;
    int hasOdd = 0;                      // 是否存在出现奇数次的字符
    for (int c = 0; c < 128; c++) {
        ans += cnt[c] / 2 * 2;           // 成对的部分全部用上
        if (cnt[c] % 2 == 1) hasOdd = 1;
    }
    return ans + hasOdd;                 // 有落单的，就放一个在正中间
}
```

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **不区分大小写** → 用 `tolower` 统一成小写，`"Aa"` 会错误地得到 2。题目明确要求区分大小写。
2. **奇数次的字符直接丢掉** → 只累加偶数次的字符，`"ccc"` 得到 0，正确答案是 3（`"ccc"` 本身就是回文）。
3. **每个奇数次的字符都加 1** → `"abc"` 会得到 3，但正中间只有一个位置，答案是 1。
4. **用 `cnt[s[i] - 'a']` 计数** ❌ → 大写字母 `'A' - 'a'` 是负数，数组越界。
5. **计数数组没有初始化** → `int cnt[128];` 里是垃圾值。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 特点 |
|---|---|---|---|---|
| 总长减去落单 | O(n) | O(1) | ⭐ | 反向思考：先全用，再去掉用不上的 |
| 贪心累加成对 | O(n) | O(1) | ⭐ | 正向构造，最直观 |

> 🎯 **学习建议**：遇到"回文"相关的计数题，先想"**对称 → 成对 → 最多一个落单**"这条规律。
