# 最小差值 I

每个元素可独立加上[−k,k]中的整数一次，返回最小可能的最大值减最小值。1 ≤ n ≤ 10^4，元素和k均在0到10^4之间。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int smallestRangeI(int* nums,int numsSize,int k);
```

## 示例 1

输入：
```text
[1]
0
```
输出：
```text
0
```

## 示例 2

输入：
```text
[0,10]
2
```
输出：
```text
6
```

## 自定义输入格式

按顺序每行一个参数：nums、k。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
