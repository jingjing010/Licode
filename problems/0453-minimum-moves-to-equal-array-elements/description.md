# 最小操作次数使数组元素相等

每次可让数组中的n−1个元素加1，返回使所有元素相等的最少次数。1 ≤ n ≤ 10^5，保证答案在int范围内。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int minMoves(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,2,3]
```
输出：
```text
3
```

## 示例 2

输入：
```text
[1,1,1]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
