# DS18B20 原始温度转换：题解

## 📖 先读懂题目

输入已按小端字节组装的16位raw，温度在−55..125℃，12位分辨率、无故障码。返回毫摄氏度，半毫单位向零截断。不包含CRC验证。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `400` | `25000` |
| 2 | `65376` | `-10000` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

12位分辨率时每最低位代表1/16摄氏度；原始16位字需要按有符号补码解释，再换算毫摄氏度。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int ds18b20MilliC(int raw) {
    /* 用显式减65536解释补码，避免实现相关的窄类型转换。 */
    int signedRaw = raw >= 32768 ? raw - 65536 : raw;
    return signedRaw * 1000 / 16;
}
```

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
