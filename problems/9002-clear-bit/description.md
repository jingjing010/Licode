在单片机中，外设通常通过一个 32 位的 **控制寄存器** 来配置。例如某个 UART 的控制寄存器 `UART_CR` 中，第 `n` 位是某个功能的使能位：`1` 表示开启，`0` 表示关闭。

现在要关闭这个功能。给定寄存器当前的值 `reg` 和位号 `n`，请把 `reg` 的 **第 `n` 位清零**（置为 0），**其余位保持不变**，返回修改后的寄存器值。

位号从 `0` 开始：第 `0` 位是最低位（LSB），第 `31` 位是最高位（MSB）。

### 示例 1

```
输入：reg = 15, n = 2
输出：11
解释：15 = 0b1111，第 2 位清零后变成 0b1011 = 11。
```

### 示例 2

```
输入：reg = 8, n = 3
输出：0
解释：8 = 0b1000，唯一的 1 正好在第 3 位，清零后为 0。
```

### 示例 3

```
输入：reg = 5, n = 1
输出：5
解释：5 = 0b101，第 1 位本来就是 0，清零后不变。
```

### 提示

- `0 <= reg <= 2^32 - 1`（即 `0x00000000` ~ `0xFFFFFFFF`）
- `0 <= n <= 31`

### 函数说明

```c
uint32_t clear_bit(uint32_t reg, int n);
```

- `reg`：寄存器的原始值（32 位无符号整数）
- `n`：要清零的位号
- 返回值：第 `n` 位清零、其余位不变后的值

### 自定义输入格式

```
15
2
```

第 1 行是 `reg`，第 2 行是 `n`，均为十进制整数。输出为修改后的寄存器值（十进制）。
