# COBS 无零字节编码：题解

## 📖 先读懂题目

编码为COBS数据区，不附加帧分隔符0。空输入编码为[1]。每块最多254个数据字节；即使最后恰好满块，也输出结尾空块码1。输入0到1024字节。返回整数数组表示字节。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[49,50,51,52,53,54,55,56,57]` | `[10,49,50,51,52,53,54,55,56,57]` |
| 2 | `[]` | `[1]` |

## 🧰 需要的 C 语言知识

`uint8_t`表示一个0到255的字节；`const uint8_t *`允许读取数据但不修改它。`size_t len`明确给出缓冲区长度，不能使用`strlen`计算二进制数据长度，因为数据中可能含0。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

每个块开头保存下一段非零数据长度加1；满254个非零字节时强制开新块。每次开块都保留码字位置，结尾写回最后码字。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *cobsEncode(const uint8_t *data, size_t len, int *returnSize) {
    int *out = malloc((len + len / 254 + 2) * sizeof(int));
    size_t index = 0, k = 1;
    int code = 1;
    for (size_t i = 0; i < len; ++i) {
        if (data[i] == 0) {
            out[index] = code;
            index = k++;
            code = 1;
        } else {
            out[k++] = data[i];
            if (++code == 255) {
                out[index] = code;
                index = k++;
                code = 1;
            }
        }
    }
    out[index] = code;
    *returnSize = (int)k;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，输出空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 把二进制缓冲区当成以零结尾的字符串，遇到0便提前停止。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
