# 3. 无重复字符的最长子串 —— 小白详细题解

> 这是学习**滑动窗口**最经典的入门题。先用"枚举起点"的笨办法做对，再一步步优化成滑动窗口。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 在字符串里找一段**连续的**、**里面没有重复字符**的片段，问这样的片段最长有多长。

拿示例 3 `s = "pwwkew"` 来说：

| 起点 | 往右扩展 | 遇到重复就停 | 长度 |
|---|---|---|---|
| p (0) | p → pw → pww ✗ | "pw" | 2 |
| w (1) | w → ww ✗ | "w" | 1 |
| w (2) | w → wk → wke → wkew ✗ | "wke" | **3** |
| k (3) | k → ke → kew | "kew" | **3** |
| e (4) | e → ew | "ew" | 2 |
| w (5) | w | "w" | 1 |

最长是 3。

**几个需要注意的细节：**

1. **子串**必须连续，**子序列**可以跳着选。`"pwke"` 是子序列，不是子串，不算。
2. 字符串可能是**空串** `""`，答案是 0。
3. 字符不只有小写字母，还有大写、数字、**空格**和各种符号。空格也是字符，也不能重复。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. C 字符串以 `'\0'` 结尾

`char* s` 只是一个地址，C 语言靠末尾的 `'\0'` 知道字符串在哪结束。所以可以这样遍历：

```c
for (int i = 0; s[i] != '\0'; i++) { /* 处理 s[i] */ }
```

也可以先用 `strlen(s)` 求出长度。注意不要在循环条件里写 `i < strlen(s)`，那样每次循环都会重新数一遍长度，变成 O(n²)。

### 2. 字符可以直接当数组下标

`char` 本质上是一个小整数（ASCII 码）：`'a'` 是 97，`' '` 是 32。题目里的字符 ASCII 码都在 0~127 之间，所以开一个 `int seen[128]`，`seen['a']` 就表示字母 a 的信息。这就是一个**最简单的哈希表**。

```c
int seen[128] = {0};      // 全部初始化为 0
seen[(int)s[i]] = 1;      // 标记 s[i] 出现过
```

---

## 💡 第三步：思路一 —— 枚举起点 + 计数数组

### 思路

1. 枚举每一个起点 `i`。
2. 从 `i` 往右扩展 `j`，用 `seen[]` 记录窗口里出现过的字符；一旦 `s[j]` 已经出现过，就停下。
3. `j - i` 就是以 `i` 为起点的最长无重复子串长度。

为什么不会太慢？题目字符最多只有 95 种可打印字符，从任何起点出发，**最多扩展 95 步**就一定会遇到重复。所以总次数约 5 × 10⁴ × 95 ≈ 5 × 10⁶，完全够快。

### 代码

```c
int lengthOfLongestSubstring(char* s) {
    int n = strlen(s);
    int best = 0;

    for (int i = 0; i < n; i++) {               // 1. 枚举起点
        int seen[128] = {0};                    // 每个起点都要重新清空
        int j = i;
        while (j < n && !seen[(int)s[j]]) {     // 2. 往右扩展，直到遇到重复字符
            seen[(int)s[j]] = 1;
            j++;
        }
        if (j - i > best) best = j - i;         // 3. s[i..j-1] 没有重复，长度 j - i
    }
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n × Σ)**：Σ 是字符种类数（≤ 128）。
- **空间复杂度 O(Σ)**：`seen` 数组。

---

## 🚀 第四步：思路二 —— 滑动窗口（一遍扫描）

### 思路

思路一里，起点从 `i` 变成 `i+1` 时，我们把之前扩展的结果全丢了，又从头开始扩展。其实很浪费：

> 如果 `s[i..j-1]` 没有重复，那它的一部分 `s[i+1..j-1]` 当然也没有重复。

于是维护一个**窗口** `[left, i]`，保证窗口内没有重复：

- 右边界 `i` 每次右移一格，把 `s[i]` 加进窗口。
- 如果 `s[i]` 在窗口里**已经出现过**（上次出现在位置 `last[s[i]]`，且 `>= left`），就把左边界**直接跳到** `last[s[i]] + 1`，把旧的那个字符"挤出去"。
- 每一步用窗口长度 `i - left + 1` 更新答案。

`last[c]` 记录字符 `c` **最近一次出现的下标**，初始为 -1 表示没出现过。

### 手动模拟（示例 1：`s = "abcabcbb"`）

| i | s[i] | last[s[i]] | 在窗口内？ | left | 窗口 | 长度 | best |
|---|---|---|---|---|---|---|---|
| 0 | a | -1 | 否 | 0 | a | 1 | 1 |
| 1 | b | -1 | 否 | 0 | ab | 2 | 2 |
| 2 | c | -1 | 否 | 0 | abc | 3 | 3 |
| 3 | a | 0 | 是 | 1 | bca | 3 | 3 |
| 4 | b | 1 | 是 | 2 | cab | 3 | 3 |
| 5 | c | 2 | 是 | 3 | abc | 3 | 3 |
| 6 | b | 4 | 是 | 5 | cb | 2 | 3 |
| 7 | b | 6 | 是 | 7 | b | 1 | 3 |

### 代码

```c
int lengthOfLongestSubstring(char* s) {
    int last[128];                       // last[c]：字符 c 最近一次出现的下标
    for (int c = 0; c < 128; c++) last[c] = -1;   // -1 表示还没出现过

    int left = 0;                        // 窗口左边界，窗口是 s[left..i]
    int best = 0;
    for (int i = 0; s[i] != '\0'; i++) {
        int c = (int)s[i];
        // 1. s[i] 上次出现的位置在窗口里 → 左边界跳到它后面一格
        if (last[c] >= left) {
            left = last[c] + 1;
        }
        // 2. 记录 s[i] 最新的位置
        last[c] = i;
        // 3. 更新答案
        if (i - left + 1 > best) best = i - left + 1;
    }
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：右边界走一遍，左边界只会往右跳。
- **空间复杂度 O(Σ)**：`last` 数组。

---

## ⚠️ 第五步：小白常见错误

1. **忘了判断 `last[c] >= left`，直接 `left = last[c] + 1`** → 左边界可能**往回跳**。例如 `"abba"`：处理到最后的 `a` 时，`last['a'] = 0`，但 `left` 已经是 2 了，往回跳到 1 会得到错误答案 3（正确是 2）。
2. **把子序列当成子串** → `"pwwkew"` 答 4（`"pwke"`）是错的。
3. **`seen` 数组开成 26** → 题目有空格、数字、大写和符号，`seen[' ']` 就越界了。开 128（或 256）最稳。
4. **思路一中 `seen` 没有在每个起点重新清零** → 上一个起点留下的标记会让新起点提前停止。
5. **循环条件写 `i < strlen(s)`** → 每轮都重新算长度，n = 5 × 10⁴ 时变成 O(n²)，可能超时。
6. **空串没处理好** → `s = ""` 时循环一次都不执行，`best` 初始值必须是 0。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 枚举起点 + 计数 | O(n × Σ) | O(Σ) | ⭐ | 先写对，理解"无重复"怎么判断 |
| 滑动窗口 | O(n) | O(Σ) | ⭐⭐ | 必须掌握的模板 |
