序列化是将一个数据结构或者对象转换为连续的比特位的操作，进而可以将转换后的数据存储在一个文件或者内存中，同时也可以通过网络传输到另一个计算机环境，采取相反方式重构得到原数据。

请设计一个算法来实现二叉树的序列化与反序列化。这里不限定你的序列 / 反序列化算法执行逻辑，你只需要保证一个二叉树可以被序列化为一个字符串并且将这个字符串反序列化为原始的树结构。

**提示:** 输入输出格式与 LeetCode 目前使用的方式一致，详情请参阅 LeetCode 序列化二叉树的格式。你并非必须采取这种方式，你也可以采用其他的方法解决这个问题。

### 示例 1

```
    1
   / \
  2   3
     / \
    4   5
```

```
输入：root = [1,2,3,null,null,4,5]
输出：[1,2,3,null,null,4,5]
```

### 示例 2

```
输入：root = []
输出：[]
```

### 示例 3

```
输入：root = [1]
输出：[1]
```

### 示例 4

```
输入：root = [1,2]
输出：[1,2]
```

### 提示

- 树中结点数在范围 `[0, 10^4]` 内
- `-1000 <= Node.val <= 1000`

### 函数说明

```c
struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

char* serialize(struct TreeNode* root);
struct TreeNode* deserialize(char* data);
```

- `struct TreeNode` 已由系统定义，**不要**在代码中重复定义
- `serialize`：把以 `root` 为根的树（可能为空）编码成一个 `'\0'` 结尾的字符串，返回 `malloc` 出来的字符串；格式由你自己决定
- `deserialize`：把 `serialize` 产生的字符串还原成树，返回根结点（结点用 `malloc` 申请）

判题程序的调用方式：

```c
char* data = serialize(root);
/* 判题程序把 data 复制一份，然后销毁原来的树 */
struct TreeNode* ans = deserialize(复制出来的字符串);
/* 输出 ans 的层序表示，应与原树完全相同 */
```

注意：判题程序会在调用 `deserialize` **之前**清空并释放原树的所有结点，所以字符串里必须真正包含树的全部信息（不能只保存指针地址）。

### 自定义输入格式

```
[1,2,3,null,null,4,5]
```

只有 1 行：二叉树的层序表示（`null` 表示空结点）。输出为还原出的树的层序表示。
