# 气球的最大数量：题解

## 📖 先读懂题目

从小写字符串中选取字母组成尽可能多个balloon，每个字符只能使用一次，返回数量。长度1到10^4。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"nlaebolko"` | `1` |
| 2 | `"loonbalxballpoon"` | `2` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

balloon需要b、a、n各一个，l、o各两个。每种字符给出一个可构造份数上限，取最小值。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int maxNumberOfBalloons(char *text) {
    int counts[26] = {0};
    for (int i = 0; text[i]; ++i)
        ++counts[text[i] - 'a'];
    int best = counts['b' - 'a'];
    char *word = "alon";
    for (int i = 0; word[i]; ++i) {
        int v = counts[word[i] - 'a'];
        if (word[i] == 'l' || word[i] == 'o')
            v /= 2;
        if (v < best)
            best = v;
    }
    return best;
}
```

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
