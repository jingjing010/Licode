# 二进制间距：题解

## 📖 先读懂题目

返回正整数 n 二进制表示中相邻两个1之间的最大位距离；少于两个1时返回0。n ≤ 10^9。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `22` | `2` |
| 2 | `8` | `0` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

遍历二进制位，保存上一个1的位置，只在遇到下一个1时更新距离。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int binaryGap(int n) {
    int last = -1, best = 0, pos = 0;
    while (n) {
        if (n & 1) {
            if (last >= 0 && pos - last > best)
                best = pos - last;
            last = pos;
        }
        n >>= 1;
        ++pos;
    }
    return best;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(log n)，额外空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。

## 🔗 举一反三

尝试把同一处理过程改成逐个输入的流式接口，思考需要保留哪些状态。用空边界、最小值、最大值和重复值检查自己的实现。
