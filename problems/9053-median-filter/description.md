传感器信号里经常会出现偶发的**尖峰干扰**（继电器吸合、电机启动、静电……），某一个采样值突然跳得很离谱。滑动平均会把尖峰"摊"到附近好几个输出上，而**中值滤波**直接取窗口内的中位数，能把孤立的尖峰整个去掉，同时保留信号的跳变沿。

给你一段采样信号 `signal`（长度 `len`）和一个**奇数**窗口大小 `k`，令 `h = (k - 1) / 2`。对每个位置 `i`（`0 <= i < len`），取以 `i` 为中心的 `k` 个值：

```
signal[i-h], ..., signal[i-1], signal[i], signal[i+1], ..., signal[i+h]
```

其中**越界的下标取最近的端点值**（下标 `< 0` 当作 `signal[0]`，下标 `>= len` 当作 `signal[len-1]`）。把这 `k` 个值排序后正中间的那个（第 `h` 小，从 0 数起）作为 `out[i]`。

请把滤波结果写入 `out`（长度同样为 `len`）。

### 示例 1

```
输入：signal = [10,12,250,11,13], k = 3
输出：[10,12,12,13,13]
解释：
i=0：[10,10,12] → 10（左边越界，用 signal[0] 补）
i=1：[10,12,250] → 12
i=2：[12,250,11] → 12（尖峰 250 被滤掉）
i=3：[250,11,13] → 13
i=4：[11,13,13] → 13（右边越界，用 signal[4] 补）
```

### 示例 2

```
输入：signal = [1,100,2,3,200,4], k = 5
输出：[1,2,3,4,4,4]
解释：
i=0：[1,1,1,100,2] → 1
i=1：[1,1,100,2,3] → 2
i=2：[1,100,2,3,200] → 3
i=3：[100,2,3,200,4] → 4
i=4：[2,3,200,4,4] → 4
i=5：[3,200,4,4,4] → 4
```

### 示例 3

```
输入：signal = [5,-3], k = 1
输出：[5,-3]
解释：窗口大小为 1 时输出等于输入。
```

### 提示

- `1 <= len <= 5 * 10^4`
- `-10000 <= signal[i] <= 10000`
- `1 <= k <= 51`，`k` 为奇数

### 函数说明

```c
void medianFilter(const int16_t* signal, size_t len, size_t k, int16_t* out);
```

- `out` 由调用者分配好（长度 `len`），你只需要填写它

### 自定义输入格式

```
[10,12,250,11,13]
3
```

第 1 行是信号，第 2 行是 `k`。输出 `out` 数组。
