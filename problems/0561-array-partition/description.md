# 数组拆分

把2n个整数分为n对，最大化每对较小值的总和。1 ≤ n ≤ 10^4，元素在−10^4到10^4之间。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int arrayPairSum(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,4,3,2]
```
输出：
```text
4
```

## 示例 2

输入：
```text
[6,2,6,5,1,2]
```
输出：
```text
9
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
