NTC 热敏电阻是最便宜、最常用的温度传感器：它和一个固定电阻串联分压，MCU 用 12 位 ADC（`0 ~ 4095`）读出电压。但 ADC 值和温度之间是复杂的非线性关系（涉及对数运算），在没有 FPU 的单片机上实时计算很慢。工程上的标准做法是：事先在电脑上算好一张"**ADC 值 → 温度**"的对照表烧进 Flash，运行时**查表 + 线性插值**。

给你两张长度为 `n` 的表：`adcTable`（**严格递增**）和对应的 `tempTable`（单位 0.1°C，例如 `253` 表示 25.3°C）。对于一个 ADC 读数 `adc`，按下面的规则计算温度：

1. 如果 `adc <= adcTable[0]`，返回 `tempTable[0]`。
2. 如果 `adc >= adcTable[n-1]`，返回 `tempTable[n-1]`。
3. 否则找到 `i` 使 `adcTable[i] <= adc < adcTable[i+1]`，记 `x0 = adcTable[i]`、`x1 = adcTable[i+1]`、`t0 = tempTable[i]`、`t1 = tempTable[i+1]`，返回

   `t0 + round((t1 - t0) × (adc - x0) / (x1 - x0))`

   其中 `round` 为**四舍五入，恰好 .5 时向远离 0 的方向舍入**（例如 `2.5 → 3`，`-2.5 → -3`，`-348.83 → -349`）。

### 示例 1

```
输入：adcTable = [100,400,700,1000], tempTable = [850,400,150,-200], queries = [50,100,250,550,999,4000]
输出：[850,850,625,275,-199,-200]
解释：
50 < 100，取第一个温度 850；100 正好是表项，850。
250 在 [100,400] 之间：850 + (400-850)×150/300 = 850 - 225 = 625。
550 在 [400,700] 之间：400 + (150-400)×150/300 = 400 - 125 = 275。
999 在 [700,1000] 之间：增量 (-350)×299/300 = -348.83 → -349，150 - 349 = -199。
4000 超出表尾，取 -200。
```

### 示例 2

```
输入：adcTable = [0,4,8], tempTable = [0,10,0], queries = [1,3,5,7]
输出：[3,8,7,2]
解释：
1：增量 10×1/4 = 2.5 → 3，结果 3。     3：增量 10×3/4 = 7.5 → 8，结果 8。
5：增量 -10×1/4 = -2.5 → -3，结果 7。  7：增量 -10×3/4 = -7.5 → -8，结果 2。
```

### 示例 3

```
输入：adcTable = [2000], tempTable = [253], queries = [0,2000,4095]
输出：[253,253,253]
解释：表只有一项时，任何输入都返回这一项。
```

### 提示

- `1 <= n <= 256`
- `0 <= adcTable[i] <= 4095`，且 `adcTable` 严格递增
- `-400 <= tempTable[i] <= 1500`
- `1 <= queries.length <= 10^4`，`0 <= queries[j] <= 4095`

### 函数说明

```c
int16_t ntcLookup(const uint16_t* adcTable, const int16_t* tempTable, size_t n, uint16_t adc);
```

- 判题程序对 `queries` 中的每个值调用一次 `ntcLookup`，输出所有结果

### 自定义输入格式

```
[100,400,700,1000]
[850,400,150,-200]
[50,100,250,550,999,4000]
```

3 行依次是 `adcTable`、`tempTable`、`queries`。
