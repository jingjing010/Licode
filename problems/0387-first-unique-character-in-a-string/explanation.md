# 387. 字符串中的第一个唯一字符 —— 小白详细题解

> 和 **383. 赎金信** 一样，这道题的关键工具是 `int cnt[26]` 计数数组。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 从左往右看，找到**第一个**在整个字符串里**只出现过一次**的字母，返回它的下标；没有这样的字母就返回 -1。

拿示例 2 `"loveleetcode"` 来说，先数每个字母出现几次：

| 字母 | l | o | v | e | t | c | d |
|---|---|---|---|---|---|---|---|
| 次数 | 2 | 2 | **1** | 4 | 1 | 1 | 1 |

再从左往右找第一个次数为 1 的：

| 下标 | 0 | 1 | 2 |
|---|---|---|---|
| 字母 | l（2 次） | o（2 次） | **v（1 次）✅** |

答案是 2。

**几个需要注意的细节：**

1. “不重复”是指在**整个字符串**里只出现一次，不是“和相邻字符不同”。
2. 要返回**下标**，不是字符本身。
3. 可能所有字符都重复（示例 3），返回 -1。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 计数数组 `cnt[26]`

```c
int cnt[26] = {0};          // 一定要初始化为 0
cnt[s[i] - 'a']++;          // 'a'→0, 'b'→1, …, 'z'→25
```

### 2. 为什么不能“每个字符都去数一遍”？

最直接的想法是：对每个位置 `i`，再扫描一遍整个字符串，数 `s[i]` 出现了几次。这是两层循环，O(n²)。n = 10⁵ 时是 10¹⁰ 次运算，**会超时**。

先花 O(n) 把所有字母的次数**一次性数好**，之后查询某个字母的次数只需要 O(1)——这就是“用空间换时间”。

### 3. 遍历到 `'\0'` 为止

```c
for (int i = 0; s[i] != '\0'; i++)    // 不需要 strlen
```

---

## 💡 第三步：思路一 —— 两次遍历（计数 + 查找）

### 思路

1. 第一遍：统计每个字母出现的次数；
2. 第二遍：从左往右找第一个 `cnt[s[i] - 'a'] == 1` 的位置。

### 手动模拟（示例 1：`"leetcode"`）

第一遍后：`l:1, e:3, t:1, c:1, o:1, d:1`。

| i | s[i] | cnt | 是 1 吗？ |
|---|---|---|---|
| 0 | l | 1 | ✅ 返回 0 |

### 代码

```c
int firstUniqChar(char* s) {
    int cnt[26] = {0};                     // 每个字母出现的次数

    // 1. 第一遍：计数
    for (int i = 0; s[i] != '\0'; i++) {
        cnt[s[i] - 'a']++;
    }

    // 2. 第二遍：按原顺序找第一个只出现一次的
    for (int i = 0; s[i] != '\0'; i++) {
        if (cnt[s[i] - 'a'] == 1) {
            return i;
        }
    }
    return -1;                             // 没有找到
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两遍扫描。
- **空间复杂度 O(1)**：固定 26 个格子。

---

## 🚀 第四步：思路二 —— 记录首次出现的位置（只扫一遍字符串）

### 思路

思路一的第二遍要再扫描整个字符串（最多 10⁵ 个字符）。其实可以在第一遍时顺便记下每个字母**第一次出现的下标** `first[k]`，然后只需要检查 **26 个字母**：

- 在所有“只出现 1 次”的字母里，取 `first` 最小的那个，就是答案。

### 手动模拟（示例 2：`"loveleetcode"`）

| 字母 | l | o | v | e | t | c | d |
|---|---|---|---|---|---|---|---|
| 次数 | 2 | 2 | 1 | 4 | 1 | 1 | 1 |
| first | 0 | 1 | **2** | 3 | 7 | 8 | 10 |

次数为 1 的有 `v(2) t(7) c(8) d(10)`，最小下标是 2。

### 代码

```c
int firstUniqChar(char* s) {
    int cnt[26] = {0};
    int first[26];                          // first[k]：字母 'a'+k 第一次出现的下标

    // 1. 一遍扫描：计数 + 记录首次出现的位置
    for (int i = 0; s[i] != '\0'; i++) {
        int k = s[i] - 'a';
        if (cnt[k] == 0) first[k] = i;      // 第一次见到这个字母
        cnt[k]++;
    }

    // 2. 只检查 26 个字母
    int ans = -1;
    for (int k = 0; k < 26; k++) {
        if (cnt[k] == 1 && (ans == -1 || first[k] < ans)) {
            ans = first[k];
        }
    }
    return ans;
}
```

> 💬 `first` 没有初始化也没关系：只有 `cnt[k] >= 1` 的字母才会读 `first[k]`，而它们一定在第一次出现时被赋值了。

### 复杂度分析

- **时间复杂度 O(n + 26)**：字符串只扫一遍，再看 26 个字母。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **两层循环暴力数次数** → O(n²)，n = 10⁵ 时超时。
2. **`cnt` 没有初始化** → `int cnt[26];` 是随机值。
3. **第二遍按字母顺序 `k = 0..25` 找** → 找到的是“字母表里最靠前的唯一字符”，不是“字符串里最靠前的”。比如 `"zab..."` 中 `z` 在前面，但会先找到 `a`。（思路二用 `first` 取最小值就是为了解决这个问题。）
4. **返回字符而不是下标** → 应该 `return i;` 而不是 `return s[i];`。
5. **把“不重复”理解成“和相邻字符不同”** → `"abca"` 中第一个唯一字符是 `b`（下标 1），不是 `a`。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 特点 |
|---|---|---|---|---|
| 两次遍历 | O(n) | O(1) | ⭐ | 最直观，推荐 |
| 记录首次位置 | O(n + 26) | O(1) | ⭐⭐ | 字符串只扫一遍 |

> 🎯 **学习建议**：两种方法复杂度相同，先写思路一。思路二的“只扫一遍”在**数据流**场景（字符一个一个到来、不能回头）时会很有用。
