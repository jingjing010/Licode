# 240. 搜索二维矩阵 II —— 小白详细题解

> 这道题的精髓是"**从右上角出发**"：每比较一次就能排除一整行或一整列。我们从暴力一路优化过去。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 有一个表格，**每一行从左到右越来越大**，**每一列从上到下越来越大**。问：`target` 这个数在不在表格里？

示例 1 的矩阵：

|  | 列0 | 列1 | 列2 | 列3 | 列4 |
|---|---|---|---|---|---|
| 行0 | 1 | 4 | 7 | 11 | 15 |
| 行1 | 2 | **5** | 8 | 12 | 19 |
| 行2 | 3 | 6 | 9 | 16 | 22 |
| 行3 | 10 | 13 | 14 | 17 | 24 |
| 行4 | 18 | 21 | 23 | 26 | 30 |

`target = 5` 在第 1 行第 1 列，返回 `true`；`target = 20` 找不到，返回 `false`。

**几个需要注意的细节：**

1. 只是**每行**、**每列**分别有序，整个矩阵按行拼起来**不是**有序的（比如第 0 行末尾是 15，第 1 行开头是 2）。所以不能把它当成一维有序数组做一次二分。
2. 返回值是 `bool`，写 `return true;` / `return false;`（本 OJ 已包含 `<stdbool.h>`）。
3. 矩阵最大 300×300，数值范围是整个 `±10^9`。

return true;

### 3. 二分查找的中点写法

```c
int mid = lo + (hi - lo) / 2;   // ✅ 推荐写法

```

## 💡 第三步：思路一 —— 暴力遍历 / 每行二分

### 暴力

把每个元素都看一遍，最多 `300 × 300 = 9 万`次比较，本题数据其实能过：

```c
bool searchMatrix(int** matrix, int matrixSize, int* matrixColSize, int target) {
    int m = matrixSize, n = matrixColSize[0];
    for (int i = 0; i < m; i++) {              // 每一行
        for (int j = 0; j < n; j++) {          // 每一列
            if (matrix[i][j] == target) {
                return true;                   // 找到就立刻返回
            }
        }
    }
    return false;                              // 全部看完都没有
}
```

- **时间复杂度 O(mn)**，**空间复杂度 O(1)**。完全没有用到"有序"这个条件。

### 每行二分

每一行都是有序的，那么在每一行里用**二分查找**：

```c
bool searchMatrix(int** matrix, int matrixSize, int* matrixColSize, int target) {
    int m = matrixSize, n = matrixColSize[0];
    for (int i = 0; i < m; i++) {
        int* row = matrix[i];                  // 当前这一行
        int lo = 0, hi = n - 1;                // 在 row[lo..hi] 里找
        while (lo <= hi) {
            int mid = lo + (hi - lo) / 2;
            if (row[mid] == target) {
                return true;
            } else if (row[mid] < target) {
                lo = mid + 1;                  // 中间的太小，往右半边找
            } else {
                hi = mid - 1;                  // 中间的太大，往左半边找
            }
        }
    }
    return false;
}
```

- **时间复杂度 O(m log n)**：每行二分 log n 次。
- **空间复杂度 O(1)**。

> 小优化：如果某一行的第一个数 `row[0] > target`，后面所有行的第一个数只会更大，可以直接结束循环。

## 🚀 第四步：思路二 —— 从右上角出发（Z 字形查找）

### 思路

站在**右上角**看：当前这个数是**它所在行的最大值**，同时是**它所在列的最小值**。

和 `target` 比较：

- **相等**：找到了！
- **当前数 > target**：这一列下面的数都比当前数还大，**整列都不可能**是答案 → 往**左**走一列
- **当前数 < target**：这一行左边的数都比当前数还小，**整行都不可能** → 往**下**走一行

每次比较都会排除一整行或一整列，最多走 `m + n` 步。

### 手动模拟（示例 1，`target = 5`）

| 步 | 位置 (r, c) | 当前数 | 比较 | 操作 |
|---|---|---|---|---|
| 1 | (0, 4) | 15 | 15 > 5 | 第 4 列排除，往左 |
| 2 | (0, 3) | 11 | 11 > 5 | 往左 |
| 3 | (0, 2) | 7 | 7 > 5 | 往左 |
| 4 | (0, 1) | 4 | 4 < 5 | 第 0 行排除，往下 |
| 5 | (1, 1) | 5 | 相等 | ✅ 返回 true |

再看 `target = 20`（找不到的情况）：

| 步 | 位置 | 当前数 | 操作 |
|---|---|---|---|
| 1 | (0,4) | 15 | 15 < 20，往下 |
| 2 | (1,4) | 19 | 19 < 20，往下 |
| 3 | (2,4) | 22 | 22 > 20，往左 |
| 4 | (2,3) | 16 | 16 < 20，往下 |
| 5 | (3,3) | 17 | 17 < 20，往下 |
| 6 | (4,3) | 26 | 26 > 20，往左 |
| 7 | (4,2) | 23 | 23 > 20，往左 |
| 8 | (4,1) | 21 | 21 > 20，往左 |
| 9 | (4,0) | 18 | 18 < 20，往下 → 出界，返回 false |

### 代码

```c
bool searchMatrix(int** matrix, int matrixSize, int* matrixColSize, int target) {
    int m = matrixSize, n = matrixColSize[0];
    int r = 0, c = n - 1;                 // 从右上角出发

    while (r < m && c >= 0) {             // 还没走出矩阵
        int cur = matrix[r][c];
        if (cur == target) {
            return true;                  // 找到了
        } else if (cur > target) {
            c--;                          // 当前列下面都更大，整列排除，往左
        } else {
            r++;                          // 当前行左边都更小，整行排除，往下
        }
    }
    return false;                         // 走出矩阵还没找到
}
```

### 复杂度分析

- **时间复杂度 O(m + n)**：每一步要么 `r++` 要么 `c--`，最多 `m + n` 步。
- **空间复杂度 O(1)**。

> 💬 **为什么不能从左上角出发？** 左上角是行最小、列最小，`cur < target` 时往右、往下都会变大，不知道该走哪边。右上角（或左下角）的两个方向一个变大、一个变小，才能做出唯一的选择。

---

## ⚠️ 第五步：小白常见错误

1. **从左上角或右下角出发** → 两个方向的变化趋势相同，无法判断往哪走。
2. **把整个矩阵当成一维有序数组做二分** → 这是"74. 搜索二维矩阵"的做法，本题行与行之间并不衔接，会漏掉答案。
3. **循环条件写成 `r < m || c >= 0`** → 一个下标出界了另一个还在循环，`matrix[r][c]` 越界崩溃。必须用 `&&`。
4. **把 `c = n - 1` 写成 `c = n`** → 第一次访问 `matrix[0][n]` 就越界。
5. **二分时写 `lo = mid` 或 `hi = mid`** → 可能陷入死循环（比如 `lo = 0, hi = 1` 时 `mid` 一直是 0）。
6. **找到后忘记 `return true`，只是 `break`** → 跳出循环后又执行到 `return false`。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力遍历 | O(mn) | O(1) | ⭐ | 没用到有序性 |
| 每行二分 | O(m log n) | O(1) | ⭐⭐ | 练习二分查找 |
| 右上角 Z 字形 | O(m + n) | O(1) | ⭐⭐ | 面试标准答案 |
