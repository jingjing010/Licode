# 1290. 二进制链表转整数 —— 小白详细题解

> 一道很好的"进制转换 + 链表遍历"入门题，顺便学会**位运算**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 链表从头到尾的 0/1 拼起来是一个二进制数（**最高位在前**），把它换算成十进制。

用示例 1（`[1,0,1]`）看看：

```
链表：      1  ->  0  ->  1
位权：     2^2    2^1    2^0
           (4)    (2)    (1)
十进制：  1×4 + 0×2 + 1×1 = 5
```

**几个需要注意的细节：**

1. 最高位在**链表头**，但我们一开始不知道链表有多长，也就不知道第一个结点的位权是 `2` 的几次方。
2. 最多 30 位，最大值是 `2^30 - 1 = 1073741823`，`int`（最大约 `2.1×10^9`）装得下。
3. 可能有前导 0，例如 `[0,0,0,1]` 表示 1。

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 遍历链表

```c
for (struct ListNode* p = head; p != NULL; p = p->next) {
    // p->val 依次是每个结点的值
}
```

### 2. "边读边算"的进制转换

十进制的例子：读入数字 `1`、`2`、`3`，

```
读到 1：ans = 0 × 10 + 1 = 1
读到 2：ans = 1 × 10 + 2 = 12
读到 3：ans = 12 × 10 + 3 = 123
```

每多读一位，原来的数整体"左移一位"（乘以进制），再加上新的一位。二进制就是把 `×10` 换成 `×2`。

### 3. 位运算：`<<` 和 `|`

- `x << 1`：二进制整体左移一位，右边补 0，等价于 `x * 2`。例如 `101 << 1 = 1010`。
- `x | 1`：把最低位设成 1。当最低位原本是 0 时，`x | bit` 等价于 `x + bit`。

所以 `ans * 2 + bit` 也可以写成 `(ans << 1) | bit`。

## 💡 第三步：思路一 —— 先求长度，再按位权相加

### 思路

1. 先遍历一遍求长度 `n`，第一个结点的位权就是 `2^(n-1)`
2. 再遍历一遍，每个为 1 的结点加上它的位权，位权每次除以 2

### 代码

```c
int getDecimalValue(struct ListNode* head) {
    // 1. 求链表长度
    int n = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) n++;

    // 2. 第一个结点的位权是 2^(n-1)
    int weight = 1;
    for (int i = 0; i < n - 1; i++) weight *= 2;

    // 3. 从高位到低位累加
    int ans = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) {
        if (p->val == 1) ans += weight;   // 这一位是 1，加上它的位权
        weight /= 2;                      // 下一位的位权减半
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：遍历两遍。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 边读边算，一次遍历（最优）

### 思路

用"读一位，乘 2 加一位"的方法，不需要知道长度。

### 手动模拟（示例 1：`[1,0,1]`）

| 读到的位 | 计算 | ans（十进制） | ans（二进制） |
|---|---|---|---|
| 开始 | - | 0 | 0 |
| 1 | 0 × 2 + 1 | 1 | 1 |
| 0 | 1 × 2 + 0 | 2 | 10 |
| 1 | 2 × 2 + 1 | 5 | 101 |

### 代码

```c
int getDecimalValue(struct ListNode* head) {
    int ans = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) {
        ans = ans * 2 + p->val;          // 原来的数左移一位，再加上新的一位
    }
    return ans;
}
```

位运算版本（效果完全一样）：

```c
int getDecimalValue(struct ListNode* head) {
    int ans = 0;
    for (struct ListNode* p = head; p != NULL; p = p->next) {
        ans = (ans << 1) | p->val;       // 左移一位，把新的一位放进最低位
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：只遍历一遍。
- **空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **把最后一个结点当最高位**：写成 `ans += p->val * (1 << i)`（`i` 从 0 开始），等于把二进制数倒过来读，`[1,1,0]` 会得到 3 而不是 6。
2. **用 `pow(2, i)` 计算位权**：`pow` 返回 `double`，存在精度和类型转换的隐患；整数运算用 `<<` 或乘法更安全。
3. **位运算没加括号**：`ans << 1 | p->val` 虽然这里优先级碰巧正确（`<<` 高于 `|`），但 `ans << 1 + p->val` 就会被理解成 `ans << (1 + p->val)`。养成加括号的习惯。
4. **`ans` 没有初始化为 0**：局部变量的初始值是随机的，结果不可预测。
5. **担心溢出而用 `long long` 又用 `%d` 打印**：本题最多 30 位，`int` 足够；返回类型要和函数签名一致。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 先求长度再按位权加 | O(n)，两遍 | O(1) | ⭐ | 符合"按位权展开"的定义 |
| 边读边算（乘 2 加） | O(n)，一遍 | O(1) | ⭐ | **推荐** |
