# Q15 饱和乘法：题解

## 📖 先读懂题目

输入为Q15原始int16整数，返回trunc(a*b/32768)并限制在−32768..32767，负数向零截断。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `16384 / 16384` | `8192` |
| 2 | `-32768 / -32768` | `32767` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

Q15乘积有30位小数，除32768恢复15位小数；−1乘−1会得到无法表示的+1，需要饱和到32767。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int q15Multiply(int a, int b) {
    int32_t scaled = (int32_t)a * b / 32768;
    if (scaled > 32767)
        return 32767;
    if (scaled < -32768)
        return -32768;
    return scaled;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
