# 867. 转置矩阵 —— 小白详细题解

> 题目本身一句话就能说完，难点全在 C 语言：**如何 `malloc` 一个二维数组并正确返回**。

---

## 📖 第一步：先读懂题目

转置 = **行变列、列变行**。原来第 `i` 行第 `j` 列的数，转置后跑到第 `j` 行第 `i` 列。

拿示例 2 来说（2 行 3 列 → 3 行 2 列）：

```
原矩阵 (2×3)        转置后 (3×2)
1 2 3               1 4
4 5 6      →        2 5
                    3 6
```

| 原位置 | 值 | 新位置 |
|---|---|---|
| (0,0) | 1 | (0,0) |
| (0,1) | 2 | (1,0) |
| (0,2) | 3 | (2,0) |
| (1,0) | 4 | (0,1) |
| (1,1) | 5 | (1,1) |
| (1,2) | 6 | (2,1) |

**关键细节：**

1. `m` 行 `n` 列的矩阵，转置后是 **`n` 行 `m` 列**。形状变了！
2. 矩阵**不一定是方阵**，所以不能在原矩阵上原地交换，必须申请一个新矩阵。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用 `malloc` 申请二维数组（"指针数组"写法）

`int**` 是"指向 `int*` 的指针"，可以理解为"**一排行指针**"：

```c
int** ans = (int**)malloc(sizeof(int*) * rows);     // 第 1 步：申请 rows 个"行指针"
for (int r = 0; r < rows; r++) {
    ans[r] = (int*)malloc(sizeof(int) * cols);      // 第 2 步：给每一行申请 cols 个 int
}
ans[r][c] = 5;                                      // 之后就能像二维数组一样使用
```

```
ans ──→ [ ans[0] ] ──→ [ □ □ □ ]   ← 第 0 行
        [ ans[1] ] ──→ [ □ □ □ ]   ← 第 1 行
```

> ⚠️ 第一步是 `sizeof(int*)`（指针的大小），第二步是 `sizeof(int)`（整数的大小）。在 64 位系统上指针占 8 字节、`int` 占 4 字节，写错了会导致内存不够、越界写坏数据。

### 2. 返回二维数组的三件套

| 要做的事 | 本题写法 |
|---|---|
| 返回矩阵 | `return ans;` |
| 行数 | `*returnSize = n;`（转置后的行数是原来的**列数**） |
| 每行列数 | `*returnColumnSizes = malloc(n 个 int)`，每个都填 `m` |

### 3. 数值范围

元素在 `±10^9` 之间，只是搬运不做计算，用 `int` 没问题。

---

## 💡 第三步：思路 —— 新建矩阵，按位置搬运

### 思路

1. 读出原矩阵的行数 `m = matrixSize`、列数 `n = matrixColSize[0]`。
2. 申请一个 `n` 行、每行 `m` 个元素的新矩阵 `ans`。
3. 双重循环：`ans[j][i] = matrix[i][j]`。
4. 设置 `*returnSize = n`，`*returnColumnSizes` 每项为 `m`。

### 代码

```c
int** transpose(int** matrix, int matrixSize, int* matrixColSize, int* returnSize, int** returnColumnSizes) {
    int m = matrixSize;          // 原矩阵行数
    int n = matrixColSize[0];    // 原矩阵列数

    // 1. 申请转置后的矩阵：n 行，每行 m 个数
    int** ans = (int**)malloc(sizeof(int*) * n);
    *returnColumnSizes = (int*)malloc(sizeof(int) * n);   // 每行的列数
    for (int j = 0; j < n; j++) {
        ans[j] = (int*)malloc(sizeof(int) * m);
        (*returnColumnSizes)[j] = m;                     // 转置后每行都有 m 列
    }

    // 2. 搬运：原来的 (i, j) 放到 (j, i)
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            ans[j][i] = matrix[i][j];
        }
    }

    // 3. 告诉调用者结果有几行
    *returnSize = n;
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(mn)**：每个元素搬运一次。
- **空间复杂度 O(1)**（不算返回的结果矩阵）。

> 💬 本题没有"更优"的算法：每个元素至少要被搬一次，O(mn) 已经是最优。

---

## 🚀 第四步：补充 —— 方阵可以原地转置

如果题目保证 `m == n`（方阵），可以不申请新矩阵，只交换主对角线**上方**的元素和**下方**对称的元素：

```c
// 仅适用于方阵的示意代码 ...
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++) {     // 只遍历上三角，否则会换两次又换回去
        int t = matrix[i][j];
        matrix[i][j] = matrix[j][i];
        matrix[j][i] = t;
    }
```

本题矩阵可能不是方阵（示例 2 是 2×3），所以不能用这个方法。这个技巧在 **48. 旋转图像** 里会用到。

---

## ⚠️ 第五步：小白常见错误

1. **新矩阵的形状写成 `m × n`** → 非方阵时行列数错了，访问 `ans[j]` 会越界。转置后是 `n × m`。
2. **`*returnSize = m`** → 行数应该是原来的列数 `n`。示例 2 会只输出 2 行。
3. **第一层 `malloc` 用了 `sizeof(int)`** → 64 位下指针 8 字节，空间只够一半，后面的行指针写到别人的内存里，随机崩溃。
4. **在原矩阵上原地交换** → 非方阵根本放不下（2×3 的矩阵没有"第 2 行"可以放 `(2,0)`）。
5. **返回局部数组** `int ans[1000][1000];` → 函数结束后内存失效，而且 4MB 的局部数组会直接栈溢出。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 额外空间 | 适用 |
|---|---|---|---|
| 新建矩阵搬运 | O(mn) | O(mn)（结果本身） | 任意矩阵 ✅ 本题 |
| 原地交换上三角 | O(n²) | O(1) | 仅方阵 |
