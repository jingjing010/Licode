给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵 **平衡** 二叉搜索树。

**平衡二叉树** 是指该树所有节点的左右子树的高度相差不超过 1。

### 示例 1

```
      0                 0
     / \               / \
   -3   9      或    -10   5
   /   /               \    \
 -10  5                -3    9
```

```
输入：nums = [-10,-3,0,5,9]
输出：true
解释：[0,-3,9,-10,null,5] 是一个答案，[0,-10,5,null,-3,null,9] 也将被视为正确答案。
（力扣原题输出一棵树；本 OJ 由判题程序检查你的树是否合法，合法则输出 true，见下方说明）
```

### 示例 2

```
  3        1
 /    或    \
1            3
```

```
输入：nums = [1,3]
输出：true
解释：[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。
```

### 提示

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 按 **严格递增** 顺序排列

### 函数说明

```c
struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

struct TreeNode* sortedArrayToBST(int* nums, int numsSize);
```

- `struct TreeNode` 已由系统定义，**不要**在代码里重复定义
- `nums`：升序数组，`numsSize`：数组长度
- 返回值：你构造的树的根结点，每个结点都要用 `malloc` 申请

### 自定义输入格式

```
[-10,-3,0,5,9]
```

只有 1 行：数组 `nums`。

**关于输出：** 本题的正确答案不唯一，所以判题程序不直接比较树的形状，而是检查你返回的树是否同时满足：

1. 树中恰好有 `numsSize` 个结点，且中序遍历结果与 `nums` 完全相同（这保证它是由 `nums` 构成的二叉搜索树）；
2. 每个结点的左右子树高度差不超过 1（高度平衡）。

全部满足输出 `true`，否则输出 `false`。
