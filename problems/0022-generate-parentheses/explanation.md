# 22. 括号生成 —— 小白详细题解

> 这道题是「回溯 + 剪枝」的经典入门：先学会暴力枚举再筛选，再学会「边生成边检查」，把不合法的分支提前砍掉。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你 `n` 对括号，也就是 `n` 个 `(` 和 `n` 个 `)`，把它们排成一行，列出所有**合法**的排法。

什么叫合法？就像数学算式里的括号：每个 `)` 都必须能和它**左边**某个还没配对的 `(` 配成一对。

| 串（n = 2） | 合法吗？ | 原因 |
|---|---|---|
| `(())` | ✅ | 外层一对包着里层一对 |
| `()()` | ✅ | 两对并排 |
| `)(()` | ❌ | 第 1 个 `)` 左边没有 `(` |
| `(()(` | ❌ | 结尾还剩两个 `(` 没配对 |
| `))((` | ❌ | 一开始就出错 |

所以 `n = 2` 的答案是 `["(())","()()"]`，`n = 3` 有 5 个（示例 1）。

**几个需要注意的细节：**

1. 每个答案的长度都是 `2n`。
2. 合法括号串的个数叫「卡特兰数」：n = 1, 2, 3, …, 8 时分别是 1, 2, 5, 14, 42, 132, 429, **1430**。
3. 顺序任意，判题时会排序。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 怎么判断一个括号串合法？——「余额」法

从左往右扫，把 `(` 当成「存 1 块钱」，`)` 当成「花 1 块钱」：

- 过程中**余额不能变成负数**（花的钱比存的多，说明某个 `)` 找不到配对）；
- 扫完后**余额必须正好是 0**（所有 `(` 都配上了）。

| 串 | 每一步的余额 | 结果 |
|---|---|---|
| `(())` | 1 → 2 → 1 → 0 | ✅ |
| `)(()` | -1 ❌ | 中途为负 |
| `(()(` | 1 → 2 → 1 → 2 | 最后不是 0 ❌ |

### 2. 返回字符串数组 `char**`

- 外层 `malloc(sizeof(char*) * 个数)`；
- 每个字符串 `malloc(2 * n + 1)`：`2n` 个括号 + 1 个结尾的 `'\0'`；
- 个数写进 `*returnSize`。

### 3. 用二进制数表示一个括号串

长度为 `2n` 的括号串，每位只有两种可能，正好对应一个 `2n` 位二进制数：第 `i` 位是 1 就放 `(`，是 0 就放 `)`。`mask` 从 `0` 数到 `2^(2n) - 1` 就能枚举所有串。

---

## 💡 第三步：思路一 —— 暴力枚举所有串，再逐个检查

### 思路

1. 枚举 `mask = 0 .. 2^(2n) - 1`，把它翻译成一个括号串；
2. 用「余额」法检查是否合法；
3. 合法的就复制进答案。

`n = 8` 时一共 2¹⁶ = 65536 个串，每个检查 16 位，约 100 万次操作，完全不会超时。

### 手动模拟（n = 1，2 位二进制）

| mask | 二进制（第 0、1 位） | 串 | 余额变化 | 合法？ |
|---|---|---|---|---|
| 0 | 0 0 | `))` | -1 | ❌ |
| 1 | 1 0 | `()` | 1 → 0 | ✅ |
| 2 | 0 1 | `)(` | -1 | ❌ |
| 3 | 1 1 | `((` | 1 → 2 | ❌ 最后不是 0 |

### 代码

```c
char** generateParenthesis(int n, int* returnSize) {
    int len = 2 * n;
    char** res = (char**)malloc(sizeof(char*) * 1430);   // n <= 8 时最多 1430 个
    char buf[17];                                       // 最多 16 个括号 + '\0'
    *returnSize = 0;

    for (int mask = 0; mask < (1 << len); mask++) {
        // 1. 把 mask 翻译成括号串，同时计算余额
        int balance = 0;
        int ok = 1;
        for (int i = 0; i < len; i++) {
            if ((mask >> i) & 1) {          // 第 i 位是 1：左括号
                buf[i] = '(';
                balance++;
            } else {                        // 第 i 位是 0：右括号
                buf[i] = ')';
                balance--;
            }
            if (balance < 0) {              // 右括号多了，不合法
                ok = 0;
                break;
            }
        }
        // 2. 合法的条件：中途没出错，并且最后余额为 0
        if (ok && balance == 0) {
            buf[len] = '\0';
            res[*returnSize] = (char*)malloc(len + 1);
            strcpy(res[*returnSize], buf);
            (*returnSize)++;
        }
    }
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n · 4ⁿ)**：一共 2²ⁿ = 4ⁿ 个串，每个检查 O(n)。
- **空间复杂度 O(n)**：一个缓冲区（答案本身不算）。

> 💬 这个方法慢在哪？大部分串在第一位就是 `)`，注定不合法，但我们还是把它整个生成了出来。

## 🚀 第四步：思路二 —— 回溯：边放边检查（剪枝）

### 思路

一位一位地往 `path` 里放括号，并时刻记住已经放了几个 `(`（`open`）和几个 `)`（`close`）：

1. **能放 `(` 的条件**：`open < n`（左括号总共只有 n 个）；
2. **能放 `)` 的条件**：`close < open`（必须有还没配对的 `(`，也就是「余额」大于 0）；
3. 放满 `2n` 个时，这个串**一定合法**，直接记录。

这样不合法的串根本不会被生成出来——这就叫**剪枝**。

### 手动模拟（n = 2）

| path | open | close | 能放 `(`？ | 能放 `)`？ |
|---|---|---|---|---|
| `` | 0 | 0 | ✅ | ❌（没有可配对的） |
| `(` | 1 | 0 | ✅ | ✅ |
| `((` | 2 | 0 | ❌（用完了） | ✅ |
| `(()` | 2 | 1 | ❌ | ✅ |
| `(())` | 2 | 2 | 满了，**记录** ✅ | |
| 回到 `(`，改放 `)` → `()` | 1 | 1 | ✅ | ❌ |
| `()(` | 2 | 1 | ❌ | ✅ |
| `()()` | 2 | 2 | 满了，**记录** ✅ | |

只走了必要的分支，就得到了全部 2 个答案。

### 代码

```c
// open / close：已经放了几个左 / 右括号；path：正在拼的串
void dfs(int n, int open, int close, char* path, char** res, int* cnt) {
    int len = open + close;                 // 已经放了几个括号
    if (len == 2 * n) {                     // 放满了，一定合法
        res[*cnt] = (char*)malloc(2 * n + 1);
        strcpy(res[*cnt], path);            // path[2n] 已经提前放好了 '\0'
        (*cnt)++;
        return;
    }
    if (open < n) {                         // 左括号还没用完，可以放 '('
        path[len] = '(';
        dfs(n, open + 1, close, path, res, cnt);
    }
    if (close < open) {                     // 有没配对的 '('，可以放 ')'
        path[len] = ')';
        dfs(n, open, close + 1, path, res, cnt);
    }
}

char** generateParenthesis(int n, int* returnSize) {
    char** res = (char**)malloc(sizeof(char*) * 1430);  // n <= 8 时最多 1430 个
    char path[17];
    path[2 * n] = '\0';                                 // 先把结尾放好
    *returnSize = 0;
    dfs(n, 0, 0, path, res, returnSize);
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(4ⁿ / √n)**：只生成合法串，个数是卡特兰数，约为 4ⁿ / (n√n)，每个复制 O(n)。
- **空间复杂度 O(n)**：递归深度 2n。

---

## ⚠️ 第五步：小白常见错误

1. **放 `)` 的条件写成 `close < n`**：会生成 `)(` 这种开头就错的串。正确的是 `close < open`。
2. **只检查「左右括号个数相等」**：`)(` 和 `())(` 个数都相等，但不合法；还要保证**中途余额不为负**。
3. **字符串没有 `'\0'`**：`malloc(2 * n)` 少一个字节，或者忘了写结尾，打印出乱码。
4. **结果数组开小了**：比如只开 `n` 行或 `2n` 行，n = 8 时有 1430 个答案，越界崩溃。
5. **思路一里 `1 << len` 写成 `1 << n`**：只枚举了一半的位数，串的后半段全是垃圾值。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 额外空间 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力枚举 + 检查 | O(n · 4ⁿ) | O(n) | ⭐⭐ | 先理解「怎样算合法」 |
| 回溯 + 剪枝 | O(4ⁿ / √n) | O(n) 递归栈 | ⭐⭐ | 标准答案，必须掌握 |

> 🎯 **学习建议**：「先暴力枚举再筛选」→「把筛选条件提前到生成过程中」，这是从暴力到回溯剪枝最典型的优化思路。
