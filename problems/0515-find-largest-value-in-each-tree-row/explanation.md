# 515. 在每个树行中找最大值 —— 小白详细题解

> 层序遍历模板的直接应用。真正要小心的是**最大值的初始值**：结点值可以是 -2³¹。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把树一层一层看，每一层挑出最大的那个数，按从上到下的顺序组成数组返回。

示例 1：`[1,3,2,5,3,null,9]`

```
          1         ← 第 0 层
         / \
        3   2       ← 第 1 层
       / \   \
      5   3   9     ← 第 2 层
```

| 层 | 这一层的值 | 最大值 |
|---|---|---|
| 0 | 1 | 1 |
| 1 | 3, 2 | 3 |
| 2 | 5, 3, 9 | 9 |

答案 `[1,3,9]`。

**几个需要注意的细节：**

1. 空树返回空数组，`*returnSize = 0`。
2. 值的范围是整个 `int`：`-2147483648` ~ `2147483647`。如果某一层全是负数，最大值也是负数——初始值写成 `0` 就错了。
3. 最多 10⁴ 个结点，层数最多 10⁴（链状）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `INT_MIN`

`<limits.h>`（本 OJ 已包含）里定义了 `INT_MIN = -2147483648`、`INT_MAX = 2147483647`。求最大值时把初始值设为 `INT_MIN`，任何 `int` 都 ≥ 它。

另一种安全的写法：**用这一层第一个结点的值作为初始值**。

### 2. 返回数组 + `*returnSize`

```c
int* res = (int*)malloc(sizeof(int) * 最多层数);
*returnSize = 层数;
```

### 3. 用数组模拟队列，按层处理

```c
int size = tail - head;          // 这一层有几个结点（先记下来！）
for (int i = 0; i < size; i++) { 出队、处理、孩子入队 }
```

---

## 💡 第三步：思路一 —— 层序遍历（BFS）

### 思路

套用第 102 题的模板：

1. 根入队。
2. 每轮先记下 `size = tail - head`，这就是这一层的结点数。
3. 出队 `size` 个结点，一边更新这一层的最大值 `mx`，一边把孩子入队。
4. 这一层处理完，把 `mx` 写进答案。

### 手动模拟（示例 1）

| 轮次 | 本层结点 | mx 的变化 | 入队 | res |
|---|---|---|---|---|
| 1 | 1 | INT_MIN → 1 | 3, 2 | [1] |
| 2 | 3, 2 | → 3 → 3 | 5, 3, 9 | [1,3] |
| 3 | 5, 3, 9 | → 5 → 5 → 9 | 无 | [1,3,9] |

### 代码

```c
int* largestValues(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 10000);   // 层数最多 10^4
    int cnt = 0;
    *returnSize = 0;
    if (root == NULL) return res;                   // 空树

    struct TreeNode** q = (struct TreeNode**)malloc(sizeof(struct TreeNode*) * 10000);
    int head = 0, tail = 0;
    q[tail++] = root;
    while (head < tail) {
        int size = tail - head;          // 这一层的结点数
        int mx = INT_MIN;                // 不能是 0：这一层可能全是负数
        for (int i = 0; i < size; i++) {
            struct TreeNode* node = q[head++];
            if (node->val > mx) mx = node->val;
            if (node->left) q[tail++] = node->left;
            if (node->right) q[tail++] = node->right;
        }
        res[cnt++] = mx;                 // 这一层的最大值
    }
    free(q);
    *returnSize = cnt;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点入队出队各一次。
- **空间复杂度 O(n)**：队列。

## 🚀 第四步：思路二 —— DFS 带着深度

### 思路

DFS 也能"按层"收集信息：递归时把当前深度 `d` 传下去。

- 如果 `d == 当前已有的层数`，说明是**第一次**到达第 `d` 层 → 直接把 `node->val` 作为这层的最大值写进去（顺便解决了"初始值"的问题）。
- 否则这一层已经有值了，取较大的。

### 手动模拟（示例 1，前序遍历）

| 访问 | 深度 d | 已有层数 | 操作 | res |
|---|---|---|---|---|
| 1 | 0 | 0 | 新层，写入 | [1] |
| 3 | 1 | 1 | 新层，写入 | [1,3] |
| 5 | 2 | 2 | 新层，写入 | [1,3,5] |
| 3 | 2 | 3 | max(5,3) | [1,3,5] |
| 2 | 1 | 3 | max(3,2) | [1,3,5] |
| 9 | 2 | 3 | max(5,9) | [1,3,9] |

### 代码

```c
static void dfs(struct TreeNode* node, int d, int* res, int* cnt) {
    if (node == NULL) return;
    if (d == *cnt) {                    // 第一次到达第 d 层
        res[(*cnt)++] = node->val;
    } else if (node->val > res[d]) {    // 这层已有值，取较大的
        res[d] = node->val;
    }
    dfs(node->left, d + 1, res, cnt);
    dfs(node->right, d + 1, res, cnt);
}

int* largestValues(struct TreeNode* root, int* returnSize) {
    int* res = (int*)malloc(sizeof(int) * 10000);
    int cnt = 0;
    dfs(root, 0, res, &cnt);
    *returnSize = cnt;
    return res;
}
```

> 为什么 `d` 最多比 `*cnt` 大不了？因为要到达第 `d` 层，一定先经过了第 `d-1` 层，所以第一次到达第 `d` 层时恰好 `*cnt == d`。

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(h)**（递归栈）。

---

## ⚠️ 第五步：小白常见错误

1. **最大值初始化为 0**：
   ```c
   int mx = 0;   // ❌ 一层全是负数时，结果错成 0
   ```
   用 `INT_MIN` 或者这一层第一个结点的值。
2. **用 `-2147483648` 字面量**：在 C 里这其实是"对 2147483648 取负"，而 2147483648 超出了 `int`，会被当成更大的类型，有时还会产生警告。直接用 `INT_MIN`。
3. **没先记下 `size`**：`for (i = 0; i < tail - head; i++)` 循环中 `tail` 在变，不同层混在一起。
4. **空树时 `*returnSize` 没赋值**：输出了随机长度的垃圾数据。
5. **DFS 时用 `d > *cnt` 判断新层**：永远不成立（`d` 最多等于 `*cnt`），所有层都写不进去。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| BFS 按层 | O(n) | O(n) | ⭐ | **首选**，"每层做点什么"的标准写法 |
| DFS 带深度 | O(n) | O(h) | ⭐⭐ | 学会"用深度当下标"的技巧 |
