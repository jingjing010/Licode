# 45. 跳跃游戏 II —— 小白详细题解

> 这是「55. 跳跃游戏」的升级版：上一题问"能不能跳到"，这一题问"**最少**跳几次"。我们先用动态规划把它做对，再用"按层扩展"的贪心把它做快。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 你站在数组的第 0 格。每一格上的数字表示"从这里**最多**能往右跳几格"（可以少跳，也可以原地不动）。问：最少跳几次能到达最后一格？

拿示例 1 `nums = [2,3,1,1,4]` 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 数值 | 2 | 3 | 1 | 1 | 4 |
| 从这里能跳到 | 1~2 | 2~4 | 3 | 4 | — |

- 方案 A：0 → 2 → 3 → 4，跳 3 次。
- 方案 B：0 → 1 → 4，跳 **2** 次 ✅（最少）。

**几个需要注意的细节：**

1. `nums[i]` 是**最大**跳跃长度，跳 1 格、2 格……都可以。
2. 题目**保证一定能到达**最后一格，不用处理"到不了"的情况。
3. 数组只有 1 个元素时，你已经站在终点了，答案是 **0**。
4. 跳到最后一格就结束，不需要"跳出"数组。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 数组参数 + 长度

```c
int jump(int* nums, int numsSize)
```

C 语言的数组传进函数后只剩一个首地址，**不知道自己多长**，所以要额外传 `numsSize`。访问 `nums[i]` 前要保证 `0 <= i < numsSize`。

### 2. 用 `malloc` 申请 dp 数组

数组长度要到运行时才知道，所以用 `malloc`：

```c
int* dp = (int*)malloc(sizeof(int) * numsSize);  // 申请 numsSize 个 int
...
free(dp);                                        // 用完记得释放
```

### 3. "无穷大"的表示

求最小值时，初始值要设成一个"很大"的数。可以用 `<limits.h>` 里的 `INT_MAX`，但要小心 `INT_MAX + 1` 会**溢出**变成负数。本题最多跳 `n - 1` 次，所以用 `numsSize` 当"无穷大"就足够安全。

---

## 💡 第三步：思路一 —— 动态规划（最容易想到）

### 思路

设 `dp[j]` = "跳到下标 `j` 最少需要几次"。

- 起点 `dp[0] = 0`。
- 站在 `i` 上，能跳到 `i+1 ~ i+nums[i]` 中的任意一格 `j`，于是 `dp[j]` 可以用 `dp[i] + 1` 来更新。
- 从左往右依次处理每个 `i`，最后答案就是 `dp[n-1]`。

### 手动模拟（示例 1：`nums = [2,3,1,1,4]`）

初始 `dp = [0, ∞, ∞, ∞, ∞]`

| 当前 i | nums[i] | 能更新的 j | 更新后 dp |
|---|---|---|---|
| 0 | 2 | 1, 2 | [0, 1, 1, ∞, ∞] |
| 1 | 3 | 2, 3, 4 | [0, 1, 1, 2, 2] |
| 2 | 1 | 3 | [0, 1, 1, 2, 2]（2 不比 2 小，不变） |
| 3 | 1 | 4 | [0, 1, 1, 2, 2] |

答案 `dp[4] = 2`。

### 代码

```c
int jump(int* nums, int numsSize) {
    // dp[j]：跳到下标 j 的最少次数
    int* dp = (int*)malloc(sizeof(int) * numsSize);
    dp[0] = 0;
    for (int j = 1; j < numsSize; j++) {
        dp[j] = numsSize;                 // 用 numsSize 当"无穷大"（最多只需要 n-1 次）
    }

    for (int i = 0; i < numsSize; i++) {
        // 从 i 出发，能跳到 i+1 到 i+nums[i] 之间的任意一格（不能超出数组）
        for (int k = 1; k <= nums[i] && i + k < numsSize; k++) {
            if (dp[i] + 1 < dp[i + k]) {
                dp[i + k] = dp[i] + 1;    // 经过 i 再跳一次更少，就更新
            }
        }
    }

    int ans = dp[numsSize - 1];
    free(dp);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n × max(nums))**：每个 `i` 最多往后看 `nums[i]` 格。本题 n ≤ 10⁴、nums[i] ≤ 1000，最坏约 10⁷ 次，能过。
- **空间复杂度 O(n)**：dp 数组。

## 🚀 第四步：思路二 —— 贪心（按层扩展，像 BFS）

### 思路

观察一个关键性质：**跳 k 次能到达的位置，一定是一段连续的区间**。

- 跳 0 次：只能在 `[0, 0]`。
- 跳 1 次：能到 `[1, 0 + nums[0]]`。
- 跳 2 次：从第 1 层区间里的每一格出发，能到的最远位置记为 `far`，那么第 2 层是 `[上一层末尾+1, far]`。
- ……

这就像 BFS 一层一层往外扩。我们只需要维护三个变量：

| 变量 | 含义 |
|---|---|
| `end` | 当前这一层（已跳 `steps` 次）能到的最远边界 |
| `far` | 扫描当前层时，"再跳一次"最远能到哪 |
| `steps` | 已经跳了几次 |

从左往右扫描 `i`，不断更新 `far = max(far, i + nums[i])`；当 `i` 走到 `end` 时，说明当前层扫完了，**必须再跳一次**，`steps++`，并把 `end` 更新为 `far`。

> ❓ **为什么循环只到 `n - 2`？** 因为到达最后一格就结束了。如果 `i` 扫到 `n - 1` 并且恰好 `i == end`，会多算一次"从终点再起跳"。

### 手动模拟（示例 1：`nums = [2,3,1,1,4]`）

| i | nums[i] | far = max(far, i+nums[i]) | i == end？ | steps | end |
|---|---|---|---|---|---|
| 初始 | | 0 | | 0 | 0 |
| 0 | 2 | 2 | 是 → 跳 | 1 | 2 |
| 1 | 3 | 4 | 否 | 1 | 2 |
| 2 | 1 | 4 | 是 → 跳 | 2 | 4 |
| 3 | 1 | 4 | 否 | 2 | 4 |

循环结束（只到 i = 3），答案 `steps = 2`。

### 代码

```c
int jump(int* nums, int numsSize) {
    int steps = 0;   // 已经跳了几次
    int end = 0;     // 当前这一跳能覆盖到的最远下标
    int far = 0;     // 再跳一次最远能到的下标

    // 注意只到 numsSize - 2：站到最后一格就不用再跳了
    for (int i = 0; i < numsSize - 1; i++) {
        if (i + nums[i] > far) {
            far = i + nums[i];        // 更新"下一跳"的最远位置
        }
        if (i == end) {               // 当前这一跳的范围走完了
            steps++;                  // 必须再跳一次
            end = far;                // 新的覆盖范围
        }
    }
    return steps;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：只扫描一遍。
- **空间复杂度 O(1)**：只用了 3 个变量。

---

## ⚠️ 第五步：小白常见错误

1. **循环写成 `i < numsSize`** → 当最后一格恰好是某层的边界时会多跳一次。例如 `[1,2]`：i=0 时跳一次 end=1；如果继续到 i=1，又满足 `i == end`，答案变成 2（正确是 1）。
2. **数组只有一个元素时返回 1** → `[0]` 已经在终点，答案是 0。贪心写法中循环一次都不执行，天然返回 0。
3. **dp 写法中 `i + k` 越界** → 内层循环条件必须同时写 `k <= nums[i] && i + k < numsSize`，否则 `[1000]` 这种数据会写到数组外面。
4. **用 `INT_MAX` 当无穷大又做 `+1`** → `dp[i] + 1` 在 `dp[i] == INT_MAX` 时溢出成负数，反而成了"最小值"。
5. **贪心时每走一格就 `steps++`** → 那是在数"走了几格"，不是"跳了几次"。只有当前层走完（`i == end`）才需要跳。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 动态规划 | O(n × max(nums)) | O(n) | ⭐⭐ | 先写对，理解"最少步数"的递推 |
| 贪心（按层扩展） | O(n) | O(1) | ⭐⭐⭐ | 面试推荐答案 |
