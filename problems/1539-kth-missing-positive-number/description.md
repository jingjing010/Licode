# 第 k 个缺失的正整数

给定严格递增正整数数组，返回未出现在其中的第k个正整数。1 ≤ 数组长度,k ≤ 1000，元素 ≤ 1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int findKthPositive(int* arr,int arrSize,int k);
```

## 示例 1

输入：
```text
[2,3,4,7,11]
5
```
输出：
```text
9
```

## 示例 2

输入：
```text
[1,2,3,4]
2
```
输出：
```text
6
```

## 自定义输入格式

按顺序每行一个参数：arr、k。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
