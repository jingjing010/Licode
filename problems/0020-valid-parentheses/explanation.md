# 20. 有效的括号 —— 小白详细题解

> "栈"这种数据结构的入门第一题。理解了它，后面的计算器、单调栈、字符串解码都是同一个套路。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一串只由 `()[]{}` 组成的字符串，判断这些括号能不能**一对一、按顺序、同类型**地配上对。

| 字符串 | 结果 | 原因 |
|---|---|---|
| `"()"` | true | 一对小括号 |
| `"()[]{}"` | true | 三对并排 |
| `"(]"` | false | 类型不匹配 |
| `"([])"` | true | 中括号嵌在小括号里 |
| `"([)]"` | false | 个数都对，但 `)` 遇到的最近的左括号是 `[`，顺序交叉了 |

**几个需要注意的细节：**

1. **只数个数是不够的**：`"([)]"` 每种括号个数都相等，但它是无效的。
2. 以右括号开头（如 `")("`）一定无效：右括号前面没有可以配对的左括号。
3. 左括号多了（如 `"(("`）也无效：最后还有没配对的。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 字符串和 `'\0'`

C 语言的字符串是一个 `char` 数组，最后有一个看不见的结束符 `'\0'`。遍历方式有两种：

```c
for (int i = 0; s[i] != '\0'; i++) { ... }   // 一直走到结束符
int n = strlen(s);                           // 或者先求长度（<string.h>）
```

### 2. 用数组模拟栈

C 没有现成的栈，用"数组 + 栈顶下标"就能模拟：

```c
char stack[10001];
int top = 0;                 // top 表示栈里有几个元素
stack[top++] = c;            // 压栈：放到 top 位置，然后 top 加 1
char x = stack[--top];       // 弹栈：top 先减 1，再取出
char peek = stack[top - 1];  // 看栈顶（不弹出），前提是 top > 0
```

### 3. 字符用单引号

`'('` 是一个字符，`"("` 是一个字符串（两个字节：`'('` 和 `'\0'`）。比较字符要写 `c == '('`。

---

## 💡 第三步：思路一 —— 反复删除相邻的一对（最容易想到）

### 思路

有效的括号串里，一定存在**相邻的** `()`、`[]` 或 `{}`。把它删掉后剩下的仍然有效。所以反复删，删到删不动为止：最后变成空串就是有效的。

| 轮次 | 字符串 | 删掉 |
|---|---|---|
| 0 | `{[()]}` | `()` |
| 1 | `{[]}` | `[]` |
| 2 | `{}` | `{}` |
| 3 | `` | 空了 → true |

### 代码

```c
bool isValid(char* s) {
    int n = strlen(s);
    char* buf = (char*)malloc(n + 1);    // 复制一份，不改原串
    strcpy(buf, s);
    bool changed = true;
    while (changed) {
        changed = false;
        int len = 0;                     // 新串长度
        for (int i = 0; buf[i] != '\0'; i++) {
            char a = buf[i], c = buf[i + 1];
            if ((a == '(' && c == ')') || (a == '[' && c == ']') || (a == '{' && c == '}')) {
                i++;                     // 跳过这一对（两个字符）
                changed = true;
            } else {
                buf[len++] = a;          // 保留这个字符
            }
        }
        buf[len] = '\0';
    }
    bool ok = (buf[0] == '\0');          // 删空了就有效
    free(buf);
    return ok;
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：最坏情况（如 `((((...))))`）每轮只能删掉一对，要 n/2 轮。n = 10⁴ 时约 5×10⁷ 次，勉强能过。
- **空间复杂度 O(n)**：复制了一份字符串。

## 🚀 第四步：思路二 —— 栈（一遍扫描）

### 思路

观察配对规则：**每个右括号，必须和它左边最近的、还没配对的左括号配对**。"最近的先配对"——后进来的先出去，这就是**栈**。

- 遇到左括号：压栈，等待配对；
- 遇到右括号：
  - 栈空了 → 没人和它配对，无效；
  - 栈顶不是对应的左括号 → 类型不对或顺序交叉，无效；
  - 否则弹出栈顶，配对成功；
- 扫完后：栈必须为空，否则有左括号没配上。

### 手动模拟（`s = "([)]"`）

| 字符 | 操作 | 栈（底→顶） |
|---|---|---|
| `(` | 压栈 | `(` |
| `[` | 压栈 | `( [` |
| `)` | 栈顶是 `[`，不是 `(` → **无效** | |

再看 `s = "([])"`：

| 字符 | 操作 | 栈（底→顶） |
|---|---|---|
| `(` | 压栈 | `(` |
| `[` | 压栈 | `( [` |
| `]` | 栈顶 `[` 匹配，弹出 | `(` |
| `)` | 栈顶 `(` 匹配，弹出 | 空 |
| 结束 | 栈为空 → **有效** ✅ | |

### 代码

```c
bool isValid(char* s) {
    int n = strlen(s);
    if (n % 2 == 1) return false;              // 奇数长度不可能全部配对
    char* stack = (char*)malloc(n + 1);        // 栈最多放 n 个左括号
    int top = 0;
    bool ok = true;
    for (int i = 0; i < n; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') {
            stack[top++] = c;                  // 左括号：压栈
        } else {
            // 右括号：先算出它需要的左括号
            char want;
            if (c == ')') want = '(';
            else if (c == ']') want = '[';
            else want = '{';
            if (top == 0 || stack[top - 1] != want) {
                ok = false;                    // 栈空或栈顶不匹配
                break;
            }
            top--;                             // 配对成功，弹栈
        }
    }
    if (top != 0) ok = false;                  // 还有左括号没配对
    free(stack);
    return ok;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个字符只看一次。
- **空间复杂度 O(n)**：栈最多存 n 个字符。

## ⚠️ 第五步：小白常见错误

1. **只统计每种括号的个数** → `"([)]"` 会被误判为有效。
2. **右括号来时不判断栈是否为空** → `")"` 会去读 `stack[-1]`，越界读到垃圾值甚至崩溃。
3. **扫完后忘了检查栈是否为空** → `"(("` 会被误判为有效。
4. **栈开得太小**：`char stack[100]` 遇到 10⁴ 个左括号就越界。要按 `strlen(s)` 申请，或者开 `10001`。
5. **`break` 之后直接 `return false` 忘了 `free`** → 本题不会出错，但养成好习惯：先记下结果，统一释放后再返回。
6. **把 `'('` 写成 `"("`** → 字符和字符串不能用 `==` 比较，编译会警告且结果错误。

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 反复删除相邻对 | O(n²) | O(n) | ⭐ | 帮助理解 |
| 栈 | O(n) | O(n) | ⭐⭐ | 标准解法，必须掌握 |
