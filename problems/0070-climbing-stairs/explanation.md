# 70. 爬楼梯 —— 小白详细题解

> 动态规划的"Hello World"。学会这道题，你就理解了 DP 最核心的一句话：**大问题的答案可以由小问题的答案拼出来**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 楼梯一共 `n` 阶，每次只能上 1 阶或 2 阶，问**一共有多少种不同的走法**能刚好走到顶。

先手算几个小的：

| n | 所有走法 | 方法数 |
|---|---|---|
| 1 | 1 | 1 |
| 2 | 1+1、2 | 2 |
| 3 | 1+1+1、1+2、2+1 | 3 |
| 4 | 1+1+1+1、1+1+2、1+2+1、2+1+1、2+2 | 5 |

1, 2, 3, 5……是不是有点眼熟？每一项都是前两项之和！

**几个需要注意的细节：**

1. `1+2` 和 `2+1` 是**不同**的走法（顺序不同）。
2. n 最大 45，答案是 1836311903，刚好在 int 范围（约 21 亿）以内。

---

## 🧰 第二步：这道题需要的 C 语言知识

1. **递归**：函数自己调用自己。必须有"出口"（如 `n <= 2` 时直接返回），否则会无限调用直到栈溢出。
2. **全局数组**：写在函数外面的 `int memo[46];` 会被自动初始化为全 0，并且在多次（递归）调用之间一直保留，适合做"备忘录"。
3. **滚动变量**：只用几个变量代替整个数组，节省空间。

---

## 💡 第三步：思路一 —— 递归 + 记忆化

### 思路

想一想**最后一步**：要站到第 n 阶，最后一步要么是从第 n-1 阶跨 1 步，要么是从第 n-2 阶跨 2 步。所以：

```
f(n) = f(n-1) + f(n-2)，  f(1) = 1，f(2) = 2
```

直接写成递归会**超时**：`f(45)` 会重复计算同一个 `f(k)` 无数次（调用次数约 10⁹ 级别）：

```c
// ❌ 纯递归：大量重复计算，n = 45 时会超时
int climbStairs(int n) {
    if (n <= 2) return n;
    return climbStairs(n - 1) + climbStairs(n - 2);
}
```

解决办法：把算过的结果存进"备忘录"数组，下次直接查表。

### 代码

```c
int memo[46];   // memo[i] 存 f(i)，全局数组自动初始化为 0，表示"还没算过"

int climbStairs(int n) {
    if (n <= 2) return n;              // 出口：f(1) = 1，f(2) = 2
    if (memo[n] != 0) return memo[n];  // 算过了，直接查表
    memo[n] = climbStairs(n - 1) + climbStairs(n - 2);   // 第一次算，记下来
    return memo[n];
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个 `f(i)` 只真正计算一次。
- **空间复杂度 O(n)**：备忘录数组 + 递归调用栈。

---

## 🚀 第四步：思路二 —— 动态规划（从小往大推，只用两个变量）

### 思路

既然 `f(n)` 只依赖 `f(n-1)` 和 `f(n-2)`，那就从小到大**循环**算，而且只需要记住"前两个"。

### 手动模拟（n = 5）

| i | a（f(i-2)） | b（f(i-1)） | c = a + b（f(i)） |
|---|---|---|---|
| 初始 | f(0)=1 | f(1)=1 | — |
| 2 | 1 | 1 | 2 |
| 3 | 1 | 2 | 3 |
| 4 | 2 | 3 | 5 |
| 5 | 3 | 5 | **8** |

> 💬 `f(0) = 1` 可以理解成"站在地面不动，算 1 种走法"，这样 `f(2) = f(1) + f(0) = 2` 也成立，代码更简洁。

### 代码

```c
int climbStairs(int n) {
    int a = 1;   // f(i-2)，一开始是 f(0) = 1
    int b = 1;   // f(i-1)，一开始是 f(1) = 1
    for (int i = 2; i <= n; i++) {
        int c = a + b;   // f(i) = f(i-1) + f(i-2)
        a = b;           // 整体往前"滚动"一格
        b = c;
    }
    return b;            // 循环结束时 b 就是 f(n)；n = 1 时不进循环，直接返回 1
}
```

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**：只有 3 个变量。

---

## ⚠️ 第五步：小白常见错误

1. **纯递归不加记忆化** → 结果对，但 n 稍大（比如 40 以上）就会超时。
2. **递归没有出口或出口写错** → 比如只写了 `if (n == 1) return 1;`，`f(2)` 会去算 `f(0)`、`f(-1)`……一直递归到栈溢出。
3. **滚动变量的赋值顺序写反** → 先写 `b = c; a = b;` 会让 `a` 也变成 `c`，下一轮就错了。
4. **开数组 `int dp[n]` 后访问 `dp[2]`** → n = 1 时数组只有 1 个元素，`dp[2]` 越界。
5. **用 `memo` 时忘了"0 表示没算过"的前提** → 本题答案都 ≥ 1，所以可以用 0 当标记；别的题如果答案可能是 0，要换成 -1 做标记。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 能否 AC |
|---|---|---|---|
| 纯递归 | O(2ⁿ) | O(n) | ❌ 超时 |
| 递归 + 记忆化 | O(n) | O(n) | ✅ |
| 循环 + 滚动变量 | O(n) | O(1) | ✅ 推荐 |
