# 228. 汇总区间 —— 小白详细题解

> 思路很简单，难点全在 C 语言细节：**返回字符串数组**、**把数字写成字符串**、以及**整数溢出**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一排从小到大、没有重复的数字。把**连续的一段**（每个数都比前一个大 1）压缩成 `"起点->终点"`；如果这一段只有一个数，就只写这个数。

示例 2：`nums = [0,2,3,4,6,8,9]`

| 分段 | 包含的数 | 输出字符串 |
|---|---|---|
| 第 1 段 | 0 | `"0"` |
| 第 2 段 | 2, 3, 4 | `"2->4"` |
| 第 3 段 | 6 | `"6"` |
| 第 4 段 | 8, 9 | `"8->9"` |

**几个需要注意的细节：**

1. 数组可能是**空的**，此时返回空列表 `[]`（`*returnSize = 0`）。
2. 数值范围是完整的 `int` 范围，`nums[j] + 1` 在 `nums[j] = 2147483647` 时会**溢出**。
3. 负数也要正确输出，例如 `"-3->-1"`。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回值 `char**` 是什么？

- `char*`：一个字符串（指向第一个字符的指针，以 `'\0'` 结尾）。
- `char**`：一个"字符串数组"——数组里每个元素都是一个 `char*`。

所以要 `malloc` **两层**：

```c
char** res = (char**)malloc(sizeof(char*) * 最多几个字符串);   // 第一层：放指针的数组
res[0] = (char*)malloc(32);                                     // 第二层：每个字符串自己的空间
```

### 2. 用 `sprintf` 把数字"打印"进字符串

`sprintf` 和 `printf` 用法一样，只是结果写进字符数组，而不是屏幕，并且会自动在末尾加 `'\0'`：

```c
char buf[32];
sprintf(buf, "%d->%d", 2, 4);   // buf 变成 "2->4"
sprintf(buf, "%d", -7);         // buf 变成 "-7"
```

> 一个字符串要多大？最长是 `"-2147483648->-2147483647"`，共 24 个字符，加上 `'\0'` 是 25。申请 32 字节足够。

### 3. 避免溢出：转成 `long long` 再比较

```c
nums[j + 1] == nums[j] + 1                         // ❌ nums[j] 为 INT_MAX 时，+1 溢出（未定义行为）
(long long)nums[j + 1] == (long long)nums[j] + 1   // ✅ 在 64 位整数里计算，不会溢出
```

---

## 💡 第三步：思路 —— 双指针分段扫描

### 思路

1. `i` 指向当前段的**起点**；
2. `j` 从 `i` 开始往后走，只要下一个数正好比当前数大 1（`nums[j+1] == nums[j] + 1`）就继续；
3. 停下时 `[nums[i], nums[j]]` 就是一个区间：`i == j` 写 `"a"`，否则写 `"a->b"`；
4. 下一段从 `j + 1` 开始，重复直到数组结束。

### 手动模拟（示例 1：`nums = [0,1,2,4,5,7]`）

| 段起点 i | j 向后扩展的过程 | 停下时 j | 区间 | 字符串 |
|---|---|---|---|---|
| 0 | 0→1（1=0+1）→2（2=1+1），4≠3 停 | 2 | [0,2] | `"0->2"` |
| 3 | 3→4（5=4+1），7≠6 停 | 4 | [4,5] | `"4->5"` |
| 5 | 已到末尾 | 5 | [7,7] | `"7"` |

### 代码

```c
char** summaryRanges(int* nums, int numsSize, int* returnSize) {
    // 区间个数最多等于元素个数；numsSize 为 0 时也申请 1 个，避免 malloc(0)
    char** res = (char**)malloc(sizeof(char*) * (numsSize > 0 ? numsSize : 1));
    int cnt = 0;                // 已经生成了几个区间字符串

    int i = 0;
    while (i < numsSize) {
        int j = i;              // 当前段从 i 开始
        // 下一个数恰好大 1 就继续扩展；用 long long 防止 INT_MAX + 1 溢出
        while (j + 1 < numsSize && (long long)nums[j + 1] == (long long)nums[j] + 1) {
            j++;
        }

        res[cnt] = (char*)malloc(32);          // 每个字符串单独申请空间
        if (i == j) {
            sprintf(res[cnt], "%d", nums[i]);                  // 只有一个数
        } else {
            sprintf(res[cnt], "%d->%d", nums[i], nums[j]);     // 一段连续的数
        }
        cnt++;

        i = j + 1;              // 下一段从 j 的后一个开始
    }

    *returnSize = cnt;          // 告诉调用者一共有几个字符串
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：`i` 和 `j` 都只往前走，每个元素只被访问常数次。
- **空间复杂度 O(1)**：除了返回的结果，只用了几个变量。

> 本题已经是最优解（每个元素至少要看一次），没有进一步优化的必要。

---

## ⚠️ 第四步：小白常见错误

1. **返回局部字符数组** `char buf[32]; res[cnt] = buf;` → 所有字符串都指向同一块会被回收的内存，输出乱码或全都一样。每个字符串都要单独 `malloc`。
2. **字符串空间开太小**，如 `malloc(5)` → `"-2147483648->2147483647"` 写不下，越界破坏内存。
3. **`nums[j] + 1` 溢出** → `[2147483646, 2147483647]` 之类的数据在部分编译器优化下会出错；`[-2147483648, 2147483647]` 若写成 `nums[j+1] - nums[j] == 1` 更会直接溢出。
4. **空数组没有处理** → `numsSize = 0` 时忘记把 `*returnSize` 设为 0，或访问了 `nums[0]`。
5. **最后一段忘记输出** → 用"遇到断点才输出上一段"的写法时，循环结束后还要补上最后一段。
6. **写成 `"%d-%d"` 或 `"%d->%d "`** → 格式必须和题目完全一致，多一个空格也是 Wrong Answer。
