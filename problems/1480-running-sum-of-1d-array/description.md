# 一维数组的动态和

返回数组的前缀和，第i项等于原数组0到i项之和。1 ≤ n ≤ 1000，|元素| ≤ 10^6。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* runningSum(int* nums,int numsSize,int* returnSize);
```

## 示例 1

输入：
```text
[1,2,3,4]
```
输出：
```text
[1,3,6,10]
```

## 示例 2

输入：
```text
[1,1,1,1,1]
```
输出：
```text
[1,2,3,4,5]
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
