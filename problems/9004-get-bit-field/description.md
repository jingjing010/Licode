单片机的寄存器里，很多配置项不是只占 1 位，而是占连续的几位，称为 **位域**（bit field）。例如某个 ADC 的状态寄存器中，第 `8 ~ 15` 位（共 8 位）存放的是当前转换通道号；某个时钟配置寄存器中，第 `2 ~ 4` 位（共 3 位）存放的是分频系数。

给定寄存器的值 `reg`，位域的 **起始位** `pos`（位域最低位的位号）和 **宽度** `width`（占几位），请读出这个位域的值，即 `reg` 的第 `pos` 位到第 `pos + width - 1` 位所组成的无符号整数。

位号从 `0` 开始：第 `0` 位是最低位（LSB），第 `31` 位是最高位（MSB）。

### 示例 1

```
输入：reg = 2882343476, pos = 8, width = 8
输出：18
解释：reg = 0xABCD1234，第 8~15 位是 0x12 = 18。
```

### 示例 2

```
输入：reg = 180, pos = 2, width = 3
输出：5
解释：180 = 0b1011_0100，第 2~4 位是 0b101 = 5。
```

### 示例 3

```
输入：reg = 4294967295, pos = 0, width = 32
输出：4294967295
解释：位域就是整个寄存器 0xFFFFFFFF。
```

### 提示

- `0 <= reg <= 2^32 - 1`
- `0 <= pos <= 31`
- `1 <= width <= 32`
- `pos + width <= 32`

### 函数说明

```c
uint32_t get_bit_field(uint32_t reg, int pos, int width);
```

- `reg`：寄存器的值
- `pos`：位域的起始位（最低位）位号
- `width`：位域宽度
- 返回值：位域的值（已经移到最低位）

### 自定义输入格式

```
180
2
3
```

依次为 `reg`、`pos`、`width`，每行一个十进制整数。输出为位域的值（十进制）。
