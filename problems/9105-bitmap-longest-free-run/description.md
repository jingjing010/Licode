# 位图最大连续空闲区

低width位表示块占用，1已用、0空闲，忽略其他位。返回最大连续空闲块数量。bitmap为uint32，width0..32。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int longestFreeRun(uint32_t bitmap,int width);
```

## 示例 1

输入：
```text
196
8
```
输出：
```text
3
```

## 示例 2

输入：
```text
4294967295
32
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：bitmap、width。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
