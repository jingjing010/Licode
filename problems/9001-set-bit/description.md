在单片机中，GPIO 端口的 **输出数据寄存器**（例如 STM32 的 `GPIOx_ODR`）是一个 32 位无符号整数：第 `n` 位为 `1` 表示第 `n` 号引脚输出高电平，为 `0` 表示输出低电平。

现在要把第 `n` 号引脚拉高。给定寄存器当前的值 `reg` 和位号 `n`，请把 `reg` 的 **第 `n` 位置为 1**，**其余位保持不变**，返回修改后的寄存器值。

位号从 `0` 开始：第 `0` 位是最低位（LSB），第 `31` 位是最高位（MSB）。

### 示例 1

```
输入：reg = 0, n = 3
输出：8
解释：0x00000000 的第 3 位置 1 后变成 0b1000 = 0x00000008 = 8。
```

### 示例 2

```
输入：reg = 5, n = 1
输出：7
解释：5 = 0b101，第 1 位置 1 后变成 0b111 = 7。第 0 位和第 2 位原来就是 1，保持不变。
```

### 示例 3

```
输入：reg = 8, n = 3
输出：8
解释：8 = 0b1000，第 3 位本来就是 1，置位后不变。
```

### 提示

- `0 <= reg <= 2^32 - 1`（即 `0x00000000` ~ `0xFFFFFFFF`）
- `0 <= n <= 31`

### 函数说明

```c
uint32_t set_bit(uint32_t reg, int n);
```

- `reg`：寄存器的原始值（32 位无符号整数）
- `n`：要置 1 的位号
- 返回值：第 `n` 位置 1、其余位不变后的值

### 自定义输入格式

```
0
3
```

第 1 行是 `reg`，第 2 行是 `n`，均为十进制整数。输出为修改后的寄存器值（十进制）。
