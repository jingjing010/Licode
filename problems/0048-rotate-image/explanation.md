# 48. 旋转图像 —— 小白详细题解

> 关键是找到"旋转前后下标"的对应关系。找到之后，用"转置 + 翻转"两步就能原地完成，非常优雅。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把一个正方形的数字表格**顺时针转 90 度**（就像把手机横过来），直接在原表格上改。

示例 1：

```
旋转前        旋转后
1 2 3        7 4 1
4 5 6   →    8 5 2
7 8 9        9 6 3
```

观察：**原来的第 0 行 `1 2 3`，变成了新矩阵的最后一列（从上往下读）**；原来的第 0 列 `1 4 7`，倒过来变成了新的第 0 行 `7 4 1`。

**几个需要注意的细节：**

1. 函数返回 `void`，判题程序看的是你修改后的 `matrix`。
2. 矩阵一定是 **n × n 的正方形**。
3. 题目要求"原地"，最理想的写法是不开新矩阵（思路一会开，作为理解的过渡）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 找到下标的对应关系

对照示例 1（n = 3），看几个元素去了哪里：

| 元素 | 原位置 (i, j) | 新位置 |
|---|---|---|
| 1 | (0, 0) | (0, 2) |
| 2 | (0, 1) | (1, 2) |
| 3 | (0, 2) | (2, 2) |
| 4 | (1, 0) | (0, 1) |

规律：**原来的 `(i, j)` 去了 `(j, n-1-i)`**。也就是：原来的行号 `i` 决定了新的列号 `n-1-i`，原来的列号 `j` 变成了新的行号。

### 2. 交换两个变量

```c
int t = a;   // 先存起来
a = b;
b = t;
```

### 3. 二维数组的 malloc

```c
int** copy = (int**)malloc(sizeof(int*) * n);      // 先申请 n 个"行指针"
for (int i = 0; i < n; i++)
    copy[i] = (int*)malloc(sizeof(int) * n);       // 每一行再申请 n 个 int
```

---

## 💡 第三步：思路一 —— 拷贝一份再填回去（O(n²) 额外空间）

### 思路

如果直接按公式 `matrix[j][n-1-i] = matrix[i][j]` 写，会把还没搬走的元素覆盖掉。所以先把原矩阵**复制一份**，然后从副本里读、往原矩阵里写。

### 代码

```c
void rotate(int** matrix, int matrixSize, int* matrixColSize) {
    int n = matrixSize;

    // 1. 复制一份原矩阵（题目 n <= 20，用固定大小的数组即可）
    int copy[20][20];
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            copy[i][j] = matrix[i][j];
        }
    }

    // 2. 原来 (i, j) 上的元素，旋转后到了 (j, n-1-i)
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            matrix[j][n - 1 - i] = copy[i][j];
        }
    }
}
```

### 复杂度分析

- **时间复杂度 O(n²)**，**空间复杂度 O(n²)**（副本）。

> 能 AC，但不满足"不要使用另一个矩阵"的要求。下面看原地做法。

---

## 🚀 第四步：思路二 —— 转置 + 每行左右翻转（原地）

### 思路

把"顺时针转 90 度"拆成两个简单的、都可以原地完成的操作：

1. **转置**（沿主对角线翻折）：`(i, j)` ↔ `(j, i)`
2. **每一行左右翻转**：`(i, j)` ↔ `(i, n-1-j)`

为什么对？跟踪一个元素：`(i, j)` →（转置）→ `(j, i)` →（左右翻转）→ `(j, n-1-i)`，正好是我们要的新位置！

### 手动模拟（示例 1）

| 步骤 | 矩阵 |
|---|---|
| 原矩阵 | `[1,2,3]` `[4,5,6]` `[7,8,9]` |
| 1. 转置 | `[1,4,7]` `[2,5,8]` `[3,6,9]` |
| 2. 每行左右翻转 | `[7,4,1]` `[8,5,2]` `[9,6,3]` ✅ |

### 代码

```c
void rotate(int** matrix, int matrixSize, int* matrixColSize) {
    int n = matrixSize;

    // 1. 转置：只交换主对角线"上方"的元素（j 从 i+1 开始）
    //    如果 j 从 0 开始，每对元素会被交换两次，等于没换
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int t = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = t;
        }
    }

    // 2. 每一行左右翻转：左右两个指针往中间靠
    for (int i = 0; i < n; i++) {
        int l = 0, r = n - 1;
        while (l < r) {
            int t = matrix[i][l];
            matrix[i][l] = matrix[i][r];
            matrix[i][r] = t;
            l++;
            r--;
        }
    }
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：每个元素被交换常数次。
- **空间复杂度 O(1)**：只用了一个临时变量 `t`。

> 💬 还有一种原地做法是"四个角一起转"：`(i,j) → (j,n-1-i) → (n-1-i,n-1-j) → (n-1-j,i) → (i,j)` 这四个位置构成一个环，用一个临时变量把四个数依次挪一格。思路更直接，但下标容易写错，可以作为练习。

---

## ⚠️ 第五步：小白常见错误

1. **不用副本直接按公式写** → `matrix[j][n-1-i] = matrix[i][j];` 会覆盖掉还没处理的元素，结果出现重复数字。
2. **转置时 `j` 从 0 开始** → 每对元素被交换两次，矩阵恢复原样，最后只剩"左右翻转"的效果。
3. **顺序反了：先左右翻转再转置** → 得到的是**逆时针**旋转 90 度。
4. **把"每行左右翻转"写成"上下翻转"（交换行）** → 转置 + 上下翻转同样是逆时针旋转。
5. **翻转一行时循环到 `l < n` 而不是 `l < r`** → 每对又被换了两次，等于没翻。
6. **在函数里 `return` 一个新矩阵** → 函数是 `void`，判题程序只看原来的 `matrix`。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 拷贝副本 | O(n²) | O(n²) | ⭐ | 理解下标公式 |
| 转置 + 左右翻转 | O(n²) | O(1) | ⭐⭐ | 推荐，好记不易错 |
| 四角循环交换 | O(n²) | O(1) | ⭐⭐⭐ | 进阶练习 |
