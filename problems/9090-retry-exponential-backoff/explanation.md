# 带上限的指数退避：题解

## 📖 先读懂题目

第attempt次退避=min(base*2^attempt,cap)。base与cap为0..INT_MAX，attempt0..100；返回毫秒数。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `10 / 0 / 1000` | `10` |
| 2 | `10 / 4 / 1000` | `160` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

倍增前比较cap/2，提前饱和避免左移溢出。实际系统可再加随机抖动，本题只实现确定性退避。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int retryDelay(int base, int attempt, int cap) {
    int delay = base < cap ? base : cap;
    for (int i = 0; i < attempt && delay < cap; ++i) {
        if (delay > cap / 2) {
            delay = cap;
            break;
        }
        delay *= 2;
    }
    return delay;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(attempt)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
