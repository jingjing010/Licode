给定一个整数，写一个函数来判断它是否是 3 的幂次方。如果是，返回 `true` ；否则，返回 `false` 。

整数 `n` 是 3 的幂次方需满足：存在整数 `x` 使得 `n == 3^x`

### 示例 1

```
输入：n = 27
输出：true
```

### 示例 2

```
输入：n = 0
输出：false
```

### 示例 3

```
输入：n = 9
输出：true
```

### 示例 4

```
输入：n = 45
输出：false
```

### 提示

- `-2^31 <= n <= 2^31 - 1`

**进阶：** 你能不使用循环或者递归来完成本题吗？

### 函数说明

```c
bool isPowerOfThree(int n);
```

- `n`：要判断的整数，可能是 0 或负数
- 返回值：是 3 的幂返回 `true`，否则返回 `false`

### 自定义输入格式

```
27
```

只有 1 行，是整数 `n`。
