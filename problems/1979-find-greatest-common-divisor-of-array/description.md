# 找出数组的最大公约数

返回数组最小元素和最大元素的最大公约数。2 ≤ n ≤ 1000，元素1到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int findGCD(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[2,5,6,9,10]
```
输出：
```text
2
```

## 示例 2

输入：
```text
[7,5,6,8,3]
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
