# 括号的最大嵌套深度

给定括号有效的ASCII表达式，忽略非括号字符，返回最大括号嵌套深度。长度1到100。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int maxDepth(char* s);
```

## 示例 1

输入：
```text
"(1+(2*3)+((8)/4))+1"
```
输出：
```text
3
```

## 示例 2

输入：
```text
"(1)+((2))+(((3)))"
```
输出：
```text
3
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
