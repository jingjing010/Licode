# 最小操作次数使数组元素相等：题解

## 📖 先读懂题目

每次可让数组中的n−1个元素加1，返回使所有元素相等的最少次数。1 ≤ n ≤ 10^5，保证答案在int范围内。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[1,2,3]` | `3` |
| 2 | `[1,1,1]` | `0` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

只关心相对差值，每次让n−1个数加1等价于让剩下一个减1，统一降到最小值。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int minMoves(int *nums, int numsSize) {
    int minimum = nums[0];
    long long sum = 0;
    for (int i = 0; i < numsSize; ++i) {
        if (nums[i] < minimum)
            minimum = nums[i];
        sum += nums[i];
    }
    /* 给n-1个元素加1，相对差值等价于给另一个减1。 */
    return (int)(sum - (long long)minimum * numsSize);
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，额外空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
