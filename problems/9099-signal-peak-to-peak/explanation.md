# 信号峰峰值：题解

## 📖 先读懂题目

返回采样最大值减最小值，输入int16范围、长度1到1000。结果范围0..65535。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[-10,2,30]` | `40` |
| 2 | `[32767,-32768]` | `65535` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

一次遍历同时保存最小和最大值，差值可达到65535，所以返回int而非int16_t。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int peakToPeak(int *samples, int samplesSize) {
    int lo = samples[0], hi = samples[0];
    for (int i = 1; i < samplesSize; ++i) {
        if (samples[i] < lo)
            lo = samples[i];
        if (samples[i] > hi)
            hi = samples[i];
    }
    return hi - lo;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
