# PWM 软启动爬坡：题解

## 📖 先读懂题目

占空比采用千分比0..1000。每tick向target靠近step且不越过，返回ticks拍后值。step0..1000，ticks0..10^6。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `0 / 1000 / 10 / 5` | `50` |
| 2 | `1000 / 0 / 30 / 100` | `0` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

每拍只朝目标移动step，达到目标后保持。可把多拍总变化量合并计算，并用64位承接乘积。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int pwmRamp(int initial, int target, int step, int ticks) {
    int64_t distance = (int64_t)step * ticks;
    if (initial < target)
        return distance >= target - initial ? target : initial + (int)distance;
    return distance >= initial - target ? target : initial - (int)distance;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
