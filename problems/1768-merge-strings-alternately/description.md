# 交替合并字符串

从word1开始交替追加两个字符串字符，较长者剩余部分直接接到末尾。两个字符串只含小写字母，长度1到100。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* mergeAlternately(char* word1,char* word2);
```

## 示例 1

输入：
```text
"abc"
"pqr"
```
输出：
```text
"apbqcr"
```

## 示例 2

输入：
```text
"ab"
"pqrs"
```
输出：
```text
"apbqrs"
```

## 自定义输入格式

按顺序每行一个参数：word1、word2。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
