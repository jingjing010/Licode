# 检查替换后的词是否有效：题解

## 📖 先读懂题目

把字符串看作不断消去abc的过程。输出缓冲区兼作栈，每放入一个字符，若栈顶三字符为abc就一起弹出。最后栈空说明整个输入可由插入abc生成。


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 反过来想：既然 s 是不断插入 "abc" 得到的，那么一定可以不断删除连续的 "abc"，最后变成空串。
2. 反复查找并删除 "abc" 是 O(n²) 的。能不能像括号匹配那样，从左到右一遍完成？
3. 用栈：每读入一个字符就入栈，如果栈顶三个字符恰好是 'a','b','c'，就把它们一起弹出。最后栈为空就是有效。

## 可直接提交的 C 代码

```c
bool isValid(char* s) {
    int n = strlen(s);
    char* st = (char*)malloc(n + 1);
    int top = 0;
    for (int i = 0; i < n; i++) {
        st[top++] = s[i];
        if (top >= 3 && st[top - 3] == 'a' && st[top - 2] == 'b' && st[top - 1] == 'c') top -= 3;
    }
    free(st);
    return top == 0;
}
```

## 📊 复杂度

时间 O(n)，空间 O(n)。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。

## 🔗 举一反三

改变输入长度为1、重复值、边界整数，手工验证每一步保存的状态。思考能否在输入逐个到达时保留相同的状态完成计算。
