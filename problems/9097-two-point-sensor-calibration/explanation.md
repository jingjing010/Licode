# 传感器两点线性标定：题解

## 📖 先读懂题目

raw/raw0/raw1在0..65535，raw0<raw1；value0/value1在−10^6..10^6，可升可降。计算value0+trunc((raw−raw0)*(value1−value0)/(raw1−raw0))，允许外推，保证结果在int范围。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `100 / 100 / 1100 / -500 / 500` | `-500` |
| 2 | `1100 / 100 / 1100 / -500 / 500` | `500` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

用两组原始值与实际值确定直线，计算比例时先乘后除并提升到64位，保留更多精度。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int calibrateSensor(int raw, int raw0, int raw1, int value0, int value1) {
    int64_t numerator = (int64_t)(raw - raw0) * (value1 - value0);
    return value0 + (int)(numerator / (raw1 - raw0));
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
