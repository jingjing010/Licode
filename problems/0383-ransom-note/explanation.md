# 赎金信：题解

## 📖 先读懂题目

判断能否用t中的字母构造s，每个字母只能用一次。仅小写英文字母，长度1到10^5。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"a" / "b"` | `false` |
| 2 | `"aa" / "aab"` | `true` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

使用26个计数器表示字母多重集合。逐字符扣减时出现负数说明缺少所需字符。来源中有剩余字母不影响结果。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
bool canConstruct(char *s, char *t) {
    int counts[26] = {0};
    /* 先统计来源，再扣除需要的字母。 */
    for (int i = 0; t[i]; ++i)
        ++counts[t[i] - 'a'];
    for (int i = 0; s[i]; ++i)
        if (--counts[s[i] - 'a'] < 0)
            return false;

    return true;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n+m)，空间 O(26) | 正式提交 |

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
