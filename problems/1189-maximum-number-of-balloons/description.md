# 气球的最大数量

从小写字符串中选取字母组成尽可能多个balloon，每个字符只能使用一次，返回数量。长度1到10^4。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int maxNumberOfBalloons(char* text);
```

## 示例 1

输入：
```text
"nlaebolko"
```
输出：
```text
1
```

## 示例 2

输入：
```text
"loonbalxballpoon"
```
输出：
```text
2
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
