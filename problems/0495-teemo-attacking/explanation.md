# 495. 提莫攻击 —— 小白详细题解

> 题目故事很长，本质是：**求若干个等长区间的并集长度**。抓住"相邻两次攻击的时间差"就能一遍算出来。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 提莫在若干个时间点攻击，每次攻击让艾希中毒 `duration` 秒（从攻击那一秒算起）。如果上一次的毒还没结束又被攻击，计时**重新开始**（不会叠加）。问：艾希一共中毒了多少秒？

把每秒是否中毒画出来（`duration = 2`）：

**示例 1：`timeSeries = [1,4]`**

| 第几秒 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 第 1 次攻击（第 1 秒） | ☠️ | ☠️ | | | |
| 第 2 次攻击（第 4 秒） | | | | ☠️ | ☠️ |
| 中毒？ | ✅ | ✅ | ❌ | ✅ | ✅ |

共 4 秒。

**示例 2：`timeSeries = [1,2]`**

| 第几秒 | 1 | 2 | 3 |
|---|---|---|---|
| 第 1 次攻击（第 1 秒） | ☠️ | ☠️ | |
| 第 2 次攻击（第 2 秒，重置） | | ☠️ | ☠️ |
| 中毒？ | ✅ | ✅ | ✅ |

第 2 秒被两次攻击覆盖，但只算一次，共 3 秒。

**几个需要注意的细节：**

1. 在 `t` 秒攻击，中毒的是第 `t, t+1, ……, t+duration-1` 秒，共 `duration` 秒。
2. 同一秒可能被多次攻击覆盖，**只算一次**。
3. `timeSeries` 可能有**相同的时间**（同一秒攻击两次），`duration` 也可能是 0。
4. 时间最大 10⁷，"开一个数组标记每一秒"需要 2×10⁷ 个格子，太浪费。

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用三目运算符取较小值

```c
int m = (a < b) ? a : b;    // a、b 中较小的那个
```

### 2. 会不会溢出？

答案最多是"最后一次攻击时间 + duration" ≈ 2×10⁷，远小于 `int` 的上限（约 2.1×10⁹），用 `int` 就够了。

---

## 💡 第三步：思路一 —— 模拟"中毒结束时间"

### 思路

用变量 `end` 表示**当前中毒状态在第几秒之前结束**（即中毒覆盖到 `end - 1` 秒）：

- 攻击发生在 `t`，本次中毒覆盖 `[t, t + duration)`；
- 如果 `t >= end`：上一次的毒已经结束，这次的 `duration` 秒**全部是新的**，`total += duration`；
- 如果 `t < end`：和上一次重叠，新增的只有 `t + duration - end` 秒；
- 最后更新 `end = t + duration`。

### 手动模拟（示例 2：`[1,2]`，`duration = 2`）

| 攻击时间 t | 之前的 end | 是否重叠 | 新增秒数 | total | 新的 end |
|---|---|---|---|---|---|
| 1 | 0 | 否 | 2 | 2 | 3 |
| 2 | 3 | 是（2 < 3） | 2 + 2 − 3 = 1 | 3 | 4 |

### 代码

```c
int findPoisonedDuration(int* timeSeries, int timeSeriesSize, int duration) {
    int total = 0;      // 总中毒秒数
    int end = 0;        // 当前中毒在第 end 秒开始时结束（覆盖到 end-1 秒）

    for (int i = 0; i < timeSeriesSize; i++) {
        int t = timeSeries[i];
        if (t >= end) {
            total += duration;              // 上次的毒已结束，本次全部计入
        } else {
            total += t + duration - end;    // 有重叠，只计入超出 end 的部分
        }
        end = t + duration;                 // 计时器重置：新的结束时间
    }
    return total;
}
```

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 相邻攻击的时间差

### 思路

换个角度，看**每一次攻击"独占"了多少秒**：

- 第 `i` 次攻击后，下一次攻击在 `gap = timeSeries[i+1] - timeSeries[i]` 秒之后：
  - 如果 `gap >= duration`：本次的毒在下次攻击前就结束了，贡献完整的 `duration` 秒；
  - 如果 `gap < duration`：下次攻击会"接管"，本次只贡献 `gap` 秒；
  - 合起来就是 **`min(gap, duration)`**。
- **最后一次攻击**后面没有人打断，一定贡献完整的 `duration` 秒。

```
答案 = min(gap₀, duration) + min(gap₁, duration) + …… + duration
```

### 手动模拟（示例 1：`[1,4]`，`duration = 2`）

| 第 i 次 | gap | min(gap, 2) |
|---|---|---|
| 0 | 4 − 1 = 3 | 2 |
| 最后一次 | — | 2 |

答案 2 + 2 = **4**。

### 代码

```c
int findPoisonedDuration(int* timeSeries, int timeSeriesSize, int duration) {
    int total = 0;
    // 除最后一次外，每次攻击贡献 min(与下一次的时间差, duration)
    for (int i = 0; i + 1 < timeSeriesSize; i++) {
        int gap = timeSeries[i + 1] - timeSeries[i];
        total += (gap < duration) ? gap : duration;
    }
    return total + duration;    // 最后一次攻击贡献完整的 duration
}
```

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(1)**。代码更短，也不容易写错边界。

---

## ⚠️ 第五步：小白常见错误

1. **直接返回 `duration * timeSeriesSize`** → 没考虑重叠，示例 2 会得到 4。
2. **重叠时直接加 `gap + 1` 或 `gap - 1`** → 区间是 `[t, t + duration - 1]`，相邻攻击独占的恰好是 `gap` 秒，多加减 1 都会错。
3. **思路二忘记加上最后一次的 `duration`** → 结果少了一截，`[1]`、`duration = 5` 会返回 0。
4. **思路二循环写成 `i < timeSeriesSize`** → 访问 `timeSeries[timeSeriesSize]` 越界。
5. **用数组标记每一秒** → 时间最大 2×10⁷，内存和时间都很浪费，而且 `duration` 大时一层层标记会超时。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 说明 |
|---|---|---|---|---|
| 模拟结束时间 | O(n) | O(1) | ⭐ | 贴近题意，容易推广到"区间长度不同"的情况 |
| 相邻时间差 | O(n) | O(1) | ⭐ | 最简洁 |
