# 82. 删除排序链表中的重复元素 II —— 小白详细题解

> 83 题的升级版：重复的数字一个都不留。这道题是学习**哑结点（dummy node）**的经典例题。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 链表从小到大排好序。如果某个数出现了**两次及以上**，就把它**全部**删掉；只出现一次的数才保留。

用示例 1（`[1,2,3,3,4,4,5]`）看看：

```
1 -> 2 -> 3 -> 3 -> 4 -> 4 -> 5
          ×    ×    ×    ×           3 和 4 都重复了，全部删除
1 -> 2 -> 5
```

示例 2（`[1,1,1,2,3]`）里，**头结点 1 也被删了**：

```
1 -> 1 -> 1 -> 2 -> 3
×    ×    ×
2 -> 3                               新的头结点是 2
```

**和 83 题的区别：**

| 题目 | `[1,1,2]` 的结果 |
|---|---|
| 83（每种留一个） | `[1,2]` |
| 82（重复的全删） | `[2]` |

**几个需要注意的细节：**

1. **头结点可能被删除**，所以返回值不一定是 `head`。
2. 可能全部被删光（如 `[1,1]`），这时返回 `NULL`。
3. 空链表直接返回 `NULL`。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 删除结点 = 让前一个结点跳过它

```
prev -> del -> X     变成     prev ---------> X      （prev->next = del->next）
```

**要删一个结点，必须拿到它的"前一个"结点**。问题来了：头结点没有前一个结点，怎么办？

### 2. 哑结点（dummy node）

在 `head` 前面**人为加一个假结点**，让头结点也有"前一个"：

```
dummy -> 1 -> 1 -> 1 -> 2 -> 3
```

```c
struct ListNode dummy;          // 直接在栈上定义一个结构体变量，不需要 malloc
dummy.next = head;              // 结构体变量用 . 访问成员
struct ListNode* prev = &dummy; // 指针用 -> 访问成员，&dummy 取它的地址
```

删除完之后，真正的头结点就是 `dummy.next`。这样"删头结点"和"删中间结点"就是**同一套代码**，不用特判。

> 💬 `dummy` 是局部变量，函数返回后就销毁了，所以**只能返回 `dummy.next`**，不能返回 `&dummy`。

### 3. `free` 释放删除的结点

被删除的结点是 `malloc` 出来的，用 `free(del)` 释放。注意**先改指针，再 free**。

---

## 💡 第三步：思路一 —— 先统计次数，再删除（最容易想到）

### 思路

值的范围只有 `-100 ~ 100`，可以开一个计数数组 `cnt[201]`，`cnt[v + 100]` 表示值 `v` 出现了几次（`+100` 是为了让下标不为负数）。

1. 第一遍遍历：统计每个值出现的次数
2. 第二遍遍历（带哑结点）：如果 `prev->next` 的值出现次数 `> 1`，就删掉它；否则 `prev` 往后走

### 代码

```c
struct ListNode* deleteDuplicates(struct ListNode* head) {
    // 1. 统计每个值出现的次数（值在 -100~100，加 100 变成下标 0~200）
    int cnt[201] = {0};
    for (struct ListNode* p = head; p != NULL; p = p->next) {
        cnt[p->val + 100]++;
    }

    // 2. 哑结点：让头结点也有"前一个结点"
    struct ListNode dummy;
    dummy.next = head;
    struct ListNode* prev = &dummy;

    while (prev->next != NULL) {
        struct ListNode* cur = prev->next;
        if (cnt[cur->val + 100] > 1) {      // 出现过不止一次 → 删掉
            prev->next = cur->next;
            free(cur);
        } else {
            prev = cur;                      // 只出现一次 → 保留，prev 前进
        }
    }
    return dummy.next;                       // 真正的头结点
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两遍遍历。
- **空间复杂度 O(值域)**：计数数组 201 个 int。这个方法**没有用到"有序"这个条件**，也依赖值域很小。

---

## 🚀 第四步：思路二 —— 哑结点 + 一次遍历（最优）

### 思路

因为有序，重复的数一定挨在一起。用 `prev` 指向"**确定保留**的最后一个结点"（一开始是 `dummy`）：

- 如果 `prev->next` 和 `prev->next->next` 的值相同（记为 `x`），说明 `x` 重复了：把 `prev` 后面所有值等于 `x` 的结点**全部跳过**，`prev` 不动
- 否则 `prev->next` 是唯一的，保留它，`prev` 往后走一步

### 手动模拟（示例 2：`[1,1,1,2,3]`）

| 步骤 | prev | prev->next, 再下一个 | 操作 | 当前链表（从 dummy 起） |
|---|---|---|---|---|
| 1 | dummy | 1, 1 | 相同，x = 1，删掉所有 1 | dummy->2->3 |
| 2 | dummy | 2, 3 | 不同，prev 走到 2 | dummy->2->3 |
| 3 | 2 | 3, NULL | 不足两个结点，结束 | dummy->2->3 |

返回 `dummy.next` = 结点 2，即 `[2,3]`。

### 代码

```c
struct ListNode* deleteDuplicates(struct ListNode* head) {
    struct ListNode dummy;                 // 哑结点，放在 head 前面
    dummy.next = head;
    struct ListNode* prev = &dummy;        // prev：已确定保留的最后一个结点

    // 后面至少还有两个结点时，才可能出现重复
    while (prev->next != NULL && prev->next->next != NULL) {
        if (prev->next->val == prev->next->next->val) {
            int x = prev->next->val;       // 这个值重复了，要全部删掉
            while (prev->next != NULL && prev->next->val == x) {
                struct ListNode* del = prev->next;
                prev->next = del->next;    // 跳过这个结点
                free(del);
            }
            // prev 不动：新的 prev->next 还需要继续判断
        } else {
            prev = prev->next;             // 值唯一，保留，prev 前进
        }
    }
    return dummy.next;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点最多被访问、删除一次。
- **空间复杂度 O(1)**：只用了哑结点和几个指针。

---

## ⚠️ 第五步：小白常见错误

1. **不用哑结点，返回 `head`**：示例 2 中头结点 1 被删了，返回 `head` 就是返回一个已经 `free` 掉的结点，输出乱码甚至崩溃。
2. **只删掉"多出来"的那几个**：写成 83 题的逻辑，`[1,1,2]` 会得到 `[1,2]`。本题要把**第一个 1 也删掉**。
3. **内层 `while` 没判断 `prev->next != NULL`**：链表以重复值结尾（如 `[1,2,2]`）时，删到最后 `prev->next` 是 `NULL`，再取 `->val` 就崩溃。
4. **删除后 `prev` 也往后走**：对 `[1,1,2,2]`，删完 1 后 `prev` 如果前进到 2，就会把第一个 2 当成"唯一"保留下来。
5. **返回 `&dummy`**：`dummy` 是局部变量，函数返回后就无效了，必须返回 `dummy.next`。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 计数数组 + 删除 | O(n) | O(值域) | ⭐ | 依赖值域小，不通用 |
| 哑结点 + 一次遍历 | O(n) | O(1) | ⭐⭐ | **推荐**，利用了有序 |

> 🎯 **学习建议**：只要题目里"头结点可能被删/被换掉"，就先写一个 `dummy`，几乎不会错。
