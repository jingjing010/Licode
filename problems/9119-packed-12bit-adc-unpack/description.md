# 两个12位 ADC 样本解包

每3字节编码两个12位无符号样本：A=(b0<<4)|(b1>>4)，B=((b1&15)<<8)|b2。输入长度为3的倍数且≤1023，返回按原序的样本数组。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* unpackAdc12(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[18,52,86]
```
输出：
```text
[291,1110]
```

## 示例 2

输入：
```text
[255,255,255]
```
输出：
```text
[4095,4095]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
