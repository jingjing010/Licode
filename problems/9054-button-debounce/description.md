机械按键在按下和松开的瞬间，金属触点会弹跳几毫秒，MCU 读到的电平会在 0 和 1 之间来回抖动。如果直接把每次电平变化都当成一次按键，按一下可能被识别成好几下。所以软件里必须做**消抖**：电平变成新值之后，要**连续保持一段时间**才认为按键状态真的改变了。

MCU 每 1ms 读一次按键引脚，得到采样序列 `samples`（`1` 表示按下，`0` 表示松开）。消抖规则如下：

- 按键的**稳定状态**初始为 `0`（松开）。
- 当采样值与稳定状态不同时，开始计数；只有**连续 `stableCount` 个**采样值都与稳定状态不同，稳定状态才翻转，并在**第 `stableCount` 个采样的下标**产生一个事件。
- 计数过程中只要出现一次与稳定状态相同的采样，就认为之前是抖动，计数清零。

请返回所有事件，每个事件为 `[下标, 新的稳定状态]`，按时间顺序排列。

### 示例 1

```
输入：samples = [0,1,0,1,1,1,1,0,1,0,0,0], stableCount = 3
输出：[[5,1],[11,0]]
解释：
下标 1 变成 1，但下标 2 又回到 0，是抖动，计数清零。
下标 3、4、5 连续 3 个 1 → 在下标 5 确认"按下"，事件 [5,1]。
下标 7 是 0，下标 8 又是 1（抖动）；下标 9、10、11 连续 3 个 0 → 在下标 11 确认"松开"，事件 [11,0]。
```

### 示例 2

```
输入：samples = [1,0,0,1], stableCount = 1
输出：[[0,1],[1,0],[3,1]]
解释：stableCount = 1 相当于不消抖，每次电平变化都产生事件；下标 2 的 0 与稳定状态相同，不产生事件。
```

### 示例 3

```
输入：samples = [1,1,1,0,1,1], stableCount = 4
输出：[]
解释：1 最多只连续出现了 3 次，没有达到 4 次，状态始终为 0。
```

### 提示

- `1 <= len <= 5 * 10^4`
- `samples[i]` 为 `0` 或 `1`
- `1 <= stableCount <= 1000`

### 函数说明

```c
int** debounce(const uint8_t* samples, size_t len, uint16_t stableCount,
               int* returnSize, int** returnColumnSizes);
```

- 返回值：`malloc` 申请的二维数组，每行是一个事件 `[下标, 新状态]`
- `*returnSize`：事件个数；`*returnColumnSizes`：`malloc` 申请的数组，每个元素都是 `2`

### 自定义输入格式

```
[0,1,0,1,1,1,1,0,1,0,0,0]
3
```

第 1 行是采样序列，第 2 行是 `stableCount`。
