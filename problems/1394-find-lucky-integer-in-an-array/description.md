# 找出数组中的幸运数

幸运数指数组中出现次数恰好等于自身数值的数，返回最大的幸运数，不存在返回−1。1 ≤ n ≤ 500，元素1到500。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int findLucky(int* arr,int arrSize);
```

## 示例 1

输入：
```text
[2,2,3,4]
```
输出：
```text
2
```

## 示例 2

输入：
```text
[1,2,2,3,3,3]
```
输出：
```text
3
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
