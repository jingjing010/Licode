# Modbus 写单寄存器请求

构造Modbus RTU功能码06请求。站号1..247，寄存器地址和值0..65535。返回完整8字节帧。CRC多项式反射常数0xA001，初值0xFFFF，无最终异或。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* modbusWriteSingle(int address,int reg,int value,int* returnSize);
```

## 示例 1

输入：
```text
1
1
3
```
输出：
```text
[1,6,0,1,0,3,152,11]
```

## 示例 2

输入：
```text
17
1
3
```
输出：
```text
[17,6,0,1,0,3,154,155]
```

## 自定义输入格式

按顺序每行一个参数：address、reg、value。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
