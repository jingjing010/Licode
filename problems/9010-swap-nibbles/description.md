一个字节由两个 **半字节**（nibble，4 位）组成：高 4 位和低 4 位。很多外设按半字节组织数据，例如 RTC 时钟芯片（DS1307、PCF8563 等）用 **BCD 码** 存时间，一个字节的高 4 位是十位、低 4 位是个位：`0x59` 表示 59 秒。有些器件（或者某些通信协议）规定的半字节顺序与单片机代码约定的正好相反，这时就需要把一个字节的 **高 4 位和低 4 位互换**。

给定一个字节 `x`，请返回把它的高 4 位与低 4 位交换后得到的字节。

### 示例 1

```
输入：x = 18
输出：33
解释：18 = 0x12，交换后为 0x21 = 33。
```

### 示例 2

```
输入：x = 171
输出：186
解释：171 = 0xAB，交换后为 0xBA = 186。
```

### 示例 3

```
输入：x = 15
输出：240
解释：15 = 0x0F，交换后为 0xF0 = 240。
```

### 提示

- `0 <= x <= 255`

### 函数说明

```c
uint8_t swap_nibbles(uint8_t x);
```

- `x`：原始字节
- 返回值：高低半字节交换后的字节

### 自定义输入格式

```
18
```

输入一行，为十进制整数 `x`。输出为交换后的字节（十进制）。
