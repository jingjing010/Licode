给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：** 答案中不可以包含重复的三元组。

### 示例 1

```
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。
```

### 示例 2

```
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。
```

### 示例 3

```
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0 。
```

### 提示

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

### 函数说明

```c
int** threeSum(int* nums, int numsSize, int* returnSize, int** returnColumnSizes);
```

- `nums`：数组首地址，`numsSize`：数组长度
- 返回值：用 `malloc` 申请的二维数组，每一行是一个用 `malloc` 申请的长度为 3 的 `int` 数组
- `*returnSize`：返回的三元组个数（没有答案时设为 0）
- `*returnColumnSizes`：你需要 `malloc` 一个长度为 `*returnSize` 的 `int` 数组，每个元素写 3，再把它的地址写进 `*returnColumnSizes`

### 自定义输入格式

```
[-1,0,1,2,-1,-4]
```

只有 1 行，是数组 `nums`。（三元组的顺序、三元组内部的顺序都任意，判题时会先把每个三元组内部从小到大排序，再把所有三元组按字典序排序后输出）
