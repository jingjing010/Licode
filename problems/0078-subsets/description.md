给你一个整数数组 `nums` ，数组中的元素 **互不相同** 。返回该数组所有可能的子集（幂集）。

解集 **不能** 包含重复的子集。你可以按 **任意顺序** 返回解集。

### 示例 1

```
输入：nums = [1,2,3]
输出：[[],[1],[1,2],[1,2,3],[1,3],[2],[2,3],[3]]
```

### 示例 2

```
输入：nums = [0]
输出：[[],[0]]
```

### 提示

- `1 <= nums.length <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中的所有元素 **互不相同**

### 函数说明

```c
int** subsets(int* nums, int numsSize, int* returnSize, int** returnColumnSizes);
```

- `nums`：数组首地址，`numsSize`：数组长度
- 返回值：用 `malloc` 申请的二维数组，每一行是一个子集（空集那一行长度为 0）
- `*returnSize`：写入子集的个数（行数）
- `*returnColumnSizes`：你需要 `malloc` 一个长度为行数的 `int` 数组，第 `i` 个元素写第 `i` 个子集的长度，再把它的地址赋给 `*returnColumnSizes`

### 自定义输入格式

```
[1,2,3]
```

只有 1 行：数组 `nums`。（子集之间的顺序、子集内部元素的顺序都任意：判题时会先把每个子集内部从小到大排序，再把所有子集按字典序排序后输出，所以示例输出和力扣原题的顺序不同）
