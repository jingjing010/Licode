# 71. 简化路径 —— 小白详细题解

> 这道题是"栈"在真实场景中的应用：你在命令行里敲 `cd ..`，系统就是用类似的办法算出你现在在哪个目录的。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一条写得很"乱"的路径（有多余的 `/`、有 `.`、有 `..`），请你把它整理成最干净的写法。

把路径按 `/` 切开，每一段只有 3 种情况：

| 段 | 含义 | 怎么处理 |
|---|---|---|
| 空（来自 `//` 或末尾的 `/`） | 没有意义 | 忽略 |
| `.` | 当前目录 | 忽略 |
| `..` | 上一级目录 | 删掉最近进入的那个目录（如果有的话） |
| 其他（包括 `...`） | 一个目录名 | 进入这个目录 |

走一遍示例 5：`"/.../a/../b/c/../d/./"`，用一个"栈"记录当前所在的目录链：

| 当前段 | 操作 | 栈（底→顶） |
|---|---|---|
| `...` | 进入 | `...` |
| `a` | 进入 | `...`, `a` |
| `..` | 返回上一级（弹出 `a`） | `...` |
| `b` | 进入 | `...`, `b` |
| `c` | 进入 | `...`, `b`, `c` |
| `..` | 弹出 `c` | `...`, `b` |
| `d` | 进入 | `...`, `b`, `d` |
| `.` | 忽略 | `...`, `b`, `d` |

最后从栈底到栈顶拼起来：`"/.../b/d"`。

**几个需要注意的细节：**

1. 在根目录 `/` 再 `..` 还是根目录，所以**栈为空时遇到 `..` 什么都不做**（示例 4）。
2. `...`、`....` 是**普通目录名**，只有恰好是 `.` 或 `..` 才特殊。
3. 栈空时答案是 `"/"`，不是空字符串。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用数组实现栈

C 语言没有现成的栈，最简单的做法是"数组 + 栈顶下标"：

```c
int stack[100];
int top = 0;             // 栈里有几个元素；栈顶元素是 stack[top - 1]

stack[top++] = x;        // push：先放到 stack[top]，再 top 加 1
top--;                   // pop：栈顶下移即可（不用真的清除数据）
if (top > 0) { ... }     // 判断栈非空
```

如果栈的大小要根据输入决定，就用 `malloc` 申请：`int* stack = (int*)malloc(sizeof(int) * n);`，用完 `free(stack);`。

### 2. 字符串的长度和结尾

C 的字符串是以 `'\0'` 结尾的 `char` 数组。`strlen(path)` 返回 `'\0'` 之前的字符个数。
我们返回的新字符串也必须**手动在末尾写上 `'\0'`**，否则判题程序会一直往后读出乱码。

### 3. `memcpy` 拷贝一段字符

`memcpy(dst, src, len)`：把从 `src` 开始的 `len` 个字节复制到 `dst`。拷贝一段目录名时很方便。

---

## 💡 第三步：思路一 —— 切分 + 字符串栈（最直观）

### 思路

1. 从左到右扫描，跳过连续的 `/`，然后读出一段名字（直到下一个 `/` 或结尾）。
2. 把这段名字**复制**成一个独立的字符串，按上面的表格处理：`..` 弹栈，`.` 忽略，其他压栈。
3. 最后把栈里的字符串依次拼接，每个前面加一个 `/`。

### 代码

```c
char* simplifyPath(char* path) {
    int n = strlen(path);
    // 栈里存的是 char*（每个目录名一个字符串），最多 n 个
    char** stack = (char**)malloc(sizeof(char*) * (n + 1));
    int top = 0;

    int i = 0;
    while (i < n) {
        while (i < n && path[i] == '/') i++;      // 1. 跳过连续的 '/'
        if (i >= n) break;                        //    后面没有名字了
        int j = i;
        while (j < n && path[j] != '/') j++;      // 2. [i, j) 是一段名字
        int len = j - i;

        // 3. 把这段名字复制成独立的字符串（多 1 个字节放 '\0'）
        char* name = (char*)malloc(len + 1);
        memcpy(name, path + i, len);
        name[len] = '\0';

        if (strcmp(name, ".") == 0) {
            free(name);                           // "." 什么都不做
        } else if (strcmp(name, "..") == 0) {
            free(name);
            if (top > 0) {                        // 栈非空才能返回上一级
                top--;
                free(stack[top]);
            }
        } else {
            stack[top++] = name;                  // 普通目录名：压栈
        }
        i = j;
    }

    // 4. 拼接结果：总长度不会超过原路径长度 + 1
    char* res = (char*)malloc(n + 2);
    int k = 0;
    for (int t = 0; t < top; t++) {
        res[k++] = '/';
        int len = strlen(stack[t]);
        memcpy(res + k, stack[t], len);
        k += len;
        free(stack[t]);
    }
    if (k == 0) res[k++] = '/';                   // 栈空：答案是根目录 "/"
    res[k] = '\0';                                // 别忘了结尾符
    free(stack);
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个字符被扫描、复制常数次。
- **空间复杂度 O(n)**：栈和复制出来的名字总长度不超过 n。

## 🚀 第四步：思路二 —— 只在栈里记"位置"，不复制字符串

### 思路

思路一里每段名字都 `malloc` 了一次，其实没必要：名字就在 `path` 里，我们只要记住**它从哪开始、有多长**。
于是栈里存两个整数：`starts[t]`（起点下标）和 `lens[t]`（长度）。判断 `.`、`..` 也不用 `strcmp`，直接看长度和字符。

### 手动模拟（示例 3：`"/home/user/Documents/../Pictures"`）

| 段 | 起点 i | 长度 | 操作 | 栈（起点,长度） |
|---|---|---|---|---|
| home | 1 | 4 | 压栈 | (1,4) |
| user | 6 | 4 | 压栈 | (1,4) (6,4) |
| Documents | 11 | 9 | 压栈 | (1,4) (6,4) (11,9) |
| .. | 21 | 2 | 弹栈 | (1,4) (6,4) |
| Pictures | 24 | 8 | 压栈 | (1,4) (6,4) (24,8) |

拼接：`/home` + `/user` + `/Pictures`。

### 代码

```c
char* simplifyPath(char* path) {
    int n = strlen(path);
    int* starts = (int*)malloc(sizeof(int) * (n + 1));   // 栈：每段名字的起点
    int* lens = (int*)malloc(sizeof(int) * (n + 1));     // 栈：每段名字的长度
    int top = 0;

    int i = 0;
    while (i < n) {
        while (i < n && path[i] == '/') i++;     // 跳过连续的 '/'
        if (i >= n) break;
        int j = i;
        while (j < n && path[j] != '/') j++;     // [i, j) 是一段名字
        int len = j - i;

        if (len == 1 && path[i] == '.') {
            // "."：忽略
        } else if (len == 2 && path[i] == '.' && path[i + 1] == '.') {
            if (top > 0) top--;                  // ".."：返回上一级
        } else {
            starts[top] = i;                     // 普通名字：记下位置
            lens[top] = len;
            top++;
        }
        i = j;
    }

    char* res = (char*)malloc(n + 2);
    int k = 0;
    for (int t = 0; t < top; t++) {
        res[k++] = '/';
        memcpy(res + k, path + starts[t], lens[t]);   // 直接从原串里拷
        k += lens[t];
    }
    if (k == 0) res[k++] = '/';
    res[k] = '\0';
    free(starts);
    free(lens);
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(n)**，但省掉了大量小块 `malloc/free`，更快也更不容易写错内存。

---

## ⚠️ 第五步：小白常见错误

1. **栈空时也执行 `top--`** → `top` 变成 -1，之后 `starts[-1]` 越界。遇到 `..` 一定先判断 `top > 0`。
2. **把 `...` 当成 `..` 处理** → 用 `strncmp(name, "..", 2) == 0` 判断会把 `...` 也算进去。必须要求长度恰好是 2。
3. **栈为空时返回空字符串 `""`** → 正确答案是 `"/"`（示例 4）。
4. **返回的字符串忘了写 `'\0'`** → 输出后面跟着乱码。
5. **`malloc(len)` 少申请 1 个字节** → 复制名字时没有地方放 `'\0'`，写越界。
6. **返回局部数组 `char res[3001];`** → 函数结束后内存失效，必须用 `malloc`。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 特点 |
|---|---|---|---|---|
| 字符串栈 | O(n) | O(n) | ⭐⭐ | 思路直观，但每段都要 malloc/free |
| 位置栈 | O(n) | O(n) | ⭐⭐ | 不复制字符串，代码更短更快 |
