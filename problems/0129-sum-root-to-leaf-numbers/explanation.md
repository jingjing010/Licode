# 129. 求根节点到叶节点数字之和 —— 小白详细题解

> 一句话题解：**往下走一步，数字就 ×10 再加上新结点的值**；走到叶子时，把拼好的数加进答案。

---

## 📖 第一步：先读懂题目

每条"从根一直走到叶子"的路径，把经过的数字连起来读，就是一个十进制数。把所有这样的数加起来。

示例 2：

```
      4
     / \
    9   0
   / \
  5   1
```

| 路径 | 拼出的数 |
|---|---|
| 4 → 9 → 5 | 495 |
| 4 → 9 → 1 | 491 |
| 4 → 0 | 40 |
| **合计** | **1026** |

**几个需要注意的细节：**

1. **只有叶子**（左右孩子都为空）才是路径的终点。像示例 2 中的 `9` 有孩子，它不是终点，`49` 不算一个数。
2. 一个结点只有一个孩子时（比如只有左孩子），它也**不是叶子**，不能在它这里结束。
3. 数字里可以有 0，路径 `1 → 0 → 9` 表示 `109`；根是 0 时，`0 → 5` 表示 `5`。
4. 树最深 10 层，题目保证答案不超过 32 位整数，用 `int` 就够了。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. "在数字后面接一位"

数字 `49` 后面接 `5`，变成 `49 * 10 + 5 = 495`。所以从根往下走时只需要维护一个整数：

```c
int cur = prefix * 10 + node->val;
```

### 2. 递归函数带参数"往下传"

前面几道题递归函数大多是"从下往上返回结果"（比如求高度）。这道题需要把"已经拼出来的数"**从上往下传**，最自然的做法就是把它作为递归函数的参数。因为是**按值传递**，每个分支拿到的都是自己的副本，左右子树互不影响，不需要手动"撤销"。

### 3. 判断叶子

```c
if (node->left == NULL && node->right == NULL)   // 两个孩子都为空才是叶子
```

---

## 💡 第三步：思路一 —— 递归 DFS，把前缀往下传

### 思路

定义 `dfs(node, prefix)`：`prefix` 是从根走到 `node` **之前**拼出来的数，函数返回"以 `node` 为根的子树里，所有到叶子的路径数字之和"。

1. `node` 为空：返回 0（没有路径）。
2. 先算出走到 `node` 后的数：`cur = prefix * 10 + node->val`。
3. `node` 是叶子：这条路径结束，返回 `cur`。
4. 否则返回 `dfs(左孩子, cur) + dfs(右孩子, cur)`。

### 手动模拟（示例 2）

| 调用 | prefix | cur | 是叶子？ | 返回 |
|---|---|---|---|---|
| dfs(4, 0) | 0 | 4 | 否 | 986 + 40 = 1026 |
| dfs(9, 4) | 4 | 49 | 否 | 495 + 491 = 986 |
| dfs(5, 49) | 49 | 495 | 是 | 495 |
| dfs(1, 49) | 49 | 491 | 是 | 491 |
| dfs(0, 4) | 4 | 40 | 是 | 40 |

### 代码

```c
// prefix：从根走到 node 之前已经拼出的数
// 返回：以 node 为根的子树中，所有"到叶子的路径"代表的数字之和
int dfs(struct TreeNode* node, int prefix) {
    if (node == NULL) return 0;                         // 空结点：没有路径
    int cur = prefix * 10 + node->val;                  // 把自己接到数字末尾
    if (node->left == NULL && node->right == NULL) {
        return cur;                                     // 叶子：一条完整路径
    }
    return dfs(node->left, cur) + dfs(node->right, cur); // 左右子树的路径加起来
}

int sumNumbers(struct TreeNode* root) {
    return dfs(root, 0);                                // 根之前什么也没有，前缀是 0
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个结点访问一次。
- **空间复杂度 O(h)**：递归栈，h 为树高（本题 h ≤ 10）。

## 🚀 第四步：思路二 —— BFS，队列里同时存"结点"和"拼到这里的数"

### 思路

不想用递归的话，可以用队列做层序遍历。关键是：每个结点入队时，**把从根到它拼出来的数一起入队**（用两个平行数组）。

1. 根入队，对应的数是 `root->val`。
2. 出队一个结点 `t` 和它的数 `num`：
   - `t` 是叶子：`sum += num`；
   - 否则把它的孩子入队，孩子对应的数是 `num * 10 + 孩子的值`。

### 手动模拟（示例 2）

| 出队 | num | 是叶子？ | 入队 | sum |
|---|---|---|---|---|
| 4 | 4 | 否 | (9, 49), (0, 40) | 0 |
| 9 | 49 | 否 | (5, 495), (1, 491) | 0 |
| 0 | 40 | 是 | — | 40 |
| 5 | 495 | 是 | — | 535 |
| 1 | 491 | 是 | — | 1026 |

### 代码

```c
int sumNumbers(struct TreeNode* root) {
    if (root == NULL) return 0;
    // 结点最多 1000 个，每个只入队一次
    struct TreeNode** nodeQ = (struct TreeNode**)malloc(sizeof(struct TreeNode*) * 1000);
    int* numQ = (int*)malloc(sizeof(int) * 1000);       // numQ[i] 对应 nodeQ[i] 拼出的数
    int head = 0, tail = 0, sum = 0;

    nodeQ[tail] = root;
    numQ[tail] = root->val;
    tail++;

    while (head < tail) {
        struct TreeNode* t = nodeQ[head];
        int num = numQ[head];
        head++;
        if (t->left == NULL && t->right == NULL) {      // 叶子：累加
            sum += num;
            continue;
        }
        if (t->left != NULL) {
            nodeQ[tail] = t->left;
            numQ[tail] = num * 10 + t->left->val;
            tail++;
        }
        if (t->right != NULL) {
            nodeQ[tail] = t->right;
            numQ[tail] = num * 10 + t->right->val;
            tail++;
        }
    }

    free(nodeQ);
    free(numQ);
    return sum;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，**空间复杂度 O(n)**（队列）。

## ⚠️ 第五步：小白常见错误

1. **在空结点处累加**：

   ```c
   if (node == NULL) return prefix;   // ❌ 只有一个孩子的结点会把自己的数多算一次
   ```

   例如 `[1,0]`：结点 1 的右孩子为空，这样写会多加一个 `1`，答案变成 11 而不是 10。必须在**叶子**处累加，空结点返回 0。
2. **把只有一个孩子的结点当叶子**：判断叶子要求 `left` 和 `right` **都**为 `NULL`。
3. **把 `cur` 写成 `prefix + node->val * 10`**：是"旧数 ×10 + 新数字"，不是反过来。
4. **用全局变量累加却没清零**：如果写 `int sum = 0;` 放在函数外面，判题多次调用时会累加上次的结果。用返回值传递最安全。
5. **在 `dfs` 里修改 `prefix` 后又传给另一个分支**：例如先 `prefix = prefix * 10 + val` 再分别递归是没问题的，但如果在递归左子树的过程中改了同一个变量（用指针传递），右子树拿到的前缀就错了。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 递归 DFS 传前缀 | O(n) | O(h) | ⭐⭐ | 推荐，最简洁 |
| BFS + 平行队列 | O(n) | O(n) | ⭐⭐ | 不想写递归时用 |
