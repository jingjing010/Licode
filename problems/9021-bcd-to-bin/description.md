DS1307、DS3231、PCF8563 等实时时钟（RTC）芯片把秒、分、时、日、月、年保存在寄存器里，格式是 **BCD 码（Binary-Coded Decimal，二进制编码的十进制）**：一个字节的**高 4 位存十位数字，低 4 位存个位数字**。例如 59 秒在寄存器里是 `0x59`（十进制值 89），23 点是 `0x23`（十进制值 35）。

MCU 通过 I2C 读出寄存器后，必须先把 BCD 码转换成普通二进制数，才能做加减比较或者显示。

请实现函数 `bcd_to_bin`：输入一个合法的 BCD 字节，返回它表示的数值（0~99）。

判题程序会把一次 I2C 连续读回的若干个寄存器依次交给你的函数，并输出转换结果。

### 示例 1

```
输入：regs = [89,35,18]
输出：[59,23,12]
解释：0x59 -> 59，0x23 -> 23，0x12 -> 12。例如秒寄存器 0x59、分寄存器 0x23、时寄存器 0x12，表示 12:23:59。
```

### 示例 2

```
输入：regs = [0,9,16,153]
输出：[0,9,10,99]
解释：0x00 -> 0，0x09 -> 9，0x10 -> 10，0x99 -> 99。
```

### 示例 3

```
输入：regs = [37]
输出：[25]
解释：37 = 0x25，表示 25。
```

### 提示

- `1 <= regs 长度 <= 1000`
- 每个字节都是合法 BCD 码：高 4 位和低 4 位都在 `0~9` 之间（即十六进制 `0x00 ~ 0x99`）

### 函数说明

```c
uint8_t bcd_to_bin(uint8_t bcd);
```

- `bcd`：一个合法的 BCD 字节
- 返回值：它表示的十进制数值 `0~99`

### 自定义输入格式

```
[89,35,18]
```

只有 1 行：寄存器字节数组（十进制写法，每个元素都是合法 BCD 码）。输出为逐个调用 `bcd_to_bin` 的结果数组。
