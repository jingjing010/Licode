# 比较版本号：题解

## 📖 先读懂题目

逐段读取点分隔的版本号，缺失段视为0。比较的是各段整数值，不能直接比较字符串，也不能把版本号转成小数。段前的0不影响整数值。

### 示例1

输入：
```text
"1.2"
"1.10"
```
输出：
```text
-1
```

### 示例2

输入：
```text
"1.01"
"1.001"
```
输出：
```text
0
```

### 示例3

输入：
```text
"1.0"
"1.0.0.0"
```
输出：
```text
0
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 把版本号按 '.' 切成一段一段的修订号，然后从左到右一段一段地比较整数大小。
2. 不需要真的切分字符串：用两个指针 i、j 分别在两个字符串上走，每次把一段连续数字转成整数（x = x * 10 + 数字），前导零会自然消失。
3. 某个字符串已经走完时，它后面缺失的修订号就当作 0；两个指针都走完还没分出大小，就返回 0。

## 可直接提交的 C 代码

```c
int compareVersion(char* version1, char* version2) {
    int i = 0, j = 0;
    while (version1[i] || version2[j]) {
        long long x = 0, y = 0;
        while (version1[i] && version1[i] != '.') x = x * 10 + (version1[i++] - '0');
        while (version2[j] && version2[j] != '.') y = y * 10 + (version2[j++] - '0');
        if (x != y) return x < y ? -1 : 1;
        if (version1[i] == '.') i++;
        if (version2[j] == '.') j++;
    }
    return 0;
}
```

## 📊 复杂度

时间 O(n+m)，空间 O(1)。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。

## 🔗 举一反三

改变输入长度为1、重复值、边界整数，手工验证每一步保存的状态。思考能否在输入逐个到达时保留相同的状态完成计算。
