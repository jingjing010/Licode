六轴传感器 MPU6050 通过 I2C 一次性读出加速度和角速度寄存器：每个轴的数据占 2 个字节，**高字节在前（大端）**，数值是 **16 位有符号整数（补码）**。例如 `ACCEL_XOUT_H = 0xFF, ACCEL_XOUT_L = 0xFE` 表示 X 轴加速度原始值为 `-2`。

请实现函数 `parse_s16_be`：缓冲区 `buf` 中共有 `len` 个字节（`len` 为偶数），依次包含 `len / 2` 个大端 int16 数据。把第 `i` 个数据（由 `buf[2i]` 和 `buf[2i+1]` 组成）解析出来，写入 `out[i]`。

`out` 的类型是 `int32_t`，方便后续换算物理量时不溢出——所以你必须**正确地处理符号**：`0xFFFE` 要得到 `-2`，而不是 `65534`。

### 示例 1

```
输入：buf = [18,52,255,254,128,0]
输出：[4660,-2,-32768]
解释：0x1234 = 4660；0xFFFE 是 -2 的补码；0x8000 是 int16 的最小值 -32768。
```

### 示例 2

```
输入：buf = [64,0,192,0,0,16]
输出：[16384,-16384,16]
解释：0x4000 = 16384（量程 ±2g 时表示 +1g）；0xC000 = -16384（-1g）；0x0010 = 16。
```

### 示例 3

```
输入：buf = [127,255]
输出：[32767]
```

### 提示

- `2 <= len <= 1000`，且 `len` 为偶数
- `0 <= buf[i] <= 255`
- `out` 已由调用者分配好 `len / 2` 个元素的空间

### 函数说明

```c
void parse_s16_be(const uint8_t* buf, int len, int32_t* out);
```

- `buf`：I2C 读回的原始字节，`len`：字节数
- `out`：输出数组，你需要写入 `out[0] ~ out[len/2 - 1]`
- 无返回值

### 自定义输入格式

```
[18,52,255,254,128,0]
```

只有 1 行：字节数组 `buf`（每个元素 0~255，长度为偶数）。输出为 `out` 中的 `len / 2` 个整数。
