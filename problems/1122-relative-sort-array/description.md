# 数组的相对排序

arr2无重复且每个值出现在arr1中；arr1按arr2指定次序排列重复值，其他值在末尾升序排列。数组长度1到1000，元素0到1000。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* relativeSortArray(int* arr1,int arr1Size,int* arr2,int arr2Size,int* returnSize);
```

## 示例 1

输入：
```text
[2,3,1,3,2,4,6,7,9,2,19]
[2,1,4,3,9,6]
```
输出：
```text
[2,2,2,1,4,3,3,9,6,7,19]
```

## 示例 2

输入：
```text
[28,6,22,8,44,17]
[22,28,8,6]
```
输出：
```text
[22,28,8,6,17,44]
```

## 自定义输入格式

按顺序每行一个参数：arr1、arr2。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
