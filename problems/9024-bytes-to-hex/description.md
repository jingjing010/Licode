调试通信协议时，最常用的手段就是把收到的原始字节**以十六进制文本打印到串口日志**，例如 `RX: 1234ABCD`；很多 AT 指令模组（NB-IoT、LoRa）发送二进制数据时，也要求把数据转成十六进制字符串放进命令里，例如 `AT+NMGS=4,1234ABCD`。

请实现函数 `bytes_to_hex`：把 `buf` 中的 `len` 个字节转换成十六进制字符串返回。

- 每个字节固定输出 **2 个字符**（高 4 位在前），不足两位补 `0`，例如 `10` 输出 `"0A"`
- 字母使用**大写** `A~F`
- 返回的字符串由 `malloc` 分配，以 `'\0'` 结尾（调用者负责 `free`）
- 不要使用 `sprintf` / `snprintf` 等格式化函数

### 示例 1

```
输入：buf = [18,52,171,205]
输出："1234ABCD"
解释：18 = 0x12，52 = 0x34，171 = 0xAB，205 = 0xCD。
```

### 示例 2

```
输入：buf = [0,255,10]
输出："00FF0A"
解释：0 -> "00"，255 -> "FF"，10 -> "0A"（前导 0 不能省略）。
```

### 示例 3

```
输入：buf = []
输出：""
```

### 提示

- `0 <= len <= 1000`
- `0 <= buf[i] <= 255`

### 函数说明

```c
char* bytes_to_hex(const uint8_t* buf, int len);
```

- `buf`：要转换的字节，`len`：字节数
- 返回值：`malloc` 分配的十六进制字符串，长度为 `2 * len`

### 自定义输入格式

```
[18,52,171,205]
```

只有 1 行：字节数组 `buf`（每个元素 0~255）。输出为带双引号的结果字符串。
