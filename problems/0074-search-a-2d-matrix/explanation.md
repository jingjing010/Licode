# 74. 搜索二维矩阵 —— 小白详细题解

> 这道题的关键是一个"视角转换"：把二维矩阵**看成**一个一维的有序数组，然后就是普通的二分查找。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一个表格，每一行从左到右是从小到大的，而且**下一行的第一个数比上一行的最后一个数还大**。问 `target` 在不在表格里。

示例 1 的矩阵：

| | 第 0 列 | 第 1 列 | 第 2 列 | 第 3 列 |
|---|---|---|---|---|
| 第 0 行 | 1 | **3** | 5 | 7 |
| 第 1 行 | 10 | 11 | 16 | 20 |
| 第 2 行 | 23 | 30 | 34 | 60 |

`target = 3` 在第 0 行第 1 列，返回 `true`；`target = 13` 找不到，返回 `false`。

**几个需要注意的细节：**

1. 两个条件合起来意味着：**一行接一行读下去，整个矩阵就是一串升序数字** `1,3,5,7,10,11,16,20,23,30,34,60`。
2. 返回的是 `bool`（`true`/`false`），不是下标。
3. 矩阵至少 1 行 1 列，不用担心空矩阵。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 力扣的二维数组参数

```c
bool searchMatrix(int** matrix, int matrixSize, int* matrixColSize, int target)
```

| 参数 | 含义 |
|---|---|
| `int** matrix` | "指针的数组"：`matrix[i]` 是第 `i` 行的首地址，`matrix[i][j]` 就是第 `i` 行第 `j` 列 |
| `int matrixSize` | 行数 |
| `int* matrixColSize` | 一个数组，第 `i` 行有 `matrixColSize[i]` 列。本题每行一样长，用 `matrixColSize[0]` |

### 2. 一维下标和二维坐标的换算

假设每行有 `n` 列，把矩阵按行拼成一维后，一维下标 `k` 对应：

```c
int row = k / n;   // 第几行（整除）
int col = k % n;   // 第几列（取余）
```

例如 `n = 4`，`k = 6`：`6 / 4 = 1` 行，`6 % 4 = 2` 列，也就是 `matrix[1][2] = 16`。

### 3. `bool` 类型

C 语言原本没有 `bool`，需要 `#include <stdbool.h>`（本 OJ 已经帮你包含了），然后就能用 `true` / `false`。

---

## 💡 第三步：思路一 —— 逐个检查（最容易想到）

### 思路

两层循环，把每个格子都和 `target` 比一下。

### 代码

```c
bool searchMatrix(int** matrix, int matrixSize, int* matrixColSize, int target) {
    for (int i = 0; i < matrixSize; i++) {            // 遍历每一行
        for (int j = 0; j < matrixColSize[i]; j++) {  // 遍历这一行的每一列
            if (matrix[i][j] == target) {
                return true;                          // 找到了
            }
        }
    }
    return false;                                     // 全看完都没找到
}
```

### 复杂度分析

- **时间复杂度 O(m × n)**：最多 100 × 100 = 10⁴ 个格子，本题能过，但完全没利用"有序"这个条件。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 当成一维数组二分查找

### 思路

既然按行读下来是一串升序数字，那就在**下标 `0` 到 `m*n-1`** 上做二分查找。每次算出中点 `mid` 后，用 `mid / n` 和 `mid % n` 找到它在矩阵里的真实位置。

### 手动模拟（示例 1，`target = 3`，`n = 4`，共 12 个数）

| 轮次 | lo | hi | mid | 坐标 (mid/4, mid%4) | 值 | 操作 |
|---|---|---|---|---|---|---|
| 1 | 0 | 11 | 5 | (1, 1) | 11 | 11 > 3，hi = 4 |
| 2 | 0 | 4 | 2 | (0, 2) | 5 | 5 > 3，hi = 1 |
| 3 | 0 | 1 | 0 | (0, 0) | 1 | 1 < 3，lo = 1 |
| 4 | 1 | 1 | 1 | (0, 1) | 3 | **相等，返回 true** |

### 代码

```c
bool searchMatrix(int** matrix, int matrixSize, int* matrixColSize, int target) {
    int m = matrixSize;          // 行数
    int n = matrixColSize[0];    // 列数（每行都一样）
    int lo = 0, hi = m * n - 1;  // 在"虚拟一维数组"的闭区间 [lo, hi] 上二分

    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        int v = matrix[mid / n][mid % n];   // 一维下标 -> 二维坐标
        if (v == target) {
            return true;                    // 找到
        } else if (v < target) {
            lo = mid + 1;                   // 中间值太小，去右半边
        } else {
            hi = mid - 1;                   // 中间值太大，去左半边
        }
    }
    return false;                           // 区间为空，没找到
}
```

### 复杂度分析

- **时间复杂度 O(log(m × n))**：10⁴ 个数最多约 14 次比较。
- **空间复杂度 O(1)**：没有真的去拼一维数组，只是在"脑子里"换算坐标。

---

## ⚠️ 第五步：小白常见错误

1. **坐标换算用了行数 `m`**：写成 `matrix[mid / m][mid % m]` 是错的，要除以**列数** `n`。
2. **`hi` 初始化为 `m * n`，却用 `lo <= hi` 循环** → `mid` 可能等于 `m * n`，访问 `matrix[m][0]` 越界崩溃。
3. **把 `matrixColSize` 当成整数用**：它是指针（数组），列数是 `matrixColSize[0]`，写 `n = matrixColSize` 会报指针类型错误。
4. **先二分找行时用错比较**：如果用"两次二分"写法，要找"最后一个首元素 `<= target` 的行"，写成"第一个 `>= target`"会错过答案所在行。
5. **找到后忘了 `return true`，只是 `break`** → 函数最后统一 `return false`，结果永远是 `false`。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐个检查 | O(m·n) | O(1) | ⭐ | 保证会写 |
| 一维二分 | O(log(m·n)) | O(1) | ⭐⭐ | 推荐，代码短且不易错 |
