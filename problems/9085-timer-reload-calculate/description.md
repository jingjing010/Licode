# 定时器重装载值计算

返回16位向上计数器的ARR。频率公式f=clockHz/((prescaler+1)*(ARR+1))，计数四舍五入（中点向上）。保证舍入计数在1..65536；PSC在0..65535，频率正，时钟≤10^8。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int timerReload(int clockHz,int prescaler,int frequency);
```

## 示例 1

输入：
```text
72000000
71
1000
```
输出：
```text
999
```

## 示例 2

输入：
```text
48000000
47
100
```
输出：
```text
9999
```

## 自定义输入格式

按顺序每行一个参数：clockHz、prescaler、frequency。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
