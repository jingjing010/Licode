给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

### 示例 1

```
1 -> 2 -> 3 -> 4 -> 5
  删除倒数第 2 个（4）
1 -> 2 -> 3 -> 5
```

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

### 示例 2

```
输入：head = [1], n = 1
输出：[]
```

### 示例 3

```
输入：head = [1,2], n = 1
输出：[1]
```

### 提示

- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**进阶：** 你能尝试使用一趟扫描实现吗？

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* removeNthFromEnd(struct ListNode* head, int n);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `head`：链表的头指针（至少 1 个结点）
- `n`：要删除倒数第几个结点（`n = 1` 表示最后一个）
- 返回值：删除后链表的头指针。删除的可能正好是头结点，链表也可能变成空链表（返回 `NULL`）

### 自定义输入格式

```
[1,2,3,4,5]
2
```

第 1 行是链表 `head`，第 2 行是整数 `n`。输出为删除后的链表。
