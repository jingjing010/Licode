# 412. Fizz Buzz —— 小白详细题解

> 逻辑非常简单，难点全在 C 语言：**如何返回一个字符串数组**。这是理解 `char**` 和二级 `malloc` 的绝佳练习。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 从 1 数到 n：遇到 3 的倍数说 "Fizz"，5 的倍数说 "Buzz"，既是 3 又是 5 的倍数说 "FizzBuzz"，其他情况就说这个数字本身。把每一句话按顺序装进一个数组返回。

以 `n = 15` 为例：

| i | 3 的倍数？ | 5 的倍数？ | answer |
|---|---|---|---|
| 1 | | | "1" |
| 3 | ✅ | | "Fizz" |
| 5 | | ✅ | "Buzz" |
| 9 | ✅ | | "Fizz" |
| 10 | | ✅ | "Buzz" |
| 15 | ✅ | ✅ | "FizzBuzz" |

**几个需要注意的细节：**

1. 题目的"下标从 1 开始"是指数字从 1 开始；在 C 语言中，数字 `i` 存放在 `answer[i - 1]`。
2. 数字也要转成**字符串**，比如 `"7"` 而不是整数 7。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `char**` 是什么？

- `char*`：一个字符串（指向第一个字符的指针，字符串以 `'\0'` 结尾）。
- `char**`：一个"装着很多 `char*` 的数组"，也就是**字符串数组**。

```
ans ──► [ ans[0] | ans[1] | ans[2] ]
            │        │        │
            ▼        ▼        ▼
           "1"      "2"     "Fizz"
```

### 2. 两层 `malloc`

```c
char** ans = (char**)malloc(sizeof(char*) * n);   // 第一层：放 n 个指针的数组
ans[0] = (char*)malloc(12);                        // 第二层：每个字符串自己的空间
```

- 第一层的每个元素只是一个**指针**（8 字节），不能直接往里写字符。
- 第二层才是真正存字符的地方。

### 3. 每个字符串开多大？

- `"FizzBuzz"` 有 8 个字符，加上 `'\0'` 要 9 字节；
- `"10000"` 有 5 个字符，加 `'\0'` 要 6 字节。

开 12 字节足够放下任何 `int`（最多 11 个字符 + `'\0'`）。

### 4. `strcpy` 和 `sprintf`

```c
strcpy(s, "Fizz");      // 把字符串常量复制到 s 指向的内存（自动带上 '\0'）
sprintf(s, "%d", 7);    // 像 printf 一样格式化，但结果写进 s 而不是屏幕：s = "7"
```

### 5. 为什么不能写 `ans[i] = "Fizz";` 然后数字用局部数组？

`ans[i] = "Fizz";` 让指针指向字符串常量，**其实可以工作**（常量一直存在）。但数字必须写进一块内存，如果用局部数组 `char buf[12]`，函数返回后 `buf` 就失效了。为了统一，每个字符串都 `malloc` 最安全。

---

## 💡 第三步：思路一 —— 直接模拟（if-else 判断）

### 思路

对每个 `i`（1 到 n）：

1. 先判断 `i % 15 == 0`（同时是 3 和 5 的倍数）→ "FizzBuzz"；
2. 否则 `i % 3 == 0` → "Fizz"；
3. 否则 `i % 5 == 0` → "Buzz"；
4. 否则把 `i` 转成字符串。

**判断顺序很重要**：如果先判断 `i % 3 == 0`，15 会被提前当成 "Fizz"。

### 代码

```c
char** fizzBuzz(int n, int* returnSize) {
    // 第一层：申请能放 n 个字符串指针的数组
    char** ans = (char**)malloc(sizeof(char*) * n);

    for (int i = 1; i <= n; i++) {
        char* s = (char*)malloc(12);         // 第二层：给当前字符串申请空间
        if (i % 15 == 0) {                   // 先判断 15 的倍数（同时是 3 和 5 的倍数）
            strcpy(s, "FizzBuzz");
        } else if (i % 3 == 0) {
            strcpy(s, "Fizz");
        } else if (i % 5 == 0) {
            strcpy(s, "Buzz");
        } else {
            sprintf(s, "%d", i);             // 数字转成字符串
        }
        ans[i - 1] = s;                      // 数字 i 放在下标 i-1
    }

    *returnSize = n;                         // 告诉调用者数组长度
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个数处理一次。
- **空间复杂度 O(1)**：除了返回的答案外没有额外空间。

---

## 🚀 第四步：思路二 —— 字符串拼接（更易扩展）

### 思路

如果规则变多（比如 7 的倍数说 "Jazz"），if-else 的组合会爆炸。更好的写法是：

- 先把字符串清空；
- 是 3 的倍数就**追加** "Fizz"，是 5 的倍数就**追加** "Buzz"；
- 最后如果字符串还是空的，才写入数字。

15 会依次追加 "Fizz" 和 "Buzz"，自然得到 "FizzBuzz"。

### 代码

```c
char** fizzBuzz(int n, int* returnSize) {
    char** ans = (char**)malloc(sizeof(char*) * n);

    for (int i = 1; i <= n; i++) {
        char* s = (char*)malloc(12);
        s[0] = '\0';                         // 先设为空字符串，strcat 需要从 '\0' 处接上
        if (i % 3 == 0) {
            strcat(s, "Fizz");               // 追加到末尾
        }
        if (i % 5 == 0) {
            strcat(s, "Buzz");
        }
        if (s[0] == '\0') {                  // 既不是 3 也不是 5 的倍数
            sprintf(s, "%d", i);
        }
        ans[i - 1] = s;
    }

    *returnSize = n;
    return ans;
}
```

- **时间复杂度 O(n)**，**空间复杂度 O(1)**（不计答案）。

---

## ⚠️ 第五步：小白常见错误

1. **先判断 `i % 3 == 0`** → 15、30 等会输出 "Fizz" 而不是 "FizzBuzz"。
2. **只申请了第一层 `malloc`，就 `strcpy(ans[i], "Fizz")`** → `ans[i]` 是没有初始化的野指针，往里写会崩溃。
3. **字符串空间开太小**：`malloc(8)` 放不下 `"FizzBuzz"` 和它末尾的 `'\0'`（共 9 字节），会越界写坏内存。
4. **数字用局部数组再赋给 `ans[i]`**：`char buf[12]; sprintf(buf, "%d", i); ans[i - 1] = buf;` → 所有元素都指向同一块会失效的内存。
5. **下标写成 `ans[i]`，循环 `i` 从 1 到 n** → `ans[n]` 越界，且 `ans[0]` 没有赋值。
6. **忘了 `*returnSize = n`** → 判题程序不知道数组多长，输出为空。
7. **`strcat` 之前没把 `s[0]` 设成 `'\0'`** → `malloc` 的内存里是垃圾数据，`strcat` 会从一个随机位置开始拼接。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 建议 |
|---|---|---|---|
| if-else 模拟 | O(n) | O(1) | 最直观 |
| 字符串拼接 | O(n) | O(1) | 规则多时更好扩展 |
