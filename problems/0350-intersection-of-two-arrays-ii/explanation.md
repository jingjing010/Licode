# 两个数组的交集 II：题解

## 📖 先读懂题目

计数数组记录第一个数组各数值的剩余配额。遍历第二个数组，只有配额大于0才加入结果并扣减。重复元素必须保留较少的出现次数，不能用集合去重。

### 示例1

输入：
```text
[1,2,2,1]
[2,2]
```
输出：
```text
[2,2]
```

### 示例2

输入：
```text
[4,9,5]
[9,4,9,8,4]
```
输出：
```text
[4,9]
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 和 349 题不同，这里重复的数字也要保留：一个数在两个数组中分别出现 a 次和 b 次，答案里就有 min(a, b) 个。
2. 数值只有 0~1000，用一个计数数组 cnt[1001] 统计 nums1 中每个数出现的次数。
3. 遍历 nums2，如果 cnt[x] > 0，就把 x 加入答案并把 cnt[x] 减 1。也可以把两个数组排序后用双指针。

## 可直接提交的 C 代码

```c
/* 计数数组（值域 0~1000），O(n + m) */
int* intersect(int* nums1, int nums1Size, int* nums2, int nums2Size, int* returnSize) {
    int cnt[1001] = {0};
    for (int i = 0; i < nums1Size; i++) cnt[nums1[i]]++;
    int* res = (int*)malloc(sizeof(int) * (nums1Size < nums2Size ? nums1Size : nums2Size));
    int k = 0;
    for (int j = 0; j < nums2Size; j++) {
        if (cnt[nums2[j]] > 0) {
            cnt[nums2[j]]--;
            res[k++] = nums2[j];
        }
    }
    *returnSize = k;
    return res;
}
```

## 📊 复杂度

时间 O(n+m)，空间 O(1001+min(n,m))。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。

## 🔗 举一反三

改变输入长度为1、重复值、边界整数，手工验证每一步保存的状态。思考能否在输入逐个到达时保留相同的状态完成计算。
