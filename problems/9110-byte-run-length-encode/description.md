# 字节游程长度压缩

按[次数,值]顺序输出RLE编码，次数1..255，相同字节尽量合并，超255拆分。空输入输出空数组。输入0到1024字节。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* runLengthEncode(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[49,50,51,52,53,54,55,56,57]
```
输出：
```text
[1,49,1,50,1,51,1,52,1,53,1,54,1,55,1,56,1,57]
```

## 示例 2

输入：
```text
[]
```
输出：
```text
[]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
