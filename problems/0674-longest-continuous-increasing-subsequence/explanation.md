# 最长连续递增序列：题解

## 📖 先读懂题目

run只表示以当前位置结尾的连续递增段长度。当前值大于前一值时run加1，否则回到1；best保存到目前为止所有run的最大值。

### 示例1

输入：
```text
[1,3,5,4,7]
```
输出：
```text
3
```

### 示例2

输入：
```text
[2,2,2,2,2]
```
输出：
```text
1
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 「连续」意味着只需要比较相邻的两个数：nums[i] 是否大于 nums[i-1]。
2. 用一个变量 cur 记录「以当前位置结尾」的递增段长度：递增就 +1，否则重置为 1。
3. 每走一步都用 cur 更新答案 ans = max(ans, cur)，注意是「严格」递增，相等不算。

## 可直接提交的 C 代码

```c
int findLengthOfLCIS(int* nums, int numsSize) {
    int run = 0, best = 0;
    for (int i = 0; i < numsSize; ++i) {
        /* 相等也会中断严格递增区间。 */
        run = i > 0 && nums[i] > nums[i - 1] ? run + 1 : 1;
        if (run > best) best = run;
    }
    return best;
}
```

## 📊 复杂度

时间 O(n)，空间 O(1)。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。

## 🔗 举一反三

改变输入长度为1、重复值、边界整数，手工验证每一步保存的状态。思考能否在输入逐个到达时保留相同的状态完成计算。
