# 控制量变化率限制：题解

## 📖 先读懂题目

初始输出0，每个采样向目标靠近至多step，不能越过目标。targets为int16范围，step0..32767，最多1000项。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[100,100,-100,-100] / 30` | `[30,60,30,0]` |
| 2 | `[1,2,3] / 0` | `[0,0,0]` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

每次计算目标与当前输出的差，把差值限制在±step以内，防止驱动电机时控制量突变。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *slewLimit(int *targets, int targetsSize, int step, int *returnSize) {
    int *out = malloc((targetsSize + 1) * sizeof(int)), y = 0;
    for (int i = 0; i < targetsSize; ++i) {
        int d = targets[i] - y;
        if (d > step)
            d = step;
        if (d < -step)
            d = -step;
        y += d;
        out[i] = y;
    }
    *returnSize = targetsSize;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，输出空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
