# 施密特触发滞回判定

初始状态0。采样≥high置1，≤low置0，其余保持。low<high，所有数值在−32768到32767之间，最多1000个采样。返回每次处理后的状态。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* schmittTrigger(int* samples,int samplesSize,int low,int high,int* returnSize);
```

## 示例 1

输入：
```text
[9,10,11,9,8,7,9]
8
10
```
输出：
```text
[0,1,1,1,0,0,0]
```

## 示例 2

输入：
```text
[0,5,10,5,0]
0
10
```
输出：
```text
[0,0,1,1,0]
```

## 自定义输入格式

按顺序每行一个参数：samples、low、high。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
