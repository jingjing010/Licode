# 50. Pow(x, n) —— 小白详细题解

> 这道题教你一个非常重要的算法：**快速幂**。它能把"乘 n 次"变成"乘 log n 次"，n = 20 亿时只需要乘 60 多次。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 自己实现一个"x 的 n 次方"，不许偷懒直接调用库函数 `pow`。

| x | n | x^n | 输出（保留 5 位小数） |
|---|---|---|---|
| 2.0 | 10 | 2×2×…×2（10 个） | 1024.00000 |
| 2.1 | 3 | 2.1×2.1×2.1 | 9.26100 |
| 2.0 | -2 | 1 / (2×2) | 0.25000 |

**几个需要注意的细节：**

1. `n` 可以是**负数**：`x^(-n) = 1 / x^n`，也等于 `(1/x)^n`。
2. `n` 可以是 **0**：任何非零数的 0 次方都是 1。
3. `n` 的范围是 `[-2147483648, 2147483647]`，**非常大**，一个一个乘会超时。
4. `n = -2147483648` 时，`-n` 是 2147483648，**超出了 `int` 的范围**！

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `double` 浮点数

`double` 是 64 位浮点数，能表示小数，大约有 15~16 位有效数字。浮点运算有微小误差，所以判题只比较到小数点后 5 位。

```c
double a = 1.0 / 4;   // 0.25。注意写成 1 / 4 会得到整数 0！
```

> ⚠️ `1 / x` 中如果 `x` 是 `double`，结果就是浮点数；但 `1 / 4` 两边都是整数，结果是 0。写 `1.0 / x` 最保险。

### 2. `int` 的取反溢出

`int` 的范围是 `[-2^31, 2^31 - 1]`，**负数比正数多一个**。所以：

```c
int n = INT_MIN;      // -2147483648
int m = -n;           // ❌ 溢出！2147483648 装不进 int
long long N = n;      // ✅ 先放进 long long
N = -N;               // ✅ N = 2147483648，没问题
```

### 3. 位运算判断奇偶、除以 2

- `N & 1`：取二进制最低位，等于 1 说明 `N` 是奇数（和 `N % 2 == 1` 一样）。
- `N >>= 1`：右移一位，相当于 `N /= 2`（对非负数）。

---

## 💡 第三步：思路一 —— 暴力连乘（会超时）

最直接的想法：把 `x` 乘 `|n|` 次。

```c
double myPow(double x, int n) {
    // ❌ n 最大约 21 亿，循环 21 亿次会超时
    long long N = n;
    if (N < 0) { x = 1.0 / x; N = -N; }
    double res = 1.0;
    for (long long i = 0; i < N; i++) {
        res *= x;
    }
    return res;
}
```

- **时间复杂度 O(|n|)**：`n = 2^31 - 1` 时要乘 21 亿次，远超 1 秒。

---

## 🚀 第四步：思路二 —— 递归快速幂

### 思路

关键观察：

- `x^10 = (x^5)^2`：算出 `x^5` 后自己乘自己一次就行；
- `x^5 = (x^2)^2 × x`：奇数次方要多乘一个 `x`；
- `x^2 = (x^1)^2`，`x^1 = (x^0)^2 × x`，`x^0 = 1`。

每一步把 `n` **减半**，所以只要 log₂n 步。

### 手动模拟（`x = 2, n = 10`）

| 调用 | N | N/2 的结果 y | N 是奇数？ | 返回 |
|---|---|---|---|---|
| f(10) | 10 | f(5) = 32 | 否 | 32 × 32 = 1024 |
| f(5) | 5 | f(2) = 4 | 是 | 4 × 4 × 2 = 32 |
| f(2) | 2 | f(1) = 2 | 否 | 2 × 2 = 4 |
| f(1) | 1 | f(0) = 1 | 是 | 1 × 1 × 2 = 2 |
| f(0) | 0 | — | — | 1 |

只做了 4 层递归，而不是 10 次乘法。

### 代码

```c
// 计算 x 的 N 次方，要求 N >= 0
double quickPow(double x, long long N) {
    if (N == 0) {                        // 递归出口：任何数的 0 次方是 1
        return 1.0;
    }
    double y = quickPow(x, N / 2);       // 先算 x 的 N/2 次方
    if (N % 2 == 1) {
        return y * y * x;                // N 是奇数：多乘一个 x
    }
    return y * y;                        // N 是偶数
}

double myPow(double x, int n) {
    long long N = n;                     // 转成 long long，避免 -INT_MIN 溢出
    if (N >= 0) {
        return quickPow(x, N);
    }
    return 1.0 / quickPow(x, -N);        // 负指数：取倒数
}
```

### 复杂度分析

- **时间复杂度 O(log n)**：每层递归 `N` 减半。
- **空间复杂度 O(log n)**：递归调用栈的深度（最多约 32 层）。

## 🚀 第五步：思路三 —— 迭代快速幂（二进制拆分）

### 思路

把 `n` 写成二进制。例如 `n = 10 = 1010₂ = 8 + 2`，所以：

```
x^10 = x^8 × x^2
```

我们从低位到高位扫描 `n` 的二进制，同时让 `x` 不断平方（`x, x^2, x^4, x^8, …`）：

- 当前位是 1，就把当前的 `x` 乘进答案；
- 每一轮 `x = x * x`，`n` 右移一位。

### 手动模拟（`x = 2, N = 10 = 1010₂`）

| 轮次 | N（二进制） | 最低位 | 当前 x | res |
|---|---|---|---|---|
| 1 | 1010 | 0 | 2 | 1 |
| 2 | 101 | 1 | 4 | 1 × 4 = 4 |
| 3 | 10 | 0 | 16 | 4 |
| 4 | 1 | 1 | 256 | 4 × 256 = 1024 |

### 代码

```c
double myPow(double x, int n) {
    long long N = n;                     // 用 long long，-2147483648 取反也不会溢出
    if (N < 0) {                         // 负指数：x^(-N) = (1/x)^N
        x = 1.0 / x;
        N = -N;
    }

    double res = 1.0;                    // 答案，从 1 开始乘
    while (N > 0) {
        if (N & 1) {                     // N 的二进制最低位是 1
            res *= x;                    // 把当前的 x（某个 x^(2^k)）乘进答案
        }
        x *= x;                          // x 变成下一位对应的值：x^(2^(k+1))
        N >>= 1;                         // 去掉已处理的最低位
    }
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(log n)**：`N` 最多 32 位，循环最多 32 次。
- **空间复杂度 O(1)**：没有递归。

---

## ⚠️ 第六步：小白常见错误

1. **`if (n < 0) n = -n;`** → `n = -2147483648` 时溢出，`n` 仍是负数，结果错误甚至死循环。一定先转 `long long`。
2. **写成 `1 / x`、`1 / res` 时用了整数** → 例如 `int` 类型参与运算会变成整数除法，得到 0。用 `1.0 / x`。
3. **递归里写 `quickPow(x, N/2) * quickPow(x, N/2)`** → 同一个值算两次，复杂度退化回 O(n)，会超时。要先存到变量 `y`。
4. **暴力连乘** → 时间 O(n)，n 达到 21 亿时一定超时。
5. **忘了 n = 0 的情况** → 递归没有出口会栈溢出；迭代写法中 `res` 初值必须是 `1.0` 而不是 `0`。
6. **直接调用 `pow(x, n)`** → 能过，但失去了练习意义，面试时也不被允许。

---

## 📊 第七步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 能否 AC | 建议 |
|---|---|---|---|---|
| 暴力连乘 | O(n) | O(1) | ❌ 超时 | 只用来理解题意 |
| 递归快速幂 | O(log n) | O(log n) | ✅ | 最好理解的快速幂 |
| 迭代快速幂 | O(log n) | O(1) | ✅ | 最常用的模板 |
