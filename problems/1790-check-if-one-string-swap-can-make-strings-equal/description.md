# 仅执行一次字符串交换能否使两个字符串相等

两个等长小写字符串中，允许在其中一个字符串内最多交换两个位置一次，判断是否能相等。长度1到100。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool areAlmostEqual(char* s1,char* s2);
```

## 示例 1

输入：
```text
"bank"
"kanb"
```
输出：
```text
true
```

## 示例 2

输入：
```text
"attack"
"defend"
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：s1、s2。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
