给定一个二叉搜索树的根节点 **root** 和一个值 **key**，删除二叉搜索树中的 **key** 对应的节点，并保证二叉搜索树的性质不变。返回二叉搜索树（有可能被更新）的根节点的引用。

一般来说，删除节点可分为两个步骤：

1. 首先找到需要删除的节点；
2. 如果找到了，删除它。

### 示例 1

```
        5                    5
       / \                  / \
      3   6      ==>       4   6
     / \   \              /     \
    2   4   7            2       7
```

```
输入：root = [5,3,6,2,4,null,7], key = 3
输出：[2,4,5,6,7]
解释：给定需要删除的节点值是 3，所以我们首先找到 3 这个节点，然后删除它。
一个正确的答案是 [5,4,6,2,null,null,7]，如上图所示。
另一个正确答案是 [5,2,6,null,4,null,7]。
两者都是合法的二叉搜索树，结点集合也都是 {2,4,5,6,7}，本 OJ 校验通过后统一输出中序遍历 [2,4,5,6,7]。
```

### 示例 2

```
输入：root = [5,3,6,2,4,null,7], key = 0
输出：[2,3,4,5,6,7]
解释：二叉树不包含值为 0 的节点，树保持不变。
```

### 示例 3

```
输入：root = [], key = 0
输出：[]
```

### 提示

- 节点数的范围 `[0, 10^4]`
- `-10^5 <= Node.val <= 10^5`
- 节点值唯一
- `root` 是合法的二叉搜索树
- `-10^5 <= key <= 10^5`

**进阶：** 要求算法时间复杂度为 `O(h)`，`h` 为树的高度。

### 函数说明

```c
struct TreeNode {
    int val;
    struct TreeNode *left;
    struct TreeNode *right;
};

struct TreeNode* deleteNode(struct TreeNode* root, int key);
```

- `struct TreeNode` 已由系统定义，**不要**在代码中重复定义
- `root`：二叉搜索树的根结点，可能为 `NULL`
- `key`：要删除的值（可能不在树中）
- 返回值：删除后的树的根结点（可能变化，也可能为 `NULL`）

### 判题方式（答案不唯一）

删除后的树形状可能有多种，都是正确的。判题程序会检查你返回的树：

1. 是一棵合法的二叉树（没有环、没有结点被重复使用）；
2. 是**二叉搜索树**（中序遍历严格递增）；
3. 结点值的集合恰好等于"原树的值去掉 `key`"（`key` 不存在时与原树相同）。

全部满足时输出这棵树的**中序遍历**（即从小到大的结点值，如 `[2,4,5,6,7]`）；否则输出错误信息，判为答案错误。

### 自定义输入格式

```
[5,3,6,2,4,null,7]
3
```

第 1 行是二叉搜索树的层序表示（`null` 表示空结点），第 2 行是 `key`。
