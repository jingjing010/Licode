给定 *n* 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

### 示例 1

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形由高度为 5 和 6 的两根柱子组成，高为 5，宽为 2，面积为 10。
```

### 示例 2

```
输入：heights = [2,4]
输出：4
```

### 提示

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`

### 函数说明

```c
int largestRectangleArea(int* heights, int heightsSize);
```

- `heights`：柱子高度数组首地址，`heightsSize`：柱子个数
- 返回值：最大矩形面积

### 自定义输入格式

```
[2,1,5,6,2,3]
```

只有 1 行，是数组 `heights`。
