# 仅仅反转字母：题解

## 📖 先读懂题目

反转ASCII字符串中的英文字母顺序，非字母字符保持位置不变。长度1到100。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"ab-cd"` | `"dc-ba"` |
| 2 | `"a-bC-dEf-ghIj"` | `"j-Ih-gfE-dCba"` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

申请输出字符串时，要在有效字符之外多留1字节写入结束符。参考实现返回动态内存，由调用方负责释放。

## 💡 推导与实现

双指针只在字母位置交换，其他字符保持原下标不动。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
char *reverseOnlyLetters(char *s) {
    int n = (int)strlen(s), l = 0, r = n - 1;
    char *out = malloc(n + 1);
    memcpy(out, s, n + 1);
    while (l < r) {
        while (l < r && !isalpha((unsigned char)out[l]))
            ++l;
        while (l < r && !isalpha((unsigned char)out[r]))
            --r;
        char t = out[l];
        out[l++] = out[r];
        out[r--] = t;
    }
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，输出空间 O(n) | 正式提交 |

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 只申请有效字符数大小的缓冲区，没有给结束符留空间。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
