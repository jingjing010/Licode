# 使数组中所有元素都等于零

一次操作选择不超过最小正元素的正整数x，从所有正元素中减x。返回全变0的最少操作次数。1 ≤ n ≤ 100，元素0到100。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int minimumOperations(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,5,0,3,5]
```
输出：
```text
3
```

## 示例 2

输入：
```text
[0]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
