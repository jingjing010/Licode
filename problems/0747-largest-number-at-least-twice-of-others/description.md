# 至少是其他数字两倍的最大数

给定非负整数数组，返回最大值下标（取最左），要求它至少是每个其他元素的两倍，否则返回−1。1 ≤ n ≤ 50，元素 ≤ 100。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int dominantIndex(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[3,6,1,0]
```
输出：
```text
1
```

## 示例 2

输入：
```text
[1,2,3,4]
```
输出：
```text
-1
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
