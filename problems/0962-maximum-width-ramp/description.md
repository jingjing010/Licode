给定一个整数数组 `nums`，*坡* 是元组 `(i, j)`，其中  `i < j` 且 `nums[i] <= nums[j]`。这样的坡的宽度为 `j - i`。

找出 `nums` 中的坡的最大宽度，如果不存在，返回 0 。

### 示例 1

```
输入：nums = [6,0,8,2,1,5]
输出：4
解释：
最大宽度的坡为 (i, j) = (1, 5): nums[1] = 0 且 nums[5] = 5.
```

### 示例 2

```
输入：nums = [9,8,1,0,1,9,4,0,4,1]
输出：7
解释：
最大宽度的坡为 (i, j) = (2, 9): nums[2] = 1 且 nums[9] = 1.
```

### 提示

- `2 <= nums.length <= 5 * 10^4`
- `0 <= nums[i] <= 5 * 10^4`

### 函数说明

```c
int maxWidthRamp(int* nums, int numsSize);
```

- `nums`：数组首地址，`numsSize`：数组长度
- 返回值：坡的最大宽度，不存在坡时返回 0

### 自定义输入格式

```
[6,0,8,2,1,5]
```

只有 1 行，是数组 `nums`。
