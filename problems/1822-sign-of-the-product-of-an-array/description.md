# 数组元素积的符号

返回非空整数数组乘积的符号：正数1、负数−1、零0。n ≤ 1000，元素在−100到100之间。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int arraySign(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[-1,-2,-3,-4,3,2,1]
```
输出：
```text
1
```

## 示例 2

输入：
```text
[1,5,0,2,-3]
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
