# Flash 写入覆盖页数

给定uint32地址、写入字节数和正页大小pageSize（≤65536），返回涉及的页数。空写入为0，地址加长度不超过2^32。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint32_t flashPages(uint32_t address,uint32_t length,int pageSize);
```

## 示例 1

输入：
```text
250
20
256
```
输出：
```text
2
```

## 示例 2

输入：
```text
256
256
256
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：address、length、pageSize。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
