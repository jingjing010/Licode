# 9026. 实现 itoa（任意进制整数转字符串）—— 小白详细题解

> 不用 `printf` 也能把数字显示出来——这是写裸机程序的基本功。这道题有三个关键点：**"除基取余"得到的数字是倒序的**、**`INT32_MIN` 取绝对值会溢出**、以及**别忘了 `'\0'`**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把整数写成 base 进制的文字。十进制负数前面加负号；其它进制把它当成 32 位无符号数来写。写进别人给你的 `buf`，再把 `buf` 还回去。

先看"除基取余"怎么得到每一位（`value = 1234`，`base = 10`）：

| 步骤 | 当前数 | `% 10`（得到的位） | `/ 10` |
|---|---|---|---|
| 1 | 1234 | **4** | 123 |
| 2 | 123 | **3** | 12 |
| 3 | 12 | **2** | 1 |
| 4 | 1 | **1** | 0（停止） |

得到的顺序是 `4 3 2 1`——**和要输出的顺序相反**，所以最后需要翻转一下。

**几个需要注意的细节：**

| 输入 | 输出 | 说明 |
|---|---|---|
| `0, 10` | `"0"` | 0 也要输出一位，不能是空字符串 |
| `-1, 16` | `"FFFFFFFF"` | 非十进制按 `uint32_t` 处理 |
| `-1, 2` | 32 个 `'1'` | 最长的结果，32 个字符 + `'\0'` |
| `-2147483648, 10` | `"-2147483648"` | 最容易溢出的边界 |

---

## 🧰 第二步：需要的 C 语言知识

### 1. 调用者提供缓冲区

```c
char buf[34];
uart_puts(my_itoa(temp, buf, 10));
```

函数不用 `malloc`，直接写进调用者给的 `buf`——这是嵌入式最常见的接口风格（没有堆碎片、实时性好）。返回 `buf` 是为了能像上面那样**链式调用**。

### 2. 查表把 0~15 变成字符

```c
static const char digits[] = "0123456789ABCDEF";
digits[11]   // 'B'
```

### 3. ⭐ `INT32_MIN` 的绝对值放不进 `int32_t`

`int32_t` 的范围是 `-2147483648 ~ 2147483647`，`-(-2147483648)` 等于 `2147483648`，**超出了范围**，属于有符号溢出（未定义行为）。安全做法是先转成**无符号数**再取负：

```c
uint32_t u = (uint32_t)value;   // -2147483648 -> 0x80000000
u = 0u - u;                     // 无符号减法按 2^32 取模，结果 0x80000000 = 2147483648 ✅
```

无符号运算溢出是**有定义的**（自动对 2^32 取模），所以这样写在任何编译器上都正确。

### 4. 非十进制为什么当作无符号数

`(uint32_t)-1 = 0xFFFFFFFF`。看寄存器值时，我们关心的是**每一位是什么**，而不是它代表的有符号数，所以十六进制、二进制都按位模式输出。

## 💡 第三步：思路一 —— 倒序写入，再整体翻转

### 思路

1. 十进制负数：先写 `'-'`，再把 `u` 取成绝对值
2. 用 `do ... while` 循环除基取余，把数字依次写入（这样 0 也会写出一位 `'0'`）
3. 写 `'\0'`
4. 把**数字部分**（不包括 `'-'`）首尾交换翻转

### 手动模拟（`value = -255, base = 10`）

| 阶段 | buf 内容 |
|---|---|
| 写负号 | `- ` |
| 255 % 10 = 5 | `- 5` |
| 25 % 10 = 5 | `- 5 5` |
| 2 % 10 = 2 | `- 5 5 2` |
| 写 `'\0'` | `- 5 5 2 \0` |
| 翻转下标 1~3 | `- 2 5 5 \0` → `"-255"` ✅ |

### 代码

```c
char* my_itoa(int32_t value, char* buf, int base) {
    static const char digits[] = "0123456789ABCDEF";
    uint32_t u = (uint32_t)value;        // 统一按无符号处理
    int pos = 0;

    if (base == 10 && value < 0) {       // 只有十进制才输出负号
        buf[pos++] = '-';
        u = 0u - u;                      // 安全地求绝对值（包括 INT32_MIN）
    }

    int start = pos;                     // 数字部分从这里开始
    do {
        buf[pos++] = digits[u % (uint32_t)base];   // 取最低位
        u /= (uint32_t)base;                       // 去掉最低位
    } while (u != 0);                    // do-while 保证 0 也输出 "0"
    buf[pos] = '\0';

    // 翻转数字部分 buf[start .. pos-1]
    for (int i = start, j = pos - 1; i < j; i++, j--) {
        char t = buf[i];
        buf[i] = buf[j];
        buf[j] = t;
    }
    return buf;
}
```

### 复杂度分析

- **时间复杂度 O(位数)**，最多 32 位；**空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 先写进临时数组的末尾，再拷贝（不用翻转）

### 思路

准备一个 33 字节的临时数组 `tmp`，从**最后一个位置往前**写数字，写完后数字在 `tmp` 里就已经是正序了，再按顺序拷贝到 `buf`。

### 手动模拟（`value = 255, base = 16`）

| 步骤 | `u % 16` | 写入位置 | tmp 末尾 |
|---|---|---|---|
| 1 | 15 → `'F'` | `tmp[32]` | `F` |
| 2 | 15 → `'F'` | `tmp[31]` | `F F` |
| 3 | u = 0，停止 | | 从 `tmp[31]` 开始拷贝 |

拷贝得到 `"FF"` ✅

### 代码

```c
char* my_itoa(int32_t value, char* buf, int base) {
    static const char digits[] = "0123456789ABCDEF";
    char tmp[33];                        // 最多 32 位二进制数字
    int p = 33;                          // 从末尾往前写
    uint32_t u = (uint32_t)value;
    int neg = (base == 10 && value < 0);
    if (neg) u = 0u - u;

    do {
        tmp[--p] = digits[u % (uint32_t)base];
        u /= (uint32_t)base;
    } while (u != 0);

    char* out = buf;
    if (neg) *out++ = '-';
    while (p < 33) *out++ = tmp[p++];   // 已经是正序，直接拷贝
    *out = '\0';
    return buf;
}
```

> 💬 两种方法速度几乎一样。思路二多用了 33 字节栈空间，但逻辑上"不用翻转"更不容易写错。在只有几百字节 RAM 的 8 位机上，思路一更省。

## 🔌 嵌入式实战

```c
char buf[34];
uart_puts("ADC=");
uart_puts(my_itoa(adc_value, buf, 10));      // ADC=2048
uart_puts(" CR1=0x");
uart_puts(my_itoa(USART1->CR1, buf, 16));    // CR1=0x200C ...
```

由于 `u % base`、`u / base` 在没有硬件除法器的 MCU（如 Cortex-M0）上比较慢，有些项目会为十进制和十六进制分别写专用版本：十六进制直接用 `u & 0xF` 和 `u >> 4` 代替取余和除法。

## ⚠️ 第五步：小白常见错误

1. **忘了翻转**：`1234` 输出成 `"4321"`。
2. **用 `while` 而不是 `do-while`**：`value = 0` 时循环一次都不执行，输出空字符串 `""`。
3. **`value = -value` 求绝对值**：`INT32_MIN` 时有符号溢出，常见结果是仍然是负数，`%` 得到负的余数，下标越界。
4. **把负号也翻转了**：翻转范围从下标 0 开始，`"-255"` 变成 `"552-"`。
5. **非十进制也加负号**：`-1, 16` 应输出 `"FFFFFFFF"`，而不是 `"-1"`。
6. **忘了写 `'\0'`**：`buf` 里原来的内容会被一起打印出来。
7. **返回局部数组**：`char tmp[33]; ... return tmp;` 函数返回后 `tmp` 就失效了，必须返回 `buf`。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 特点 |
|---|---|---|---|
| 倒序写入 + 翻转 | O(位数) | O(1) | 省内存 |
| 临时数组从后往前写 | O(位数) | O(33) 栈 | 不用翻转，逻辑简单 |
| `sprintf` | — | 大量 Flash/栈 | 本题禁止，小 MCU 上很重 |
