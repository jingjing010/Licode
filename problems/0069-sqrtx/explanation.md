# 69. x 的平方根 —— 小白详细题解

> 这是学习**二分查找**的绝佳例题：答案在一个有序的范围里，每次排除一半。顺便还要处理 `int` 乘法溢出。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 找一个**最大的整数 k**，使得 `k * k` 不超过 `x`。

| x | 真实平方根 | 答案 k | 验证 |
|---|---|---|---|
| 4 | 2 | 2 | 2×2 = 4 ≤ 4，3×3 = 9 > 4 |
| 8 | 2.828… | 2 | 2×2 = 4 ≤ 8，3×3 = 9 > 8 |
| 0 | 0 | 0 | |
| 2147483647 | 46340.95… | 46340 | |

**几个需要注意的细节：**

1. 小数部分直接**舍去**（向下取整），不是四舍五入：`8` 的答案是 2 而不是 3。
2. 不许用 `sqrt`、`pow` 等库函数。
3. `x` 最大是 2147483647，而 `46341 * 46341 = 2147488281` **超过了 `int` 的上限**。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 乘法溢出

两个 `int` 相乘，结果也是 `int`。如果真实结果超过 2147483647，就会**溢出**成一个奇怪的数（通常是负数）：

```c
int k = 46341;
int sq = k * k;                    // ❌ 溢出，结果不对
long long sq2 = (long long)k * k;  // ✅ 先把 k 转成 long long，再乘
```

> ⚠️ `long long sq = k * k;` 也是错的！右边 `k * k` 先按 `int` 算完（已经溢出了），才转换成 `long long`。必须**先转换再乘**。

### 2. 另一种防溢出的写法：用除法

`k * k <= x` 等价于 `k <= x / k`（当 `k > 0` 时，整数除法向下取整，结论依然成立）。除法不会溢出，但要注意 `k = 0` 时不能除。

### 3. 二分查找求中点

```c
int mid = lo + (hi - lo) / 2;   // ✅ 推荐
int mid = (lo + hi) / 2;        // ❌ lo + hi 可能超过 INT_MAX
```

---

## 💡 第三步：思路一 —— 从小到大逐个试（最朴素）

### 思路

从 `k = 0` 开始，只要 `(k+1)*(k+1) <= x` 就让 `k` 加 1。最终的 `k` 就是答案。

最多试到 46341 左右，大约 4.6 万次，完全不会超时。

### 手动模拟（`x = 8`）

| k | (k+1)² | ≤ 8？ | 操作 |
|---|---|---|---|
| 0 | 1 | 是 | k = 1 |
| 1 | 4 | 是 | k = 2 |
| 2 | 9 | 否 | 停止，答案 2 |

### 代码

```c
int mySqrt(int x) {
    long long k = 0;                       // 用 long long，(k+1)*(k+1) 不会溢出
    while ((k + 1) * (k + 1) <= x) {       // 下一个数的平方还不超过 x
        k++;                               // 那就可以再大一点
    }
    return (int)k;                         // k 最大 46340，可以安全转回 int
}
```

### 复杂度分析

- **时间复杂度 O(√x)**：最多循环约 46341 次。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 二分查找（标准解法）

### 思路

`k * k` 随着 `k` 增大而增大（单调），所以可以二分：

- 在区间 `[lo, hi] = [0, x]` 里取中点 `mid`；
- 如果 `mid * mid <= x`，说明 `mid` 可能是答案，记下来，然后去**右半边**找更大的；
- 否则 `mid` 太大了，去**左半边**找。

### 手动模拟（`x = 8`）

| lo | hi | mid | mid² | ≤ 8？ | ans | 操作 |
|---|---|---|---|---|---|---|
| 0 | 8 | 4 | 16 | 否 | 0 | hi = 3 |
| 0 | 3 | 1 | 1 | 是 | 1 | lo = 2 |
| 2 | 3 | 2 | 4 | 是 | 2 | lo = 3 |
| 3 | 3 | 3 | 9 | 否 | 2 | hi = 2 |

`lo > hi`，结束，答案 `2`。

### 代码

```c
int mySqrt(int x) {
    int lo = 0, hi = x;                    // 答案一定在 [0, x] 之间
    int ans = 0;                           // 目前找到的满足条件的最大 k
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;      // 防溢出的中点写法
        if ((long long)mid * mid <= x) {   // 先转 long long 再乘，防止溢出
            ans = mid;                     // mid 满足条件，先记下
            lo = mid + 1;                  // 试试更大的
        } else {
            hi = mid - 1;                  // mid 太大，往小了找
        }
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(log x)**：每次区间减半，最多约 31 次。
- **空间复杂度 O(1)**。

---

## 🚀 第五步：思路三 —— 牛顿迭代（拓展）

### 思路

牛顿法求 `√x`：从一个比答案大的猜测 `r` 开始，不断用 `r = (r + x / r) / 2` 修正。整数版本中，`r` 会单调减小，一直到 `r * r <= x` 为止，此时的 `r` 就是向下取整的平方根。它收敛得非常快。

### 代码

```c
int mySqrt(int x) {
    long long r = x;                       // 初始猜测：x 本身（一定不小于答案）
    while (r * r > x) {                    // 还太大，继续修正
        r = (r + x / r) / 2;               // 牛顿迭代公式（整数版）
    }
    return (int)r;
}
```

- **时间复杂度约 O(log x)**，**空间复杂度 O(1)**。了解即可，面试一般写二分。

---

## ⚠️ 第六步：小白常见错误

1. **`mid * mid <= x` 直接用 `int` 乘** → `x` 接近 `INT_MAX` 时 `mid * mid` 溢出，二分走错方向。
2. **`long long sq = mid * mid;`** → 乘法先按 `int` 算完才转换，还是溢出。要写 `(long long)mid * mid`。
3. **`mid = (lo + hi) / 2`** → `lo + hi` 可能超过 `INT_MAX`。
4. **用 `k <= x / k` 时 `k` 从 0 开始** → 除以 0 会让程序崩溃。
5. **用 `(int)sqrt(x)`** → 题目不允许；而且浮点误差可能让完全平方数的结果小 1。
6. **二分结束后直接返回 `lo`** → 退出循环时 `lo` 已经是"第一个不满足的数"，应该返回 `hi` 或者记录下来的 `ans`。

## 📊 第七步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 逐个尝试 | O(√x) | O(1) | ⭐ | 先理解题意 |
| 二分查找 | O(log x) | O(1) | ⭐⭐ | 标准答案，务必掌握 |
| 牛顿迭代 | O(log x) | O(1) | ⭐⭐⭐ | 拓展了解 |
