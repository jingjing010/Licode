# 回绕安全的截止时间检查

now、deadline为uint32_t节拍，保证真实时间差的绝对值小于2^31。返回是否已到期，等于截止时为true。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool deadlineReached(uint32_t now,uint32_t deadline);
```

## 示例 1

输入：
```text
100
100
```
输出：
```text
true
```

## 示例 2

输入：
```text
99
100
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：now、deadline。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
