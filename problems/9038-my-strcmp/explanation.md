# 9038. 实现 strcmp —— 小白详细题解

> strcmp 是"查字典"的程序版本。它的代码只有 5 行，但有两个点面试官一定会追问：**循环什么时候停？** 和 **为什么要转成 unsigned char？** 本题的测试数据里专门放了中文，就是为了检验第二点。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 两个字符串从头开始一个字符一个字符地比，第一个不一样的字符决定大小；如果一直比到两个都结束了还一样，就相等。

拿示例 3 来说（`s1 = "abcd"`，`s2 = "abc"`）：

| 下标 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| s1 | a | b | c | **d (100)** |
| s2 | a | b | c | **\0 (0)** |
| 比较 | 相同 | 相同 | 相同 | 100 > 0 → **正数** |

`s2` 先结束了，它的 `'\0'` 值为 0，比任何字符都小，所以"前缀更短的串更小"这条规则是自动成立的，不需要特殊处理。

**几个需要注意的细节：**

1. 只看**正负**，返回 `-1/1` 还是差值都可以。
2. 按 **`unsigned char`** 比较：`"中"` 的第一个字节是 `0xE4`（228），比 `'a'`（97）大。
3. 大写字母比小写字母小（`'A'` = 65，`'a'` = 97），所以 `"Apple" < "apple"`。
4. 两个空串相等。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 字符就是小整数

`'a'` 在内存里就是 97，`'A'` 是 65，`'0'` 是 48，`'\0'` 是 0。比较字符其实就是比较整数，`'e' < 'y'` 等价于 `101 < 121`。

### 2. 有符号 char 的坑（和 9034 memcmp 一样）

UTF-8 中文的每个字节都 `>= 128`。在 x86 上 `char` 默认有符号，`0xE4` 会被当成 **-28**：

| 比较 `"中"` 和 `"a"` | 第一个字节 | 结果 |
|---|---|---|
| 按 `unsigned char` | 228 vs 97 | 正数 ✅ |
| 按 `signed char` | **-28** vs 97 | 负数 ❌ |

C 标准明确规定 strcmp 按 `unsigned char` 比较。所以要先把指针转成 `const unsigned char*`，或者在相减时写 `(unsigned char)*s1 - (unsigned char)*s2`。

### 3. 循环停止的条件

两个指针一起走，下面任意一种情况发生就停：

- 两个字符**不同**
- `s1` 到了 `'\0'`（此时如果 `s2` 也是 `'\0'`，说明相等；如果不是，说明两个字符不同，结果也正确）

所以条件写成 `*a != '\0' && *a == *b` 就够了——**不需要再单独判断 `*b != '\0'`**：如果 `*b` 是 `'\0'` 而 `*a` 不是，`*a == *b` 自然为假。

---

## 💡 第三步：思路一 —— 下标逐个比较（最朴素）

### 思路

1. `i` 从 0 开始
2. 只要 `s1[i]` 不是 `'\0'` 并且 `s1[i] == s2[i]`，就 `i++`
3. 停下后返回两个字符（按 unsigned char）的差

### 手动模拟（示例 1：`"apple"` vs `"apply"`）

| i | s1[i] | s2[i] | 继续吗 |
|---|---|---|---|
| 0 | a | a | 相同，继续 |
| 1 | p | p | 相同，继续 |
| 2 | p | p | 相同，继续 |
| 3 | l | l | 相同，继续 |
| 4 | e (101) | y (121) | **不同，停** → 101 - 121 = -20 |

返回 -20，判题程序输出 `-1`。

### 代码

```c
int my_strcmp(const char* s1, const char* s2) {
    size_t i = 0;
    // s1 还没结束，并且当前两个字符相同，就继续往后比
    while (s1[i] != '\0' && s1[i] == s2[i]) {
        i++;
    }
    // 第一个不同的字符（或者两个 '\0'）决定结果，必须按无符号比较
    return (int)(unsigned char)s1[i] - (int)(unsigned char)s2[i];
}
```

### 复杂度分析

- **时间复杂度 O(min(n, m))**：最多比较到较短的字符串结束。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— unsigned char 指针（库函数风格）

### 思路

一开始就把两个指针转成 `const unsigned char*`，后面所有的读取天然都是无符号的，不用每次强制转换，代码更干净，也不可能忘记转换。

### 代码

```c
int my_strcmp(const char* s1, const char* s2) {
    // 一次性转换，之后读出来的都是 0~255
    const unsigned char* a = (const unsigned char*)s1;
    const unsigned char* b = (const unsigned char*)s2;

    while (*a && *a == *b) {   // *a 不是 '\0' 且两个字符相同
        a++;
        b++;
    }
    return (int)*a - (int)*b;  // 差值的正负就是大小关系
}
```

### 复杂度分析

- **时间复杂度 O(min(n, m))**。
- **空间复杂度 O(1)**。

## 🔌 嵌入式实战：串口命令表

```c
typedef struct {
    const char* name;
    void (*handler)(void);
} Command;

static const Command cmd_table[] = {
    {"reboot",  do_reboot},
    {"led on",  led_on},
    {"led off", led_off},
};

void dispatch(const char* line) {
    for (size_t i = 0; i < sizeof(cmd_table) / sizeof(cmd_table[0]); i++) {
        if (strcmp(line, cmd_table[i].name) == 0) {   // 注意：相等时返回 0
            cmd_table[i].handler();
            return;
        }
    }
    uart_puts("unknown command\r\n");
}
```

如果命令表**按字典序排好**，还可以用 strcmp 的正负结果做二分查找，命令很多时更快。

## ⚠️ 第五步：小白常见错误

1. **把返回值当布尔用**：

   ```c
   if (strcmp(cmd, "reboot")) reboot();   // ❌ 相等时 strcmp 返回 0，条件为假，反而不重启
   ```

   要写 `if (strcmp(cmd, "reboot") == 0)`。
2. **用 `char` 直接相减**：`return *s1 - *s2;` 在 x86 上对中文判反，`"中"` 和 `"a"` 会输出 `-1`。
3. **用 `==` 比较字符串**：`if (cmd == "reboot")` 比较的是两个**地址**，几乎永远为假。
4. **只在一个串结束时停，忘了判断不同**：`while (*a) { a++; b++; }` 根本没有比较内容。
5. **两个串长度不同时越界**：`while (*a == *b) { a++; b++; }` 没有判断 `'\0'`，两个完全相同的串会在 `'\0'` 之后继续比较，读出界。
6. **以为返回值只能是 -1/0/1**：写 `if (strcmp(a, b) == -1)` 是错误的，库函数可能返回 -20。应该写 `< 0`。

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 下标 + 相减时转换 | O(min(n,m)) | O(1) | ⭐ | 直观 |
| unsigned char 指针 | O(min(n,m)) | O(1) | ⭐ | 推荐，不会忘记转换 |

## 🔗 举一反三

- **9034. 实现 memcmp**：比较固定长度的内存，遇到 0 不停。
- **strncmp**：最多比较 `n` 个字符，常用于判断前缀：`strncmp(line, "AT+", 3) == 0`。试着在本题基础上加一个 `n` 参数实现它。
- **strcasecmp**：忽略大小写比较，AT 指令解析时很常用。提示：比较前把两个字符都转成小写。
- **思考题**：为什么本题的循环条件只判断了 `*a != '\0'`，而没有判断 `*b != '\0'`？试着列举 `*a`、`*b` 是否为 `'\0'` 的四种组合，验证每种情况都能正确停下。
