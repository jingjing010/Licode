# 七段数码管段码

digit为0..9。位0..6依次表示a,b,c,d,e,f,g，不含小数点；commonAnode=0使用高电平点亮，=1使用低电平点亮，位7始终0。返回段码。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int sevenSegment(int digit,int commonAnode);
```

## 示例 1

输入：
```text
0
0
```
输出：
```text
63
```

## 示例 2

输入：
```text
0
1
```
输出：
```text
64
```

## 自定义输入格式

按顺序每行一个参数：digit、commonAnode。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
