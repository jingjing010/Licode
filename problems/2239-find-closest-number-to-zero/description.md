# 找到最接近 0 的数字

返回非空数组中最接近0的数；距离相同返回较大者。n ≤ 1000，元素范围−10^5到10^5。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int findClosestNumber(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[-4,-2,1,4,8]
```
输出：
```text
1
```

## 示例 2

输入：
```text
[2,-1,1]
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
