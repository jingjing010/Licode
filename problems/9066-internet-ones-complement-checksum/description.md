# 网络反码校验和

实现Internet 16位反码校验和。字节按网络序组字，奇数长度末字节作为高8位。0到1024字节，结果为无符号16位整数。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint16_t internetChecksum(const uint8_t* data,size_t len);
```

## 示例 1

输入：
```text
[49,50,51,52,53,54,55,56,57]
```
输出：
```text
63018
```

## 示例 2

输入：
```text
[]
```
输出：
```text
65535
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
