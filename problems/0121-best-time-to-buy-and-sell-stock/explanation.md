# 121. 买卖股票的最佳时机 —— 小白详细题解

> 这是"动态规划 / 贪心"的入门题。核心只有一句话：**想在今天卖，就要在今天之前最便宜的那天买**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你每天的股价。你只能**买一次、卖一次**，而且必须**先买后卖**。问最多能赚多少钱？赚不到钱就返回 0（干脆不买）。

拿示例 1 `prices = [7,1,5,3,6,4]` 来说：

| 第几天（下标） | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 价格 | 7 | **1** | 5 | 3 | **6** | 4 |

第 1 天以 1 买入，第 4 天以 6 卖出，赚 `6 - 1 = 5`，这是最大的。

**几个需要注意的细节：**

1. 不能"先卖后买"：`7 - 1 = 6` 是不行的，因为 7 在 1 的前面。
2. 价格一直跌（示例 2）时，任何交易都亏钱，答案是 0，**不是负数**。
3. 只有 1 天时没法完成交易，答案也是 0。

---

## 🧰 第二步：这道题需要的 C 语言知识

1. **`INT_MAX`**：`<limits.h>` 中定义的 int 最大值（2147483647）。用它给"最小值"变量赋初值，第一次比较时一定会被真实价格替换。
2. **数组 + 长度**：C 语言的数组不知道自己多长，所以要传 `pricesSize`，循环写 `i < pricesSize`。
3. **复杂度估算**：本题 n 最大 10⁵，两层循环约 5×10⁹ 次运算，远超 1 秒的承受范围（约 10⁸ 次）。

---

## 💡 第三步：思路一 —— 暴力枚举（会超时）

### 思路

枚举所有"买入日 i、卖出日 j（j > i）"的组合，算出 `prices[j] - prices[i]`，取最大值。

### 代码

```c
// ❌ 思路正确，但 O(n²) 在 n = 10^5 时会超时（Time Limit Exceeded）
int maxProfit(int* prices, int pricesSize) {
    int best = 0;                                   // 不交易时利润为 0
    for (int i = 0; i < pricesSize; i++) {          // 买入日
        for (int j = i + 1; j < pricesSize; j++) {  // 卖出日一定在买入日之后
            int profit = prices[j] - prices[i];
            if (profit > best) best = profit;
        }
    }
    return best;
}
```

### 复杂度分析

- **时间复杂度 O(n²)**：约 n²/2 次比较。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 一次遍历，记住历史最低价

### 思路

换个角度：**假设今天（第 j 天）卖出**，那么最佳买入价就是 `prices[0..j-1]` 中的最小值。

所以从左往右走，用一个变量 `minPrice` 记住"到目前为止见过的最低价"：

- 今天的价格更低 → 更新 `minPrice`（以后在这天买更划算）
- 否则 → 试一试"今天卖出"能赚多少：`prices[j] - minPrice`，更新答案

### 手动模拟（示例 1：`[7,1,5,3,6,4]`）

| j | prices[j] | minPrice（更新后） | 今天卖能赚 | best |
|---|---|---|---|---|
| 0 | 7 | 7 | 0 | 0 |
| 1 | 1 | 1 | 0 | 0 |
| 2 | 5 | 1 | 4 | 4 |
| 3 | 3 | 1 | 2 | 4 |
| 4 | 6 | 1 | 5 | **5** |
| 5 | 4 | 1 | 3 | 5 |

### 代码

```c
int maxProfit(int* prices, int pricesSize) {
    int minPrice = INT_MAX;   // 到目前为止的最低价，初值设为最大的 int
    int best = 0;             // 最大利润，不交易就是 0

    for (int i = 0; i < pricesSize; i++) {
        if (prices[i] < minPrice) {
            minPrice = prices[i];               // 发现更便宜的买入点
        } else if (prices[i] - minPrice > best) {
            best = prices[i] - minPrice;        // 今天卖出更赚
        }
    }
    return best;
}
```

> 💬 为什么能用 `else if`？如果今天刷新了最低价，那"今天买今天卖"利润是 0，不可能更新答案，所以可以直接跳过。

### 复杂度分析

- **时间复杂度 O(n)**：只扫描一遍。
- **空间复杂度 O(1)**：只用了两个变量。

> 从动态规划的角度看：`minPrice` 就是"前 i 天的最低价"这个状态，`best` 是"前 i 天能获得的最大利润"，每一步都只依赖上一步。

---

## ⚠️ 第五步：小白常见错误

1. **直接用"最大值 - 最小值"** → `[7,1,5,3,6,4]` 里最大值 7 在最小值 1 前面，`7 - 1 = 6` 不合法。必须保证先买后卖。
2. **`minPrice` 初始化为 0** → 价格都 ≥ 0，最低价永远是 0，答案就错成"最高价"了。要用 `INT_MAX` 或 `prices[0]`。
3. **`best` 初始化为负数或 `prices[1] - prices[0]`** → 价格一路下跌时会返回负数，正确答案应该是 0。
4. **用两层循环** → 思路对但 n = 10⁵ 时超时。
5. **默认至少有 2 天，直接访问 `prices[1]`** → `pricesSize == 1` 时越界。从循环里统一处理就不会有这个问题。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 能否 AC |
|---|---|---|---|
| 暴力枚举 | O(n²) | O(1) | ❌ 超时 |
| 一次遍历（记录最低价） | O(n) | O(1) | ✅ |
