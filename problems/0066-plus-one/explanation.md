# 66. 加一 —— 小白详细题解

> 这道题考的其实是**小学竖式加法**，再加上 C 语言里"返回一个新数组"的基本功。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一个很大的整数，被拆成一位一位地放在数组里（最高位在最前面）。请你把这个数**加 1**，然后同样一位一位地放进数组返回。

拿几个例子看：

| 输入数组 | 代表的数 | 加 1 后 | 输出数组 |
|---|---|---|---|
| [1,2,3] | 123 | 124 | [1,2,4] |
| [1,2,9] | 129 | 130 | [1,3,0] |
| [9] | 9 | 10 | [1,0] |
| [9,9,9] | 999 | 1000 | [1,0,0,0] |

**几个需要注意的细节：**

1. 数组最多有 **100 位**！这已经远远超过了 `int`（约 10 位）和 `long long`（约 19 位）能表示的范围，所以**不能**先把数组转成整数再加 1。
2. 加 1 可能产生**进位**，而且进位可能一路传到最高位（比如 `199 → 200`）。
3. 如果每一位都是 9，结果会**多出一位**，返回数组的长度是 `digitsSize + 1`。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 返回数组：`malloc` + `*returnSize`

```c
int* plusOne(int* digits, int digitsSize, int* returnSize)
```

- 返回值 `int*` 是一个数组的地址。这个数组必须用 `malloc` 申请（局部数组在函数结束后就失效了）。
- C 语言的数组不知道自己多长，所以要通过 `*returnSize = 长度;` 告诉调用者。注意是 `*returnSize`，不是 `returnSize`。

### 2. 为什么不能转成整数？

```c
long long x = 0;                       // ❌ 最多只能存约 19 位的数
for (int i = 0; i < digitsSize; i++)
    x = x * 10 + digits[i];            //    100 位的数会溢出，结果完全错误
```

`long long` 的最大值约是 `9.2 × 10^18`，只有 19 位。题目给的数有 100 位，必须**逐位**处理。

### 3. `calloc`：申请并清零

```c
int* res = (int*)calloc(n, sizeof(int));   // 申请 n 个 int，并且全部初始化为 0
```

`malloc` 申请的内存里是随机的"垃圾值"，而 `calloc` 会帮你全部填 0。全是 9 的情况下正好用得上。

---

## 💡 第三步：思路一 —— 模拟竖式加法（带进位）

### 思路

就像列竖式一样，从**个位**（数组最后一个元素）开始加：

1. 一开始要加的数 `carry = 1`（就是题目要求的"加一"）
2. 每一位：`sum = digits[i] + carry`，这一位写 `sum % 10`，新的进位 `carry = sum / 10`
3. 所有位处理完后，如果还有进位，就在最前面补一个 1

为了方便处理"多一位"的情况，我们直接申请 `digitsSize + 1` 个格子，从后往前填。

### 手动模拟（`digits = [1,9,9]`）

| i | digits[i] | carry（加之前） | sum | 写入 | carry（加之后） |
|---|---|---|---|---|---|
| 2 | 9 | 1 | 10 | 0 | 1 |
| 1 | 9 | 1 | 10 | 0 | 1 |
| 0 | 1 | 1 | 2 | 2 | 0 |

最后 `carry = 0`，不需要多一位，结果是 `[2,0,0]`。

### 代码

```c
int* plusOne(int* digits, int digitsSize, int* returnSize) {
    // 1. 多申请一个格子，以防最高位还有进位（比如 999 + 1 = 1000）
    int* tmp = (int*)malloc(sizeof(int) * (digitsSize + 1));
    int carry = 1;                              // 题目要求加 1，就当作最开始有一个进位

    // 2. 从个位开始往前加。digits[i] 写到 tmp[i + 1]，tmp[0] 留给可能的进位
    for (int i = digitsSize - 1; i >= 0; i--) {
        int sum = digits[i] + carry;
        tmp[i + 1] = sum % 10;                  // 这一位留下个位数
        carry = sum / 10;                       // 满 10 就向前进 1
    }

    // 3. 根据最后是否还有进位，决定结果从哪里开始
    if (carry == 1) {
        tmp[0] = 1;                             // 多出来一位
        *returnSize = digitsSize + 1;
        return tmp;
    }

    // 4. 没有多出一位：把 tmp[1..] 挪到前面
    for (int i = 0; i < digitsSize; i++) {
        tmp[i] = tmp[i + 1];
    }
    *returnSize = digitsSize;
    return tmp;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每一位处理一次。
- **空间复杂度 O(n)**：返回的新数组（这是题目要求的，一般不算额外空间）。

## 🚀 第四步：思路二 —— 找最后一个不是 9 的位置（更简洁）

### 思路

仔细想想"加 1"会发生什么：

- 从个位往前看，**末尾连续的 9** 全部会变成 0；
- 遇到的**第一个不是 9 的数**加 1，然后就结束了，前面的数都不变；
- 如果一路全是 9，结果就是 `1` 后面跟 `n` 个 0。

所以只要从后往前找到第一个 `< 9` 的位置就够了，不需要一直维护进位变量。

### 手动模拟

| 输入 | 从后往前第一个不是 9 的下标 | 处理 | 结果 |
|---|---|---|---|
| [1,2,3] | 2（数字 3） | 3 → 4 | [1,2,4] |
| [1,9,9] | 0（数字 1） | 1 → 2，后面两个 9 → 0 | [2,0,0] |
| [9,9] | 没有 | 全是 9 | [1,0,0] |

### 代码

```c
int* plusOne(int* digits, int digitsSize, int* returnSize) {
    // 从个位往前找第一个不是 9 的位置
    for (int i = digitsSize - 1; i >= 0; i--) {
        if (digits[i] < 9) {
            int* res = (int*)malloc(sizeof(int) * digitsSize);
            for (int j = 0; j < i; j++) res[j] = digits[j];   // 前面的位不变
            res[i] = digits[i] + 1;                          // 这一位加 1，不会再进位
            for (int j = i + 1; j < digitsSize; j++) res[j] = 0;  // 后面的 9 全变 0
            *returnSize = digitsSize;
            return res;
        }
    }

    // 走到这里说明每一位都是 9：结果是 1 后面跟 digitsSize 个 0
    int* res = (int*)calloc(digitsSize + 1, sizeof(int));   // calloc 已经全部置 0
    res[0] = 1;
    *returnSize = digitsSize + 1;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：最多看一遍所有位，再复制一遍。
- **空间复杂度 O(n)**：返回的新数组。

> 两种思路复杂度一样，但思路二把"进位"这件事想透了：**只有末尾的 9 会受影响**。这种"先观察规律、再简化代码"的习惯非常重要。

---

## ⚠️ 第五步：小白常见错误

1. **把数组转成 `int` / `long long` 再加 1** → 超过 19 位就溢出，100 位的测试点必错。
2. **忘了全是 9 的情况** → `[9,9]` 返回了 `[0,0]`，应该是 `[1,0,0]`，长度要变成 `digitsSize + 1`。
3. **返回局部数组** `int res[101]; return res;` → 函数结束后这块内存就失效了，输出乱码。
4. **写成 `returnSize = digitsSize`** → 少了 `*`，改的是指针本身，调用者拿不到长度。
5. **从前往后加** → 加法要从个位（数组末尾）开始，`digits[0]` 是最高位。
6. **全是 9 时用 `malloc` 却忘了把后面清零** → `malloc` 的内存里是垃圾值，输出会出现奇怪的数字。用 `calloc` 或手动赋 0。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 竖式加法（带进位） | O(n) | O(n) | ⭐ | 通用，可推广到"两个大数相加" |
| 找最后一个非 9 位 | O(n) | O(n) | ⭐ | 代码更短，体现对题目规律的观察 |

> 🎯 **学习建议**：先写思路一，体会"进位"是怎么一位一位传递的；再思考思路二为什么能省掉 `carry` 变量。
