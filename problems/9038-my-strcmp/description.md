命令行解析是嵌入式里非常常见的需求：串口收到一行 `"reboot"`、`"led on"`、`"get temp"`，要逐个和命令表比较，决定执行哪个函数——这就离不开 `strcmp`。

请你实现 `my_strcmp(s1, s2)`，按字典序比较两个字符串：

- 从第一个字符开始逐个比较，找到第一个不同的字符，把两个字符都当成 **`unsigned char`**（0 ~ 255）比较：`s1` 的较小返回**负数**，较大返回**正数**
- 两个字符串完全相同返回 `0`
- 一个串是另一个串的前缀时，短的那个更小（因为它的 `'\0'` 是 0，比任何字符都小）

> **不要调用库函数 `strcmp` / `strncmp` / `memcmp` 等**，请自己用指针完成。

判题程序把返回值规范化后输出：负数输出 `-1`，零输出 `0`，正数输出 `1`。

### 示例 1

```
输入：s1 = "apple", s2 = "apply"
输出：-1
解释：前 4 个字符相同，第 5 个字符 'e'(101) < 'y'(121)。
```

### 示例 2

```
输入：s1 = "led on", s2 = "led on"
输出：0
```

### 示例 3

```
输入：s1 = "abcd", s2 = "abc"
输出：1
解释：前 3 个字符相同，然后 'd'(100) 和 s2 的 '\0'(0) 比较，s1 更大。
```

### 提示

- `0 <= strlen(s1), strlen(s2) <= 10^5`（按字节计）
- 字符串由可打印 ASCII 字符和 UTF-8 编码的中文组成；中文的每个字节都 `>= 128`

### 函数说明

```c
int my_strcmp(const char* s1, const char* s2);
```

- 返回值：负数 / 0 / 正数（具体数值任意，只看正负）

### 自定义输入格式

```
"apple"
"apply"
```

两行，分别为带双引号的 `s1` 和 `s2`。输出为 `-1`、`0` 或 `1`。
