# 32位节拍回绕后的时间差

now与start为32位无符号节拍，实际经过时间保证小于2^32个tick，返回经过tick数。允许计数器发生一次回绕。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint32_t elapsedTicks(uint32_t now,uint32_t start);
```

## 示例 1

输入：
```text
10
3
```
输出：
```text
7
```

## 示例 2

输入：
```text
3
4294967290
```
输出：
```text
9
```

## 自定义输入格式

按顺序每行一个参数：now、start。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
