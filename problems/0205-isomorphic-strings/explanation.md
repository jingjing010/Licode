# 205. 同构字符串 —— 小白详细题解

> 这道题考的是**一一映射**（双射）。关键在于想明白：为什么只检查一个方向不够？

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 能不能给 `s` 里的每种字符都找一个"替身"，把 `s` 中的字符全部换成替身后，正好变成 `t`？要求：同一个字符的替身必须固定；不同的字符不能用同一个替身。

拿示例 3 `"paper"` 和 `"title"` 来说，按位置对齐：

| 下标 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| s | p | a | p | e | r |
| t | t | i | t | l | e |

映射关系：`p→t`、`a→i`、`e→l`、`r→e`。`p` 出现两次，两次都对应 `t`，没有矛盾，所以是同构的。

示例 2 `"foo"` 和 `"bar"`：`o` 第一次对应 `a`，第二次对应 `r`，**一个字符有两个替身**，矛盾 → `false`。

**容易忽略的反方向：** `s = "ab"`，`t = "aa"`。

- 从 s 看：`a→a`、`b→a`，每个字符都只有一个替身，看起来没问题；
- 但是 `a` 和 `b` **两个不同字符用了同一个替身** `a`，违反规则 → `false`。

所以必须检查**两个方向**：`s→t` 不能一对多，`t→s` 也不能一对多。

**几个需要注意的细节：**

1. 字符可以映射到自己：`"ab"` 和 `"ab"` 是同构的。
2. 字符可以是任意 ASCII 字符（包括空格、标点、数字），不只是小写字母。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用数组当"哈希表"

ASCII 字符只有 128 种（扩展后 256 种），每个字符本身就是一个 0~255 的整数，可以**直接当数组下标**：

```c
unsigned char s2t[256] = {0};   // s2t['p'] = 't' 表示 p 的替身是 t；0 表示还没有替身
s2t['p'] = 't';
```

`= {0}` 会把整个数组初始化为 0。

### 2. 为什么用 `unsigned char`？

`char` 在很多编译器上是**有符号**的，取值 -128~127。如果某个字符的编码大于 127，直接 `s2t[c]` 会变成负数下标，数组越界。先转成 `unsigned char` 就能保证下标在 0~255 之间。

### 3. 返回 `bool`

`bool`、`true`、`false` 来自 `<stdbool.h>`（OJ 已经帮你包含了）。

## 💡 第三步：思路一 —— 比较"第一次出现的位置"

### 思路

换个角度描述"同构"：**两个字符串的"结构"相同**。

怎么描述结构？对每个位置 `i`，看 `s[i]` 这个字符**第一次出现在哪个下标**。同构的两个串，这些"首次出现位置"必须完全一样。

| 下标 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| s = paper | p | a | p | e | r |
| s[i] 首次出现于 | 0 | 1 | **0** | 3 | 4 |
| t = title | t | i | t | l | e |
| t[i] 首次出现于 | 0 | 1 | **0** | 3 | 4 |

两行完全相同 → 同构。

再看 `s = "ab"`、`t = "aa"`：s 的首次出现位置是 `0, 1`，t 是 `0, 0`，不同 → `false`。这个方法**自动**包含了两个方向的检查。

### 代码

```c
bool isIsomorphic(char* s, char* t) {
    // firstS[c]：字符 c 在 s 中第一次出现的下标 + 1（0 表示还没出现过）
    static int firstS[256], firstT[256];
    memset(firstS, 0, sizeof(firstS));
    memset(firstT, 0, sizeof(firstT));

    for (int i = 0; s[i] != '\0'; i++) {
        unsigned char a = (unsigned char)s[i];
        unsigned char b = (unsigned char)t[i];
        if (firstS[a] == 0) firstS[a] = i + 1;   // 第一次见到，记下位置
        if (firstT[b] == 0) firstT[b] = i + 1;
        if (firstS[a] != firstT[b]) {            // 结构不同
            return false;
        }
    }
    return true;
}
```

> 💬 为什么存 `i + 1`？因为下标 0 也是合法位置，如果直接存 `i`，就分不清"出现在下标 0"和"还没出现过"了。

### 复杂度分析

- **时间复杂度 O(n)**：扫描一遍。
- **空间复杂度 O(1)**：两个固定大小为 256 的数组。

## 🚀 第四步：思路二 —— 双向映射表（最直接）

### 思路

直接按题意建两张表：

- `s2t[a]`：`s` 中字符 `a` 的替身；
- `t2s[b]`：`t` 中字符 `b` 是谁的替身。

逐个位置检查 `(a, b)`：

1. 两张表都没记录 → 新建映射 `a↔b`；
2. 否则必须满足 `s2t[a] == b` **且** `t2s[b] == a`，任何一个不满足就是矛盾。

### 手动模拟（`s = "badc"`，`t = "baba"`）

| i | a | b | s2t[a] | t2s[b] | 操作 |
|---|---|---|---|---|---|
| 0 | b | b | 空 | 空 | 建立 b↔b |
| 1 | a | a | 空 | 空 | 建立 a↔a |
| 2 | d | b | 空 | **b** | t2s['b'] = 'b' ≠ 'd'，矛盾！返回 false |

如果只检查 `s2t`，第 2 步 `s2t['d']` 是空的，会误以为可以建立 `d→b`，最后错误地返回 `true`。

### 代码

```c
bool isIsomorphic(char* s, char* t) {
    // 0 表示还没有映射（测试数据都是可打印字符，不会是 0）
    unsigned char s2t[256] = {0};   // s 的字符 -> t 的字符
    unsigned char t2s[256] = {0};   // t 的字符 -> s 的字符

    for (int i = 0; s[i] != '\0'; i++) {
        unsigned char a = (unsigned char)s[i];
        unsigned char b = (unsigned char)t[i];
        if (s2t[a] == 0 && t2s[b] == 0) {
            // 两边都是第一次见：建立双向映射
            s2t[a] = b;
            t2s[b] = a;
        } else if (s2t[a] != b || t2s[b] != a) {
            // 已有的映射和当前这一对不一致
            return false;
        }
    }
    return true;
}
```

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**：字符集大小固定为 256。

## ⚠️ 第五步：小白常见错误

1. **只检查一个方向** → 只用 `s2t`，`s = "ab"`、`t = "aa"` 会错误地返回 `true`。
2. **只比较字符种类数** → "两个串不同字符的个数相同"不代表同构，例如 `"ab"` 和 `"ba"`……这个其实同构；但 `"aab"` 与 `"abb"` 种类数都是 2，却不同构。
3. **用 `char` 直接当下标** → 编码大于 127 的字符会变成负数下标，越界。要先转 `unsigned char`。
4. **数组开成 26** → `int map[26]; map[c - 'a']` ❌ 本题字符是任意 ASCII，不只是小写字母，空格、数字都会越界。
5. **用 0 表示"没有映射"，又把下标 0 存进去** → 思路一如果存 `i` 而不是 `i + 1`，下标 0 处的字符会被当作"没出现过"。
6. **局部数组没初始化** → `int first[256];` 里是垃圾值，判断"是否出现过"就全乱了。

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 特点 |
|---|---|---|---|---|
| 首次出现位置 | O(n) | O(1) | ⭐⭐ | 巧妙，自动包含双向检查 |
| 双向映射表 | O(n) | O(1) | ⭐ | 直接按题意实现，最好理解 |
