# 198. 打家劫舍 —— 小白详细题解

> 这是动态规划（DP）最经典的入门题之一。核心只有一句话：**每间房子要么偷、要么不偷**，把这两种选择的结果比一比就行。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一排房子，每间有一些钱。你可以挑任意几间偷，但**不能偷相邻的两间**。问最多能偷多少钱？

拿示例 2 `nums = [2,7,9,3,1]` 来说：

| 房子编号 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 金额 | 2 | 7 | 9 | 3 | 1 |
| 方案 A | 偷 | | 偷 | | 偷 |
| 方案 B | | 偷 | | 偷 | |

- 方案 A：2 + 9 + 1 = **12** ✅
- 方案 B：7 + 3 = 10

**几个需要注意的细节：**

1. "不相邻"不代表"隔一个偷一个"。例如 `[2,1,1,2]`，最优是偷第 0 间和第 3 间（中间隔了两间），得 4。
2. 只有一间房子时，直接偷它。
3. 金额可能是 0，答案至少是 0。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用 `malloc` 开一个 dp 数组

```c
int* dp = (int*)malloc(sizeof(int) * (numsSize + 1));   // 下标 0 ~ numsSize
...
free(dp);
```

### 2. 三目运算符求最大值

C 语言没有内置的 `max` 函数，常用写法：

```c
int m = a > b ? a : b;   // 如果 a > b 成立，结果是 a，否则是 b
```

也可以自己写一个小函数：

```c
static int maxInt(int a, int b) { return a > b ? a : b; }
```

`static` 表示这个函数只在当前文件里可见，避免和别人的同名函数冲突。

## 💡 第三步：思路一 —— 动态规划（dp 数组）

### 思路

定义 `dp[i]` = **只考虑前 i 间房子**（编号 0 ~ i-1）时，最多能偷多少钱。

站在第 `i` 间房子（编号 `i-1`）门口，只有两个选择：

| 选择 | 后果 | 能偷到的钱 |
|---|---|---|
| 不偷它 | 前 i-1 间随便安排 | `dp[i-1]` |
| 偷它 | 它的左邻居（编号 i-2）不能偷，前 i-2 间随便安排 | `dp[i-2] + nums[i-1]` |

所以：**`dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])`**

边界：`dp[0] = 0`（没有房子），`dp[1] = nums[0]`（只有一间，偷它）。

### 手动模拟（示例 2：`[2,7,9,3,1]`）

| i | 新房子金额 nums[i-1] | 不偷：dp[i-1] | 偷：dp[i-2] + nums[i-1] | dp[i] |
|---|---|---|---|---|
| 0 | — | — | — | 0 |
| 1 | 2 | — | — | 2 |
| 2 | 7 | 2 | 0 + 7 = 7 | 7 |
| 3 | 9 | 7 | 2 + 9 = 11 | 11 |
| 4 | 3 | 11 | 7 + 3 = 10 | 11 |
| 5 | 1 | 11 | 11 + 1 = 12 | **12** |

### 代码

```c
int rob(int* nums, int numsSize) {
    // dp[i]：只考虑前 i 间房子时能偷到的最多钱
    int* dp = (int*)malloc(sizeof(int) * (numsSize + 1));
    dp[0] = 0;              // 没有房子
    dp[1] = nums[0];        // 只有一间：偷它（题目保证 numsSize >= 1）

    for (int i = 2; i <= numsSize; i++) {
        int notTake = dp[i - 1];                 // 不偷第 i 间
        int take = dp[i - 2] + nums[i - 1];      // 偷第 i 间，那第 i-1 间就不能偷
        dp[i] = notTake > take ? notTake : take;
    }

    int ans = dp[numsSize];
    free(dp);
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每间房子算一次。
- **空间复杂度 O(n)**：dp 数组。

> 💬 如果你一开始想到的是"递归：偷或不偷，两条路都试一遍"，那是对的思路，但不加记忆的递归会把同一个子问题算很多遍，时间是 O(2ⁿ)，n = 100 时根本跑不完。dp 数组就是把每个子问题的答案**记下来**，只算一次。

## 🚀 第四步：思路二 —— 滚动变量（O(1) 空间）

### 思路

仔细看转移方程：算 `dp[i]` 只用到 `dp[i-1]` 和 `dp[i-2]`，更早的值再也用不上了。所以根本不需要整个数组，**两个变量**就够：

- `prev1`：相当于 `dp[i-1]`
- `prev2`：相当于 `dp[i-2]`

每算出一个新的 `cur`，就把它们整体"往右挪一格"：`prev2 = prev1; prev1 = cur;`

### 手动模拟（示例 1：`[1,2,3,1]`）

| 当前房子 | 金额 | prev2 | prev1 | cur = max(prev1, prev2 + 金额) |
|---|---|---|---|---|
| 0 | 1 | 0 | 0 | max(0, 0+1) = 1 |
| 1 | 2 | 0 | 1 | max(1, 0+2) = 2 |
| 2 | 3 | 1 | 2 | max(2, 1+3) = 4 |
| 3 | 1 | 2 | 4 | max(4, 2+1) = **4** |

### 代码

```c
int rob(int* nums, int numsSize) {
    int prev2 = 0;   // dp[i-2]：前前一步的最优值
    int prev1 = 0;   // dp[i-1]：前一步的最优值

    for (int i = 0; i < numsSize; i++) {
        int take = prev2 + nums[i];                    // 偷当前这间
        int cur = prev1 > take ? prev1 : take;         // 和"不偷"比较
        prev2 = prev1;                                 // 整体往右挪一格
        prev1 = cur;
    }
    return prev1;    // 最后一步的最优值就是答案
}
```

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**：只用了几个变量。

---

## ⚠️ 第五步：小白常见错误

1. **"隔一个偷一个"的贪心**：分别算奇数下标之和、偶数下标之和取较大 → `[2,1,1,2]` 得到 3，正确答案是 4。
2. **滚动时更新顺序写反** `prev1 = cur; prev2 = prev1;` → `prev2` 拿到的是新值，旧的 `dp[i-1]` 丢了。必须先 `prev2 = prev1` 再 `prev1 = cur`。
3. **dp 数组只开 `numsSize` 个** → 用 `dp[numsSize]` 时越界。下标从 0 到 numsSize，要开 `numsSize + 1` 个。
4. **数组写法中 `numsSize == 1` 时访问 `nums[1]`** → 越界。转移要从 `i = 2` 开始，用的是 `nums[i-1]`。
5. **不加记忆的递归** → O(2ⁿ)，n = 100 时超时。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力递归 | O(2ⁿ) | O(n) | ⭐ | 只用来理解"偷/不偷" |
| dp 数组 | O(n) | O(n) | ⭐⭐ | 先写这个，理解转移方程 |
| 滚动变量 | O(n) | O(1) | ⭐⭐ | 面试推荐 |
