# 存在连续三个奇数的数组

判断是否存在连续三个奇数。1 ≤ n ≤ 1000，元素1到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool threeConsecutiveOdds(int* arr,int arrSize);
```

## 示例 1

输入：
```text
[2,6,4,1]
```
输出：
```text
false
```

## 示例 2

输入：
```text
[1,2,34,3,4,5,7,23,12]
```
输出：
```text
true
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
