FreeRTOS、uC/OS、RT-Thread 等实时操作系统（RTOS）的核心是**基于优先级的抢占式调度**：任何时刻，CPU 总是运行**已就绪任务中优先级最高的那个**；一旦更高优先级的任务就绪，当前任务立刻被抢占。

现在有 `n` 个任务，任务 `i` 的优先级为 `priority[i]`（`0 ~ 31`，**数字越大优先级越高**，与 FreeRTOS 一致），在第 `arrive[i]` 拍就绪，总共需要运行 `burst[i]` 拍。

请从第 `0` 拍开始逐拍模拟。每一拍：

1. 在所有**已就绪**（`arrive[i] <= 当前拍`）且**还没运行完**的任务中，选出一个任务运行这一拍：
   - 优先级高的优先；
   - 优先级相同，**到达早**（`arrive` 小）的优先；
   - 再相同，**编号小**的优先。
2. 如果没有可运行的任务，CPU 空闲，记为 `-1`。

当所有任务都运行完时模拟结束。返回每一拍运行的任务编号（空闲为 `-1`），数组长度等于最后一个任务完成时经过的拍数。

### 示例 1

```
输入：priority = [1,3,2], arrive = [0,1,2], burst = [3,2,1]
输出：[0,1,1,2,0,0]
解释：
第 0 拍：只有任务 0 就绪 → 0
第 1 拍：任务 1（优先级 3）就绪，抢占任务 0 → 1
第 2 拍：任务 2（优先级 2）就绪，但任务 1 优先级更高 → 1（任务 1 完成）
第 3 拍：任务 2 优先级 2 > 任务 0 的 1 → 2（任务 2 完成）
第 4、5 拍：任务 0 运行剩下的 2 拍。
```

### 示例 2

```
输入：priority = [5,5], arrive = [2,0], burst = [1,1]
输出：[1,-1,0]
解释：第 0 拍运行任务 1；第 1 拍没有就绪任务，空闲；第 2 拍任务 0 就绪并运行。
```

### 示例 3

```
输入：priority = [2,2], arrive = [0,0], burst = [2,1]
输出：[0,0,1]
解释：两个任务优先级相同、同时到达，编号小的任务 0 先运行，运行完之后才轮到任务 1。
```

### 提示

- `1 <= n <= 500`
- `0 <= priority[i] <= 31`
- `0 <= arrive[i] <= 5 * 10^4`
- `1 <= burst[i] <= 100`

### 函数说明

```c
int* prioritySchedule(const uint8_t* priority, const uint32_t* arrive, const uint16_t* burst,
                      size_t n, int* returnSize);
```

- 返回值：`malloc` 申请的数组，第 `t` 个元素是第 `t` 拍运行的任务编号（空闲为 `-1`）
- `*returnSize`：数组长度

### 自定义输入格式

```
[1,3,2]
[0,1,2]
[3,2,1]
```

3 行依次是 `priority`、`arrive`、`burst`。
