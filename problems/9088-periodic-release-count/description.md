# 周期任务累计释放次数

任务第一次在period时刻释放，之后固定周期释放。输入非递减非负时间戳times（≤10^6），返回每次轮询自上次轮询以来新增的释放次数。period为1..1000，最多1000次轮询。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* periodicReleases(int* times,int timesSize,int period,int* returnSize);
```

## 示例 1

输入：
```text
[0,9,10,35,35,40]
10
```
输出：
```text
[0,0,1,2,0,1]
```

## 示例 2

输入：
```text
[1,2,3]
1
```
输出：
```text
[1,1,1]
```

## 自定义输入格式

按顺序每行一个参数：times、period。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
