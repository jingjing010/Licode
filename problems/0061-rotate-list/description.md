给你一个链表的头节点 `head` ，旋转链表，将链表每个节点向右移动 `k` 个位置。

### 示例 1

```
原链表：     1 -> 2 -> 3 -> 4 -> 5
旋转 1 次：  5 -> 1 -> 2 -> 3 -> 4
旋转 2 次：  4 -> 5 -> 1 -> 2 -> 3
```

```
输入：head = [1,2,3,4,5], k = 2
输出：[4,5,1,2,3]
```

### 示例 2

```
原链表：     0 -> 1 -> 2
旋转 1 次：  2 -> 0 -> 1
旋转 2 次：  1 -> 2 -> 0
旋转 3 次：  0 -> 1 -> 2
旋转 4 次：  2 -> 0 -> 1
```

```
输入：head = [0,1,2], k = 4
输出：[2,0,1]
```

### 提示

- 链表中节点的数目在范围 `[0, 500]` 内
- `-100 <= Node.val <= 100`
- `0 <= k <= 2 * 10^9`

### 函数说明

```c
struct ListNode {
    int val;
    struct ListNode *next;
};

struct ListNode* rotateRight(struct ListNode* head, int k);
```

- `struct ListNode` 已由系统定义，**不要**在代码里重复定义
- `head`：链表的头指针，空链表用 `NULL` 表示
- `k`：向右移动的位置数（可能远大于链表长度）
- 返回值：旋转后链表的头指针（直接修改原结点的 `next` 即可，不需要 `malloc` 新结点）

### 自定义输入格式

```
[1,2,3,4,5]
2
```

第 1 行是链表 `head`（空链表写作 `[]`），第 2 行是整数 `k`。输出为旋转后的链表。
