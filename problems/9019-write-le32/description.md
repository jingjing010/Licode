你正在为一个低功耗蓝牙（BLE）设备编写通信协议。BLE 规范规定多字节数值一律采用 **小端（低字节在前）** 格式。现在要把一个 32 位时间戳打包进发送缓冲区，缓冲区里其它位置已经填好了帧头、长度等字段。

请实现函数 `write_le32`：把 32 位无符号整数 `value` 按 **小端** 格式写入 `buf[offset] ~ buf[offset + 3]`：

- `buf[offset]` = 最低字节（bit7~0）
- `buf[offset + 1]` = bit15~8
- `buf[offset + 2]` = bit23~16
- `buf[offset + 3]` = 最高字节（bit31~24）

缓冲区中**其它位置的字节必须保持不变**。你的代码必须与运行它的 CPU 字节序无关。

### 示例 1

```
输入：buf = [0,0,0,0], offset = 0, value = 305419896
输出：[120,86,52,18]
解释：305419896 = 0x12345678，小端写入为 78 56 34 12，即 [120,86,52,18]。
```

### 示例 2

```
输入：buf = [2,1,0,0,0,0,255], offset = 2, value = 1000
输出：[2,1,232,3,0,0,255]
解释：1000 = 0x000003E8，写入 E8 03 00 00 到下标 2~5，其余字节不变。
```

### 示例 3

```
输入：buf = [9,9,9,9,9], offset = 1, value = 4294967295
输出：[9,255,255,255,255]
```

### 提示

- `4 <= buf 长度 <= 1000`
- `0 <= buf[i] <= 255`
- `0 <= offset`，且 `offset + 4 <= buf 长度`
- `0 <= value <= 4294967295`

### 函数说明

```c
void write_le32(uint8_t* buf, int offset, uint32_t value);
```

- `buf`：发送缓冲区首地址
- `offset`：写入的起始下标
- `value`：要写入的 32 位无符号整数
- 无返回值：直接修改 `buf`，判题程序会打印修改后的**整个**缓冲区

### 自定义输入格式

```
[0,0,0,0]
0
305419896
```

第 1 行是缓冲区初始内容 `buf`（每个元素 0~255），第 2 行是 `offset`，第 3 行是十进制的 `value`。输出为调用后整个 `buf` 的内容（十进制字节数组）。
