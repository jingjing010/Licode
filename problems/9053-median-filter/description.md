传感器信号除了持续的小噪声，还经常出现**脉冲干扰**：电机启动、继电器动作的一瞬间，ADC 读数突然跳到一个离谱的值，下一次又恢复正常。滑动平均会把这个"毛刺"摊到好几个输出里，而**中值滤波**直接取窗口里的**中位数**，单个毛刺根本选不上，能被干净地剔除。

给你一段采样信号 `signal`（长度 `len`）和一个**奇数**窗口大小 `k`，请计算中值滤波的结果 `out`（长度同样为 `len`）：

- `out[i]` = 以 `i` 为中心、宽度为 `k` 的窗口（下标 `i - k/2` 到 `i + k/2`，`k/2` 向下取整）中 `k` 个值的**中位数**（排序后正中间的那个）。
- 窗口超出信号两端时，用**端点值补齐**：下标小于 `0` 的位置取 `signal[0]`，大于 `len - 1` 的位置取 `signal[len - 1]`。

### 示例 1

```
输入：signal = [10,12,250,11,13], k = 3
输出：[10,12,12,13,13]
解释：
i=0：窗口 [10(补齐),10,12] → 10
i=1：窗口 [10,12,250] → 12
i=2：窗口 [12,250,11] → 12      ← 毛刺 250 被剔除
i=3：窗口 [250,11,13] → 13
i=4：窗口 [11,13,13(补齐)] → 13
```

### 示例 2

```
输入：signal = [1,100,2,3,200,4], k = 5
输出：[1,2,3,4,4,4]
解释：i=0 的窗口为 [1,1,1,100,2]，中位数 1；i=5 的窗口为 [3,200,4,4,4]，中位数 4。
```

### 示例 3

```
输入：signal = [5,-3], k = 1
输出：[5,-3]
解释：k = 1 时窗口只有自己，输出等于输入。
```

### 提示

- `1 <= len <= 10^4`
- `-10000 <= signal[i] <= 10000`
- `1 <= k <= 51`，且 `k` 为奇数（`k` 可能大于 `len`）

### 函数说明

```c
void medianFilter(const int16_t* signal, size_t len, size_t k, int16_t* out);
```

- `out` 由判题程序提前分配好（长度 `len`），把结果写进去即可

### 自定义输入格式

```
[10,12,250,11,13]
3
```

第 1 行是信号数组，第 2 行是 `k`。输出数组 `out`。
