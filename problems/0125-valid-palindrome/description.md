# 验证回文串

忽略非字母数字字符与大小写，判断ASCII字符串是否为回文。长度0到2*10^5。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool isPalindrome(char* s);
```

## 示例 1

输入：
```text
"A man, a plan, a canal: Panama"
```
输出：
```text
true
```

## 示例 2

输入：
```text
"race a car"
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
