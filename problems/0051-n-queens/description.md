按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

### 示例 1

```
输入：n = 4
输出：[["..Q.","Q...","...Q",".Q.."],[".Q..","...Q","Q...","..Q."]]
解释：如上所示，4 皇后问题存在两个不同的解法。
```

### 示例 2

```
输入：n = 1
输出：[["Q"]]
```

### 提示

- `1 <= n <= 9`

### 函数说明

```c
char*** solveNQueens(int n, int* returnSize, int** returnColumnSizes);
```

- `n`：棋盘大小和皇后个数
- 返回值：用 `malloc` 申请的数组，每个元素是一种解法（一个 `char**`，共 `n` 行）；每一行是长度为 `n`、以 `'\0'` 结尾的字符串，也要 `malloc`
- `*returnSize`：写入解法的个数（无解时写 0）
- `*returnColumnSizes`：你需要 `malloc` 一个长度为解法个数的 `int` 数组，每个元素写对应解法的行数（都是 `n`），再把它的地址赋给 `*returnColumnSizes`

### 自定义输入格式

```
4
```

只有 1 行：整数 `n`。（解法之间的顺序任意：判题时会把所有解法按字典序排序后输出，所以示例输出和力扣原题的顺序不同；每种解法内部的行必须按棋盘从上到下的顺序排列）
