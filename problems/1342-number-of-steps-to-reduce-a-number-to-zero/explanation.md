# 1342. 将数字变成 0 的操作次数 —— 小白详细题解

> 一道"照着规则做"的模拟题。做完后再从**二进制**的角度看，会发现除以 2 和减 1 其实都是在操作二进制位。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 一个数，偶数就除以 2，奇数就减 1，一直做到变成 0，问一共做了几步。

示例 1，`num = 14`：

| 步骤 | 当前数 | 奇偶 | 操作 | 结果 |
|---|---|---|---|---|
| 1 | 14 | 偶 | ÷ 2 | 7 |
| 2 | 7 | 奇 | − 1 | 6 |
| 3 | 6 | 偶 | ÷ 2 | 3 |
| 4 | 3 | 奇 | − 1 | 2 |
| 5 | 2 | 偶 | ÷ 2 | 1 |
| 6 | 1 | 奇 | − 1 | 0 |

共 6 步。

**几个需要注意的细节：**

1. `num = 0` 已经是 0 了，答案是 **0** 步。
2. 1 是奇数，最后一步一定是 `1 - 1 = 0`。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 判断奇偶

```c
num % 2 == 0     // 偶数
num & 1          // 取二进制最低位：1 表示奇数，0 表示偶数（只适用于非负数时最直观）
```

### 2. 位运算与除法的关系

| 操作 | 十进制 | 二进制（以 14 为例） |
|---|---|---|
| `num / 2` 或 `num >> 1` | 14 → 7 | `1110` → `111`（整体右移一位） |
| 奇数 `num - 1` | 7 → 6 | `111` → `110`（最低位的 1 变成 0） |

对非负整数，`num >> 1` 和 `num / 2` 结果相同。

---

## 💡 第三步：思路一 —— 直接模拟

### 思路

完全按照题意：只要 `num > 0`，偶数除 2、奇数减 1，步数加 1。

### 代码

```c
int numberOfSteps(int num) {
    int steps = 0;                   // 记录操作次数
    while (num > 0) {                // 还没变成 0 就继续
        if (num % 2 == 0) {
            num /= 2;                // 偶数：除以 2
        } else {
            num -= 1;                // 奇数：减 1
        }
        steps++;                     // 每做一次操作，步数加 1
    }
    return steps;
}
```

### 复杂度分析

- **时间复杂度 O(log num)**：每两步之内至少除一次 2，`num ≤ 10^6` 时最多约 40 步。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 二进制计数

### 思路

把 `num` 写成二进制，观察两种操作：

- **奇数减 1**：最低位是 1，把它变成 0。每个 1 都要被这样"消掉"一次；
- **偶数除 2**：最低位是 0，右移一位。从最高位到最低位，一共要右移 `位数 - 1` 次（最后剩下的最高位 1 通过减 1 变成 0）。

所以：

> **步数 = 二进制中 1 的个数 + 二进制的位数 − 1**（`num > 0` 时）

### 手动验证

| num | 二进制 | 1 的个数 | 位数 | 步数 |
|---|---|---|---|---|
| 14 | 1110 | 3 | 4 | 3 + 4 − 1 = 6 ✅ |
| 8 | 1000 | 1 | 4 | 1 + 4 − 1 = 4 ✅ |
| 123 | 1111011 | 6 | 7 | 6 + 7 − 1 = 12 ✅ |

### 代码

```c
int numberOfSteps(int num) {
    if (num == 0) {                  // 0 不需要任何操作
        return 0;
    }
    int ones = 0;                    // 二进制中 1 的个数
    int bits = 0;                    // 二进制的总位数
    while (num > 0) {
        ones += num & 1;             // 最低位是 1 就计数
        bits++;                      // 每处理一位，位数加 1
        num >>= 1;                   // 右移，处理下一位
    }
    return ones + bits - 1;          // 每个 1 减一次，再右移 (位数 - 1) 次
}
```

### 复杂度分析

- **时间复杂度 O(log num)**：二进制有几位就循环几次（最多 20 次）。
- **空间复杂度 O(1)**。

> 💡 GCC 还提供了内置函数：`__builtin_popcount(num)` 求 1 的个数，`__builtin_clz(num)` 求前导 0 的个数。答案也可以写成 `__builtin_popcount(num) + 31 - __builtin_clz(num)`（`num > 0`）。在嵌入式开发中这类函数经常被编译成一条机器指令。

---

## ⚠️ 第五步：小白常见错误

1. **把 `num = 0` 的答案算成 1 或负数** → 二进制公式里 `0 + 0 - 1 = -1`，必须先特判。
2. **偶数和奇数的操作写反** → 奇数除以 2 会丢掉余数，结果偏小。
3. **每次循环把步数加了两次**（例如在 `if` 和 `else` 里各写一次 `steps++`，又在外面写一次）→ 结果翻倍。
4. **`if (num & 1 == 0)` 少了括号** → `==` 优先级高于 `&`，实际变成 `num & (1 == 0)` 即 `num & 0`，永远为 0。要写 `(num & 1) == 0`。
5. **用 `while (num != 1)` 作为循环条件** → 漏掉最后一步 `1 → 0`，而且 `num = 0` 时会死循环。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 建议 |
|---|---|---|---|
| 直接模拟 | O(log n) | O(1) | 先写这个 |
| 二进制计数 | O(log n) | O(1) | 理解位运算的本质 |
