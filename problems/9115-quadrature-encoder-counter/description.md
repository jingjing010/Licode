# 正交编码器状态解码

AB状态编码为0..3，正向顺序00→01→11→10→00，每次合法边沿+1，逆向−1，不变或双位跳变计0。返回净边沿数；初始采样不计数。最多1000项。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int quadratureCount(int* states,int statesSize);
```

## 示例 1

输入：
```text
[0,1,3,2,0]
```
输出：
```text
4
```

## 示例 2

输入：
```text
[0,2,3,1,0]
```
输出：
```text
-4
```

## 自定义输入格式

按顺序每行一个参数：states。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
