# 丢失的数字：题解

## 📖 先读懂题目

完整集合0到n中的每个值，与数组实际值逐一异或。相同数异或抵消为0，只剩缺失值。初始放入n，再对下标i和nums[i]异或，避免求和溢出。

### 示例1

输入：
```text
[3,0,1]
```
输出：
```text
2
```

### 示例2

输入：
```text
[0,1]
```
输出：
```text
2
```

### 示例3

输入：
```text
[9,6,4,2,3,5,7,0,1]
```
输出：
```text
8
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 可以开一个长度为 n + 1 的标记数组，把出现过的数打上标记，再找没被标记的那个。
2. 0 + 1 + ... + n 的总和可以用公式 n(n+1)/2 直接算出来。用它减去数组所有元素之和，剩下的是什么？
3. 异或有两个性质：x ^ x = 0，x ^ 0 = x。把 0~n 和数组里所有数全部异或起来，成对出现的都抵消了。

## 可直接提交的 C 代码

```c
int missingNumber(int* nums, int numsSize) {
    int x = numsSize;
    for (int i = 0; i < numsSize; i++) x ^= i ^ nums[i];
    return x;
}
```

## 📊 复杂度

时间 O(n)，空间 O(1)。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。

## 🔗 举一反三

改变输入长度为1、重复值、边界整数，手工验证每一步保存的状态。思考能否在输入逐个到达时保留相同的状态完成计算。
