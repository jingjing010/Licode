# C 语言刷题 OJ（本地版）

一个完全在自己电脑上运行的 C 语言刷题平台：题目来自力扣（LeetCode）+ 嵌入式 C 原创题，判题方式与力扣相同（**核心代码模式**：只写函数，不写 `main`）。
不需要联网、不需要注册，题目、代码、提交记录、笔记全部保存在本地。

- 题库 300 题：**力扣 Hot 100** 全部 + **嵌入式 C 60 题** + 经典分类题 140 道
- 每道题都有：题面、函数模板、公开样例 + 隐藏测试点、渐进式提示、**面向零基础的详细题解**（题解里的代码都能直接 AC）
- 学习工具：题单、收藏、错题本、Markdown 笔记、每日推荐、随机一题、统计与进度

---

## 1. 环境准备

| 依赖 | 要求 | 说明 |
|---|---|---|
| Python | 3.8 及以上 | 只用标准库，**不需要 pip install 任何东西** |
| gcc | MinGW-w64（Windows）/ 系统 gcc（Linux、macOS） | 用来编译你的代码 |
| 浏览器 | Chrome / Edge / Firefox 新版 | 打开网页做题 |

检查是否装好：

```powershell
python --version
gcc --version
```

如果 `gcc` 找不到，任选一种方式告诉 OJ 它在哪：

1. 把 gcc 所在的 `bin` 目录加入系统环境变量 `PATH`（推荐）；
2. 在项目根目录新建 `config.json`：`{ "gcc": "C:\\mingw64\\bin\\gcc.exe" }`；
3. 设置环境变量 `OJ_GCC` 为 gcc 的完整路径。

## 2. 启动

**Windows：双击 `start.bat`** 即可，或者在项目目录执行：

```powershell
python server.py
```

启动后会自动打开浏览器访问 <http://127.0.0.1:8080>。终端窗口就是服务器，**做题期间不要关掉它**；想停止时在终端按 `Ctrl + C`。

| 启动参数 | 作用 |
|---|---|
| `python server.py 9000` | 换成 9000 端口（端口被占用时会自动往后找空闲端口） |
| `python server.py --no-browser` | 不自动打开浏览器 |

## 3. 怎么做题

1. 打开 **题库**，点一道题（推荐从「1. 两数之和」开始）；
2. 左边读题，右边编辑器里已经写好了函数框架，**只在函数体里写代码**；
3. 点 **▶ 运行**（`Ctrl + Enter`）：只跑公开样例，能看到输入、你的输出和预期输出；
4. 样例都对了，点 **⬆ 提交**（`Ctrl + Shift + Enter`）：跑全部隐藏测试点，全部通过就是 **Accepted**；
5. 卡住了先看题面下方的 **💡 提示**（一条比一条接近答案），再看 **题解** 标签页。

几条最重要的规则：

- **不要写 `main`，不要自己 `scanf`**：系统会读输入、调用你的函数、打印返回值；
- **不要改函数签名**；常用头文件（`stdio/stdlib/string/stdbool/limits/math/ctype/stdint`）已自动包含；
- 链表、二叉树题的 `struct ListNode` / `struct TreeNode` 已经定义好，不要重复定义；
- 调试用 `fprintf(stderr, ...)`，它显示在「标准错误」区域，不影响判题；用 `printf` 会混进输出导致答案错误；
- 返回数组要 `malloc`，并通过 `*returnSize` 写出长度。

更多细节（判题结果含义、输入输出格式、`returnSize` / `returnColumnSizes` 的用法）见网页里的 **新手指南**，或直接看 [`docs/GUIDE.md`](docs/GUIDE.md)。

| 功能 | 位置 | 说明 |
|---|---|---|
| 题单 | 题库顶部标签 | 全部 / 🔥 Hot 100 / 🔧 嵌入式 C / ⭐ 我的收藏 / 📕 错题本。做题页的「上一题 / 下一题」在当前题单内跳转 |

| 📅 今日推荐 | 题库页顶部 | 每天固定推荐一道没做过的 Hot 100 题 |
| 🎲 随机一题 | 题库页顶部 | 从当前筛选结果里随机挑一道没做过的 |
| ⭐ 收藏 | 列表里的 ☆ / 题目标题旁 | 收藏后在「我的收藏」里集中练 |
| 📕 错题本 | 题单标签 | 提交过但还没通过的题自动进来 |
| 📝 笔记 | 做题页「笔记」标签 | 支持 Markdown 和预览，自动保存，有笔记的题在列表里显示 📝 |
| 自定义输入 | 做题页「测试用例」 | 按题面末尾的「自定义输入格式」写数据再运行 |

| 提交记录 | 做题页 / 记录页 | 每次提交的结果、耗时和代码 |
| 统计 | 统计页 | 通过数、难度分布、各题单进度 |

编辑器快捷键：`Ctrl + /` 注释，`Tab` / `Shift + Tab` 缩进。代码会自动保存在浏览器里。

## 5. 数据保存在哪

| 内容 | 位置 |
|---|---|
| 提交记录、收藏、笔记 | `data/oj.db`（SQLite） |
| 编辑器里的代码草稿 | 浏览器 localStorage |

## 7. 维护题库（给出题者）

```powershell
$env:PYTHONIOENCODING='utf-8'; [Console]::OutputEncoding=[Text.Encoding]::UTF8   # 防止中文乱码

python tools/progress.py -v      # 查看进度：每批完成数、缺哪些题、哪些题文件不完整
python tools/build.py 20 21      # 构建指定题：生成测试 → 核对样例 → 参考答案与题解代码全部 AC
python tools/build.py --all      # 全量构建 + 自检
python tools/verify.py 20        # 只检查不重新生成
```

新增一道题的完整步骤和格式要求见 [`docs/ADD_PROBLEM.md`](docs/ADD_PROBLEM.md)，以 `problems/0001-two-sum/` 为标准范例。

项目用 git 做存档，题目批量更新后建议提交一次：`git add -A && git commit -m "..."`，出问题时可以用 `git checkout -- problems/` 找回。

## 8. 常见问题

**打开网页显示无法访问？** 确认启动 `server.py` 的终端窗口还开着；端口被占用时会自动换端口，看终端里打印的实际地址。

**提示「未找到 gcc 编译器」？** 见第 1 节配置 gcc，改完重启 `server.py`。

**第一次运行特别慢或超时？** 杀毒软件会扫描新生成的 exe，把项目文件夹加入白名单即可。

**`printf("%zu")` 输出不对？** Windows 的 MinGW 使用 msvcrt，不支持 `%zu`，请用 `%d` 或强转后用 `%lu`。

**我的代码丢了？** 草稿存在浏览器里，换浏览器或清缓存会丢；提交过的代码在「提交记录」里都能找回。重要代码可以用「⤓ 导出」保存成文件。
