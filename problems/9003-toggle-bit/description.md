让 LED 闪烁是每个嵌入式工程师的第一个程序：在定时器中断里每次把 GPIO 输出寄存器 `GPIOx_ODR` 中 LED 对应的那一位 **翻转** 一次——原来是高电平就变低，原来是低电平就变高。

给定寄存器当前的值 `reg` 和位号 `n`，请把 `reg` 的 **第 `n` 位取反**（0 变 1，1 变 0），**其余位保持不变**，返回修改后的寄存器值。

位号从 `0` 开始：第 `0` 位是最低位（LSB），第 `31` 位是最高位（MSB）。

### 示例 1

```
输入：reg = 0, n = 0
输出：1
解释：第 0 位由 0 变为 1。
```

### 示例 2

```
输入：reg = 5, n = 0
输出：4
解释：5 = 0b101，第 0 位由 1 变为 0，得到 0b100 = 4。
```

### 示例 3

```
输入：reg = 0, n = 31
输出：2147483648
解释：最高位由 0 变为 1，得到 0x80000000 = 2147483648。
```

### 提示

- `0 <= reg <= 2^32 - 1`（即 `0x00000000` ~ `0xFFFFFFFF`）
- `0 <= n <= 31`

### 函数说明

```c
uint32_t toggle_bit(uint32_t reg, int n);
```

- `reg`：寄存器的原始值（32 位无符号整数）
- `n`：要翻转的位号
- 返回值：第 `n` 位取反、其余位不变后的值

### 自定义输入格式

```
5
0
```

第 1 行是 `reg`，第 2 行是 `n`，均为十进制整数。输出为修改后的寄存器值（十进制）。
