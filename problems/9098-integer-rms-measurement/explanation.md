# 整数均方根测量：题解

## 📖 先读懂题目

返回floor(sqrt(sum(x²)/n))。输入为int16采样，1≤n≤1000，不使用浮点输出。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[3,4]` | `3` |
| 2 | `[32767,-32768]` | `32767` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

`uint32_t`运算按2^32取模。先转换为无符号类型再移位，避免负数左移；移位数必须小于类型位宽。超过INT_MAX的结果仍要按无符号值理解。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

先用64位累加平方，再除采样数得到均方值，最后用整数二分求向下取整平方根。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int integerRms(int *samples, int samplesSize) {
    uint64_t sum = 0;
    for (int i = 0; i < samplesSize; ++i)
        sum += (int64_t)samples[i] * samples[i];
    uint64_t mean = sum / (unsigned)samplesSize;
    uint32_t lo = 0, hi = 32768;
    while (lo < hi) {
        uint32_t mid = lo + (hi - lo + 1) / 2;
        if ((uint64_t)mid * mid <= mean)
            lo = mid;
        else
            hi = mid - 1;
    }
    return (int)lo;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n+log 32768)，空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 用有符号int承接无符号32位位模式，导致最高位被当成符号。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
