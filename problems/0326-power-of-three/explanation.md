# 326. 3 的幂 —— 小白详细题解

> 和 231. 2 的幂 是姐妹题，但 2 的幂那套位运算技巧在这里用不上了。我们来看看还有什么巧妙办法。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 判断 n 是不是 1、3、9、27、81、243……中的某一个。

| n | 是 3 的幂？ | 原因 |
|---|---|---|
| 27 | ✅ | 3³ |
| 0 | ❌ | 3 的任何次方都不为 0 |
| 9 | ✅ | 3² |
| 45 | ❌ | 45 = 3² × 5，含有 5 |
| 1 | ✅ | 3⁰ |

**几个需要注意的细节：**

1. **0 和负数一定不是**（3 的整数次幂都是正数）。
2. `int` 范围内最大的 3 的幂是 `3^19 = 1162261467`（`3^20` 约 34.8 亿，超出 `int`）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `%` 判断整除，`/` 做除法

`n % 3 == 0` 表示能被 3 整除；`n /= 3` 把 n 除以 3。

### 2. 为什么 2 的幂的位运算技巧不能用？

2 的幂在二进制下"只有一个 1"，但 3 的幂没有这种规律：`9 = 1001`，`27 = 11011`。所以要换思路。

### 3. 质数的幂的约数

3 是质数，所以 `3^19` 的**正约数**恰好只有 `3^0, 3^1, …, 3^19` 这 20 个。换句话说：

> 一个正整数 n 能整除 `3^19`，**当且仅当** n 是 3 的幂。

---

## 💡 第三步：思路一 —— 不断除以 3

### 思路

- `n <= 0`：返回 `false`；
- 只要 `n` 能被 3 整除，就除以 3；
- 最后剩下 1 就是 3 的幂。

### 手动模拟

| n | 过程 | 剩下 | 结果 |
|---|---|---|---|
| 27 | 27 → 9 → 3 → 1 | 1 | ✅ |
| 45 | 45 → 15 → 5（5 不能被 3 整除） | 5 | ❌ |

### 代码

```c
bool isPowerOfThree(int n) {
    if (n <= 0) {                // 0 和负数不是；同时避免 n = 0 时死循环
        return false;
    }
    while (n % 3 == 0) {         // 能被 3 整除就一直除
        n /= 3;
    }
    return n == 1;               // 最后剩 1，说明只由因子 3 组成
}
```

### 复杂度分析

- **时间复杂度 O(log n)**：最多除 19 次。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 判断是否为 3^19 的约数（不用循环）

### 思路

利用上面的结论：`n > 0` 并且 `1162261467 % n == 0`，n 就是 3 的幂。

### 手动验证

| n | 1162261467 % n | 结果 |
|---|---|---|
| 27 | 0 | ✅ |
| 45 | 1162261467 = 45 × 25828032 + 27，余 27 | ❌ |
| 6 | 1162261467 是奇数，不能被 6 整除 | ❌ |

### 代码

```c
bool isPowerOfThree(int n) {
    // 1162261467 = 3^19，是 int 范围内最大的 3 的幂
    // 因为 3 是质数，3^19 的正约数恰好就是全部的 3^k（0 <= k <= 19）
    return n > 0 && 1162261467 % n == 0;
}
```

> ⚠️ 这个技巧只对**质数**的幂有效。比如 4 的幂就不行：`2` 能整除 `4^15`，但 2 不是 4 的幂。

### 复杂度分析

- **时间复杂度 O(1)**，**空间复杂度 O(1)**。

---

## ⚠️ 第五步：小白常见错误

1. **忘记判断 `n <= 0`** → `n = 0` 时 `0 % 3 == 0` 永远成立，死循环；思路二中 `1162261467 % 0` 是**除以零**，程序直接崩溃。
2. **用 `log(n) / log(3)` 判断是否为整数** → 浮点误差：`log(243) / log(3)` 可能算出 4.999999999，不可靠。
3. **照搬 `n & (n - 1) == 0`** → 那是 2 的幂的判断方法，对 3 的幂完全不适用。
4. **写错最大的 3 的幂** → 写成 `3^20` 会溢出 `int`；用 `pow(3, 19)` 返回的是 `double`，`%` 不能用于 `double`。直接写常量 `1162261467` 最安全。
5. **只判断 `n % 3 == 0`** → 能被 3 整除的数不一定是 3 的幂，比如 6、45。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 建议 |
|---|---|---|---|
| 不断除以 3 | O(log n) | O(1) | 通用，先写这个 |
| 3^19 % n | O(1) | O(1) | 进阶答案（仅适用于质数的幂） |

---

## 🔗 举一反三

- **231. 2 的幂**：可以用 `n & (n - 1)`，也可以用 `2^30 % n`。
- **342. 4 的幂**：不能用"约数法"，需要结合 2 的幂判断和 `n % 3 == 1`（或位掩码）。
- **263. 丑数**：同样是"除尽某些因子看是否剩 1"的思路。
