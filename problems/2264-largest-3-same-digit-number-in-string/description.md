# 字符串中最大的 3 位相同数字

返回数字字符串中最大的连续三位相同数字子串，允许000；不存在则返回空字符串。长度3到1000。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* largestGoodInteger(char* num);
```

## 示例 1

输入：
```text
"6777133339"
```
输出：
```text
"777"
```

## 示例 2

输入：
```text
"2300019"
```
输出：
```text
"000"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
