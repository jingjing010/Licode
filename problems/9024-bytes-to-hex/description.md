调试通信协议时，我们经常需要把收到的原始字节通过串口打印出来看，或者把设备序列号、芯片 UID、哈希值以文本形式上报给服务器（JSON 里不能直接放二进制）。最常用的格式就是**十六进制字符串**：每个字节写成两位十六进制字符。

请实现函数 `bytes_to_hex`：把 `buf` 中的 `len` 个字节依次转换成**两位大写十六进制**字符，拼接成一个以 `'\0'` 结尾的新字符串并返回。

- 每个字节固定输出 2 个字符，**前导 0 不能省略**：`10` 要输出 `"0A"`
- 字母一律**大写**
- 返回的字符串必须用 `malloc` 分配（判题程序会调用 `free`）；`len = 0` 时返回空字符串 `""`
- 不要使用 `sprintf`/`snprintf`

### 示例 1

```
输入：buf = [18,52,171,205]
输出："1234ABCD"
解释：18 = 0x12，52 = 0x34，171 = 0xAB，205 = 0xCD。
```

### 示例 2

```
输入：buf = [0,255,10]
输出："00FF0A"
```

### 示例 3

```
输入：buf = []
输出：""
```

### 提示

- `0 <= len <= 1000`
- `0 <= buf[i] <= 255`

### 函数说明

```c
char* bytes_to_hex(const uint8_t* buf, int len);
```

- `buf`：要转换的字节，`len`：字节数
- 返回值：`malloc` 得到的字符串，长度为 `2 * len`

### 自定义输入格式

```
[18,52,171,205]
```

只有 1 行：字节数组 `buf`（每个元素 0~255）。输出为带双引号的结果字符串。
