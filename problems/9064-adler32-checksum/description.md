# Adler-32 数据块校验

计算Adler-32：a初值1，b初值0，每字节更新a=(a+x)%65521，b=(b+a)%65521，返回(b<<16)|a。长度0到1024，结果按无符号十进制输出。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint32_t adler32Block(const uint8_t* data,size_t len);
```

## 示例 1

输入：
```text
[49,50,51,52,53,54,55,56,57]
```
输出：
```text
152961502
```

## 示例 2

输入：
```text
[]
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
