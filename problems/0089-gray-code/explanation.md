# 89. 格雷编码 —— 小白详细题解

> 格雷码是一种"相邻两个数只差一位"的编码，在旋转编码器、跨时钟域的计数器里非常常见。这道题有两种漂亮的构造方法：**镜像反射**和**一行公式 `i ^ (i >> 1)`**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把 `0 ~ 2^n - 1` 这 `2^n` 个数**排个队**，从 0 开始，要求**每相邻两个数的二进制只差一位**，而且**队尾和队头也只差一位**（首尾相接成一个环）。

拿示例 1（`n = 2`）来说：

| 位置 | 0 | 1 | 2 | 3 | （回到 0） |
|---|---|---|---|---|---|
| 十进制 | 0 | 1 | 3 | 2 | 0 |
| 二进制 | 00 | 01 | 11 | 10 | 00 |
| 和下一个差几位 | 1 | 1 | 1 | 1 | |

**几个需要注意的细节：**

1. **答案不唯一**：`[0,2,3,1]` 也对。本 OJ 会检查你的序列是否合法，合法就统一输出 `[0,1,3,2]` 这样的标准序列。
2. 每个数必须**恰好出现一次**，数组长度必须是 `2^n`。
3. 第一个数必须是 `0`。
4. 在 C 语言里 `2^n` **不是**"2 的 n 次方"，`^` 是异或！`2` 的 `n` 次方要写成 `1 << n`。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. `1 << n` 就是 2 的 n 次方

`1 << 3` 把 1 左移 3 位，得到 `1000₂ = 8`。`n` 最大是 16，`1 << 16 = 65536`，int 完全放得下。

### 2. 异或 `^`：相同为 0，不同为 1

```
  0110
^ 0011
------
  0101
```

两个数异或后，结果里的 1 就是它们**不同的那些位**。所以"`a` 和 `b` 只差一位" ⇔ "`a ^ b` 恰好只有一个 1"。

### 3. 返回数组：`malloc` + `*returnSize`

和第 1 题一样，返回的数组要用 `malloc` 申请（局部数组在函数结束后就失效了），并且要通过 `*returnSize = 长度;` 告诉调用者数组有多长。

---

## 💡 第三步：思路一 —— 镜像反射构造

### 思路

假设我们已经有了 `n - 1` 位的格雷码序列 `G`，怎么得到 `n` 位的？

1. **前一半**：照抄 `G`（最高位补 0）。相邻只差一位，没问题。
2. **后一半**：把 `G` **倒过来**，每个数的最高位置 1。倒过来之后相邻的仍然只差一位。
3. **接缝处**：前一半的最后一个数是 `G[末尾]`，后一半的第一个数是 `G[末尾] | 最高位`，只差最高位这一位！
4. **首尾**：整个序列的第一个是 `0`，最后一个是 `G[0] | 最高位 = 最高位`，也只差一位。

就像照镜子一样，所以叫**镜像反射**。

### 手动模拟

| 位数 | 前一半（照抄） | 后一半（倒序 + 最高位 1） | 结果 |
|---|---|---|---|
| 0 位 | | | `[0]` |
| 1 位 | `0` | `0` 置最高位 → `1` | `[0, 1]` |
| 2 位 | `00, 01` | 倒序 `01, 00`，置最高位 → `11, 10` | `[0, 1, 3, 2]` |
| 3 位 | `000, 001, 011, 010` | `110, 111, 101, 100` | `[0, 1, 3, 2, 6, 7, 5, 4]` |

### 代码

```c
int* grayCode(int n, int* returnSize) {
    int total = 1 << n;                              // 一共 2^n 个数
    int* res = (int*)malloc(sizeof(int) * total);
    res[0] = 0;                                      // 0 位格雷码：只有一个 0
    int len = 1;                                     // 当前已经构造好的长度

    for (int k = 0; k < n; k++) {                    // 每次多加一位：第 k 位
        // 把已有的 len 个数倒序抄到后面，并把第 k 位置 1
        for (int i = len - 1; i >= 0; i--) {
            res[len + (len - 1 - i)] = res[i] | (1 << k);
        }
        len *= 2;                                    // 长度翻倍
    }

    *returnSize = total;                             // 告诉调用者数组长度
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(2^n)**：每个数只被写一次。
- **空间复杂度 O(1)**：除了返回数组外只用了几个变量。

## 🚀 第四步：思路二 —— 公式 `i ^ (i >> 1)`

### 思路

把镜像构造得到的序列写出来，再和下标 `i` 对比，会发现一个规律：

| i | i 的二进制 | i >> 1 | i ^ (i >> 1) | 格雷码 |
|---|---|---|---|---|
| 0 | 000 | 000 | 000 | 0 |
| 1 | 001 | 000 | 001 | 1 |
| 2 | 010 | 001 | 011 | 3 |
| 3 | 011 | 001 | 010 | 2 |
| 4 | 100 | 010 | 110 | 6 |
| 5 | 101 | 010 | 111 | 7 |
| 6 | 110 | 011 | 101 | 5 |
| 7 | 111 | 011 | 100 | 4 |

**第 `i` 个格雷码就是 `i ^ (i >> 1)`**：格雷码的每一位 = 二进制的这一位 异或 它左边那一位。

**为什么相邻只差一位？** `i` 到 `i + 1` 时，`i` 末尾的一串 1 全变成 0，它左边的那个 0 变成 1（比如 `0111 → 1000`）。在"每一位异或左边一位"之后，那一串连续变化的位两两抵消，最后只剩**一位**发生了变化。

### 代码

```c
int* grayCode(int n, int* returnSize) {
    int total = 1 << n;                              // 2^n 个数
    int* res = (int*)malloc(sizeof(int) * total);
    for (int i = 0; i < total; i++) {
        res[i] = i ^ (i >> 1);                       // 第 i 个格雷码
    }
    *returnSize = total;
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(2^n)**：一个循环。
- **空间复杂度 O(1)**（不算返回数组）。

> 💬 **反过来**：已知格雷码 `g`，怎么还原 `i`？`i` 的最高位等于 `g` 的最高位，然后从高到低每一位等于"`g` 的这一位 异或 `i` 的上一位"，也就是 `i = g ^ (g >> 1) ^ (g >> 2) ^ ...` 一直异或下去（这是数学写法，不是代码）。

---

## ⚠️ 第五步：小白常见错误

1. **把 2 的 n 次方写成 `2 ^ n`**：`^` 是异或，`2 ^ 2 = 0`！要写 `1 << n`。
2. **镜像时顺着抄而不是倒着抄**：`res[len + i] = res[i] | (1 << k)` 会得到 `[0,1,2,3]`，`1 → 2`（`01 → 10`）差了两位，不合法。
3. **忘了设置 `*returnSize`**：调用者不知道数组长度，输出为空数组。
4. **返回局部数组** `int res[65536]; return res;`：函数结束后内存失效，而且 256KB 的局部数组还可能栈溢出。
5. **以为只能输出示例里那一种**：任何合法的格雷码都算对，比如镜像时把新位加在最低位也行。但是首尾也必须只差一位，别忘了检查这一点。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 镜像反射 | O(2^n) | O(1) | ⭐⭐ | 能讲清楚"为什么对"，面试推荐先讲它 |
| 公式 `i ^ (i >> 1)` | O(2^n) | O(1) | ⭐ | 代码最短，记住这个公式 |
