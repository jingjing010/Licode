# 88. 合并两个有序数组 —— 小白详细题解

> 这道题是"归并排序"里**合并**那一步的原型，也是学习"**从后往前**双指针"的经典题。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 有两排已经从小到大排好的数字 `nums1`（有效部分是前 `m` 个）和 `nums2`（共 `n` 个）。请把它们合成一排，仍然从小到大，并且**直接放进 `nums1` 里**。

`nums1` 特意准备了 `m + n` 个格子，后 `n` 个是占位用的 0，就是留给你放结果的。拿示例 1 来说：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| nums1（合并前） | 1 | 2 | 3 | 0（空位） | 0（空位） | 0（空位） |
| nums2 | 2 | 5 | 6 | | | |
| nums1（合并后） | 1 | 2 | 2 | 3 | 5 | 6 |

**几个需要注意的细节：**

1. 函数返回 `void`，**结果必须写在 `nums1` 里**，判题程序会打印整个 `nums1`。
2. `nums1` 后面的 0 只是**占位**，不是真正的数据，不能参与合并。比如示例 3 的 `nums1 = [0], m = 0`，那个 0 不算数。
3. `m` 或 `n` 都**可能是 0**。
4. 数值可以是负数，范围到 `±10^9`，但不会超过 `int` 的范围。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 函数参数里的 `Size` 和 `m`、`n`

```c
void merge(int* nums1, int nums1Size, int m, int* nums2, int nums2Size, int n)
```

| 参数 | 含义 |
|---|---|
| `nums1Size` | `nums1` 的**总长度**，等于 `m + n` |
| `m` | `nums1` 里**有效元素**的个数 |
| `nums2Size` | `nums2` 的长度，等于 `n` |

这是力扣的固定写法，`nums1Size` 和 `nums2Size` 在本题里用不太到，但不能删掉参数。

### 2. `void` 函数如何"返回"结果

函数没有返回值，但 `nums1` 是指针，指向调用者的数组。你往 `nums1[k]` 里写数，调用者那边就能看到。

### 3. `qsort`：C 标准库的排序函数

```c
int cmp(const void* a, const void* b) {
    int x = *(const int*)a, y = *(const int*)b;
    return (x > y) - (x < y);   // x<y 返回 -1，x==y 返回 0，x>y 返回 1
}
qsort(数组首地址, 元素个数, sizeof(int), cmp);
```

> ⚠️ 不要写 `return x - y;`！当 `x = 10^9, y = -10^9` 时，`x - y = 2×10^9` 超出了 `int` 的范围（溢出），排序结果会出错。

---

## 💡 第三步：思路一 —— 先拼起来再排序（最容易想到）

### 思路

1. 把 `nums2` 的 `n` 个数复制到 `nums1` 的后 `n` 个空位上
2. 对整个 `nums1` 排序

完全没有利用"两个数组本来就有序"这个条件，但胜在简单、不容易错。

### 手动模拟（示例 1）

| 步骤 | nums1 |
|---|---|
| 初始 | [1,2,3,0,0,0] |
| 复制 nums2 到后面 | [1,2,3,2,5,6] |
| 排序 | [1,2,2,3,5,6] |

### 代码

```c
int cmp(const void* a, const void* b) {
    int x = *(const int*)a, y = *(const int*)b;
    return (x > y) - (x < y);          // 安全的比较写法，不会溢出
}

void merge(int* nums1, int nums1Size, int m, int* nums2, int nums2Size, int n) {
    // 1. 把 nums2 放到 nums1 的空位里（下标 m 到 m+n-1）
    for (int i = 0; i < n; i++) {
        nums1[m + i] = nums2[i];
    }
    // 2. 整体排序
    qsort(nums1, m + n, sizeof(int), cmp);
}
```

### 复杂度分析

- **时间复杂度 O((m+n) log(m+n))**：排序的代价。
- **空间复杂度 O(log(m+n))**：`qsort` 内部递归用的栈空间。

## 🚀 第四步：思路二 —— 从后往前双指针（最优）

### 为什么不从前往后？

合并两个有序数组的标准做法是：两个指针分别指向两个数组的开头，每次取较小的那个放进结果。
但这里结果要放回 `nums1`！如果从前往后写，会**覆盖掉 `nums1` 里还没比较的数**：

```
nums1 = [1,2,3,0,0,0], nums2 = [2,5,6]
第 1 步取 1 写到 nums1[0]，没问题；
第 3 步取 nums2 的 2 写到 nums1[2]，就把还没用的 3 盖掉了！ ❌
```

### 换个方向：从后往前

`nums1` 的**末尾**是空位！那就反过来：每次比较两个数组**最后**一个还没用的数，把**较大的**放到 `nums1` 的最后一个空位。

- `i = m - 1`：指向 `nums1` 有效部分的最后一个数
- `j = n - 1`：指向 `nums2` 的最后一个数
- `k = m + n - 1`：指向 `nums1` 中下一个要写入的位置（从最后开始）

> ❓ **会不会覆盖还没用的数？** 不会。写入位置 `k = i + j + 1`，只要 `nums2` 还有数没放（`j >= 0`），就有 `k > i`，写的位置永远在 `i` 的右边。

当 `nums2` 全部放完（`j < 0`）时就可以结束了——`nums1` 剩下的数本来就在正确的位置上。

### 手动模拟（示例 1：`nums1 = [1,2,3,_,_,_]`，`nums2 = [2,5,6]`）

| 步 | nums1[i] | nums2[j] | 较大的 | 写到 nums1[k] | nums1 |
|---|---|---|---|---|---|
| 1 | 3 (i=2) | 6 (j=2) | 6 | k=5 | [1,2,3,_,_,6] |
| 2 | 3 (i=2) | 5 (j=1) | 5 | k=4 | [1,2,3,_,5,6] |
| 3 | 3 (i=2) | 2 (j=0) | 3 | k=3 | [1,2,3,3,5,6] |
| 4 | 2 (i=1) | 2 (j=0) | 一样大，取 nums2 的 | k=2 | [1,2,2,3,5,6] |

此时 `j = -1`，`nums2` 已放完，结束。结果 `[1,2,2,3,5,6]`。

### 代码

```c
void merge(int* nums1, int nums1Size, int m, int* nums2, int nums2Size, int n) {
    int i = m - 1;          // nums1 有效部分的最后一个元素
    int j = n - 1;          // nums2 的最后一个元素
    int k = m + n - 1;      // 下一个要写入的位置（从 nums1 末尾开始）

    while (j >= 0) {                            // 只要 nums2 还有数没放
        if (i >= 0 && nums1[i] > nums2[j]) {    // nums1 还有数，并且它更大
            nums1[k] = nums1[i];                // 把 nums1[i] 搬到后面
            i--;
        } else {                                // nums1 用完了，或 nums2[j] 更大（或相等）
            nums1[k] = nums2[j];
            j--;
        }
        k--;                                    // 写入位置往前挪一格
    }
    // 循环结束时 nums2 已经全部放好；nums1 剩下的前 i+1 个数本来就在正确位置
}
```

### 复杂度分析

- **时间复杂度 O(m + n)**：每个数只被搬动一次。
- **空间复杂度 O(1)**：只用了三个下标变量。

---

## ⚠️ 第五步：小白常见错误

1. **从前往后合并直接写入 `nums1`** → 覆盖掉还没比较的数。如果坚持从前往后，就要先把 `nums1` 前 `m` 个数复制到一个临时数组里。
2. **把占位的 0 当成真实数据** → 例如直接对 `nums1` 前 `nums1Size` 个和 `nums2` 合并，示例 3 会得到 `[0,1]` 而不是 `[1]`。
3. **循环条件写成 `while (i >= 0 && j >= 0)` 之后忘了处理剩余的 `nums2`** → `nums1 = [4,5,6,0,0,0], nums2 = [1,2,3]` 时，`nums1` 先用完，`nums2` 的 1、2、3 根本没放进去。
4. **`if` 里没有判断 `i >= 0`** → `m = 0` 或 `nums1` 用完时会访问 `nums1[-1]`，越界。
5. **比较函数写成 `return x - y;`** → 数值范围是 `±10^9`，相减会溢出，`qsort` 排出错误顺序。
6. **对 `nums1` 排序时长度写成 `m`** → 应该是 `m + n`，否则 `nums2` 的数没参与排序。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 拼接后排序 | O((m+n) log(m+n)) | O(log(m+n)) | ⭐ | 先保证能写对 |
| 从后往前双指针 | O(m+n) | O(1) | ⭐⭐ | 题目进阶要求，面试标准答案 |

> 🎯 **学习建议**：这道题最值得记住的是"**正着写会覆盖，就倒着写**"这个想法，很多原地修改的题都会用到。
