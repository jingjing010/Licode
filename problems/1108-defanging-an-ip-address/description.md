# IP 地址无效化

把有效IPv4地址中的每个点替换为[.]，返回新字符串。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* defangIPaddr(char* address);
```

## 示例 1

输入：
```text
"1.1.1.1"
```
输出：
```text
"1[.]1[.]1[.]1"
```

## 示例 2

输入：
```text
"255.100.50.0"
```
输出：
```text
"255[.]100[.]50[.]0"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
