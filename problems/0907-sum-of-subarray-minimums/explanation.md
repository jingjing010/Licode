# 907. 子数组的最小值之和 —— 小白详细题解

> 这道题教你一个非常重要的思维转换：**与其枚举所有子数组，不如问"每个元素对答案贡献了多少"**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把数组所有**连续**的子数组都列出来，每个子数组取它的最小值，把这些最小值加起来（最后对 10⁹+7 取模）。

示例 1 `arr = [3,1,2,4]`：

| 子数组 | 最小值 |
|---|---|
| [3] | 3 |
| [1] | 1 |
| [2] | 2 |
| [4] | 4 |
| [3,1] | 1 |
| [1,2] | 1 |
| [2,4] | 2 |
| [3,1,2] | 1 |
| [1,2,4] | 1 |
| [3,1,2,4] | 1 |
| **合计** | **17** |

**几个需要注意的细节：**

1. 长度为 n 的数组有 n(n+1)/2 个子数组，n = 3×10⁴ 时约 4.5×10⁸ 个，逐个枚举会超时。
2. 答案可能超过 `int`，中间计算要用 `long long` 并且**随时取模**。
3. 数组里可能有**相等的元素**，按"贡献"计算时要小心重复计数（后面详细讲）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 取模与 `long long`

```c
const long long MOD = 1000000007LL;
long long ans = 0;
ans = (ans + x) % MOD;            // 每加一次就取模，防止越界
```

`int` 最大约 2.1×10⁹。`arr[i] × 左边个数 × 右边个数` 最大约 3×10⁴ × 3×10⁴ × 3×10⁴ = 2.7×10¹³，必须用 `long long`（最大约 9.2×10¹⁸）。

### 2. 乘法前先转成 `long long`

```c
long long a = arr[i] * cnt;              // ❌ 先按 int 相乘，已经溢出了，再转也没用
long long b = (long long)arr[i] * cnt;   // ✅ 先把一个数转成 long long，再相乘
```

### 3. 单调栈（存下标）

```c
int* st = (int*)malloc(sizeof(int) * n);
int top = 0;
while (top > 0 && arr[st[top - 1]] >= arr[i]) top--;   // 弹出所有 >= arr[i] 的
st[top++] = i;
```

## 💡 第三步：思路一 —— 暴力枚举（会超时，用来理解）

固定左端点 i，向右扩展右端点 j，一边扩展一边维护最小值：

```c
// ❌ O(n²)：n = 3×10^4 时约 4.5×10^8 次循环，在本题时限下有超时风险
int sumSubarrayMins(int* arr, int arrSize) {
    long long ans = 0;
    for (int i = 0; i < arrSize; i++) {
        int mn = arr[i];
        for (int j = i; j < arrSize; j++) {
            if (arr[j] < mn) mn = arr[j];   // [i..j] 的最小值
            ans += mn;
        }
        ans %= 1000000007;
    }
    return (int)ans;
}
```

这个代码本身是对的，适合 n 很小时对拍；但数据大时太慢，我们需要换个思路。

---

## 🚀 第四步：思路二 —— 计算每个元素的贡献 + 单调栈

### 思路

换个问法：**`arr[i]` 是多少个子数组的最小值？** 如果答案是 `cnt[i]`，那么

\[ \text{答案} = \sum_i arr[i] \times cnt[i] \]

`arr[i]` 是子数组 `[l..r]` 的最小值，需要：
- 子数组包含 i：`l <= i <= r`；
- 子数组里没有比 `arr[i]` 更小的数。

设 `L` = i 左边**第一个比 arr[i] 小**的位置（没有就是 -1），`R` = i 右边**第一个 ≤ arr[i]** 的位置（没有就是 n）。
那么 l 可以取 `L+1 .. i`，共 `i - L` 种；r 可以取 `i .. R-1`，共 `R - i` 种。

\[ cnt[i] = (i - L) \times (R - i) \]

### ❓ 为什么一边是 `<`，一边是 `≤`？

看 `[2,2]`：子数组 `[2]`、`[2]`、`[2,2]`，答案 6。`[2,2]` 的最小值"是哪个 2"？只能算一次！

- 如果两边都用 `<`：两个 2 都认为自己是 `[2,2]` 的最小值，算了两次 → 8 ❌
- 如果两边都用 `≤`：两个 2 都不认为自己是 `[2,2]` 的最小值 → 4 ❌
- 一边 `<`、一边 `≤`：规定"相等时算**最左边**那个"，不重不漏 → 6 ✅

### 手动模拟（示例 1：`[3,1,2,4]`）

| i | arr[i] | L（左边第一个 <） | R（右边第一个 ≤） | (i-L) × (R-i) | 贡献 |
|---|---|---|---|---|---|
| 0 | 3 | -1 | 1 | 1 × 1 = 1 | 3 |
| 1 | 1 | -1 | 4 | 2 × 3 = 6 | 6 |
| 2 | 2 | 1 | 4 | 1 × 2 = 2 | 4 |
| 3 | 4 | 2 | 4 | 1 × 1 = 1 | 4 |

合计 3 + 6 + 4 + 4 = **17** ✅

### 怎么用单调栈求 L？

从左往右扫，栈里保持**值递增**。处理 i 时，把所有 `>= arr[i]` 的栈顶弹掉，剩下的栈顶就是"左边第一个 < arr[i]"的位置。

| i | arr[i] | 弹出 | L[i] | 栈（下标，底→顶） |
|---|---|---|---|---|
| 0 | 3 | | -1 | 0 |
| 1 | 1 | 0 | -1 | 1 |
| 2 | 2 | | 1 | 1 2 |
| 3 | 4 | | 2 | 1 2 3 |

求 R 就是从右往左扫，弹掉所有 `> arr[i]` 的。

### 代码

```c
int sumSubarrayMins(int* arr, int arrSize) {
    const long long MOD = 1000000007LL;
    int n = arrSize;
    int* left = (int*)malloc(sizeof(int) * n);    // left[i]：左边第一个 < arr[i] 的下标
    int* right = (int*)malloc(sizeof(int) * n);   // right[i]：右边第一个 <= arr[i] 的下标
    int* st = (int*)malloc(sizeof(int) * n);      // 单调栈（存下标）
    int top = 0;

    // 1. 从左往右：弹掉 >= arr[i] 的，剩下的栈顶就是左边第一个更小的
    for (int i = 0; i < n; i++) {
        while (top > 0 && arr[st[top - 1]] >= arr[i]) top--;
        left[i] = (top > 0) ? st[top - 1] : -1;
        st[top++] = i;
    }

    // 2. 从右往左：弹掉 > arr[i] 的，剩下的栈顶就是右边第一个 <= 的
    top = 0;
    for (int i = n - 1; i >= 0; i--) {
        while (top > 0 && arr[st[top - 1]] > arr[i]) top--;
        right[i] = (top > 0) ? st[top - 1] : n;
        st[top++] = i;
    }

    // 3. 累加贡献 arr[i] * (i - left) * (right - i)
    long long ans = 0;
    for (int i = 0; i < n; i++) {
        long long cnt = (long long)(i - left[i]) * (right[i] - i);   // 以 arr[i] 为最小值的子数组个数
        ans = (ans + arr[i] * cnt) % MOD;                            // cnt 已是 long long，乘法不会溢出
    }

    free(left);
    free(right);
    free(st);
    return (int)ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：两次单调栈扫描，每个下标进出栈各一次。
- **空间复杂度 O(n)**：`left`、`right`、`st` 三个数组。

---

## ⚠️ 第五步：小白常见错误

1. **两边都用 `<` 或都用 `≤`** → 相等元素被重复计数或漏算，`[2,2]` 会得到 8 或 4，正确是 6。
2. **`int` 溢出** → `arr[i] * (i - L) * (R - i)` 可达 2.7×10¹³，必须用 `long long`，而且要在乘法**之前**转换。
3. **最后才取模** → `ans` 一直累加，可能超过 `long long`。每次累加后都 `% MOD`。
4. **L、R 的默认值写错** → 左边没有更小的元素时 L 应该是 **-1**，右边没有时 R 应该是 **n**，不是 0。
5. **第二次扫描前忘了 `top = 0`** → 栈里还残留着第一次扫描的内容，R 全部算错。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 暴力枚举 | O(n²) | O(1) | ⭐ | 只适合小数据/对拍 |
| 贡献法 + 单调栈 | O(n) | O(n) | ⭐⭐⭐ | 标准解法 |
