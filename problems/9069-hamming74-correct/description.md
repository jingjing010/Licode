# Hamming(7,4) 单比特纠错

采用9068题的位布局，保证合法码字传输中至多翻转1位。输入0到127，返回原始4位数据。此编码不能可靠纠正两位错误。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int hamming74Decode(int word);
```

## 示例 1

输入：
```text
0
```
输出：
```text
0
```

## 示例 2

输入：
```text
1
```
输出：
```text
0
```

## 自定义输入格式

按顺序每行一个参数：word。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
