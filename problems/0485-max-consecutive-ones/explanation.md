# 485. 最大连续 1 的个数 —— 小白详细题解

> 最基础的"一遍扫描 + 计数器"题。把它写熟，以后遇到"最长连续××"都能套用。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 数组里只有 0 和 1。把被 0 隔开的每一段 1 数一数有多长，返回最长的那一段的长度。

示例 1：`nums = [1,1,0,1,1,1]`

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 数值 | 1 | 1 | 0 | 1 | 1 | 1 |
| 分段 | 第 1 段 | 第 1 段 | 分隔 | 第 2 段 | 第 2 段 | 第 2 段 |

第 1 段长 2，第 2 段长 3，答案是 `3`。

**几个需要注意的细节：**

1. 数组可能**全是 0**，答案是 0。
2. 最长的一段可能在**数组末尾**（如示例 1），循环结束后不要漏算。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 三目运算符 `?:`

```c
cnt = (nums[i] == 1) ? cnt + 1 : 0;
// 等价于：
// if (nums[i] == 1) cnt = cnt + 1; else cnt = 0;
```

### 2. 打擂台求最大值

```c
if (cnt > ans) ans = cnt;    // 新的值比当前最大值大，就替换
```

---

## 💡 第三步：思路一 —— 一遍扫描 + 计数器

### 思路

- `cnt`：**当前这一段**连续 1 的个数；
- `ans`：目前见过的最长一段。

遇到 1，`cnt++`，并用 `cnt` 更新 `ans`；遇到 0，`cnt` 清零。

> 💡 每次 `cnt` 加 1 后**立刻**更新 `ans`，这样即使数组以 1 结尾，也不会漏掉最后一段。

### 手动模拟（示例 2：`nums = [1,0,1,1,0,1]`）

| i | nums[i] | cnt | ans |
|---|---|---|---|
| 0 | 1 | 1 | 1 |
| 1 | 0 | 0 | 1 |
| 2 | 1 | 1 | 1 |
| 3 | 1 | 2 | 2 |
| 4 | 0 | 0 | 2 |
| 5 | 1 | 1 | 2 |

答案 `2`。

### 代码

```c
int findMaxConsecutiveOnes(int* nums, int numsSize) {
    int ans = 0;                    // 最长的一段
    int cnt = 0;                    // 当前这一段的长度
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] == 1) {
            cnt++;                  // 连续 1 又多了一个
            if (cnt > ans) {
                ans = cnt;          // 立刻更新最大值
            }
        } else {
            cnt = 0;                // 遇到 0，这一段断了，重新开始数
        }
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：只扫描一遍。
- **空间复杂度 O(1)**：只用了两个变量。

---

## 🚀 第四步：思路二 —— 记录"上一个 0 的位置"

### 思路

换个角度：如果知道**上一个 0 出现在下标 `lastZero`**，那么以 `i` 结尾的这段连续 1 的长度就是 `i - lastZero`。

- 一开始假设下标 `-1` 处有一个 0（`lastZero = -1`），这样从头开始的 1 也能正确计算；
- 遇到 0，就更新 `lastZero = i`；
- 遇到 1，长度是 `i - lastZero`，用它更新答案。

这个"记录边界位置、用下标差算长度"的写法，在很多**滑动窗口**题里都会用到。

### 手动模拟（示例 1：`nums = [1,1,0,1,1,1]`）

| i | nums[i] | lastZero | i - lastZero | ans |
|---|---|---|---|---|
| 0 | 1 | -1 | 1 | 1 |
| 1 | 1 | -1 | 2 | 2 |
| 2 | 0 | 2 | — | 2 |
| 3 | 1 | 2 | 1 | 2 |
| 4 | 1 | 2 | 2 | 2 |
| 5 | 1 | 2 | 3 | 3 |

### 代码

```c
int findMaxConsecutiveOnes(int* nums, int numsSize) {
    int ans = 0;
    int lastZero = -1;              // 假想在下标 -1 处有一个 0
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] == 0) {
            lastZero = i;           // 记录最近一个 0 的位置
        } else if (i - lastZero > ans) {
            ans = i - lastZero;     // 以 i 结尾的连续 1 的长度
        }
    }
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**；**空间复杂度 O(1)**。和思路一同样高效，只是换了一种计数方式。

---

## ⚠️ 第五步：小白常见错误

1. **只在遇到 0 时才更新答案** → 数组以 1 结尾时（示例 1），最后一段没被统计，返回 2。
2. **遇到 0 时忘记把 `cnt` 清零** → 统计的变成了"1 的总个数"，示例 2 会返回 4。
3. **`ans` 初始化为 1** → 全是 0 的数组应返回 0。
4. **思路二 `lastZero` 初值写成 0** → 从下标 0 开始的连续 1 会被少算一个。

---

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 说明 |
|---|---|---|---|---|
| 计数器 | O(n) | O(1) | ⭐ | 最直观 |
| 记录上一个 0 | O(n) | O(1) | ⭐ | 用下标差算长度，为滑动窗口打基础 |
