# 367. 有效的完全平方数 —— 小白详细题解

> 和 69. x 的平方根 几乎一样，都是**二分查找**的入门练习。区别是这里要找"恰好等于"，而不是"不超过"。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 判断 num 能不能写成 `k × k`（k 是整数）。

| num | 能否写成 k × k | 结果 |
|---|---|---|
| 16 | 4 × 4 | ✅ |
| 14 | 3 × 3 = 9，4 × 4 = 16，夹在中间 | ❌ |
| 1 | 1 × 1 | ✅ |
| 2147483647 | 46340² = 2147395600 < num < 46341² | ❌ |

**几个需要注意的细节：**

1. 不能用 `sqrt`。
2. `num` 最大是 `2^31 - 1`，而 `46341 × 46341` 已经超过 `int` 上限——计算平方时要防止溢出。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 乘法溢出与 `long long`

```c
int k = 50000;
long long a = k * k;              // ❌ k * k 先按 int 算，已经溢出，再转 long long 也没用
long long b = (long long)k * k;   // ✅ 先把 k 转成 long long 再乘
```

### 2. 二分查找模板

```c
int lo = 1, hi = num;
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;   // 不写 (lo + hi) / 2，避免 lo + hi 溢出
    // 根据 mid 的情况，把区间缩小一半
}
```

---

## 💡 第三步：思路一 —— 从 1 开始逐个尝试

### 思路

`k` 从 1 开始，只要 `k * k < num` 就让 `k` 加 1。停下来时检查 `k * k == num`。

最多试到约 46341，完全不会超时。

### 手动模拟（`num = 14`）

| k | k × k | 和 14 比较 |
|---|---|---|
| 1 | 1 | 小于，继续 |
| 2 | 4 | 小于，继续 |
| 3 | 9 | 小于，继续 |
| 4 | 16 | 不小于，停 → 16 ≠ 14 → `false` |

### 代码

```c
bool isPerfectSquare(int num) {
    long long k = 1;                  // 用 long long，k * k 不会溢出
    while (k * k < num) {             // 平方还比 num 小，就继续增大 k
        k++;
    }
    return k * k == num;              // 停下时 k*k >= num，看是否恰好相等
}
```

### 复杂度分析

- **时间复杂度 O(√num)**：最多约 46341 次。
- **空间复杂度 O(1)**。

---

## 🚀 第四步：思路二 —— 二分查找

### 思路

在 `[1, num]` 中二分查找 `k`：

- `mid * mid == num`：找到了，返回 `true`；
- `mid * mid < num`：`mid` 太小，去右半边；
- `mid * mid > num`：`mid` 太大，去左半边。

区间为空还没找到，就返回 `false`。

### 手动模拟（`num = 16`）

| lo | hi | mid | mid² | 比较 | 操作 |
|---|---|---|---|---|---|
| 1 | 16 | 8 | 64 | > 16 | hi = 7 |
| 1 | 7 | 4 | 16 | == 16 | 返回 true |

### 代码

```c
bool isPerfectSquare(int num) {
    int lo = 1, hi = num;                    // k 一定在 [1, num] 中
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;        // 防溢出的中点
        long long sq = (long long)mid * mid; // 防溢出的平方
        if (sq == num) {
            return true;                     // 恰好相等，是完全平方数
        } else if (sq < num) {
            lo = mid + 1;                    // 平方太小，往右找
        } else {
            hi = mid - 1;                    // 平方太大，往左找
        }
    }
    return false;                            // 找遍了也没有
}
```

### 复杂度分析

- **时间复杂度 O(log num)**：最多约 31 次。
- **空间复杂度 O(1)**。

## 🚀 第五步：思路三 —— 奇数之和（数学拓展）

一个有趣的规律：`1 = 1`，`4 = 1 + 3`，`9 = 1 + 3 + 5`，`16 = 1 + 3 + 5 + 7`……

**完全平方数 = 从 1 开始的连续奇数之和**。所以可以不断从 `num` 里减去 1、3、5、7……，恰好减到 0 就是完全平方数。

```c
bool isPerfectSquare(int num) {
    int odd = 1;                     // 当前要减的奇数
    while (num > 0) {
        num -= odd;                  // 依次减去 1, 3, 5, 7
        odd += 2;
    }
    return num == 0;                 // 恰好减到 0 说明是完全平方数
}
```

- **时间复杂度 O(√num)**。不涉及乘法，所以完全没有溢出问题。

---

## ⚠️ 第六步：小白常见错误

1. **`mid * mid` 用 `int` 计算** → `num` 很大时 `mid` 约为 10 亿，平方严重溢出，二分方向错误。
2. **`long long sq = mid * mid;`** → 乘法已经按 `int` 溢出，再赋给 `long long` 也救不回来。
3. **`int k` 写逐个尝试的循环** → `k * k < num` 在 `k = 46341` 时溢出变成负数，会继续循环，最终出错。
4. **`(int)sqrt(num) * (int)sqrt(num) == num`** → 题目不允许；且浮点误差有时会让结果偏小 1。
5. **二分时写 `lo = mid` 或 `hi = mid`** → 可能导致区间不缩小，陷入死循环。用 `mid + 1` 和 `mid - 1`。

---

## 📊 第七步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 建议 |
|---|---|---|---|
| 逐个尝试 | O(√n) | O(1) | 最直观 |
| 二分查找 | O(log n) | O(1) | 标准答案 |
| 奇数之和 | O(√n) | O(1) | 有趣的数学拓展 |
