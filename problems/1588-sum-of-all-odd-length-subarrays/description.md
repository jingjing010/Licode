# 所有奇数长度子数组的和

返回所有长度为奇数的连续子数组的元素总和之和。1 ≤ n ≤ 100，元素1到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int sumOddLengthSubarrays(int* arr,int arrSize);
```

## 示例 1

输入：
```text
[1,4,2,5,3]
```
输出：
```text
58
```

## 示例 2

输入：
```text
[1,2]
```
输出：
```text
3
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
