# 数组中两元素的最大乘积

从两个不同下标i,j中最大化(nums[i]−1)*(nums[j]−1)。2 ≤ n ≤ 500，元素1到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int maxProduct(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[3,4,5,2]
```
输出：
```text
12
```

## 示例 2

输入：
```text
[1,5,4,5]
```
输出：
```text
16
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
