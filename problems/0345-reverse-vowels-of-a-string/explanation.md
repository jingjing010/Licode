# 反转字符串中的元音字母：题解

## 📖 先读懂题目

两个指针分别从左右寻找元音，交换后继续向内移动。判断元音包含大小写AEIOUaeiou，非元音字符的原位置不变。

### 示例1

输入：
```text
"IceCreAm"
```
输出：
```text
"AceCreIm"
```

### 示例2

输入：
```text
"leetcode"
```
输出：
```text
"leotcede"
```


## 🧰 C 语言知识

数组参数传入的是指针，长度单独传递。字符串结尾的`'\0'`不是普通数据，动态结果必须多留一个字节。链表通过`next`连接，断开或拼接前要确定后继仍可找到。返回数组时同时设置`*returnSize`。

## 💡 解题步骤

1. 先写一个辅助函数判断字符是不是元音，注意大写的 'A'、'E'、'I'、'O'、'U' 也算。
2. 可以把所有元音的下标按顺序记下来，然后把这些位置上的字符首尾互换。
3. 更省空间的做法：左右两个指针，左边找到一个元音、右边找到一个元音就交换，然后继续向中间走。

## 可直接提交的 C 代码

```c
static bool isVowel(char c) {
    return strchr("aeiouAEIOU", c) != NULL && c != '\0';
}

char* reverseVowels(char* s) {
    int l = 0, r = (int)strlen(s) - 1;
    while (l < r) {
        while (l < r && !isVowel(s[l])) l++;
        while (l < r && !isVowel(s[r])) r--;
        if (l < r) {
            char t = s[l];
            s[l] = s[r];
            s[r] = t;
            l++;
            r--;
        }
    }
    return s;
}
```

## 📊 复杂度

时间 O(n)，额外空间取决于是否复制字符串。先用题面样例逐步跟踪变量，再检查最短输入与重复值，不应仅凭一个正常样例判断算法正确。

## ⚠️ 常见错误

- 把数组边界`i < n`误写成`i <= n`。
- 忘记返回数组的有效长度，或字符串结尾缺少`'\0'`。
- 把题目中的严格比较写成允许相等，或把有重数的元素当作集合。
- 返回局部数组地址，函数退出后该内存不再有效。

## 🔗 举一反三

改变输入长度为1、重复值、边界整数，手工验证每一步保存的状态。思考能否在输入逐个到达时保留相同的状态完成计算。
