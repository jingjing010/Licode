# 整数均方根测量

返回floor(sqrt(sum(x²)/n))。输入为int16采样，1≤n≤1000，不使用浮点输出。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int integerRms(int* samples,int samplesSize);
```

## 示例 1

输入：
```text
[3,4]
```
输出：
```text
3
```

## 示例 2

输入：
```text
[32767,-32768]
```
输出：
```text
32767
```

## 自定义输入格式

按顺序每行一个参数：samples。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
