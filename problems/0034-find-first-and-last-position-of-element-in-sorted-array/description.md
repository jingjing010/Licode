给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

### 示例 1

```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

### 示例 2

```
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

### 示例 3

```
输入：nums = [], target = 0
输出：[-1,-1]
```

### 提示

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是一个非递减数组
- `-10^9 <= target <= 10^9`

### 函数说明

```c
int* searchRange(int* nums, int numsSize, int target, int* returnSize);
```

- `nums`：非递减数组首地址，`numsSize`：数组长度（可能为 0）
- 返回值：用 `malloc` 申请的长度为 2 的数组，`[开始位置, 结束位置]`，不存在时为 `[-1,-1]`
- `*returnSize`：必须设置为 2

### 自定义输入格式

```
[5,7,7,8,8,10]
8
```

第 1 行是数组 `nums`（空数组写作 `[]`），第 2 行是 `target`。
