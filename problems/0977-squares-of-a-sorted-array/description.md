# 有序数组的平方

输入为非递减数组，返回所有元素平方后按非递减排序的数组。1 ≤ n ≤ 10^4，|元素| ≤ 10^4。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* sortedSquares(int* nums,int numsSize,int* returnSize);
```

## 示例 1

输入：
```text
[-4,-1,0,3,10]
```
输出：
```text
[0,1,9,16,100]
```

## 示例 2

输入：
```text
[-7,-3,2,3,11]
```
输出：
```text
[4,9,9,49,121]
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
