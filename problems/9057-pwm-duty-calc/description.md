用 STM32 之类 MCU 的通用定时器输出 PWM（控制 LED 亮度、电机转速、舵机角度）时，需要配置三个寄存器：

- **PSC（预分频器）**：定时器时钟 `clk` 先经过 `PSC + 1` 分频，计数器每秒计数 `clk / (PSC + 1)` 次。
- **ARR（自动重装载值）**：计数器从 `0` 数到 `ARR` 后归零，一个 PWM 周期共计数 `ARR + 1` 次。所以 PWM 频率 = `clk / ((PSC + 1) × (ARR + 1))`。
- **CCR（比较值）**：PWM 模式 1 下，计数值 `< CCR` 时输出高电平，否则输出低电平。所以占空比 = `CCR / (ARR + 1)`。

给你定时器时钟 `clk`（Hz）、已经选好的预分频值 `psc`、目标 PWM 频率 `freq`（Hz）和目标占空比 `duty`（百分数，`0 ~ 100` 的整数），请按下面的**精确公式**计算 `ARR` 和 `CCR`：

1. 周期计数 `N = round(clk / ((psc + 1) × freq))`，然后 `ARR = N - 1`。
2. `CCR = round(N × duty / 100)`。

其中 `round(x)` 为**四舍五入**：小数部分 `>= 0.5` 时进位（本题所有量均非负）。

（`duty = 100` 时 `CCR = ARR + 1`，计数值始终小于 CCR，输出恒为高电平；`duty = 0` 时 `CCR = 0`，输出恒为低电平。）

### 示例 1

```
输入：clk = 72000000, psc = 71, freq = 1000, duty = 25
输出：[999,250]
解释：计数频率 72MHz / 72 = 1MHz，N = 1000000 / 1000 = 1000，ARR = 999；CCR = 1000 × 25% = 250。
```

### 示例 2

```
输入：clk = 84000000, psc = 0, freq = 30000, duty = 33
输出：[2799,924]
解释：N = 84000000 / 30000 = 2800，ARR = 2799；CCR = 2800 × 0.33 = 924。
```

### 示例 3

```
输入：clk = 16000000, psc = 15, freq = 3000, duty = 50
输出：[332,167]
解释：计数频率 1MHz，1000000 / 3000 = 333.33，四舍五入 N = 333，ARR = 332；
     CCR = 333 × 0.5 = 166.5，四舍五入为 167。
```

### 提示

- `1 <= clk <= 5 × 10^8`
- `0 <= psc <= 65535`
- `1 <= freq <= clk`
- `0 <= duty <= 100`
- 保证 `1 <= N <= 65536`（ARR 在 16 位寄存器范围 `0 ~ 65535` 内）

### 函数说明

```c
void pwmCalc(uint32_t clk, uint32_t psc, uint32_t freq, uint32_t duty, uint32_t* arr, uint32_t* ccr);
```

- 结果通过指针参数输出：`*arr = ARR`，`*ccr = CCR`

### 自定义输入格式

```
72000000
71
1000
25
```

4 行依次是 `clk`、`psc`、`freq`、`duty`。输出 `[ARR,CCR]`。
