# 分发饼干：题解

## 📖 先读懂题目

孩子胃口为g，饼干大小为s，一块饼干只能分给一个孩子且必须不小于胃口。返回最多满足人数。1 ≤ g长度 ≤ 3*10^4，0 ≤ s长度 ≤ 3*10^4，值为正整数。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `[1,2,3] / [1,1]` | `1` |
| 2 | `[1,2] / [1,2,3]` | `2` |

## 🧰 需要的 C 语言知识

数组形参是指针，不能用`sizeof(指针)`推算元素个数，要使用单独传入的长度。下标从0开始，最后一个有效下标是长度减1。

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

排序后从胃口最小的孩子开始，用刚好够大的饼干满足他，较大的饼干留给后面的孩子。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
static int cmp(const void *a, const void *b) {
    int x = *(const int *)a, y = *(const int *)b;
    return (x > y) - (x < y);
}
int findContentChildren(int *g, int gSize, int *s, int sSize) {
    qsort(g, gSize, sizeof(int), cmp);
    qsort(s, sSize, sizeof(int), cmp);
    int child = 0;
    /* 每次用最小可用饼干满足最小胃口。 */
    for (int i = 0; i < sSize && child < gSize; ++i)
        if (s[i] >= g[child])
            ++child;
    return child;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n log n+m log m)，排序栈空间 O(log(n+m)) | 正式提交 |

## ⚠️ 常见错误

- 循环写成`i <= 长度`，访问数组末尾之后的内存。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
