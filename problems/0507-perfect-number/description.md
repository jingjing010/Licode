# 完美数

正整数 num 的所有正因子（不含自身）之和等于 num 时称为完美数。判断给定 num 是否满足，num ≤ 10^8。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool checkPerfectNumber(int num);
```

## 示例 1

输入：
```text
28
```
输出：
```text
true
```

## 示例 2

输入：
```text
7
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：n。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
