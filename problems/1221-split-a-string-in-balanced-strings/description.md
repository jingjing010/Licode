# 分割平衡字符串

输入仅含L、R且数量相等的非空字符串，最大化分割段数，使每段L与R数量也相等。长度2到1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int balancedStringSplit(char* s);
```

## 示例 1

输入：
```text
"RLRRLLRLRL"
```
输出：
```text
4
```

## 示例 2

输入：
```text
"RLLLLRRRLR"
```
输出：
```text
3
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
