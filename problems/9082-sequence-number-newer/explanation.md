# 16位序列号的新旧判定：题解

## 📖 先读懂题目

循环序列号范围0..65535。定义候选号相对参考号的模差在1..32767时为更新，其他情况返回false，尤其差32768返回false。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `1 / 65535` | `true` |
| 2 | `65535 / 1` | `false` |

## 🧰 需要的 C 语言知识

整数除法会向零截断。乘法中间结果可能大于最终答案，要在乘法发生之前转换为更宽的整数类型。布尔函数使用`true`与`false`表达判断结果。

## 💡 推导与实现

计算模2^16距离，距离在1到32767时认为更新，距离0相等，半圈处不能确定更新。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
bool sequenceNewer(int candidate, int reference) {
    uint16_t distance = (uint16_t)((unsigned)candidate - (unsigned)reference);
    return distance != 0 && distance < 0x8000u;
}
```

## ⚠️ 常见错误

- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
- 修改函数签名或参数顺序，导致判题驱动无法正确调用。
