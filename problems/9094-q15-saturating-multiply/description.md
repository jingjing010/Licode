# Q15 饱和乘法

输入为Q15原始int16整数，返回trunc(a*b/32768)并限制在−32768..32767，负数向零截断。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int q15Multiply(int a,int b);
```

## 示例 1

输入：
```text
16384
16384
```
输出：
```text
8192
```

## 示例 2

输入：
```text
-32768
-32768
```
输出：
```text
32767
```

## 自定义输入格式

按顺序每行一个参数：a、b。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
