# Modbus 写单寄存器请求：题解

## 📖 先读懂题目

构造Modbus RTU功能码06请求。站号1..247，寄存器地址和值0..65535。返回完整8字节帧。CRC多项式反射常数0xA001，初值0xFFFF，无最终异或。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `1 / 1 / 3` | `[1,6,0,1,0,3,152,11]` |
| 2 | `17 / 1 / 3` | `[17,6,0,1,0,3,154,155]` |

## 🧰 需要的 C 语言知识

返回数组需要申请独立内存，并把有效元素数写入`*returnSize`。调用方释放结果，因此不能返回函数内的局部数组。输入数组长度与输出长度不一定相同。

## 💡 推导与实现

顺序组装站号、功能码06、寄存器地址和值，两个16位字段高字节先发，最后追加CRC16/MODBUS低字节与高字节。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
int *modbusWriteSingle(int address, int reg, int value, int *returnSize) {
    int *out = malloc(8 * sizeof(int));
    out[0] = address;
    out[1] = 6;
    out[2] = reg >> 8;
    out[3] = reg & 255;
    out[4] = value >> 8;
    out[5] = value & 255;
    uint16_t crc = 0xffff;
    for (int i = 0; i < 6; ++i) {
        crc ^= (uint16_t)out[i];
        for (int b = 0; b < 8; ++b)
            crc = (crc & 1) ? (crc >> 1) ^ 0xa001 : crc >> 1;
    }
    /* 寄存器字段为大端，CRC在线上却是低字节先发。 */
    out[6] = crc & 255;
    out[7] = crc >> 8;
    *returnSize = 8;
    return out;
}
```

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(1)，输出空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 只返回指针却忘记设置`*returnSize`，平台无法知道输出多少元素。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。
- 直接复制main函数或打印调试信息，导致与平台自动生成的输入输出冲突。
