**绝对值编码器**（例如电机、机械臂关节上的角度传感器）通过一组光栅或磁极直接输出当前位置的编号。如果用普通二进制编码，位置从 `7`（`0111`）走到 `8`（`1000`）时 4 个位要同时翻转，而机械和电路不可能做到绝对同步，读数的瞬间可能读到 `1111`、`0000` 等完全错误的值。

因此编码器普遍输出 **格雷码**（Gray code）：相邻两个位置的编码 **只有一位不同**，任何时刻读到的值最多差一格。二进制数 `b` 对应的格雷码为：

```
g = b ^ (b >> 1)
```

单片机读到格雷码后，需要把它 **还原成普通二进制** 才能计算角度、速度。给定编码器输出的 32 位格雷码 `gray`，请返回它对应的二进制数 `b`（即满足 `b ^ (b >> 1) == gray` 的唯一的 `b`）。

### 示例 1

```
输入：gray = 6
输出：4
解释：6 = 0b110。二进制 4 = 0b100 的格雷码是 0b100 ^ 0b010 = 0b110，所以答案是 4。
```

### 示例 2

```
输入：gray = 3
输出：2
解释：3 = 0b11。二进制 2 = 0b10 的格雷码是 0b10 ^ 0b01 = 0b11。
```

### 示例 3

```
输入：gray = 2147483648
输出：4294967295
解释：格雷码 0x80000000 对应二进制 0xFFFFFFFF：0xFFFFFFFF ^ 0x7FFFFFFF = 0x80000000。
```

### 提示

- `0 <= gray <= 2^32 - 1`

### 函数说明

```c
uint32_t gray_to_binary(uint32_t gray);
```

- `gray`：编码器输出的格雷码
- 返回值：对应的普通二进制数

### 自定义输入格式

```
6
```

输入一行，为十进制整数 `gray`。输出为解码后的二进制数（十进制）。
