颠倒给定的 32 位无符号整数的二进制位。

### 示例 1

```
输入：n = 43261596
输出：964176192
解释：
43261596  的二进制表示为 00000010100101000001111010011100 ，
964176192 的二进制表示为 00111001011110000010100101000000 ，
后者正是前者的二进制位颠倒过来的结果。
```

### 示例 2

```
输入：n = 4294967293
输出：3221225471
解释：
4294967293 的二进制表示为 11111111111111111111111111111101 ，
3221225471 的二进制表示为 10111111111111111111111111111111 。
```

### 提示

- 输入是一个长度为 `32` 的二进制串所表示的无符号整数，即 `0 <= n <= 2^32 - 1`

**进阶**：如果多次调用这个函数，你将如何优化你的算法？

### 函数说明

```c
uint32_t reverseBits(uint32_t n);
```

- `n`：32 位无符号整数
- 返回值：二进制位颠倒后的 32 位无符号整数

### 自定义输入格式

```
43261596
```

输入一行，为十进制整数 `n`；输出为颠倒后的值（十进制）。
