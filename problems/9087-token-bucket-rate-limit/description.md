# 令牌桶请求限速

times是非递减毫秒时间戳（0..10^6）。时刻0有capacity个令牌，此后每interval毫秒补1个，上限capacity。每个请求有令牌则接受并消耗，输出1，否则0。同一时刻依输入顺序处理。容量1..100，interval1..1000，最多1000个请求。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* tokenBucket(int* times,int timesSize,int capacity,int interval,int* returnSize);
```

## 示例 1

输入：
```text
[0,0,0,10,20]
2
10
```
输出：
```text
[1,1,0,1,1]
```

## 示例 2

输入：
```text
[0,1,2,3,4]
1
2
```
输出：
```text
[1,0,1,0,1]
```

## 自定义输入格式

按顺序每行一个参数：times、capacity、interval。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
