# 438. 找到字符串中所有字母异位词 —— 小白详细题解

> 这道题是**定长滑动窗口**的模板题：窗口大小固定为 `p` 的长度，每次右移一格，只有"一进一出"两个字母发生变化。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 在 `s` 里找所有长度等于 `p` 的连续片段，如果这个片段**打乱顺序后能变成 `p`**，就记下它的起始位置。

"打乱顺序后相同"等价于：**每个字母出现的次数完全一样**。

示例 1：`s = "cbaebabacd"`，`p = "abc"`（长度 3）：

| 起点 | 子串 | 字母次数 | 是异位词？ |
|---|---|---|---|
| 0 | cba | a1 b1 c1 | ✅ |
| 1 | bae | a1 b1 e1 | ❌ |
| 2 | aeb | a1 b1 e1 | ❌ |
| 3 | eba | a1 b1 e1 | ❌ |
| 4 | bab | a1 b2 | ❌ |
| 5 | aba | a2 b1 | ❌ |
| 6 | bac | a1 b1 c1 | ✅ |
| 7 | acd | a1 c1 d1 | ❌ |

答案 `[0,6]`。

**几个需要注意的细节：**

1. 如果 `p` 比 `s` 还长，一个答案都没有，返回空数组（`*returnSize = 0`）。
2. 答案可能非常多（例如 `s = "aaaa..."`、`p = "a"`），返回数组要开够 `n` 个。
3. 判断异位词**不需要排序**，统计 26 个字母的次数就行。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 用 `c - 'a'` 把字母变成 0~25

```c
int cnt[26] = {0};
cnt[s[i] - 'a']++;      // 'a' → 0, 'b' → 1, ..., 'z' → 25
```

### 2. 比较两个数组是否完全相同

C 语言不能用 `==` 比较两个数组（那样比的是地址）。可以写循环，或者用 `memcmp`：

```c
memcmp(a, b, sizeof(a)) == 0     // a、b 两段内存的每个字节都相同
```

### 3. 返回数组 + `*returnSize`

和"两数之和"一样：返回数组要 `malloc`，长度写进 `*returnSize`。

---

## 💡 第三步：思路一 —— 定长滑动窗口 + 比较计数数组

### 思路

最笨的做法是对每个起点都重新数一遍 `m` 个字母，O(n × m)。但相邻两个窗口只差两个字母：

```
窗口 [i-m+1 .. i]  →  窗口 [i-m+2 .. i+1]
     去掉 s[i-m+1]，加上 s[i+1]
```

所以维护一个窗口计数 `win[26]`，每右移一格只改两个位置，再和 `p` 的计数 `need[26]` 比较（26 次）。

### 手动模拟（示例 2：`s = "abab"`, `p = "ab"`，`need = {a:1, b:1}`）

| i | 进 | 出 | 窗口 | win | 相等？ | 记录 |
|---|---|---|---|---|---|---|
| 0 | a | - | a | a1 | 窗口不满 | |
| 1 | b | - | ab | a1 b1 | ✅ | 0 |
| 2 | a | a | ba | a1 b1 | ✅ | 1 |
| 3 | b | b | ab | a1 b1 | ✅ | 2 |

### 代码

```c
int* findAnagrams(char* s, char* p, int* returnSize) {
    int n = strlen(s), m = strlen(p);
    int* res = (int*)malloc(sizeof(int) * (n + 1));   // 最多 n 个答案
    *returnSize = 0;
    if (m > n) return res;                            // p 更长，不可能有答案

    int need[26] = {0}, win[26] = {0};
    for (int i = 0; i < m; i++) need[p[i] - 'a']++;  // 1. 统计 p 的字母次数

    for (int i = 0; i < n; i++) {
        win[s[i] - 'a']++;                            // 2. 右边进来一个字母
        if (i >= m) win[s[i - m] - 'a']--;            // 3. 窗口超长，左边出去一个字母
        // 4. 窗口长度正好为 m 时，比较计数
        if (i >= m - 1 && memcmp(win, need, sizeof(win)) == 0) {
            res[*returnSize] = i - m + 1;             // 窗口起点
            (*returnSize)++;
        }
    }
    return res;
}
```

### 复杂度分析

- **时间复杂度 O(26 × n)**：每个位置比较一次 26 个计数。
- **空间复杂度 O(26)**（返回数组不算）。

---

## 🚀 第四步：思路二 —— 只维护"有几个字母对不上"

### 思路

每次都比较 26 个数还是有点浪费。改为维护一个差值数组 `diff[c] = 窗口里 c 的次数 - p 里 c 的次数`，再用 `bad` 记录 **`diff` 中不为 0 的字母有几个**。

- `bad == 0` 就说明窗口是异位词。
- 某个字母的 `diff` 改变时：改之前是 0 → `bad++`；改之后变成 0 → `bad--`。

这样每次移动只要 O(1)。

### 代码

```c
int* findAnagrams(char* s, char* p, int* returnSize) {
    int n = strlen(s), m = strlen(p);
    int* res = (int*)malloc(sizeof(int) * (n + 1));
    *returnSize = 0;
    if (m > n) return res;

    // 1. 第一个窗口 s[0..m-1]：diff = 窗口次数 - p 的次数
    int diff[26] = {0};
    for (int i = 0; i < m; i++) {
        diff[s[i] - 'a']++;
        diff[p[i] - 'a']--;
    }
    int bad = 0;                                   // diff 不为 0 的字母个数
    for (int c = 0; c < 26; c++) if (diff[c] != 0) bad++;
    if (bad == 0) res[(*returnSize)++] = 0;

    // 2. 窗口右移：s[i] 进来，s[i-m] 出去
    for (int i = m; i < n; i++) {
        int in = s[i] - 'a', out = s[i - m] - 'a';

        if (diff[in] == 0) bad++;                  // 原来对得上，马上要对不上了
        diff[in]++;
        if (diff[in] == 0) bad--;                  // 改完正好对上

        if (diff[out] == 0) bad++;
        diff[out]--;
        if (diff[out] == 0) bad--;

        if (bad == 0) res[(*returnSize)++] = i - m + 1;
    }
    return res;
}
```

> 💬 `res[(*returnSize)++] = x;` 等价于 `res[*returnSize] = x; (*returnSize)++;`。括号不能省：`*returnSize++` 会先移动指针再取值，完全是另一个意思。

### 复杂度分析

- **时间复杂度 O(n + m + 26)**。
- **空间复杂度 O(26)**。

---

## ⚠️ 第五步：小白常见错误

1. **没处理 `m > n`** → 第一个窗口就越界读 `s` 后面的内存。
2. **返回数组只开了很小的空间** → `s = "aaaa"`, `p = "a"` 时答案有 n 个，开小了就会写越界。
3. **用 `win == need` 比较数组** → 比较的是两个数组的地址，永远不相等。要用循环或 `memcmp`。
4. **把 `(*returnSize)++` 写成 `*returnSize++`** → 运算符优先级问题，`++` 作用在指针上，长度没有增加。
5. **窗口出去的字母下标算错**（写成 `s[i - m + 1]`）→ 窗口长度会变成 m - 1，结果全错。
6. **没答案时忘了设置 `*returnSize = 0`** → 调用者读到一个随机长度。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 每个窗口重新计数 | O(n × m) | O(26) | ⭐ | 思路起点，数据大时较慢 |
| 滑动窗口 + memcmp | O(26n) | O(26) | ⭐⭐ | 推荐，简单不易错 |
| 滑动窗口 + 差异计数 | O(n) | O(26) | ⭐⭐⭐ | 进阶，严格线性 |
