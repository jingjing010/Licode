# 解码字母到整数映射

a到i编码为1到9，j到z编码为10#到26#。给定合法编码，返回解码字符串。长度1到1000。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* freqAlphabets(char* s);
```

## 示例 1

输入：
```text
"10#11#12"
```
输出：
```text
"jkab"
```

## 示例 2

输入：
```text
"1326#"
```
输出：
```text
"acz"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
