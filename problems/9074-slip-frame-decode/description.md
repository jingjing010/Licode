# SLIP 帧转义解码

输入为9073生成的一个完整合法帧，首尾为C0，内部转义有效，不含其他帧。返回原始数据。长度2到2050。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* slipDecode(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[192,49,50,51,52,53,54,55,56,57,192]
```
输出：
```text
[49,50,51,52,53,54,55,56,57]
```

## 示例 2

输入：
```text
[192,192]
```
输出：
```text
[]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
