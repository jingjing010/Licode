# 9036. 实现 strcpy —— 小白详细题解

> `while ((*d++ = *s++) != '\0');` —— 这一行代码几乎出现在每一本 C 语言教材里，也是面试中"手写 strcpy"的标准答案。这道题我们把它拆开、讲透，再聊聊为什么很多公司的编码规范**禁止使用 strcpy**。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 把 `src` 的字符一个一个抄到 `dst`，**连最后的 `'\0'` 也要抄**，然后把 `dst` 原样还回去。

拿示例 1 来说（`src = "hello"`，`dst` 正好 6 字节，事先填满 `'#'`）：

| 偏移 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| src | h | e | l | l | o | `\0` |
| dst（复制前） | # | # | # | # | # | # |
| dst（复制后） | h | e | l | l | o | **`\0`** |

**几个需要注意的细节：**

1. **`'\0'` 必须复制**。如果漏了，`dst[5]` 还是 `'#'`，`dst` 就不是合法字符串，打印时会一路读出界。
2. strcpy **不知道** `dst` 有多大，它假设调用者已经准备好了足够的空间——这正是它危险的地方。
3. 返回值是**原始的 `dst`**，方便链式调用，例如 `printf("%s", strcpy(buf, "hi"))`。
4. 空串也要复制一个 `'\0'`（示例 2）。

---

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 赋值表达式也有值

C 语言里 `a = b` 不只是一条语句，它还是一个**表达式**，值就是赋给 `a` 的那个值。所以可以写：

```c
char c;
if ((c = *s) == '\0') { /* 刚刚赋的值是 '\0' */ }
```

`while ((*d++ = *s++) != '\0');` 就利用了这一点：先复制一个字符，再判断**刚复制的**是不是 `'\0'`——这样 `'\0'` 一定会被复制之后循环才结束。

### 2. `*d++` 的运算顺序

后置 `++` 优先级比 `*` 高，但它"先用旧值，后加 1"：

```c
*d++ = *s++;
// 等价于
*d = *s;
d++;
s++;
```

### 3. 空语句 `;`

`while (...);` 末尾的分号是一个**空的循环体**——所有工作都在条件里做完了。为了可读性，很多规范要求把 `;` 单独放一行，或者写成 `{}`。

### 4. `const char* src`

`src` 只读不写，所以用 `const char*`。这样如果你不小心写成 `*src = ...`，编译器会直接报错。

## 💡 第三步：思路一 —— 下标循环（最朴素）

### 思路

1. `i` 从 0 开始，只要 `src[i]` 不是 `'\0'`，就 `dst[i] = src[i]`，`i++`
2. 循环结束时 `src[i]` 是 `'\0'`，**单独补上** `dst[i] = '\0'`
3. 返回 `dst`

### 手动模拟（`src = "hi"`）

| i | src[i] | 动作 | dst |
|---|---|---|---|
| 0 | h | dst[0] = h | `h##` |
| 1 | i | dst[1] = i | `hi#` |
| 2 | `\0` | 退出循环，补 dst[2] = `\0` | `hi\0` |

### 代码

```c
char* my_strcpy(char* dst, const char* src) {
    size_t i = 0;
    // 1. 复制 '\0' 之前的所有字符
    while (src[i] != '\0') {
        dst[i] = src[i];
        i++;
    }
    // 2. 循环在 '\0' 处停下了，别忘了补上结束符
    dst[i] = '\0';
    // 3. 返回原始的 dst
    return dst;
}
```

### 复杂度分析

- **时间复杂度 O(n)**，n 为 `src` 的长度。
- **空间复杂度 O(1)**。

## 🚀 第四步：思路二 —— 指针一行流（经典写法）

### 思路

把"复制"和"判断"合并到一起：先复制，再判断刚复制的字符。`'\0'` 被复制之后条件为假，循环结束，**不需要单独补 `'\0'`**。

### 手动模拟（`src = "hi"`）

| 轮次 | `*d = *s` 复制了 | 值是 '\0' 吗 | 继续？ |
|---|---|---|---|
| 1 | h | 否 | 是 |
| 2 | i | 否 | 是 |
| 3 | `\0` | **是** | 否，结束 |

### 代码

```c
char* my_strcpy(char* dst, const char* src) {
    char* d = dst;                      // 用 d 移动，dst 留着当返回值
    while ((*d++ = *src++) != '\0') {
        // 循环体为空：复制和判断都在条件里完成
    }
    return dst;
}
```

> 💬 `src` 是形参（指针的副本），在函数里移动它不会影响调用者，所以这里直接 `src++` 也没问题。`dst` 就不行了——它要作为返回值。

### 复杂度分析

- **时间复杂度 O(n)**。
- **空间复杂度 O(1)**。

## 🔌 嵌入式实战：为什么规范里禁用 strcpy？

MISRA C、CERT C 等编码规范都不推荐 `strcpy`，因为它**从不检查目标缓冲区的大小**：

```c
char dev_name[8];
strcpy(dev_name, received_name);   // ❌ 上位机发来 20 个字节的名字 → 栈溢出，覆盖返回地址
```

在单片机上这类 bug 的表现是"偶尔死机"或"变量莫名其妙被改"，非常难查。更安全的写法：

```c
// 1. snprintf：一定会以 '\0' 结尾，最多写 sizeof(dev_name) 个字节
snprintf(dev_name, sizeof(dev_name), "%s", received_name);

// 2. 自己写一个带长度的复制（类似 BSD 的 strlcpy）
size_t safe_copy(char* dst, const char* src, size_t size) {
    size_t i = 0;
    if (size == 0) return 0;
    while (i + 1 < size && src[i]) { dst[i] = src[i]; i++; }
    dst[i] = '\0';          // 保证结尾
    return i;
}
```

注意 `strncpy` **并不是**安全版的 strcpy，它在源串过长时不会补 `'\0'`，详见 9037。

## ⚠️ 第五步：小白常见错误

1. **漏了 `'\0'`**：

   ```c
   while (*src) *d++ = *src++;   // ❌ 循环结束时 '\0' 没有被复制
   return dst;
   ```

   判题会输出"没有复制结尾的 '\0'"。
2. **返回了移动后的指针**：直接移动 `dst` 再 `return dst;`，返回的是末尾地址。
3. **条件写成 `*s++ != '\0'` 再复制**：先判断后复制，`'\0'` 正好被跳过，和第 1 条一样。
4. **`=` 和 `==` 混淆**：`while (*d++ == *s++)` 变成了比较，什么都没复制。GCC 对 `while (a = b)` 会提示"suggest parentheses"，加上 `!= '\0'` 意图最清楚。
5. **目标缓冲区不够大**：`char buf[5]; strcpy(buf, "hello");` 需要 6 个字节，多写的 1 个字节会破坏相邻变量。
6. **源和目标重叠**：`strcpy(s + 1, s)` 想把字符串右移一位，结果会把第一个字符刷满整块内存，直到崩溃。重叠时要用 `memmove`（见 9032）。

## 📊 第六步：两种方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 下标循环 + 手动补 '\0' | O(n) | O(1) | ⭐ | 最好理解 |
| 指针一行流 | O(n) | O(1) | ⭐⭐ | 面试经典写法，务必能解释清楚每个符号 |

> 🎯 **学习建议**：先写思路一，确认自己理解"`'\0'` 也要复制"；再把它改写成思路二，对照手动模拟表看每一轮发生了什么。
