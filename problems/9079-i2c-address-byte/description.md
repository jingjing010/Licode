# I2C 七位地址与方向字节

address为7位地址0..127，read为0写或1读。返回总线上传输的地址字节；本题只做编码，不判断保留地址能否用于设备。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int i2cAddressByte(int address,int read);
```

## 示例 1

输入：
```text
0
0
```
输出：
```text
0
```

## 示例 2

输入：
```text
0
1
```
输出：
```text
1
```

## 自定义输入格式

按顺序每行一个参数：address、read。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
