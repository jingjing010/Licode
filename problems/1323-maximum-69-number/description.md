# 6 和 9 组成的最大数字

正整数 num 只由6和9组成，最多改变一位（6变9或9变6），返回可得到的最大整数。num ≤ 10^4。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int maximum69Number(int num);
```

## 示例 1

输入：
```text
9669
```
输出：
```text
9969
```

## 示例 2

输入：
```text
9996
```
输出：
```text
9999
```

## 自定义输入格式

按顺序每行一个参数：n。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
