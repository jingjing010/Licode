# 三个数的最大乘积

从数组选择三个不同下标，返回最大乘积。3 ≤ n ≤ 10^4，−1000 ≤ 元素 ≤ 1000。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
int maximumProduct(int* nums,int numsSize);
```

## 示例 1

输入：
```text
[1,2,3]
```
输出：
```text
6
```

## 示例 2

输入：
```text
[-100,-99,1,2,3]
```
输出：
```text
29700
```

## 自定义输入格式

按顺序每行一个参数：nums。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
