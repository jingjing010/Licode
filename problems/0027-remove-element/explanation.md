# 27. 移除元素 —— 小白详细题解

> 这是一道"原地修改数组"的入门题，学会它，你就掌握了**快慢双指针**这个超级常用的套路。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 给你一排数字和一个数 `val`。请你把所有**不等于** `val` 的数字挪到数组的**最前面**，然后告诉我这样的数字一共有几个（记为 `k`）。

拿示例 2 来说（`val = 2`）：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|---|
| 修改前 | 0 | 1 | **2** | **2** | 3 | 0 | 4 | **2** |
| 修改后（一种可能） | 0 | 1 | 3 | 0 | 4 | ? | ? | ? |

不等于 2 的数是 `0,1,3,0,4`，共 5 个，所以返回 `5`，数组前 5 个位置放这 5 个数。后面的 `?` 是什么都无所谓。

**几个需要注意的细节：**

1. 不能新建数组返回，要**直接修改**传进来的 `nums`，判题程序会去读 `nums` 的前 `k` 个元素。
2. 前 `k` 个元素的**顺序可以任意**。本 OJ 会把它们排好序再比较，所以 `[0,1,3,0,4]` 和 `[4,0,3,1,0]` 都算对。
3. 数组**可能是空的**（`numsSize = 0`），这时直接返回 0。
4. `val` 可能根本不在数组里，这时 `k = numsSize`。

## 🧰 第二步：这道题需要的 C 语言知识

### 1. 为什么在函数里改 `nums[i]`，外面能看到？

```c
int removeElement(int* nums, int numsSize, int val)
```

`nums` 是一个**指针**，存的是数组在内存里的地址。你写 `nums[0] = 5;` 时，是顺着这个地址**直接改了那块内存**。调用者用的是同一块内存，所以能看到变化。

> 对比：普通参数 `int val` 是一份**拷贝**，你在函数里改 `val`，外面看不到。

### 2. "删除"数组元素到底是什么意思？

C 语言的数组**长度是固定的**，没法真的把某个格子"删掉"。所谓"删除"，其实就是：

- 把要保留的数**挪到前面**；
- 用返回值 `k` 告诉调用者"前 `k` 个才是有效的"。

后面那些格子还在，只是没人再关心它们了。

### 3. `k++` 的小技巧

```c
nums[k++] = nums[i];
```

等价于：

```c
nums[k] = nums[i];
k = k + 1;
```

`k++` 是"先用 `k` 的旧值，再把 `k` 加 1"。

## 💡 第三步：思路一 —— 临时数组（最容易想到）

### 思路

1. 申请一个临时数组 `tmp`
2. 从头扫描 `nums`，遇到不等于 `val` 的数就放进 `tmp`
3. 把 `tmp` 的内容拷贝回 `nums` 的前面，释放 `tmp`

### 手动模拟（示例 1：`nums = [3,2,2,3], val = 3`）

| i | nums[i] | 等于 val 吗？ | tmp | k |
|---|---|---|---|---|
| 0 | 3 | 是，丢掉 | [] | 0 |
| 1 | 2 | 否，保留 | [2] | 1 |
| 2 | 2 | 否，保留 | [2, 2] | 2 |
| 3 | 3 | 是，丢掉 | [2, 2] | 2 |

拷贝回去后 `nums = [2,2,2,3]`，返回 `k = 2`，前 2 个是 `[2,2]`，正确。

### 代码

```c
int removeElement(int* nums, int numsSize, int val) {
    // 1. 申请临时数组。numsSize 可能是 0，多申请 1 个避免 malloc(0)
    int* tmp = (int*)malloc(sizeof(int) * (numsSize + 1));
    int k = 0;                              // tmp 里已经放了几个数

    // 2. 扫描：不等于 val 的数放进 tmp
    for (int i = 0; i < numsSize; i++) {
        if (nums[i] != val) {
            tmp[k] = nums[i];
            k++;
        }
    }

    // 3. 拷贝回 nums 的前 k 个位置
    for (int i = 0; i < k; i++) {
        nums[i] = tmp[i];
    }

    // 4. 用完记得释放
    free(tmp);
    return k;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：扫描一遍 + 拷贝一遍。
- **空间复杂度 O(n)**：用了一个和原数组一样大的临时数组。

## 🚀 第四步：思路二 —— 快慢双指针（原地，O(1) 空间）

### 思路

观察思路一：往 `tmp[k]` 写数时，`k` 永远**不会超过** `i`（写的位置不会跑到读的位置前面）。
所以可以直接写回 `nums[k]`——这个位置的数**已经被读过了**，覆盖它不会影响后面。

- **快指针 `i`**：往前扫描每个数（负责"读"）
- **慢指针 `k`**：下一个要保留的数写到哪（负责"写"），`nums[0..k-1]` 是已经整理好的部分

### 手动模拟（示例 2：`nums = [0,1,2,2,3,0,4,2], val = 2`）

| i | nums[i] | 等于 2 吗？ | 操作 | 前 k 个 |
|---|---|---|---|---|
| 0 | 0 | 否 | nums[0] = 0, k = 1 | [0] |
| 1 | 1 | 否 | nums[1] = 1, k = 2 | [0,1] |
| 2 | 2 | 是 | 跳过 | [0,1] |
| 3 | 2 | 是 | 跳过 | [0,1] |
| 4 | 3 | 否 | nums[2] = 3, k = 3 | [0,1,3] |
| 5 | 0 | 否 | nums[3] = 0, k = 4 | [0,1,3,0] |
| 6 | 4 | 否 | nums[4] = 4, k = 5 | [0,1,3,0,4] |
| 7 | 2 | 是 | 跳过 | [0,1,3,0,4] |

返回 `k = 5`。

### 代码

```c
int removeElement(int* nums, int numsSize, int val) {
    int k = 0;                              // 慢指针：下一个保留元素写到 nums[k]
    for (int i = 0; i < numsSize; i++) {    // 快指针：逐个检查
        if (nums[i] != val) {               // 要保留
            nums[k] = nums[i];              // 写到慢指针的位置
            k++;                            // 慢指针后移
        }
        // 等于 val 的直接跳过，相当于"删掉"了
    }
    return k;                               // 前 k 个就是保留下来的元素
}
```

### 复杂度分析

- **时间复杂度 O(n)**：只扫描一遍。
- **空间复杂度 O(1)**：只用了 `i`、`k` 两个变量。

### 🌟 进阶：左右双指针（交换次数更少）

既然题目允许**顺序改变**，那么遇到要删的数时，可以直接拿**数组最后一个数**来填这个坑，并把数组"缩短"一格。
当要删除的元素很少时（比如 `[1,2,3,4,5]` 删 `1`），这种写法几乎不用搬动元素。

```c
int removeElement(int* nums, int numsSize, int val) {
    int left = 0, right = numsSize;         // 有效区间是 [left, right)
    while (left < right) {
        if (nums[left] == val) {
            nums[left] = nums[right - 1];   // 用最后一个数填坑
            right--;                        // 数组缩短一格；left 不动，因为填进来的数还没检查
        } else {
            left++;                         // 这个数保留，看下一个
        }
    }
    return left;                            // 此时 left == right，就是保留的个数
}
```

> 注意：填坑后 `left` **不能**加 1，因为从末尾搬来的数可能也等于 `val`，需要再检查一次。

## ⚠️ 第五步：小白常见错误

1. **返回了新数组或只数个数不改数组** → 返回 `k` 正确但 `nums` 没改，判题程序读前 `k` 个就会发现不对，Wrong Answer。
2. **用 `for` 循环边删边把后面的元素整体前移，却还让 `i++`** → 比如 `[2,2]` 删 2：删掉第一个 2 后第二个 2 挪到了下标 0，而 `i` 已经变成 1，就漏掉了它。
3. **左右双指针写法里填坑后执行了 `left++`** → 例如 `[3,3]` 删 3：`nums[0]` 被最后一个 3 填上后没有再检查，结果返回 1，错误。
4. **忘了空数组** → `numsSize = 0` 时，如果写了 `nums[numsSize - 1]` 之类的访问就会越界。快慢指针写法天然不会出问题。
5. **把 `nums[k++] = nums[i]` 写成 `nums[++k] = nums[i]`** → `++k` 是先加再用，第一个保留的数会写到 `nums[1]`，`nums[0]` 就成了垃圾值。
6. **写了 `main` 函数** → 只需要写 `removeElement`，`main` 由判题系统提供。

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 临时数组 | O(n) | O(n) | ⭐ | 先写这个，理解"保留哪些数" |
| 快慢双指针 | O(n) | O(1) | ⭐⭐ | 必须掌握的标准写法，保持相对顺序 |
| 左右双指针 | O(n) | O(1) | ⭐⭐ | 要删的数很少时赋值次数更少，但会打乱顺序 |

> 🎯 **学习建议**：快慢双指针是"原地修改数组"类题目的万能钥匙，一定要亲手写熟。
