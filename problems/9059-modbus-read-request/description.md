Modbus RTU 主机（例如 PLC、网关、你的 MCU）要读取从机（电表、温控器、变频器）里的数据时，最常用的命令是**功能码 `0x03`：读保持寄存器**（Read Holding Registers）。请求帧固定为 8 个字节：

| 字节 | 内容 | 说明 |
|---|---|---|
| 0 | 从机地址 | `1 ~ 247` |
| 1 | 功能码 | 固定为 `0x03` |
| 2 | 起始地址高字节 | 寄存器地址 `0 ~ 65535`，**高字节在前** |
| 3 | 起始地址低字节 | |
| 4 | 寄存器数量高字节 | 数量 `1 ~ 125`，**高字节在前** |
| 5 | 寄存器数量低字节 | |
| 6 | CRC 低字节 | 对字节 0 ~ 5 计算 CRC-16/MODBUS，**低字节在前** |
| 7 | CRC 高字节 | |

CRC-16/MODBUS 的算法：crc 初值 `0xFFFF`；对每个字节先 `crc ^= byte`，再重复 8 次：最低位为 1 则 `crc = (crc >> 1) ^ 0xA001`，否则 `crc >>= 1`（详见 9049 题）。

请实现函数，把请求帧写入 `frame`，并返回帧的长度 `8`。如果参数不合法，**不写帧、返回 `0`**。不合法的情况包括：

- 从机地址不在 `1 ~ 247` 之间（`0` 是广播地址，广播时从机不会回应，不能用于读操作；`248 ~ 255` 是保留地址）；
- 寄存器数量不在 `1 ~ 125` 之间（一帧响应最多容纳 125 个寄存器）；
- `startAddr + quantity > 65536`（要读的寄存器超出了地址范围）。

### 示例 1

```
输入：slave = 1, startAddr = 0, quantity = 1
输出：[1,3,0,0,0,1,132,10]
解释：前 6 个字节为 01 03 00 00 00 01，CRC = 0x0A84，低字节 0x84 = 132 在前，高字节 0x0A = 10 在后。
```

### 示例 2

```
输入：slave = 17, startAddr = 107, quantity = 3
输出：[17,3,0,107,0,3,118,135]
解释：这是 Modbus 官方协议文档中的例子：11 03 00 6B 00 03 76 87，读 17 号从机的 40108 ~ 40110 号寄存器。
```

### 示例 3

```
输入：slave = 0, startAddr = 0, quantity = 1
输出：[]
解释：0 是广播地址，不能用于读操作，返回 0，输出空数组。
```

### 提示

- `0 <= slave <= 255`
- `0 <= startAddr <= 65535`
- `0 <= quantity <= 65535`

### 函数说明

```c
size_t modbusBuildReadRequest(uint8_t slave, uint16_t startAddr, uint16_t quantity, uint8_t* frame);
```

- `frame`：判题程序提供的缓冲区（至少 8 字节）
- 返回值：写入的字节数（`8`），参数不合法返回 `0`；判题程序输出 `frame` 的前"返回值"个字节

### 自定义输入格式

```
17
107
3
```

3 行依次是 `slave`、`startAddr`、`quantity`。
