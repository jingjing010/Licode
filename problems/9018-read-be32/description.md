某气压传感器通过 UART 上报数据帧，帧格式如下：第 1 个字节是帧头 `0xAA`，后面紧跟一个 **大端（高字节在前）** 的 32 位无符号整数表示气压值（单位 Pa），最后是校验字节。MCU 收到的数据都存放在一个 `uint8_t` 接收缓冲区里。

请实现函数 `read_be32`：从字节缓冲区 `buf` 的下标 `offset` 处开始，读取连续 4 个字节，按 **大端** 规则组装成一个 `uint32_t` 返回。

即：结果 = `buf[offset] × 2^24 + buf[offset+1] × 2^16 + buf[offset+2] × 2^8 + buf[offset+3]`。

**注意**：你的代码必须与运行它的 CPU 是大端还是小端**无关**。

### 示例 1

```
输入：buf = [18,52,86,120], offset = 0
输出：305419896
解释：4 个字节依次是 0x12 0x34 0x56 0x78，大端组装为 0x12345678 = 305419896。
```

### 示例 2

```
输入：buf = [170,0,1,134,160,85], offset = 1
输出：100000
解释：跳过帧头 0xAA，从下标 1 读取 0x00 0x01 0x86 0xA0，组装为 0x000186A0 = 100000（即 100000 Pa）。
```

### 示例 3

```
输入：buf = [1,255,255,255,255], offset = 1
输出：4294967295
解释：从下标 1 读取 0xFF 0xFF 0xFF 0xFF，得到 0xFFFFFFFF = 4294967295。
```

### 提示

- `4 <= buf 长度 <= 1000`
- `0 <= buf[i] <= 255`
- `0 <= offset`，且 `offset + 4 <= buf 长度`

### 函数说明

```c
uint32_t read_be32(const uint8_t* buf, int offset);
```

- `buf`：接收缓冲区首地址（只读）
- `offset`：要读取的 32 位整数在缓冲区中的起始下标
- 返回值：按大端规则组装出的 32 位无符号整数

### 自定义输入格式

```
[18,52,86,120]
0
```

第 1 行是缓冲区 `buf`（每个元素是 0~255 的十进制字节值），第 2 行是 `offset`。输出为十进制整数。
