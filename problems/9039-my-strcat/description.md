嵌入式里经常需要把几段字符串拼起来再发出去，比如拼 AT 指令 `"AT+CWJAP=" + ssid`、拼日志 `"Temp=" + "25C"`。这就要用到 `strcat`。

请你实现 `my_strcat(dst, src)`：把字符串 `src`（包括结尾的 `'\0'`）接到字符串 `dst` 的末尾——`src` 的第一个字符覆盖 `dst` 原来的 `'\0'`。返回 `dst`。

> **不要调用库函数 `strcat` / `strcpy` / `strlen` / `memcpy` 等**，请自己用指针完成。

判题程序准备一个**刚好** `strlen(dst) + strlen(src) + 1` 字节的缓冲区，先放入字符串 `dst`，剩余部分填满字符 `'#'`，然后调用 `my_strcat(dst, src)`，把结果当作字符串输出。

### 示例 1

```
输入：dst = "Temp=", src = "25C"
输出："Temp=25C"
```

### 示例 2

```
输入：dst = "", src = "abc"
输出："abc"
解释：dst 是空串，它的 '\0' 在下标 0，从这里开始复制。
```

### 示例 3

```
输入：dst = "abc", src = ""
输出："abc"
解释：src 是空串，只复制一个 '\0'（覆盖原来的 '\0'），内容不变。
```

### 提示

- `0 <= strlen(dst), strlen(src) <= 10^5`
- 字符串由可打印 ASCII 字符和 UTF-8 编码的中文组成

### 函数说明

```c
char* my_strcat(char* dst, const char* src);
```

- `dst`：以 `'\0'` 结尾的字符串，所在缓冲区足够大
- `src`：要追加的字符串，与 `dst` 的缓冲区不重叠
- 返回值：必须返回 `dst`

缓冲区后面有一段"哨兵"内存。如果结果没有以 `'\0'` 结尾、返回值不是 `dst`，或写到了缓冲区之外，会输出一行错误信息（判为答案错误）。

### 自定义输入格式

```
"Temp="
"25C"
```

两行，分别为带双引号的 `dst` 和 `src`。输出为拼接后的 `dst`。
