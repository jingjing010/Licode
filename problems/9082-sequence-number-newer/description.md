# 16位序列号的新旧判定

循环序列号范围0..65535。定义候选号相对参考号的模差在1..32767时为更新，其他情况返回false，尤其差32768返回false。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
bool sequenceNewer(int candidate,int reference);
```

## 示例 1

输入：
```text
1
65535
```
输出：
```text
true
```

## 示例 2

输入：
```text
65535
1
```
输出：
```text
false
```

## 自定义输入格式

按顺序每行一个参数：candidate、reference。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
