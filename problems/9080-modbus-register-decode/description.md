# Modbus 大端寄存器解析

输入已经通过帧与CRC检查的Modbus寄存器数据区，不含地址、功能码、字节数和CRC。长度为0到250的偶数；返回大端寄存器值数组。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
int* decodeRegisters(const uint8_t* data,size_t len,int* returnSize);
```

## 示例 1

输入：
```text
[18,52,255,255]
```
输出：
```text
[4660,65535]
```

## 示例 2

输入：
```text
[]
```
输出：
```text
[]
```

## 自定义输入格式

按顺序每行一个参数：data。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
