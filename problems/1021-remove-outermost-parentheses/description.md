# 删除最外层的括号

输入有效括号字符串，将每个不可再分的有效括号原语的最外层括号删除。长度2到10^5。

## 约束与接口

返回数组/字符串由调用方释放；不要返回局部数组。

```c
char* removeOuterParentheses(char* s);
```

## 示例 1

输入：
```text
"(()())(())"
```
输出：
```text
"()()()"
```

## 示例 2

输入：
```text
"(()())(())(()(()))"
```
输出：
```text
"()()()()(())"
```

## 自定义输入格式

按顺序每行一个参数：s。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。
