# 338. 比特位计数 —— 小白详细题解

> 191 题是"数一个数里有几个 1"，这题是"把 0 到 n 每个数都数一遍"。每个都单独数当然可以，但更聪明的做法是**利用已经算好的小数的答案**——这就是动态规划最简单的形式。

---

## 📖 第一步：先读懂题目

用大白话说就是：

> 对 `0, 1, 2, ……, n` 这 `n + 1` 个数，分别算出它的二进制里有几个 1，按顺序放进数组返回。

拿示例 2（`n = 5`）来说：

| i | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 二进制 | 0 | 1 | 10 | 11 | 100 | 101 |
| 1 的个数 | 0 | 1 | 1 | 2 | 1 | 2 |

答案是 `[0,1,1,2,1,2]`。

**几个需要注意的细节：**

1. 数组长度是 **`n + 1`**，不是 `n`（包含 0 和 n 两端）。
2. `n` 可以是 0，此时返回 `[0]`。
3. 要用 `malloc` 申请数组，并设置 `*returnSize = n + 1`。

---

## 🧰 第二步：需要的 C 语言知识

### 1. 申请长度为 n + 1 的数组

```c
int* ans = (int*)malloc(sizeof(int) * (n + 1));   // 注意括号：sizeof(int) * (n + 1)
*returnSize = n + 1;
```

### 2. `i >> 1` 和 `i & 1`

- `i >> 1`：去掉 `i` 的最低位，相当于 `i / 2`；
- `i & 1`：取出 `i` 的最低位，相当于 `i % 2`。

```
i      = 1 0 1 1   (11)
i >> 1 =   1 0 1   (5)
i & 1  =         1
```

### 3. `i & (i - 1)`：去掉最右边的 1

```
i           = 1 1 0 0   (12)
i - 1       = 1 0 1 1
i & (i - 1) = 1 0 0 0   (8)   ← 少了一个 1
```

---

## 💡 第三步：思路一 —— 每个数单独数

### 思路

对每个 `i`，用 191 题的 `x & (x - 1)` 方法数 1：每消掉一个 1 计一次数，直到 `x` 变成 0。

### 手动模拟（`i = 5 = 101`）

| 第几次 | x | x & (x - 1) | count |
|---|---|---|---|
| 1 | 101 | 100 | 1 |
| 2 | 100 | 000 | 2 |

### 代码

```c
int* countBits(int n, int* returnSize) {
    int* ans = (int*)malloc(sizeof(int) * (n + 1));
    for (int i = 0; i <= n; i++) {
        int x = i, count = 0;
        while (x != 0) {
            x &= x - 1;     // 消掉最右边的 1
            count++;
        }
        ans[i] = count;
    }
    *returnSize = n + 1;
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n log n)**：每个数最多有 17 个 1（`10^5 < 2^17`）。
- **空间复杂度 O(1)**（不算返回数组）。

---

## 🚀 第四步：思路二 —— 动态规划：`ans[i] = ans[i >> 1] + (i & 1)`

### 思路

观察 `i` 和 `i >> 1` 的关系：`i >> 1` 就是 `i` 扔掉最低位之后的数。

- 扔掉的最低位如果是 0，1 的个数不变；
- 扔掉的最低位如果是 1，1 的个数少了 1 个。

所以：**`i` 中 1 的个数 = `(i >> 1)` 中 1 的个数 + `i` 的最低位**。

而 `i >> 1` 比 `i` 小，**它的答案在前面已经算好了**，直接查表即可！

### 手动模拟（示例 2：`n = 5`）

| i | 二进制 | i >> 1 | ans[i >> 1] | i & 1 | ans[i] |
|---|---|---|---|---|---|
| 0 | 0 | | | | 0（初始值） |
| 1 | 1 | 0 | 0 | 1 | 1 |
| 2 | 10 | 1 | 1 | 0 | 1 |
| 3 | 11 | 1 | 1 | 1 | 2 |
| 4 | 100 | 2 | 1 | 0 | 1 |
| 5 | 101 | 2 | 1 | 1 | 2 |

### 代码

```c
int* countBits(int n, int* returnSize) {
    int* ans = (int*)malloc(sizeof(int) * (n + 1));
    ans[0] = 0;                              // 0 里没有 1
    for (int i = 1; i <= n; i++) {
        // i >> 1 比 i 小，答案已经算好；再加上被扔掉的最低位
        ans[i] = ans[i >> 1] + (i & 1);
    }
    *returnSize = n + 1;
    return ans;
}
```

### 复杂度分析

- **时间复杂度 O(n)**：每个数 O(1) 算出来，一趟扫描。
- **空间复杂度 O(1)**（不算返回数组）。

> 💬 **另一个递推式**：`ans[i] = ans[i & (i - 1)] + 1`。`i & (i - 1)` 是 `i` 去掉最右边一个 1 后的数，它比 `i` 小、少一个 1。两种写法都是 O(n)。

---

## ⚠️ 第五步：小白常见错误

1. **数组只申请了 `n` 个**：`malloc(sizeof(int) * n)` 少一个位置，写 `ans[n]` 时越界。要申请 `n + 1` 个。
2. **`*returnSize = n`**：少输出最后一个数。
3. **`ans[i >> 1] + i & 1` 少了括号**：`+` 比 `&` 先算，变成 `(ans[i >> 1] + i) & 1`，结果只剩 0 或 1。要写 `ans[i >> 1] + (i & 1)`。
4. **从 `i = 0` 开始用递推式**：`ans[0] = ans[0] + 0` 读了一个还没初始化的值（`malloc` 不会清零）。要先写 `ans[0] = 0`，循环从 1 开始。
5. **`malloc(sizeof(int) * n + 1)`**：只多申请了 1 个**字节**而不是 1 个 `int`。乘法要括起来：`sizeof(int) * (n + 1)`。

---

## 📊 第六步：方法对比

| 方法 | 时间复杂度 | 空间复杂度 | 难度 | 建议 |
|---|---|---|---|---|
| 每个数单独数 | O(n log n) | O(1) | ⭐ | 先写对 |
| 动态规划 | O(n) | O(1) | ⭐⭐ | 满足进阶要求，体会"利用小问题的答案" |
