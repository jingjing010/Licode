# 扩展 CAN 标识符组装

自定义29位扩展CAN ID：位28..26为priority(0..7)，位25..16为node(0..1023)，位15..0为message(0..65535)。返回组装的ID，不包含硬件寄存器中的IDE/RTR位。

## 约束与接口

只实现函数，输入输出由平台处理。

```c
uint32_t composeCanId(int priority,int node,int message);
```

## 示例 1

输入：
```text
1
2
3
```
输出：
```text
67239939
```

## 示例 2

输入：
```text
7
1023
65535
```
输出：
```text
536870911
```

## 自定义输入格式

按顺序每行一个参数：priority、node、message。数组使用 `[1,2]`，字符串使用双引号。数组长度由平台自动传入。

本题在主机上模拟固件逻辑；实际移植时需根据芯片手册接入外设和临界区。
