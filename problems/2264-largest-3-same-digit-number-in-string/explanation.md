# 字符串中最大的 3 位相同数字：题解

## 📖 先读懂题目

返回数字字符串中最大的连续三位相同数字子串，允许000；不存在则返回空字符串。长度3到1000。

| 示例 | 输入参数 | 返回结果 |
|---|---|---|
| 1 | `"6777133339"` | `"777"` |
| 2 | `"2300019"` | `"000"` |

## 🧰 需要的 C 语言知识

C字符串以`'\0'`结束，`strlen`返回有效字符数，不包含结束符。使用`ctype.h`判断字符时先转成`unsigned char`，避免负char带来未定义行为。

申请输出字符串时，要在有效字符之外多留1字节写入结束符。参考实现返回动态内存，由调用方负责释放。

## 💡 推导与实现

只检查长度3的窗口，三位相等则比较该数字字符的大小。

先按定义手工处理第一个示例，再确认每一步保存的状态足够决定下一步。循环结束时只返回题目要求的结果，不返回尚未处理的中间状态。

```c
char *largestGoodInteger(char *num) {
    char best = 0;
    for (int i = 2; num[i]; ++i)
        if (num[i] == num[i - 1] && num[i] == num[i - 2] && num[i] > best)
            best = num[i];
    char *out = malloc(4);
    int n = best ? 3 : 0;
    for (int i = 0; i < n; ++i)
        out[i] = best;
    out[n] = 0;
    return out;
}
```

## 📊 复杂度与取舍

| 方法 | 代价 | 用途 |
|---|---|---|
| 上述实现 | 时间 O(n)，输出空间 O(1) | 正式提交 |

## ⚠️ 常见错误

- 忘记字符串末尾的`'\0'`，导致打印越过已申请内存。
- 只申请有效字符数大小的缓冲区，没有给结束符留空间。
- 忽略题面约束与特殊边界，直接把某个正常样例的结论推广到所有输入。
- 先用int乘法再转换到64位；溢出已经发生，转换无法补救。

## 🔗 举一反三

尝试把同一处理过程改成逐个输入的流式接口，思考需要保留哪些状态。用空边界、最小值、最大值和重复值检查自己的实现。
